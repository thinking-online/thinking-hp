# 第1章　基本の基本編　図の仕様

2色（黒＋ネイビー #15467E）、線画。文字は最小限。
図だけ見て意味が取れること。本文を読まないと分からない図は作らない。

全部で7点。02に1点、03〜08に各1点。

---

## 02　バケツ3つ（この本で初出。巻頭にバケツは出ない）

横に3つならべる。

```
　1　穴が空いたバケツ　水を注いでいる　下から漏れている
　2　穴をふさいだバケツ　1と同じ量を注いでいる　半分たまっている
　3　穴をふさいだバケツ　多く注いでいる　いっぱいになっている
```

注ぐ水の線の太さは、1と2で同じにする。ここが図の仕事。
同じ量なのに、2にはたまる、を目で分からせる。

下に3語だけ。　やめる　／　直す　／　やる

巻頭にバケツは出てこない。ここが初出なので、3つで1組として描く。
古い企画書（docs/03、docs/11）には「巻頭の3コマ」と書いてあるが、
著者が巻頭を11個の数字に書き換えたときに落ちている。そちらが古い。

## 03　選ぶ力　2時間の横棒

横棒を2本、上下にならべる。長さは同じ（＝同じ2時間）。

```
　上　5等分。それぞれの区切りの中に、短い進み線。どれもゴール線に届いていない
　下　区切りなし。1本の進み線がゴール線まで届いている
```

右端にゴール線（縦の点線）。

左に見出し2つ。　上「5冊に手をつけた」　下「1冊に絞った」
右に結果2つ。　　上「0点」　　　　　　下「点になる」

同じ長さの棒だと一目で分かることが条件。棒の長さを変えない。

---

## 04　入れる力　入れる矢印と、出す矢印

左に本、まん中に頭、右に紙。横一列。

```
　上の矢印　本　→　頭　　太い　　ラベル「入れる」　添え「目を開けていれば、起きる」
　下の矢印　頭　→　紙　　細い　　ラベル「出す」　　添え「自分で探さないと、起きない」
```

下の矢印だけ、ネイビー。上は黒。

いちばん下に1行。　テストの日に使うのは、下の矢印だけ。

太さの差をはっきりつける。楽な作業と、重い作業の差が絵で出ること。

---

## 05　つなげる力　ばらばらの点と、つながった点

上下2段。

```
　上　点を3つ、離して置く。それぞれから上へ短い線が1本ずつ（3本、別々）
　下　同じ点3つ。3つが1か所で合流していて、そこから上へ太い線が1本
```

上の3本のうち1本を、途中で切れた点線にする（＝1本切れたら、その1語は出ない）。
下の合流点はネイビーの丸。そこから出る1本が「取っ手」。

点の横に小さく　available　capable　reliable
合流点の横に　-able

左に見出し。　上「1個ずつ覚える」　下「くっつける」

---

## 06　出す力　一方通行の道

横長の道を1本。7×1 から 7×9 までの目盛りを9つ。

```
　上　左から右への矢印。太い実線。ラベル「上から言う練習　2000回」
　下　右から左への矢印。点線で、途中で切れている。ラベル「逆から言う練習　0回」
```

切れたところに小さく「ここで止まる」。

下に1行。　練習した形でしか、出てこない。

道は1本であることが大事。同じ道なのに、片方向にしか通れないという絵。

---

## 07　なおす力　問題文の4行と、止まった指

問題文を4本の横線で表す（文字は書かない）。

```
　1行目　　黒い線　　右に小さく「読めた」
　2行目　　黒い線　　右に小さく「読めた」
　3行目　　ネイビーの線　右に「ここで止まった」　左から指のアイコンが指している
　4行目　　グレーの線　右に小さく「以降、ついていけない」
```

右に、3行目から矢印を1本出して、小さな四角へ。
四角の中は2行。　知らなかった　／　気づかなかった

直すのは問題ではなく、この1行、が伝わること。

---

## 08　続ける力　回る円と、止まった円

左右に円を1つずつ。

```
　左　×　円の上に「やる気」、下に「始める」。「やる気」のところで矢印が切れている
　　　　　円が回っていない。切れ目に小さく「ここで待っている」

　右　○　円の上に「始める」、下に「やる気」。矢印がつながって、円が回っている
　　　　　回転方向の矢じりを2つ入れる
```

右の円のまん中に小さく「3分」。

左の円は黒、右の円はネイビー。

待つ側は止まり、始める側は回る、が一目で出ること。
