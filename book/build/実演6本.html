章の入口の実演　6本

各章の入口に置く2ページ。問いが右ページ、答えが左ページ。
説明より先に、読者にその場で失敗させる。巻頭の11個の数字と同じ作り。
組み指定　問いと答えは、かならず別ページ。同じ見開きに答えが見えていたら死ぬ。

選ぶ力　問いのページ

テストまで、あと1週間。

範囲は40問あります。1日に使えるのは、2時間。

2人います。

　　Ａ　40問ぜんぶを、1回ずつやる
　　Ｂ　40問のうち13問を、3回ずつやる

どちらが、点が高いと思いますか。

（めくってください）

選ぶ力　答えのページ

Ｂです。

テストで点になるのは、できる問題だけです。

Ａは、40問すべてが「1回やった」で止まります。
1回やった問題は、まだできるになっていません。
テスト当日、40問すべてが「見たことはある」になります。

Ｂは、13問が「できる」になります。残りの27問は、白紙です。

40問を見たことがある人と、13問できる人。
点が入るのは、13問のほうです。

ここで、いちばん大事なことを言います。

Ａを選んだ人は、27問を捨てなかったのではありません。
40問ぜんぶを、捨てたのです。

ただし、Ｂには条件が1つあります。
その13問が、テストに出る13問であること。

どれをやるかを、先に決める。それが、この章です。

では、聞かせてください。
次のテストで、あなたが3回やる問題は、どれですか。

30秒で、3つ書いてください。

入れる力　問いのページ

次の文を1回だけ読んで、下の問題に答えてください。

　　アミラーゼという酵素はグルコースがつながってできたデンプンを分解するが、
　　同じグルコースからできていても、形が違うセルロースは分解できない。
　　問　セルロースは（　　　）と形が違う。
　　　　1　デンプン
　　　　2　アミラーゼ
　　　　3　グルコース
　　　　4　酵素

（めくってください）

入れる力　答えのページ

答えは、1のデンプンです。

正解できた人も、できなかった人も、1つ確かめてください。

アミラーゼが何か、知っていましたか。
グルコースが何か、説明できますか。
セルロースを、見たことがありますか。

たぶん、全部ノーです。それでも、解けます。

この問題は、知識を1つも使いません。使うのは、文の形だけです。

　　アミラーゼは、Ａを分解する。
　　でも、Ｂは分解できない。
　　なぜなら、ＡとＢは形が違うから。

だからセルロースと形が違うのは、デンプンです。

3を選んだ人は、「同じグルコースからできていても」に引っぱられています。
2や4を選んだ人は、知っている言葉を拾いに行っています。

言葉を拾って読むと、知らない言葉が出てきた時点で止まります。
形をつかんで読むと、知らない言葉が5つ出てきても、解けます。

あなたが「難しい」と思ってきた参考書の解説は、
知らない言葉が多かったのではなく、形をつかんでいなかっただけかもしれません。

つなげる力　問いのページ

次の6つの英単語を、10秒で覚えてください。

　　import　　export　　portable
　　transport　　porter　　report

はい、10秒。

　　　……

本を伏せて、6つ言えますか。

たぶん、3つか4つで止まったはずです。

では、1つだけ、教えます。

（めくってください）

つなげる力　答えのページ

port は、運ぶ、という意味です。

　　im（中へ）　　＋　port　＝　中へ運ぶ　　　　輸入する
　　ex（外へ）　　＋　port　＝　外へ運ぶ　　　　輸出する
　　port＋able（できる）　　＝　運べる　　　　　持ち運べる
　　trans（越えて）＋port　＝　越えて運ぶ　　　 輸送する
　　port＋er（人）　　　　　＝　運ぶ人　　　　　荷物運び
　　re（うしろへ）＋port　＝　持ち帰って伝える　報告する

もう一度、見てください。

　　import　　export　　portable
　　transport　　porter　　report

6つ、言えますよね。

覚えた数は、6つから1つに減りました。
port という1つだけです。

そして、次に support という単語が出てきたとき、
あなたは意味を推測できます。下から（sup）運ぶ。支える。

7つ目は、覚えなくても手に入りました。

これが、1つ入れて10動かす、ということです。

出す力　問いのページ

次の4行を、1回だけ読んでください。

　　鎌倉幕府は、将軍と御家人の主従関係で成り立っていた。
　　将軍は御家人の領地を保護し、これを御恩といった。
　　御家人は戦のときに命がけで戦い、これを奉公といった。
　　この御恩と奉公の関係を、封建制度という。

読みましたか。

わかりましたか。

　　　……

では、本を伏せてください。

いま読んだ4行を、紙に書いてください。

（めくってください）

出す力　答えのページ

書けましたか。

たぶん、1行目の途中で止まったはずです。

「御恩」と「奉公」という言葉は出てきたけれど、
どっちがどっちか、あやしくなったと思います。

さっき、あなたは「わかった」と思いました。
それは嘘ではありません。読んでいる間は、本当にわかっていました。

でも、出せませんでした。

わかった、と、出せる、は、別のものです。

テストの日にあるのは、出せるほうだけです。
本を開いて読み返すことは、できません。

ここから先、この本では、こう言います。

　　読んで、わかった　　　　　→　　まだ0個
　　閉じて、書けた　　　　　　→　　1個

さっきの4行を、もう一度読んでから、また閉じてみてください。
2回目で書けたら、それが1個です。

直す力　問いのページ

ある生徒の答案です。

　　　2x ＋ 3 ＝ 7 － x
　　　2x － x ＝ 7 － 3
　　　　　　x ＝ 4
　　　答え　x ＝ 4

正しい答えは、x ＝ 4/3 です。この答案は、間違っています。

では、直すべきなのは、どの行ですか。

　　　ア　1行目
　　　イ　2行目
　　　ウ　3行目
　　　エ　答えの行

（めくってください）

直す力　答えのページ

イの、2行目です。

×がつくのは、答えの行です。
だから多くの人は、答えの行を見ます。

でも、答えの行は、ただの結果です。
崩れたのは、その3行前です。

　　　2x ＋ 3 ＝ 7 － x

右辺の －x を左辺に移すと ＋x、左辺の ＋3 を右辺に移すと －3。
つまり、正しくはこうなります。

　　　2x ＋ x ＝ 7 － 3

この生徒は、移項したときの符号を、逆に書きました。

3行目も、答えの行も、2行目からは正しく計算されています。
つまり、この生徒は計算はできます。できていないのは、移項です。

もし「答えを間違えた」で片づけたら、次も同じところで崩れます。
「移項の符号を間違えた」まで戻ったら、次から直ります。

直すのは、×がついた場所ではありません。
最後に合っていた場所の、次です。

回す力　問いのページ

質問を、2つします。

　　1　先週の月曜日、何時間勉強しましたか。
　　2　先週の月曜日、何ができるようになりましたか。

どちらも、思い出してから、めくってください。

（めくってください）

回す力　答えのページ

1は、答えられた人がいると思います。

2時間くらい、とか、ほとんどやってない、とか。だいたいでも出てきます。

2は、どうでしたか。

たぶん、1つも出てこなかったはずです。

これは、記憶力の問題ではありません。
数えていないものは、思い出せないからです。

あなたは先週、時間を数えていました。だから時間は出てきます。
できるようになった数は、数えていませんでした。だから出てきません。

そして、人は、数えていないものを増やせません。

回す力とは、根性で続ける力ではありません。
何周したかが、あとから数えられる形にしておく力です。

明日から、1日の終わりに1行だけ書いてください。

今日、できるようになったこと1つ

これだけで、来週の月曜、2の質問に答えられます。
