# 01　定義と図

## 定義

正式版
成績が伸びる人とは、必要な「できない」を、期限までに「できる」に変えた数が多い人。

短縮版
必要な「できない」を「できる」に変えた数が多い人。

### なぜこの定義か

- 一言で言い切れる
- 聞いた瞬間に常識が1つひっくり返る（時間→数）
- 反証できる。10時間やって1つも変えていない人は、この定義では伸びない人
- 頑張っているのに伸びない読者が救われる。才能でも時間でもなく、数の問題
- 定義の言葉が、そのまま6つの力に分解される
- 45の見開き全部の判定基準になる。「この行動は、数を増やすか減らすか」

### 反例と、その閉じ方

- 勉強していないのに成績がいい人　→　主語を「伸びる人」にしたので反例にならない。伸びるは変化、頭がいいは状態
- 重い1つを変えたら一気に伸びた人　→　「数」の定義で閉じる。芋づるで変わった分も数える
- 数は多いが試験に出ないものだった人　→　「必要な」の定義で閉じる
- 変えたはずが本番で戻った人　→　「できる」の定義で閉じる。本番で出せてできる
- 期限のない勉強　→　対象外と第1章で明言する。試験のある勉強の本

### 「期限までに」の扱い

正式版には入れる。「多い」の分母（同じ期限の中で比べる）と、伸びると受かるをつなぐ橋（数が多ければ伸びる、期限までに揃えば受かる）の2つの役割。
短縮版では外す。括弧書きにはしない。

### 定義の表現の使い分け

- 表紙・帯　「秘密は、数え方にある」「昨日、何個できるようになった？」
- 第1章の言い切り　正式版
- 45法則の結論　「数が増える／減る」
- 図の説明　「できない」と「できる」のあいだを、何往復もしている
- 親向け章　「何時間やったの？」を「何個できるようになった？」に変える
- 付録　「できた数カレンダー」

### 頭のなかの先生（説明装置。定義ではない）

伸びる人の頭のなかには先生がいる。伸びない人の頭のなかには生徒しかいない。
6つの力は、頭のなかの先生がやっている6つの仕事。
第1章で「なぜ数が多いのか」の答えとして使う。定義に混ぜない。定義は測れるもの、比喩は腹落ち用。

## 図

### 4段階で出す（第1章の中で順番に）

図1　勉強とは、この矢印のこと
　できない　→　できる。箱2つ、矢印1本。

図2　「できない」は1つではない
　知らない　→　知っている　→　わかっている　→（解いてみる：○／×）→　できる
　知らない・知っている・わかっている、の3つの箱の上に「できない」と括る線を1本。
　一言　「わかっている」と「できる」は、違う段階です。
　この図が本のメッセージ。SNSと面談で使う。

図3　うまくいかないときは、さかのぼる。しかも、忘れる
　×から、知らない／知っている／わかっている、の3箇所へ扇状に戻る矢印3本（さかのぼる）。
　できる　→　知っている、へ点線の矢印（忘れる）。
　さかのぼるは自分の意思で戻る。忘れるは勝手に戻る。別物として描く。

図4　完全版
　左に漏斗（できないがたくさん入り、必要なできないだけ通る。捨てられたものは×で1つ2つ落ちている）。漏斗の出口に「必要なできない」のラベル。
　4つの箱、解いてみるの判定（○／×）、さかのぼる3本、忘れる1本。
　右端は状態ではなく「できるの数」のカウンター（+1）。できるの箱には「本番で自力で出せる」と小さく添える。
　下に「今日 → 試験日」の片向きの線。回す力はこの線の上に置く。
　6つの力は、図の中の要素と色で対応させる。上に凡例として横一列。説明文と点線は付けない。
　　捨てる力　青　→　漏斗
　　突き止める力　緑　→　3つの箱を囲む枠（虫眼鏡）
　　つなげる力　黄　→　知っている→わかっているの矢印
　　取り出す力　桃　→　解いてみるの矢印と判定
　　さかのぼる力　赤　→　戻る3本の矢印
　　回す力　紫　→　今日→試験日の線
　タイトルは定義の1文。図の下に定義の別バージョンを置かない（動詞が違う文を2つ置かない）。

### 図の運用

- 完全版は、第1章の最後、まとめ、見返し（折り込み）の3箇所
- 各章の扉に、完全版を灰色にして、その章の力だけ色をつけた版。6章で6枚
- 各見開きの隅に、完全版を小さく置き、伸びない人の道とあの子の道を色で描く
- 表紙に図は使わない
- 主人公のキャラクターは1人で通す。性別や年齢の幅は杉浦さんとデザイナーの判断に委ねる

### 7つの型の図上の位置

- 今日は6時間型　知っているの箱に溜まって、解いてみるを通っていない
- 参考書ルート型　漏斗がない
- 全部わからない型　自分がどの箱にいるかを間違えている
- 10回書く型　知っている→わかっているの矢印がない
- あーね型　わかっているで止まって、できるだと思っている
- あとで付箋型　×のあと、さかのぼっていない
- 計画表に1時間型　図が回っていない
