# 03　目次と45法則

形式　問いから入る本。はじめに（1問）、章扉（6問）、見開き（45問）の三層。
各見開きは `04_見開きテンプレート.md` の型で書く。
左ページの入口に「分かれ道」（伸びない人／伸びる人の4行対比）を置く。

## はじめに

Q　あなたは塾の先生です。生徒が「毎日5時間やってるのに上がりません」と言っています。時間は増やせない。参考書も、塾も、変えられない。あなたなら、何を変えますか。
直感の答え　やり方を教える。復習の仕方を変える。
本当の答え　生徒の勉強は何も変えない。変えたのは、先生の質問。「何時間やった？」を「何個できるようになった？」に変えた。その日、生徒は答えられなかった。1週間後、3つ、と答えた。1ヶ月後、数を答えるために、勉強のやり方が勝手に変わっていた。
原理　生徒の行動を変えるのではなく、数える物差しを変える。
形式　エレベーター本の導入に倣い、1ページ1問、余白を広く、答えはめくった先。4ページ。
注意　1ページ目で読者に役を振らない。「あなたは塾の先生です」は置かず、問題だけを渡す。
先生の側に座ってもらうのは、第1章で予告してから、6つの章扉で。

## あの子が、絶対にやらない45のこと

見開き1枚。はじめにの直後、序章の前。
表紙の約束を、本の入口で回収するためのページ。番号とチェック欄と1行だけ。
45行は、各見開きの分かれ道の左列に1対1で対応する。6つの力の名前はここでは出さない（章番号だけ）。
書店の立ち読みで完結し、そのまま買う理由になるページとして設計する。

## 序章　あなたは、何を数えている？

見開き1　数える診断
- 左ページ導入　サボっている人は、この本を読んでいません。あなたは、やっている。昨日の勉強を思い出して、書ける数を全部書いてください
- 昨日、勉強した時間／進んだページ／解いた問題／覚えた単語や公式／今の問題集は何周目／立て直した計画
- 最後の1つ　昨日、新しく「できる」ようになったこと　1、2、3
- 右ページ上　上の6つは書けた。最後の3つは？　書けなかった人は、できるの数以外の何かを数えている。それが型。上の6つのうち一番はっきり書けたものに印。それが主の型
- 右ページ下　場面で確かめる3問（あの子の選択肢も隠さず並べる）
　解説を読み終えた。次にすることは。　「あーね」と次へ→5／「あとで」の付箋→6／解説を閉じて白紙に解き直す→あの子
　勉強を始める。最初にすることは。　続きのページ→2／計画を立て直す→7／配点の高いところのできないを1つ選ぶ→あの子
　わからない問題がある。先生に何と言うか。　「全部わからないです」→3／「ここは知ってるけど、ここから先が出てこない」→あの子

見開き2　7つのカウンター
- 7つの型をカウンターの絵で並べ、右端にあの子の「できる」カウンター
- 各カード　1行、セリフ、見えている姿、頭のなか、読む章
- 下段　7つとも、頑張っている人の型です。この本は、カウンターを付け替える本です
- この本の読み方　自分の型の章から読んでいい。ただし第1章だけは先に

## 第1章　あの子の頭のなかでは、何が起きているのか

- Q　同じ参考書、同じ3時間。片方だけ伸びた。何が違った？
- この本の2人　やればやるだけ伸びるあの子と、やっても伸びない人。どちらも勉強している
- 「頭がいい人」ではなく「伸びる人」の話をする
- 法則1　成績は、時間ではなく「できない」を「できる」に変えた数で決まる（図1、図2）
- 「必要な」とは何か、「できる」とは何か、「数」とは何か
- 法則2　「わかっている」と「できる」は、別の段階（図2）
- 法則3　解けなかったら、×の場所ではなく、最後にできていた場所に戻る（図3）
- 伸びると、受かるは違う
- あの子の頭のなかには、先生がいる
- 図4、完全版。6つの力は、この図を回す先生の6つの仕事
- 7つの型を、図の上に置く

## 第2章　あの子には「捨てる力」がある

章扉Q　英語の長文が読めない、と言う高校生。長文の練習をさせますか。
答え　させない。志望校の過去問で長文の配点を数えさせた。文法と語彙の配点のほうが大きかった。
原理　苦手を減らすより先に、どの苦手を減らすかを決める。

| 番号 | Q | 法則 |
|---|---|---|
| 4 | 志望校の過去問、まだ解けない。開く？ | 過去問は、解くためではなく捨てるために、最初に開く |
| 5 | 参考書3冊やって伸びない。4冊目、買う？ | 買う前に、終わらせる1冊を決める |
| 6 | 今日、何から始める？1ページ目？ | 1ページ目ではなく、配点の大きい「できない」から始める |
| 7 | 苦手が5つある。全部つぶす？ | 苦手は、順番を決めてから1つずつ |
| 8 | 模試が返ってきた。まず見るのは、点数？ | 模試は、捨てていい単元を見つけるために見る |
| 9 | 計画、理想の自分で立てる？ | 計画は、今の自分からしか立てられない |
| 10 | 「全部やった」と言える？ | 捨てた単元を言えるのが、設計した証拠 |

章末　捨てるとは、数を「必要な数」にすること

## 第3章　あの子には「突き止める力」がある

章扉Q　数学が「全部わからない」と言う生徒。基礎からやり直させますか。
答え　やり直させない。問題文を1文ずつ日本語に訳させたら、3文目で止まった。わからなかったのは数学ではなく、3文目の日本語だった。
原理　全部わからない、は存在しない。止まっている1行がある。

| 番号 | Q | 法則 |
|---|---|---|
| 11 | 問題文の途中で、パターンがわかった。解き始める？ | 問題文は、最後まで読んでから解く |
| 12 | 何を聞かれているか、言える？ | 解く前に、設問を自分の言葉で言い換える |
| 13 | 授業中、板書を写す？ | 板書は写さず、先生の話を1行に要約する |
| 14 | 「全部わからない」と言いそうになった | 全部ではなく、止まった1行を指さす |
| 15 | 難しい、と思った。知らない？わかっていない？ | 知らないと、わかっていないを分けてから動く |
| 16 | 文章のまま考えている | 図に描き直せないものは、まだつかめていない |
| 17 | 長文、本文から読む？ | 設問を先に読んで、本文に探しに行く |

章末　突き止めるとは、「できない」の場所を1点に絞ること

## 第4章　あの子には「つなげる力」がある

章扉Q　英単語が覚えられない、と言う生徒。単語帳を変えますか。
答え　変えない。単語帳の日本語訳のほうをテストしたら、半分答えられなかった。覚えられなかったのは英語ではなく、つなげる先の日本語がなかった。
原理　新しいものは、知っているものにしかつながらない。

| 番号 | Q | 法則 |
|---|---|---|
| 18 | 新しい問題。ゼロから考える？ | 解く前に、前に見た形を探す |
| 19 | 覚える前に、なぜ、を持ってる？ | 覚える前に「なぜ」を1つつける |
| 20 | 単語10個、10回ずつ書く？ | 1つの例文で、10個覚える |
| 21 | 覚えたもの、別の科目で使った？ | 覚えたものは、別の科目で1回使う |
| 22 | 似たもの、それぞれ覚える？ | 似たものは、違いだけで覚える |
| 23 | 覚えるとき、見る？思い出す？ | 覚えるとは、見ることではなく思い出すこと |
| 24 | まとめノート、作る？ | まとめは紙ではなく、頭のなかに作る |

章末　つなげるとは、1つ変えて、10変えること

## 第5章　あの子には「取り出す力」がある

章扉Q　問題集を2周した、と言う生徒。本当に解けているか、何を見ますか。
答え　別冊解答を見た。本体より解答冊子のほうがボロボロだった。解きながら見ていた。2周分「わかった」を積んで、「できる」は1つもなかった。
原理　できるかどうかは、解説を閉じたときにしかわからない。

| 番号 | Q | 法則 |
|---|---|---|
| 25 | 解説を読んで、納得した。次、どうする？ | 解説を閉じて、白紙に解き直す |
| 26 | 「わかった」と思った。信じる？ | わかった、は出せるまで信じない |
| 27 | できたかどうか、何で判定する？ | 白紙に出せるかで判定する |
| 28 | 友達に説明して、と言われた | 説明できないものは、まだできていない |
| 29 | 制限時間、つける？ | 本番と同じ時間で解けて、はじめてできる |
| 30 | 解けない問題、どこに置く？ | 解けない問題は、隠さず集める |
| 31 | 途中までしかわからない。手を止める？ | 途中までを自力で書く。そこができないの境目 |

章末　取り出せて初めて、「できる」と数える

## 第6章　あの子には「さかのぼる力」がある

章扉Q　同じ問題を3回間違えた生徒。4回目を解かせますか。
答え　解かせない。1つ前の、正解していた問題を解説なしで解き直させたら、解けなかった。正解はまぐれだった。崩れていたのは、間違えた問題ではなく、正解していた問題のほうだった。
原理　戻る場所は、×の場所ではない。最後に本当にできていた場所。

| 番号 | Q | 法則 |
|---|---|---|
| 32 | 間違えた。まず見るのは、正解？ | 正解より先に、どこで崩れたかを探す |
| 33 | 「ケアレスミス」と言いそう | ケアレスミスと言った瞬間、原因は消える。なぜ、を3回 |
| 34 | 同じ問題を、3回間違えた。4回目、やる？ | 4回目より、1つ前のできていた問題を解き直す |
| 35 | 間違いノート、何を書く？ | 間違いノートには、正解ではなく原因を書く |
| 36 | 間違いが10個。数える？分ける？ | 間違いは数えず、種類で分ける |
| 37 | 解説、最初から読み直す？ | 解説は、どこから読めなくなったかだけ探す |
| 38 | 点数が下がった。自分を責める？ | 下がったら、自分ではなく、変えたことを見る |

章末　さかのぼるとは、失敗を数に変えること

## 第7章　あの子には「回す力」がある

章扉Q　「やる気が出ない」と言う生徒。やる気の出し方を教えますか。
答え　教えない。帰る前に、明日やる1問を机の上に開いたまま置いて帰らせた。翌日、座った時点でやることが決まっている。やる気は必要なかった。
原理　やる気を出すのではなく、やる気がいらない状態を作る。

| 番号 | Q | 法則 |
|---|---|---|
| 39 | やる気が出ない。待つ？ | やる気は、計画に入れない |
| 40 | 机に座った。最初の10分、何をする？ | 最初の10分は、毎日同じことにする |
| 41 | 勉強、何を記録する？ | 時間ではなく、できた数を記録する |
| 42 | 今日、何で終える？ | 今日できた1つ、で終える |
| 43 | 崩れた日。計画を捨てる？ | 崩れる日は、最初から計画に入れておく |
| 44 | 忘れた。自分を責める？ | どうせ忘れる。戻る日を、先に決める |
| 45 | 計画、いつ直す？ | 計画は、週に1回だけ直す |

章末　回すとは、期限までに数を揃えること

## 章扉の6問について

現在の6問は作り話。著者の実話に差し替えられるものは差し替える（`08` 参照）。
