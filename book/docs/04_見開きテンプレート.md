# 04　見開きテンプレート

参考にした形式　『小さなビジネスモデル100』（Q＋HINT／成功例＋発想のコツ＋POINT＋例）。
1法則＝1見開き。右ページが問い、めくった左ページが答え。

## 右ページ（問い）

1. 力の名前と法則番号（例　取り出す力　25）
2. 場面タグ　1語（解説を読んだあと／定期テスト前日／模試の翌日／授業中／単語帳の前で など）
3. Q　生徒が実際に口にする質問を、そのまま置く（2026-09-08 変更）
　　　著者が作った選択肢の言い方（「計画、理想の自分で立てる？」など）は使わない。
　　　塾で本当に聞かれる形（「計画って、どう立てればいいですか」）にする。
　　　判定基準は、その言葉を録音の書き起こしに見つけられるかどうか。
　　　右ページでいちばん大きい文字になるので、ここが読者の「自分だ」を決める
4. 状況文　3〜4行。中学生か高校生の具体場面。固有名詞（科目、教材の種類、テスト名）を入れる
5. イラスト
6. HINT　1行。答えを言わず、探す場所だけずらす（隣の層を指す）

## 左ページ（答え）

1. 分かれ道　4行×2列の対比表。左が伸びない人、右が伸びる人。ここが左ページの入口で、目で見て差がわかる部分
2. 伸びない人の答え　2〜3行。何をして、何を数えて、図のどこで止まるか。必ず、頑張っている人の思考として書く。この選択をする理由を1つ持たせる
3. 伸びる人の答え　3〜4行。何をして、何を数えて、図のどこへ進むか。実行できる形で書く
4. 法則　番号つきで1行。マネできる行動の形で言い切る（`03` の法則文）
5. 他の場面で　同じ法則を別の科目・別の場面で使う例を2つ（数学で／定期テストで、など）
6. 結論の一行　できないノートの行が「1行消える」か「1行増える」かに着地させる（`01` の数の単位）
　　　増える側も前進として書く。全45法則がこの2つのどちらかに着地していること
7. 隅の図　完全版を小さく置き、伸びない人の道と伸びる人の道を色で描く

### 分かれ道の4行（全45法則で固定）

| 行 | 何を書くか |
|---|---|
| すること | 行動だけ。そのままマネできる粒度で。「意識する」は書かない |
| 数えているもの | 頭のなかで回っているカウンター。7つの型と対応させる |
| 図の上では | どの箱で止まるか／どの矢印を通るか。図の言葉だけで書く |
| 試験の日に | その積み重ねが本番でどうなるか。定義の「期限までに」に着地させる |

各セルは15字前後まで。長い説明は下の散文に置く。
この表は、まとめの「45の分かれ道」一覧にそのまま流用する。

## 二項対立の主語

伸びない人／伸びる人。この2つで揃える（`00` の確定事項）。
「あの子」は、表紙・序章・第1章・章タイトル・まとめ・帯で使う言葉。
第1章の冒頭で「伸びる人＝あの子」とつないであるので、45の見開きの中では伸びる人で通す。
片方だけ愛称（あの子）にすると、対立の軸が非対称になって、対比が効かなくなる。

## 書くときの条件

- 伸びない人の答えは、まともに見えること。Aを選ぶ人がAを選ぶ理由を必ず1つ持てるようにする。ここが崩れると「正解はBでした」を45回読まされる本になる
- 答えは、問いと同じ層に置かない。隣の層（先生の質問、日本語、別冊解答、正解した問題、机の上）に置く。HINTがその層を指す
- 答えは1つの行動にする。「意識を変えよう」ではなく「解説を閉じる」
- 中学生の場面と高校生の場面を、章の中で4対3か3対4で混ぜる
- 分かれ道の表と、下の散文で、同じことを二度言わない。表は行動と場所、散文は理由と気持ち
- 社会人の場面は書かない
- 結論は必ず「消えた行」か「増えた行」に帰着させる。場所・原因・時間で終わらせない
- 結論の書き出しを「同じ〇〇で」で揃えすぎない。12本前後は崩す
- 6つの力の名前は、章タイトル以外では多用しない。読者は法則の行動で覚える

## 見本　法則25

右ページ

取り出す力　25
場面タグ　解説を読んだあと

Q
解説を読んで、納得した。次、どうする？

状況文
数学の問題集。解けなかった問題の解説を読んで、なるほど、と思った。理解できたし、今日はあと3問やる予定がある。時計を見ると、あと40分。

HINT
解説を「読む」以外の使い方があるとしたら……？

左ページ

分かれ道

| | 伸びない人 | 伸びる人 |
|---|---|---|
| すること | 解説を読んで次へ進む | 解説を閉じて白紙に解き直す |
| 数えているもの | わかった、の回数 | 白紙に出せた数 |
| 図の上では | わかっているの箱で止まる | 判定を通ってできるへ |
| 試験の日に | 解説なしで初めて解くことになる | 一度出したことがある状態で解く |

伸びない人の答え
次の問題へ進む。理解できたし、時間もない。頭のなかでは「わかった」のカウンターが1つ回る。でも、わかっているの箱から出ていない。次に同じ問題が本番で出たとき、解説がない状態で初めて解くことになる。そのとき、出てこない。

伸びる人の答え
解説を閉じて、白紙に、もう一度解く。閉じた瞬間に、解説の内容が消える部分がある。そこが、わかっていたけどできていなかった場所。白紙に出せたところまでが、できる。出せなかったところが、次に変えるできない。

法則25
解説を閉じて、白紙に解き直す

他の場面で
英語の長文。全訳を読んで納得したら、全訳を閉じて、もう一度自分で訳す。
定期テストのワーク。解答を見ながら埋めた問題は、解答を閉じてもう一度。

結論
伸びない人は解説を見ながら解く。伸びる人は解説を閉じてから解く。この差で、数が1つ増えるか、変えるべき場所が1つ見つかる。どちらでも前に進む。

隅の図
伸びない人の道はわかっているの箱で止まる。伸びる人の道は判定を通ってできるへ。

## 見本　法則34（HINTの例）

Q　同じ問題を、3回間違えた。4回目、やる？
HINT　崩れているのは、その問題……？
伸びる人の答え　1つ前の、正解していた問題を、解説なしで解き直す。正解はまぐれだったかもしれない。崩れていた場所は、×の問題ではなく、その手前にある。
