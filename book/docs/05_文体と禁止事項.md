# 05　文体と禁止事項

## 文体

- 話し言葉。1文を短く。先生の声ではなく、あの子の隣の席の人の声に聞こえる温度
- 読者を責めない。7つの型は全部、頑張っている人の型。「やっているのに伸びない」人に向けて書く
- 読者は中学生と高校生。中学生が意味を知らない言葉を表紙・見出し・法則文に使わない
- 説明より問い。説明したくなったら、問いに変えられないか考える
- 原理は1行で。説明しない。答えから読者が自分で引き出す
- 対比の主語は「伸びる人／伸びない人」。表紙のあの子を本文に通す場合は「あの子／私たち」に統一する（未確定。`08` 参照）

## 必ず守る

- 定義（`01`）と齟齬を出さない。「できる」は本番で自力で出せること。「わかった」をできると書かない
- 結論は数に帰着させる。数が増えるか、減るか
- 伸びない人の選択には、必ずまともな理由を1つ持たせる
- 場面は中学生と高校生。社会人は書かない
- 答えは1つの行動。「意識」「姿勢」「心がけ」で終わらせない
- 才能、根性、やる気、時間の量を、成績の原因として書かない
- 「頭がいい」を才能の意味で使わない。使うなら、頭がいいは状態、伸びるは変化、と第1章で処理した後

## 使わない

- アスタリスクによる太字・強調（著者の指定。全出力で）
- 「絶対」「必ず」を法則文で多用しない（表紙の「絶対にやらないこと」は別）
- 「理解力」「暗記力」「計画力」など既視感のある能力名
- 「復習が大事」「基礎が大事」のような順接の常識。法則は逆説か、常識の言い換えになっていること
- 「〜しましょう」の連発。言い切りで書く
- 大学名、偏差値、早慶などの固有名詞を本文の見出しに置かない（本文中の具体例には使ってよい。表紙と帯表には使わない）
- 塾の宣伝を本文に入れない。塾への導線は付録とLINE特典に限る

## 表記

- 著者の表記は「朝倉 徹大」または「受験の王様」
- 「あの子」は鍵括弧つきで表紙に。本文では鍵括弧なしでよい
- 数字は半角。法則番号は「法則25」
- 図の箱の名前は、知らない、知っている、わかっている、できる、で固定。「理解している」「習得」などに言い換えない

## 見出しの型

- 章タイトル　あの子には「〇〇力」がある
- 章扉　Q（問題）→ めくって答え → 原理1行 → その章の7法則の予告
- 見開き　Q は、生徒が実際に口にする言葉。塾で聞かれる形のまま置く
　　（「計画って、どう立てればいいですか」「ケアレスミスが、減らないんです」）
　　著者が作った選択肢の言い方（「計画、理想の自分で立てる？」）は使わない
- 法則　行動の言い切り。主語を省く。「〜する」「〜で判定する」「〜から始める」
