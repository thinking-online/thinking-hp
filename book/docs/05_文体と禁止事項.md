# 05　文体と禁止事項

## 文体

- 話し言葉。1文を短く。先生の声ではなく、あの子の隣の席の人の声に聞こえる温度
- 読者を責めない。7つの型は全部、頑張っている人の型。「やっているのに伸びない」人に向けて書く
- 読者は中学生と高校生。中学生が意味を知らない言葉を表紙・見出し・法則文に使わない
- 説明より問い。説明したくなったら、問いに変えられないか考える
- 原理は1行で。説明しない。答えから読者が自分で引き出す
- 対比の主語は「伸びる人／伸びない人」。表紙のあの子を本文に通す場合は「あの子／私たち」に統一する（未確定。`08` 参照）

## 必ず守る

- 定義（`01`）と齟齬を出さない。「できる」は本番で自力で出せること。「わかった」をできると書かない
- 結論は数に帰着させる。数が増えるか、減るか
- 伸びない人の選択には、必ずまともな理由を1つ持たせる
- 場面は中学生と高校生。社会人は書かない
- 答えは1つの行動。「意識」「姿勢」「心がけ」で終わらせない
- 才能、根性、やる気、時間の量を、成績の原因として書かない
- 「頭がいい」を才能の意味で使わない。使うなら、頭がいいは状態、伸びるは変化、と第1章で処理した後

## 使わない

- アスタリスクによる太字・強調（著者の指定。全出力で）
- 「絶対」「必ず」を法則文で多用しない（表紙の「絶対にやらないこと」は別）
- 「理解力」「暗記力」「計画力」など既視感のある能力名
- 「復習が大事」「基礎が大事」のような順接の常識。法則は逆説か、常識の言い換えになっていること
- 「〜しましょう」の連発。言い切りで書く
- 大学名、偏差値、早慶などの固有名詞を本文の見出しに置かない（本文中の具体例には使ってよい。表紙と帯表には使わない）
- 塾の宣伝を本文に入れない。塾への導線は付録とLINE特典に限る

## 表記

- 著者の表記は「朝倉 徹大」または「受験の王様」
- 「あの子」は鍵括弧つきで表紙に。本文では鍵括弧なしでよい
- 数字は半角。法則番号は「法則25」
- 図の箱の名前は、知らない、知っている、わかっている、できる、で固定。「理解している」「習得」などに言い換えない

## 見出しの型

- 章タイトル　あの子には「〇〇力」がある
- 章扉　Q（問題）→ めくって答え → 原理1行 → その章の7法則の予告
- 見開き　Q は、生徒が実際に口にする言葉。塾で聞かれる形のまま置く
　　（「計画って、どう立てればいいですか」「ケアレスミスが、減らないんです」）
　　著者が作った選択肢の言い方（「計画、理想の自分で立てる？」）は使わない
- 法則　行動の言い切り。主語を省く。「〜する」「〜で判定する」「〜から始める」

## 「ん？」となる文は書かない（著者の指示。2026-11-16）

著者の言葉：「法則は、気持ちを見ていません。」を読んで「ん？ってなる」。「今後もだけど、こういう『ん？』って処理が必要なものはダメ」。

読んだ瞬間に、意味が1つに決まる文だけを書く。考えないとわからない文は、言い回しがよくても使わない。本文、目次、見出し、コピー、すべてに当てはめる。

こちらで分けた、「ん？」になる形（著者の言葉ではなく、こちらの整理）

- 人ではないものを、人のように書く（「法則は、気持ちを見ていません」）　→　そのまま言う（「どんな気持ちでやっても、結果は同じです」）
- たとえの言葉のまま、話を進める（「ここに乗った時だけ」）　→　たとえを出したら、すぐ次の行で、勉強の言葉に戻す
- 何を指すかが、すぐわからない言葉（「同じものがあります」「ここから」「何からズレていたのか」）　→　指しているものを書く
- 省きすぎた言葉、作った言葉（「キリで区切る」「仕分けて全力」「止まった手前に戻る」）　→　省かずに書く
- 同じ言葉を2つの意味で使う言い回し（「その"普通"が、あなたの"普通"と違います」）

区別：「え、そうなの？」と気になる文（「頭のいい人は、『覚えよう』としない」）は、意味はすぐわかるので使っていい。ダメなのは、意味がすぐわからない文。
- 問いと答えの形がそろっていない（「足りなかったのは、時間ではありません。…ズレていたんです」。「足りなかったのは」で始めたのに、何が足りなかったかに答えていない。著者の指摘）　→　始めた形のまま答える
- 何のことかを、物の名前で言っていない（「この6つを、その場面で使ったものです」。著者の指摘）　→　「授業の受け方も、単語の覚え方も」のように、名前で言う
- 節の最初の文を「これは」「それは」で始めない（著者の指摘。2026-11-17）。見出しをはさむと、前の節の何を指すのかが、わからなくなる。指しているものを、言葉で書く

## 追記：研究の書き方（出典で突かれないようにする　2026-11-17、著者の指示）

著者「研究に関しては、今後もそうだが、出典が違った、となるのは避けたい。基本、突かれないように表記していきたい」。本文に研究を書く時は、次を守る。

1. 確かめた所までしか、書かない。確かめ方で、書ける範囲を決める
   - 論文の要旨か本文で確かめた：大学名、人数、やったこと、結果の向き（高かった、変わらなかった）を書いてよい
   - 解説記事や大学の広報でしか確かめていない：大学名と、やったこと、結果の向きまで。数字は書かない
   - 本やネットで広まっている話で、もとを確かめられない：研究としては書かない。使わないのが基本
2. 大学名は「〇〇大学の研究者たちの実験」と書く（「〇〇大学でやった実験」と書かない。研究者の所属と、実験をした場所が違うことがある）。同じ名前の大学がある時は、区別がつく書き方にする（例：ワシントン大学は2つある）
3. 数字は、丸めて書く（「84パーセント」→「8割以上」、「426人」→「400人以上」）
4. 実験と調査を、書き分ける（グループに分けて比べたものが実験。アンケートと成績を比べたものは調査）
5. 「証明された」「科学的に正しい」「必ず」は使わない。「この実験では、〜でした」と書く
6. 研究者の結論を「　」に入れない（そのままの引用に見える）。「研究者たちは、〜と結論づけています」と書く
7. 1つの実験から、言いすぎない。本の主張は著者の言葉で書き、研究は裏づけとして置く
8. 研究者名と年号は本文に出さない（前からのルール）。巻末の参考文献に、正確に書く。本文に書いた研究は、全部、巻末にある状態にする

## 追記：無駄な改行をなくす（2026-11-20、著者の指示）

著者「普通に、無駄な改行はなくしていく、というルールでやっていけば、その分、ページ的にもいい」。

- 同じ話の文は、1つの段落につなげる。1文ごとに改行しない
- 改行を残すのは、働きがある所だけ：最初の問いのあとの「……」（考える間）、やって見せる見本（ブロック）、×と○、強く止めたい1文（1項目に1〜2か所まで）
- 表、箇条書き、小見出しは、行を使う（小見出しは1つで2行）。文で言えるものは、文にする
- 本の形（縦書き）でページを数える時は、もう、文をつなげて段落にして数えている（`scripts/build_tate_book.py`。170字までを1つの段落にする）。台本（Word）を出し直す時も、同じつなぎ方にそろえる

## 追記：チャットに台本を出す時の形（2026-11-20、著者の指示）

- 小見出しの印は「⚫︎」にする（「■」は使わない）。著者が自分で書く原稿と、同じ印
- コピーして貼れるように、1つの囲みの中に、項目の全部を入れる
- 順番：番号と題 → 「×　頭のいい人は『…』をしない。」「○　頭のいい人は『…』をする。」→ 本文 → 今日からできる3STEP → まとめ
