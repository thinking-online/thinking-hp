## データの読み

1. 対象を広げると売れる。みおりんさんの2冊は同じ著者・同じ登録者数で、対象の広さだけが違い、8倍の差。市場で観察できるほぼ実験
2. 売上より返品率。仕入の多さはフック（書店の期待）、返品率は読者に刺さったか。『やってはいけない』は仕入は取れたが35%が返った。目標は返品率1割以下＝表紙の約束と中身の一致
3. 「東大」「有名IP」「勉強法に名前をつける」は、単独では効いていない
4. 売れた2冊の共通点はフックの強さではなく参入障壁の低さ。「1分でできる」「中学生から使える」
5. 杉浦さんの懸念　大学受験に絞ると売れない。ただし著者の発信が大学受験特化なら、広げると初速の読者が離れる。Instagram上位20投稿の内訳で確認する

## 対象を「中高生」に決めた理由

- データが支持しているのは「中学生から」であり「社会人まで」ではない
- 学研の本で学参棚に置かれる。社会人はその棚に来ない
- 「あの子」は中高生の言葉。社会人と並べると表紙がちぐはぐになる
- 骨格は対象非依存なので、社会人が読めば読める本にはなる。狙って書くと薄まる

## 返品率の仕組み（要約）

- 委託販売制度。書店は一定期間（新刊はおおむね3ヶ月半）内なら返品できる。再販制度で値引きできないので、売れ残りは返品するしかない
- 返品率＝返品÷仕入。書籍全体の平均は近年3割強
- 出版社は実売で利益が決まる。編集者は発売後3ヶ月の実売と返品で重版を判断。書店は返品の多い著者の次の本を少なめに仕入れる
- 著者の印税は発行部数基準の契約が多い（学研との契約を確認）。重版は実売で決まる
- 著者にできること　表紙と中身の一致、発売直後に書店で買われること（書店POSに乗る）、初版を欲張らない

## 自己買いの線引き

- 客注（書店経由の取り寄せ注文）は返品されない注文で、出版社と書店が最も歓迎する
- ただし数字のためだけに買って倉庫に積むのは自己買い。発覚する、重版判断が歪む、信頼が消える
- 実際に使う本（塾生配布、献本、学校寄贈）を書店経由の客注で買うのは正当。確定需要として発売前に杉浦さんに伝える
- 自分で買うより、読者を書店に向かわせる特典設計のほうが効く

## タイトル検討の経緯（捨てた案と理由）

- 成績が「伸びる人」と「伸びない人」の、勉強中の頭のなか　→　対比型。既視感。あの子案に発展
- 勉強ができる人は、頭のなかで「この図」を回している　→　図が表紙だと説明的で学参の顔になる
- 頑張っているのに伸びないのは、才能のせいじゃない　→　自己啓発寄り。著者知名度依存
- 勉強は、根性じゃなく設計だ。　→　ブランド直結だが3秒で何の本かわからない。2冊目以降向き
- 頭のいい「あの子」　→　頭がいいは才能の言葉
- 学年1位の「あの子」　→　結果の言葉で、読者の痛みから遠い
- 「勉強してないのに成績がいい」あの子　→　実際には勉強しているので嘘になる
- 「急に伸びた」あの子　→　希望は強いが嫉妬の熱がない。帯裏に回す
- 「こぞって捨てる勉強法」　→　こぞって、は複数主語の言葉。あの子は1人
- 早慶合格・学年1位・偏差値70超え、の肩書き行　→　早慶で大学受験に見える。帯裏と著者プロフィールへ

決め手　あの子も読者も勉強している。違うのはやった分が伸びに変わるか。「やればやるだけ伸びる」は定義（同じ時間で変えた数が多い）の言い換え。読者を「勉強していない人」にも「才能がない人」にもしない。

## 1冊目の考え方

- 数字より「この人はこれが書ける」という認識を作る
- 編集者が次を頼む条件は、売れた実績、一緒に仕事しやすい、次のネタ。こだわりは中身と販促に、進行は編集者の言う通りに
- 1冊目に2冊目の証拠を埋め込む（親向け章、対象非依存の骨格）。次の企画は編集者が自分で気づく形にする
- 発売前に「次は子育て系を」と言わない。初動の数字が出てから
