# 09　原案と現行版の比較

企画が通ったときの企画書（原案）と、現在の版の比較。
中身と構成は変えてよいと編集部から言われているが、
「なぜ通ったのか」に関わる要素を落としていないかを確認するために残す。

---

## 原案（企画が通ったもの）

タイトル　『頭のいい人が、受験勉強で絶対にやらないこと』
サブ　　　早慶合格者が実践している　パクるだけで成績が伸びる勉強法

　はじめに　頑張っているのに結果が出ない君へ
　第1章【現実】努力しているのに伸びない本当の理由（8項目）
　第2章【戦略】合格するための「正しい戦い方」（9項目）
　第3章【勉強法】パクったら伸びる　頭のいい人の勉強法（8項目）
　第4章【科目別】合格者が実践している点数が伸びる勉強法（8項目）
　第5章【AI×受験勉強】24時間自分専用の家庭教師の作り方（8項目）
　第6章【計画】結果が出る「勉強計画の立て方」（8項目）
　おわりに　次は、君の番だ。

原案の全文は著者の手元にある。ここには構成と、比較に必要な箇所だけを写す。

### 原案から引き継いだもの

- 「勉強は、スポーツと違って上手い人のやり方が目に見えない」という一節。
　原案のいちばんの資産。現行版の「あの子の頭のなかを、そのままパクる」に直結している
- 「パクる」。原案のサブタイトルにあり、現行版では帯裏に置いている
- 「頑張っているのに結果が出ない」読者像。原案のはじめにの副題そのもの
- 逆説の提示形式（絶対にやらないこと）。タイトルに残っている

### 原案から落としたもの

- 第4章【科目別】（8科目8項目）　→　現行版ではまとめの「英語で答え合わせ」に縮小
- 第5章【AI×受験勉強】（8項目）　→　現行版には一切ない
- 大学受験特化の語彙（共通テスト、国立の換算得点、私立の学部別、推薦、早慶）
　→　現行版での出現回数はいずれも0回
- 「君」の二人称と、その熱量
- 「2000人以上の指導」という実績の数字

## 原案が強いところ（現行版が失っているもの）

1. AI章の新規性。中高生向けでAI活用を正面から扱った本は少ない。書店のフックとして最も強い可能性がある
2. 科目別章の具体性。書店で目次に科目名があるのは、買う理由になる
3. 目次で何の話かわかる。【戦略】【勉強法】【計画】は読者の言葉
4. 著者の声の熱量。SNS発の著者らしさ。ファンには刺さる
5. 「2000人以上の指導」という、中身の根拠になる数字

## 現行版が強いところ

1. 対象が中高生。`06` のデータ（みおりんさんの2冊で8倍差）が支持している方向
2. 定義1文からの演繹。なぜ6つの力なのかに答えられる
3. 同じことを繰り返さない。原案の第1章8項目は、1つの主張の言い換え
4. 読者を責めない。保護者が買う本として成立する
5. 表紙の約束と中身の対応が設計されている（返品率対策）
6. 問い形式で、読者が48回、自分のことを聞かれる
7. 図がある。自分がどこで止まっているかがわかる
8. 保護者への導線があり、2冊目の証拠になっている
9. AI章がないので陳腐化しない。毎年、同じ販促で読者が生まれる（`07` の継続の項）

## 最大のリスク

企画が通った理由を、こちらの判断で2つ消している可能性がある（AI章と科目別章）。
杉浦さんに「なぜこの企画が通ったのか」を聞く前に構成を大きく変えたので、
提出時に、原案から何を残し何を変えたか、その理由を1枚で説明する必要がある。

その1枚は企画書に入れる（`08` の提案を参照）。
