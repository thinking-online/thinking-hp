# 12　見本組の仕様

`build/見本組.pdf`。台本ではなく、本そのものの体裁で組んだもの。
編集用の注記は1文字も入っていない。杉浦さんに「こう見えます」と渡せる形。
`scripts/build_book.py` と `scripts/book.css` で作る。2026-09-09 作成。

---

## 判型と版面

| | |
|---|---|
| 判型 | A5（148 × 210mm） |
| 組 | 縦組み・1段・右綴じ |
| 天 | 17mm |
| 地 | 19mm（柱とノンブルが入る） |
| 小口・ノド | 各14mm（左右対称。本番では製本side に合わせてノドを広げる） |
| 本文 | Noto Serif CJK JP　9.4pt　行送り1.68 |
| 見出し | Noto Sans CJK JP |
| 1ページ | およそ52字 × 21行 |

本文の書体は仮。本番では本明朝・游明朝・リュウミンなど、制作側の指定に差し替える。

## 右綴じの決まり

右綴じなので、奇数ページが左、偶数ページが右になる。
見開きを開いたとき、先に目に入るのは偶数ページ。

だから、この本では次を強制している。

　法則の問いページ　　　　必ず偶数ページ（見開きの右）
　法則の答えページ　　　　必ず奇数ページ（見開きの左）
　章扉　　　　　　　　　　必ず偶数ページ
　巻頭・巻末の各節　　　　必ず偶数ページ始まり

ページが足りないときは、白ページを1枚入れて丁合いを合わせる。
組んでみないと改ページ位置は分からないので、
`build_book.py` は「組む → 各ブロックの厚みを測る → 白の入れどころを決め直す → もう一度組む」
を、動かなくなるまで繰り返す。最後に、実際のPDFを測り直して、
ずれが1つでもあればエラーで止まる。

## 柱とノンブル

地の小口寄りに、横組みで入れる。

　偶数ページ（右）　右下　ノンブル＋章名
　奇数ページ（左）　左下　ノンブル＋書名

入れないページ　カバー、白ページ、本扉、目次、章扉、奥付。

柱とノンブルは、本文を組んだあとに別ファイルで作って重ねている
（`build/_overlay.pdf`）。CSSの改ページはページ番号を持てないため。

## 法則の見開きの組み

問いのページと答えのページで、組みを変えている。学参ではふつうの作り。

　問いのページ　9.8pt　行送り1.9　　余白を大きく取る。Qは13ptのゴシック
　答えのページ　8.9pt　行送り1.62　 分かれ道の表、2つの答え、法則、他の場面で、結論が入る

答えのページの右上に「分かれ道」の表を回り込みで置く。
図が入る位置は、破線の枠（26 × 34mm）で示している。中身は制作側で描く。

## いまの見本組で分かっていること

1　45の見開きは、全部きっちり2ページに収まっている。あふれは0本。
2　章扉は全部1ページ。全部偶数ページに乗っている。
3　目次のノンブルは、組んだ結果と一致している。
4　「あの子が、絶対にやらない45のこと」は、原稿量が多いので4ページ使っている。
　　`03` では見開き1枚（2ページ）としてある。2ページに収めるなら、
　　前後の文章を削るか、チェック欄の級数をさらに落とす。著者判断。
5　本文の書体・級数・字詰めは仮。ここは制作側の領分なので、
　　「この分量が、この判型でこのページ数になる」ことを見せるためのもの。

## 作り直し方

```
cd book
python3 scripts/build_book.py
```

原稿を直したら、これを走らせるだけで組み直る。
収まらないものがあれば、エラーで止まって、どれが収まらないかを出す。
