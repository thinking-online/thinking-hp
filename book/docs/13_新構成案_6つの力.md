# 第1部　本の主張

## 主張は、6文でぜんぶ言える

　　成績は、頭の良さでは決まりません。
　　できるようになった数で決まります。

　　できない が できる に変わるとき、人は必ず同じ工程を通ります。

# 第2部　削るものと、残すもの

いまの本には、読者が覚えなければいけない概念が10個ある。多すぎる。
6つの力を入れるなら、同時に4つ削らないと、複雑になって死ぬ。

## 削る　4つ

| 削るもの | いま何をしているか | どこに畳むか |
|---|---|---|
| 4段階の図（わかっていない／わかっている／できる／…） | わかる と できる の違いを図で説明 | 6つの工程の図に統合する。図は1枚だけにする |
| 2つの通貨（1行消える／1行増える） | 数え方を2種類に分けている | 「1周で1個」に一本化する |
| 7つの型 | 読者を7タイプに分けて章へ送る | 「6つのうち、どこで止まっているか」に置き換える。型という概念ごと消える |
| 巻頭の3ステップ（1やめる 2覚える 3増やす） | 量ではなく順番だと説明 | 6つの力の中にすでに入っている（下記） |

3ステップは、消すのではなく、6つの中に見つかる形にする。

　　1　やめる　　　　＝　選ぶ力
　　2　やり方を覚える＝　入れる・つなげる・出す・直す
　　3　量を増やす　　＝　回す力

巻頭で「順番がある」と言い、本文で「その順番が、この6つです」と回収する。
概念は増えない。

## 残す　4つ＋道具1つ

| | なぜ残すか |
|---|---|
| 定義（成績＝できるようになった数） | 本の背骨。ここだけは動かさない |
| 6つの力 | 読者の現在地を示す地図。図はこれ1枚 |
| 二項対立（伸びない人／伸びる人） | 45の見開きの装置。本の中身そのもの |
| 期限（試験の日までに何周） | 受験という制約。図の外枠 |
| できないノート（道具） | 数を数えるための実物。付録に置く |

# 第3部　6つの力

## 一覧

```
　　選ぶ　→　入れる　→　つなげる　→　出す　→　直す
　　　↑　　　　　　　　　　　　　　　　　　　↓
　　　└───────────────────────────────────┘
　　　　　　　　　　　　回す
```

読むときは6つ並列。図にするときは5つの輪＋回す。
リストは覚えるため、図は仕組みを見せるため。両方使ってよい。
ただし本文で1回だけ、こう認める。

　　6つ目だけは、ほかの5つを止めないための力です。

これを言わないと、図とリストが食い違って見える。

## 定義と境界

境界の基準は2つだけ。
　　入れる／つなげる　　対象が1つか、複数の関係か
　　出す／直す　　　　　解く前か、解いたあとか

| 力 | どこまでやったら、この力は終わりか |
|---|---|
| 選ぶ | やるものとやらないものが、口で言えるところまで |
| 入れる | 目の前の1つを、正しい形で取り込むところまで |
| つなげる | すでに入っている他のものと、関係づけるところまで |
| 出す | 何も見ずに外に出して、出せたか出せなかったかを判定するところまで |
| 直す | 出せなかったものの、崩れた場所まで戻るところまで |
| 回す | 試験の日まで、この5つを止めないところまで |

## 数える は、出す力の中に置く

帯は「違いは、昨日、何個できるようになったか」と数を約束している。
6つの見出しに数がないと、表紙と中身が切れる。だから出す力の定義に畳む。

　　出す力とは、何も見ずに出すこと。そして、出せたら1個と数えること。

出すことと数えることは、同じ瞬間に起きている。別の力にする必要はない。

## 二項対立　6枚

| 力 | 伸びない人 | 伸びる人 |
|---|---|---|
| 選ぶ | 範囲の全部に、一度ずつ手をつける | 出るところから、順番に手をつける |
| 入れる | 量を入れる | 形を入れる |
| つなげる | 1つずつ、別々に覚える | 1つ入れて、10動かす |
| 出す | 見てわかった、で終える | 何も見ずに出せた、で終える |
| 直す | 赤で、正解を写す | どの行から違ったかを、指す |
| 回す | やる気が出たら、回す | やる気がなくても、回る形にする |

## 章扉に置く1行

| 力 | 1行 |
|---|---|
| 選ぶ | 全部やろうとした人から、間に合わなくなる |
| 入れる | 入っていないものは、つなげようがない |
| つなげる | つないだものは忘れにくい。バラバラのものは忘れる |
| 出す | 出せなかったものは、入っていなかったということ |
| 直す | 間違いは、次にどこを直すかを教えてくれている |
| 回す | 1周で1個。あとは、何周できるか |

## 実演　6つ

各章の入口で、読者にその場で失敗させる。説明より先に体験を置く。
巻頭の11個の数字と同じ作りを、6章ぶん用意する。

| 力 | 実演 | 何が起きるか |
|---|---|---|
| 選ぶ | 定期テストの範囲表を出して、30秒で「絶対に出る」3つに丸をつける | 丸がつけられない。選んでいなかったと分かる |
| 入れる | アミラーゼの4択（下記） | 用語を1つも知らなくても解ける。知識ではなく形だと分かる |
| つなげる | import / export / portable を10秒で覚える → port＝運ぶ、と1行だけ渡す | 覚える量が変わっていないのに、覚えられる |
| 出す | 本を閉じて、1ページ前に書いてあったことを3つ書く | 読んだばかりなのに出てこない。読んだ＝入った、ではない |
| 直す | 連立方程式の途中式5行。3行目で符号ミス。「×はどこ」と聞く | 多くの人が最終行を指す。直す場所は3行目 |
| 回す | 先週の月曜、何を勉強したか書く | 書けない。記録がないと、周回数が数えられない |

入れる力の実演（著者が持ってきたもの。そのまま使う）

　　アミラーゼという酵素はグルコースがつながってできたデンプンを分解するが、
　　同じグルコースからできていても、形が違うセルロースは分解できない。

　　問　セルロースは（　　）と形が違う。
　　　　1 デンプン　2 アミラーゼ　3 グルコース　4 酵素

　　答え　1

　　この問題は、用語を1つも知らなくても解けます。
　　知識の問題ではありません。文の形の問題です。

## トレーニング　6つ

各章の最後に1つだけ。今日その場でできるものに限る。

| 力 | 訓練 |
|---|---|
| 選ぶ | 今週やらない単元を3つ、紙に書いて口に出す |
| 入れる | 問題を読んだら、解く前に「要するに何を出すか」を1行書く |
| つなげる | 1つ覚えたら、同じ形のものをもう1つ探して隣に書く |
| 出す | 解けた問題を、誰もいない部屋で声に出して説明する |
| 直す | 間違い10個を、種類で3つに束ねる。10問直さず、3種類直す |
| 回す | 崩れる日を1日、先に決めて空けておく |

## 序章を、型から力に変える

いまの序章は7つの型を診断して章へ送っている。
型という概念を消して、6つのどこで止まっているかを診断する形にする。

　　6つの質問に答えると、止まっている力が1つ決まる。
　　その章から読む。

質問はそのまま二項対立の左右を選ばせる形でよい。

| 質問 | 左を選んだら |
|---|---|
| テスト前、範囲の全部に手をつける？　出るところから？ | 選ぶ力 |
| 解説を読んで、知っている言葉を拾う？　文の形をつかむ？ | 入れる力 |
| 単語は1つずつ覚える？　1つから10動かす？ | つなげる力 |
| 見てわかったで終える？　何も見ずに出せたで終える？ | 出す力 |
| 間違えたら赤で正解を写す？　どの行から違ったか探す？ | 直す力 |
| やる気が出たら勉強する？　出なくても回る形にしてある？ | 回す力 |

7つの型の名前を考える作業（Instagram質問箱待ち）は、これで不要になる。

# 第5部　45法則の再割り当て

章の枠は動かない。ただし1本、明確にずれているものがある。

## 移す　1本

法則23「覚えるとは、見ることではなく思い出すこと」
　　いま　第4章（つなげる力）
　　案　　第5章（出す力）

思い出す、は完全に出す力の行為。赤シートを閉じて書き出すのは、白紙に出すのと同じこと。
入れる／出す に分けたことで、前の分け方（覚え方／確かめ方）では見えなかったずれが出た。

移すと第4章が6本、第5章が8本になる。7本ずつに戻すなら、
第5章の法則30（解けない問題は、隠さず集める）を第6章（直す力）に送る。
集める行為は、直すの入口なので自然。第6章は8本になるので、
法則38（下がったら、自分ではなく変えたことを見る）を第7章（回す力）へ。
下がったときに何を変えるかは、回し方の話でもある。

結果

| 章 | 力 | 本数 |
|---|---|---|
| 第1章 | 総論 | 3 |
| 第2章 | 選ぶ | 7 |
| 第3章 | 入れる | 7 |
| 第4章 | つなげる | 6 |
| 第5章 | 出す | 7 |
| 第6章 | 直す | 7 |
| 第7章 | 回す | 8 |

7本ずつに揃えたいなら、第4章に1本足す。
つなげる力は、いまの7本（前に見た形を探す／なぜを1つ／1つの例文で10個／
別の科目で1回使う／違いだけで覚える／まとめは頭のなかに）が6本になるので、
「1つ覚えたら、同じ形をもう1つ探す」を1本立てるのが自然。

## 境界が微妙で、置き場所を宣言しておくべきもの　3本

| 法則 | いま | もう一方の解釈 | 判断 |
|---|---|---|---|
| 14　全部ではなく、止まった1行を指さす | 入れる | 直す | 解く前の行為なので入れるでよい |
| 15　知らないと、わかっていないを分ける | 入れる | 直す | 同上 |
| 30　解けない問題は、隠さず集める | 出す | 直す | 直すへ送る（上記） |

どちらに置いても嘘ではないので、置き場所より、章扉で境界を宣言してあるかのほうが効く。

# 第6部　まだ決まっていないこと

## 1　入れる力の章タイトル

【入れ方】は軽い。【読み方・聞き方】は長い。他の5章と揃えにくい。
案　【入れ方】読んだ、聞いた、が入っていない
案　【読み方】言葉を拾うか、形をつかむか

## 2　入れる力に、1本足りない

いまの第3章7本は「入れる作業の手順」で、
「入れたつもりで入っていない」を突きつける法則が1本もない。
アミラーゼの実演を受け止める法則が必要。

案　法則　文の形が言えないものは、まだ読めていない
　　伸びない人　知っている言葉を拾って、意味をつなぐ
　　伸びる人　　何が何にかかっているかを、指で追う

これを入れると第3章が8本になるので、割り当ては再調整。

## 3　削除する4概念を、本当に削ってよいか

とくに2つの通貨（1行消える／1行増える）は、
できないノートの説明に使っている。「1周で1個」に一本化すると、
付録の書き方が変わる。ここは付録を書き直す前提での判断。

## 4　巻頭の3ステップの見せ方

6つの力の中に入っていると分かる形にするが、
巻頭では6つをまだ出していない。
巻頭では順番だけ言い、第1章で「その順番が、この6つです」と回収する流れでよいか。
