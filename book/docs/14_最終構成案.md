## 6つの力　一言説明

その力が「ある人はこうなる」で書く。行動ではなく、状態で書く。
下に「ないとどうなるか」を並べる。生徒はこちらで自分を見つける。

| 力 | ある人は | ない人は |
|---|---|---|
| 選ぶ力 | やらないものが、決まっている | 全部やろうとして、間に合わない |
| 入れる力 | 「つまり、どういうこと」が言える | 読んだのに、何も残らない |
| つなげる力 | 1つ覚えると、10がついてくる | 覚えた数しか、増えない |

# 4　旧番号との対応

45本のうち、中身を書き直すのは1本だけ。あとは番号と章が動くだけで、本文はそのまま使える。

| 新 | 旧 | 動いた理由 |
|---|---|---|
| 08 | 新規 | 入れる力に、文の構造を扱う法則が1本もなかった。アミラーゼの実演を受け止める1本 |
| 22 | 旧2 | 第1章から出す力へ。わかっている／できる の話は、出す力の定義そのもの |
| 24 | 旧23 | つなげるから出すへ。思い出す、は完全に出す側の行為 |
| 30 | 旧30 | 出すから直すへ。集める行為は、直すの入口 |
| 31 | 旧3 | 第1章から直す力へ。最後にできていた場所に戻る、は直す力の核 |
| 38 | 旧38 | 直すから回すへ。下がったときに何を変えるかは、回し方の話 |
| ─ | 旧1 | 法則から降ろして、第1章の定義本文にする |

# 5　削るものと、残すもの

読者が覚える概念を、10個から5個に減らす。

| 削る | 畳み先 |
|---|---|
| 4段階の図 | 6つの工程の図に統合。本の図は1枚だけにする |
| 2つの通貨（1行消える／1行増える） | 「1周で1個」に一本化 |
| 7つの型 | 「6つのうちどこで止まっているか」に置き換え。型という概念ごと消える |
| 巻頭の3ステップ | 6つの中に見つかる形にする |

3ステップは消さない。6つの中に入っていると分かる形にする。

　　1　やめる　　　　＝　選ぶ力
　　2　やり方を知る　＝　入れる・つなげる・出す・直す
　　3　量を増やす　　＝　回す力

残すのは、定義／6つの力／二項対立／期限／できないノート（道具）の5つ。

「数える」は力から降ろして、出す力の定義に畳む。

　　出す力とは、何も見ずに出すこと。そして、出せたら1個と数えること。

# 6　序章を、型から力に変える

7つの型を消して、6つのどこで止まっているかを診断する形にする。
質問は、二項対立の左右を選ばせるだけでよい。

| 質問 | 左を選んだら |
|---|---|
| テスト前、範囲の全部に手をつける？　出るところから？ | 選ぶ力 |
| 解説を読むとき、知っている言葉を拾う？　文の形をつかむ？ | 入れる力 |
| 単語は1つずつ覚える？　1つから10動かす？ | つなげる力 |
| 見てわかったで終える？　何も見ずに出せたで終える？ | 出す力 |
| 間違えたら赤で正解を写す？　どの行から違ったか探す？ | 直す力 |
| やる気が出たら勉強する？　出なくても回る形にしてある？ | 回す力 |

型の名前を考える作業（Instagram質問箱待ち）は、これで不要になる。
