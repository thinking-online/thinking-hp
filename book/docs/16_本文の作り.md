# 本文の作り

書籍の本文は、文章で書く。見開き2ページ完結の形式は使わない。

理由。見開き完結は、勉強法の強化書（PDF教材）がすでにその形で、
書籍で同じことをやると図解本かムック本になる。
1つの主張を掘れないので、本質まで届かない。分量も足りない。
45×2ページで本文90ページ。四六判の単行本にならない。

そのかわり、読者が自分を見つける装置（二項対立とチェック）は、
本文のレイアウトからは外して、巻頭・章扉・章末に集める。

## 2　1節の作り

節は、この順で書く。ページ数は節によって変える。

　　1　場面　　　　生徒が実際に言った言葉から入る。時刻を追って、その日を再現する
　　2　犯人を否定　意志・集中力・スマホのせいにする結論を、いったん止める
　　3　名指し　　　何が起きていたのかを、1つの言葉で言い切る
　　4　本質　　　　なぜそうなるのかを、仕組みで説明する。ここがその節の芯
　　5　証拠　　　　同じ仕組みが働いている別の場面を2〜3個ならべる
　　6　やり方　　　手順。3つまで
　　7　注意　　　　やりすぎるとどうなるか
　　8　残るもの　　これをやると、その子に何が残るか。責めずに終わる
　　9　まとめ　　　1〜2行 ＋「今日やること」1行

4が節の芯になる。ここが弱い節は、節にしない。
巻頭のチェックリストの1行として残して、本文からは落とす。

---

## 3　節の長さは、そろえない

そろえると、読み物ではなく一覧表になる。
実際に読んで疲れるのも、AIが書いたように見えるのも、ここが原因になる。

　　厚い節　　　9ページ前後　　各章1本　　　　　計6本　　約30,000字
　　標準の節　　5ページ前後　　　　　　　　　　 計24本　 約62,000字
　　短い節　　　3ページ前後　　　　　　　　　　 計15本　 約21,000字

　　本文合計　約113,000字　＝　約206ページ

厚い節には、著者の実話・固有名詞・数字を入れる。
短い節は、1つの言い切りと1つの手順で終わらせる。

---

## 4　本文に残す図と装置

節のなかで使えるのは、この3つだけ。多いと図解本に戻る。

　　節の頭に、二項対立の2行

　　　　やらない人　1日の計画を、to doリストで立てて　→　夜まで動かず、自己嫌悪で終わる
　　　　頭のいい人　1日を6つに割って計画を立てて　　　→　午前が終わるたびに、結果が出る

　　図は、1節につき最大1つ

　　節の最後に「今日やること」1行

チェックボックス形式（強化書 p75 の形）は、本文では使わない。
巻頭の45行と、各章末の1枚に集める。
本文の全節に置くと、1つ1つの文章が読まれなくなる。

---

## 5　二項対立の書き方

勉強法の強化書は、20法則すべてでこの形をとっている。

　　p74　　頭の悪い人は、朝から夜まで まとめて計画を立てる
　　　　　　頭の良い人は、ブロックに分けて 計画を立てる
　　p75　　1日単位で計画を立てて挫折　→　1日の終わりに、死ぬほど後悔
　　p77　　1日を細かくブロックに分けて計画　→　期限を意識できるから集中できる

両側に「行動」と「結末」がある。片側だけだと対立にならない。
書籍でもこの形を守る。ただし「頭の悪い人」という言い方はしない。

## 6　本番サンプル

　　manuscript/見本_節_計画.md

7章【回す力】の1節を、上の作りで書いたもの。3,500字。約6ページ。
強化書 p71〜80 の法則1（ブロック計画）が元になっている。

芯にしたのは、次の1つ。

　　計画を立てるとは、やることを決めることではなく、締切を増やすこと。

夏休みが溶けるのも、模試前の3日だけ進むのも、塾に行くと進むのも、
全部これで説明できる。ブロック計画は、その結論として出てくる。

# 1項目の形（2026-11-17、著者が決めた。今の形）

これより上は、前の版の作り方。50項目は、次の形で書く。

```
　　章最初のページ　　　法則の言葉と絵（第1章の6つだけ）
　　導入文　　　　　　　フックから入る。読者が「自分のことだ」と思える場面で始める
　　質問ページ　　　　　型は、50個とも同じ（下）
　　本文
　　頭のいい人と伸びない人の違い　　2コマ。大きい言葉と、小さい声
　　今日からできる3STEP　　　　　　STEP01〜03（見出し＝やること、吹き出し＝その時の声）
　　できた基準　　　　　「〜できたらOK！」
　　まとめ　　　　　　　一言 → わかったこと3つ → だから、こうする
```

## 質問ページの型（著者の指示「全部パターン同じだから、今後も覚えておいて」）

```
　　頭のいい人が絶対やらないこと
　　「何度も読む」
　　じゃあ、何をするの？
```

変わるのは、まん中の「　」の言葉だけ。50個ぶんの言葉は、2コマの「伸びない人」の大きい言葉（`scripts/taihi_card_v2.py`）を使う。

## 導入文の書き方（著者の指示）

フックから入って、気になる形にする。読者が自分ごとにできる場面（例：長時間勉強した日の夜、「今日って、何を勉強したっけ」）で始める。

## 追記：3STEPのシートに入る字数（2026-11-17。著者のひな形の絵から見積もった目安）

著者のひな形（題「頭のいい人の『　　』3STEP」／STEP 01・02・03 それぞれに、見出しの場所と吹き出し1つ、右に王様の絵／下に「できた」の基準の箱）に入るように、STEPを書く。著者「このスペースに入るように設計をするべき」。

- 題（『』の中）：6字までが目安。ひな形の空きは2〜3字ぶんなので、6字にするなら空きを広げる
- STEPの見出し（やること）：2行。1行12〜13字、合わせて24字前後まで
- 吹き出し（その時の声）：1行。14字まで
- 「できた」の基準：2行。36字まで
- ※の注、表、リストは、シートに入らない。いる時は、シートの前のページに「チェック」の箱として置く
- 王様の絵は、STEP 01＝考えている、STEP 02＝本を読んでいる、STEP 03＝書いている。「見つける → 読む → やる」の流れだと、絵とそのまま合う
- 字数は、絵の大きさからの見積もり。組む時の字の大きさが決まったら、数字を直す
- 今の50個（`scripts/step_card_v1.py`）を、この数字で調べた結果：3つの枠に全部入るのは14個。見出しが24字を超えるのは29項目（一番長くて28字）、声が14字を超えるのは12項目（一番長くて16字）、基準は全部入る。超えているのは数字までなので、言葉を詰めれば入る

## 追記：第2章から先の、1項目の形（2026-11-17、著者の指示）

著者「第2章以降は、章の最初のところだけ導入文を書いて、そのあとは、もういきなり全部【質問ページ】から始まるようにしたい」。

- 章の最初：章の題 → 章の導入文（1つだけ）
- 項目（07〜50番）：質問ページ → 本文 → 頭のいい人と伸びない人の違い（2コマ）→ 今日からできる3STEP → できた基準 → まとめ
- 項目ごとの「章最初のページ」と「導入文」は、ない（それがあるのは、第1章の6つだけ）
- 質問ページは、50個とも同じ型（頭のいい人が絶対やらないこと／「〜」／じゃあ、何をするの？）
- 本文は、よくある場面から始める（質問ページをめくると、その場面が出てくる）。そのあとに、なぜ伸びないのか、頭の中、やり方（①②③）の順
- 3STEPのシートは、本文の「やり方」の3つを、ひな形に入る長さにしたもの（中身は同じ。シートは1枚で見るためのもの）
- まとめは、一言 → わかったこと3つ → だから → 自分への問い
