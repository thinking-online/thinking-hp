# 類書分析と、内容の補強

見た4冊。

```
A　『「説明」がうまい人がいつも頭においていること』
B　『人望がある人がいつも頭においていること』
C　『科学的根拠×タイムパフォーマンスを追求してわかった！ 勉強法BEST100』
D　『最短の時間で最大の成果を手に入れる 超効率勉強法』（メンタリストDaiGo）
```

AとBは形式の参考。CとDは中身の競合。

---

## 1　いちばん先に処理すべきこと　Dとの重複

Dの第1章は「やってはいけない！7つの勉強法」。中身はこう。

```
1　ハイライトまたはアンダーライン
2　語呂合わせ
3　テキストの要約
4　テキストの再読
5　集中学習
6　自分の学習スタイルに合わせる
7　忘れる前に復習する
```

いま書いた序章は、やめる4つが 線を引く／読み返す／まとめる／見ながら書く。
そして本題が「自分に合った勉強法を探すな」。

4つのうち3つがDの1・3・4と同じ。
本題がDの6と同じ。

このまま出すと既視感が出る。内容は正しいので、枠と角度を変える。

### 変える3点

1　見出しを、やめる4つではなく「自分に合った勉強法を探すな」にする
　　Dは7つのうちの6番目として軽く触れている。こちらは序章まるごとをこれに使う。
　　同じ結論でも、本の中での重さが違えば別の本になる。

2　根拠を、研究ではなく指導現場に置く
　　Dの強みは研究の紹介。ここで勝負しても勝てないし、二番煎じになる。
　　こちらの根拠はこの3つ。
　　　　なぜ「合ってる気がする」のか（やった感じの強さを測っているだけ）
　　　　人は、やったことのないものを候補にできない
　　　　早く固まった人ほど危ない（中学で量が効いて、高校2年で止まる）
　　どれも研究の引用ではなく、2000人を見た人間にしか書けない話。

3　著者の実話を、序章の軸にする
　　14時間、偏差値42、10校不合格。
　　しかも「自分に合ったやり方を完璧に持っていた」という形で出す。
　　Dにもこの本にも、著者が自分の失敗を証拠に出す場面はない。

研究の話は、本文では1段落に抑える。巻末にまわす。

## 2　Cとの関係　直接の競合

Cは100項目。形式が、こちらが作った目次とほぼ同じ。

```
C　　001 ×とりあえず勉強する → ○勉強の定義をはっきりさせる
こちら　01 実力がついてから、過去問を開く
　　　　　×「まだ早い。力がついてから使おう」
　　　　　○「解かずに開いて、出るところだけ数える」
```

形は似ているが、中身の作りが2つ違う。ここが勝負どころ。

### 違い1　×を、行動ではなく心の声で書く

Cの×は行動。「とりあえず勉強する」。
こちらの×は、そのとき頭の中で言っている言葉。「まだ早い。力がついてから使おう」。

行動を読んでも、自分のこととは思わない。
心の声を読むと、昨日言ったことが出てくる。

これはAから取った作りで、Cにはない。

### 違い2　1項目あたりの深さ

Cは100項目。1項目あたり2〜3ページ。
こちらは45〜50項目。1項目あたり5ページ。

Cは網羅で勝つ本。こちらは深さで勝つ本。
数で張り合うと、Cの下位互換になる。

ただし、Cが拾っていてこちらが拾えていない論点はある。それは次。

## 3　足りていない論点

CとDから拾った、こちらの45に入っていないもの。
重要度の高い順。

### A　分散学習（間をあけて復習する）

科学的にいちばん効果が確かめられている2つのうちの1つ。
もう1つが、思い出す練習（こちらはすでに本の背骨にしている）。

これが入っていないのは、穴として大きい。
いまの42番「忘れてから、最初から覚え直す」が近いが、
あれは「忘れた後の話」で、「間をあける」という設計の話になっていない。

### B　復習は、順番どおりではなく混ぜる

同じ種類の問題を続けて解くより、混ぜたほうが残る。
Cの031「順番に復習する → ランダムに復習する」。

こちらには1項目もない。

### C　人に説明する

Dの「ティーチング・テクニック」、Cの035「人に説明するように覚える」。
こちらの33番「説明できないのは、説明が下手なだけだと思う」が近いが、
あれは判定の話で、やり方として独立していない。

### D　試験本番の、解く順番と持ち物

Cは第7章まるごとこれに使っている（097〜100）。
こちらには1項目もない。

本番の1時間で点が変わる話なので、読者にとっての価値が高い。
しかも、他の項目を全部やったあとの最後に来るので、本の終わり方として強い。

### E　満点を取ろうとする → 合格点を取る

Cの011。こちらにない。
戦略編の芯に近い話なので、入れるべき。

### F　睡眠を削る

Cの051。Dも睡眠に1項目使っている。
中高生の本で、睡眠に触れないのは不自然。保護者も見る。

### G　スキマ時間と、場所

Cの041〜043。
優先度は上の6つより低い。入らなければ落としてよい。

## 4　こちらのほうが正確にできる論点　3つ

CとDで、言い方が雑になっているところがある。
ここを精密に書けば、こちらの本の価値が立つ。

### 論点1　答えは、すぐ見るのか、粘るのか

```
C　020　×じっくり考えてから答えを見る → ○すぐに答えを見る
こちら 28　×出てこなかったら、すぐ答えをめくる
```

正面からぶつかっている。

どちらも半分正しい。
長く粘るのは時間の無駄。これはCが正しい。
ただし、1回も思い出そうとせずに見るのは、ただのインプットになる。

正確な答えはこう。

　　10秒だけ出そうとする。出なければ見る。粘らない。
　　大事なのは、見る前に「どこまで出たか」を確かめること。

この10秒が、思い出す練習になっている。
Cの「すぐ見る」は時間効率の話だけをしていて、この10秒を落としている。

28番の○を、時間で切った形に書き直す。

### 論点2　計画は、時間で区切るのか、量で区切るのか

```
C　009　×時間単位で勉強計画を立てる → ○ノルマ単位で勉強計画を立てる
こちら 10　×1日の計画を、to doリストで立てて終わる（量だけでは締切がない）
```

これも正面からぶつかっている。

両方の指摘が、それぞれ正しい。

　　量だけで決めると、締切がない。だから夜まで動かない（こちらの指摘）
　　時間だけで決めると、座っているだけで達成になる（Cの指摘）

正確な答えは、両方セットにすること。

　　×　10時〜12時　数学
　　×　数学20問
　　○　10時〜12時までに、数学20問

ブロックに入れるのは、時間ではなく「量と締切のセット」。
どちらの本も、片方しか言っていない。ここは勝てる。

10番の本文を、この形に書き直す。

### 論点3　1つずつ終わらせるのか、混ぜるのか

```
こちら 03　×5つの苦手を、1日ずつ順ぐりに回す → ○1つ終わらせてから、次に行く
C　023　×一つの科目ばかりやる → ○複数の科目を勉強する
C　031　×順番に復習する → ○ランダムに復習する
```

このままだと、読者が混乱する。

正確には、新しく入れるときと、復習するときで逆になる。

　　新しく覚えるとき　　1つを、できるまでやってから次へ
　　復習するとき　　　　混ぜる。順番どおりにやらない

理由も違う。
新しく入れるときは、途中でやめると1つも完成しないから。
復習するときは、順番で解くと「次はこれだ」がわかってしまい、思い出す練習にならないから。

03番の書き方を、新しく入れるときの話だと明示する。
そのうえで、復習編に「混ぜる」の項目を1本足す。

## 5　形式について、CとDから取るもの

### Cから

章の見出しの上に、小さいあおり文を1行置いている。

```
　　最も効率的に最短で結果を出す
序章　勉強法「5つの原則」

　　科学的根拠とタイパを実現する
第1章　目標設定と勉強計画
```

これは効く。目次に動きが出る。こちらも入れる。

巻末に「参考文献（登場順）」。
こちらも入れる。学研の校閲でも必要になる。

### Dから

章の頭に Introduction を置いて、その章で何をやるかを1〜2ページで示している。

こちらは章扉を軽くする予定だったが、1ページだけ入れたほうがいい。
45項目を章で区切る以上、区切り目に何かが要る。

### 取らないもの

Cの100という数。
数で張り合うと深さが死ぬ。45〜50のまま、1項目5ページで行く。

Dの研究紹介の密度。
研究の名前を本文に出すのは、中高生向けでは重い。巻末にまわす。
