# 類書5冊の総括と、本質の置き場所

追加で見た2冊。

```
E　『スタンフォード大学オンライン高校の校長が教える 世界の研究に基づいた 勉強法大全』
F　『科学的根拠に基づく最高の勉強法』（安川康介）
```

既出の4冊と合わせて、全体像が出た。

---

## 1　いちばん大きな発見

5冊を同じ軸に並べると、こうなる。

```
　　　　　　　　　　戦略　　やり方　　量
D　DaiGo　　　　　　なし　　◎　　　　なし
E　スタンフォード　　なし　　◎　　　　なし
F　安川　　　　　　　なし　　◎　　　　なし
C　BEST100　　　　　少し　　◎　　　　037に1本だけ
A　説明がうまい人　　形式の参考
```

全部、やり方の本である。

何をやらないかを決める話が、ほぼない。
量が必要だという話は、もっとない。

理由ははっきりしている。
どの本もタイパと効率を売っている。量の話は、売り文句にならない。

ここが、この本の立ち位置になる。

　　世の中の勉強法の本は、やり方の列しか書いていない。
　　やり方が0の人には効く。
　　でも、あなたの0が戦略か量だったら、何も変わらない。

勉強法の本を読んだのに変わらなかった読者は、これで説明がつく。
しかも、どの本も否定していない。列が1つしかなかった、と言っているだけ。

これを第1章の芯にする。

---

## 2　Fとの重複　序章がまた当たっている

Fの CHAPTER1「科学的に効果が高くない勉強法」。

```
1　繰り返し読む（再読）
2　ノートに書き写す・まとめる
3　ハイライトや下線を引く
4　好みの学習スタイルに合わせる
```

こちらの序章と、4つとも同じ。
Dの第1章とも同じ。Cの017・045とも重なる。

つまり、この4つはもう3冊が書いている。
序章の売りには、できない。

### 序章で勝てる部分

3冊とも書いていないことが、3つある。

```
1　なぜ、やめられないのか
　　効果が低いやり方ほど「やった感じ」が強い、という説明。
　　3冊は「効果がない」までしか言わない。「だから選んでしまう」を言わない。

2　「探している間は、やらなくていい」
　　自分に合った勉強法を探す行為そのものが、やらない理由になっている。
　　これはどの本にもない。指導現場でしか見えない話。

3　著者が全部やって、落ちている
　　14時間、偏差値42、10校不合格。
　　しかも「自分に合ったやり方を完璧に持っていた」という形で出す。
　　研究を引用する本には、絶対に書けない。
```

序章の見出しは「自分に合った勉強法を、探すのをやめる」のままでよい。
ただし、4つの説明は短くして、上の3つに紙を使う。

## 3　EとFから拾う中身

### 本番編を、3本から5本にしたい

Eは本番（第5章）に10本使っている。中高生がいちばん欲しいところ。
こちらは3本。2本足したい。

```
　　緊張したときに「落ち着こう」とする
　　　×「落ち着け、落ち着け」
　　　○「これは興奮だ、と言いかえる」　　　（リアプレイザルの中身）

　　不安なまま、試験会場に座っている
　　　×「不安だけど、考えないようにしよう」
　　　○「始まる10分前に、不安を紙に書き出す」　（書き出すと点が上がる研究がある）
```

どちらも、読んだその日から使えて、他の中高生向けの本に入っていない。

### 暗記編に、記憶術を1本

Fの CHAPTER3（イメージ変換法・ストーリー法・場所法）。
こちらには1本もない。

ただし、記憶術は使いどころが狭い。
意味のないものを覚えるときだけ。意味のあるものには向かない。
1本だけ入れて、使いどころを限定して書くのがよい。

### 「なぜ？」と問う（精緻的質問）

Fが1節使っている。効果の確認されている方法。
こちらの23番「なぜを持たずに、語呂だけで覚える」が近いが、
あれは語呂の話であって、「なぜと問う」が独立していない。

23番の本文の中で、やり方として書き切る。項目は増やさない。

### 入れないもの

```
E　ポモドーロ、マインドフルネス呼吸、場所法、第一原理思考、弁証法、
　　ソクラテス式問答法、アブダクション、社会的構成主義

理由　中高生が明日やることにならない。
　　　Eは高校生向けに見えて、実際は大人向けの語彙で書かれている。
　　　ここに合わせると、この本の読者が落ちる。
```

## 4　本質を、どこに置くか

ここまでの50項目は、放っておくとノウハウ集になる。
それを防ぐのが、序章と第1章。

この2章で言うべきことを、5つに絞った。

```
1　頭のいい人の頭のなかは、外から見えない
　　だから真似できない。だからこの本で見える化する。
　　（冒頭メッセージで提示済み。序章で受ける）

2　効果が低いやり方ほど、やった感じが強い
　　だから、自分の感覚で勉強法を選ぶと、必ず外す。
　　選ぶ基準は「やりやすいか」ではなく「出せたか」。

3　「自分に合った勉強法」を探している間は、やらなくていい
　　探す行為が、始めない理由になっている。

4　結果 ＝ 戦略 × やり方 × 量。掛け算なので、1つが0なら全部0
　　14時間 × 戦略0 × やり方0 ＝ 偏差値42

5　勉強法の本を読んでも変わらなかった理由
　　世の中の勉強法の本は、やり方の列しか書いていない。
　　あなたの0が、別の列にあった。
```

1〜3が序章。4〜5が第1章。

5を入れることで、50項目が「ノウハウの羅列」ではなくなる。
50項目それぞれが、3つの列のどれかを埋めにいく作業になる。

## 5　二項対立は、全項目で守る

類書には二項対立になっていないものもある（D・E・F）。
それでも、こちらは50項目すべてで×と○を立てる。

理由は3つ。

```
1　読者が、自分がどちら側かを即座に判定できる
2　目次が、そのまま100行の自己診断になる
3　×に心の声を置けるのは、二項対立の形だけ
```

Cは二項対立を使っているが、×が行動で書かれている。
こちらは心の声で書く。ここだけで、別の本になる。
