# 本質と具体を、つなぐ設計

世の中の勉強法の本は、2つに分かれている。

```
A　本質だけで終わる本　　抽象的で、読後感はある。でも明日の行動が決まらない
B　具体だけの本　　　　　やることはある。でも点々としていて、つながらない
　　　　　　　　　　　　 だから、3日で元に戻る
```

この本は、本質から具体へ下ろす。
ただし、両方を載せるだけでは足りない。両方載っている本でも、行動は変わらない。

理由。
1章で本質を読み、10章で具体を読む。そのあいだをつなぐ部品がない。
だから本質は2章で蒸発し、読者は50個のテクニックを覚えようとして、10個忘れる。

つなぐ部品を、3つ置く。

---

## 部品1　本質を、3つの問いに畳む

概念は持ち歩けない。問いは持ち歩ける。

結果 ＝ 戦略 × やり方 × 量。
これを、その場で自分に聞ける3つの問いにする。

```
始める前　　　　これ、出るのか？

やっている間　　いま、閉じて出せるか？

終わったあと　　今日、何個増えた？
```

3つが、式の3つの列にそのまま対応している。
しかも、時間の順に並んでいる。始める前、最中、終わったあと。

この本を読み終わったあと、読者が持って帰るのはこの3行だけでいい。
50の項目は、この3つの問いの練習問題になる。

再現性の正体は、ここにある。
本に載っていない場面でも、この3つを自分に聞けば、同じ答えにたどり着く。

---

## 部品2　頭のなかを、書き起こす

この本の約束は、冒頭メッセージに書いてある。

　　頭のいい人の頭のなかは、外から見えない。だから真似できない。
　　だから、見える化する。

約束を守る方法は、1つしかない。
その瞬間の頭のなかを、独白としてそのまま書くこと。

アドバイスではない。書き起こしである。

```
伸びない人の頭のなか（解説を読み終わった瞬間）

　「あー、なるほどね」
　「ここで両辺に2をかけるのか」
　「わかったわかった。次いこう」


頭のいい人の頭のなか（同じ瞬間）

　「なるほど。……いや待て。いま、なるほどって言っただけだ」
　「閉じたら、出るか？」
　「2行目までは出る。3行目の、両辺に2をかけるところ。あれは自分で思いつくか？」
　「たぶん、出ない」
　「じゃあ、閉じる」
```

2つの違いは、1か所しかない。

　　「……いや待て」

install するのは、この1か所。
やり方ではなく、やり方を呼び出す声を渡す。

50項目すべてに、この書き起こしを入れる。
50回読むと、読者の頭のなかで声が鳴り始める。

これが、本質と具体のあいだをつなぐ部品になる。
本質は3つの問い。具体は手順。そのあいだで、問いが手順を呼び出す瞬間を見せる。

---

## 部品3　各項目の最後に、どの問いが見つけたかを書く

```
この場面を見つけた問い　　いま、閉じて出せるか？
```

1行だけ置く。

読者は、50回これを読む。
50個のルールを覚えるのではなく、3つの問いを50回練習したことになる。

項目のラベル（戦略・計画・暗記など）は探すためのもの。
この1行は、持ち帰るためのもの。役割が違う。

---

## 項目の型

50項目すべて、この順で書く。

```
　番号　やっていること（行動で書く。禁止形にしない）

　　×「　」　やっているときの心の声
　　○「　」　頭のいい人の、同じ瞬間の心の声

1　場面　　　　　　生徒が実際に言った言葉から。時刻と具体物を入れる
2　犯人を否定　　　意志・集中力・センスのせいにする結論を止める
3　何が起きているか　仕組みで説明する。3つの問いのどれかに接続する
4　頭のなか　　　　伸びない人／頭のいい人の独白を、並べて書き起こす
5　やり方　　　　　手順。3つまで
6　注意　　　　　　やりすぎるとどうなるか
7　残るもの　　　　これをやると、その子に何が残るか。責めずに終わる
8　まとめ　　　　　1〜2行
　　この場面を見つけた問い　　3つのうちの1つ
　　今日やること　　　　　　　1行
```

4が、この本にしかない部分。
類書5冊のどれにも、頭のなかの書き起こしはない。

---

## 巻末で、再現性を試す

本に載っていない場面を5つ出して、読者に判定させる。

```
次の5つは、この本に出てきていない場面です。
3つの問いだけを使って、自分で答えを出してください。

1　英語のリスニングの問題集を買った。1回聞いて、スクリプトを見た。次に進んでいいか
2　先生が「ここ、出すぞ」と言った。ノートに書いた。これで足りているか
3　塾の宿題が終わらない。残り2時間。何から手をつけるか
4　暗記カードを3周した。全部○になった。もうやらなくていいか
5　模試が3週間後。過去問を開くのは、いつか
```

答えは次のページに載せる。
ただし、答えそのものより「どの問いで解いたか」を書く。

ここで答えられたら、この本は役目を果たしている。
答えられなかったら、どの項目に戻ればいいかを示す。

これを巻末に置くことで、読者は自分の再現性をその場で測れる。

---

## 第1章に、3つの問いを入れる位置

いまの第1章は、最後に3つの質問で自分の0を診断させている。

```
1　今年やらないと決めた単元を、3つ言えますか
2　今日の勉強のなかで、何も見ずに出した場面が、1回でもありましたか
3　先週、机に向かった時間の合計を、だいたい言えますか
```

これは「いまの自分を測る質問」。1回きりのもの。

3つの問いは、これとは別。「毎日その場で使う問い」。

混ざると、どちらも弱くなる。
診断の3つを先に置き、そのあとに持ち帰る3つを置いて、役割の違いを明示する。

```
　　いまの自分を測る質問　　　　読み始める前に、1回だけ
　　持ち帰る3つの問い　　　　　これから毎日、その場で
```
