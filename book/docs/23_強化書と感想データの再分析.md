# 強化書20法則と、感想データの再分析

材料
```
勉強法の強化書　300ページ　全20法則を抽出
感想の生データ　3,005件　うち先頭50件を精読
```

注意。感想は3,005件のうち50件しか読めていない。
しかも2023年9月23日、配布初日に回答した層なので、いちばん熱心な人に偏っている。
以下の「頻出」は、その50件の中での話。全件の傾向とは限らない。

---

## 2　感想でわかったこと

### 名前を出して褒められた項目

50件の中で、具体的に名指しされたもの。

```
計画に余白を作る　　　　　　　　　　　　3回　　法則4
他人と比較するな／昨日の自分と比較　　　3回　　法則17
まとめノートを作るのは伸びない人　　　　2回　　法則14
わかったつもりで終わっている　　　　　　2回　　法則10
ただ長時間やればいいわけではない　　　　2回　　法則6
ぶっ通しで勉強／タイマーで休憩　　　　　2回　　法則3
頭のいい人はめんどくさがり屋　　　　　　1回
```

### ここが重要

**他人と比較するな、が最頻出級なのに、いまの60に入っていない。**

いまの60番「点が下がったら、自分を責める」は近いが、別物。
比較の相手が、自分の過去ではなく他人、という場面が抜けている。

感想の原文。

```
「最近、周りの友達の会話をきいていて、共テ本番で8割ぐらい取れるぐらいの
　偏差値だったーとか、そういうことが多くて、自分は努力してるのに
　なんでこんなに低いんだろうと悩んで泣いたりしていました」

「他人と比較するのは絶対に辞めようってそう、思いました」
```

泣いた、という言葉が出ている。これは、いちばん痛いところ。

### メンタルの層が、想像以上に効いている

```
「勉強法だけでなく気持ちの面でもありがたいことを教えていただきました」
「努力を習慣にすること、また強い心を持つことが大切だと分かった。
　強いメンタルの作り方も教えていただきたいです」　←　リクエストが来ている
「自分の頭の出来が悪いんだ…とかって思ってたけど、
　やり方次第で変われるんだ！っていう自信にもなりました」
```

強化書は20のうち5つをここに使っている。
いまの60は、最後の4つだけ。薄い。

### 量が、熱意として受け取られている

```
「枚数がとても多く、熱意や私たちに成功して欲しい、
　変わって欲しいという思いが強く伝わってきました」
「まさか300枚以上しっかりと丁寧に書かれているのは
　てったさんの信念と思いが伝わりました」
```

256ページは、薄くしないほうがいい。量そのものが伝えている。

### 不満は2つだけ

```
「いいことはたくさん書いてあったけどページ数が多かったです」（70点）
「最後の方をもう1回読みたいと思っても、ページ数が多く、
　そこに行くのが少し大変。最初に目次があるといい」（99点）
```

どちらも、戻れないことへの不満。内容ではない。
書籍では、目次・柱・ノンブル・巻末の引き方で解決する。すでに設計に入っている。

### 形式で評価されたもの

```
図・イラストがあってわかりやすい　　　評価の第1位級
NGとOKの比較　　　　　　　　　　　　 第2位級
短い文　　　　　　　　　　　　　　　　複数
```

図解ラフ50点は、削ってはいけない。ここが評価の中心にある。

## 3　強化書と書籍で、1か所だけ揃っていない

### 法則9

```
強化書　　書かず、繰り返し見て暗記
書籍23番　閉じて、思い出して書く
```

一見、逆に見える。

ただし、強化書の本文（p155）はこう書いている。

```
「1分間に10回書いて覚えるよりも、1分間に60回繰り返し見てテストした方が
　脳に定着します。繰り返し見るもの、思い出すものを
　『脳は大事な情報』だと認識をして忘れない知識になるのです」
```

テスト、思い出す、という言葉が入っている。
STEPでも「反射レベルで出てくるようになった単語を覚えたと言おう」と書いてある。

つまり、意図は思い出す練習で合っている。
緩いのは、見出しの「書かず、繰り返し見て」のほうだけ。
これだけ読むと、ただの再読に見える。

### 扱い方

矛盾として隠すのではなく、書籍で精密化する。
これは、誠実さとして武器になる。3,005人が強化書を読んでいる。

書き方の案。

```
前に配った教材で「書くより、見るほうが速い」と書きました。
あれは、半分合っていて、半分足りませんでした。

正確には、こうです。

　　見て、隠して、出す。

見るだけだと、速いけれど残りません。
見たあとに隠して、出せたかどうかを確かめる。ここまでで1周です。
```

23番の本文に、この3行を入れる。

## 5　60に足すべきもの

### 必ず足す（感想データが支持している）

```
　他人と比べて、落ち込む
　　　×「あの子は8割取れてる。自分は何をやってるんだろう」
　　　○「比べる相手は、先週の自分」

　「できない」で、話を終わらせる
　　　×「自分は、数学ができない」
　　　○「まだ、できていない。まだ、を足す」
```

1つ目は、感想で最頻出級なのに入っていなかったもの。
2つ目は、Yetの話。1つ目とセットで効く。

### 足したほうがいい（著者のリスト由来）

```
　なぜそうなるのかを聞かずに、そのまま覚える
　　　×「そういうものだと覚えよう」
　　　○「なぜ？　を1回だけ、自分に聞く」
```

### 部活

感想に、こうある。

```
「私は中学三年生の受験生です。夏休みは部活が忙しいとかスマホばっかりで
　言い訳して逃げてきました」
```

部活は、中高生にとって言い訳にも、事実にもなる。
類書5冊に1本もない。入れるべき。

```
　部活がある日を、勉強しない日にする
　　　×「今日は疲れてるから、明日まとめてやる」
　　　○「部活の日にやることを、先に1つだけ決めておく」
```

ただし、中身は著者の現場の答えが要る。
週6で帰宅8時の子に、実際に何をさせてきたか。

## 6　改訂後の項目数

```
現在　　　　　　　　　　　　60本
足す　　他人と比べる　　　　＋1
　　　　Yet　　　　　　　　 ＋1
　　　　なぜそうなる　　　　＋1
　　　　部活　　　　　　　　＋1
削る　　02 満点を取るつもりで（01・03と重複）　　−1
　　　　26 科目の数だけ覚え直す（抽象的）　　　　−1
　　　　51 いつも同じ場所で（根拠も実行も弱い）　−1
　　　　　　　　　　　　　　61本
```

61は半端なので、もう1本削るか足すかで60か62にそろえる。

### 章の配分も変える

```
第10章　続かないとき　　4本　→　7本
　　　　　やる気が出るのを待つ
　　　　　解けないまま、その日を終える
　　　　　睡眠を削って、勉強時間を増やす
　　　　　他人と比べて、落ち込む　　　　　　★新
　　　　　「できない」で、話を終わらせる　　★新
　　　　　点が下がったら、自分を責める
　　　　　部活がある日を、勉強しない日にする　★新　←　章を移すかも
```

感想が示しているのは、ここが薄いということ。
強化書は20のうち5つをメンタルに使って、そこが刺さっていた。
60のうち7つなら、比率としては強化書より薄い。それでちょうどいい。
書籍は勉強法の本なので、メンタルが主役になってはいけない。
