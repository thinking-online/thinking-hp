# レイアウトイメージ用　ChatGPTプロンプト

ChatGPTの画像生成は日本語が崩れる。
文字を読ませる目的ではなく、組みの雰囲気を見る目的で使う。

文字まで正確なものが必要なら、HTMLで実物を組んでPNGにする。

---

# 前提（3枚に共通）

```
判型　　四六判（127×188mm）
組み　　縦組み・右綴じ
色　　　2色刷り（黒＋1色）。1色は濃い青か、くすんだ赤
書体　　本文は明朝、見出しと数字はゴシック
余白　　多め。文字を詰めない
対象　　中高生と、その保護者
棚　　　学参と実用書の中間
```

---

# プロンプト1　項目の1ページ目

```
日本語の書籍の、1ページを真上から見た画像を作ってください。

【本の種類】
中高生向けの勉強法の本。四六判（127×188mm）の単行本。縦組み・右綴じ。
2色刷り。黒と、濃い青の2色だけ。派手な色は使わない。

【ページの構成】　上から下へ
1　ページの上端に、細い柱。小さなゴシックで章名
2　その下に、大きな数字「23」。青。太いゴシック。ページ幅の5分の1くらいの大きさ
3　数字の左に、縦組みの見出し。2行。大きめの明朝。黒
4　見出しの下に、細い横罫線を1本
5　罫線の下に、囲みが1つ。薄い青の地に、2行
　　1行目の頭に「×」、2行目の頭に「○」。本文より小さい文字
6　囲みの下に、本文が始まる。縦組み。9ポイント相当。行間はゆったり
　　本文は5行から7行だけ見えていて、ページの下で終わる
7　ページの右下に、小さくノンブル

【雰囲気】
静か。余白が多い。学参っぽくない。
ビジネス書の落ち着きと、中高生が読める軽さの中間。
イラストは入れない。写真も入れない。

【絶対にやらないこと】
派手な色、グラデーション、丸いポップな装飾、
ページ全体を囲む枠、背景に模様、手書き風フォント
```

# プロンプト2　「頭のなか」のページ

この本の目玉のページ。ここのレイアウトがいちばん大事。

```
日本語の書籍の、1ページを真上から見た画像を作ってください。

【本の種類】
中高生向けの勉強法の本。四六判。縦組み・右綴じ。
2色刷り。黒と濃い青のみ。

【ページの構成】
1　ページ上部に、小見出し。「頭のなか」という短い見出し。
　　左に短い縦線が入ったスタイル
2　その下に、縦長の囲みが2つ、横に並んでいる
　　右の囲みと左の囲みは同じ大きさ。あいだに適度な間隔

　　右の囲み
　　　上に小さな見出し。地は白。枠線は細いグレー
　　　中に、短い縦書きの行が4行。それぞれ鍵括弧でくくられている
　　　行の長さはバラバラ。短い行が多い

　　左の囲み
　　　上に小さな見出し。地はごく薄い青。枠線は細い青
　　　中に、短い縦書きの行が9行。それぞれ鍵括弧でくくられている
　　　右の囲みより行数が多い。長さはバラバラ

3　2つの囲みの下に、本文が3行
4　右下に小さくノンブル

【意図】
2つの囲みは、同じ場面での2人の心の中の声を並べたもの。
右が少なく、左が多い。その差が目で見てわかることが大事。
左の囲みのほうが、情報量が多く見えるようにする。

【雰囲気】
会話の吹き出しにはしない。あくまで文章の囲み。
漫画っぽくしない。静かで、読み物らしく。

【絶対にやらないこと】
吹き出し、人物イラスト、顔のアイコン、矢印、
派手な色、グラデーション
```

# プロンプト3　目次の見開き

```
日本語の書籍の、目次の見開き2ページを真上から見た画像を作ってください。

【本の種類】
中高生向けの勉強法の本。四六判。縦組み・右綴じ。
2色刷り。黒と濃い青のみ。

【見開きの構成】
右ページの右端に、章の見出し。
　大きな縦組みの文字で1行。その右肩に小さく「第5章」
　章見出しの下に、細い青の縦線が長く引かれている

その左から、項目が縦に並ぶ。右から左へ。
1つの項目は、縦3行のかたまりになっている。

　1行目　左に番号（2桁の数字、青、ゴシック）。その左に見出し。黒の明朝
　2行目　1行目より1段下げて、小さい文字。頭に「×」。グレー寄りの黒
　3行目　さらに同じ段。頭に「○」。青

　項目のいちばん下に、点線のリーダーと、小さなページ番号

項目のかたまりが、見開きで8組くらい並んでいる。
かたまりとかたまりのあいだに、はっきりした間隔がある。

【意図】
×と○が全項目についているので、目次を上から下まで見るだけで、
「自分は×のほうだ」と何度も気づくようになっている。
そこが見た目でわかることがいちばん大事。

【雰囲気】
整然としている。余白が多い。
×の行がグレー寄り、○の行が青で、色で対比が見える。

【絶対にやらないこと】
イラスト、アイコン、罫線で区切った表、
背景色のベタ塗り、派手な装飾
```

# プロンプト4　章扉（必要なら）

```
日本語の書籍の、章扉1ページを真上から見た画像を作ってください。

四六判。縦組み・右綴じ。2色刷り。黒と濃い青。

【構成】
1　ページ中央より少し上に、小さな文字で1行のあおり文
2　その左に、大きな縦組みの章タイトル。2行。
　　1行目は書名のくり返し、2行目が場面の名前
3　章タイトルの右肩に「第5章」と小さく
4　ページの下4分の1は、完全な余白

【雰囲気】
何も置かない。余白が主役。
章の変わり目で、読者の呼吸が1回入る感じ。

【絶対にやらないこと】
イラスト、写真、背景のベタ塗り、飾り罫
```

# 実際に入れる文字（画像が崩れたとき、口で説明する用）

## プロンプト1に対応する中身

```
柱　　　第5章　覚えるとき
番号　　23
見出し　単語を、1語10回ずつ書いて覚える
×　　　「10回書けば、さすがに覚える」
○　　　「見て、隠して、出す。これで1周」
タグ　　やり方

本文の出だし
　　英語の小テストが明日あります。範囲は30語。
　　ノートを開いて、1語ずつ書いていきます。
```

## プロンプト2に対応する中身

```
小見出し　　頭のなか

右の囲み　　ノートに向かって、伸びない人
　　　「available、available……」
　　　（単語帳を見ながら書く）
　　　「あと7回」
　　　「次、consist」

左の囲み　　同じとき、頭のいい人
　　　「10個、見る」
　　　（30秒見る）
　　　（単語帳を閉じる）
　　　「available ……利用できる、だ」
　　　「consist ……」
　　　「……出てこない」
　　　「飛ばして次。indicate ……示す」
　　　（10個書いて、開く）
　　　「出なかったのは、consist と obtain の2個か」
```

# 注意

ChatGPTに縦組みを正確に描かせるのは難しい。
横組みで出てくることがある。そのときは、こう追記する。

```
文字は上から下へ流れる縦書き（vertical Japanese text）にしてください。
行は右から左へ進みます。
```

それでも崩れる場合は、レイアウトの骨格（どこに何が、どの大きさで）だけ見て、
文字は無視する。
