# 章の切り方　場面で切るか、力で切るか

2026年11月4日　著者からの問いに対する回答

---

# 結論

章は、場面で切る。

```
第1章　計画　　第2章　授業　　第3章　暗記　　第4章　演習
第5章　復習　　第6章　集中　　第7章　気持ち　　終章　本番
```

6つの力は、章名から降りて、各項目の右肩に移す。
章名として6回出るかわりに、62項目の肩に62回出る。

成果物は2つある。

```
manuscript/企画書/構成_場面版.md　　推奨。これで進める
manuscript/企画書/構成_力版.md　　　比較用。手元に置く
```

---

# 1　なぜ場面か

## 理由1　目次を読む人が、説明を待たなくていい

書店で、中学生か保護者が目次を開く。見ている時間は30秒。

```
×　第3章　つなげる力　　　　　　意味が、読むまでわからない
○　第3章　暗記　　　　　　　　　読む前に、わかる
　　　　　「覚えても、すぐ忘れます」
```

「つなげる力」は、本を読み終えた人には最高の言葉になる。
けれど目次でそれを見る人は、まだ1行も読んでいない。
目次は、読んだあとの言葉ではなく、読む前の言葉で書く。

## 理由2　力で切ると、章の厚さが歪む

```
力版　　選ぶ 9　入れる 7　つなげる 5　出す 9　なおす 9　続ける 18
　　　　　　　　　　　　　　　　　　　　　いちばん薄い章と、2.6倍の差

場面版　計画 11　授業 7　暗記 9　演習 9　復習 9　集中 6　気持ち 6　本番 5
　　　　　　　　　　　　　　　　　　　　　いちばん薄い章と、1.8倍の差
```

歪みは、調整の問題ではない。意味がある。

力版の第6章「続ける力」は18本になり、そのままでは読めないので、
中で「計画6・集中6・気持ち6」に割らないといけなかった。
つまり力版は、いちばん大きい章の中で、すでに場面で切っていた。

力は、生徒の悩みが集まる単位ではない。場面が、その単位。

## 理由3　杉浦さんのご指摘が、根元から消える

ご指摘は、「①→⑥を全部済ませてから次」と読まれると
「どれだけ面倒で時間のかかる勉強をするんだ」になる、だった。

```
力版　　　目次に「選ぶ力・入れる力・つなげる力……」が並ぶ
　　　　　番号を外しても、6つを順に通る工程には見えてしまう
　　　　　「6つ全部を毎回使うわけではありません」と本文で消すしかない

場面版　　目次に「計画・授業・暗記・演習・復習・集中・気持ち」が並ぶ
　　　　　どう見ても工程に見えない。場面は、順に通るものではないから
　　　　　本文で消す必要がない
```

本文で弁解するより、目次でそう見えないほうが強い。

## 理由4　6つの力は、弱くならない。強くなる

```
力版　　　章名として　　　　　6回　出る
場面版　　各項目の右肩に　　 62回　出る
　　　　　＋　章扉に「この章でよく使う武器」2つ
　　　　　＋　序章で6つまとめて
　　　　　＋　終章で6つ全部
　　　　　＋　巻末カード6行
```

同じ言葉を62回見た人は、覚える。6回では覚えない。
生徒が持ち帰るのは章名ではなく、「いま、閉じて出せる？」という1行。
その1行は、項目の中にいるほうが、何度も目に入る。

# 2　失うもの

## 体系が、目次からは見えなくなる

これは本当に失う。埋め方を3つ置く。

```
1　序章26ページで、6つを1問の流れで渡す
　　読者は、第1章に入る前にもう6つ持っている

2　章扉に「この章でよく使う武器」を2つだけ書く
　　章に入るたびに、どれを使う章かがわかる

3　終章で、6つが本番の1日に全部出てくるところを見せる
　　読み終わった人が、自分が6つ持っていたことに気づく
```

## 目次が、類書と似る

計画・暗記・演習・復習は、勉強法本の標準形。
調べた5冊は全部この形に近い。

これは欠点に見えるが、売るうえでは利点。

```
目次　　　見慣れた形　　　→　安心して、買える
中身　　　見たことのない形 →　読んで、驚く
```

差別化を目次に置くと、買う前に説明が必要になる。
買う前に説明が必要な本は、書店で売れない。
差別化は、ページをめくった先に置く。

# 3　杉浦さんへの出し方

## 両方送って選んでもらうのは、すすめない

著者の案として「どっちとも作って杉浦さんに聞く」があった。
作るのは正しい。両方作った。ただ、両方送るのはすすめない。

```
2案を並べて送ると　　「ご指摘にどう答えるか、決められませんでした」
　　　　　　　　　　　 と読まれる

1案で送ると　　　　　「ご指摘を、構成で解決しました」
　　　　　　　　　　　 と読まれる
```

杉浦さんのご指摘は、具体的な問題の指摘だった。
それに対して2案で返すのは、問題を返送するのに近い。
編集長の時間を使わせずに、答えを出したほうがいい。

## 送る形

場面版1本＋3行。

```
前回の企画書から、章の切り口を変えました。
ご指摘いただいた「①→⑥を順に通る工程に見える」問題を、
本文の弁解ではなく構成で消すためです。

章は、生徒が困っている場面で切りました（計画・授業・暗記・
演習・復習・集中・気持ち・本番）。6つの力は章名から降ろし、
62項目それぞれの右肩と、巻末カードに置きます。
章名で6回出るより、項目で62回出るほうが残ると判断しました。
```

力版は手元に置く。
「力で切る案も考えたのか」と聞かれたら、その場で出せる状態にしておく。
聞かれなければ出さない。だから両方作る意味はある。

# 4　内容の変更点

章を切り直すついでに、中身を4本入れ替えた。

## 入れた4本

```
12　授業を、聞く時間だと思っている
　　×「先生の話を、ちゃんと聞いておこう」
　　○「次に何を聞かれるかを、先に考える」

14　授業中、当てられないように下を向く
　　×「間違えたら、恥ずかしい」
　　○「当てられる前に、心の中で答えを出す」

18　小テストを、点が出たら捨てる
　　×「10点満点の小テストなんて、意味がない」
　　○「小テストは、本番の予告。間違えたものだけ残す」

21　英単語を、1語1訳で覚える
　　×「available は、利用できる。以上」
　　○「同じ形の仲間を、まとめて見る」
```

12・14・18を入れたのは、授業という場面が独立した章になったから。
調べた類書5冊に、授業中の話は1本もない。
全部、大学受験か社会人向けで、学校の授業が時間の中心にない読者を想定している。
中高生は1日6時間を授業に使う。ここが空いているのは、もったいない。

## 隣に吸収した4本

消したのではなく、近い項目の中に1ページとして入れ直す。

```
旧18　なぜを持たずに語呂だけで覚える　→　22（なぜ？を聞く）の中
旧29　説明できないのは説明が下手なだけ →　25（人に説明する）の中
旧44　毎晩、明日の計画を立て直す　　　 →　10（崩れてから作り直す）の中
旧49　休憩のたびにスマホを開く　　　　 →　47（スマホを机に置く）の中
```

4本入れて4本吸収したので、項目数は62のまま、ページも約270で変わらない。

# 5　これで確定するもの

```
章　　　　　8つ（序章＋7章＋終章）
項目　　　 62本。連番01〜62
武器　　　 6つ。各項目の右肩に1つ
二項対立　 62項目すべてに ×／○
ページ　　 約270　四六判
```

力は、選ぶ11／入れる8／つなげる5／出す10／なおす10／続ける18。
続ける力が18本あるが、計画・集中・気持ち・本番の4か所に分かれて出るので、
読んでいて重くならない。これが力版では1章18本になって重かった。
