# v5の前半と、6つの武器を、どう結合するか

2026年11月4日

---

# 結論

結合できる。しかも、つなぎ目を新しく作る必要がない。
はじめにが、すでに6つの武器の受け口を作っている。

---

# 1　はじめにが、すでに約束している

著者原稿（`manuscript/冒頭メッセージ.md`）の終盤。

```
　さっきの11個の数字を、思い出してください。
　1回目と2回目、外から見たら、まったく同じです。
　違うのは、そのとき頭のなかで何をしているか。そして、何をしていないか。

　ただ、それは映りません。

　あの子に聞いても、たぶん答えられません。
　「普通にやってるだけ」と言われて終わります。

　この本で、それを全部、見える化します。
```

これは手形である。

「頭のなかを見える化する」と言った以上、見える化されたものを出さないといけない。
その中身が、6つの武器。

```
　約束　　はじめに　　　頭のなかは映らない。だから見える化する
　回収　　第2章　　　　 見える化すると、6本あった
　使用　　第3章〜　　　 その6本を、62の場面で使う
```

別々に作ったのに、受け口がすでに空いていた。

---

# 2　6つは、式から出てくる

ここが結合の本体。6つの武器を、天から降ってきたものにしない。

```
　　　　　　　結果 ＝ 戦略 × やり方 × 量
　　　　　　　　　　　 │　　　│　　　│
　　　　　　　　　　選ぶ力　入れる力　続ける力
　　　　　　　　　　　　　　つなげる力
　　　　　　　　　　　　　　出す力
　　　　　　　　　　　　　　なおす力

　　　　　　　　　　　11本　　33本　　18本　＝　62
```

第1章で式を立てる。
第2章で「やり方」という1語を4つに割る。それだけ。

6つを覚えてもらうのではなく、式を分解したら6つになった、という順番にする。
読者の負担が、1つも増えない。

## 検算できる主張になる

第1章_v5 には「勉強法の本を読んでも、変わらなかった人へ」という節がある。
類書はやり方の列しか埋めていない、という主張。

この分解をすると、その主張が数字で裏が取れる。

```
　類書5冊　　やり方の列だけ。戦略と量は空
　この本　　 62本のうち29本（47%）が、戦略と量
```

docs/20、docs/21 の類書分析と一致している。

---

# 3　アクティブリコールの扱い

序章 v5 には「絶対に外してはいけない要素＝アクティブリコール」がある。
6つの武器では「入れる力＋出す力＝閉じること」と言っている。

同じものを2つの名前で呼んでいる状態。これは直す。

```
　出し方　　1回だけ出して、すぐ日本語に落とす

　　「アクティブリコール、と呼ばれています。
　　　この本では『閉じて、出す』と書きます」
```

カタカナを1回出す理由は、書店で保護者に効くから。
類書（科学的根拠に基づく最高の勉強法ほか）がこの言葉で売れている。

使うのは日本語のほう。中高生に「アクティブリコールしろ」は届かない。

---

# 4　章にするか、第1章に入れるか

6つの武器を、第1章の中に置くこともできる。章として独立させることもできる。

## 章にするほうを推す

```
　第1章　結果 ＝ 戦略 × やり方 × 量
　第2章　頭のいい人が持っている、6つの武器
　第3章　頭のいい人が、絶対にやらないこと　計画編
```

目次の上で「持っている」と「やらないこと」が対になる。

6つの武器は、この本でいちばん独自な部分。
第1章の中に埋めると、目次に1文字も出ない。

## 第1章に入れた場合の問題

第1章 v5 はすでに5,822字ある。
そこに6つの武器（約2,500字＋図）を足すと、第1章だけで18ページになる。

過去に、第1章に式・6つ・ノート・図3枚を全部入れた案を作って、
著者から「微妙」と言われている（docs/18）。同じことになる。

# 6　序章v6（1問やらせる案）の行き先

数字で1問やらせて、閉じて、もう1問。
これは序章 v5 と入れ替えるために書いたが、v5 を使うことになったので宙に浮いた。

置き場所の候補は第2章の頭。

```
　第2章の冒頭で、もう1回やらせる
　　1から100までの和（やり方つき）　→　できる
　　本を閉じて、1から60まで　　　　　→　出ない
　　「わかった、とできる、は別」　　 →　入れる力・出す力に名前をつける
```

はじめにの11個の数字が「見方の話」。
第2章の1問が「わかった≠できる の話」。
同じ形の体験を2回やることになるが、証明している中身が違う。

ただし、開幕が数字で2連続になる。
捨てる判断もある。著者に確認が必要。
