# なぜこれが要るか

62項目を機械で測った結果。

```
　著者の声（僕／私）がある　　 0本　／　62本
　実在の生徒らしい記述　　　　 2本　／　62本
```

はじめに・序章・第1章には著者が出てくる。
本文62本には、一度も出てこない。

2000人を教えてきた人の本で、本文に教えた人がいない。
原理は正しいのに、誰が言っているのかわからない。

ここを埋めると、本が変わる。
僕が書ける部分ではないので、場所と質問だけ用意した。

# A　まるごと1本　7か所

名前は仮名でいい。学校名は出さない。

```
09　1日の計画を、to doリストで立てて終わる

　　ブロック計画を最初に渡した子で、いちばん変わった子は誰ですか。
　　何が、何点から何点になりましたか。
　　渡したとき、その子は何と言いましたか。
```

```
11　部活がある日を、勉強しない日にする

　　週6で部活、帰宅8時の子に、最初の1個として実際に何をやらせましたか。
　　その子は、何週間で崩れましたか。崩れたあと、何を変えましたか。
　　最後、どうなりましたか。
```

```
19　教科書に線を引いて、まとめノートを作る

　　3時間かけてきれいなノートを作ってきた子に、何と言いましたか。
　　その子は、そのあとどうしましたか。
　　ノートを捨てさせましたか。それとも使わせましたか。
```

```
20　単語を、1語10回ずつ書いて覚える

　　10回書いて覚えていた子を「見て、隠して、出す」に変えたとき、
　　最初の1週間で何が起きましたか。
　　最初は嫌がりましたか。何と言って納得させましたか。
```

```
32　解説を読んで納得したら、次の問題へ進む

　　白紙再現を初めてやらせたとき、生徒はどんな顔をしましたか。
```

```
42　ケアレスミス、次は気をつける、で終える

　　ミスに名前をつけさせたとき、生徒が実際につけた名前は何でしたか。
　　（例　符号を落とす／条件を読み飛ばす／単位を書かない）
　　名前をつけたあと、その子のミスは何回から何回に減りましたか。
```

```
55　他人と比べて、落ち込む
```

# B　1行か2行　14か所

ここは長くなくていい。「僕が見てきた中では」で始まる1文でいい。
断定が強いのに、根拠が著者の経験しかない場所。

```
01　実力がついてから、過去問を開く
　　過去問を早く開かせて、変わった子はいますか。何が変わりましたか。

10　計画が崩れてから、作り直す
　　崩れる日を先に入れた子は、どのくらい続きましたか。

14　授業中、当てられないように下を向く
　　下を向く子に、何と言ってきましたか。

17　授業でわかったから、その単元は復習しない
　　授業でわかったのに点が出ない子の、いちばん多いパターンは何ですか。

24　忘れてから、最初から覚え直す
　　「忘れる前にもう1回」を、実際に何日あけてやらせていますか。

28　問題文の途中で、わかった気になって解き始める
　　問題文の読み飛ばしで落とす子の、よくある落とし方は何ですか。

32　解説を読んで納得したら、次の問題へ進む
　　（Aと同じ項目。Aで書くならここは不要）

36　全部は解けないから、白紙のまま飛ばす
　　部分点でどのくらい拾えた子がいますか。

37　「ここ、全部わからないです」と言う
　　そう言われたとき、何と聞き返していますか。

47　スマホを、机の上に置いたまま勉強する
　　スマホを別の部屋に置かせて、何が変わりましたか。

48　集中できないのを、自分のせいにする
　　切れた場所を書かせたら、いちばん多かった原因は何でしたか。

54　勉強した時間を、記録して満足する
　　時間ではなく「何ができたか」を書かせたとき、生徒は何と言いましたか。
```

# C　著者にしか書けない、ほかの3つ

```
1　おわりに
　　いまは「1日14時間やって偏差値42だった」で始まっている。
　　でもその話は、はじめに・序章・第1章ですでに4回出ている。
　　おわりにに要るのは「そのあと何があったか」。

　　浪人して、何を最初に変えましたか。
　　いつ「これだ」と思いましたか。
　　2000人を見てきて、いちばん変わった子は誰ですか。

2　西野亮廣さんの話（第1章「若いうちの努力」）
　　このセッションからは出典サイトが読めない。
　　内容を1段落で教えてください。

3　1週間の実物の、本当の数字（09番）
　　いまは仮で置いてある。
　　週6部活・帰宅8時の中2が、実際に何時に何を何分やったか。
　　崩れた日に、実際にどうしたか。
```

# 書き方のお願い

```
　仮名でいい。学校名は出さない。
　きれいに書かなくていい。箇条書きでいい。こちらで文体を合わせる。
　数字があると強い。28点が64点、1週間で、3回から0回、など。
　うまくいかなかった話が1つあると、本全体の信用が上がる。
```

A7本とB14本で、合計21か所。
ぜんぶ埋まると、62項目の3分の1に著者が出てくることになる。
