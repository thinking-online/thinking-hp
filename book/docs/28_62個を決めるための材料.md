# 4　採用の基準　5つ

新しい項目を入れるとき、また今の項目を残すか決めるとき。

```
1　生徒が、実際にやっているか
　　理屈で間違っているだけのものは入れない。見たことがあるものだけ

2　×側に、まともな理由があるか
　　サボりの行動は入れない。この本は、頑張っている人の型しか扱わない
　　「10回書く」は入る。「勉強しない」は入らない

3　分岐点が、1語で言えるか
　　言えないものは、判断の項目ではなく事実の項目
　　事実の項目は、章に1〜2本まで

4　○側が、明日できるか。数字があるか
　　「意識する」「心がける」は不可
　　「10語」「0.5秒」「25分」のように、数で書けること

5　ほかの61本と、分岐点が重なっていないか
　　場面が違っても、分岐点が同じなら1本にまとめる
```

3と5が、いちばん落ちる。
