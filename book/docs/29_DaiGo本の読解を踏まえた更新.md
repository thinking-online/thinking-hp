# 1　最優先　序章が衝突している

資料の10ページに書いてある警告が、そのまま当たっている。

```
　DaiGo 第1章 非効率法6　　「自分の学習スタイルに合わせる」
　うちの序章　　　　　　　 「自分に合った勉強法」を、探すのをやめる
```

タイトルがほぼ同じ。さらに序章の中身を見ると。

```
　「この4つは、効果がいちばん低いグループです」
　　　→　Dunlosky 2013。DaiGo第1章の土台そのもの

　「人によって合うやり方が違う、は調べられています」
　　　→　Pashler 2008。非効率法6そのもの
```

序章の前半が、DaiGo第1章の要約になっている。同じ出版社、同じ根拠、同じ結論。

## ただし、後半は衝突していない

```
　1　「合ってる気がする」の正体
　2　人は、やったことのないものを選べません　　←　DaiGoにない
　3　早く固まった人のほうが、危ない　　　　　　←　DaiGoにない
```

2と3は、うちの幹（その場の自分を信用しない）から出ている議論。
DaiGoは「科学的に支持されていない」で終わる。
うちは「なぜ人はそれを選んでしまうのか」まで行く。

## 直し方

序章の入口を、科学から始めない。

```
　いま　　効果の低い4つ　→　科学ではこう　→　だから探すな
　　　　　　　　　　　　　　　↑　ここがDaiGoと同じ道

　直す　　やったことのないものは選べない　→　だから「合ってる気がする」は
　　　　　当てにならない　→　選ぶ基準を、やりやすさから、出せたかに変える
　　　　　　　　　　　　　　　↑　科学は根拠として後ろに置く。前に出さない
```

根拠が同じでも、出す順番を変えれば別の本になる。

同じことが24番にも起きている。

```
　DaiGo 非効率法7　「忘れる前に復習する」（望ましい困難。Bjork）
　うちの24番　　　　「忘れてから、最初から覚え直す」
```

こちらは向きが逆なので衝突しない。ただし見出しが似ないよう注意する。

# 2　入れたい候補　7つ

DaiGoの35技法のうち、うちの62本にないもので、
うちの幹に乗るものだけを選んだ。

## A　解法を、声に出して実況する　　上級テク1

```
　ひとりごと学習（self-talk）。問題を解きながら、やっていることを口に出す
```

これを推す理由は、根拠より構造にある。

この本は62本すべてで「頭のいい人の頭のなか」を実況して見せている。
その実況を、読者自身にやらせる項目になる。

```
　本が　　　頭のいい人の頭のなかを、実況して見せる
　読者が　　自分の頭のなかを、実況してみる
```

本の作り方そのものが、1つの技法になる。他の本にはできない。

置き場所　演習編
武器　　　出す力

## B　満点を取ったら、そこでやめる　　上級テク7

```
　オーバーラーニング（Shibata 2017）。できるようになった後の追加練習で定着が固まる
```

うちの20番（0.5秒で出る）の延長。
「出た」で終わらせない、の次は「できた」で終わらせない。

さらに、いま薄い「○がついた」の発生源（2本しかない）を埋める。

置き場所　暗記編
武器　　　出す力

## C　朝型が正しい、と思っている　　緩和テク5

```
　クロノタイプ。朝型夜型は遺伝的傾向で、型に反した時間帯は認知成績が落ちる
```

「朝早く起きて勉強しなさい」は、親と学校から来る圧力。
夜型の子が、朝型に矯正されて成績を落としている場面は実在する。

保護者の方へのページにも効く。

置き場所　集中編
武器　　　続ける力

## D　新しい単元に入るとき、いきなり読み始める　　準備テク2

```
　既知の書き出し（スキーマ理論）。学ぶ前に知っていることを書き出すと定着しやすい
```

うちのつなげる力（前にやったものにくっつける）の、入口版。
いまつなげる力は5本しかなく、いちばん薄い武器。

置き場所　授業編
武器　　　つなげる力

## E　誰のために受けるのかを、考えたことがない　　準備テク1

```
　自己超越目標（Yeager 2014）。自分のためより、誰かのため・社会のための目標の方が
　退屈な課題でも持続しGPAが上がる
```

気持ち編の根っこ。いまの気持ち編6本は、落ちたあとの立て直しばかりで、
そもそも何のためにやるのかがない。

ただし、中高生に「社会のため」は届きにくい。
「親に言われたから」から「誰に見せたいか」に変える形で書く。

置き場所　気持ち編
武器　　　続ける力

## F　努力したこと自体を、評価してしまう　　成長マインドセット3

```
　偽の成長マインドセット批判（Dweck 2015）。努力だけをほめるのは誤解で、
　本質は戦略の修正
```

これは第1章の「努力を美徳とするな」「過程に意味が出るのは勝ったあと」と完全に一致する。
すでに本の思想として入っているので、項目にするかは要検討。

第1章の根拠として置くだけでもいい。

## G　部活の日は、勉強が入らないと思っている　　緩和テク3

```
　学習後の運動（van Dongen 2016）。学習4時間後の運動で記憶保持が向上
```

これは慎重に扱う。研究は「学習のあとの運動」であって、
部活のあとに勉強する順番とは逆。

ただし、朝に覚えて放課後に部活、という順番なら合う。
11番（部活がある日を、勉強しない日にする）に、朝の単語20個の根拠として置ける。

新しい項目にはしない。11番の中に1段落。

# 4　研究の使い方

うちの文体ルールは「研究の名前を出さない」「〜と言われていますで逃げない」。
これは変えない。

```
　研究は　　何を書くかを決めるために使う
　本文には　出さない
```

Dunlosky 2013 も Shibata 2017 も、本文には1行も出さない。
出すのは、そこから出てきた数字と手順だけ。

参考文献は巻末に2ページ置く。そこにだけ、一次研究を並べる。

資料にある通り、年と著者は記憶ベースなので、
巻末に載せる前に原典で書誌を確認する。
確認できなかったものは載せない。

# 6　やること

```
1　序章の入口を、科学から「やったことのないものは選べない」に組み替える
　　　　　　　　　　　　　　　　　　　　　　　　　　　　　←　最優先

2　新しい項目を5本入れる　　A B C D E
　　入れるなら、いまの62本から5本外すか、67本にするか

3　11番に、朝の単語の根拠として運動の話を1段落足す（G）

4　第1章の「努力を美徳とするな」に、根拠を1行足す（F）

5　巻末に参考文献2ページ。書誌は原典で確認してから載せる

6　脱稿前に、DaiGo本と見出しを章ごとに照合する
```

2が決まらないと項目数が確定しない。62という数字は表紙に出る。
