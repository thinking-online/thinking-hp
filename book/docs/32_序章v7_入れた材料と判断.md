## 目次での見せ方を変えた

序章を「00番」にして、75項目とまったく同じ形で目次に出す。

```
　序章　00　「自分に合った勉強法」を、探す
　　　　　　×「自分に合ったやり方を、見つけたい」
　　　　　　○「やりやすさで選ぶのを、やめる」
```

理由は3つ。

1　75項目は全部「やってしまっていること」で書かれている。
　　03は「全部やろうとする」であって「全部やろうとするな」ではない。
　　序章だけが命令形（探すのをやめる）で、形が違っていた。
　　00にすると、1行目から最後まで形が揃う。

2　読者は序章を飛ばす。前置きに見えるから。
　　×／○がついていると、中身に見える。

3　目次の最初に×／○が1回出るので、01に着く前に読み方を覚えている。

表紙の75とは矛盾しない。「75個あります。その前に、0個目があります」と言える。

### 1　アクティブリコールを前に出す

効果の一覧を、2000人の節より前に移した。
下から見せるのではなく、先に1位を見せてから、下を見せる形にした。

```
　4つにチェック
　→　効果には順番がついている
　　　いちばん上のグループは2つだけ　思い出すこと／間隔をあけること
　　　しかも2つはセット　「間隔をあけて、思い出す」
　　　「思い出す」＝教科書を閉じて、自分の中から出す
　　　英語ではアクティブリコール。この本では「閉じて、出す」
　→　さっきの4つを同じ一覧で探すと
　　　線を引く／読み返す／まとめる　→　いちばん下
　　　何回も書いて覚える　→　見ながらやるなら、いちばん下
　→　2000人が、全員同じだった。しかも全員が同じ場所、いちばん下
```

順番を変えたことで、2000人の節の意味が変わった。
前は「全員が同じだった」という驚きだけだった。
いまは「効果が下のものに、全員が集まっていた」になる。
著者が言っていた「想像以上に多い」が、ここで出る。

4つ目だけ「見ながらやるなら」にしたのは、正確さのため。
隠して書くのは思い出すことになる。29番への伏線にもなる。

いちばん上を「1つ」と書きたくなるが、嘘になる。
効果の一覧で最上位は、思い出すことと間隔をあけること、の2つ。
2つをセットとして出せば、1つのことを言うのと同じ強さになる。

### 2　「探していい／探してはいけない」を作り直した

著者の指摘どおり、あの表は壊れていた。

```
　旧　探していい　　　　どうやって、出すか
　　　探してはいけない　出すかどうか
```

対になっていない。「どうやって出すか」は方法、「出すかどうか」は是非。
種類のちがうものを、無理やり同じ動詞（探す）に乗せていた。
しかも章全体が「探すな」なのに、ここだけ「探していい」なので主張が割れる。

```
　新　変えられない　　閉じて、出す
　　　変えていい　　　どうやって、出すか
```

節の名前も「ただし、探していいものもあります」から
「では、何なら選んでいいのか」に変えた。
ゆずる言い方をやめて、向きを変える言い方にした。

そのうえで、間違いを具体的に出した。


## 追記2　2026年11月8日　著者の指摘5つで、前半を作り直した

5つとも正しかった。特に3つ目は論証が壊れていた。

### 1　「誰からも教わっていない」は嘘だった

先輩に聞いたやり方もあるし、塾で言われたものもある。
自分でなんとなく始めて続いている人もいる。
「誰からも教わっていない人がいちばん多い」は、事実ではなかった。

12歳で決めた、も落とした。著者の言うとおり、何歳かは問題ではない。

問題は、教わったかどうかではなく、確かめたかどうか。
そこで、問いを2段にした。

```
　1　それ、どこで覚えましたか
　　　→　先輩／塾／友達／なんとなく。どれもありえる

　2　そのやり方が点になっているかどうか、1回でも確かめたことがありますか
　　　→　ない
```

1は全員ちがう。2は全員同じ。だから2が本題になる。

そのうえで、確かめなかった理由を本人の外に置いた。

```
　　テストが返ってきます。点が書いてあります。
　　でも、そこに書いてあるのは、結果だけです。
　　どのやり方が効いて、どのやり方が効かなかったのか。
　　これは、どこにも書いてありません。

　　点が下がったときに言われるのは、だいたい「もっとやれ」です。
　　やり方を見直せ、とは言われません。
```

結論の言い方も変えた。

```
　旧　最初にやったものが、そのまま残っただけです
　新　いまあなたがやっているのは、選んだやり方ではありません。
　　　誰にも止められなかった、やり方です
```

### 2　「センス・要領がいい」を節にした（新規）

著者の材料。節として立てた。

```
　　1　たまたま、上のほうのやり方で始めた
　　2　誰かに教わって、それを続けている
```

1のほうが多い。本人は自分が何をしているか分かっていない。

巻頭の「普通にやってるだけだよ」が、ここで回収になる。

```
　　あれは、ごまかしているのではありません。
　　本当に、分かっていないんです。
　　自分では、普通にやっているつもりだからです。

　　だから、センスに見えます。
　　でも、センスではありません。
　　やっていることが、たまたま上のほうだっただけです。
　　そして、やっていることなら、あとから真似できます。
```

表紙の「頭のいい人」が、ここで定義される。才能ではなく、やっていること。

### 3　「ばらけるはず」の論証を落とした

```
　旧　2000人がばらばらに探して、全員が同じ4つにたどり着く。
　　　探して選んだならばらけるはず。ばらけない＝誰も選んでいない。
```

これは証明になっていない。
全員が同じところから同じことを言われていれば、そろうのは当たり前。
ばらけないことは「誰も選んでいない」の証拠にならない。

しかも1の修正（教わっている人もいる）と矛盾していた。

```
　新　学校がちがっても、学年がちがっても、成績がちがっても、同じでした。
　　　2000人が、同じところで止まっている。
　　　ここまで同じだと、もう個人の問題ではありません。
　　　誰も確かめなかった、というだけです。
```

推論をやめて、事実の大きさだけで押す形にした。
そのぶん「責めない」が強くなった。

### 4　「勝った人は、勝ち方のプロです」を落とした

言い過ぎ。合格した先輩はプロではない。普通に勝っただけ。

```
　新　ただ、その人たちは、勝ったんです。
　　　なぜ勝てたのかを、確かめたわけではありません。
```

ことわざの説明も、著者の読みに合わせた。
勝ちには運が混じるが、負けには必ず原因がある。
だから原因を見つけて、次は同じことをしなければいい。

この読みのほうが、本の形（やらないこと75）に直結する。

### 5　「1回も閉じていません」を、1位との距離で言う形に

```
　旧　4つとも、見ながらやる作業です。1回も、閉じていません。
　新　4つとも、見ながらやっています。思い出す場面が、1回もありません。
　　　（11個の数字に戻したうえで）
　　　効果が低いやり方を、やっているのではありません。
　　　いちばん効くことを、1回もやっていないだけです。
```

「閉じていない」は観察。「1位を1回もやっていない」は距離。
先に1位を出してあるので、距離で言えるようになった。
