# 32　序章 v7　入れた材料と、入れなかった判断

2026年11月8日。著者から出た材料をもとに、序章を v6 → v7 にした。
2,760字 → 5,092字（約7 → 約12ページ）。

## 目次での見せ方を変えた

序章を「00番」にして、75項目とまったく同じ形で目次に出す。

```
　序章　00　「自分に合った勉強法」を、探す
　　　　　　×「自分に合ったやり方を、見つけたい」
　　　　　　○「やりやすさで選ぶのを、やめる」
```

理由は3つ。

1　75項目は全部「やってしまっていること」で書かれている。
　　03は「全部やろうとする」であって「全部やろうとするな」ではない。
　　序章だけが命令形（探すのをやめる）で、形が違っていた。
　　00にすると、1行目から最後まで形が揃う。

2　読者は序章を飛ばす。前置きに見えるから。
　　×／○がついていると、中身に見える。

3　目次の最初に×／○が1回出るので、01に着く前に読み方を覚えている。

表紙の75とは矛盾しない。「75個あります。その前に、0個目があります」と言える。

## 著者の材料を、そのまま入れなかった3か所

### 1　「科学的に否定されています」→ 書き換えた

線を引く・再読・まとめるは、否定ではなく「効果が低い」。
言い切ると、知っている読者と編集者に刺される。

本文はこうした。

```
　　勉強のやり方には、効果を調べて順番をつけたものがあります。
　　その一覧を見ると、さっきの4つのうち3つが、いちばん下のグループに入っています。

　　　やっている人が、いちばん多い。
　　　効果は、いちばん低い。
```

正確で、しかも「否定されています」より刺さる。

置く順番も変えた。

```
　×　科学的に否定されている　→　だから2000人も同じだった
　○　2000人が、全員同じだった　→　しかも効果は最下段にある
```

科学を先に出すと、同じ出版社の類書と同じ入り方になる。
2000人は朝倉 徹大にしか書けない。自分のデータを主、研究を裏づけに回す。

### 2　「自己流＝事故流」→ 著者自身に向けた

読者に向けると、本のルール（伸びない人を責めない）を破る。
後半の「僕は自分に合ったやり方を完璧に持っていました」の落ちにした。

```
　　僕は、自己流でした。
　　誰にも教わらず、自分で決めて、自分のやり方を信じていました。

　　いまから思えば、事故流です。
```

同じ話を2回しなくて済むうえ、punchは残る。

### 3　①②③とバケツ　→　02から序章に移した

役割が割れた。

```
　序章　何をどの順でやるか（①②③とバケツ）
　02　　なぜその順番なのか（掛け算。いちばん小さい数を直すのがいちばん効く）
```

02は 3,213 → 3,043字。全体の長さはほぼ変わっていない。

あわせて、巻頭が答えずに置いた「では、どれを捨てますか？」を、
序章の①②③で回収するようにした。
捨てるものは自分で選ぶのではなく、順番どおりにやると勝手に決まる、という答え。

## いちばんの収穫　「勝ちに不思議の勝ちあり、負けに不思議の負けなし」

この本が「やらないこと75」という否定形で書かれている理由を、
序章で説明できるようになった。

```
　　勝ち方　　人による　　　運が混じる　　　真似できないことがある
　　負け方　　全員同じ　　　確かめられる　　先に、消せる
```

あわせて「教える人は、勝ち方のプロ。でも、学び方のプロとは限らない」を入れた。
先生・先輩・親の助言が効かない理由を、誰も責めずに説明できる。
保護者が買う本なので、ここは大きい。

言葉の出どころ（野村克也／松浦静山）は本文に出さない。
中高生には「昔から、こういう言葉があります」で足りる。

## 「作業か、勉強か」を言葉として立てた

```
　　作業　　終わらせることが目的。終われば、達成感がある
　　勉強　　できるようになることが目的。できなければ、意味がない
```

やりやすさの話の落ちとして置いた。
読者が持ち帰る言葉が1つ増える（6つの力の上に乗る、序章だけの言葉）。

## 残っている判断　序章12ページは長いか

```
　巻頭　　 7ページ
　序章　　12ページ
　第1章　 28ページ
　　　　　47ページ　← 09番（最初の場面別項目）に着くまで
```

287ページの17%。中高生が「で、何すればいいの」と思う前に着けるか。

削るならここ、という順に並べておく。

```
　1　勝ち負けの節の「勝った理由は1つではありません」　　 約200字
　2　逃げ道の2つ目　　　　　　　　　　　　　　　　　　　約250字
　3　作業か勉強か　　　　　　　　　　　　　　　　　　　 約350字
　4　最後に、1つだけ　　　　　　　　　　　　　　　　　　約180字
```

1と2は削っても論が通る。3と4は削ると、著者が入れたかったものが消える。
著者の判断待ち。

## scripts/check.py を作った

同じ種類の事故が3回続いたので、機械で止めるようにした。

```
　1　稼働中のビルダーが、存在しない原稿を指していないか

```

5は機械では判定できないので、一覧だけ出して人が確かめる。
いまは9か所。全部、相手がいることを確認済み。
