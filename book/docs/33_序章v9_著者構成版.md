
## 入れた研究

本文には研究者名も年号も出さない。大学名と実験の中身だけ書く。

```
　コロラド大学　再読の実験
　　3グループ（1回／2回続けて／1週間あけて2回）× テスト時期2つ
　　直後は「2回続けて」が1位、2日後は逆転して「間隔をあけて」が1位
　　→　読み返しが効くと信じられている理由まで説明できる

　アメリカの大学生　ハイライトの実験（8000語、3条件）
　　1週間後のテストで、3グループに差がなかった

　歴史の教科書　下線の実験
　　事実問題は差なし。推論問題は、下線を引いた人のほうが低かった
　　→　英語長文や現代文では、やらないほうがまし

　大学生200人以上　普段の勉強法と成績の調査
　　いちばん多く使われているのは 再読／ノートの読み返し／マーカー
　　そのどれも点数と関係がなく、点が高いのは自分で解いて確認していた人
　　→　勉強時間の長さより、何をしていたかのほうが点を説明していた
```

コロラド大学の実験は、この章でいちばん働いている。
「再読は効かない」で終わらせず、「直後は本当に効く。だから信じてしまう。
でも数日で消える」まで言えるので、読者を責めずに否定できる。
そして「読むなら間隔をあける」という次の手まで渡せる。

マーカーの色分け（認知負荷）と「マーカーは2周目から」は序章に入れなかった。
あれは「どう直すか」の話なので、19番と28番で扱う。
