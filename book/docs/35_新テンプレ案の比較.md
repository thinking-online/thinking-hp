# 35　本文テンプレの新案（著者案）と、いまの型の比較

著者案

```
　Q　生徒が実際に本当に悩む言葉で投げかける
　↓
　頭のいい人が絶対にやらないことを、まず明示する
　↓
　具体的な説明・解説・イラスト
　↓
　じゃあどうすればいいのか（頭のいい人の勉強法・思考プロセス）
　↓
　最後にまとめ
```

見本　`manuscript/試作/新テンプレ3本.md`
PDF　`build/新テンプレ3本.pdf`（横）／`build/縦組み_新テンプレ3本.pdf`（縦）

採用はまだ。どう見えるかを確かめるための3本。

---

## 1　いまの型との対応

```
いまの8ステップ                新案の5ステップ
1　見出し（やらないこと）　　→　2　頭のいい人が絶対にやらないこと（見出しは残す）
2　二項対立 ×／○　　　　　 →　2　の中に置く
3　武器タグ　　　　　　　　→　そのまま右肩
4　こんなとき（場面）　　　→　1　Q に変わる
5　あなたのせいではない　　→　3　の中
6　何が起きているか　　　　→　3
7　やり方　　　　　　　　　→　4
8　まとめ　　　　　　　　　→　5
（頭のなか）　　　　　　　 →　4　の中に移す
```

ステップの数は減るが、中身はほぼ同じ場所に収まる。
捨てるものは、ない。置き場所が変わるだけ。

## 2　変わるところ

### 入口が、場面から「生徒の声」に変わる

いまの型は、三人称の場面から始まる。

　　「夜の9時。中学3年生。数学のワークを進めています。12問目で止まりました」

新案は、生徒の一人称から始まる。

　　Q「解説を読んだら分かるんです。でも、自分で解くとできません」

ここがいちばん大きい。読者が「自分だ」と気づくまでの距離が、1行になる。
指導の現場で実際に出る言葉なので、著者にしか書けない部分でもある。

ただし、場面描写そのものは捨てない。3（具体的な説明）の頭に移す。
あの具体（12月の3週間／配点4点／50個中30個）が、この本の強みなので。

### 「やらないこと」が、早く・はっきり出る

いまの型だと、やってはいけないことは見出しにあるだけで、
本文は場面→原因と進むので、宣言が弱い。

新案は、Qのすぐ後ろで言い切る。

　　==解説を読んで「なるほど」と思ったら、そのまま次の問題へ進む。==
　　これだけは、やりません。

タイトルの約束（絶対にやらない51のこと）と、本文の作りがそろう。

### 図の置き場所が決まる

3（具体的な説明）に、図が1点入る前提になる。
いまは図の置き場所が項目ごとにばらばらで、82点の仕様が決まらなかった。
新案だと「1項目1点、3の中」と決められる。

### 「頭のなか」が、答えの側に移る

いまは原因の説明のあとに置いていて、独立した読み物になっている。
新案では「じゃあどうすればいいのか」の最初に来るので、
手順の前振りとして働く。伸びない人の側は3で説明済みなので、短くできる。

## 3　値段（ページ数）

同じ3本を、両方の型で組んで測った。

```
　　　　　　　　いまの型　　　　　新案
30　解説を読んで　2,107字 6ページ　1,845字 6ページ
25　忘れてから　　1,710字 4ページ　1,753字 6ページ
40　机に座ってから 2,907字 7ページ　1,466字 5ページ
```

40が短いのは、見本で吸収ぶん（やる気を待つ／集中が切れた場所）を入れなかったから。
実際に組むなら、いまと同じ長さになる。

25を見るのがいちばん正確で、==同じ字数で2ページ増える==。
見出しが1項目あたり2つか3つ増えて、囲みも1つか2つ増えるため。

場面別43本に当てると、おおよそ

```
　　329ページ　→　390〜410ページ
```

四六判で390ページは、定価を上げるか、本文を削るかの話になる。
学研の目標は280ページだった。

## 4　どうするか（3案）

```
A　全面採用して、1本あたり300〜400字削る
　　　Qの導入と、3の場面描写が重なるので、そこを詰める。
　　　いまの型の「これをやると、何が残るか」は、5（まとめ）に吸収できる。
　　　→　340〜350ページに収まる。いちばん素直。

B　見出しを減らして採用する
　　　5つのうち、固定の見出しは「Q」と「まとめ」だけにして、
　　　2・3・4は見出しなしで続ける（段落の頭で示す）。
　　　→　ページ増はほぼ消える。ただし型の見え方は弱くなる。

C　Qだけ採用する
　　　入口だけを生徒の声に変えて、あとはいまの型のまま。
　　　→　ページ増ゼロ。いちばん安いが、「やらないことを明示する」が弱いまま。
```

Aが本筋だと思う。削る300字は、いまの本文にある重複なので、
削って悪くなる場所ではない。

## 5　決めてもらいたいこと

```
・A／B／C のどれか
・Qは全項目に付けるか、場面が強い項目は場面のままにするか
・固定見出しの文言
　　「頭のいい人が、絶対にやらないこと」
　　「なぜ、それだと伸びないのか」　※項目ごとに変える案もある
　　「じゃあ、どうすればいいのか」
　　「まとめ」
・基本の基本8本は、この型にしない（序章の続きとして読ませる）でいいか
```
