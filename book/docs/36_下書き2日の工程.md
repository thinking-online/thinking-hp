# 36　下書きを2日で書き上げる工程

11月9日（月）・10日（火）の2日で、下書きを通しまで持っていく。

ルールは1つ。==上から順にやる。終わるまで次に行かない。==

いまどこにいるかは、これで出る。

```
　　python3 scripts/step.py
```

自己申告のチェックではなく、ファイルの中身を見て判定する。
通らないステップがあると、その先は表示されない。

---

# 全体

```
　S1〜S6　　設計と材料　　著者が主役　　　9日の午前
　S7〜S16　 書く　　　　　こちらが主役　　9日の午後〜10日の午後
　S17〜S18　通す　　　　　　　　　　　　　10日の夜
```

S1からS6が終わるまで、1文字も書かない。
ここを飛ばすと、捨てる原稿が出る。それがいちばん高い。

---

# S1　50本の中身を確定する

やること　いまの51本を見て、入れるもの・外すもの・足すものを決める。

終わったと言える条件

```
　manuscript/企画書/現行案.md の「# 7 50項目」に、項目が50本
　50本すべてに ×「…」と ○「…」の2行がある
　50本すべてに力（選ぶ力／入れる力／…）が付いている
```

## 判断の材料

### いまの51本から外す候補

```
　43　覚えるときも、音楽をかけたままにする
　　　　独立してはいるが、効き幅がいちばん小さい。3ページ

　37　ケアレスミス、次は気をつける、で終える
　38　10個の間違いを、10問とも順に直す
　　　　この2本は「名前をつける → 名前でまとめる」で方法としては続き。
　　　　1本にすると中身は濃くなるが、目次から見出しが1つ消える

　18　授業中、当てられないように下を向く　　3ページ
　19　小テストを、点が出たら捨てる　　　　　3ページ
　　　　どちらも薄い。18は中身も弱い
```

### 入っていないが、入れる価値がある候補

```
　・塾に行ってるから、家では復習しない
　・親に「勉強しなさい」と言われてから始める　　　※保護者も読者
　・テスト2週間前から、やっと始める
　・音読を、声を出すだけで終える
　・丸つけを、翌日にまとめてやる
```

### 長さが偏っている本

```
　13ページ　48　他人と比べて、落ち込む　　　← 吸収を入れすぎた。要分割か圧縮
　 9ページ　02　やり方だけを、直そうとする
　 8ページ　15／24／26／47
　 3ページ　18／19／43
```

4〜5ページに27本が集中している。ここはS3で散らす。

# S2　テンプレを確定する

やること　docs/35 の A／B／C から1つ選ぶ。

```
　A　新テンプレを全面採用して、1本300〜400字削る　→　340〜350ページ
　B　固定見出しを「Q」と「まとめ」だけにする　　　→　ページ増ほぼなし
　C　Qだけ採用して、あとはいまの型のまま　　　　　→　ページ増ゼロ
```

あわせて決める　基本の基本8本に、この型を使うか。
（序章の続きとして読ませる流れなので、使わないほうがいいと思う）

終わったと言える条件

```
　manuscript/企画書/決定.md に
　　テンプレ　＝　A
　　基本の基本8本　＝　新テンプレを使わない
　の2行がある
```

# S3　長さを50本に割る

やること　50本それぞれに、目標ページ数を振る。

目安

```
　2ページ　12本　　言い切るだけで効くもの
　4ページ　29本　　標準
　6ページ　 9本　　章に1本。物語として読ませる
```

読み終わりの手ざわりは、ここで決まる。
いま全部が同じ長さなので、20本目から読者が次を予測できる。

終わったと言える条件

```
　現行案.md の50本すべての見出し行の末尾に ［2p］［4p］［6p］のどれかがある
```

# S4　固定見出しの文言を確定する

やること　新テンプレの見出しを決める。試作で使ったのはこれ。

```
　Q「…………」
　頭のいい人が、絶対にやらないこと
　なぜ、それだと伸びないのか　　　← 項目ごとに変える案もある
　じゃあ、どうすればいいのか
　まとめ
```

終わったと言える条件

```
　決定.md に 見出し1〜見出し5 の5行がある
```

# S5　Qを50本ぶん書く

やること　50本すべてに、生徒が実際に言う言葉を1行ずつ。

==ここは朝倉さんにしか書けない。== 面談で実際に出た言い回しそのままがいい。
きれいな日本語にしないこと。「〜なんですけど」「〜なんですよね」で止まっていい。

例

```
　30　解説を読んだら分かるんです。でも、自分で解くとできません
　25　覚えても、次の日には忘れてるんですけど
　40　やる気はあるんです。でも、座ってから1時間たってます
```

終わったと言える条件

```
　manuscript/企画書/Q50.md に「NN　Q文」が50行。空行・〔　〕なし
```

# S6　実話を10個えらぶ（各章1つ）

やること　章ごとに1つ、実在の生徒の話を出す。章末に置く。

docs/27 に21か所ぶんの「場所と質問」が用意してある。まず10個でいい。

1つにつき3行。

```
　いつ　　　　高3の11月
　誰　　　　　週6で部活をしていた男子
　何があった　単語帳を1ページ目から3回やり直して、模試で出なかった
```

名前は出さない。学年・時期・状況だけでいい。
これがないと、真ん中の250ページに著者が1人も出てこない本になる。

終わったと言える条件

```
　manuscript/企画書/実話10.md に、10件。各件3行以上。〔　〕なし
```


# 守れなかったときに起きること

```
　S1を飛ばして書く　　→　外す本の原稿を書くことになる。1本あたり2時間の損
　S2を飛ばして書く　　→　43本ぶんの組み直し。1日の損
　S3を飛ばして書く　　→　全部が同じ長さの本になる。読み終わりが「役に立った」で止まる
　S5を飛ばして書く　　→　Qをこちらが作文することになる。いちばん効く部分が偽物になる
　S6を飛ばして書く　　→　本文250ページに著者が出てこない本のまま出る
```
