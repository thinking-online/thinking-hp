# 37　S1「50本の中身を確定する」の進め方

決めることが大きいので、S1の中をさらに6つに割る。上から順に。

```
　S1-a　51本を2つの数字で採点する　　　20分　著者
　S1-b　外すものを決める　　　　　　　 10分　著者
　S1-c　足すものを決める　　　　　　　 15分　著者
　S1-d　50本に合わせる　　　　　　　　  5分　著者
　S1-e　章の配分を見る　　　　　　　　 10分　著者
　S1-f　ファイルに書く　　　　　　　　　5分　こちら
```

合計1時間。

---

# 考え方　「どれが大事か」を考えない

51本に順位をつけようとすると、止まる。全部それなりに大事に見えるから。

かわりに、==1本につき2つの数字だけ==を出す。

```
　頻度　　直近で見た生徒10人のうち、何人がこれをやっているか　　0〜10
　効き　　やめたら、何点動くか　　　　　　　　　　　　　　　　 0 / 5 / 10
```

どちらも、2000人を見てきた人にしか出せない数字。
考え込まない。1本15秒で出す。迷ったら低いほうを書く。

この2つで、置き場所が自動で決まる。

```
　　　　　　　　効き 10　　　　　　　効き 5　　　　　　　効き 0

　頻度 7〜10　　絶対入れる　　　　　 入れる（短く）　　　 外す候補
　　　　　　　　6ページで厚く　　　　2ページで言い切る

　頻度 4〜6　　 入れる　　　　　　　 入れる　　　　　　　 外す候補
　　　　　　　　4ページ標準　　　　　4ページ標準

　頻度 0〜3　　 入れる（物語に）　　　外す候補　　　　　　 外す
　　　　　　　　6ページ　　　　　　　
```

==この2つの数字で、S3（長さを50本に割る）も同時に終わる。==
だから、ここを丁寧にやると、あとが速い。

---

# 採点するときに外す考え

## 原稿の出来を、判断に入れない

よく書けている原稿ほど残したくなる。でも原稿は書き直せる。
いま判断するのは「この場面が本にいるか」であって「この原稿がいいか」ではない。

## 「抜けがあると困る」を、判断に入れない

辞書を作っているのではない。抜けより、重なりのほうが害が大きい。
読者は、同じことを2回言われると、その本を信用しなくなる。

## 章の数合わせを、判断に入れない

3本しかない章ができても、いまは気にしない。章はあとで寄せられる（S1-e）。
章を埋めるために弱い項目を残すのが、いちばんやってはいけない。

## 目次映えは、同点のときだけ使う

見出しとして読みたくなるかは、売れ方に効く。だから捨てない。
ただし、頻度と効きで決着がついているところに持ち込まない。==同点のときのタイブレークだけ。==

# S1-a　採点する

```
　manuscript/企画書/S1_採点.md
```

効きの数字は、こちらで下書きを入れてある。違うと思ったら直す。
==頻度は、空にしてある。ここは朝倉さんにしか出せない。==

書き方

```
　01　7　5　過程に、意味を持たせる
　　　↑  ↑
　　頻度 効き
```

チャットで「01 7 5」みたいに並べて送ってくれれば、こちらで入れる。
番号順じゃなくていい。思い出した順でいい。

採点したら

```
　python3 scripts/s1.py
```

2×2の表と、外す候補、章の偏りが出る。

---

# S1-b　外すものを決める

s1.py が出した「外す候補」を上から見る。

外すと決めたら、その行の頭に `×` を付ける。

```
　× 43　2　0　覚えるときも、音楽をかけたままにする
```

1本外すごとに、こう自問する。

```
　この場面を外したら、読者はどこで困るか。
　その困りごとを、残した50本のどれかが拾っているか。
```

拾っていれば外していい。拾っていなければ、残す。

---

# S1-c　足すものを決める

逆向きに考える。

```
　この1年の面談で、いちばんよく出た相談で、本に無いものは何か。
```

思いつくまま3つ書く。それが本当の候補。

こちらが持っている候補も置いておく。頻度と効きを付ければ、同じ土俵で比べられる。

```
　・塾に行ってるから、家では復習しない
　・親に「勉強しなさい」と言われてから始める　　※保護者も読者
　・テスト2週間前から、やっと始める
　・音読を、声を出すだけで終える
　・丸つけを、翌日にまとめてやる
　・提出物を、答えを写して出す
　・ワークを、2周目から答えを覚えて解く
```

足すものは、`S1_採点.md` の末尾に `＋` を付けて書く。

```
　＋ 　8　10　塾に行ってるから、家では復習しない
```

---

# S1-d　50本に合わせる

```
　51　−　外した数　＋　足した数　＝　50
```

合わなければ、外す候補の次点か、足す候補の次点で調整する。

ここで無理に50にしない。49でも52でも、s1.py が差分を出すので、
もう一度 S1-b か S1-c に戻る。==数合わせで弱い項目を入れない。==

---

# S1-e　章の配分を見る

s1.py が章ごとの本数を出す。

```
　2本以下の章　　→　隣の章に寄せる
　9本以上の章　　→　割るか、1本を別の章へ
```

いまは 計画3本・終章3本 が薄い。
計画は集中に寄せられる。終章は本番のまま3本でもいい（終章は短くていい）。

章を動かしたら、採点シートの章の行を書き換える。

# S1-f　ファイルに書く

```
　python3 scripts/s1.py --write
```

これで、

```
　現行案.md の「# 7 51項目」が「# 7 50項目」になる
　番号が振り直される
　各項目に ［2p］［4p］［6p］ が付く　　← S3 がここで終わる
　manuscript/企画書/番号対応表_S1.json ができる
　本文の相互参照（N番）で、直す必要があるものが一覧で出る
```

相互参照の直しは、こちらでやる。

そのあと

```
　python3 scripts/step.py
```

S1 と S3 に ✓ が付いて、S2 が出れば終わり。
