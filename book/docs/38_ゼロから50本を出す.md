# 38　ゼロから50本を出す

いまの51本は、75本から重なりを畳んだ結果。読者から組み直したものではない。
だから、ゼロから出し直す。docs/37（採点して削る）はこの方法に置き換える。

---

# ゼロから出すときの、唯一の落とし穴

20本はすぐ出る。そこから手が止まる。
止まったあと、人は「カテゴリを埋めるため」に項目を作りはじめる。
==それが、いちばん弱い項目になる。==

だから、やり方を1つだけ変える。

```
　「やってはいけないこと」から考えない。
　「生徒が実際に言う言葉」から考える。
```

やってはいけないことは、抽象。頭から絞り出すもの。
生徒の言葉は、具体。思い出すもの。==思い出すほうが、速くて、多く出て、嘘がない。==

そして、ここで出した言葉が、そのまま本文の1行目（Q）になる。
==S1とS5が、同時に終わる。==

---

# 進め方

```
　S1-1　生徒の言葉を、思い出せるだけ書く　　　　　40分　著者
　S1-2　それぞれ「で、何をやってるのか」を書く　　30分　著者
　S1-3　重なりを潰す　　　　　　　　　　　　　　 20分　こちら＋著者
　S1-4　いまの51本と突き合わせる　　　　　　　　 10分　こちら
　S1-5　50本に決める　　　　　　　　　　　　　　 20分　著者
　S1-6　章と力を振る　　　　　　　　　　　　　　 15分　こちら＋著者
```

2時間。削る方式より1時間長い。その1時間で、本の中身が変わる。

---

# S1-1　生徒の言葉を、思い出せるだけ書く

```
　manuscript/企画書/S1_ゼロから.md
```

## 50を目指さない。70〜80を目指す

50を目指すと、48本目から質が落ちる。
70出してから20削ると、残った50が全部強くなる。==出し切ってから削る。==

## カテゴリで考えない。時間で思い出す

「暗記の項目を出そう」と考えると出てこない。
生徒の1日・1週間・1年をなぞると、勝手に出てくる。

シートは、その順に並べてある。

```
　1　授業中に、生徒が言うこと
　2　家で勉強を始めるときに言うこと
　3　覚えるときに言うこと
　4　問題を解くときに言うこと
　5　間違えたとき・直すときに言うこと
　6　テスト前に言うこと
　7　テストが返ってきたときに言うこと
　8　本番の前後に言うこと
　9　続かないときに言うこと
　10　保護者から言われること
```

## 書くときのルール

```
　・実際の言い回しのまま。きれいにしない
　・「〜なんですけど」「〜なんですよね」で止まっていい
　・同じようなものが3つ出てもいい。あとで潰す
　・「それ本に書けるかな」と考えない。思い出したら書く
　・1つ10秒。止まったら次のカテゴリに飛ぶ
```

止まったら、こう自分に聞く。

```
　先週の面談で、誰が、何を言っていたか
　いちばん多く答えている質問は何か
　答えるたびに「それ、よく聞かれます」と言っている質問は何か
　LINEで同じ返事を何度も打っている質問は何か
```

# S1-2　「で、何をやってるのか」を書く

生徒の言葉の下に、矢印で、実際にやっている行動を書く。

```
　「覚えても、次の日には忘れてるんですけど」
　　→　忘れきってから、1ページ目に戻る
```

==ここが、項目の見出しになる。==

書くときのルール

```
　・行動で書く。能力で書かない
　　　×　記憶力がない
　　　○　忘れきってから、1ページ目に戻る
　・「〜しない」より「〜する」で書く
　　　×　復習しない
　　○　授業でわかったから、その単元を飛ばす
```

矢印が書けないものは、本にならない。そこで消していい。
==生徒の言葉はあるのに、行動が書けない。それは悩みであって、やってはいけないことではない。==

# S1-3　重なりを潰す

```
　python3 scripts/s1zero.py
```

似ているものを並べて出す。見て、まとめるか分けるかを決める。

判断は1つ。

```
　やることが同じなら、1本。
　やることが違うなら、2本。
```

場面が違っても、やることが同じなら1本にする。
（例　「授業でわかった」と「2週間前に大丈夫だと思った」は、どちらも閉じて出すだけ）

# S1-4　いまの51本と突き合わせる

s1zero.py が自動で出す。

```
　新しいリストが、いまの51本のどれに当たるか
　　当たる　　→　原稿がある。書き直すだけ
　　当たらない →　ゼロから書く。1本あたり2時間

　いまの51本で、新しいリストに出てこなかったもの
　　→　忘れているのか、本当に要らないのか。1本ずつ見る
```

==ここで「ゼロから書く本数」が出る。== これが2日の下書きに収まるかの分かれ目。

```
　5本まで　　そのまま進む
　6〜12本　　進むが、その章は2日目に回す
　13本以上　 多すぎる。いまの51本に寄せるか、下書きの締切を1日延ばす
```

出てこなかった項目は、消す前に1回だけこう聞く。

```
　これを言う生徒が、この1年で1人もいなかったか。
　いたのに出てこなかっただけなら、戻す。
　本当に1人もいなかったなら、本にはいらない。
```

# S1-5　50本に決める

70本が残っているはず。20本削る。

削る順番

```
　1　矢印（やっていること）が書けなかったもの
　2　他の項目をやれば自動で直るもの
　3　年に数回しか言われないもの
　4　言われるけれど、やめても点が動かないもの
```

4まで来ても余ったら、残りは全部残す価値がある。
そのときは50にこだわらず、52でも55でもいい。==あとで長さで調整できる。==

---

# S1-6　章と力を振る

s1zero.py が、50本を章ごと・力ごとに数えて出す。

```
　2本以下の章　　→　隣に寄せる
　9本以上の章　　→　割る
　1本しかない力　→　その力の見せ方を見直す（第1章の8本に関わる）
```

ここまで終わったら

```
　python3 scripts/s1zero.py --write
```

現行案.md が新しい50本になる。番号も振り直す。
そのあと `python3 scripts/step.py` で、S1 に ✓ が付く。
