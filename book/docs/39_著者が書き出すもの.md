# 39　著者が書き出すもの　6つだけ

下書き2日で、朝倉さんが実際に手を動かして書き出すのは、これだけ。
あとは全部こちら。

```
　①　生徒の言葉　　　　　　　　70本　　40分
　②　その子が実際にやってること 70本　　30分
　③　残すものを選ぶ　　　　　　50本に　20分
　④　テンプレを選ぶ　　　　　　 1行　　 5分
　⑤　見出しの文言　　　　　　　 5行　　10分
　⑥　実話　　　　　　　　　　　10本　　40分

　　　　　　　　　　　　　　　　合計　2時間25分
```

①から順に。①が終わるまで②を考えない。

---

# ①　生徒の言葉を70本

書き出すもの　生徒が面談・DM・LINEで実際に言う言葉。それだけ。

```
「覚えても、次の日には忘れてるんですけど」
「解説読んだら分かるんです。でも自分で解くとできません」
「やる気はあるんです。でも座ってから1時間たってます」
「ノートは取ってるんですけど、見返しても分かりません」
```

==かぎかっこの中だけ。== 番号もカテゴリも要らない。順番もばらばらでいい。

## なぜ70か

50狙いだと、48本目から質が落ちる。70出してから20削ると、残った50が全部強い。

## ルール

```
　・実際の言い回しのまま。きれいにしない
　・「〜なんですけど」「〜なんですよね」で止めていい
　・同じようなのが3つ出てもいい。あとで機械が潰す
　・1つ10秒。止まったら次へ飛ぶ
　・矢印（何をやってるか）は、まだ書かない
```

## 守ること

==いまの51本のリストを開かない。==
開いた瞬間、「思い出す」が「選ぶ」に変わる。同じ51本が出てきて、今日やる意味がなくなる。
突き合わせは、あとで機械がやる。

## 出てこなくなったら

```
　直近3回の面談で、生徒が最初に言った言葉は何か
　答えるたびに「それ、よく聞かれます」と言ってる質問は何か
　LINEで、同じ返事を何度も打ってる質問は何か
　インスタのDMで、いちばん多く来る質問は何か
　保護者面談で、毎回出る言葉は何か
```

それでも止まったら、生徒の時間をなぞる。

```
　授業中　→　家で始めるとき　→　覚えるとき　→　解くとき　→　間違えたとき
　→　テスト前　→　返ってきたとき　→　本番　→　続かないとき　→　親から
```

## これがそのまま本文の1行目になる

新テンプレのQ。==だから、この作業でS5（Qを50本）も終わる。==

# ②　その子が実際にやってること

①の70本に、1行ずつ足す。

```
「覚えても、次の日には忘れてるんですけど」
　→　忘れきってから、1ページ目に戻る
```

==矢印の右が、項目の見出しになる。==

## 書き方

行動で書く。能力で書かない。

```
　×　記憶力がない
　○　忘れきってから、1ページ目に戻る

　×　復習しない
　○　授業でわかったから、その単元を飛ばす
```

## 矢印が書けないもの

消していい。それは悩みであって、やってはいけないことではない。

# ③　残すものを選ぶ

①②が終わったら、こちらで重なりを潰して、いまの51本と突き合わせる。
残り何本か、ゼロから書くのが何本かを出す。

そこで朝倉さんがやるのは、==消すものに × を付けるだけ。==

削る順番

```
　1　矢印が書けなかったもの
　2　他の項目をやれば、自動で直るもの
　3　年に数回しか言われないもの
　4　言われるけれど、やめても点が動かないもの
```

4まで来ても余ったら、全部残す価値がある。
そのときは50にこだわらない。52でも55でもいい。長さで調整できる。

# ④　テンプレを選ぶ

1行だけ。A／B／C のどれか。

```
　A　新テンプレを全面採用。1本300〜400字削る　　→　340〜350ページ
　B　固定見出しを「Q」と「まとめ」だけにする　　→　ページ増ほぼなし
　C　Qだけ採用。あとはいまの型のまま　　　　　　→　ページ増ゼロ
```

こちらの推しはA。削る300字は、いまの本文にある重複なので、削って悪くなる場所ではない。

あわせて1行　基本の基本8本に、この型を使うか。
（序章の続きとして読ませる流れなので、使わないほうがいいと思う）

# ⑥　実話10本

章ごとに1つ、実在の生徒の話。1本3行。10章で30行。

```
　いつ　　　　高3の11月
　誰　　　　　週6で部活をしてた男子
　何があった　単語帳を1ページ目から3回やり直して、模試で1問も出なかった
```

名前は出さない。学年・時期・状況だけでいい。

==これが、本文250ページに著者が1人も出てこない問題を直す、唯一の材料。==
原理が正しくても、誰が言っているのかわからない本になる。ここだけは代われない。

各章で何を思い出すかは `manuscript/企画書/実話10.md` に問いを書いてある。
