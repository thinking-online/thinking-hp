# 1　いちばん大きく変えたところ

## 第7章に「終わりの基準」を立てた

質問101問の中核が「どこまでやったら次に行っていいか」だった。
いまの本には1本もなかった。6ページの★厚く書くで入れた。

```
33　「できた」の基準を、決めずに進む　［6p］
　　×「なんとなくできたから、次に行っていいかな」
　　○「次に行く条件を、始める前に1行で決める」
　　Q「一回全問正解できたからチェックをつけていいのか不安です」
```

## 第9章を「不安とモチベ」にして、不安を正面から扱う

質問173問で最大の領域。うち「不安・焦り・自信」が46問。
いまの本は48番（他人と比べて落ち込む）だけだった。

```
47　不安なまま、手を動かさずに考え続ける　［6p］　〔新〕
　　Q「やり方が合ってるのかも不安になります。やってもやっても不安で」
```

## 睡眠の向きを変えた

旧44「睡眠を削って、勉強時間を増やす」は、質問32問の実態と逆だった。
削る話ではなく、起きられない・眠いの話。2本に分けた。

```
41　休む時刻を決めずに、終わるまでやる　［4p］
42　起きられないのを、意志の問題だと思う　［2p］　〔新〕
```

## 第4章を「授業」から「授業・学校」に広げた

学校との両立が67問なのに、本は1本だった。課題・内職・補習・小テストを入れた。

```
21　学校から出てくるものを、全部同じ重さで受ける　［4p］　〔新〕
22　テスト勉強を、範囲が出てから始める　［6p］　〔新〕
```

22は、著者の追加分「テスト勉強って、どのくらい前から始めるのがいいですか」から。
