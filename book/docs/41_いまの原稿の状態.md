## 選べるのは3つ

```
A　このまま337ページで出す
　　　四六判337ページは、この価格帯で普通。定価は1,760〜1,980円になる
　　　中身は50本すべてに数字・判断・動作・理由がそろっている状態

B　組み方を詰めて、300ページ前後にする
　　　見出しを減らす、囲みを減らす、段落をもっとつなぐ
　　　いまは1ページあたり約360字しか入っていない（紙の容量は720字）
　　　読みやすさは落ちる

C　本文を25,000字削って、280ページにする
　　　本文の4分の1。50本すべてから均等に削ることになる
　　　いま4つそろっているものが、また薄くなる
```

==こちらの推しはA。== 中身を削ってページを合わせるのは、順番が逆だと思う。
杉浦さんに、337ページでの定価と部数を一度聞いてもらうのがいいのでは。

Bは、やるとしても組版が決まってからのほうが正確。
