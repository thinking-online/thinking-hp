# 2　文字数は気にしなくていいのか

結論から言うと、==文字数は気にしなくていい。気にするのはページ数。==

理由は1つで、文字数を見る人が誰もいないからです。
杉浦さんも、印刷所も、書店も、見るのはページ数のほうです。

```
　×　文字数が多い／少ない
　○　ページ数が何ページになるか
```

ページ数が決まると、こう連鎖します。

```
　ページ数　→　紙代と印刷代　→　原価　→　定価　→　刷る部数
```

## ただ、ここが問題になっている

四六判1ページに入る紙の容量は 45字×16行 ＝ 720字。
でもいまの原稿は、1ページ約360字しか入っていません。半分です。

見出しが多い、×／○の囲みがある、段落をこまかく切っている。
読みやすさのためにそうしているので、それ自体は悪いことではない。

その結果がこれです。

```
　117,254字　÷　約360字／ページ　＝　約337ページ
　　　　　　　　　　　　　　　　　　（学研の目標は280ページ）
```

57ページ出ている。
だから「文字数が多い」のではなく、==「1ページに入れている字が少ない」== という話。

選べるのは3つで、docs/41 に書いたとおりです。

```
A　このまま337ページで出す　　　　　　　←　こちらの推し
B　組み方を詰めて300ページ前後にする
C　本文を25,000字削って280ページにする
```

Aを推す理由は、Cだと50本すべてから均等に削ることになり、
いま数字・判断・動作・理由の4つがそろっている状態が、また薄くなるからです。
中身を削ってページを合わせるのは、順番が逆だと思う。

==これは12月上旬までに決める必要があります。== 定価と部数に直結するので。

# 3　12月からの動き

ここから先は、商業出版の一般的な流れです。
==学研の実際の進行は杉浦さんに確認が必要。== 出版社ごとにけっこう違います。

## 2月末発売から逆算した形

```
　11月30日　　　　原稿提出　　　　　　　　　　　　著者
　　↓
　12月上旬　　　　編集者が通読、指摘が戻ってくる　杉浦さん
　　　　　　　　　構成・削り・足しの指示。1〜2週間
　　↓
　12月中旬　　　　著者直し　　　　　　　　　　　　著者
　　　　　　　　　2週間は見ておく。最後の大きな直しはここ
　　↓
　12月下旬　　　　図版82点の仕様確定・発注　　　　編集部＋著者
　　↓
　12月下旬〜1月上旬　入稿（DTPで組む）→ 初校ゲラ
　　↓
　1月上旬〜中旬　　初校校正　　　　　　　　　　　著者＋校閲
　　↓
　1月中旬　　　　　再校ゲラ → 再校校正
　　↓
　1月下旬　　　　　校了 → 印刷
　　↓
　2月中旬　　　　　見本が出る
　　↓
　2月下旬　　　　　配本・発売
```

## 本文より先に決まるもの

ここが見落としやすいところ。
==タイトルとカバーは、本文が終わる前に決まります。==
1月に書店営業が始まるので、それに間に合わせないといけない。

```
　タイトル・サブタイトル　　12月中に確定
　カバーデザイン・帯　　　　12月〜1月上旬
　部数と定価　　　　　　　　1月上旬に確定（ページ数が決まらないと出せない）
　買取・販促費の話　　　　　部数確定の前。印税率に影響する
　予約キャンペーン　　　　　発売3〜4週間前＝1月下旬から
```

```
　2  実話10本（S6）　　　　　　　　　　　　 入稿前が最後。入稿後は入れられない
　3  プロフィール文、著者写真
　4  帯の推薦コメントを誰かに頼むなら、依頼　12月中

```

5は、学研から言われる前に自分で設計しておいたほうがいい。
部数の判断材料になるので、==1月上旬の部数確定より前に出すと効きます。==
