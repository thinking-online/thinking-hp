# 2　文字数は気にしなくていいのか

結論から言うと、==文字数は気にしなくていい。気にするのはページ数。==

理由は1つで、文字数を見る人が誰もいないからです。
杉浦さんも、印刷所も、書店も、見るのはページ数のほうです。

```
　×　文字数が多い／少ない
　○　ページ数が何ページになるか
```

ページ数が決まると、こう連鎖します。

```
　ページ数　→　紙代と印刷代　→　原価　→　定価　→　刷る部数
```

## ただ、ここが問題になっている

四六判1ページに入る紙の容量は 45字×16行 ＝ 720字。
でもいまの原稿は、1ページ約360字しか入っていません。半分です。

見出しが多い、×／○の囲みがある、段落をこまかく切っている。
読みやすさのためにそうしているので、それ自体は悪いことではない。

その結果がこれです。

```
　117,254字　÷　約360字／ページ　＝　約337ページ
　　　　　　　　　　　　　　　　　　（学研の目標は280ページ）
```

57ページ出ている。
だから「文字数が多い」のではなく、==「1ページに入れている字が少ない」== という話。

選べるのは3つで、docs/41 に書いたとおりです。

```
A　このまま337ページで出す　　　　　　　←　こちらの推し
B　組み方を詰めて300ページ前後にする
C　本文を25,000字削って280ページにする
```

Aを推す理由は、Cだと50本すべてから均等に削ることになり、
いま数字・判断・動作・理由の4つがそろっている状態が、また薄くなるからです。
中身を削ってページを合わせるのは、順番が逆だと思う。

==これは12月上旬までに決める必要があります。== 定価と部数に直結するので。

# 5　追記　努力の前倒しの話（11月9日）

著者から、キングコング西野さんの「20代でついた差は一生埋まらない／努力は前倒し」
の話が来た。本に入れるかどうかの判断を書いておく。

## 結論

==入れる必要はない。すでに序章に入っている。==

序章の「なぜ、いまやるのか」のところに、こう書いてある。

```
　いま中学生や高校生なら、2つのものを持っています。
　1つは、時間です。まとまった時間が取れるのは、いまです。あとから手に入りません。
　もう1つは、失敗していい回数です。
　いまの小テストで0点を取っても、人生は何も変わりません。
　だから、新しいやり方を試せます。
　試せる回数が多い人が、いちばん速く正しいやり方にたどり着きます。
```

これが「今日がいちばん若い」の、この本の言い方。
しかも ==「若いうちに量をやれ」ではなく「若いうちは試せる回数が多い」== になっている。
量ではなく、やり方の本なので、こちらのほうが幹に合っている。

著者が書いていた4行のうち、

```
　努力は報われる → 努力しなかった自分と比べれば
```

これも46番に入っている。見出しは「比べる相手は、先週の自分」。

## 西野版をそのまま入れない理由

```
　1  「差は一生埋まらない」は、この本の読者に終わりを宣告する
　　　読む子は「もう出遅れた」と思って開く。本の原則（責めない）に正面から反する

　2  著者自身が、差を埋めた側の実例
　　　現役で10校全落ち、浪人1年で偏差値70。本文で「埋まらない」と書くと
　　　おわりにと矛盾する

　3  「総量100を前倒し」は量の話
　　　50項目すべて「量ではなくやり方」で通している。ここだけ量の話になる
```

## 使い道

SNS向き。==Instagram 9万・LINE 4万で、1月下旬の予約期間に出す素材。==
そちらは読者が中高生に限らないので、20代の話がそのまま効く。
本に入れるより、告知で使ったほうが届く。

## おわりにが2つある

```
　manuscript/おわりに.md　　　　2,099字　長い版（7節。恩師、女の子の手紙、ノート1冊）
　manuscript/本文/巻末.md 内　　 約700字　短い版（14時間、責めない、3つの問い）
```

どちらを本に載せるかが決まっていない。

短い版は、3つの問いで締める形で、巻末の流れにつながっている。

==長い版を本体にして、短い版の「3つの問い」だけを最後に足すのがいいと思う。==
