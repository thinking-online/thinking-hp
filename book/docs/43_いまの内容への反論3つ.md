# 反論1　「50個」という形そのものが、この本の主張に反している

## 反論

この本がいちばん強く言っているのは、これ。

```
　03　全部やろうとする　　→　選ぶ力
```

選ぶ力は8本あって、6つの力のうち最多タイの扱いになっている。
巻末には、こう書いてある。

```
　やらないことを50個覚えるのは、無理です。
```

おわりににも、こう書いてある。

```
　この本を、明日から50個全部やろうとしないでください。
```

==ところが、読者が手に取るのは337ページ・50項目の本である。==

しかも、選ぶための道具が全部うしろにある。

```
　「50を、1枚に」　　　　巻末
　「悩み別の引き方」　　　巻末
　「再現性テスト」　　　　巻末
　3つの問い（まとめ）　　 おわりに
```

300ページ目以降。
==つまり、この本の教えに忠実な読者は、選ぶための道具に一生たどり着かない。==
全部を前に置いて、選ぶを後ろに置いている。本がやるなと言っている順番そのもの。

## こう反論できる

3つの問いは、巻末にしかないわけではない。
序章の「6つあります」の表で合言葉として出していて、
42本すべてに「この場面を見つけた問い」として入っている。
だから問いは全編に通っている。

それでも、==「どこから読むか」を決める道具が前にないのは事実。==

## 11月中に打てる手

```
　巻頭と序章のあいだに「この本の引き方」を2ページ入れる
　　・悩み別の引き方（巻末のものをそのまま前に出す）
　　・3つの問いを先に1ページ
　・巻末のほうは1枚コピー用として残す（用途が違うので重複にならない）
```

2ページ増えるだけ。中身を1行も書き足さずに、構造の矛盾が消える。
==50本すべての手書き作業より、こちらのほうが効く。==

# 反論2　×／○を50回くり返す構造は、「責めない」と両立していない

## 反論

本の設計原則はこれ。

```
　伸びない人を責めない。7つの型は全部、頑張っている人の型
```

ところが形式は、==読者自身のセリフを50回連続で×の位置に置く== というもの。

```
　×「なんとなくできたから、次に行っていいかな」
　×「あの子はもう8割。自分は何をやってるんだろう」
　×「解説読んで納得したし、次いこう」
```

しかもこのセリフは、質問6,360件から取った生徒の実際の言葉。
==正確であるぶん、刺さり方も強い。==
「自分のことが書いてある」は、ほめ言葉にも、刃にもなる。

46番では、こうも書いている。

```
　比べて落ち込んだ1時間に、1問も解いていません。
```

直後に「責めているのではありません」と断ってはいる。
だが、断らなければいけない文を書いているということ自体が、答えになっている。

そして、ほどく言葉がまた全部うしろ。

```
　「サボっているのではありません。教わっていないだけです」　　巻末 保護者ページ
　「半分以上が当てはまったと思います。それは、あなたが
　　ちゃんと勉強してきたということです」　　　　　　　　　　 巻末 おわりに
```

==自分は頭が悪いと思って開いた子が、50回自分の失敗を正確に名指しされたあと、
300ページ目でようやく「あなたのせいじゃない」と言われる。==

タイトルも同じ向きに働く。
巻頭は2,650字かけて「頭がいい＝生まれつき」という見方を壊している。
その本の表紙が『頭のいい人が絶対にやらないこと』。
==壊したはずの枠組みで売っている。==

## こう反論できる

タイトルは確定事項で、売るための約束（`docs/00`）。
中身で裏切らなければ、表紙で枠組みを使うのは問題ない。むしろ入口になる。
×／○も、二項対立は著者が維持すると決めたもの。
そして各項目の本文は、ほぼ必ず「これは責めているのではない」の節を持っている。

それでも、==ほどく言葉の置き場所が後ろすぎるのは事実。==

## 11月中に打てる手

```
　1  「教わっていないだけです」を巻頭に上げる
　　　いま巻末の保護者ページにある。本文最強の一文がいちばん奥にある
　　　巻頭の最後、11個の数字のあとに3行で入る

　2  新テンプレの「頭のいい人が、絶対にやらないこと」50本を書くとき
　　　2つ目の×にしない。「ここは、やってる人ほどハマる」の形で書く
　　　＝ 残っている最後の中身の仕事を、この反論への答えとして使う
```

2が効く。==50本ぶんの手書きの方針が、これで決まる。==

# 反論3　中学生に対して、約束したことを果たしていない

## 反論

読者は「やっているのに伸びない中高生」と、その親（`CLAUDE.md`）。
では本文の語彙を数えてみる。

```
　模試　　　　37回
　単語帳　　　23回
　過去問　　　18回
　偏差値　　　 5回
　志望校　　　 4回

　内申　　　　 0回　←
　高校受験　　 0回　←
```

==内申が、1回も出てこない。==

中1・中2にとって、高校受験でいちばん効く一手は内申点である。
提出物、授業態度、小テスト、課題の出し方。
そして本書は、そのすべてに触れる項目を持っている。

```
　20　小テストを、点が出たら捨てる
　21　学校から出てくるものを、全部同じ重さで受ける
　22　テスト勉強を、範囲が出てから始める
```

21は「量を足し算するな、1・2・3に分けろ」という話。
==いちばん大事な分け方の軸（内申に効くかどうか）を、名指ししていない。==

逆に、模試37回・過去問18回・偏差値・志望校という語彙は受験学年のもの。
中1は模試をほぼ受けない。
==本の場面は高校生に寄っていて、表紙は中高生と言っている。==

そして学研がいちばん強いのは中学生の棚である。
杉浦さんが営業会議に持っていったとき、
「これは中学生に何を売る本なのか」が最初の質問になる。

## こう反論できる

勉強のやり方そのものは学年に依存しない。
閉じて出す、間違いを翌日に出す、基準を先に決める——中1でも高3でも同じ。
この本は「やり方」の本なので、学年別の制度（内申の付き方は自治体で違う）に
踏み込まないのは、意図した設計でもある。

それでも、==1回も出てこないのは「踏み込まない」ではなく「落ちている」。==

## 11月中に打てる手

```
　A  21番に、分け方の軸として内申を入れる（2ページ）
　　　「1・2・3に分ける」の1の条件に、内申に効くかどうかを足すだけ
　　　制度の説明はしない。判断軸として名前を出すだけでいい

　B  20番（小テスト）と22番（テスト勉強）に、中学生の場面を1つずつ足す
```

Aだけで足りる。==制度の解説をしなくても、名前が1回出れば中学生は自分の本だと思える。==

# 補足　337ページという判断にも、鋭い反論がある

さっき「Aのまま337ページで出す」を推した。これへの反論。

```
　337ページ　→　定価1,760〜1,980円
```

中高生は1,980円の本を自分で買わない。買うのは保護者。
一方で学研のこの棚の競合は、だいたい1,200〜1,500円。

==つまりAは、ページ数の話ではなく「誰が買う本か」を変える判断である。==
1,980円にするなら、表紙が語りかける相手を保護者寄りに動かす必要が出てくる。
それは反論3とつながっている。

```
　337ページ・1,980円　→　保護者が買う　→　表紙は保護者に向ける
　　　　　　　　　　　　　　　　　　　　　→　でも中身は中高生向け
　280ページ・1,500円　→　中高生が自分で買える　→　でも25,000字削る
```

ここは、12月上旬に杉浦さんに部数と定価を出してもらう前に、
==「誰の財布で買う本か」を先に聞いたほうがいい。==
それが決まると、Aかどうかは自動で決まる。
