# 44　「答えを先に見るか」問題の決着（2026年11月9日）

著者から質問。
勉強法には、すぐ答えを見ろという説と、自分で考えてから見ろという説がある。
どっちが正しいのか、何を正解にすればいいのか。

---

# 1　2つの説の出どころ

```
　すぐ見る側
　　　知識問題は考えても出ない
　　　オーストラリア（ニューサウスウェールズ大）の認知負荷の研究
　　　自力で解く試行錯誤に頭を使うと、理解に回す余力がなくなる
　　　図形の問題で、見本を先に見た群のほうが成績が高かった

　考えてから見る側
　　　ロンドン大学ユニバーシティ・カレッジの実験
　　　知らない言葉を、いきなり正解で学ぶ群と、
　　　先に誤答を作ってから正解を見る群に分けた
　　　誤答を作った群のほうが、あとのテストで成績が高かった
```

---

# 2　結論　対立していない。測っているものが違う

## 違い1　かけた時間

```
　誤答を作る実験　　　考えた時間は　数秒
　見本を先に見る実験　考えた時間は　数十分
```

==2つとも「長く粘るな」と言っている。==
片方が「でも0秒はもったいない」、もう片方が「30分はやりすぎ」と言っているだけ。

だから答えは「10秒」。本書31番が最初から書いていた数字。

## 違い2　材料が、知識か手順か

```
　知識・対応づけ（英単語、用語、化学式）
　　　考えても出ない。でも10秒の「取りに行く」は効く
　　　出てこなかったあとに見た答えは、残りやすい

　手順（数学の解法、物理、化学の計算）
　　　見たことのない型は、ゼロから発明できない
　　　先に解答を見て、閉じて再現する
```

## 違い3　いちばん見落とされるところ　熟達度

見本を先に見たほうが強かったのは、==その単元を初めてやる人==のとき。
同じ研究の流れで、続きがわかっている。
ある程度できる人では逆転し、==自力で解いたほうが伸びる。==

```
　1周目　見たことのない型　→　先に解答を見て、閉じて再現する
　3周目　知っている型　　　→　先に自力で解く。10分やる
```

同じ問題集を、同じ人が、逆のやり方で回す。
「答えは先に見るべきか」に1つの答えがないのは、これが理由。

---

# 3　2つの実験が、1つだけ同じことを言っている

```
　誤答を作る実験　　→　外した直後に、必ず正解を見せている
　見本を見る実験　　→　見本のあとに、必ず自分で解かせている
```

==争点は「見る前に考えるか」ではない。==
どちらも「見たあと、閉じて出したか」で差がついている。

```
　×　考える時間を長くする
　×　考える時間を0にする
　○　見たあとに、自分で出す回数を増やす
```

本書の背骨（閉じて出す）が、両方の研究から出てくる。

---

# 4　本文に入れた

31番「考える時間を、決めずに始める」に4節追加した。

```
　2つの実験が、逆のことを言っているように見えます
　違いは、かけた時間です
　もう1つ、見落としやすい違いがあります　　←　1周目と3周目で逆になる
　2つの実験が、1つだけ同じことを言っています
```

1,112字。31番は研究の密度が本書で最高になった（計測値12）。
==ページ数は増えていない（308ページのまま）。==
目標は6p→8pに更新した。

巻末の参考文献にも2件足した。

```
　誤答を作ってから学ぶ　　　　　　　　31番の根拠
　例題を先に見せる効果と、その逆転　　31番・30番の根拠
```

---

# 5　注意　著者の資料にある数字は、本には入れないほうがいい

共有された資料に、こうあった。

```
　「スウェラー（1988）」
　「例題を示されたグループの正答率が約80%、自力で解いたグループは60〜65%」
```

2つ問題がある。

```
　1  研究者名と年号は、本文に出さない決め方にしてある（CLAUDE.md）
　　　巻末の参考文献も、実験の中身だけ書く形で統一している

　2  80% / 60〜65% という数字の出どころが確認できていない
　　　学研には校閲が入る。確認できない数字は、まず指摘される
　　　確定できなければ、数字を書かずに向きだけ書くのが安全
```

今回入れた本文には、数字を1つも入れていない。向きだけで成立している。

---

# 6　言い方の注意

「脳は楽に手に入れた情報を価値が低いと判定する」という説明をよく見るが、
これは比喩で、研究が示していることではない。

研究が示しているのは、==取りに行く動き（検索）そのものが経路を強くする==ということ。
31番は、もともと正しい言い方をしている。

```
　探して見つからなかった場所に、答えが置かれるからです。
```

ここは変えていない。
