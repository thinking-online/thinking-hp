# 45　「1日後・3日後・7日後」は運用できない問題（2026年11月9日）

著者から。
忘却曲線の話で、1日後・○日後・○日後に復習しろと書いてある本が多いが、
実際に運用するのは無理ではないか。本質的にどうするのがいいのか。

==著者の指摘が正しい。そして、本書の26番が、その無理なほうを書いていた。==
直した。

---

# 1　なぜ無理なのか。数で出す

今日30個やる。5回の復習日がつく。明日も30個やる。これにも5回つく。
1ヶ月続けると、こうなる。

```
　　ある1日にやる復習　　5つの別の日の、5つの別の範囲
　　　　　　　　　　　　　30 × 5 ＝ 150個
　　そこに新しい30個　　　合計 180個
```

しかも、どれが何日目のぶんかを1個ずつ管理する必要がある。
==これは勉強ではなく、在庫管理。==

そして、もっと大きな無駄がある。
==全部の項目が、同じ間隔を必要としていない。==
1回で入るものもあれば、8回かかるものもある。
日付で管理する方式は、その両方に同じ回数を使う。

---

# 2　グラフ自体にも、問題がある

```
　1  材料が、意味のない3文字の並び（ZOF、QAX、MUV）
　　　意味がなく、つながりもなく、既知と結びつかない
　　　＝ 忘れ方がいちばん速くなる材料
　　　学校の勉強は逆の性質を全部持っている。あのグラフほど速く忘れない

　2  測ったのは「どれだけ覚えているか」ではない
　　　覚え直すのに、どれだけ時間が短くて済むか（節約率）
　　　「20分で42%忘れる」という紹介は、測ったものと違う

　3  1日後・3日後・7日後の表は、あのグラフには書いていない
　　　あとから別につけられたもの
```

よくある紹介は、==材料も、測ったものも、表の出どころも、ずれている。==

---

# 3　本質的な解決　日付をやめて、出来で仕分ける

==間隔を「決める」のではなく、間隔が「決まるようにする」。==

```
　　1周目　全部やる。出なかったものに印を1つ
　　2周目　印があるものだけ。出たら終わり、出なかったら印を足す
　　3周目　印が2つ以上のものだけ
```

何が起きるか。

```
　　1回で入ったもの　→　2周目から出てこない　→　勝手に間隔が広がる
　　8回かかるもの　　→　毎周出てくる　　　　→　勝手に間隔が狭まる
```

==間隔を決めていないのに、1個ずつ別の間隔になる。==
日付方式が絶対にできないこと。

そして量が減るので、周と周の間が自然に空く。

```
　　1周目　500語　60分
　　2周目　180語　20分
　　3周目　 60語　 7分
　　4周目　 20語　 3分
```

==日付を書かなくても、間隔はここから出てくる。==
この数字は、もともと26番に入っていた。本は答えを持っていて、やり方だけが古かった。

## 日付を使っていい、唯一の1箇所

```
　　1回目だけ　→　翌日。カレンダーは要らない。今日のぶんを明日やるだけ
　　2回目以降　→　印で回す。日付は見ない
```

1回目だけは、やらないと忘れきる。そして「翌日」は管理コストが0。

---

# 4　もう1つ　間隔は正確でなくていい

間隔の研究でわかっているのは、==ちょうどいい間隔の近くは平らだ==ということ。
少し外しても、残る量はほとんど変わらない。
はっきり損をするのは、間隔が0のとき（覚えたその場で続けて繰り返す）だけ。

```
　　×　正確な日にやる　　　　　→　管理できなくて、やらなくなる
　　○　だいたい空いていればいい　→　続く
```

==正確にやろうとして続かない人より、雑に空けて続く人のほうが残る。==

---

# 5　そして　スケジュールはもう組まれている

```
　　授業　→　小テスト　→　定期テスト　→　模試　→　入試
　　　　　　（数日後）　　（1〜2ヶ月後）　（数ヶ月後）
```

自分で作るどんな予定表より正確に並んでいて、しかも勝手にやってくる。
==並行してもう1本作る必要はない。使っていないだけ。==

20番（小テストを点が出たら捨てる）と22番（テスト勉強を範囲が出てから始める）が、
ちょうどこれ。26番から2本につないだ。

# 7　この直しが、本全体で意味を持つ理由

勉強法の本で、忘却曲線の表を載せていない本はほとんどない。
そして、そのとおりに運用できた読者も、ほとんどいない。

==「本に書いてあるとおりにやったのに続かなかった」は、読者の失敗ではなく、本の設計ミス。==
それを名指しして、持つ形に置き換えた項目は、たぶん他にない。

本書の原則（伸びない人を責めない）が、いちばんはっきり出る項目になった。
