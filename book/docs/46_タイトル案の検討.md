# 2　「早慶合格・学年1位・試験一発合格！」について

## 2-1　確定事項と正面からぶつかる

9月に「表紙に置かない」と決めたものを、表紙のいちばん上に出す案になっている。
変えるなら変えていいが、==9月に裏へ回した理由のほうを先に見るべき。==

## 2-2　中学生を切ることになる

これが大きい。`docs/43`の反論3で書いたとおり、本書には中学生の穴がある。

```
　　内申　　0回　　高校受験　0回
　　模試　37回　　過去問　 18回
```

ただでさえ語彙が高校生に寄っている。
そこに早慶を表紙のいちばん上に置くと、==中2は自分の本だと思わない。==

そして学研がいちばん強いのは中学生の棚。
直せる穴（内申を1か所足すだけ）を、表紙で塞がらない穴に変えてしまう。

## 2-3　「試験一発合格」は中高生の言葉ではない

これは宅建・簿記・TOEIC・公務員試験の帯の言葉。
中高生の受験では「一発合格」とは言わない。受かるか落ちるかしかない。

そして著者本人が、==現役で10校受けて10校落ちている。==
おわりにの柱と、表紙が衝突する。

## 2-4　3つのうち、1つだけ生きる

```
　　早慶合格　　　　→　高校生だけに効く。中学生を切る
　　試験一発合格！　→　読者の語彙ではない。著者の経歴とも衝突
　　学年1位　　　　 →　○　中学生にも高校生にも届く唯一のもの
```

# 3　「非常識な」について

## 3-1　中身が非常識ではない

本書が渡しているのは、こういうもの。

```
　　閉じて出す　　間を空ける　　できた基準を先に決める
　　出なかったものにだけ印をつける　　解く順番を2つに分ける
```

==どれも非常識ではない。まっとうなこと。==
本書の価値は「意外なことを言う」ことではなく、
==正しいと言われていることを、実際にできる形にした==ところにある。

## 3-2　だから、約束の向きが違う

```
　　表紙　「非常識」　→　常識の逆を読ませてくれる、という約束
　　中身　正統　　　 →　言われていることを、やれる形にした
```

読んだ人が「どこが非常識なの？」になる。
`docs/06`の返品率の話に、まっすぐ当たる。

## 3-3　語感

「非常識な○○法則」は、自己啓発とビジネス書の語感。
保護者が買う本で、学研から出す本としては、浮きやすい。

# 4　「パクるだけで伸びた」について

## 4-1　これは新案ではなく、確定サブタイトルの言い換え

```
　　確定　　マネするだけで伸びる、あの子の勉強法則45
　　著者案　パクるだけで伸びた
```

## 4-2　パクる、のほうが本に忠実

```
　　帯裏　　あの子の頭のなかを、そのままパクる
　　序章　　③ そのやり方を、徹底的にパクる
```

本文がすでに「パクる」で書いてある。==マネするより、パクるのほうがいい。==

## 4-3　ただし2つ直したい

```
　　「だけで」　→　序章に「質の話を先にして、量をやらなかった人が
　　　　　　　　　伸びたのを、僕は見たことがありません」と書いてある
　　　　　　　　　その本の表紙に「〜だけで」は危ない

　　「伸びた」　→　過去形だと、誰の話かわからない
　　　　　　　　　「伸びる」なら、読者の話になる
```

# 5　著者の感覚のうち、正しいもの

## 5-1　「頭のいい人が絶対にやらない」は、本文がすでにそう書いている

数えた。

```
　　頭のいい人　　47回
　　伸びない人　　40回
　　伸びる人　　　 0回　　←
　　あの子　　　　13回　　（表紙・帯・序章・章タイトルなど、決めた6か所ぶん）
```

`docs/00`は「本文の二項対立の主語は『伸びない人／伸びる人』で書く」としている。
==でも本文は、1回も「伸びる人」と書いていない。47回すべて「頭のいい人」。==

9月に仮タイトルとして置いた言葉に、2か月かけて本文のほうが戻ってきている。
著者がいま「頭のいい人が絶対にやらない」と書いたのも、同じこと。

==これは、仮タイトルが正しかったという証拠として扱っていい。==

## 5-2　パンチが足りない、という感覚も正しい

確定案のメインは、こう。

```
　　あの子が、勉強中に絶対にやらないこと
```

「あの子」は、本を読んだ人には効く言葉。
==でも書店で3秒見る人には、まだ意味がない。==
実績を足したくなるのは、そこが埋まっていないから。

# 6　提案　パンチは実績ではなく、参入障壁に置く

`docs/06`のデータの読み4は、こうだった。

```
　　売れた2冊の共通点は、フックの強さではなく、参入障壁の低さ
```

そして本書は、その答えをすでに持っている。帯表の4行目。

```
　　勉強時間は、1分も増やしません。
```

これを表紙に上げる。理由。

```
　1  中学生にも高校生にも、等しく届く（早慶は高校生だけ）
　2  本当である。本の中身がそうなっている
　3  競合と差がつく。時間を増やせと言わない本は多いが、
　　　1分も増やさないと言い切る本はない
　4  「非常識」が狙っていた意外性を、嘘をつかずに出せる
```

## 3案、並べる

```
A　確定案のまま（数字だけ50に更新）
　　　あの子が、勉強中に絶対にやらないこと
　　　マネするだけで伸びる、あの子の勉強法則50

B　こちらの推し
　　　勉強時間は、1分も増やしません。　　　　　←　キャッチ
　　　頭のいい人が、絶対にやらないこと50　　　←　メイン
　　　やっているのに伸びないのは、　　　　　　←　サブ
　　　　やり方を教わっていないだけ
　　　帯裏に、学年1位・早稲田・9万人（いまのまま）

C　著者案
　　　早慶合格・学年1位・試験一発合格！
　　　頭のいい人が絶対にやらない
　　　非常識な合格法則
```

Bを推す理由は、==本文47回がすでにBで書かれているから。==
Aを選ぶなら、本文の47か所を直す仕事が別に発生する。
