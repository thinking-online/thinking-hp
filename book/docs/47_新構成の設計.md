# 2　判断してほしいこと　学校の場面が、全部消える

宙に浮く21本を並べると、傾向がはっきり出る。

## 消えるもの1　学校の場面（5本・8,968字）

```
　旧17　授業を、聞く時間だと思っている
　旧18　板書を、全部そのまま写す
　旧20　小テストを、点が出たら捨てる
　旧21　学校から出てくるものを、全部同じ重さで受ける
　旧22　テスト勉強を、範囲が出てから始める
```

新47本に、==授業・板書・小テスト・定期テストの項目が1本もない。==

`docs/43`の反論3で「中学生の穴がある」と書いた。
新構成は、その穴を埋めるどころか、==残っていた5本も抜いてしまう。==

中1・中2が1日のうち勉強に触れる時間の大半は、授業と学校の課題。
そこを1本も扱わない本は、中学生の本として成立しにくい。
そして学研がいちばん強いのは中学生の棚。

## 消えるもの2　間違いを直す工程（5本・10,193字）

```
　旧07　間違えた問題を、もう一度解く
　旧34　「できた」の基準を、決めずに進む
　旧36　解けなかった問題を、もう一度そのまま解く
　旧37　ケアレスミス、次は気をつける、で終える
　旧38　10個の間違いを、10問とも順に直す
```

新47本は「どう覚えるか」「どう集中するか」は厚いが、
==間違えたあとに何をするかが、ほぼ空いている。==

新36（不正解の選択肢を使う）が近いが、1本だけ。
点が上がるのは、この工程を回したときなので、ここは薄くしないほうがいい。

## 消えるもの3　本番（3本・6,187字）

```
　旧48　前日に、新しい問題集を開く
　旧50　問題を、1番から順に解く
　旧09　実力がついてから、過去問を開く
```

新47本の本番系は、新19（緊張）と新38（PPR）の2本だけ。
どちらもメンタル。==解く順番・時間配分・前日の過ごし方が消える。==

## なぜこうなったか

新しい47本は、==心理学の効果で並んでいる。==

```
　インターリーブ　プレクラスティネーション　ディスフルエンシー
　ツァイガルニク　ダニングクルーガー　サンクコスト　プロダクション効果
```

いまの50本は、==生徒が困る場面で並んでいる。== 質問6,360件から起こしたので。

```
　効果で並べる　→　類書と同じ棚に乗る。研究の密度が上がる。AI章が作れる
　場面で並べる　→　読者が自分の明日と結びつけられる。中学生に届く
```

どちらも正しい。==ただ、効果だけで並べると、学校と本番が構造的に落ちる。==
