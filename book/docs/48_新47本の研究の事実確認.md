# 1　C　使わないほうがいい　3件

## C-1　「人は1日に3万5000回の意思決定をしている」（新28）

```
　この数字の元になった研究が、見つからない。
```

ネット上では「ケンブリッジ大学の研究」として紹介されることが多いが、
該当する論文が特定できない。==典型的な、出どころのない数字。==

校閲でほぼ確実に止まる。

```
　○　人は1日に、数えきれないほどの選択をしています。
　　　ほとんどは、考えずに決めています。
```

数字を外しても、言いたいこと（脳は楽をしたがる）は成立する。

## C-2　「マルチタスクでIQが10ポイント下がる」（新26）

```
　企業の委託調査で、査読論文ではない。
　そして、調べた本人が後に「メディアに誇張された」と公に述べている。
```

「徹夜明けと同じ」という比較も、その調査から出たものではない。

==ここは、代わりになる研究がすでに本書にある。==

```
　テキサス大学のスマホ実験（机の上・カバン・別室）
　　→　新34に入っている。こちらは査読論文で、追試もある
```

マルチタスクの話は、テキサス大学の実験1本で足りる。

## C-3　「読みにくい字にすると成績が上がる」（新05）

実験自体は実在する（プリンストン大学）。問題は後日談のほう。

```
　その後、数千人規模の追試が複数行われ、再現しなかった。
```

==「負荷をかけると残る」の根拠としては、いま弱い。==
絶対法則②（負荷をかけろ）の柱にすると、足をすくわれる。

代わりに、本書がすでに持っている根拠を使う。

```
　テスト効果　　同じ文章を4回読むより、1回読んで3回思い出すほうが残る
　誤答を作ってから学ぶ　外してから正解を見たほうが、あとのテストで高い
```

どちらも追試が積み重なっている。==負荷の話は、この2つで立てたほうが強い。==
殴り書きでいい、という結論自体は変えなくていい（理由が変わるだけ）。

# 2　B　言い方を直せば使える　5件

## B-1　「集中が切れると、戻るまでに23分15秒」（新26）

数字は正しい（カリフォルニア大学アーバイン校）。測ったものが違う。

```
　×　深い集中に戻るまで23分15秒
　○　中断されたあと、元の作業に戻ってくるまでに平均23分かかった
```

同じ研究は「中断された仕事はむしろ速く片づいた、ただしストレスは増えた」とも
報告している。==「23分無駄になる」と書くと、校閲で引っかかる。==

## B-2　「深い集中は1日4〜6時間が限界」（新02・新24）

研究として紹介されているが、==出典が特定できない。==
研究ではなく、経験則として書けば問題ない。

```
　○　1日じゅう同じ集中は続きません。僕も、2000人を見てきて、
　　　深く頭を使えるのは1日のうち数時間だと思っています。
```

## B-3　「脳は90分周期で動く」（新24）

睡眠中の約90分周期は確か。==起きているあいだの90分周期は、証拠が弱く、
個人差が大きい。== 断定しないほうがいい。

```
　○　集中は、ずっと同じ高さでは続きません。区切って使います。
```

90分ブロックという「やり方」はそのままでいい。理由づけを弱めるだけ。

## B-4　「ダートマス大学の、保持したい期間の10〜20%」（新09）

公式そのものは正しい。==ただし、この公式を出した研究グループは
ダートマス大学ではないはず。== 大学名の確認が要る。

確認が取れなければ、大学名を書かずに中身だけ書く。本書の巻末はその形で統一してある。

なお、この項目はいまの原稿の26番で、==日付管理をやめて印で仕分ける形に
書き直してある（docs/45）。== 著者が「まだアクションプランを考えていない」と
書いていた部分は、すでに答えが出ている。

## B-5　「サリー大学のロバート・ナッシュ」（新07）

目を閉じて思い出す研究は、イギリスのヨーク大学のもので正しい。
==ナッシュ氏の所属はサリー大学ではないはず。== 別の研究と混ざっている。

ヨーク大学の1件だけにすれば、確認の手間がなくなる。

# 4　研究ではない引用について

```
　ファインマン　　　　簡単な言葉で説明できないなら理解していない
　松下幸之助　　　　　これで十分だ／まだ足りないかもしれない

```

`CLAUDE.md`の「研究者名と年号は本文に出さない」は、==研究の話。==
名言の引用は別なので、人名を出していい。

ただし2つ注意。

```
　1  ダーウィンの「変化に適応した者が生き残る」は、
　　　ダーウィン本人の言葉ではないことが知られている。
　　　経営学者の言い換えが広まったもの。出典を書くと指摘される

　2  ハイキュー!!の台詞は著作物。
　　　商業出版で引用する場合、出典表記が要る。杉浦さんに確認
```
