# 2　絶対法則は6にする。しかも⓪を①に上げる

著者の提案どおり6にする。==ただし⓪を頭に持ってくる。==

## 理由

この本のタイトルは「頭のいい人が絶対にやらないこと」。
==これは「みんながやっていることは、たぶん間違っている」という主張そのもの。==

```
　⓪　みんながやってるから正しい、じゃない
```

これが本のテーゼ。章の入り口に置くと読み飛ばされる。
==本のいちばん大事な一文を、法則に数えないのはもったいない。==

## 6つに、1語の名前をつける

```
　①　疑う　　　　みんながやっているから正しい、ではない
　②　思い出す　　何も見ないで、思い出す
　③　負荷　　　　今の自分に合うを、やらない
　④　戦略　　　　闇雲にやらない。努力を美徳化しない
　⑤　分散　　　　まとめてやらない
　⑥　速度　　　　完璧を待たない。出して、直す
```

==疑う・思い出す・負荷・戦略・分散・速度。==
6つとも2〜3文字なので、45本のどこからでも呼び戻せる。
各項目の最後に「これは③の話」と1行入れられる形になる。

著者案の「行動から変えようとする（考え方→行動→結果）」は、
③④と同じことを言っているので==法則に独立させず③に吸収した。==

6 ＋ 44 ＝ 50。

