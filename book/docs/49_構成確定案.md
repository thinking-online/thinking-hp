# 1　新47本の、唯一の弱点

カテゴリで数えると、一目で出る。

```
　集中・環境　13本
　メンタル　　11本
　覚える　　　10本
　計画　　　　 7本
　AI・人　　　 3本
　解く　　　　 2本　←
　直す　　　　 0本　←
　学校　　　　 0本　←
```

## なぜこれが問題か

中高生が1日のうち、勉強に使っている時間の中身で考える。

```
　授業を受けている　　　　6時間　　　←　本に1本もない
　問題を解いている　　　　1〜3時間　 ←　本に2本
　間違いを直している　　　　　　　　 ←　本に0本
　環境を整えている　　　　　10分　　　←　本に13本
　メンタルを調整している　　　　　　　←　本に11本
```

==集中と環境は、勉強の準備であって、勉強ではない。==
13本は、準備に割く量としては多すぎる。

## もっと大きいのは、本の中で論理が閉じていないこと

絶対法則①が「何も見ないで思い出すが最強」。これは正しいし、本の背骨。

```
　思い出す　→　出てこないものが見つかる　→　？
```

==思い出す練習をすると、必ず×が出る。その×をどう処理するかが、点になる工程。==
新47本は、そこが36（不正解の根拠）の1本しかない。

絶対法則①を5本の筆頭に置くなら、==その結果出てくる×を扱う章が要る。==
これは既存原稿の話ではなく、新しい構成が自分で呼んでいる章。

## 学校について

中1・中2が高校受験に向けて動かせる、いちばん大きなレバーは内申。
提出物、授業態度、小テスト、課題。

そして授業は、==本人が選べない6時間。== ここを1本も扱わない本は、
読者の1日の大半に触れないまま終わる。

学研の棚でいちばん強いのも中学生。

## 第1章　頭のいい人の絶対法則5　　5本

```
　⓪　みんながやってるから正しい、じゃない　←　章の入り口。法則に数えない
　①　何も見ないで、思い出す
　②　今の自分に合うを、やらない
　③　闇雲にやらない。戦略が全て
　④　まとめてやらない。分散する
　⑤　完璧を待たない。出して、直す
```

==⓪は6つ目の法則にしない。== 表紙とタイトルが「5」を約束するので、6にすると弱る。
⓪はスタンス（疑え）であってやり方ではないので、
自己紹介のバケツの穴の話から第1章へ渡す橋として置く。

著者案の「行動から変えようとする（考え方→行動→結果）」は、
②③と同じことを言っているので、==法則に独立させず②に吸収する。==
