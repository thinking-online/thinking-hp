# 50　新しい目次（8章・50本）

章は8つ。章タイトルは、全部「頭のいい人は、〜しない」。項目タイトルは、全部「読者がいま、良いと思ってやっていること」。

# 章タイトル

```
　第1章　頭のいい人は、「みんなと同じ」をやらない　　〔絶対法則6・6本〕
　第2章　頭のいい人は、授業を「聞かない」　　〔学校の使い方・4本〕
　第3章　頭のいい人は、「覚えよう」としない　　〔覚え方・6本〕
　第4章　頭のいい人は、解けた問題を数えない　　〔解き方と直し方・11本〕
　第5章　頭のいい人は、計画を守らない　　〔計画と続け方・7本〕
　第6章　頭のいい人は、集中力に頼らない　　〔集中と環境・6本〕
　第7章　頭のいい人は、落ち着こうとしない　　〔メンタルと本番・7本〕
　第8章　頭のいい人は、ひとりで頑張らない　　〔AIと人の使い方・3本〕
```

ふつうは「やったほうがいい」と思われていることを、章タイトルに置いた。答えが、章の中身になっている。

```
　授業を「聞かない」　　　→　聞く時間ではなく、思い出す時間にしている
　「覚えよう」としない　　→　覚えるのではなく、思い出す練習をしている
　解けた問題を数えない　　→　点になるのは、解けなかった問題のほう
　計画を守らない　　　　　→　崩れる前提で作って、直しつづける
　集中力に頼らない　　　　→　意志ではなく、環境と区切りで作る
　落ち着こうとしない　　　→　気持ちは消さずに、やることを変える
　ひとりで頑張らない　　　→　AIと人を、使い倒す
```
