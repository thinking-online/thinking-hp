# 3　前の原稿から、変わったこと

## 「6つの力」と「3つの問い」は、絶対法則6に置きかえた

```
　前　　6つの力（選ぶ・入れる・つなげる・出す・なおす・続ける）＋ 3つの問い
　いま　絶対法則6（疑う・思い出す・負荷・戦略・分散・速度）
```

2つを両方残すと「6」が2種類あって混乱するので、絶対法則6に一本化した。
44本の最後に、==「もとにある絶対法則　② 思い出す」==のように、1行で戻る印を入れてある。

「いま、閉じて出せる？」という問いだけは、絶対法則②の合言葉として残した。

## 序章は、第1章の①②③になった

序章（著者が自分の言葉で書いたもの）は、中身がそのまま絶対法則の①疑う・②思い出す・③負荷だった。
文章は、できるだけそのまま使っている。

## 巻頭の自己紹介は、「はじめに」に移した

巻頭は、11個の数字から「やり方が見えなかっただけです」まで。
自己紹介は、著者が今回書いた文章を整えて「はじめに」にした。

## おわりにを、対にした

```
　はじめに　恩師「お前の勉強法、ぜーんぶ、ズレとる」
　おわりに　恩師「俺も、夢を語ったときは、笑われた」
```

夢は笑わない。やり方は容赦なく直す。この2つで本を閉じる形にした。

　　　　いまのPDFでは、ふつうの引用になっている
