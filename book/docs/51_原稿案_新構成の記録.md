# 3　前の原稿から、変わったこと

## 「6つの力」と「3つの問い」は、絶対法則6に置きかえた

```
　前　　6つの力（選ぶ・入れる・つなげる・出す・なおす・続ける）＋ 3つの問い
　いま　絶対法則6（疑う・思い出す・負荷・戦略・分散・速度）
```

2つを両方残すと「6」が2種類あって混乱するので、絶対法則6に一本化した。
44本の最後に、==「もとにある絶対法則　② 思い出す」==のように、1行で戻る印を入れてある。

「いま、閉じて出せる？」という問いだけは、絶対法則②の合言葉として残した。

## 序章は、第1章の①②③になった

序章（著者が自分の言葉で書いたもの）は、中身がそのまま絶対法則の①疑う・②思い出す・③負荷だった。
文章は、できるだけそのまま使っている。

## 巻頭の自己紹介は、「はじめに」に移した

巻頭は、11個の数字から「やり方が見えなかっただけです」まで。
自己紹介は、著者が今回書いた文章を整えて「はじめに」にした。

## おわりにを、対にした

```
　はじめに　恩師「お前の勉強法、ぜーんぶ、ズレとる」
　おわりに　恩師「俺も、夢を語ったときは、笑われた」
```

夢は笑わない。やり方は容赦なく直す。この2つで本を閉じる形にした。

# 8　07番（授業）のやり方を、時間で区切る形に変えた（11月14日）

```
　前　　先生の「つまり」「じゃあ」が聞こえたら、答えが来る前に、自分で答える

```

# 10　08番（板書）を書き直した（11月14日）

著者の指示。

```
　・「頭は形の処理をしています」は、何のことかわからない → 言いかえる
　・「手に入るもののために、手に入らないものを捨てています」は、かみくだく
　・板書は、許可があれば写真でもいい。写す作業より、理解に専念する
　・ただ、理解だけだと復習できない。ゴールは「先生が解説したものを、白紙からできること」
　・そのために、覚えておくことと、思い出すときのヒントをメモする
```

直したこと。

```
　・「形の処理」→ 黒板を見る→字を覚える→ノートを見る→書く、の順に書いて
　　「字を覚えて、書きうつすことで、いっぱい」にした
　・「手に入るもの…」→ 表にして「あとで見られるほうを写して、
　　その場でしか聞けないほうを聞きのがしている」にした
　・節「授業のゴールは、ノートではありません」を足した
　・節「ただし、『わかった』だけで帰ると、家で困ります」を足した（メモは2種類）
　・STEPを、聞く → ヒントだけ書く → その日のうちに白紙から解く、に変えた
　・基準は「その日のうちに、何も見ずに、白紙から最後まで解けた」
　・写真は「先生がいいと言っているなら」「必ず先に聞く」と書いた
　・ノート提出がある授業では、区切りごとにまとめて写す、を残した
```

前は08番に入っていた「読むときも、同じことが起きています」（知らない言葉を記号に置きかえる話）は、
板書の話ではないので、20番（問題文を、最後まで読まずに解き始める）に移した。

08番の本文は `manuscript/本文/v2/08.md`。
