# 1　「やり方」の型

50本すべて、同じ形にした。

```
　## やり方
　### STEP 01　（きっかけと、最初の動作）
　### STEP 02　（本体。数字つき）
　### STEP 03　（確かめる。外れたときの次の手）
　　　「できた」の基準　　（1行）
```

## 3つのSTEPに入れたもの

```
　いつ・何をきっかけに　　「1ページ読んだら」「タイマーが鳴ったら」「歯をみがいたら」
　　　→　きっかけまで決めた行動のほうが、実際にやる割合が高い（28番の研究）

　何を・どれだけ　　　　　「3つ言う」「3問、何も見ずに」「10秒」「25分」
　　　→　数字がないと、やったかどうかを自分でごまかせる

　確かめて、直す　　　　　「出なかった1か所だけ見る」「次の日にもう1回」
　　　→　思い出す練習は、すぐ確かめて、日をあけてもう一度やると残る（02番・05番）
```

## 「できた」の基準

本文の23番で「基準は、何を・どんな条件で・どれだけ」と教えているので、
==この本の「やり方」そのものが、その形になっていないとおかしい。==
50本すべてに、自分で判定できる1行をつけた。

```
　覚える系　　「何も見ずに言えた。次の日にも言えた」　　その場と、次の日の2回
　解く系　　　「本番と同じ時間で、何も見ずに解けた」
　続ける系　　「14日のうち12日」「0の日が2日以内」　　　日数で数える
　気持ち系　　「書いて裏返したあと、10分、手が動いた」　 動いたかどうかで見る
```

気持ちが楽になったか、ではなく、==そのあと手が動いたか==を基準にしている。

## 直したところ

```
　・4手順あったものを3つにまとめた　　21 23 24 25 26 27 31 39 43 44 45 46 47
　・「やり方」の節がなかったものに足した　　02 07 09 36
　・「今日やること」がなかったものに足した　07 09 22 36 46
　・10番　「答えを写すかどうか」の1行を外して、「終わりの時刻を決める」にした
　・08番　ノート提出がある授業では写す、を足した（内申への配慮）
　・16番　前の説明は「日付のかわりに、印で回します」として残した
```

正は `manuscript/本文/v2/_steps/NN.md`。組み立てのときに、本文の「やり方」をこれで置きかえる。

# 2　Googleドキュメント版

```
　node scripts/build_docx_v2.js　　→　build/原稿_v2.docx
```

Googleドライブに入れて「Googleドキュメントで開く」と、そのまま編集できる。

```
　見出し1　　巻頭／はじめに／第1章〜第8章／コラム／巻末／おわりに
　見出し2　　項目（01〜50）
　見出し3　　項目の中の節（頭のなか、やり方、など）
　見出し4　　STEP 01〜03 と小見出し
```

左の「ドキュメントの概要」から、章 → 項目 → 節 と飛べる。

```
　飾り　　　　　なし。ページ区切りも入れていない
　大事なところ　黄色の蛍光ペン（原稿のマーカー）
　×の行　　　　灰色
　○の行、基準　紺の太字
```

## 直したものを、原稿に戻すとき

原稿の正は、リポジトリの中の本文ファイル。
Googleドキュメントで直したら、直した場所を教えてもらうか、ファイルを戻してもらえば、
こちらで本文に反映して、組み直す。
