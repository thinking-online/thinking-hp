# 53　わかりにくさの総チェック

2026年11月14日。著者の指示「その視点で、わかりにくさがあるところがないかを総チェックしてほしい」を受けて、原稿ぜんぶを読み直した記録です。

きっかけになった2つの文（07番・08番で著者が指摘したもの）

- 「この間、頭は形の処理をしています。」
- 「手に入るもののために、手に入らないものを捨てています。」

どちらも、読んだ瞬間に、頭の中で訳し直さないと入ってこない文でした。同じ種類の文を、原稿ぜんぶから探して直しました。

## 1　基準

「中学2年生が、立ち止まらずに、一度で読めるか」。止まるところだけを直す。声は平らにしない。

直したのは、次の8種類です。

1. 抽象的な名詞で言い切っている文（例：設計が持たない／在庫の管理／判定する／物理的に／効率が落ちる）
2. 圧縮された逆説・言葉遊び・説明のないたとえ（例：いちばん高い買い物です／いない人の計画を、いる人が実行する／飾りと骨）
3. 「これ」「その判断」が何を指すか、戻らないとわからない文
4. 理由が1段ぬけていて、なぜそうなるのかがつながらないところ
5. 中高生が知らない言葉（シラバス、争点、闇雲 など）
6. 番号の参照がいまの番号と合っていないところ、もうない言葉（「6つの力」の残り）
7. 主語がなくて、誰が何をしているのかわからない文
8. 表が1行につぶれているところ、1段落が長すぎるところ（言葉ではなく、改行の問題）

直し方の決まり

- 意味は変えない。新しい研究や主張は足さない。
- 抽象名詞は「誰が・何を・どうする」という、目に見える動作に言いかえる。
- 場面の描写、会話、「頭のなか」のセリフ、マーカー、絶対法則の6つの言葉はそのまま。
- 巻頭・はじめに・コラム・おわりには、著者本人の言葉がもとなので、直さずに候補だけ出す（4にまとめた）。

## 2　件数

直したのは 401 か所、83 ファイルです。文字数は 141,225字 から 142,959字 になりました（言いかえで少し増えた分と、表に戻した分）。

50本とも、「やり方」1つ・STEP 3つ・「できた」の基準1つ・今日やること1つの型はそのままです。アスタリスクは0です。

## 3　中身にかかわる直し（著者に見てほしいもの）

言い回しではなく、数字・番号・理屈を直したところです。

数字

- 巻頭｜「1週間たつと、…新しい5つと復習15で、20になります」→「1か月たつと」。1日後・1週間後・1か月後の3回が全部そろうのは、1か月たってからです（1週間後の時点では15）。
- 16番｜「同じ量を、4分の1の時間で維持できます」→「同じ500語を、およそ半分の量で、覚えたままにできます」。すぐ下の数字が 760語ぶん と 1500語ぶん で、4分の1にはなっていませんでした。
- 45番｜「4回に1回は知らない単語」→「5回に1回」。2000語のうち1600語を覚えているなら、知らないのは5分の1です。
- 50番｜STEP 03「3分で答えが返ってきます」→「2分」。本文の「2分で終わります」に合わせました。
- 34番｜「1単元にかけられる時間が倍」→「ほぼ倍」。40単元が22単元なら、約1.8倍です。
- 22番｜見出し「3つ以上出てきたら」→「4つ以上出てきたら」。本文が「3つくらいまでは頭の中で動かせる。4つになると消える」なので、そろえました。

理屈

- 16番｜「量が減るので、次の周までの間が自然に空く」は、理由がつながっていませんでした。「出せた単語は、次の周には出てこない。だから、その単語との間が自然に空く。出せなかった単語だけが、すぐもう一度出てくる」に直しました（やり方の STEP 03 も同じ）。
- 10番｜「手を抜くのは損」と書いたすぐあとに「1は、いちばん短い方法で終わらせる。中身は求めない」とあり、同じことに読めました。「先に30分と時間を決めて、その中で終わらせる。時間をかけたまま中身だけ薄くする『手を抜く』とは、ここが違う」を足しました。
- 13番｜「引いていい線と、引いてはいけない線」の節。番号が古いままでした（09・10・25・29）。いまの本で線を引く場面（04番・09番・20番・34番）に直し、説明も「引いたあとに、やることが決まるから引く」にそろえました。
- 30番｜本文の「崩れなかった週は、その日で先に進めます」が、STEP 03 の「休みです」と食いちがっていたので、「休んでも、先に進めてもいい」にそろえました。場面の計画表（月曜〜日曜）は、1行につぶれていたので表にしました。
- 31番｜「2時間半は、短くありません」→「ゼロではありません」。見出しが「短いのです」で、逆のことを言っていました。
- 25番｜「同じ3時間です。次の模試で差が出ます。」の「同じ3時間です。」を削りました。すぐ下に「3時間半が、1時間半になります」とあり、食いちがっていました。
- 02番｜「いま、閉じて出せる？」のブロックが2回続けて入っていたので、1つにしました。
- 34番｜「AIにやらせるなら」が「今日やること」の後ろにあったので、「これをやると、何が残るか」の前に移しました。

## 4　著者の言葉なので、直していない候補

巻頭

- 「どこで手を止めて、何を書かずに済ませているか。」→ 案：「どこで手を止めて、何を書いていないのか。」
- 「結局、その真相が、見えない。」→ 案：「結局、その中身が、見えない。」
- 「ここから先は、たいてい書いてありません。」→ 「ここ」が少し遠い。案：「どれを捨てるのか。そこから先は、たいてい書いてありません。」

はじめに

- 「そして勝負に勝つためには、まず、負けないことです。」→ 案：「そして勝つためには、まず、負ける原因をなくすことです。」
- 「1人ずつ、頭の中を開けてきました。」→ 案：「1人ずつ、頭の中で何を考えているのかを、聞いてきました。」
- 「どの章よりも大事な大前提です。」→ 案：「どの章よりも大事な、土台です。」
- 「言い訳だけは達者。」→ 案：「言い訳だけは、うまい。」

コラム

- 第2章｜「人は、行動より先に、『ふつう』の基準をまわりからもらっています。」→ 案：「人は、何をするかより先に、何が『ふつう』かを、まわりからもらっています。」
- 第2章｜「基準の高い場所を1つ持ってください。」→ 案：「『やるのがふつう』の場所を1つ持ってください。」
- 第6章｜タイトル「無駄な同調圧力に、屈するな」→「同調圧力」「屈する」がかたい。案：「『みんなと同じ』の空気に、合わせなくていい」
- 第7章｜「かっこよく見える途中より、かっこわるくても、届く途中を選んでください。」→ 案：「かっこよく見えるやり方より、かっこわるくても、合格に届くやり方を選んでください。」
- 第8章｜「いちばん割のいい投資です。」→ 案：「いちばん得な、お金と時間の使い方です。」
- 第5章｜「受け取るのは、未来の自分です。」→ 案：「その30分に助けられるのは、未来の自分です。」
- 第3章（2本目）｜「場所には、くせがつきます。」→ 案：「同じ机で同じことをしていると、座っただけで、それが始まるようになります。」
- 第1章｜「あそこで終わっていたら、それが証明になっていた。」→ 案：「あそこでやめていたら、それが弱さの証明になっていた。」
- 第4章｜「その感じが、変わる入口です。」→ 案：「そのいやな感じが、変わりはじめた合図です。」
