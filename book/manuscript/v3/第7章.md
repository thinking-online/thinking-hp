# 第7章　【モチベ・メンタル】頭のいい人は、落ち着こうとしない

## 章の導入文

テストの前、心臓が速くなります。手が冷たくなります。

　　「落ち着け、落ち着け」

そう唱えるほど、落ち着いていない自分に気づいて、もっと焦ります。

落ちこんだ時。不安な時。失敗した時。真面目な人ほど、気持ちを「なんとかしよう」とします。前向きになろうとする。自分を責めて、気合いを入れ直そうとする。不安を、頭の中で消そうとする。

頭のいい人は、気持ちを消そうとしていません。==気持ちはそのままにして、やることを変えています。==

前半の4つが、普段の気持ちの扱い方。後半の3つが、本番の前日と当日です。

# 41　「自分はできる」と言い聞かせる

## 質問ページ

頭のいい人が絶対やらないこと
「「自分はできる」と言い聞かせる」
じゃあ、何をするの？

## 本文

数学の模試が、返ってきました。また、40点です。落ちこみます。

こんな時、あなたなら、自分に、何と言いますか？

　　「大丈夫。自分はできる。次は絶対いける」

気持ちは、少し楽になりました。

次の模試。40点でした。

### 前向きな言葉は、気持ちいいぶん、動けなくなります

「ポジティブに考えよう」「自分を信じよう」。よく言われます。

ニューヨーク大学の研究者たちが、長く続けている研究があります。うまくいく場面を、強く、明るく思い描いた人ほど、==そのあとの行動が減り、結果も出にくかった==というものです。

33番で書いたのと、同じことが起きています。「自分はできる」と言い聞かせると、気持ちが楽になります。その楽さで、少し満足します。何も変えていないのに、もう大丈夫な気がしてしまう。だから、次の模試までに、やることが変わりません。

### 逆に、「できない」で終わっても、次が出てきません

じゃあ、落ちこんだままでいいのか。それも、違います。

面談で、一番よく聞く言葉があります。

　　「自分、数学できないんで」

この言葉を言った瞬間に、話が終わります。できないのだから、やってもしょうがない。やらないので、できないままになる。

文として見てください。「自分は、数学ができない」は、そこで言い切って、終わっている文です。終わっている文には、続きがありません。続きがないので、次にやることも出てきません。

「自分はできる」も、「自分はできない」も、同じです。==どちらも、そこで終わっている==んです。

### 1語だけ、足します

　　自分は、数学が、==まだ==できない。

この文は、終わっていません。「まだ」と言った瞬間に、じゃあ、いつできるのか、という続きが必要になります。

これは、前向きに考えよう、という話ではありません。==どう言うかで、次にどこを見るかが決まる==という話です。

「数学ができない」では、どこを見ればいいのか、わかりません。数学は、大きすぎます。

「まだ」を足すと、言い直したくなります。全部ができないわけではないからです。計算はできる。基本問題も解ける。

　　「二次関数の最大値が、まだ出せない」

ここまで小さくなれば、教科書のそのページを開けばいい。「まだ」を足すと、できないところが、自然に小さくしぼられます。前向きになるからではなく、==正確になるから==です。

### つまずきを、「限界」と呼ぶか、「途中」と呼ぶか

難しい問題にぶつかった時、頭の中で起きることは、2通りあります。

```
　　「できない」　　　→　自分の力の、限界だと受け取る　→　やめる
　　「まだできない」　→　今、途中にいると受け取る　　　→　続ける
```

スタンフォード大学の研究者たちの研究では、力は伸ばせるものだと考えている生徒のほうが、難しい問題にぶつかった時に、やめずに続ける傾向がありました。

力そのものが違ったのではありません。==つまずきの呼び方==が、違っただけです。

### 無理に、明るくならなくていいです

落ちこんで、いいです。40点は、うれしくありません。うれしくないものを、うれしいふりをする必要はありません。

やるのは、気持ちを変えることではなく、==事実を、そのまま、正確に言うこと==です。

　　「今、二次関数の場合分けが、まだできていない」

暗い言葉ではありません。明るい言葉でもありません。正しい言葉です。そして、正しい言葉からは、次にやることが出てきます。

逆も、同じです。「英語はできる」も、言い切って終わっている文です。終わっているので、確かめようとしません。「今のところ、出せている」と言えば、また確かめる気になります。（27番の話です）

# 42　自分を責める

## 質問ページ

頭のいい人が絶対やらないこと
「自分を責める」
じゃあ、何をするの？

## 本文

小テストが、返ってきました。ケアレスミスが、3つ。符号の間違い。単位の書き忘れ。問題の読み違い。昨日も、同じミスをしました。

こんな時、あなたなら、自分に、何と言いますか？

　　「なんで、こんなミスを。自分は、本当にダメだ」

家に帰ってからも、ずっと考えています。夕飯の時も、お風呂でも。

その夜は、何も手につきませんでした。

### 自分に厳しい人ほど、真面目です

まず、これを言わせてください。

失敗した自分を責めるのは、どうでもいいと思っていないからです。ちゃんとやりたい。次は取りたい。そう思っているから、責めます。

「自分に厳しく」は、いいこととして教わります。自分を甘やかすな、と。

ただ、その厳しさが、次の点につながっているかどうか。そこだけ、見てください。

### 責めても、次の点は上がりません

自分を責める言葉を、頭は、==外から攻撃された時==と同じように受け取ります。

攻撃されると、人は身を守ろうとします。固まるか、逃げるかです。「もう考えたくない」「机に向かいたくない」。責めれば責めるほど、勉強から遠ざかります。

その夜、何も手につかなかったのは、気合いが足りなかったからではありません。責められて、動けなくなっていたんです。

そして、責めていた3時間に、解いた問題は0問です。

### 親友が、同じ失敗をしたら

親友が、同じ小テストを持ってきたとします。ケアレスミスが3つ。落ちこんでいます。

あなたは、何と言いますか。

　　「お前は、本当にダメだな」

言わないですよね。

　　「でも、ここは合ってるじゃん」
　　「ミス、3つとも種類が違うね。次は、符号だけ見直してみたら？」

たぶん、こう言います。できているところを見て、次にやることを1つ、一緒に考えます。

==自分にだけ、一番ひどい言葉を使っている。==ほとんどの人が、そうです。

### 思いやりのある言葉のほうが、次に動けます

カリフォルニア大学の研究者たちの実験です。

学生に、難しいテストを受けてもらいます。ほとんどの人が、うまくいきません。そのあと、あるグループには、自分に思いやりのある言葉をかけてもらいました。「うまくいかないことは、誰にでもある」というような言葉です。

次のテストに向けて、どれだけ勉強するかを見ました。==思いやりのある言葉をかけたグループのほうが、長く勉強しました。==

厳しくしたほうが、頑張れる。そう思いがちです。実際は、逆でした。

### 甘やかすのとは、違います

基準を下げる、という話ではありません。3つのミスを「まあいいか」で流すのは、甘やかしです。

変えるのは、基準ではなく、==言葉の向き==です。

```
　　×　自分はダメだ　　　　　　　　　人の話。次にやることが出ない
　　○　符号の見直しを、していない　　やり方の話。次にやることが出る
```

「ダメだ」は、人に向いた言葉です。「どの作業で落としたか」は、やり方に向いた言葉です。（落とした作業に名前をつける方法は、26番に書きました）

### 変えられるものと、変えられないものを、分けます

責めている時、考えているのは、たいてい==もう変えられないもの==です。

```
　　変えられないもの　　返ってきた点数。昨日の自分。問題の難しさ。他の人の点
　　変えられるもの　　　次の見直しのやり方。今日の30分
```

変えられないものは、何時間考えても、変わりません。考えた時間だけが、消えます。

分けるコツは、起きたことと、それを見て自分が思ったことを、分けることです。

```
　　起きたこと　　　　3問、間違えた
　　自分が思ったこと　自分はダメだ
```

起きたことは、1つです。思ったことのほうは、変えられます。「3問間違えた。うち2問は、見直しをしていれば取れた」。同じ3問を見て、こう思うこともできます。

### 少し離れて、自分を見ます

「親友なら、何と言うか」が効くのは、少し離れたところから、自分を見られるからです。

他にも、やり方があります。部活の後輩が同じことで悩んでいたら、何とアドバイスするか。1年後の自分が、今日のことを見たら、何と言うか。

近すぎると、責める言葉しか出てきません。==一歩はなれると、次にやることが見えます。==

# 43　友達と比べる

## 質問ページ

頭のいい人が絶対やらないこと
「友達と比べる」
じゃあ、何をするの？

## 本文

休み時間。前の席で、友達が話しています。

　　「模試どうだった？」「んー、まあまあ。8割くらい」

自分の結果は、カバンの中にあります。5割でした。判定は、Eでした。自分は、毎日やっています。あの子が遊んでいる時も、やっていました。それでも、3割違います。

こんな時、あなたなら、どう思いますか？

　　「やっぱり、自分は向いてないのかもしれない」

その日は、家に帰ってから、何もできませんでした。

---

これを書いているのは、同じことを経験した人からの手紙を、何百通も読んできたからです。その中の1通に、こうありました。「自分は努力してるのになんでこんなに低いんだろうと悩んで、泣いたりしていました」まず言いたいのは、これです。

その感覚は、正しいです。

実際に差があるし、実際に悔しい。気にするな、というのは無理です。無理なことを言っても、意味がありません。

だから、別の話をします。

### 見えないものと、比べています

あの子の8割は、いつから積み上げた結果でしょうか。

今日できたことではありません。小学校から今日までの、積み上げの結果です。自分の5割も、同じです。今日までの積み上げです。つまり、比べているのは、お互いの「これまで全部」です。これまで全部は、今日どうにもなりません。どうにもならないものを比べているので、何回比べても同じ結論になります。そして、もっと大事なことがあります。あの子が、先月から何点上がったのかは、見えません。下がっているかもしれません。見えているのは、あの子の今の点だけ。どれだけ伸びたかは、見えません。見えないものと比べているから、何回比べても、答えが出ないのです。

### 比べること自体は、悪くありません

よく「人と比べるな」と言われます。無理です。教室に人がいるかぎり、比べます。比べないようにしよう、というのは、やり方ではありません。やるのは、比べる相手を変えることです。

　　先週の自分。

これなら、変化が見えます。しかも、自分で動かせます。

```
先週　52点
今週　58点
　　　6点、上がっている
```

あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきりわかります。

### 「でも、追いつかない」

ここで、こう思うはずです。

　　先週より6点上がっても、あの子には追いつかない。

その通りです。1週間では、追いつきません。ただ、計算してみてください。受験まで、あと何週間ありますか。仮に30週あるとします。

```
1週間に2点ずつ上げる
　30週で　60点
```

今3割の差があっても、届く可能性が出てきます。これは、気休めで言っているのではありません。見るものを変えると、計算できるようになる、という話です。「あの子との差」は、計算できません。「1週間に何点上げるか」は、計算できます。計算できるものだけが、今日やることに変わります。

### 落ち込んだ1時間は、0問です

ここは、少し冷たいことを言います。比べて落ち込んだ1時間に、1問も解いていません。これは、責めているのではありません。落ち込むな、とも言いません。落ち込みます。言いたいのは、落ち込む時間を短くしたほうが得だ、ということです。そして、短くする方法が1つあります。落ち込んだ時に、やることを決めておきます。

　　先週の自分の点を、見る。

これだけです。紙でも、スマホのメモでもいい。先週の自分が、どこにいたかを見ます。1分で終わります。そして、落ち込んでいる状態から、計算できる状態に戻ります。

### 物差しを、2本持ちます

結果を出す人は、自分を測る物差しを、2本持っています。そして、その2本を混ぜません。

```
　　1本目　ゴールまでの距離　　あと何点、足りないか
　　2本目　昨日からの伸び　　　前より、何ができるようになったか
```

1本目だけの人は、いつ測っても「足りない」になります。ゴールに着くまで、ずっと足りない。それが何ヶ月も続くと、折れます。

2本目だけの人は、「伸びてるから大丈夫」で止まります。伸びていても、間に合わなければ、届きません。

だから、2本とも使います。1本目で、まだ足りないことを冷静に見る。2本目で、1ミリでも進んだことを、ちゃんと見る。

結果が出るまでは、よろこばない。そういう人もいます。その厳しさは、強さです。でも、==進んだことに気づける==のも、同じくらい大事な力です。手ごたえがない日も、少しずつ、積み上がっています。それが見えている人が、最後まで続きます。

### 下がったのは、やり方です。人ではありません

比べる相手を変えても、先週の自分に負ける日があります。

模試が返ってきて、前回より20点下がっていました。この2ヶ月、前よりやったのに下がりました。やっぱり自分には向いてないのかもしれない。その日は、勉強できませんでした。

点が下がった時、考えられることは2つです。やり方が合っていなかったか、その回がたまたま難しかったか。==どちらも、やり方か、テストの問題の話です。あなたという人の話ではありません。== でも下がった瞬間に出てくる言葉は、たいてい、自分という人の話です。向いてない、頭が悪い、才能がない。これを言っても、次にやることが1つも決まりません。

一番の問題は、責めると成績表を見なくなることです。見るとつらいので、ファイルにしまって開かなくなる。どこで落としたかがわからないまま、次も同じところで落とします。==責めることが、直すのを止めています。==

だから、質問の形に変えます。「自分がダメだ」を「どこが下がった?」に。質問にすると、見るものが、「自分という人」から「点を落とした場所」に移ります。見るのは総合点ではなく大問ごとです。英語マイナス12、数学マイナス15、国語プラス7。言葉が「向いてない」から「長文が落ちた」に変わります。長文が落ちたなら、長文を見ればいい。「向いていない」には、やることがありません。

そして、国語は上がっています。20点下がったという見方をすると、この7点は見えません。上がったところには理由があって、その理由は他の科目にも使えます。

やり方が悪かったこともあります。その場合も、責める必要はありません。この本にある50のうち、1つを変えてみてください。==やり方は変えられます。人は、変えなくていいです。==

## 頭のいい人と伸びない人の違い

伸びない人
友達と比べる
あの子は8割。自分は……

頭のいい人
先週と比べる
前より、何点上がった？

## 今日からできる3STEP

題：頭のいい人の『比べ方』3STEP

STEP01

「42、48、55」

STEP02

「前より7点、上がってる」

「あと20点。週に2点ずつ」

## できた基準

## まとめ

```
　　2　比べるのをやめる必要はない。相手を変える
```

だから、友達と比べない。先週の自分と比べる。

# 44　不安を考えないようにする

## 質問ページ

頭のいい人が絶対やらないこと
「不安を考えないようにする」
じゃあ、何をするの？

## 本文

夜の10時。参考書を開いています。目は、字を追っています。でも、頭は、別のことを考えています。

　　このやり方で、合ってるのかな。
　　このままで、間に合うのかな。

こんな時、あなたなら、どうしますか？

　　「考えるな。考えるな。集中しろ」

1時間たちました。進んだのは、3ページです。机には、いました。参考書も、開いていました。それでも、頭は1時間ずっと、答えの出ない問いを、考え続けていました。

### 不安は、今、答えが出ない問いです

ここが、一番大事なところです。「このやり方で合ってるのか」という問いに、今、答えは出ません。やってみて、テストを受けて、点を見るまで出ないからです。出ないものを考え続けると、==考えるだけで終わります。==そして、考えている間は勉強している感じがします。真剣だからです。だから、止まっていることに気づけません。

```
　　答えが出る問い　　「この問題の答えは?」　　　→　解けば出る
　　答えが出ない問い　「このやり方は正しい?」　  →　やってみるまで出ない
```

下の問いを机の前でぐるぐる考えていると、時間だけが減ります。

### 不安が強い人ほど、真面目です

先に言っておきます。

```
　3　使えそうな定理や公式の名前を書く
```

この3つは、たいてい書けます。かける時間は、2分です。無理につなげようとしないでください。書けるところまで書いて、次に行きます。解けない問題を全部白紙にすると、0点です。それぞれで3点から5点拾うと、合計で10点から15点になります。これは、新しいことを覚えなくても取れる点です。今持っている知識のままで、書き方を変えるだけで取れます。選択問題でも、同じです。マークシートなら、必ず塗ります。4択なら25パーセントで当たります。明らかに違う選択肢を1つ消せれば33パーセント、2つ消せれば50パーセントです。

### 気をつけること

マークシートの場合、解く順番を変えると、塗る場所がズレる危険があります。解いた問題の番号を、必ず確認してください。飛ばした問題のマークを、空けておくのを忘れないでください。ここだけは、慎重にやります。

## まとめ

1番から順に解くと、後ろにある解ける問題に、時間が残らない。

```
　　1　最初の1分で、全部めくる
　　2　知っていれば解ける問題を、先に全部終わらせる
　　3　時間がかかる問題に、残りの時間を使う
```

だから、1番から順に解かない。解ける問題から解く。
