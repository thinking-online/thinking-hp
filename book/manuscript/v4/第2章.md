# 第2章　【インプット】頭のいい人は、「入れるだけ」で終わらない
頭の中に知識を入れる

## 章の導入文

### 次の文の中に、「の」は、何個ありますか？

　　昨日の夜、ぼくの兄の友達の犬が、となりの家の庭の池に落ちた。兄の友達は、あわてて、池の中の犬を助けた。

数えてください。

……

10個です。

では、文を手で隠して、答えてください。誰の犬が、どこに、落ちましたか。

……

出てこなかった人が、多いと思います。

目は、全部の字を、通りました。1字も、飛ばしていません。それでも、中身は、頭に入っていません。

今度は、「誰が、何をしたか」を意識して、もう一度、読んでみてください。

……

すっと、入ったはずです。

同じ文です。読んだ時間も、ほとんど同じです。違うのは、==読む時に、何を意識していたか==だけです。

インプットは、「どれだけ見たか」「どれだけ聞いたか」では、決まりません。その時、頭が、何に向いていたかで、決まります。意識する所を間違えると、目の前を通っても、頭には入りません。間違って入ったものは、間違ったまま、残ります。

授業中に、黒板を写すことを意識している。教科書を読む時に、最後のページまで行くことを意識している。単語を覚える時に、書いた回数を意識している。どれも、「の」を数えているのと、同じです。

第3章では、頭に入れたものを、取り出す話をします。でも、入っていないものは、取り出せません。だから、先に、入れ方です。

この章では、==インプットの時に、何を意識すればいいのか==を、書いていきます。前半の5つが、わかるための入れ方（理解編）。後半の4つが、覚えるための入れ方（暗記編）です。

理解編は、最初の2つが、どの場面でも使う意識です。人に教えるつもりで入れる（07番）。先に、全体をつかむ（08番）。あとの3つは、場面ごとのやり方です。授業（09番）。文章を読む時（10番）。家で勉強する時（11番）。

# 07　人に説明できないまま、次へ進む

## 質問ページ

頭のいい人が絶対やらないこと
「わかったつもりで次へ」
じゃあ、何をするの？

## 本文

### ファスナーは、どうやって閉まるのか。説明できますか？

制服にも、カバンにも、筆箱にも、ついています。毎日、使っています。

では、あのつまみを上げると、どうして、左右の歯がかみ合うのか。小学生に教えるつもりで、30秒、説明してみてください。

……

「えーと、ギザギザが、こう……」。そこで止まった人が、ほとんどだと思います。

知らなかったわけでは、ありません。何百回も使っているので、「知っている」つもりでした。説明しようとして初めて、言葉にならないことに気づきます。

勉強でも、同じことが起きています。授業で「わかった」と思ったのに、友達に「今日、何やったの？」と聞かれると、言葉になりません。

### 説明できないものは、まだ「知っている」だけです

頭のいい人は、「わかった」を3つに分けています。

```
　　知っている　　聞いたことがある。見れば思い出す
　　わかっている　何も見ずに、自分の言葉で説明できる
　　使える　　　　テストで、形を変えて出されても解ける
```

授業を聞いて「わかった」と思った時、ほとんどの場合は、1段目です。テストで点になるのは、3段目だけです。そして、2段目を通らずに、3段目には行けません。

　　==人に説明できない　＝　まだ、わかっていない==

### 教えるつもりで入れるだけで、変わります

面白い実験があります。同じ文章を、2つのグループに読んでもらいます。片方には「あとでテストをします」、もう片方には「あとで、この内容を人に教えてもらいます」と伝えます。実際には、どちらも、誰にも教えません。

結果は、==教えるつもりで読んだグループのほうが、よく覚えていました。==どこが大事か、どういう順番で話すかを、読みながら、勝手に考えるからです。

第2章の最初に、インプットは、その時、何を意識していたかで決まる、と書きました。==意識するのは、「あとで、人に教える」です。==

### 型を、入れる「前」に書きます

でも、つもり、と言われても、頭の中で、何をすればいいのか。勉強が苦手な人ほど、ここで止まります。だから、型を使います。僕が、生徒に実際にやってもらっているやり方です。==「KW言語化勉強法」==と呼んでいます。KWは、キーワードのことです。

```
　　結局、【　　　　　　　　　　】の話。
　　キーワードは、【　　　】【　　　】【　　　】。
```

一番大事なのは、順番です。==この2行を、入れる「前」に、ノートのすみに書きます。==空いている枠があると、人の頭は、埋めたくなります。授業を聞いている間も、教科書を読んでいる間も、「結局、何の話だろう」「大事な言葉は、どれだろう」と、探しながら入れることになります。

入れ終わったら、閉じて、3つの言葉を使って、30秒で説明します。光合成なら、こうです。

```
　　結局、【植物が、自分で養分を作る】話。
　　キーワードは、【光】【二酸化炭素と水】【デンプンと酸素】。
　　「光合成は、植物が光を使って、二酸化炭素と水から、
　　　デンプンなどの養分を作ること。その時、酸素が出る」
```

枠は、3つしかありません。大事なものと、細かいものを、分けるしかなくなります。これが、選ぶ力です。そして、3つの言葉を、自分でつなげて、1つの話に組み立て直します。これが、つなげる力です。==選んで、つなげる。==これが、「説明する」ということの中身です。

### 声に出します。相手がいなくても、できます

巻頭で出した質問に、ここで答えます。声に出すのか、心の中でいいのか。==声に出します。==心の中だと、止まったことを、自分でごまかせるからです。途中で止まったら、止まったところだけ開いて見て、閉じて、少し前から、もう一度言います。

見開き2ページを、全部説明しようとしないでください。教科書の小見出し1つぶん。授業なら、黒板1枚ぶん。小さく区切って、1つずつ、型を埋めます。

相手は、ぬいぐるみでも、壁でも、スマホの録音でもいいです。AIに向かって説明するのも、いい方法です。型を埋めて、30秒の説明を書いたら、こう頼みます。

　　「光合成を、次のように理解しました。合っていますか。違っている所があれば、答えは言わずに、どの点を、何を意識して復習すればいいかだけ、教えてください」

答えをもらうのでは、ありません。自分の説明を、直してもらいます。（AIの使い方は、42番に書きます）

型を書いた紙は、捨てないでください。電車の中で、キーワードの3つだけを見て、30秒の説明をもう一度言えば、復習になります。出てこなかったら、そこが、まだわかっていない場所です。このあとの09番、10番、11番は、この型を、場面ごとに使う話です。

# 08　1ページ目から、順番に読む

## 質問ページ

頭のいい人が絶対やらないこと
「1ページ目から順番に」
じゃあ、何をするの？

## 本文

### 次の文を、読んでください。何の話か、わかりますか？

```
　　まず、人数を数えます。
　　同じ量になるように、1つずつ、分けていきます。
　　最初に多く入れすぎると、最後に、足りなくなります。
　　全員に行きわたったら、残りを、ほしい人で分けます。
　　終わったら、決まった場所に、戻します。
```

……

何の話か、わからなかったと思います。知らない言葉は、1つもないのに、です。

題は、「給食当番」です。

もう一度、読んでみてください。同じ文が、今度は、すっと入ってきます。

==先に全体を知っていると、同じ文が、読めるようになります。==知らないまま読むと、1行1行は読めても、何の話なのかが、つかめません。

新しい参考書を買った時にも、同じことが起きています。日本史の、300ページある1冊。「1ページ目から、丁寧に読んでいこう」。1か月たちました。まだ、平安時代です。縄文時代は、もう、ほとんど忘れています。そして、この本が、全部でどんな話なのかは、まだ知りません。

全体を知らないまま読むと、==今読んでいる所が、全体のどこなのかが、わかりません。==どこが大事なのかも、わかりません。だから、全部が同じ大事さに見えて、全部を丁寧に読むことになります。

### 先に、5分で、最後までめくります

読む前に、5分だけ使います。中身は、読みません。==見るのは、「何が、どの順番で並んでいるか」だけです。==さっきの日本史の1冊なら、こうなります。

```
　　目次を読む　　　　　「全部で6章。古い時代から、順番に並んでいる」
　　最後までめくる　　　「前半は、貴族の話。後半は、武士の話が多い」
　　閉じて、3つで言う　「時代は、6つ。前半は貴族、後半は武士」
```

目次では、章の題を、声に出して読みます。めくる時に見るのは、見出しと、太字と、図だけです。わからなくて、いいです。

そのあとで、1ページ目から読みます。同じページでも、見え方が変わります。「これは、あとで出てくる武士の話の、準備だな」。今読んでいる所が、全体のどこなのかが、わかるからです。

歴史なら、先に、マンガや年表で、流れを最後まで見ておきます。数学なら、章の最初に、例題の題だけを、全部見ておきます。英語の長文なら、先に、設問を見ておきます。全部、先に、全体を見ています。

### 1周目は、薄く、最後まで行きます

読み始めてからも、同じ考え方を使います。

```
　　×　1章を完璧にしてから、2章へ　　　　　→　最後の章に着くのは、何か月もあと。そのころ、1章は忘れている
　　○　薄く、最後まで1周してから、2周目へ　→　全体を知った上で、細かい所を読める
```

絶対法則06で書いた通り、1回目から完璧にする必要は、ありません。絶対法則05で書いた通り、同じ所は、別の日に、もう一度やります。1周目は、「何が書いてあるか」を知るための周です。

わからないまま進むのは、気持ち悪いと思います。その気持ちは、まともです。ただ、最初の章でわからなかったことが、あとの章を読んだら、わかる。そういうことは、よくあります。全体を知らないと、わからない所だったからです。

わからない所には、ふせんを貼って、先へ進んでください。2周目に戻ってきた時には、いくつかは、もう、わかるようになっています。

# 09　授業を、聞く時間だと思っている

## 質問ページ

頭のいい人が絶対やらないこと
「授業は聞くだけ」
じゃあ、何をするの？

## 本文

### 授業の最初に、先生がこう言ったら、聞き方は変わりますか？

　　「今日の授業の終わりに、1人、前に出てもらいます。今日の内容を、30秒で、みんなに説明してもらいます。誰に当てるかは、最後に決めます」

……

変わりますよね。

同じ先生の、同じ50分です。それでも、聞き方が、まるで変わります。大事な所を、探しながら聞きます。わからない所を、そのままにできません。ノートに書くことも、変わります。

先生の話は、1つも変わっていません。変わったのは、==「あとで、自分が説明する」と決まったこと==だけです。

ふだんの授業では、誰も、そう言ってくれません。だから、ちゃんと聞いているのに、その日の夜、同じ範囲のワークを開くと、1問目で手が止まります。「明日は、もっと集中して聞こう」。そう決めて、次の日も、同じことが起きます。

### 「ちゃんと聞く」だけでは、話が、通っていくだけです

授業中の頭の使い方は、3つに分けられます。

```
　　聞くだけ　　　先生の言葉が、耳を通っていく
　　写す　　　　　黒板の字を、ノートに運ぶ。手は動く。頭は、字を運んでいるだけ
　　自分で作る　　大事な所を選ぶ。自分の言葉にする。次を予想する
```

下に行くほど、頭に残ります。「集中して聞く」は、どれだけ頑張っても、1つ目です。先生の説明は、わかりやすく作られています。だから、聞いている間は、すっと通ります。「わかった」と感じます。でも、絶対法則01で見た通り、「わかった感じ」と、頭に残ったことは、別です。

### 「終わったら、30秒で人に教える」と決めてから、聞きます

頭を「自分で作る」に向ける決まりは、1つです。

　　==授業が終わったら、30秒で、人に教える。そう決めてから、聞く。==

先生は、当ててくれません。だから、毎回、自分で自分に当てます。教える相手は、今日休んだ友達でも、家の人でも、かまいません。いなければ、頭の中の相手で十分です。07番で書いた通り、教える「つもり」になるだけで、入り方が変わります。

### 50分の中で、やることは3つです

「教えるつもり」を、授業の前、途中、あとに、1つずつ置きます。歴史の授業（鎌倉時代）なら、ノートは、こうなります。

```
　　始まる前　　　結局、【　　　　　　】の話。キーワードは、【　】【　】【　】。
　　15分　　　　　頼朝／鎌倉／御家人
　　30分　　　　　御恩と奉公／土地／？
　　45分　　　　　北条氏／執権／承久の乱
　　終わった直後　結局、【頼朝が、鎌倉に、武士の政府を作った】話。
　　　　　　　　　キーワードは、【頼朝】【御恩と奉公】【執権】。
```

1つ目。始まる前に、10秒。ノートの一番上に、07番の型を書きます。空いた枠があると、50分の間、それを埋めるものを、探しながら聞くことになります。

2つ目。15分に1回、30秒。ここまでの話を、言葉3つで、ノートのすみに書きます。黒板も、ノートも、見ません。50分の最後に、初めて思い出そうとすると、前半は、もう出てこないからです。出てこなかったら、「？」を1つ書いておきます。そこが、休み時間に確かめる所です。

先生が黒板に書いている間や、プリントを配っている間に、やってください。15分ちょうどでなくて、いいです。ハーバード大学の研究者たちの実験でも、授業の映像の途中に、短いテストをはさんだグループは、==ぼんやりしていた時間が減って、最後のテストの点も高くなりました。==

3つ目。チャイムが鳴ったら、教科書をしまう前に、30秒。15分ごとに書いた言葉の中から、キーワードを3つ選んで、型を埋めます。その3つを使って、「今日は、結局、こういう話」を、頭の中の相手に教えます。型が埋まって、30秒で言えたら、今日の授業は、入っています。

### ノートには、「教える時のヒント」だけを書きます

黒板を、全部写す人が多いです。でも、黒板に書いてあることは、教科書や問題集にも、だいたい載っています。あとで、何回でも見られます。先生が口で言ったことは、その場で聞きのがしたら、もう聞けません。全部写している人は、==あとで見られるほうを一生けんめい写して、その場でしか聞けないほうを、聞きのがしています。==

説明の間は、ペンを置いて聞きます。書くのは、あとで教える時の、ヒントだけです。

```
　　先生が口で言ったこと　　　「aで割る前に、a=0を確かめる」「ここ、テストに出す」
　　最初の一手と、その理由　　「まず、yについて解く。文字を1つにするため」
　　「？」と「！」　　　　　　わからなかった所。予想が外れた所
```

「！」は、予想が外れた所です。先生が「なぜだと思う？」と聞いたら、当てられていなくても、心の中で、先に答えます。外れて、かまいません。予想してから聞いた答えは、ただ聞いた答えと、残り方が違います。

1つの例題に、3行まで。図だけは、写してください。グラフや地図は、手で描いたほうが、頭に入ります。

数学や理科の例題は、30秒で教えるかわりに、その日のうちに、1問、白紙から解きます。解き方は、言葉で言うより、手で再現したほうが、確かめやすいからです。（16番に書きます）

### 映像授業は、止めて、教えます

映像授業には、教室にないものが、1つあります。止められることです。

```
　　10分たったら　　　　　　→　止める。ここまでを、声に出して教える
　　先生が問題を出した直後　→　止める。答えを見る前に、自分で解く
```

倍速にすると、入る速さは上がります。でも、頭が自分で作った回数は、0のままです。1周目は、普通の速さで、止めながら。倍速は、2周目からです。==倍速の正しい使い道は、速く入れることではなく、速く確かめることです。==

# 14　黙って、じっと見つめて覚える

## 質問ページ

頭のいい人が絶対やらないこと
「見つめて覚える」
じゃあ、何をするの？

## 本文

### 家の玄関に、今、靴は何足、出ていますか？

思い浮かべて、数えてみてください。

……

数えている間、目は、どこを見ていましたか。

この本から目を離して、上か、遠くを見たはずです。目を閉じた人も、いると思います。

人は、何かを思い出そうとする時、目の前のものから、目を離します。目に入ってくるものが、じゃまになるからです。

逆に言うと、==教材をじっと見つめている間、頭は、思い出していません。==

歴史のテストが、近づいています。「集中して、じっと見ていれば、頭に入るはず」。教科書を開いて、黙って、見つめます。目は、同じ行の上を、何度もすべっています。20分たって、教科書を閉じます。何が書いてあったか、言おうとしても、出てきません。

### 見つめている間、頭は受け取っているだけです

じっと見るのは、真面目な人ほどやります。静かで、集中しているように見えます。本人も、集中しているつもりです。

でも、やっていることは「入れる」だけです。絶対法則02で書いた通り、点になるのは「思い出して、出す」ほうでした。

では、思い出す時、体をどう使えばいいのか。ここが、この項目の話です。使うのは、==目と、口==です。

### 目を閉じると、思い出しやすくなります

イギリスのヨーク大学の研究者たちの実験です。

映像を見てもらって、そのあと内容を思い出してもらいます。片方のグループには、目を開けたまま思い出してもらいました。もう片方には、目を閉じて思い出してもらいました。

目を閉じたグループのほうが、==見たものも、聞いたものも、正確に思い出せました。==

理由は、単純です。目を開けていると、目の前のものが、ずっと頭に入ってきます。机の上、壁のポスター、窓の外。見るつもりがなくても、頭は、それを全部受け取っています。目を閉じると、それが止まります。そのぶん、頭を、思い出すことに使えます。

教材を見つめたまま「思い出そう」としても、目に答えが入ってきてしまいます。それは、思い出しているのではなく、見ているだけです。

### 声に出すと、残りやすくなります

もう1つは、口です。カナダのウォータールー大学の研究者たちの実験です。

単語のリストを覚えてもらいます。半分の単語は、声に出して読む。もう半分は、黙って読む。あとでテストをすると、==声に出した単語のほうが、よく覚えていました。==

声に出すと、口が動きます。自分の声が、耳から入ってきます。黙って読む時は目だけですが、声に出すと、目と口と耳を使います。思い出す時の手がかりが、増えるんです。

そして、声にはもう1つ、いいところがあります。頭の中で言うと、言えたかどうかを、自分でごまかせます。声は、出てこなければ止まります。==ごまかせません。==

### 2つを、1つの動作にします

```
　　×　教材を開いたまま、黙って、見つめる
　　○　教材を閉じて、目も閉じて、声に出す
```

本を閉じる。目を閉じる。声に出す。これで、1つの動作です。

見つめる人は、教材に向かっています。頭のいい人は、教材から顔を上げています。自習室や図書館で、時々天井を見ている人がいますよね。あれは、さぼっているのではありません。思い出しています。

### 声を出せない場所では

電車の中や、図書館では、声が出せません。

その時は、口だけ動かします。声ほどではありませんが、黙って眺めているよりは残ります。家に帰ったら、声に出します。家で黙って勉強するのは、もったいないです。

# 15　用語を、1つずつバラバラに覚える

## 質問ページ

頭のいい人が絶対やらないこと
「バラバラに覚える」
じゃあ、何をするの？

## 本文

### 1週間前の夜、何を食べましたか？

思い出してみてください。

……

出てこないはずです。

では、聞き方を変えます。1週間前は、何曜日でしたか。その日、誰と一緒にいましたか。部活は、ありましたか。帰りは、何時でしたか。

……

出てきませんか。

### 記憶は、1個では取り出せません

思い出せなかったのは、忘れたからではありません。引っぱり出すための取っ手が、なかったからです。

人の頭は、1個だけポツンと置かれたものを取り出せません。取り出せるのは、何かにくっついているものだけです。「曜日」「誰と」「部活」が取っ手になって、晩ごはんが出てきました。晩ごはん自体は、ずっとそこにありました。つかむところが、なかっただけです。

### 1個ずつ覚えると、取っ手がゼロになります

単語帳を1ページ目から、1語ずつ覚える。年号を、1つずつ覚える。公式を、1個ずつ覚える。

丁寧で、真面目なやり方に見えます。でも全部、取っ手のない状態で置いています。

```
　　available　　利用できる
　　capable　　　能力がある
　　reliable　　 信頼できる
```

1語1訳で、3つをばらばらに覚えた人は、1つ忘れたら、その1語は出てきません。-able が同じだと気づいた人は、1語思い出せたら、残り2語も一緒に出てきます。

### 頭が一度に持てるのは、4つくらいです

もう1つ、理由があります。

人が一度に頭の中に置いておけるものは、多くありません。だいたい4つ前後と言われています。ばらばらの11個は、持てません。

巻頭の数字を思い出してください。

```
　　1　4　9　1　6　2　5　3　6　4　9　　　ばらばらなら、11個
　　1×1　2×2　3×3　……　7×7　　　　　　　まとまりにしたら、1個
```

あの時、記憶力は1ミリも変わっていませんでした。変わったのは、==11個を、1つのまとまりにしたこと==だけです。

まとまりにすると、頭の中の場所を1つしか使いません。だから、同じ頭で、沢山持てます。

### 似ているものは、違いだけ覚えます

つなげると、覚える量そのものが減ります。

似ている3つを、3つとも別々に覚える人は、3個覚えます。同じところを1つにまとめて、違うところ1か所だけ覚える人は、ほとんど1個で済みます。

```
　　×　鎌倉幕府、室町幕府、江戸幕府を、別々に覚える
　　○　「武士が政治をする仕組み」が3回。違うのは、場所と、武士のまとめ方
```

### 文字だけでわからない時は、絵か、たとえにします

つなげる先は、教科書の中だけではありません。

文字だけ読んでも入ってこないものは、絵にします。図にします。自分の好きなものに、たとえます。電流を水の流れにたとえる。細胞を工場にたとえる。歴史の対立を、部活のチーム分けにたとえる。

自分の知っているものにくっついた瞬間に、取っ手ができます。たとえが思いつかない時は、AIに「サッカーでたとえて」「中学生にもわかるように絵で説明して」と頼んでいいです。（AIの使い方は、43番でやります）
