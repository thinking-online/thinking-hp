# 第3章　【アウトプット】頭のいい人は、解けた問題を数えない
頭の中の知識を取り出す

## 章の導入文

### 一番最近やった問題集。○は、何問でしたか？

……

だいたい、答えられたと思います。「10問中、8問」。

では、×だった問題は、どんな問題でしたか。1つ、言ってみてください。

……

出てこなかった人が、多いと思います。

○の数は、覚えています。×の中身は、覚えていません。

でも、10問中8問の○は、解く前から解けた問題です。解いても、点は、1点も増えていません。点が増えるのは、×だった2問を、○に変えた時だけです。

頭のいい人は、解けた問題を、数えていません。==解けなかった問題を、どう扱うか==だけを見ています。

第2章で、頭に入れました。この章では、それを、取り出します。使うのは、主に、絶対法則03の「負荷」と、絶対法則06の「速度」です。×がつく所が、伸びる所。早く解いて、早く×を見つけて、早く直します。

点が動くのは、この章です。前半の5つが、問題の解き方。後半の4つが、解いたあとの復習の仕方です。

# 16　解説を読んで、「わかった」で終わる

## しないこと、すること

頭のいい人は、「解説を読んで、『わかった』で終わる」をしない。
かわりに、「閉じて、白紙に、最初から再現する」をする。

## 本文

### 1から100までを、全部足すと、いくつですか？

解き方を、書きます。

```
　　1と100を足すと、101。2と99を足しても、101。
　　こういうペアが、50組できる。
　　だから、101×50＝5050。
```

「なるほど」と、思いましたね。

では、上の3行を手で隠して、解いてください。

　　1から40までを、全部足すと、いくつですか。

……

答えは、820です。（41×20）

「ペアは、何組だっけ」。そこで、手が止まりませんでしたか。

解き方を読んで、「なるほど」と思いました。それでも、数字が変わっただけで、止まります。

問題集の解説を読んだあとにも、同じことが起きています。「なるほど、わかった。次」。赤ペンで答えを写して、次の問題へ進みます。1週間後。同じ問題が、小テストに出ました。最初の1行が、書けません。

### 解説を読んでいる間、決めているのは、解説のほうです

解説を読んで「わかった」時、やっていたことは、何でしょうか。

人が解いた道を、後ろから、ついて歩いただけです。

```
　　わかる　　解説の1行1行に、「うん、そうなる」と言える
　　できる　　何も見ずに、最初の1行から、自分で書ける
```

道案内をしてもらって着いた場所に、次の日、1人で行けるとは、かぎりません。「次、どっちに曲がるか」を、自分で決めていないからです。

解説も、同じです。一番難しいのは、「最初に、何をするか」を、自分で決める所です。解説を読んでいる間、そこは、解説が決めてくれています。

テストで聞かれるのは、「できる」のほうだけです。

### 解説を閉じて、白紙に、最初から書きます

やることは、1つです。

==解説を読んだら、閉じます。白紙に、最初の1行から、自分で書きます。==

これを、「白紙再現」と呼びます。絶対法則02の「思い出す」を、問題でやっているだけです。さっきの「1から40まで」なら、白紙は、こうなります。

```
　　1行目　1と40を足すと、41。2と39でも、41。
　　2行目　ペアは……（手が止まった。ここに印）
　　　→　止まった所だけ、解説を見る。「100までで、50組」
　　　→　閉じて、最初から、もう一度書く
　　1行目　1と40を足すと、41。2と39でも、41。
　　2行目　ペアは、40の半分で、20組。
　　3行目　41×20＝820。
```

解説は、わかるまで読んでいいです。閉じたら、答えも、途中の式も、見えないようにします。

やってみると、驚くと思います。「わかった」はずなのに、途中で、手が止まります。==手が止まった所が、本当は、わかっていなかった所です。==解説を読んでいるだけでは、そこは、見つかりません。

### 写すのとは、違います

解説を見ながら、ノートに書き写す。これは、白紙再現では、ありません。写している間、頭は、「次に何をするか」を、1回も決めていません。きれいな解答が、ノートに残ります。でも、頭には、残っていません。

見るのは、止まった時だけ。そして、見たら、もう一度、閉じます。

### 数学だけでは、ありません

```
　　数学・理科の計算　解説を閉じて、最初の式から書く
　　英語の長文　　　　和訳を閉じて、線を引いた文を、自分で訳す
　　社会・理科の説明　教科書を閉じて、「なぜ、そうなったか」を書く
　　授業の例題　　　　その日のうちに、白紙から解く（11番）
```

全部の問題で、やる必要はありません。==解説を読んで、「わかった」と思った問題だけ==で、いいです。自分で解けた問題は、もう、できています。

### 別の日に、もう一度だけ

解説を閉じたすぐあとは、まだ、頭に解説が残っています。だから、書けて当然、という面もあります。

絶対法則05で決めた通り、同じ問題を、別の日に、もう一度、白紙から解きます。そこで書けたら、その問題は、「できる」になっています。

## 頭のいい人と伸びない人の違い

伸びない人
読んで終わり
なるほど、わかった。次

頭のいい人
白紙に書く
閉じて、自分で書ける？

## 今日からできる3STEP

STEP01　解説を読んだら、閉じて、白紙を出す
STEP02　最初の1行から書いて、止まった所に印
STEP03　止まった所だけ見て、閉じて、もう一度
「できた」の基準：解説を閉じて、最初から最後まで、白紙に書けたらOK！

## まとめ

解説を読んで「わかる」と、自分で「できる」の間には、段差がある。
だから、「わかった」で終わらない。閉じて、白紙に、最初から書く。
迷ったら、自分に聞きます。「これ、白紙に書ける？」

# 17　参考書を読み終えてから、問題集を開く

## しないこと、すること

頭のいい人は、「参考書を読み終えてから、問題集を開く」をしない。
かわりに、「問題集と過去問を先に開いて、わからない所だけ調べる」をする。

## 本文

### バスの問題です。読んでください

```
　　バスに、5人乗っています。
　　最初のバス停で、3人乗って、2人降りました。
　　次のバス停で、4人乗って、1人降りました。
　　その次のバス停で、2人降りました。
```

では、問題です。

　　バス停は、いくつ、ありましたか。

……

乗っている人の数を、数えていませんでしたか。

聞かれることを、先に知っていたら、数えるものが違ったはずです。

勉強でも、同じことが起きています。何を聞かれるかを知らないまま、参考書を、1ページ目から読んでいる。何を聞かれるかは、過去問と問題集に、書いてあります。

高校3年生の6月。志望校の赤本を、買いました。めくってみましたが、1問も解けません。

　　「今やっても解けない。力がついてから、腕試しに解こう」

本棚に、立てました。今やっても解けないから、意味がない。過去問は数が限られているので、使い切りたくない。腕試しは、力がついてからのほうが、正確に測れる。理由は、どれも、まともです。

それでも、11月に、こうなります。過去問を解き始めて、2日目。大問3を見て、気づきます。この学部には、この分野が、一度も出ていない。夏の2ヶ月、そこをやっていました。

### 試験には、範囲があります

問題集は、解くための本です。だから「解けるようになってから使う」が正しい。本棚に立てた判断は、問題集に対しては、正しいのです。でも、過去問は問題集ではありません。

試験には、出るものと出ないものがあります。受験も、定期テストも、そうです。出題する側は、時間も配点も決まっているので、どこを出すかを決めてから作ります。そして、どこが出て、どこが出ないかが書いてある紙は、1種類しかありません。過去問です。

出ない分野を3ヶ月やっても、点は1点も増えません。努力が足りなかったという話ではありません。努力した場所が、採点されない場所だった、という話です。

### 最初の15分で、「やる分野」と「やらない分野」を分けます

過去問は、解く前に、見ます。この15分では、1問も解きません。見て、書き出すだけです。解く分は、あとに取っておけます。

過去問を3年分開いて、大問ごとに、分野と配点を書き出します。次に、今使っている参考書の目次を、横に並べます。そして、3年分に一度も出ていない分野に、線を引きます。数学なら、こうなります。

```
　　参考書の目次　　3年前　2年前　去年
　　2次関数　　　　　○　　　○　　　○　　毎年出る。配点も大きい
　　確率　　　　　　　○　　　　　　　○　　やる
　　図形と計量　　　　　　　　○　　　　　　やる
　　データの分析　　　　　　　　　　　　　　線を引く。今はやらない
```

線を引かなかった所が、やる場所です。

1年分だけで決めないでください。1年だけ出ていなかった分野を捨てると、翌年に出ます。3年分、できれば5年分見ます。同じ大学でも、学部で出題が変わります。同じ県でも、高校で変わります。自分が受けるところの過去問を見てください。

捨てたのは「今はやらない」であって「永久にやらない」ではありません。線を引いた紙は、取っておきます。余裕ができたら、そこから戻します。3年分を目で並べるのが手間なら、書き出した紙を、AIに渡して、分けてもらえます。分け方が出てきたら、自分の目で、1回確かめてください。

### 問題集も、同じです。参考書を読み終える前に、開きます

参考書を最後まで読んでから、問題集を開く。その順番だと、絶対法則06で見た通り、どこがわかっていないのかが、いつまでもわかりません。先に、問題集を開きます。解けなくて、かまいません。

```
　　全部読んでから、解く　→　どの行も同じに見える。どこが大事か、わからない
　　先に問題を見てから、読む　→　「さっきのあれは、ここか」と、探しながら読む
```

問題を先に見た人は、何を探して読めばいいかを、知っています。参考書は、最初から最後まで読む本では、なくなります。==わからなかった所を調べる、辞書になります。==

先に解くと、×だらけになります。それが嫌で、先に全部読もうとする人が多いです。でも、その×は、予定通りです。×がついた所だけを、参考書で調べます。

まったく習っていない単元なら、解くのは、1問だけで十分です。3分考えて、「たぶん、こう」を1行書く。それから、読みます。

### 調べていて止まった時も、1ページ目には戻りません

参考書を進めていると、止まるページが出てきます。78ページの応用問題。解説を読んでも、何を言っているのかわかりません。基礎が抜けているのかもしれない、と思って、1ページ目に戻りたくなります。戻るという判断は、正しいです。手前に原因があることは、よくあります。問題は、どこまで戻るかです。

　　わかった最後の場所を探す。

78ページがわからないなら、77ページはわかりますか。わかるなら、原因は78ページの中にあります。77ページもわからないなら、70ページはどうですか。たいていは、3ページから10ページ戻れば見つかります。

範囲の時は、出ないところに線を引きました。つまずいた時は、わかっているところに線を引きます。残ったところだけをやります。

## 頭のいい人と伸びない人の違い

伸びない人
過去問は最後
今解いても、解けないし

頭のいい人
過去問は最初
何が出るか、先に見よう

## 今日からできる3STEP

STEP01　過去問を3年分開いて、配点と分野を書き出す
STEP02　今使っている参考書の目次を、横に並べる
STEP03　3年分に一度も出ていない分野に、線を引く
「できた」の基準：15分で、「やる分野」と「やらない分野」が分かれたらOK！

## まとめ

過去問は、力試しの本ではなく、やらないことを決める本。
だから、過去問も問題集も、最後ではなく、最初に開く。
迷ったら、自分に聞きます。「何が出るか、もう見た？」

# 18　正解した問題に、○をつけて終わる

## しないこと、すること

頭のいい人は、「正解した問題に、○をつけて終わる」をしない。
かわりに、「ほかの選択肢が、なぜ違うかを言う」をする。

## 本文

### 日本で一番長い川は、どれですか？

```
　　ア　利根川　　イ　信濃川　　ウ　石狩川　　エ　最上川
```

……

答えは、イの信濃川です。正解した人も、多いと思います。

では、もう1問です。

　　アの利根川は、何が、日本一ですか。

……

流域面積（その川に水が集まってくる土地の広さ）です。

1問目に正解した人でも、2問目で止まります。正解の選択肢だけを見て、○をつけたからです。

外れの選択肢は、ただの外れでは、ありません。==次のテストで、正解になるかもしれない選択肢です。==

英語の4択問題でも、同じです。なんとなく、イな気がする。答えを見ると、イ。「よし、合ってた。次」。1週間後、よく似た問題が出ました。今度は、ウを選んで、×でした。

### その○は、当たったのか、わかっていたのか

○には、2種類あります。

```
　　根拠があって選んだ○　　次も、取れる
　　なんとなく選んだ○　　　次は、わからない
```

答え合わせの時、この2つは、同じ○に見えます。赤ペンで丸をつけた瞬間に、どちらだったのかが、わからなくなります。

そして、なんとなくの○は、一番やっかいです。×なら、解説を読みます。○は、読みません。==わかっていないのに、一度も見直されないまま、本番まで行きます。==

### 選ぶ前に、根拠を一言、書きます

==選ぶ前に、根拠を1つ決めます。==「イだ。なぜなら、主語が複数だから」。問題番号の横に、一言で書いておきます。

コロンビア大学の研究者たちが、確かめていることがあります。自信を持って答えて、それが間違いだった時。人は、正しい答えを、普通より強く覚えます。「え、違うの？」という驚きが、記憶を強くするからです。逆に、なんとなく選んで間違えた時は、あまり残りません。

根拠を書いておけば、合っていた時は、その根拠が使えるとわかります。間違っていた時は、「え、違うの？」と驚くので、正しい答えが強く残ります。どちらに転んでも、残ります。

### 選ばなかった3つが、なぜ違うかを、声に出します

4択の問題は、1問に見えます。でも、選択肢は4つあります。答え合わせの時に、4つとも、理由を声に出します。最初の川の問題なら、こうなります。

```
　　選ぶ前の根拠　「長さの日本一は、信濃川と習った」
　　ア　利根川　　ちがう。日本一なのは、流域面積
　　イ　信濃川　　合っている。長さが、日本一
　　ウ　石狩川　　ちがう。北海道の川で、長さは3番目
　　エ　最上川　　ちがう。……理由が、言えない
```

4つとも言えたら、4問ぶんの勉強です。イを選んで○をつけて終わった人は、1問ぶん。しかも、当たっただけかもしれない1問ぶんです。

間違いの選択肢は、適当に作られていません。==多くの人が間違える考え方==を、わざと並べてあります。つまり、選ばなかった3つは、次に自分が引っかかる場所の一覧です。

### 言えなかった○は、△にします

さっきの見本では、エの理由が言えませんでした。答えは合っていても、この問題は、○にしません。

```
　　○　選んだ理由も、他が違う理由も、言えた
　　△　合っていたけれど、理由が言えなかった
　　×　間違えた
```

△は、×と同じ扱いにします。次の日に、もう一度やる問題です。

選択問題でなくても、同じです。数学で答えが合っていた時。途中の式を、説明できますか。記述問題で丸をもらった時。模範解答と、自分の答えの、どこが違うかを言えますか。==なぜ合っていたかまで言えて、初めて○です。==

### 解説に、間違いの理由が書いていない時

問題集によっては、正解の説明しか載っていません。

その時は、AIに聞いていいです。「この問題で、ウが違う理由を、中学生にもわかるように説明して」。答えを聞くのではなく、理由を聞きます。（42番でやります）

問題集を選ぶ時も、ここを見てください。間違いの選択肢について、1つずつ理由が書いてあるもの。それが、いい問題集です。

## 頭のいい人と伸びない人の違い

伸びない人
○で終わり
合ってた。次！

頭のいい人
理由まで言う
他は、なんで違うの？

## 今日からできる3STEP

STEP01　選ぶ前に、根拠を一言、問題番号の横に書く
STEP02　選ばなかった選択肢が、なぜ違うかを声に出す
STEP03　言えなかった問題は△にして、次の日にもう一度
「できた」の基準：全部の選択肢の理由を言えた問題だけを、○にできたらOK！

## まとめ

○には、わかっていた○と、当たっただけの○がある。
だから、○で終わりにしない。理由まで言う。
迷ったら、自分に聞きます。「他は、なんで違うの？」

# 19　時間を測らずに、解けるまで解く

## しないこと、すること

頭のいい人は、「時間を測らずに、解けるまで解く」をしない。
かわりに、「本番と同じ時間で、解けたか」をする。

## 本文

### 10秒で、「さ」で始まる食べ物を、5つ言ってください

心の中で、10数える間です。どうぞ。

……

5つ、言えましたか。

時間がいくらでもあれば、全員、言えます。知らない言葉は、1つもありません。それでも、「10秒で」と言われたとたんに、3つで止まった人も、いると思います。

==知っていることと、時間内に出せることは、別の力です。==テストで測られるのは、あとのほうです。

数学の問題集を、進めています。

```
　　1問目　10分かかったけど、解けた
　　2問目　15分かかったけど、解けた
　　3問目　20分かかったけど、解けた
```

「時間はかかったけど、解けた。全部○」。そうつけました。

模試の日。同じレベルの問題が、大問3つで、制限時間は60分でした。1問目に25分かかって、2問目の途中で、終わりました。

### 時間を測らないと、「できる」が本番とズレます

20分かけて解けた問題は、できる問題でしょうか。

本番で、その問題に20分使えるなら、できる問題です。本番で使えるのが7分なら、できない問題です。同じ問題でも、持ち時間によって、できる・できないが変わります。時間を測らないと、どちらなのかがわかりません。

### 本番の1問あたりの時間を、紙に書いて、机に貼ります

ここで一度、計算してみてください。

　　試験時間　÷　問題数　＝　1問あたりの時間

数学で、60分で大問4つなら、1問15分です。英語で、80分で長文2つと文法30問なら、長文1つに25分です。この数字を知らずに練習している人が、かなりいます。知らないと、何分で解けばいいかがわかりません。計算したら、紙に書いて、机に貼ります。

### タイマーを置いて解いて、○△×をつけます

```
　　○　時間内に、解けた
　　△　解けたが、時間をこえた
　　×　解けなかった
```

本番が1問15分だとして、最初の数学の3問を、つけ直します。

```
　　1問目　10分　○
　　2問目　15分　○
　　3問目　20分　△　原因：最初の式を決めるまでに、8分かかった
```

「全部○」では、ありませんでした。△には、原因を1行書きます。そして、時間内で、もう一度解きます。時間内に解けたものだけが、○です。

# 21　わからない問題を、わかるまで粘る

## しないこと、すること

頭のいい人は、「わからない問題を、わかるまで粘る」をしない。
かわりに、「上限を先に決める。5秒か、3分か、10分か」をする。

## 本文

### オーストラリアの首都は、どこですか？

5秒で、答えてください。

……

答えは、キャンベラです。

出てこなかった人に、聞きます。あと3分考えたら、出たと思いますか。

出ません。知らないものは、いくら考えても、出てこないからです。

英単語を、テストの形で復習している時も、同じです。available の意味が、出てきません。この時、やり方は、2つに分かれます。

```
　　A　すぐに、答えを見る
　　B　思い出せるまで、粘る
```

どちらも、よくあるやり方です。そして、どちらも、うまくいきません。

Aの人は、1秒でページをめくります。「利用できる、か」。次の単語も、出てこなければ、1秒でめくります。30語が、5分で終わります。次の日、同じ30語をやると、同じ所で、同じように出てきません。

Bの人は、1語に3分かけます。それでも、出てきません。30語が、終わりません。

### 考える時間を、解く前に決めます

単語が出てこない時、頭の中では探しています。その単語を見た時の、ページの位置。隣に書いてあった単語。一緒に覚えた例文。色々な方向から、取りに行っています。この「取りに行く」が、思い出す練習です。

1秒でめくると、取りに行く前に終わります。5秒やると、取りに行く動きが入ります。出てこなくても、入ります。自分で探したあとだと、「ああ、それか」と、答えが頭に入りやすくなります。

5秒を超えたら、見てください。30秒考えても、1分考えても、結果は同じです。5秒です。ここは、数えてください。数学の問題は、時間が変わります。

```
　　単語　　　　　　　　　　　　　→　5秒で見る
　　数学で、方針が立たない　　　　→　3分で見る
　　方針は立つが、計算で詰まった　→　10分やる
```

方針というのは、「何をすればいいか」です。何をすればいいかがわからない時は、考えても出ません。3分で見ます。何をすればいいかはわかっていて、計算の途中で詰まった時は、やればできます。ここは粘る価値があります。

### 2つの実験は、どちらも「長く粘るな」と言っています

ロンドンの大学の研究者たちの実験では、知らない言葉の意味を、まず当てずっぽうで答えて、はずしてから正解を見たグループのほうが、最初から正解を見たグループより、あとのテストの成績がよくなりました。

オーストラリアの大学の研究者たちの実験では、逆でした。図形の問題を、自力で解いたグループより、解き方の見本を先に見たグループのほうが、成績がよくなりました。

違いは、かけた時間です。

```
　　はずしてから見た実験　数秒、考えてから見る　　→　残る
　　見本を先に見た実験　　数十分、考えてから見る　→　残らない
```

片方が「0秒はもったいない」、もう片方が「30分はやりすぎ」と言っているだけです。

### 時間が来るまでは、手がかりを探します

数学で、方針が立たない時の、3分。この3分で何をするかが、分かれ目です。

ゼロから考える時、人は、まったく新しい解き方を、自分で発明しようとしています。でも、試験に出る問題は、習った型の組み合わせです。出す側は、習っていないことを出せません。見たことがない、と感じる問題も、よく見ると、知っている型が2つ組み合わさっているだけです。だから、3分でやるのは、発明ではありません。探すことです。

　　知っている型の、どれに似ているか。

```
　　形を見る　　　　2乗がある、分数がある、円と直線が接している
　　数字を見る　　　3、4、5が出てきたら、直角三角形かもしれない
　　聞かれ方を見る　「最大値を求めよ」なら、やることは限られている
```

そのために、準備が1つ要ります。単元ごとに、「この形が出たら、この3つを試す」を紙に書いておきます。

```
　　2乗が出たら　　　平方完成／因数分解／置きかえ
　　分数式が出たら　　通分／部分分数分解
　　図形で角度なら　　平行線／円周角／外角
```

リストがある人は、上から順に試します。考えるのではなく、手を動かして、違ったら次に行きます。解けた問題が増えるたびに、リストに1行足します。初めて見る問題に強い人は、ひらめく力が強いのではありません。「これかもしれない」と試せる型を、沢山持っているのです。

### 時間が来たら見ます。閉じて、もう1回解きます

2つの実験には、同じ所が、1つあります。はずしてから見る実験では、はずしたあとに、正解を見せています。見本を先に見る実験では、見本のあとに、自分で解かせています。考える時間を長くしても、残る量は増えません。増えるのは、==見たあとに自分で出した回数==のほうです。だから、見て終わりにしません。

```
　　単語　5秒、出ない　→　答えを見る　→　隠して、もう1回言う
　　数学　3分、方針が立たない　→　解説を見る
　　　　　→　閉じて、最初の1行から、もう1回解く（16番）
```

見た問題を、その場で、何も見ずに、もう1回解けたら、OKです。

### 1周目は、先に解答を見ていいです

考えること自体は、大事です。ただ、見本を先に見たほうが強かったのは、==その単元を初めてやる人==の時です。ある程度できるようになった人では、逆になります。見本を見るより、自力で解いたほうが伸びます。だから、1周目と3周目で、やることが逆になります。

```
　　1周目　見たことのない型　→　先に解答を見て、閉じて再現する
　　3周目　知っている型　　　→　先に自力で解く。10分やる
```

頭のいい人
3分で答えを見る
見たら、閉じてもう1回

※計算で詰まった時は、10分
STEP02　時間が来るまでは、手がかりを探す

### 2周目の時間の多くを、もう解ける問題に使っています

1周目で、200問のうち、120問が解けたとします。

2周目に、1番から全部解くと、その120問を、もう一度解くことになります。==解く前から、解ける問題です。解いても、点は増えません。==

絶対法則03で見た通り、スラスラ解ける時、頭には、負荷がかかっていません。気持ちはいいですが、伸びてはいません。

```
　　全部、もう1周　　　　200問。そのうち120問は、もう解ける
　　解けなかった所だけ　　 80問。全部が、点が増える問題
```

同じ時間で、下のやり方なら、解けなかった問題を、2回やれます。

それでも、全部やり直す人が多いです。理由は、最初の質問に答えられなかったのと、同じです。==どれが解けて、どれが解けなかったかを、記録していないからです。==

### 1周目から、○△×を、問題番号の横に書きます

記録は、3つの記号だけです。

```
　　○　何も見ずに、時間内に、解けた
　　△　解けたが、時間をこえた。または、たまたま合っていた
　　×　解けなかった
```

問題番号の横に、小さく書きます。日付も、書いておきます。

```
　　12　　○ 6/3
　　13　　× 6/3
　　14　　△ 6/3
```

迷ったら、下の記号にしてください。きびしくつけたほうが、あとで得をします。

### 2周目は、△と×だけを解きます

2周目は、△と×がついた問題だけを解きます。○は、飛ばします。

```
　　12　　○ 6/3
　　13　　× 6/3　　△ 6/10
　　14　　△ 6/3　　○ 6/10
```

2周目で○になったら、その問題は、3周目には出てきません。3周目は、まだ△か×の問題だけです。例えば、1周目は200問、2周目は80問、3周目は30問、4周目は10問。周を重ねるたびに、やる量が減ります。

そして、==残っている問題は、全部、自分がまだ解けない問題==です。問題集が、自分だけの弱点集に、変わっていきます。12番で、単語に印をつけたのと、同じ考え方です。

### ○が不安な時と、×が多い時

「○をつけた問題も、忘れていそうで不安です」。よく聞かれます。テストの前に、○の問題を、3問だけ選んで、解いてみてください。3問とも解けたら、○は、信じて大丈夫です。落としたら、その問題だけ、△に変えます。

×が多い時は、原因でまとめます。×を並べてみると、原因は、3つか4つに集まっていることが多いです。10問を、1問ずつ直すより、一番多い原因を先に直すほうが、速いです。因数分解ができない×が3問あれば、因数分解を直すと、3問の×が、同時に消えます。（ミスに名前をつけるやり方は、22番に書きました）

## 頭のいい人と伸びない人の違い

伸びない人
全部もう1周
とりあえず、1番から

頭のいい人
△と×だけ
○は、もう解かない

## 今日からできる3STEP

STEP01　解いたら、番号の横に、○△×と日付を書く
STEP02　2周目は、△と×の問題だけを解く
STEP03　○になったら外して、残りだけ、もう1周
「できた」の基準：△と×だった問題を、何も見ずに、○にできたらOK！

## まとめ

解ける問題をもう一度解いても、点は増えない。
だから、全部はやり直さない。記録して、△と×だけ回す。
迷ったら、自分に聞きます。「これ、○だった？」

# 24　1冊が終わる前に、次の1冊を買う

## しないこと、すること

頭のいい人は、「1冊が終わる前に、次の1冊を買う」をしない。
かわりに、「『終わり』の条件を決めて、1冊をやり込む」をする。

## 本文

### 本棚を、見てください。最後のページまでやった問題集は、何冊ありますか？

……

では、途中で止まっている本は、何冊ありますか。

……

途中の本のほうが多かった人は、めずらしくありません。

英語の文法の問題集を、やっています。今、3分の1くらいです。本屋に行くと、新しい問題集が、並んでいます。「これ1冊で、完成」。友達も、「あの本がいい」と言っています。

　　「こっちのほうが、良さそう。こっちに変えよう」

新しい1冊を、買いました。1ページ目から、始めます。半年たちました。本棚には、3分の1だけやった問題集が、4冊、並んでいます。

### 4冊の最初の3分の1は、だいたい同じ内容です

どの問題集も、最初は、基本から始まります。

```
　　4冊を、3分の1ずつ　→　同じ基本を4回。後ろの3分の2は、1回も見ていない
　　1冊を、最後まで　　→　基本から応用まで、1回通った
```

やった量は、ほとんど同じです。でも、上のやり方では、テストに出る範囲の後ろの3分の2が、空いたままです。

==途中までの4冊は、最後までやった1冊に、勝てません。==

新しい本が良く見えるのには、理由があります。今の本の「しんどい所」は、もう知っています。新しい本の「しんどい所」は、まだ知りません。それだけの違いです。

### 終われないのは、「終わり」が決まっていないからです

1冊をやり込む、と決めても、次の問題が出てきます。「参考書って何周すればいいんですか」「どこまでできたら次に行っていいのか教えてほしいです」。一番多い相談です。どちらも、同じことを聞いています。==終わっていいかどうかの条件を、誰も教えてくれない。==

条件がないと、人は、2つのどちらかになります。不安で、いつまでも同じ本を回し続けるか。なんとなく、次の本に手を出すか。だから、先に、「終わり」の条件を決めます。

### 表紙の裏に、「終わり」の条件を、1行で書きます

本を開く前に、書きます。条件は、この3つでできています。

```
　　1　何を　　　　　　どの問題を
　　2　どんな条件で　　何も見ずに／時間内に
　　3　どれだけ　　　　何問中、何問
```

3つそろって、初めて、できたかどうかを確かめられます。

```
　　×　「この章を理解する」　　　　　　　確かめられない
　　×　「ちゃんとできるようにする」　　　確かめられない
　　○　「章末問題10問を、解説を見ずに、8問正解」　確かめられる
```

1行です。本の表紙の裏に書いて、見える場所に置いておきます。条件を満たすまで、ほかの本は、開きません。

### 8割で、次の1冊へ進みます

10割にしないでください。10問中10問を基準にすると、==たまたま落とした1問で止まります。==その1問のために、もう1周することになります。残りの2割は、次の段階で拾えます。基本の本で取りこぼした2割は、その次の演習で何度も出てきます。そこで拾うほうが速いです。

いつも8割、ではありません。どの段階かで変わります。

```
　　初めて習う単元　　→　6割で次へ。わからない場所が分かれば、終わり
　　2周目　　　　　　→　8割で次へ。ここで、できる状態を作る
　　試験前の最終確認　→　10割。ただし、範囲を絞ったぶんだけ
```

条件を満たしたら、不安でも、次の1冊へ進みます。それが、その本の「終わり」です。

### 本を変えていいのは、重すぎる時だけです

「合わない本でも、最後までやらないといけませんか」。そんなことは、ありません。ただ、変える時の決まりを、先に作っておきます。

```
　　2週間は、やってみる
　　10問中、ほとんど全部で手が止まるなら、今の自分には重すぎる　→　変える
　　10問中、2〜4問で止まるなら、合っている　→　しんどくても、続ける
```

絶対法則03の目安と同じです。しんどいから変える、ではありません。==重すぎて、何も残っていないから変える==んです。「あの本のほうが良さそう」は、変える理由に、なりません。

## 頭のいい人と伸びない人の違い

伸びない人
次の1冊を買う
こっちのほうが、良さそう

頭のいい人
1冊をやり切る
終わりの条件は、決めた

## 今日からできる3STEP

STEP01　表紙の裏に、「終わり」の条件を1行で書く
STEP02　条件を満たすまで、ほかの本は開かない
STEP03　満たしたら、不安でも、次の1冊へ進む
「できた」の基準：書いた条件の通りに、1冊を終わらせられたらOK！

## まとめ

途中までの4冊は、最後までやった1冊に勝てない。
だから、次の1冊を買う前に、今の1冊の「終わり」を決める。
迷ったら、自分に聞きます。「この1冊の終わりは、決めた？」
