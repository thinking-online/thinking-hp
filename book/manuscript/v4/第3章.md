# 第3章　【アウトプット】頭のいい人は、解けた問題を数えない
頭の中の知識を取り出す

## 章の導入文

### 一番最近やった問題集。○は、何問でしたか？

……

だいたい、答えられたと思います。「10問中、8問」。

では、×だった問題は、どんな問題でしたか。1つ、言ってみてください。

……

出てこなかった人が、多いと思います。

○の数は、覚えています。×の中身は、覚えていません。

でも、10問中8問の○は、解く前から解けた問題です。解いても、点は、1点も増えていません。点が増えるのは、×だった2問を、○に変えた時だけです。

頭のいい人は、解けた問題を、数えていません。==解けなかった問題を、どう扱うか==だけを見ています。

第2章で、頭に入れました。この章では、それを、取り出します。使うのは、主に、絶対法則03の「負荷」と、絶対法則06の「速度」です。×がつく所が、伸びる所。早く解いて、早く×を見つけて、早く直します。

点が動くのは、この章です。前半の5つが、問題の解き方。後半の4つが、解いたあとの復習の仕方です。

# 16　解説を読んで、「わかった」で終わる

## 質問ページ

頭のいい人が絶対やらないこと
「解説を読んで「わかった」」
じゃあ、何をするの？

## 本文

### 1から100までを、全部足すと、いくつですか？

解き方を、書きます。

```
　　1と100を足すと、101。2と99を足しても、101。
　　こういうペアが、50組できる。
　　だから、101×50＝5050。
```

「なるほど」と、思いましたね。

では、上の3行を手で隠して、解いてください。

　　1から40までを、全部足すと、いくつですか。

……

答えは、820です。（41×20）

「ペアは、何組だっけ」。そこで、手が止まりませんでしたか。

解き方を読んで、「なるほど」と思いました。それでも、数字が変わっただけで、止まります。

問題集の解説を読んだあとにも、同じことが起きています。「なるほど、わかった。次」。赤ペンで答えを写して、次の問題へ進みます。1週間後。同じ問題が、小テストに出ました。最初の1行が、書けません。

### 解説を読んでいる間、決めているのは、解説のほうです

解説を読んで「わかった」時、やっていたことは、何でしょうか。

人が解いた道を、後ろから、ついて歩いただけです。

```
　　わかる　　解説の1行1行に、「うん、そうなる」と言える
　　できる　　何も見ずに、最初の1行から、自分で書ける
```

道案内をしてもらって着いた場所に、次の日、1人で行けるとは、かぎりません。「次、どっちに曲がるか」を、自分で決めていないからです。

解説も、同じです。一番難しいのは、「最初に、何をするか」を、自分で決める所です。解説を読んでいる間、そこは、解説が決めてくれています。

テストで聞かれるのは、「できる」のほうだけです。

### 解説を閉じて、白紙に、最初から書きます

やることは、1つです。

==解説を読んだら、閉じます。白紙に、最初の1行から、自分で書きます。==

これを、「白紙再現」と呼びます。

```
　　① 解説を読む　　　　　　　　　わかるまで読んでいい
　　② 解説を閉じる　　　　　　　　答えも、途中の式も、見えないようにする
　　③ 白紙に、最初から書く　　　　止まったら、そこに印をつける
　　④ 止まった所だけ、解説を見る　見たら、また閉じて、最初からもう一度
```

絶対法則02の「思い出す」を、問題でやっているだけです。

やってみると、驚くと思います。「わかった」はずなのに、3行目で、手が止まります。==手が止まった所が、本当は、わかっていなかった所です。==解説を読んでいるだけでは、そこは、見つかりません。

### 写すのとは、違います

解説を見ながら、ノートに書き写す。これは、白紙再現では、ありません。

写している間、頭は、「次に何をするか」を、1回も決めていません。見て、書いているだけです。きれいな解答が、ノートに残ります。でも、頭には、残っていません。

見るのは、止まった時だけ。そして、見たら、もう一度、閉じます。

### 数学だけでは、ありません

```
　　数学・理科の計算　　解説を閉じて、最初の式から書く
　　英語の長文　　　　　和訳を閉じて、線を引いた文を、自分で訳す
　　社会・理科の説明　　教科書を閉じて、「なぜ、そうなったか」を、白紙に書く
　　授業　　　　　　　　その日のうちに、先生が解いた例題を、白紙から解く（07番）
```

全部の問題で、やる必要はありません。==解説を読んで、「わかった」と思った問題だけ==で、いいです。自分で解けた問題は、もう、できています。

### 別の日に、もう一度だけ

解説を閉じたすぐあとは、まだ、頭に解説が残っています。だから、書けて当然、という面もあります。

絶対法則05で決めた通り、同じ問題を、別の日に、もう一度、白紙から解きます。そこで書けたら、その問題は、「できる」になっています。

なるほど、わかった。次

頭のいい人

## 今日からできる3STEP

題：頭のいい人の『解説の使い方』3STEP

「わかった。じゃあ、閉じる」

STEP02

```

```

迷ったら、自分に聞きます。「これ、白紙に書ける？」

# 17　参考書を読み終えてから、問題集を開く

## 質問ページ

頭のいい人が絶対やらないこと
「力がついてから解く」
じゃあ、何をするの？

## 本文

### バスの問題です。読んでください

```
　　バスに、5人乗っています。
　　最初のバス停で、3人乗って、2人降りました。
　　次のバス停で、4人乗って、1人降りました。
　　その次のバス停で、2人降りました。
```

では、問題です。

　　バス停は、いくつ、ありましたか。

……

乗っている人の数を、数えていませんでしたか。

聞かれることを、先に知っていたら、数えるものが違ったはずです。

勉強でも、同じことが起きています。何を聞かれるかを知らないまま、参考書を、1ページ目から読んでいる。何を聞かれるかは、過去問と問題集に、書いてあります。

高校3年生の6月。志望校の赤本を、買いました。めくってみましたが、1問も解けません。

　　「今やっても解けない。力がついてから、腕試しに解こう」

本棚に、立てました。今やっても解けないから、意味がない。過去問は数が限られているので、使い切りたくない。腕試しは、力がついてからのほうが、正確に測れる。理由は、どれも、まともです。

それでも、11月に、こうなります。過去問を解き始めて、2日目。大問3を見て、気づきます。この学部には、この分野が、一度も出ていない。夏の2ヶ月、そこをやっていました。

### 過去問を、問題集だと思っています

今起きていることは、1つだけです。過去問を、問題集として扱っている。問題集は、解くための本です。だから「解けるようになってから使う」が正しい。本棚に立てた判断は、問題集に対しては完全に正しいのです。でも、過去問は問題集ではありません。

### 試験には、範囲があります

ここが、一番大事なところです。試験には、出るものと出ないものがあります。どんな試験にもです。受験、定期テスト、資格の試験、全部そうです。出題する側は、無限に出せません。時間も配点も決まっているので、どこを出すかを決めてから作ります。つまり、試験が始まる前から、どこが出るかは、もう決まっています。そして、どこが出て、どこが出ないかが書いてある紙は、1種類しかありません。

過去問です。

過去問は、問題が載っているだけの本ではありません。出るものと出ないものの境目が書いてある、ただ1つの紙です。これを見ないまま進むのは、テスト範囲を知らないまま、テスト勉強をするのと同じです。出ない分野を3ヶ月やっても、点は1点も増えません。努力が足りなかったという話ではありません。努力した場所が、採点されない場所だった、という話です。

### 進めていて止まった時も、1ページ目には戻りません

やる場所を決めたあと、参考書を進めていると、必ず止まるページが出てきます。78ページの応用問題。解説を読んでも、何を言っているのかわかりません。基礎が抜けているのかもしれない、と思います。途中で飛ばしたところもあった気がします。1ページ目に戻ります。1ページから30ページは、簡単です。スラスラ進みます。3日かかって、また78ページに戻ってきて、やっぱりわかりません。戻るという判断は、正しいです。手前に原因があることは、よくあります。問題は、どこまで戻るかです。戻る先の決め方は、1つだけです。

　　わかった最後の場所を探す。

78ページがわからないなら、77ページはわかりますか。わかるなら、原因は78ページの中にあります。77ページもわからないなら、70ページはどうですか。こうやって、わかるところが出てくるまで戻ります。たいていは、3ページから10ページ戻れば見つかります。1ページ目まで戻ることは、ほとんどありません。ここでも、やっているのは同じことです。やらない場所に線を引いています。範囲の時は、出ないところに線を引きました。つまずいた時は、わかっているところに線を引きます。残ったところだけをやります。

### 問題集も、同じです。参考書を読み終える前に、開きます

参考書と問題集の関係も、同じです。

参考書を最後まで読んでから、問題集を開く。その順番だと、絶対法則06で見た通り、どこがわかっていないのかが、いつまでもわかりません。

先に、問題集を開きます。解けなくて、かまいません。

```
　　参考書を全部読んでから、解く　→　どの行も同じに見える。どこが大事か、わからない
　　先に問題を見てから、読む　　　→　「さっきのあれは、ここか」と、探しながら読む
```

問題を先に見た人は、何を探して読めばいいかを、知っています。参考書は、最初から最後まで読む本では、なくなります。==わからなかった所を調べる、辞書になります。==

先に解くと、×だらけになります。それが嫌で、先に全部読もうとする人が多いです。でも、その×は、予定通りです。×がついた所だけを、参考書で調べます。

まったく習っていない単元なら、解くのは、1問だけで十分です。3分考えて、「たぶん、こう」を1行書く。それから、読みます。

### やりすぎないための注意

1年分だけで決めないでください。1年だけ出ていなかった分野を捨てると、翌年に出ます。3年分、できれば5年分見ます。同じ大学でも、学部で出題が変わります。同じ県でも、高校で変わります。自分が受けるところの過去問を見てください。捨てたのは「今はやらない」であって「永久にやらない」ではありません。線を引いた紙は、取っておきます。余裕ができたら、そこから戻します。

### AIにやらせるなら

書き出した紙を、そのまま渡せます。「過去3年分の出題分野と配点を貼ります。毎年出ている分野と、一度も出ていない分野に分けてほしい」3年分を目で並べるのは手間です。分け方が出てきたら、自分の目で1回確かめてください。AIも、見落とすことがあります。

「解かない。見るだけ」

# 18　正解した問題に、○をつけて終わる

## 質問ページ

頭のいい人が絶対やらないこと
「正解したら終わり」
じゃあ、何をするの？

## 本文

### 日本で一番長い川は、どれですか？

```
　　ア　利根川　　イ　信濃川　　ウ　石狩川　　エ　最上川
```

……

答えは、イの信濃川です。正解した人も、多いと思います。

では、もう1問です。

　　アの利根川は、何が、日本一ですか。

……

流域面積（その川に水が集まってくる土地の広さ）です。

1問目に正解した人でも、2問目で止まります。正解の選択肢だけを見て、○をつけたからです。

外れの選択肢は、ただの外れでは、ありません。==次のテストで、正解になるかもしれない選択肢です。==

英語の4択問題でも、同じです。なんとなく、イな気がする。答えを見ると、イ。「よし、合ってた。次」。1週間後、よく似た問題が出ました。今度は、ウを選んで、×でした。

### その○は、当たったのか、わかっていたのか

○には、2種類あります。

```
　　根拠があって選んだ○　　次も、取れる
　　なんとなく選んだ○　　　次は、わからない
```

答え合わせの時、この2つは、同じ○に見えます。赤ペンで丸をつけた瞬間に、どちらだったのかが、わからなくなります。

そして、なんとなくの○は、一番やっかいです。×なら、解説を読みます。○は、読みません。==わかっていないのに、一度も見直されないまま、本番まで行きます。==

### 選ばなかった3つに、点が眠っています

4択の問題は、1問に見えます。でも、選択肢は4つあります。

```
　　ア　なぜ、違うのか
　　イ　なぜ、合っているのか
　　ウ　なぜ、違うのか
　　エ　なぜ、違うのか
```

4つとも言えたら、4問ぶんの勉強です。イを選んで○をつけて終わった人は、1問ぶん。しかも、当たっただけかもしれない1問ぶんです。

もう1つあります。間違いの選択肢は、適当に作られていません。==多くの人が間違える考え方==を、わざと並べてあります。つまり、選ばなかった3つは、次に自分が引っかかる場所の一覧です。

### 根拠を持って選ぶと、間違えた時に残ります

コロンビア大学の研究者たちが、確かめていることがあります。

自信を持って答えて、それが間違いだった時。人は、正しい答えを、普通より強く覚えます。「え、違うの？」という驚きが、記憶を強くするからです。

逆に、なんとなく選んで間違えた時は、あまり残りません。驚かないからです。

だから、==選ぶ前に、根拠を1つ決めます。==「イだ。なぜなら、主語が複数だから」。合っていれば、その根拠が使えるとわかります。間違っていれば、「え、違うの？」と驚くので、正しい答えが強く残ります。どちらに転んでも、残ります。

### 言えなかった○は、△にします

答え合わせのやり方を、1つ変えます。

```
　　○　選んだ理由も、他が違う理由も、言えた
　　△　合っていたけれど、理由が言えなかった
　　×　間違えた
```

△は、×と同じ扱いにします。もう一度やる問題です。

### 選択問題でなくても、同じです

数学で答えが合っていた時。途中の式を、説明できますか。なぜその公式を使ったのか、言えますか。

記述問題で丸をもらった時。模範解答と、自分の答えの、どこが違うかを言えますか。

答えが合っていた、で止まらない。==なぜ合っていたかまで言えて、初めて○です。==

### 解説に、間違いの理由が書いていない時

問題集によっては、正解の説明しか載っていません。

その時は、AIに聞いていいです。「この問題で、ウが違う理由を、中学生にもわかるように説明して」。答えを聞くのではなく、理由を聞きます。（42番でやります）

問題集を選ぶ時も、ここを見てください。間違いの選択肢について、1つずつ理由が書いてあるもの。それが、いい問題集です。

## 頭のいい人と伸びない人の違い

○で終わり
合ってた。次！

頭のいい人
理由まで言う

「なんとなくで、選ばない」

「イは、ここが本文と逆だ」

```

だから、○で終わりにしない。理由まで言う。
迷ったら、自分に聞きます。「他は、なんで違うの？」

# 19　時間を測らずに、解けるまで解く

## 質問ページ

頭のいい人が絶対やらないこと
「時間を測らずに解く」
じゃあ、何をするの？

## 本文

### 10秒で、「さ」で始まる食べ物を、5つ言ってください

心の中で、10数える間です。どうぞ。

……

5つ、言えましたか。

時間がいくらでもあれば、全員、言えます。知らない言葉は、1つもありません。それでも、「10秒で」と言われたとたんに、3つで止まった人も、いると思います。

==知っていることと、時間内に出せることは、別の力です。==テストで測られるのは、あとのほうです。

数学の問題集を、進めています。

```
　　1問目　10分かかったけど、解けた
　　2問目　15分かかったけど、解けた
　　3問目　20分かかったけど、解けた
```

「時間はかかったけど、解けた。全部○」。そうつけました。

模試の日。同じレベルの問題が、大問3つで、制限時間は60分でした。1問目に25分かかって、2問目の途中で、終わりました。

### 時間を測らないと、「できる」が本番とズレます

20分かけて解けた問題は、できる問題でしょうか。

本番で、その問題に20分使えるなら、できる問題です。本番で使えるのが7分なら、できない問題です。同じ問題でも、持ち時間によって、できる・できないが変わります。時間を測らないと、どちらなのかがわかりません。

### 本番の持ち時間を、知っていますか

ここで一度、計算してみてください。

　　試験時間　÷　問題数　＝　1問あたりの時間

時間を測ると、解き方が変わります。

15分と決めて解き始めると、途中で時計を見ます。7分経って、まだ方針が立っていなかったら、焦ります。焦ると、決めます。この問題は後回しにしよう、とか、別の方法を試そう、とか。

## 本文

### オーストラリアの首都は、どこですか？

5秒で、答えてください。

……

答えは、キャンベラです。

出てこなかった人に、聞きます。あと3分考えたら、出たと思いますか。

出ません。知らないものは、いくら考えても、出てこないからです。

英単語を、テストの形で復習している時も、同じです。available の意味が、出てきません。この時、やり方は、2つに分かれます。

```
　　A　すぐに、答えを見る
　　B　思い出せるまで、粘る
```

どちらも、よくあるやり方です。そして、どちらも、うまくいきません。

Aの人は、1秒でページをめくります。「利用できる、か」。次の単語も、出てこなければ、1秒でめくります。30語が、5分で終わります。次の日、同じ30語をやると、同じ所で、同じように出てきません。

Bの人は、1語に3分かけます。それでも、出てきません。30語が、終わりません。

### すぐ見るのは、半分だけ正しいです

長く考え込むのは、時間の無駄です。これは、本当です。わからない単語を3分考えても、出てきません。知らないものは、考えても出ません。だから、すぐ見るのは、間違いではありません。問題は、1秒だということです。

### 5秒が、分かれ目です

出てこない時、頭の中では探しています。その単語を見た時の、ページの位置。隣に書いてあった単語。一緒に覚えた例文。似た形の別の単語。色々な方向から、取りに行っています。この「取りに行く」が、思い出す練習です。

1秒でめくると、取りに行く前に終わります。練習になっていません。5秒やると、取りに行く動きが入ります。出てこなくても、入ります。

出てこなかったあとに見た答えは、残りやすくなります。自分で探したあとだと、「ああ、それか」と、答えが頭に入りやすくなるからです。

### 粘ってはいけないのも、本当です

5秒を超えたら、見てください。30秒考えても、1分考えても、結果は同じです。知らないものは出てきません。そして、1問に1分かけると、30語で30分かかります。時間が足りなくなります。5秒です。ここは、数えてください。

ここは、本や先生によって、言うことが分かれるところです。どちらも聞いたことがあるかもしれないので、両方書きます。

ロンドンの大学の研究者たちの実験です。知らない言葉の意味を、覚えてもらいます。片方のグループには、最初から正解を見せます。もう片方には、まず当てずっぽうで答えさせます。知らない言葉なので、当然はずれます。はずしたあとで、正解を見せます。あとのテストで成績がよかったのは、==はずしたほうでした。==

オーストラリアの大学の研究者たちの実験は、逆のことを言っています。図形の問題を使いました。片方のグループには、解き方の見本を先に見せます。もう片方には、自力で解かせます。あとのテストで成績がよかったのは、==見本を先に見たほうでした。==

どちらも本当です。ただ、2つの実験は、やらせたことが少し違います。

### 違いは、かけた時間です

はずしてから見た実験で、当てずっぽうに使った時間は、数秒です。
見本を先に見た実験で、自力で解こうとした時間は、数十分です。

```
　　数秒　考えてから見る　　→　残る
　　数十分　考えてから見る　→　残らない
```

つまり2つの実験は、どちらも==「長く粘るな」と言っています。==
片方が「でも0秒はもったいない」、もう片方が「30分はやりすぎ」と言っているだけです。

だから、5秒なのです。

見本を先に見たほうが強かったのは、==その単元を初めてやる人==の時です。

同じ種類の研究で、続きがわかっています。ある程度できるようになった人では、逆になります。見本を見るより、自力で解いたほうが伸びます。見本が、邪魔になるからです。

だから、1周目と3周目で、やることが逆になります。

```
　　1周目　見たことのない型　→　先に解答を見て、閉じて再現する
　　3周目　知っている型　　　→　先に自力で解く。10分やる
```

「答えは先に見るべきか」に、1つの答えがないのは、これが理由です。

### 2つの実験が、1つだけ同じことを言っています

はずしてから見る実験では、はずしたあとに==必ず正解を見せています。==
見本を先に見る実験では、見本のあとに==必ず自分で解かせています。==

```

　　どちらも「見たあと、閉じて出したか」で差がついています。
```

考える時間を長くしても、残る量は増えません。
増えるのは、==見たあとに自分で出した回数==のほうです。

### 数学の問題だと、時間が変わります

```

```

```

数学の問題集を、1周しました。全部で、200問です。「とりあえず、1番から、もう1周しよう」。1番。解けました。2番。解けました。3番も、解けました。1周目にも、解けた問題です。

2周目も、1周目と同じだけ、時間がかかりました。3周目に入ります。また、1番からです。

### 2周目の時間の多くを、もう解ける問題に使っています

1周目で、200問のうち、120問が解けたとします。

2周目に、1番から全部解くと、その120問を、もう一度解くことになります。==解く前から、解ける問題です。解いても、点は増えません。==

絶対法則03で見た通り、スラスラ解ける時、頭には、負荷がかかっていません。気持ちはいいですが、伸びてはいません。

点が増えるのは、解けなかった80問を、解けるようにした時だけです。

```
　　全部、もう1周　　　　200問。そのうち120問は、もう解ける
　　解けなかった所だけ　　 80問。全部が、点が増える問題
```

同じ時間で、下のやり方なら、解けなかった問題を、2回やれます。

それでも、全部やり直す人が多いです。理由は、最初の質問に答えられなかったのと、同じです。==どれが解けて、どれが解けなかったかを、記録していないからです。==

### 1周目から、○△×を、問題番号の横に書きます

記録は、3つの記号だけです。

```
　　○　何も見ずに、時間内に、解けた
　　△　解けたが、時間をこえた。または、たまたま合っていた
　　×　解けなかった
```

問題番号の横に、小さく書きます。日付も、書いておきます。

```
　　12　　○ 6/3
　　13　　× 6/3
　　14　　△ 6/3
```

迷ったら、下の記号にしてください。きびしくつけたほうが、あとで得をします。

### 2周目は、△と×だけです

2周目は、△と×がついた問題だけを解きます。○は、飛ばします。

```
　　12　　○ 6/3
　　13　　× 6/3　　△ 6/10
　　14　　△ 6/3　　○ 6/10
```

2周目で○になったら、その問題は、3周目には出てきません。3周目は、まだ△か×の問題だけです。例えば、こうなります。

```
　　1周目　200問
　　2周目　 80問
　　3周目　 30問
　　4周目　 10問
```

周を重ねるたびに、やる量が減ります。そして、==残っている問題は、全部、自分がまだ解けない問題==です。問題集が、自分だけの弱点集に、変わっていきます。

12番で、単語に印をつけたのと、同じ考え方です。

### ○の問題が、不安な時

「○をつけた問題も、忘れていそうで不安です」。よく聞かれます。

テストの前に、○の問題を、3問だけ選んで、解いてみてください。3問とも解けたら、○は、信じて大丈夫です。落としたら、その問題だけ、△に変えます。

全部をやり直す前に、3問で確かめます。

### ×が多い時は、原因でまとめます

×を並べてみると、原因は、3つか4つに集まっていることが多いです。

```
　　符号のミス　　　　　　3問
　　因数分解ができない　　3問
　　問題文の読み違い　　　2問
　　時間切れ　　　　　　　2問
```

10問を、1問ずつ直すより、一番多い原因を先に直すほうが、速いです。因数分解を直すと、3問の×が、同時に消えます。（ミスに名前をつけるやり方は、22番に書きました）

# 24　1冊が終わる前に、次の1冊を買う

## 質問ページ

頭のいい人が絶対やらないこと
「次の1冊を買う」

## 本文

### 本棚を、見てください。最後のページまでやった問題集は、何冊ありますか？

……

……

途中の本のほうが多かった人は、めずらしくありません。

英語の文法の問題集を、やっています。今、3分の1くらいです。本屋に行くと、新しい問題集が、並んでいます。「これ1冊で、完成」。友達も、「あの本がいい」と言っています。

　　「こっちのほうが、良さそう。こっちに変えよう」

新しい1冊を、買いました。1ページ目から、始めます。半年たちました。本棚には、3分の1だけやった問題集が、4冊、並んでいます。

### 4冊の最初の3分の1は、だいたい同じ内容です

どの問題集も、最初は、基本から始まります。

```
　　4冊を、3分の1ずつ　→　同じ基本を、4回やった。後ろの3分の2は、どの本でも、1回も見ていない
　　1冊を、最後まで　　→　基本から応用まで、1回通った
```

やった量は、ほとんど同じです。でも、上のやり方では、テストに出る範囲の後ろの3分の2が、空いたままです。

==途中までの4冊は、最後までやった1冊に、勝てません。==

新しい本が良く見えるのには、理由があります。今の本の「しんどい所」は、もう知っています。新しい本の「しんどい所」は、まだ知りません。それだけの違いです。

### 終われないのは、「終わり」が決まっていないからです

1冊をやり込む、と決めても、次の問題が出てきます。

```
　　「参考書って何周すればいいんですか」
　　「どこまでできたら次に行っていいのか教えてほしいです」
　　「一回全問正解できたから次に行っていいのか、不安です」
```

一番多い相談です。全部、同じことを聞いています。==終わっていいかどうかの条件を、誰も教えてくれない。==

条件がないと、人は、2つのどちらかになります。不安で、いつまでも同じ本を回し続けるか。なんとなく、次の本に手を出すか。

だから、先に、「終わり」の条件を決めます。

### 条件は、3つでできています

本を開く前に、「終わり」の条件を、1行で書きます。条件は、必ずこの3つでできています。

```
　　1　何を　　　　　　どの問題を
　　2　どんな条件で　　何も見ずに／時間内に
　　3　どれだけ　　　　何問中、何問
```

3つそろって、初めて、できたかどうかを確かめられます。

```
　　×　「この章を理解する」　　　　　　　確かめられない
　　×　「ちゃんとできるようにする」　　　確かめられない
　　○　「章末問題10問を、解説を見ずに、8問正解」　確かめられる
```

1行です。本の表紙の裏に書いて、見える場所に置いておきます。

### なぜ8割なのか

10割にしないでください。理由が2つあります。

1つ目。10問中10問を基準にすると、==たまたま落とした1問で止まります。==その1問のために、もう1周することになります。

2つ目。残りの2割は、次の段階で拾えます。基本の本で取りこぼした2割は、その次の演習で何度も出てきます。そこで拾うほうが速いです。

8割というのは、「完璧ではないが、次に行っても困らない」という線です。

### 段階で、基準が変わります

いつも8割、ではありません。どの段階かで変わります。

```
　　初めて習う単元　　→　6割で次へ
　　　　　　　　　　　　　1周目は、どこがわからないかを探す周。
　　　　　　　　　　　　　わからない場所が分かれば、1周目の仕事は終わり
　　2周目　　　　　　→　8割で次へ
　　　　　　　　　　　　　ここで、できる状態を作る
　　試験前の最終確認　→　10割
　　　　　　　　　　　　　ただし、範囲を絞ったぶんだけ。
　　　　　　　　　　　　　全範囲で10割は、誰にもできない
```

条件を満たしたら、不安でも、次の1冊へ進みます。それが、その本の「終わり」です。

### 本を変えていいのは、重すぎる時だけです

「合わない本でも、最後までやらないといけませんか」。そんなことは、ありません。

ただ、変える時の決まりを、先に作っておきます。

```
　　2週間は、やってみる
　　10問中、ほとんど全部で手が止まるなら、今の自分には重すぎる　→　変える
　　10問中、2〜4問で止まるなら、合っている　→　しんどくても、続ける
```

絶対法則03の目安と同じです。しんどいから変える、ではありません。==重すぎて、何も残っていないから変える==んです。

「あの本のほうが良さそう」は、変える理由に、なりません。
