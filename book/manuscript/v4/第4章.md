```

　　◻︎　テストの結果を見て、落ちこんで、手につかなかった
```

……

1つでも当てはまった人に、聞きます。その時、自分に、何と言いましたか。

# 25　明日の自分に期待して、計画を立てる

## しないこと、すること

頭のいい人は、「明日の自分に期待して、計画を立てる」をしない。
かわりに、「先週やった時間を見てから、決める」をする。

## 本文

### 夏休みの宿題を、「7月中に終わらせる」と決めたことは、ありますか？

……

そして、7月中に、終わりましたか。

終わった人は、少ないと思います。

サボったから、とはかぎりません。計画を立てた日の自分が、「毎日やる気があって、予定通りに進む自分」で計算していたからです。

同じことが、毎週の計画でも、起きています。

日曜日の夜。今週は、ほとんど勉強しませんでした。「反省した。来週こそ、ちゃんとやる」。

```
　　月曜から金曜　　1日3時間
　　土曜と日曜　　　1日6時間
```

週に27時間です。書き終わって、少しすっきりしました。

月曜。部活から帰ったのが7時。ごはんを食べて、8時。机に座ったのが8時半で、11時に寝ました。2時間でした。火曜は1時間半。水曜は0でした。木曜の朝、計画表を見ます。全部、ずれています。

### この計画は、誰の計画ですか

この計画は、月曜に3時間やれる自分に合わせて作っています。でも、その自分は、まだ一度も現れていません。先週も、その前の週も、実際にやったのは1日2時間でした。守れないのは、当たり前です。意志の問題ではありません。最初に書いた数字が、自分の数字ではなかった、というだけです。

理想の自分で立ててしまうのは、日曜の夜だからです。日曜の夜は、やる気があります。1週間を反省したあとなので、今週こそは、と思っています。そして月曜の夜、実際に机に向かうのは、部活で疲れた、いつもの自分です。計画を立てる人と、実行する人が、別人になっています。

人は、自分がかかる時間も、短く見積もります。学生に、卒業論文がいつ終わるかを予測させた調査があります。「うまくいった場合」と「うまくいかなかった場合」の両方を答えてもらいました。実際に終わったのは、==「うまくいかなかった場合」の予測より、さらに遅く==でした。自分のことなのに、毎回、同じ方向に外れます。だから、意志で直すのではなく、記録から立てます。

### 先週、実際にやった時間を、数えます

記憶ではなく、記録で数えます。記録がない人は、今日から、その日にやった時間を、スマホのメモに1行書きます。7日ぶんたまったら、それが基準です。多いか少ないかは、気にしません。

### 来週の計画は、先週の8割の量で立てます

先週、13時間半やれたなら、来週は、11時間で組みます。

```
　　先週やった時間　月2　火1.5　水0　木2　金2　土3　日3　→　13時間半
　　来週の計画　　　13時間半の8割　→　11時間で組む
　　かかる時間　　　「30分でできる」と思ったものは、45分で書く
```

かかる時間には、1.5をかけます。「この問題集は、1日で終わる」と思ったら、1.5日で書きます。==見積もりに1.5をかけた数字==が、だいたい本当の時間です。

量は少なめに、時間は多めに書きます。早く終わったら、それは余裕になります。終わらなかったら、それは「できなかった」になります。同じ1日でも、残る気持ちがまるで違います。

計画に使うのは、10分までです。きれいな表を作って、色を分けて、1時間かけても、まだ1問も解いていません。==10分で切ります。==10分経ったら、途中でも、立てるのをやめて始めます。足りないところは、やりながら直します。

### 週に1日、何も入れない日を作ります

記録から立てた計画も、崩れます。水曜に、部活の遠征で丸一日つぶれました。木曜の朝、計画表を見ると、全部がズレています。新しい紙を出して、30分かけて作り直しました。次の週も、同じことが起きます。

学校行事、部活、体調、家の用事、急な小テスト。1週間に1日くらいは、何かが入ります。崩れることは、例外ではありません。毎週起きることです。そして、作り直した30分で、問題は1問も解いていません。

だから、1週間の計画を立てる時、1日を空けておきます。何も入れません。予備日です。崩れなかった週は、その日は休んでも、先に進めてもいいです。崩れた週は、その日で取り返します。

木曜の朝にやるのは、水曜の分を予備日に移すだけです。矢印を1本引いて、30秒で終わります。紙は、1枚のままです。曜日はどこでもいいですが、週の後半に置くほうが使いやすいです。前半で崩れることが多いからです。1ヶ月の計画なら、4週のうち1週を、調整の週にします。

## 頭のいい人と伸びない人の違い

伸びない人
理想で計画
明日から、1日5時間！

頭のいい人
実績で計画
先週、何時間できた？

## 今日からできる3STEP

STEP01　先週、実際にやった時間を、数える
STEP02　来週の計画は、先週の8割の量で立てる
STEP03　週に1日、何も入れない日を作る
「できた」の基準：立てた計画の8割以上を、実際にやれたらOK！

## まとめ

計画が崩れるのは、理想から立てているから。
だから、理想で立てない。実績で立てる。
迷ったら、自分に聞きます。「先週、何時間できた？」

# 26　「何時間やるか」で、計画を立てる

## しないこと、すること

頭のいい人は、「『何時間やるか』で、計画を立てる」をしない。
かわりに、「『何を、どこまで』で決める」をする。

## 本文

### 昨日、何時間、勉強しましたか？

……

では、もう1つ。昨日、新しくできるようになったことを、1つ、言ってください。

……

1つ目は、すぐ答えられたはずです。2つ目で、止まりませんでしたか。

時間は、数えています。できるようになったことは、数えていません。

日曜日の朝です。今日は、1日、空いています。「今日は、3時間やろう」。机に向かいます。英語の教科書を開いて、読みます。ノートを、少し整理します。途中で、スマホを少し見ます。時計を見ると、3時間たっていました。

「よし、3時間やった」。満足して、終わります。何ができるようになったかは、答えられません。

### 時間は、座っているだけで、過ぎます

「3時間やる」という計画は、3時間たてば、達成です。

その間に、何をしたかは、問われません。集中していても、ぼんやりしていても、3時間は、3時間です。

```
　　「3時間やる」　　　　　　　　　　座っていれば、終わる
　　「単語の51〜100を、閉じて言う」　言えるようになるまで、終わらない
```

絶対法則01で見た通り、「勉強した感じ」と、「点が上がる」は、別のものです。時間で立てた計画は、「勉強した感じ」のほうを、ゴールにしてしまいます。

テストは、何時間やったかを、聞いてきません。==聞かれるのは、何ができるか、だけです。==

### 今日やることを、「何を、どこまで」で書きます

計画は、時間ではなく、中身で書きます。

```
　　×　英語を1時間
　　○　英単語の51〜100を、閉じて、意味を言う
　　×　数学を2時間
　　○　問題集の△と×の12問を、解き直す
　　×　日本史を、がんばる
　　○　教科書の鎌倉時代を読んで、流れを、何も見ずに3つで言う
```

○のほうは、どれも、「終わったかどうか」が、自分でわかります。24番で決めた「終わりの条件」を、1日の大きさにしたものです。

こう決めると、早く終われば、早く休めます。「3時間」の計画では、速くやっても、得をしません。「ここまで」の計画では、==集中した分だけ、早く終わります。==

### 「絶対終わる」と思う量まで、減らします

時間を、見なくていいわけでは、ありません。25番で、先週、実際にできた時間を見ました。それが、自分の入れ物の大きさです。例えば、90分ある日。「単語50個」と「数学12問」が、入るかどうか。入らないなら、中身を減らします。

最初は、「これなら、絶対終わる」と思う量にしてください。多く書いて、終わらない日が続くと、計画を見るのが、嫌になります。少なく書いて、毎日終わるほうが、続きます。余ったら、次の日の分を、少しやれば、いいだけです。

### 終わったら線で消して、かかった時間を書きます

終わったものは、線で消します。横に、かかった時間を書きます。

```
　　英単語の51〜100を、閉じて、意味を言う　→　線で消す。40分
　　問題集の△と×の12問を、解き直す　　　→　5問まで。1問に8分
```

終わらなかった時には、理由がわかります。「12問のうち、5問しかできなかった。1問に、思ったより時間がかかった」。「数学1問に、8分かかった」とわかれば、次からは、入る量を、決められます。次の計画を、直せます。

## 頭のいい人と伸びない人の違い

伸びない人
時間で決める
今日は、3時間やろう

頭のいい人
中身で決める
今日は、ここまでやる

## 今日からできる3STEP

STEP01　今日やることを、「何を、どこまで」で書く
STEP02　「絶対終わる」と思う量まで、減らす
STEP03　終わったら線で消して、かかった時間を書く
「できた」の基準：書いたことが、全部、線で消えたらOK！

## まとめ

テストが聞くのは、何時間やったかではなく、何ができるか。
だから、時間で計画を立てない。「何を、どこまで」で決める。
迷ったら、自分に聞きます。「今日は、何を、どこまで？」

# 27　やる気が出た時に、目標を立てる

## しないこと、すること

頭のいい人は、「やる気が出た時に、目標を立てる」をしない。
かわりに、「『○○したら、△△する』を1つだけ決める」をする。

## 本文

### 今年のお正月に立てた目標を、言えますか？

……

思い出せなかった人。思い出せたけど、もうやっていない人。どちらかが、ほとんどだと思います。

では、もう1つ。昨日の夜、歯をみがきましたか。

こちらは、目標を立てていません。やる気も、要りません。それでも、毎日、続いています。

違いは、気合いでは、ありません。==「いつ、やるか」が、決まっているかどうか==です。

模試の結果が返ってきた夜。悔しくて、眠れません。動画で、逆転合格した先輩の話を見ました。やる気が、わいてきます。

　　「よし、今日から毎日、英単語を100個やるぞ！」

ノートの表紙に、大きく書きました。3日後。ノートは、カバンの中に入ったままです。

### やる気が高い日の自分は、別人です

やる気が満タンの時、人は「できる」と思います。毎日100個。毎日3時間。朝5時起き。

その目標を実行するのは、誰でしょうか。

やる気が満タンの自分ではありません。==部活で疲れて帰ってきた、普通の日の自分==です。やる気が高い時に立てた目標は、普通の日の自分には、重すぎます。だから、3日で止まります。意志が弱いからではありません。

続いている人を見ると、「意志が強いんだな」と思いますよね。逆です。続く人ほど、自分の意志をあてにしていません。やる気があってもなくても、==勝手に始まる形==を、先に作っています。

### 「○○したら、△△する」と書いて、貼ります

形は、1つだけです。

```
　　×　毎日、英単語をやる
　　○　歯をみがいたら、英単語を5個やる
```

「○○」に入れるのは、もう毎日やっていることです。先に、毎日やっていることを、3つ書きます。その中の1つに、つなげます。

```
　　毎日やっていること　　歯みがき／夕飯／お風呂
　　書いて、貼る1行　　　「歯をみがいたら、英単語を5個やる」
```

決めた1行を、紙に書いて、目に入る所に貼ります。

「いつ、どこで、何をするか」まで決めておく。ニューヨーク大学の研究者たちの研究で、ここまで決めていた人たちは、決めていなかった人たちより、実際にやった割合がはっきり高くなりました。

理由は、迷う場面がなくなるからです。「毎日やる」だと、毎日「いつやろうかな」と考えることになります。考えるたびに、「あとでいいか」が入りこみます。「歯をみがいたら」と決めてあれば、考えません。歯ブラシを置いたら、始まります。

### 「前」ではなく、「後」につなげます

ここは、間違えやすいところです。

```
　　×　夕飯の前に、やる
　　×　お風呂に入る前に、やる
　　○　夕飯の食器を下げたら、やる
　　○　お風呂から出て、髪をかわかしたら、やる
```

「○○の前に」は、続きません。「夕飯の前」は、夕飯が始まるギリギリまで、いくらでも先のばしにできるからです。

「○○の後に」は、ズレません。==もう毎日やっていることの、すぐ後ろ==につなげます。歯みがき、夕飯、お風呂、電車に乗る、家に着く。すでに習慣になっているものが、スイッチになります。

### 足すのは、1つだけ。2週間続いたら、少し増やします

やる気が高い時は、3つも4つも足したくなります。1つにしてください。3つ同時に足した人は、3つとも止まります。1つずつ足した人は、3ヶ月後に、3つ続いています。

最初の1つは、小さくていいんです。単語5個。1分で終わります。やる気が出たら始める、と考えている人が多いです。順番が逆です。==やる気は、始めたあとに出てきます。==5分やると、もう少しやろうか、という気になります。

2週間続いたら、量を少しだけ増やします。5個を、10個に。1つが、考えなくても始まるようになったら、次の1つを足します。

# 28　「毎日2時間やる」と、決める

## しないこと、すること

頭のいい人は、「『毎日2時間やる』と、決める」をしない。
かわりに、「最低1分、最高2時間。ゼロの日だけ作らない」をする。

## 本文

### アプリやゲームの「連続記録」が切れた、次の日。開きましたか？

連続ログイン。連続日数。10日、20日と続いていたものが、1日忘れて、0に戻る。

その次の日、どうしましたか。

……

「もういいや」と、開かなくなった人が、多いと思います。

記録が切れた時に、やめたくなる。これは、誰にでも起きます。勉強でも、まったく同じことが起きます。

「今日から毎日、英語を2時間やる。1日も休まない」。そう決めて、3日続きました。4日目。部活の練習試合で、帰りが9時を過ぎました。疲れて、そのまま寝てしまいました。

5日目の朝。

　　「あーあ、途切れた。もういいや」

そこから、英語を開かなくなりました。

### 折れるのは、できなかった日ではありません。その次の日です

こうなる生徒を、何百人も見てきました。4日目にできなかったことは、たいした問題ではありません。次の日に戻れば、何も起きません。問題は、5日目です。「毎日やる」と決めた人にとって、1日の抜けは、==計画の全部が失敗したこと==に見えます。失敗したものを続ける理由がないので、やめます。

部活の試合。文化祭の準備。風邪。家の用事。いつも通りにいかない日は、必ず来ます。「毎日、同じだけやる」という計画は、こういう日が1日もないものとして、作られています。==この計画は、最初から崩れることが決まっています。==崩れたのは、あなたのせいではありません。

### 目標を、「最低」と「最高」の2つで書きます

決め方を、変えます。

```
　　×　毎日、2時間やる
　　○　最低1分。最高2時間。ゼロの日だけ、作らない
```

1つの数字ではなく、幅にします。ノートに、こう書きます。

```
　　英語　　最低：単語を1個、声に出す　　最高：2時間
```

調子がいい日は、2時間やります。部活で遅くなった日は、1分やります。単語を1個、声に出す。それで、その日は達成です。最低は、熱があってもできる量にします。寝る前に、1問だけ解いて、○をつけて寝る。それでいいんです。

### 1分で、何が変わるのか

1分では、力はつきません。それは、その通りです。1分で守っているのは、力ではありません。==「続いている」という事実==です。

0の日があると、次の日は「再開」になります。再開は、重いです。1でもやってあれば、次の日は「続き」です。続きは、軽いです。

### 0の日が出たら、次の日は、最低だけやります

やった時間を、カレンダーに書いていきます。1週間で、こうなります。

```
　　月　2時間　　火　10分　　水　1分（部活の試合）　　木　1時間
　　金　0（帰って、そのまま寝た）　　土　1分　　日　2時間
```

金曜日に、0が出ました。取り返そうとは、しません。次の日は、最低の1分だけやります。1分やってあれば、日曜日は、「続き」から始められます。

結果を出した生徒の記録を見ると、どの子も、でこぼこしています。3時間の日もあれば、10分の日もあります。共通しているのは、==0の日がほとんどない==ことだけです。目指すのは、1日も欠けない毎日ではありません。波があっても、続いている毎日です。

## 頭のいい人と伸びない人の違い

伸びない人
毎日2時間
1日も休まない。絶対

頭のいい人
最低1分
0の日だけは、作らない

## 今日からできる3STEP

STEP01　目標を、「最低」と「最高」の2つで書く
STEP02　最低は、熱があってもできる量にする
STEP03　0の日が出たら、次の日は最低だけやる
「できた」の基準：1ヶ月のカレンダーで、0の日が2日以内ならOK！

## まとめ

「毎日同じだけやる」は、最初から、崩れることが決まっている。
だから、「毎日2時間」と決めない。最低1分と決める。
迷ったら、自分に聞きます。「今日の最低は、やった？」

# 29　寝る時間を削って、勉強する

## しないこと、すること

頭のいい人は、「寝る時間を削って、勉強する」をしない。

## 本文

先に、予想を決めてください。決めたら、スマホの、使った時間の記録（スクリーンタイムなど）を、開いてみてください。

……

予想より、長かった人が、多いと思います。

「時間が足りない」と思った時、多くの人が最初に削るのは、寝る時間です。でも、削れる時間は、たいてい、別の所にあります。

テストの日。問題を読んでも、頭に入ってきません。計算を、2回間違えました。覚えたはずのことが、出てきません。

昼に覚えたことは、その時点では、まだ消えやすい状態です。寝ている間に、頭の中で整理されて、固まります。寝ないと、この作業が起きません。つまり、夜中の2時間で覚えたことは、寝ていないので、固まらないまま朝を迎えます。

```

```

だから、最初に決めるのは、勉強の時間ではなく、寝る時刻です。「23時に寝る」と、紙に書きます。

```
　　2　次に、スマホの時間を削る

```

睡眠は、一番最後です。そして、削るとしても、1時間までにしてください。2時間を超えると、頭の働きが、はっきり落ちます。

睡眠を削る前に、見つけておくものがあります。==何もしていない時間==です。1日だけ、記録してみてください。スマホをなんとなく見ていた時間。電車でぼーっとしていた時間。合計すると、たいてい1時間を超えます。

## しないこと、すること

頭のいい人は、「好きな音楽を聴きながら、勉強する」をしない。
かわりに、「無音か、歌詞のない音にする」をする。

### 好きな曲のサビを、頭の中で歌いながら、次の3行を読んでください

```

```

### 「集中できている感じ」と、集中は、別です

好きな音楽を聞くと、気分が上がります。気分がいいので、はかどっている気がします。でも、はかどっている「気がする」のと、頭に入っているのは、別のことです。絶対法則01で見たのと同じです。やっかいなのは、==自分では気づけない==ことです。

理由は、単純です。歌詞は、言葉です。読んでいる文章も、言葉です。言葉が通る道は、頭の中に1本しかありません。2つが同時に来ると、取り合いになります。聞き流しているつもりでも、歌詞は勝手に入ってきます。そのぶん、文章が入る場所が減ります。

歌詞のある音楽を聞きながら文章を読むと、内容の理解が落ちる。これは、いくつもの実験で繰り返し確かめられています。特に、読む、覚える、文章を書く。==言葉を使う勉強ほど、大きく落ちます。==

```
　　読む　　　英語の長文、国語の文章、教科書、解説
　　覚える　　英単語、古文単語、社会の用語
　　書く　　　英作文、記述の答え、要約
```

言葉を使う勉強の間は、歌詞のある曲を止めます。無音だと、かえって落ち着かない人もいます。家がにぎやかで、音を消したい人もいます。その時は、言葉のない音にします。

```
　　×　歌詞のある曲　　好きな曲ほど、歌詞を追ってしまう
　　○　雨の音、波の音、カフェのざわざわした音、歌のない音楽
　　◎　無音
```

言葉がなければ、取り合いは起きません。

### 気分を上げたいなら、始める前に1曲

音楽が全部だめ、ということではありません。使う場所を変えます。始める前に、好きな曲を1曲。聞き終わったら、止めて、始めます。休憩の5分に聞くのもいいです。==気分を上げる時間と、頭に入れる時間を、分けます。==

### 「自分は、ながらでもできる」について

「自分は、音楽を聞きながらでも勉強できるタイプなんで」。よく聞きます。

実際に起きているのは、同時ではありません。==ものすごく速い、切りかえ==です。文章、歌詞、文章、歌詞。行ったり来たりしています。そして、切りかえるたびに、読んだ内容が、少しずつ抜け落ちています。頭のいい人は、同時にやっていません。1つずつ、やっています。

### 机の上も、1つにします

「ながら」は、音だけではありません。

机の上に、数学のノートと、英語の単語帳と、スマホと、漫画がある。目に入るたびに、頭は少しだけ、そっちのことを考えてしまいます。

机の上には、==今やる1つだけ==を置きます。そして、今やることを紙に1行書いて、見えるところに置きます。「数学　p.34の3番まで」。それが終わるまで、他のものは開きません。

歌を聞きながら
音楽があると、集中できる

頭のいい人

## 今日からできる3STEP
