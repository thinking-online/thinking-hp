# 31　好きな音楽を聴きながら、勉強する

## しないこと、すること

×　頭のいい人は「音楽を聴きながら勉強」をしない。

## 本文

### 「あいうえお、かきくけこ……」と言い続けながら、下の●を、数えてください

小さな声でも、口だけ動かすのでも、かまいません。止めずに、続けます。

```
　　●●●●●●●●●●●●●●●●●●●●●●●
```

……

答えは、23個です。

数える時、頭の中では、「1、2、3……」と、言葉を使っています。そこに、別の言葉が重なると、どちらかが、止まります。数えている途中で話しかけられて、「あれ、いくつまで数えたっけ」となるのも、同じです。

==人が、頭の中で、一度に扱える言葉は、ほんの少しです。==

歌詞のある曲を聴きながら、勉強する。この時、頭の中では、今と同じことが、起きています。

### 「音楽があったほうが、集中できるんです」

「私、音楽を聴きながらのほうが、集中できます」「音楽がないと、集中できないんですよね……」。こう言う生徒は、本当に、多くいます。

気持ちは、わかります。好きな曲を聴くと、気分が上がります。気分がいいので、はかどっている気がします。でも、==「集中できている感じ」と、「頭に入っている」は、別のこと==です。絶対法則01で見たのと、同じです。

勉強は、頭を、目いっぱい使います。文を読む。前の文を、覚えておく。つなげて、意味を取る。全部、頭の中で、言葉を使う作業です。そこに、歌詞が入ってきます。聞き流しているつもりでも、言葉は、勝手に入ってきます。「あいうえお」と言いながら、●を数えていたのと、同じ状態です。

ポルトガルの大学の研究者たちの実験でも、歌詞のある音楽を流すと、文章の理解も、覚える力も、落ちました。歌のない音楽では、落ちませんでした。

### 勉強中の音は、歌詞のないものにします

教科で、分けなくていいです。勉強中の音は、基本、歌詞なし。これだけです。

```
　　×　歌詞のある曲　　好きな曲ほど、歌詞を追ってしまう
　　○　歌詞のない音　　雨や波の音、歌のない音楽
　　○　無音
```

僕は、受験生の時から、今も、作業をする時は、ずっとそうしています。流しているのは、瞑想用のBGMか、ブラウンノイズです。ブラウンノイズは、低い音が強めの、「ゴーッ」という、おだやかな音です。僕の場合は、まわりの急な物音が、気にならなくなります。動画サイトやアプリで、名前を入れて探すと、出てきます。

ただ、ブラウンノイズで集中力が上がる、と確かめられているわけでは、ありません。合う人も、合わない人も、います。大事なのは、音の種類ではなく、==言葉が入っていないこと==です。

好きな曲は、やめなくていいです。使う場所を、変えます。始める前に1曲。休憩の5分に1曲。気分を上げる時間と、頭に入れる時間を、分けます。

### 集中できたかは、「感覚」ではなく、「結果」で決めます

音の話とは別に、大事なことを、1つ。

「集中できた」「いい感じだった」。自分の感覚で、うまくいったかどうかを、決めないでください。「集中できた気がする」も、「わかった気がする」も、当てになりません。==見るのは、結果です。集中した結果、何が、できるようになったのか。==

```
　　×　今日は、集中できた気がする
　　○　25分で、単語を30個、言えるようになった
```

曲を流した25分と、歌詞のない音にした25分。できた数を、比べてみてください。「聴きながらのほうが、集中できる」が本当かどうかは、数字が、教えてくれます。

# 32　「スマホは触らない」と、心に決める

## 本文

### プールで泳いでいる時、「スマホ、見ようかな」と迷ったことは、ありますか？

……

ないはずです。水泳の授業でも、部活の試合の最中でも、同じです。「見ようかな。いや、我慢しよう」。そんなふうに、迷うことすら、ありません。

我慢強いからでは、ありません。触れないからです。==触れないものは、我慢しなくていいんです。==

では、勉強している時は、どうでしょうか。スマホは、机の上。手をのばせば、届きます。

### 「触っていないから、大丈夫」では、ありません

こんな経験は、ありませんか。「画面は下向き。通知も切った。触らなければ、大丈夫」。2時間、1回も、触りませんでした。でも、進んだのは、ワーク3ページです。

触っていなくても、机の上にあるだけで、集中は、けずられます。見える所にある間、頭は、「見ない」「触らない」を、ずっと続けているからです。==我慢するのにも、頭を使います。==鳴っていないのに、鳴った気がして、目が行く。それは、頭のどこかで、ずっとスマホを気にしている、ということです。31番で見た通り、頭が一度に扱える量は、多くありません。その一部が、我慢に使われています。

スタンフォード大学の研究者たちが、幼稚園の子どもたちで行った、有名な実験があります。「食べずに待てたら、好きなほうのお菓子をあげる」と伝えて、待ってもらいます。お菓子が見えている子は、長く待てませんでした。見えない所に置かれた子は、ずっと長く待てました。差を作ったのは、意志の強さより、==見えているかどうか==でした。

### 見るのは、10秒。でも、失うのは、10秒では、ありません

例えば、数学の問題を、解いている途中です。机の上で、通知が光りました。「確認するだけ」。10秒で、画面を伏せて、ノートに戻ります。

失ったのは、10秒でしょうか。

10秒では、ありません。==集中は、眠りと、似ています。入るまでに、時間がかかるからです。==

夜、やっと眠れそうになった時に、物音で、10秒だけ、目が覚めた。そんな経験が、あると思います。起きていたのは、10秒です。でも、もう一度眠れるまでには、ずっと長く、かかったはずです。

勉強でも、同じことが起きます。ノートに戻ると、「えーと、どこまで解いたっけ」。問題文を、読み直します。しかも、頭のどこかで、さっきの通知のことを、まだ考えています。

作業を中断された人が、元の作業に戻るまでに、平均で20分以上かかっていた、という、アメリカの大学の調査があります。一度切れた集中は、すぐには、戻りません。

### 「つい、触っちゃうんです」

相談で、本当に、よく聞く言葉です。でも、スマホが、勝手に、手の中に飛びこんでくることは、ありません。最後は、自分の手で、取っています。

責めているのでは、ありません。逆です。机の上にあれば、「触るか、触らないか」を、何十回も、自分で決めることになります。何十回も決めていれば、誰でも、いつかは、「触る」を選びます。

真面目な人ほど、「次こそ、誘惑に負けない」と、気持ちで勝とうとします。でも、変えるのは、気持ちでは、ありません。==「触るか、触らないか」を、決めなくていい状態にします。==

プールの中では、迷いませんでした。触れなかったからです。勉強の間も、同じ状態を、作ります。

### 始める前に、電源を切って、別の部屋に置きます

置き方を工夫しても、変わりません。変えるのは、場所です。

テキサス大学の研究者たちが、スマホの置き場所を変えて、頭を使う課題の成績を比べた実験があります。机の上に伏せて置く。ポケットやカバンに入れる。別の部屋に置く。どれも、音は鳴らず、誰も触っていません。それでも、成績が一番よかったのは、別の部屋に置いた人たちでした。同じ結果にならなかった実験もありますが、別の部屋に置いて、損をすることは、ありません。

```
　　×　机の上に置く（画面を下にしても、同じ）
　　○　別の部屋に置く
　　○　家の人に預ける
```

基準は、2つです。見えないこと。立ち上がらないと、取れないこと。

僕は、受験生の時、スマホの電源を切って、別の部屋の、リュックの一番底に入れていました。取り出すには、部屋を出て、リュックを開けて、荷物を全部出して、電源を入れて、起動を待たないといけません。そこまで面倒だと、「まあ、いいか」になります。

「連絡が来るかもしれないから」。そう思う人は、始める前に、家の人に、一言、言っておきます。「9時まで、別の部屋に置くから、用がある時は、部屋に来て」。

スマホを持っていない人は、ゲーム機や、漫画で、同じことをしてください。

# 33　早起きして、朝型になろうとする

## 本文

### お昼ごはんのあとの授業。眠くて、先生の話が、頭に入ってこなかったことは、ありませんか？

……

あると思います。サボっていたわけでは、ありません。1時間目は、ちゃんと聞けていました。同じ日の、同じあなたです。違うのは、時間だけです。

==集中には、1日の中で、波があります。==高い時間と、低い時間です。昼すぎに落ちるのは、お昼ごはんを抜いても、起きることがわかっています。意志では、動かせません。

そして、この波の形は、人によって、違います。

### 「朝5時に起きる人が、勝つ」は、本当でしょうか

「できる人は、朝5時に起きている」。そう聞いて、早起きを始めたことがある人も、多いと思います。僕も、やりました。

浪人していた頃、「朝活だ」と言い出して、朝5時に起きるようにしました。朝一番に、ハンバーガーのお店に入って、勉強を始めます。なんだか、できる人になった気がしました。3日は、続きました。でも、午前は、ずっと眠い。昼を過ぎると、何を読んでも、頭に入らない。1週間で、やめました。

あとから、気づきました。勉強するために早く起きたはずなのに、いつのまにか、==早く起きることが、目的==になっていました。

朝早くからやっている人は、えらく見えます。でも、見るのは、起きた時刻では、ありません。その日、どれだけ進んだかです。

ドイツの大学の研究者たちが、8歳から90歳まで、約2万5千人の、寝る時刻と起きる時刻を調べました。朝型と夜型の、2つには、分かれませんでした。真ん中が一番多くて、朝に強い人も、夜に強い人も、少しずついます。しかも、10代は、20歳ごろに向かって、体のリズムが、だんだん後ろにずれていくことも、わかりました。

10代で、朝がつらいのは、怠けているからでは、ありません。

朝に頭が回らない人が、無理に朝5時に起きて、一番難しい問題を解く。それは、==わざわざ、自分の波が一番低い時間を、選んでいる==ことになります。

### 何時にやるかより、「波が高い時間に、何を置くか」

大事なのは、何時に勉強するかでは、ありません。==自分の頭が一番回る時間に、一番大事なものを置くこと==です。

まず、自分の波を、つかみます。31番で見た通り、感覚では、決めません。1週間、25分ごとに、できた数を、時刻と一緒に書いておきます。多く進んだ時間帯が、あなたの波の、高い所です。

```
　　波が高い時間　→　重いもの。数学の応用、英語の長文、初めて習う所
　　波が低い時間　→　軽いもの。単語、漢字、丸つけ
```

09番の「25分」も、波に合わせて、変えていいです。高い時間は、少し長く。低い時間は、短く区切ります。

僕の場合は、午前が、一番進みます。だから、午前に、考える問題と読解を置いて、眠くなる昼すぎは、暗記を速く回す時間にしていました。

波が低い時間に、眠気と戦いながら、1時間座っている。これが、一番もったいないです。同じ行を何度も読んで、何も残りません。

眠い時は、寝ます。ただし、短くです。10分から20分の仮眠で、眠気が取れて、そのあとの成績も上がった、という実験が、いくつもあります。==たった15分でも、頭は、相当すっきりします。==

```
　　・タイマーを、15分にかける
　　・ベッドには入らない。机に伏せるか、いすにもたれる
　　・30分はこえない。長く寝るほど、起きた直後に、ぼーっとしやすい
```

小さなコツを、1つ。コーヒーや緑茶をふだん飲む人は、仮眠の直前に飲んでおくと、すっきり起きやすくなります。カフェインが効き始めるのは、30分ほどあと。眠りのじゃまはせず、ちょうど起きるころに、効いてくるからです。夕方より遅い時間には、やりません。夜、眠れなくなります。

受験は、長距離走です。1日だけ、朝5時に起きて、次の日から崩れる。それより、自分の波に合わせて、毎日、進め続ける。本番までの合計が大きくなるのは、あとのほうです。

1日の合計。1週間の合計。本番までの合計。見るのは、ここです。「あの人は、朝5時からやっている」に、振り回されないでください。

1つだけ。入試は、午前に始まります。極端な早起きは、いりません。ただ、試験が始まる時刻には、頭が働いている状態に、しておきたいところです。本番が近づいたら、起きる時刻を、少しずつ、本番の日に合わせます。そして、試験が始まる時刻に、一番重いものを解くようにします。

### テスト前になると、急に、部屋を片づけたくなりませんか？

……

なりますよね。ふだんは、気にならないのに。

僕も、定期テストのたびに、やっていました。「まず、机を片づけよう。きれいにしてから、本気を出す」。プリントを分けて、引き出しを整理して、本棚もそろえます。新しいノートとペンを、買いにも行きました。帰ってきたら、夜でした。問題は、1問も、解いていません。

だらしないからでは、ありません。人の頭には、こうなる「くせ」があります。

### バケツが、2つあります。どちらを拾って、ゴールまで運びますか？

あなたは、スタートからゴールまで、まっすぐ歩きます。途中に、同じ重さのバケツが、2つ。どちらか1つだけを拾って、ゴールまで運びます。

……

Aを拾っても、早くは終わりません。それでも、「バケツを拾う」という用事を、頭に残したまま歩くより、先にすませてしまいたかったのです。

頭の中に「やらなきゃ」があると、それだけで、気になります。だから、==余計な力を使ってでも、早く1つ、片づけてしまいたくなる。==「プレクラスティネーション」と呼ばれる、人のくせです。（名前は、覚えなくてOKです）

そして、==準備で、時間も、体力も、使い切ります。==試合の前のウォーミングアップで、走りすぎて、試合でへとへと。あの日の僕は、それと、同じことをしていました。

### 「まず、〇〇してから」が浮かんだら、先に1問、解きます

片づけだけでは、ありません。計画表を作り直す。ノートをまとめ直す。文房具をそろえる。==「まず、〇〇してから」==が頭に浮かんだら、同じくせが、出ています。

このくせは、気合いでは、消えません。だから、使います。早く1つ終わらせたいなら、その「1つ」を、勉強にします。

```
　　×　〇〇する　→　勉強を始める
　　○　1問だけ解く　→　〇〇する
```

浮かんだ用事は、紙に1行、書きます。「あとで、引き出し」。書けば、頭から降ろせます。そして、先に、1問だけ解きます。1問なら、5分で終わります。○でも、×でも、「1つ終わった」が、すぐに手に入ります。書いた用事をやるのは、25分やったあとの、休憩の5分です。

# 35　出された宿題を、全部同じ本気でやる

## しないこと、すること

×　頭のいい人は「全部に全力」をしない。
○　頭のいい人は「選んで全力」をする。

## 本文

### 「あれもやらなきゃ、これもやらなきゃ」。そう思っているうちに、1日が終わったことは、ありませんか？

……

あると思います。やる気は、ありました。机にも、向かいました。でも、数学を解いている途中で、「あ、英語の課題、明日までだ」。英語を開くと、「理科のレポートも、あった」。どれも、少しずつ手をつけて、どれも、終わっていません。

「やらなきゃ」は、別のことをやっている間も、消えていません。頭のどこかに、ずっと、残っています。

スマホで、アプリをいくつも開いたままにすると、動きが重くなります。頭も、同じです。「やらなきゃ」を、いくつも抱えたままだと、目の前の1つに、力を回せません。

集中できないのは、意志が弱いからでは、ありません。==抱えたままの「やらなきゃ」が、多すぎるからです。==

### 「決めていないこと」は、頭を使い続けます

31番で見た通り、頭が一度に扱える量は、多くありません。

アメリカの大学の研究者たちの実験です。「まだ終わっていない用事」を抱えた人に、それとは関係のない文章を、読んでもらいました。読んでいる間も、用事のことが、何度も頭に浮かびました。別の課題の成績も、落ちました。

ところが、その用事を、「いつ、どうやるか」まで決めてもらうと、じゃまは、消えました。用事は、まだ、1つも終わっていません。==終わらせなくても、決めるだけで、頭から降りたのです。==

集中できる人は、用事が少ない人では、ありません。決めてある人です。

### 全部に全力は、最初から、入りきりません

では、全部を「やる」と決めれば、いいのでしょうか。それは、できません。

数学の先生は、数学のことだけを考えて、課題を出します。英語の先生も、理科の先生も、同じです。その全部を、足し算した人は、どこにもいません。誰も、悪くありません。ただ、最初から、1日に入りきらない量です。

「全部、ちゃんとやらないと」と抱えている限り、終わらないものが、頭の中に、ずっと残ります。==全部に全力を出そうとする人ほど、集中できなくなります。==

### 選んで、全力を出します

やることは、1つです。==頭の中の「やらなきゃ」を、全部、「いつ、やる」か、「やらない」に、変えます。==

「やらなきゃ」を、紙に書き出します。そして、1つずつ、2つのことを確かめます。気持ちでは、決めません。==見ればわかる事実で、決めます。==

```
　質問1　04番で決めた「やること」に、入っている？
　　　　　はい　→　全力。一番進む時間に置く（33番）
　質問2　全員が、やると決まっているもの？
　　　　　はい　→　短く。いつ、何分でやるかを決めて、終わらせる
　　　　　いいえ　→　やらない
```

質問1は、04番で書いた紙を見れば、わかります。質問2は、全員が出す提出物や小テストなら「はい」、希望する人だけの補習や、自分で足した参考書なら「いいえ」です。誰が分けても、同じ答えになります。

```
　　英語の長文（「やること」に入れた）　　　→　全力。毎日、夜8時から
　　理科のレポート（入れていない。全員が出す）→　短く。木曜に、40分
　　希望する人だけの補習（入れていない教科）→　やらない
```

中学生で、内申が入試に使われる人は、提出物や小テストも、04番の「やること」に入ります。入試の点、そのものだからです。

「全力」は、できるようになるまで、やります。「短く」は、終わらせれば、十分です。混ぜません。

書き終わった紙に、「やらなきゃ」は、もう、1つもありません。あるのは、「いつ、やる」と、「やらない」だけです。頭に残るのは、今やる1つです。

ブレない人は、性格が強いのでは、ありません。決めてあるから、ブレないのです。==やらないことを決めた人だけが、やると決めたことに、頭の全部を使えます。==
