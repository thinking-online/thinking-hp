# 第6章　【モチベーション】頭のいい人は、やる気に頼らない

## 章の導入文

### 「元気、出しなよ」。そう言われて、元気が出たことは、ありますか？

……

あまり、ないと思います。「気にするな」と言われても、気になります。「落ち着いて」と言われても、落ち着けません。

気持ちは、命令では、動きません。人に言われても、動かない。それなのに、自分には、毎日、命令しています。「やる気を出せ」。「落ち込むな」。「不安になるな」。そして、動かない自分を見て、「自分は、メンタルが弱い」と思ってしまいます。

弱いのでは、ありません。==やり方が、違うだけです。==

落ち込む。人と比べる。不安になる。どれも、本気でやっている人に、起きることです。頭のいい人にも、同じように起きています。違うのは、そのあとです。頭のいい人は、気持ちを、変えようとしません。==変えるのは、言葉と、行動です。==気持ちは、あとから、ついてきます。

この章では、そのやり方を、5つ、書きます。

やる気は、合格体験記を、先に自分で書いて作る。失敗した時は、親友に言う言葉を、自分にかける。比べる相手は、昨日までの自分にする。「できない」には、「まだ」を足す。不安は、消そうとせずに、紙に書く。

5つとも、やっていることは、同じです。気持ちと、戦わない。気持ちがどうであっても、動ける形を、持っておく。

# 36　合格体験記を読んで、やる気を出す

## しないこと、すること

×　頭のいい人は「合格体験記を読む」をしない。
○　頭のいい人は「合格体験記を先に書く」をする。

## 本文

### 先輩の合格体験記を読んで、「よし、自分も」と思ったことは、ありませんか？

……

あると思います。E判定からの、逆転合格。読んでいると、胸が熱くなります。気づくと、受かった自分を、思い描いています。「逆転合格」の動画でも、同じです。

では、もう1つ。その「よし、自分も」は、何日、続きましたか。

……

次の日には、消えていた人が、多いと思います。やる気が足りないからでは、ありません。思い描いたものが、「結果」だったからです。

### 「成功した自分をイメージすれば、夢はかなう」。実験の結果は、逆でした

カリフォルニア大学ロサンゼルス校の研究者たちが、試験を1週間後にひかえた大学生で、確かめています。毎日5分、次のどちらかを、思い描いてもらいました。

```
　　A　いい点を取って、喜んでいる自分
　　B　机に向かって、勉強している自分
```

何も思い描かなかった学生たちと比べると、Bのグループは、勉強時間が長く、点も高くなりました。Aのグループは、勉強時間が、かえって短くなりました。点も、上回りませんでした。

いい結果を思い描くと、いい気分になります。その時、頭は、まだ何もしていないのに、「もう、手に入れた」と、かんちがいします。安心すると、人は、動きません。

==思い描くなら、結果ではなく、途中です。==

### 読むのではなく、自分の合格体験記を、先に書きます

先輩の体験記を読んで手に入るのは、「受かった」という結果の気分と、先輩の途中です。あなたの途中は、どこにも、書いてありません。だから、自分で書きます。

受かったあとの自分になったつもりで、==自分の合格体験記を、今、書きます。==全部、過去形です。書くのは、4つ。この順番で、書きます。

```
　　①合格した日の場面　3月10日。番号を見つけて、母に「あった」と言った
　　②一番きつかった時　9月。部活のあと、ベッドでスマホを見ていた
　　③その時、どうしたか　家に着いたら、座る前に、1問だけ解くことにした
　　④月ごとに、やったこと　4月、寝る前に単語を30個。毎日やった
　　　　　　　　　　　　　夏休み、基礎の問題集を、3周した
```

結果を書くのは、①だけです。ここは、思いきり、いい気分で書いて、かまいません。ただ、①だけで終わると、さっきのAのグループと、同じです。==すぐ下に、②と③を並べます。==すると、頭は、「まだ、手に入れていない」と、気づきます。

この並べ方には、名前があります。かなえたいこと（Wish）、いい場面（Outcome）、邪魔（Obstacle）、その時どうするか（Plan）。頭文字を取って、「WOOP（ウープ）」。心理学で、よく知られたやり方です。この4つを、30分、紙に書いた高校生は、別のことを書いた高校生より、そのあとに解いた練習問題が、6割ほど、多くなりました。

受験がまだ先の人は、次の定期テストで書きます。「期末テストで、数学が80点を超えた日」の体験記です。

### 邪魔は、自分の中から、探します

一番大事なのは、②です。コツは、1つ。自分で変えられることを、書きます。

```
　　×　部活が、忙しかった　　　　　　　　　　自分では、変えられない
　　○　部活のあと、ベッドでスマホを見ていた　自分で、変えられる
```

「忙しい」「時間がない」と書くと、③に、書くことが、なくなります。「その時、自分は、何をしてしまうか」まで書くと、③が、決まります。③は、28番の「if-thenプラン」の形で書きます。

### 書けない所が、まだ決まっていない所です

④を書いていると、手が止まる月が、出てきます。「夏休みに、何をやったか」が、書けない。それは、夏休みにやることが、まだ決まっていない、ということです。

書けなくて、いいんです。==書けない所を見つけるために、書きます。==見つけたら、その月にやることを、1行だけ決めて、書きこみます。先輩の体験記を読むなら、ここで使います。気持ちではなく、「やったこと」を、④に抜き出します。

### 毎日の勉強で、1行ずつ、本当のことにします

書いた体験記は、机の前に貼ります。そこに書いてあるのは、まだ、起きていないことです。毎日の勉強で、1行ずつ、本当のことにしていきます。

今日の長文1題は、ただの1題では、ありません。体験記の1行を、本当にする1題です。やる気が出ない日は、気分を上げようとしなくていいです。自分に、こう聞きます。==「受かった自分は、今日のことを、何と書く？」==

### 親友が、模試でE判定を取りました。何と、声をかけますか？

……

では、自分が、テストで悪い点を取った時。自分に言った言葉を、思い出してください。

……

2つを、並べてみてください。同じ言葉でしたか。

### 親友が同じ失敗をしたら、何と言うかを、書きます

紙を1枚、出します。まず、起きたことだけを、1行で書きます。「3問、間違えた」。「自分はダメだ」は、起きたことではありません。それを見て、自分が思ったことです。起きたことは、1つです。思ったことのほうは、変えられます。

　　「でも、ここは合ってるじゃん」
　　「ミス、3つとも種類が違うね。次は、符号だけ見直してみたら？」

できているところを見て、次にやることを1つ、一緒に考えます。==自分にだけ、一番ひどい言葉を使っている。==ほとんどの人が、そうです。親友に言うその言葉を、2行、自分に向けて書きます。

　　変えられるもの　　　次の見直しのやり方。今日の30分
```

変えられないものは、何時間考えても、変わりません。考えた時間だけが、消えます。書き終わった紙は、こうなります。

```

　　親友なら　　　　「でも、ここは合ってるじゃん」
　　　　　　　　　　「次は、符号だけ見直してみたら？」

親友が思い浮かばない時は、部活の後輩や、1年後の自分でも、かまいません。近すぎると、責める言葉しか出てきません。==一歩はなれると、次にやることが見えます。==

### 甘やかすのとは、違います

基準を下げる、という話ではありません。3つのミスを「まあいいか」で流すのは、甘やかしです。変えるのは、基準ではなく、==言葉の向き==です。

```

「ダメだ」は、人に向いた言葉です。「どの作業で落としたか」は、やり方に向いた言葉です。（落とした作業に名前をつける方法は、22番に書きました）

# 38　できる友達と比べて、落ち込む

## しないこと、すること

×　頭のいい人は「友達と比べる」をしない。
○　頭のいい人は「昨日の自分と比べる」をする。

## 本文

### クラスで、自分より成績がいい人を、1人、思い浮かべてください

すぐに、顔が浮かんだと思います。その人の、前のテストの点も、だいたい言えるはずです。

　　「模試どうだった？」「んー、まあまあ。8割くらい」

---

これを書いているのは、同じことを経験した人からの手紙を、何百通も読んできたからです。その中の1通に、こうありました。「自分は努力してるのになんでこんなに低いんだろうと悩んで、泣いたりしていました」まず言いたいのは、これです。

あの子の8割は、今日できたことではありません。小学校から今日までの、積み上げの結果です。自分の5割も、同じです。つまり、比べているのは、お互いの「これまで全部」です。これまで全部は、今日どうにもなりません。

```
　　変えられないもの　他人と、これまで
　　変えられるもの　　自分と、これから
```

考えていいのは、下だけです。上は、何時間考えても、変わりません。

そして、あの子が、先月から何点上がったのかは、見えません。下がっているかもしれません。見えているのは、あの子の今の点だけです。見えないものと比べているから、何回比べても、答えが出ないのです。

よく「人と比べるな」と言われます。無理です。教室に人がいるかぎり、比べます。やるのは、比べる相手を変えることです。

```

これなら、変化が見えます。しかも、自分で動かせます。あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきりわかります。

### 落ち込んだら、その点を見て、上がった理由を書きます

比べて落ち込んだ1時間に、1問も解いていません。責めているのではありません。落ち込むな、とも言いません。落ち込みます。言いたいのは、落ち込む時間を短くしたほうが得だ、ということです。だから、落ち込んだ時に、やることを決めておきます。

# 39　「自分はできる」と、言い聞かせる

## しないこと、すること

×　頭のいい人は「無理にポジティブ思考」をしない。
○　頭のいい人は「Not Yet思考」をする。

## 本文

### 心の中で、3回、言ってみてください。「自分は、天才だ」

……

信じられましたか。

言いながら、どこかで、「いや、そんなわけないし」という声が、聞こえたと思います。自分が本当だと思っていない言葉は、何回言っても、信じられません。

例えば、数学の模試が、返ってきた時。また、40点です。落ちこみます。

　　「大丈夫。自分はできる。次は絶対いける」

気持ちは、少し楽になりました。次の模試。40点でした。

### 「できる」も「できない」も、そこで話が終わります

「ポジティブに考えよう」「自分を信じよう」。よく言われます。ニューヨーク大学の研究者たちが、長く続けている研究があります。うまくいく場面を、強く、明るく思い描いた人ほど、==そのあとの行動が減り、結果も出にくかった==というものです。

36番で書いたのと、同じことが起きています。「自分はできる」と言い聞かせると、気持ちが楽になります。その楽さで、少し満足します。だから、次の模試までに、やることが変わりません。

じゃあ、落ちこんだままでいいのか。それも、違います。面談で、一番よく聞く言葉は、「自分、数学できないんで」です。この言葉を言った瞬間に、話が終わります。できないのだから、やってもしょうがない。やらないので、できないままになる。「自分はできる」も、「自分はできない」も、同じです。==どちらも、そこで終わっている==んです。

### 1語だけ、足します

　　自分は、数学が、==まだ==できない。

この文は、終わっていません。「まだ」と言った瞬間に、じゃあ、いつできるのか、という続きが必要になります。==どう言うかで、次にどこを見るかが決まる==という話です。「まだ」は、英語で、Not Yet。この考え方を、「Not Yet思考」と呼びます。

「数学ができない」では、どこを見ればいいのか、わかりません。数学は、大きすぎます。「まだ」を足すと、言い直したくなります。全部ができないわけではないからです。計算はできる。基本問題も解ける。だから、「何が」まだなのかを、小さく言います。

```
　　自分は、数学ができない
　　→　自分は、数学が、まだできない
　　→　二次関数の最大値が、まだ出せない
　　→　今日、教科書の、最大値のページを開く
```

ここまで小さくなれば、今日やることが、1つに決まります。教科書のそのページを開けばいい。「まだ」を足すと、できないところが、小さくしぼられます。前向きになるからではなく、==正確になるから==です。

### つまずきを、「限界」と呼ぶか、「途中」と呼ぶか

難しい問題にぶつかった時、頭の中で起きることは、2通りあります。

```
　　「できない」　　　→　自分の力の、限界だと受け取る　→　やめる
　　「まだできない」　→　今、途中にいると受け取る　　　→　続ける
```

アメリカのシカゴに、単位を落とした生徒の成績を、「不合格」ではなく、「Not Yet（まだ）」とつける高校があります。スタンフォード大学の研究者が、講演で紹介した話です。「不合格」は、そこで終わりです。「まだ」は、道の途中です。この研究者たちは、「力は、伸ばせるものだ」という考え方を、「成長マインドセット」と呼んでいます。そう考えている生徒のほうが、難しい問題にぶつかった時に、やめずに続ける傾向がありました。

### 無理に、明るくならなくていいです

落ちこんで、いいです。うれしくないものを、うれしいふりをする必要はありません。Not Yet思考は、2つで、できています。「今は、できない」と、認めること。そして、「でも、できるようになる」と、考えること。できない自分を、ごまかさない。そのうえで、地に足をつけて、進みます。やるのは、気持ちを変えることではなく、==事実を、そのまま、正確に言うこと==です。

　　「今、二次関数の場合分けが、まだできていない」

暗い言葉ではありません。明るい言葉でもありません。正しい言葉です。そして、正しい言葉からは、次にやることが出てきます。

## 頭のいい人と伸びない人の違い

伸びない人
「自分はできる」
いける。絶対いける

頭のいい人
「まだ、できない」
じゃあ、何が足りない？

## 今日からできる3STEP

STEP01　「できない」と言いそうになったら、「まだ」を足す
STEP02　「何が」まだなのかを、小さく言う
STEP03　今日やることを1つ決めて、そのページを開く
「できた」の基準：「○○が、まだできない」と言えて、そのページを開けたらOK！

## まとめ

「自分はできる」も「自分はできない」も、そこで話が終わる言葉。
だから、無理に前向きにならない。「まだ」をつける。
迷ったら、自分に聞きます。「何が、まだできない？」

# 40　不安や緊張を、頭の中で消そうとする

## しないこと、すること

×　頭のいい人は「不安を消そうとする」をしない。
○　頭のいい人は「不安を紙に書く」をする。

## 本文

### これから10秒、白いクマのことを、絶対に、考えないでください

どうぞ。

……

考えましたね。

「考えるな」と言われると、頭は、「今、考えていないか」を確かめ続けます。確かめるたびに、白いクマが出てきます。不安も、同じです。

こんな経験は、ありませんか。夜の10時。参考書を開いています。目は、字を追っています。でも、頭は、別のことを考えています。

　　このやり方で、合ってるのかな。
　　このままで、間に合うのかな。

「考えるな。考えるな。集中しろ」。1時間たちました。進んだのは、3ページです。机には、いました。参考書も、開いていました。それでも、頭は1時間ずっと、答えの出ない問いを、考え続けていました。

### 不安は、今、答えが出ない問いです

「このやり方で合ってるのか」という問いに、今、答えは出ません。出ないものを考え続けると、==考えるだけで終わります。==そして、考えている間は勉強している感じがします。真剣だからです。だから、止まっていることに気づけません。

```
　　答えが出る問い　　「この問題の答えは？」　　→　解けば出る
　　答えが出ない問い　「このやり方は正しい？」　→　やってみるまで出ない
```

サボっている人は、不安になりません。やり方が合っているか気になるのは、結果を出したいからです。==不安は、手を抜いていない証拠です。==

### 紙に出して、10分だけ手を動かす

最初の、白いクマと同じです。不安も、考えないようにするほど、考え続けます。消そうとするのではなく、==置く場所を変えます。==頭の中から、紙の上へ。

```
　1　紙を1枚出して、今、不安なことを全部書く。5分。文にならなくていい
　2　書いたら、その紙を裏返す
　3　タイマーを10分にして、一番軽いものを1つやる
　　　単語10個。計算3問。漢字10個
　4　10分経ったら、もう一度その紙を見る
```

4が大事です。10分前に書いた不安を見ると、==大きさが変わっています。==手を動かす前は、やることが「全部」残っています。10分やったあとは、「残り」になっています。減ることがわかると、次の10分に入れます。

### 不安の種類で、やることが変わります

書き出した紙を見ると、不安は、3つに分かれます。

```
　　このやり方で、合ってるのかな　→　1　10分やって、閉じて出せたかを見る
　　このままで、間に合うのかな　→　2　数字にする。あと何週間、1週間に何点
　　落ちたら、どうしよう　　　　→　3　答えは出ない。書いて、裏返す
```

1と2は、手を動かすと答えが出ます。3は、出ません。3を1や2と同じように考え続けるから、終わらなくなります。==3は、解決するものではなく、置いておくものです。==

### それでも動けない日のために

ここまでのやり方は、「不安だけど、やろうとは思える」状態のためのものです。涙が出て止まらない。眠れない日が続く。何日も机に向かえない。そういう日があるなら、それは勉強のやり方の問題ではありません。==先に、人に言ってください。==親でも、学校の先生でも、塾の人でも、誰でもいいです。言いにくければ、紙に書いて渡すだけでもいいです。僕も、浪人の年に動けなくなった時期がありました。あの時動けるようになったのは、やり方を変えたからではありません。1人、笑わずに聞いてくれる人がいたからです。勉強の話は、そのあとで間に合います。

### 本番の前も、同じです。10分前に、紙に出します

試験が始まる、15分前。席に座っています。参考書を開いていますが、頭に入ってきません。落ちたらどうしよう。あの単元、やってない。周りの人、みんなできそうに見える。「落ち着け。考えるな」。そう思ったとたん、もっと考えます。

やることは、普段と同じです。試験開始の10分前に、紙を1枚出して、今、不安に思っていることを、5分、全部書きます。書いたら、裏返します。捨ててもいいです。

シカゴ大学の研究者たちの実験では、試験の直前に10分、今、不安に思っていることを紙に書き出したグループのほうが、関係のないことを書いたグループより、==試験の点が高くなりました。==差が一番大きかったのは、普段から試験で不安が強くなる学生でした。

書くのは、不安そのものです。対策では、ありません。ここで「じゃあ図形を10分でやろう」としないでください。できないことを始めると、不安が増えます。

### 緊張は、「ワクワクしている」と言いかえます

紙を裏返したあと、まだ心臓が速いことがあります。落ち着け、落ち着け、と心の中で言います。言うたびに、落ち着いていない自分に気づいて、余計に焦ります。上がっている心拍数を、1分で下げるのは、無理があります。

```
　　緊張している時　　　　心臓が速い　手が冷たい　息が浅い　体が熱い
　　ワクワクしている時　　心臓が速い　手が冷たい　息が浅い　体が熱い
```

体に起きていることは、同じです。違うのは、それを自分が何と呼んでいるかだけです。だから、落ち着こうとするかわりに、こう言います。

```
　　ワクワクしている。
　　体が、本気を出す準備をしている。
```

声に出さなくていいです。心の中で3回。心拍数は、下がりません。下げる必要が、ありません。==変えるのは、体ではなく、呼び方です。==息が苦しい時は、吐くほうを、長くします。4秒で吸って、8秒で吐く。これを3回。

言いかえは、会場に着く前から使えます。電車でそわそわする。開始1分前。全部、「ワクワクしている」です。普段の小テストや模試で使っておくと、本番で、自然に出ます。

## 頭のいい人と伸びない人の違い

伸びない人
不安を消す
考えるな、考えるな……

頭のいい人
不安を書く
紙に出して、手を動かそう

STEP02　一番軽いものを、10分だけやる
STEP03　緊張したら、「ワクワクしている」と3回言う
「できた」の基準：書いて裏返したあと、10分、手が動いたらOK！

## まとめ

不安も緊張も、頭の中で消そうとするほど、大きくなる。
だから、消そうとしない。不安は、紙に出す。緊張は、言いかえる。
迷ったら、自分に聞きます。「今の不安、紙に書いた？」
