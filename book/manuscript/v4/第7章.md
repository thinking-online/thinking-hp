# 第7章　【アップデート】頭のいい人は、1人で頑張らない

## 章の導入文

### この1か月で、勉強のことを、誰かに質問しましたか？

先生でも、友達でも、AIでも、かまいません。何回、ありましたか。

……

0回か、1回。そういう人も、多いと思います。

聞きたいことが、なかったからでは、ありません。「こんなことを聞いたら、恥ずかしい」「自分の力でやらないと、意味がない」。そう思って、1人で、抱えこんでいます。真面目な人ほど、そうです。

頭のいい人は、違います。==使えるものは、全部使います。==人にも聞きます。AIも使います。ただし、使い方を知っています。頭を使うところは、自分でやる。そうでないところは、人やAIの力を借りる。

そうやって、自分のやり方を、新しくし続けます。この本では、それを、「アップデート」と呼びます。絶対法則01の「疑う」を、自分のやり方に、向け続けることです。

最後の章は、6つです。人の力の借り方が2つ。AIの使い方が2つ。お金の使い方が1つ。そして最後に、この本で、一番伝えたいことを書きます。

# 41　全部、自分1人でやろうとする

## しないこと、すること

×　頭のいい人は「全部、自分1人でやろうとする」をしない。
○　頭のいい人は「途中で見せて、指摘をもらう」をする。

## 本文

### 録音した自分の声を、聞いたことがありますか？

……

「え、こんな声なの？」と、思いませんでしたか。

生まれてから毎日、聞いている声です。それでも、外から聞くと、自分が思っていた声とは、違います。

==自分のことは、自分では、見えません。==声でさえ、そうです。勉強のやり方や、答案の書き方は、もっと見えません。

英作文の練習を、しています。問題を解いて、模範解答を見ます。自分の答えと、模範解答は、違う文です。

　　「人に見せるのは、もう少し書けるようになってから。今は、自分で直そう」

模範解答を、ノートに写します。「こう書けばいいのか」。次の問題へ進みます。

3か月たちました。50題、解きました。でも、自分の書いた文が、何点なのかは、今も、わかりません。同じ間違いを、50回、続けていたかもしれません。

### フォームも、自分では見えません

バスケのシュートを、ひじが開いたまま1000本打つと、ひじが開いたフォームが、体に入ります。本人は、気づいていません。自分のフォームは、自分では見えないからです。コーチが、横から見て、一言。「ひじ、開いてるよ」。3秒で、わかります。

勉強も、同じです。答えが違う、計算が合わない。こういう間違いは、自分で気づけます。でも、考え方のくせ、答案の書き方、時間の使い方、勉強のやり方そのものは、1人で何時間やっても、見えません。==見えないものは、直せません。==

### 見せるのは、「できてから」ではなく、「途中」です

多くの人は、「もう少しできるようになってから、見せよう」と思います。できていない所を、見られたくないからです。でも、順番が逆です。

```
　　できてから見せる　→　ズレたまま、何十時間も進む。直す量が、増える
　　途中で見せる　　　→　ズレが小さいうちに、直せる
```

絶対法則06で書いた通り、早く間違えて、早く直す。人に見せるのも、同じです。==見せるのが早いほど、直すのが楽です。==

### 見せるものを1つ決めて、「一番直す所」を聞きます

見せる相手は、学校の先生、塾の先生、その教科が得意な先輩や友達。相手がいない時は、AIにも見せられます（43番と44番）。見せるものは、3つあります。この中から、1つ決めます。

```
　　答案　　記述、英作文、数学の途中の式。「どこで点を引かれますか」
　　やり方　今使っている本と、1週間の進め方。「これで、足りますか」
　　計画　　ゴールと、やる3つ（絶対法則04）。「順番は、これで合っていますか」
```

そして、聞き方を、1つ決めておきます。

　　==「一番直したほうがいい所は、どこですか」==

「どうですか」と聞くと、「いいんじゃない」で終わります。「一番直す所」を聞くと、1つ、返ってきます。直すのは、その1つだけで、いいです。全部を直そうとすると、続きません。（質問のしかたは、42番で、もう少し細かく書きます）

言われた所を直したら、もう一度、同じ人に見せます。直ったかどうかも、自分では、見えないからです。「直りました」と言ってもらって、初めて、その1つが終わります。最初に出した英作文の練習なら、こうなります。

```
　　見せるもの　英作文の答案を、3題
　　聞く　　　　「一番直したほうがいい所は、どこですか」
　　返ってきた　「時制。昨日の話なのに、現在形で書いている」
　　直す　　　　3題とも、時制だけを書き直す
　　もう一度　　同じ先生に見せて、「直りました」をもらう
```

### 1人でやるのが、えらいわけではありません

「人に頼るのは、甘えだ」。「自分の力でやらないと、力がつかない」。真面目な人ほど、そう思っています。分けて考えます。

```
　　自分でやること　　　　考える。解く。思い出す。直す
　　人に見てもらうこと　　どこがズレているかを、見つける
```

解くのを、人にやってもらったら、力はつきません。でも、ズレを見つけてもらうのは、甘えでは、ありません。スポーツの選手に、コーチがいるのと、同じです。

## 頭のいい人と伸びない人の違い

伸びない人
1人でやり切る
見せるのは、できてから

頭のいい人
途中で見せる
一番直す所は、どこ？

## 今日からできる3STEP

STEP01　見せるものを1つ決める。答案か、やり方か
STEP02　「一番直す所は、どこですか」と聞く
STEP03　言われた1つを直して、同じ人にもう一度見せる
「できた」の基準：言われた所を直して、もう一度、見てもらえたらOK！

## まとめ

自分のフォームは、自分では見えない。
だから、全部を1人でやろうとしない。途中で見せて、直す所をもらう。
迷ったら、自分に聞きます。「これ、誰かに見せた？」

# 42　「ここ、全部わからないです」と質問する

## しないこと、すること

×　頭のいい人は「『ここ、全部わからないです』と質問する」をしない。
○　頭のいい人は「わかった最後の1行を、指で押さえる」をする。

## 本文

### 友達から、電話です。「道に迷った。どうすればいい？」

あなたは、最初に、何と聞きますか。

……

「今、どこにいるの？」「近くに、何が見える？」。そう聞くはずです。

今いる場所がわからないと、道は、教えようがありません。質問も、同じです。

物理の問題が、解けません。解説を読んでも、わかりません。先生に、質問しに行きます。

　　「先生、ここ、全部わからないです」

塾の自習室で、高校1年生に、そう言われたことがあります。「どこから？」と聞くと、こう返ってきました。

　　「もう、最初から全部です」

本当に、そうでしょうか。

「物体の重さは、書いてある？」「あ、はい。5キロです」「重力は、下向きだよね」「はい」「じゃあ、この斜面に垂直な成分は？」「……それがわからないです」

わからないのは、そこからでした。最初からでは、ありません。

### 全部わからない、は、ほぼ必ず間違いです

全部わからない、という状態は、実はめったに起きません。授業を受けていて、教科書を開いていて、全部わからないということは、まず、ありません。たいてい、どこかまではわかっています。そして、ある1行から、急にわからなくなっています。

全部わからないと感じるのは、わからない箇所が1つあると、そこから先が全部わからなくなるからです。3行目がわからないとします。4行目以降は、3行目を使って進みます。だから、4行目も5行目も、わかりません。読み終わった時の感覚は「全部わからない」です。でも、実際にわからないのは、3行目だけです。その1行が、見つかっていないだけです。

### 指を1行目に置いて、1行ずつ、決めます

わからなくなった1行は、指で見つけます。解説の1行目に、指を置きます。「この行は、わかる」と思えたら、指を次の行へ動かします。「わからない」と思った行で、指を止めます。そこが、わからなくなった最初の行です。1つ前の行までは、わかっています。最初の物理の問題なら、こうなります。

```
　　1行目　物体の重さは、5キロ　　　　　　　→　わかる
　　2行目　重力は、下向きにかかる　　　　　→　わかる
　　3行目　重力を、斜面に垂直な成分に分ける　→　わからない
```

止まった行の中で、わからない言葉を、1つ選びます。この問題なら、「垂直な成分」です。「全部わからない」が、「3行目の、垂直な成分がわからない」に変わります。

### 見つけたあと、最初には戻りません

数学の解説を読んでいます。7行あります。5行目でわからなくなりました。もう一度、1行目から読みます。4行目までは、さっきもわかりました。5行目。やっぱり、わかりません。3回読んで、3回とも5行目で止まりました。

解説は、短く書かれています。当然わかるだろうという部分は、省略されています。5行目でわからない時、たいていは、4行目と5行目の間に、書かれていない一歩があります。1行目から読み直しても、その一歩は出てきません。書いていないからです。

やるのは、1行だけ進むことです。

　　4行目から5行目に行くために、何をしたのか。

これを、自分で埋めます。4行目が 3x + 6 = 0、5行目が x = -2 なら、間で、2つのことをやっています。6を移項して、3で割る。余白に「6を移項 → 3で割る」と書いて、6行目に進みます。頭の中だけだと、次の行で消えます。

埋められない時は、そこでやっていることの名前を探します。「これは、平方完成というやつか」。名前がわかれば、調べられます。名前は、たいていその単元の最初のページに書いてあります。2回試して埋まらなければ、そこで止めて、聞きます。

### 「ここまではわかります」から、聞きます

聞く時は、この形で聞きます。

　　「ここまではわかります。この行の、ここがわかりません」

「全部わからない」と言われた先生は、最初から説明するしかありません。すでにわかっていた部分の説明を、聞くことになります。わかるところを先に言うと、言われた側は、そこから先だけを説明すればよくなります。「この解説の4行目から5行目で、何をしてるんですか」。この聞き方なら、1分で答えが返ってきます。

自分にとっても、いいことがあります。わかるところを声に出すと、自分がどれだけわかっているかに気づきます。全部わからないと思っていたのに、8割わかっていた、ということが起きます。

## 頭のいい人と伸びない人の違い

伸びない人
「全部わからない」
どこから聞けばいいの…

頭のいい人
「ここまでわかる」
この行で、止まりました

## 今日からできる3STEP

STEP01　指を1行目に置いて、1行ずつ、わかるかを決める
STEP02　わからなくなった最初の行で、言葉を1つ選ぶ
STEP03　「ここまではわかる。ここがわからない」と聞く
「できた」の基準：質問が、「この行の、この言葉がわからない」になったらOK！

## まとめ

「全部わからない」は、ほとんどの場合、本当ではない。
だから、「全部わかりません」と言わない。「ここまではわかります」と言う。
迷ったら、自分に聞きます。「どの行まで、わかった？」

# 43　AIに、答えを教えてもらう

## しないこと、すること

×　頭のいい人は「AIに、答えを教えてもらう」をしない。
○　頭のいい人は「考えるのは自分。AIには、ヒントと反論をもらう」をする。

## 本文

### 一番よく連絡する友達の、電話番号を、言えますか？

……

言えない人が、ほとんどだと思います。何百回も、連絡しているのに、です。

覚える力がないから、では、ありません。スマホが覚えているので、自分の頭を、1回も使っていないからです。

==任せたものは、頭に残りません。==便利なのは、悪いことでは、ありません。ただ、「自分の頭に残したいもの」まで任せると、残りません。

数学の宿題。3番の問題が、わかりません。

　　「写真を撮って、AIに聞こう。答えを教えてもらえば、早い」

10秒で、答えと解説が返ってきました。きれいな解説です。ノートに写します。「なるほど。わかった」。宿題は、15分で終わりました。

次の週の小テスト。同じ形の問題が、出ました。手が、動きません。

### 答えをもらうと、頭にかかる負荷が、ゼロになります

AIを使うと、頭が悪くなるのか。よく聞かれます。答えは、==使い方しだい==です。そして、一番多い使い方が、一番力のつかない使い方です。答えを、聞くことです。

絶対法則03を思い出してください。力がつくのは、「うーん」と止まっている時間だけでした。AIに答えを聞くと、その時間が、丸ごとなくなります。止まる前に、答えが来ます。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で調べています。AIに自由に質問できて、答えも聞けたグループは、練習問題の正答率が、一番高くなりました。ところが、AIなしで受けたテストでは、==AIを使わなかったグループよりも、点が低くなりました。==AIが、答えは言わずに、ヒントだけ出したグループは、下がりませんでした。

答えを聞いた生徒は、練習では解けていました。でも、解いていたのは、AIです。

### 先に自分で考えて、1行書いてから、聞きます

わからない、と思った瞬間に聞かないでください。21番で書いた時間だけ、自分で考えます。単語なら5秒。数学で方針が立たないなら、3分。

そして、聞く前に、==自分の考えを1行書きます。==「たぶん、相似を使う。でも、どの三角形かわからない」。ここまで書いてから、聞きます。自分で一度考えてから見た答えは、頭に残ります。考えずにもらった答えは、残りません。

### 答えではなく、ヒントをもらいます

聞き方を、変えます。最初に、「答えは言わないで」と入れます。

```
　　×　この問題の答えを教えて
　　○　答えは言わないで。最初の一歩だけ教えて
　　○　何がわかれば、この問題は解けますか
　　○　答えを教えずに、質問をしながら、僕を答えまで連れていって
```

最後の聞き方は、特に効きます。AIが「まず、求めたいものは何ですか？」と聞いてきます。答えると、次の質問が来ます。考えているのは、ずっと自分です。さっきの1行と合わせると、AIに送る文は、こうなります。

```
　　「たぶん、相似を使う。でも、どの三角形かわからない。
　　　答えは言わないで。最初の一歩だけ教えて」
```

解けたら、次の日に、AIなしで、もう1回解きます。ヒントをもらって解いた問題は、まだ、1人では解いていません。何も見ずに解けたら、その問題は、できるようになっています。

### 自分の考えに、反対してもらいます

AIの、もう1つのいい使い方です。自分の考えの穴は、自分では見えません。だから、==穴を探してもらいます。==

```
　　この英作文の、間違っているところを3つ指摘して。直した文は、まだ書かないで
　　この説明で、抜けていることは何？
　　僕のこの考えに、反対の立場から意見を言って
```

ほめてもらうために使うのではなく、突っこんでもらうために使います。07番でやった、30秒の説明を聞いてもらうのも、同じ使い方です。「この理解で合ってる？　違うなら、どこを復習すればいいかだけ教えて」。

### AIも、間違えます

AIの答えは、いつも正しいとはかぎりません。自信たっぷりに、間違ったことを言うことがあります。絶対法則01の「疑う」は、ここでも同じです。大事なところは、教科書か、解説で確かめてください。

ヒントをもらう使い方をしていれば、確かめるのは、自然にできます。自分で考えているので、おかしいところに気づけるからです。

## 頭のいい人と伸びない人の違い

伸びない人
AIに答えを聞く
もう、聞いちゃおう

頭のいい人
AIはヒントだけ
答えは、言わないで

## 今日からできる3STEP

STEP01　聞く前に、決めた時間だけ考えて、1行書く
※決めた時間＝単語は5秒、数学で方針が立たない時は3分（21番）
STEP02　最初に、「答えは言わないで、ヒントだけ」と入れる
STEP03　解けたら、次の日に、AIなしで、もう1回解く
「できた」の基準：次の日に、AIなしで、何も見ずに解けたらOK！

## まとめ

AIに答えを聞くと、頭にかかる負荷が、0になる。
だから、AIに答えを聞かない。ヒントを聞く。
迷ったら、自分に聞きます。「先に、自分で考えた？」

# 44　「AIに頼るのはズルだ」と、自力にこだわる

## しないこと、すること

×　頭のいい人は「『AIに頼るのはズルだ』と、自力にこだわる」をしない。
○　頭のいい人は「分析と問題づくりは、AIに任せる」をする。

## 本文

### 洗濯機があるのに、毎日、服を手で洗っている人がいます。何と、声をかけますか？

　　「自分の手で洗わないと、きれいにならない気がして」

……

「洗濯機を使って、空いた時間で、ほかのことをしたら？」。そう言いますよね。

勉強でも、同じことが起きています。

志望校の過去問が、5年ぶんあります。どんな問題が出ているのかを、表にまとめたい。AIを使えば、すぐにできます。

　　「AIを使うのは、ズルな気がする。自分の力でやらないと、力がつかない」

大問ごとに、出た単元を書き出して、数えます。3日かかりました。4日目も、表の続きです。問題は、まだ、1問も解いていません。

自分でやることが、大事。それは、その通りです。ただ、==「全部を」自分でやる必要は、ありません。==

### 自分でやるところと、任せるところを、分けます

43番で、AIに答えを聞いてはいけない、と書きました。力がつく作業を、AIにやらせてしまうからです。では、力がつかない作業は、どうでしょうか。

思い出す。解く。説明する。間違いを直す。ここで、力がつきます。AIには、任せません。調べる。集める。数える。整理する。問題を作る。ここでは、力がつきません。時間だけ、かかります。任せていいのは、こちらです。最初の過去問なら、こう分かれます。

```
　　5年ぶんを数えて、表にする　　→　任せていい
　　表を見て、よく出る単元を解く　→　自分でやる
```

3日かけて表を作っても、数学の力はつきません。AIなら、数分です。==空いた3日で、問題を解く。==それが、頭のいい使い方です。

### 「任せていい」ほうを、AIに頼みます

僕の塾生が、この本を書いている時点で、実際に任せている作業です。

```
　　覚えにくい英単語を、絵にしてもらう（14番）
　　選択肢がなぜ違うのかを、説明してもらう（18番）
　　過去問を、分析してもらう
```

わからない問題のヒントをもらう使い方と、自分の説明の穴を教えてもらう使い方は、43番に書きました。一番差がつくのは、過去問です。

### 過去問から、「未来問」を作ります

過去問は、解くだけのものではありません。AIに過去問を見せて、こう頼みます。

```
　　「よく出る単元を、大問ごとに数えて」
　　「過去問に出てきた単語だけで、志望校だけの単語帳を作って」
　　「過去問と同じ形式、同じ難しさの問題を、新しく作って」
```

3つ目が、未来問です。過去に出た問題ではなく、==これから出そうな問題==です。過去問は、数にかぎりがあります。未来問は、いくらでも作れます。

作ってもらった問題は、その日のうちに、自分で解きます。作ってもらっただけでは、力はつきません。以前は、こういう分析に、何日もかかりました。今は、分析はAIに任せて、生徒は、出てきた問題を解くことに時間を使っています。

偏差値50台から、早稲田と慶應の両方に受かった生徒も、志望校に合わせた対策を、誰よりも早く始めていました。17番で書いた、過去問を先に見ることを、AIでもっと深くやっていたんです。

### 「AIを使うのは、ズルな気がします」

その気持ちは、まともです。ただ、任せるのは、力がつかない作業だけです。使い方を決めておけば、AIは、いつでも横にいる家庭教師にもなります。

# 45　勉強に使うものを、値段だけで決める

## しないこと、すること

×　頭のいい人は「勉強に使うものを、値段だけで決める」をしない。
○　頭のいい人は「時間が短くなるものには、迷わず使う」をする。

## 本文

### あなたの1時間は、いくらですか？

……

考えたことがない人が、ほとんどだと思います。

高校生がアルバイトをすると、1時間で、だいたい1,000円くらいです。仮に、あなたの1時間も、1,000円だとします。この数字を、覚えておいてください。

本屋で、参考書を選んでいます。1冊は、1,500円。解説が詳しくて、今の自分に合っています。もう1冊は、兄が使っていた古い本。家にあるので、0円です。ただ、解説が短くて、読んでも、よくわかりません。

　　「お金がもったいない。家にあるほうで、いいや」

古い本で、始めます。解説を読んでも、わからない。1問に、30分かかります。3か月たって、まだ、半分です。

### 節約したのは1,500円。使ったのは、30時間です

古い本を選んで、1,500円、節約しました。そのかわり、解説がわからなくて止まった時間が、積み重なりました。1日20分でも、3か月で、30時間です。1時間が1,000円なら、30時間は、30,000円です。

テストまでの日数は、誰にも増やせません。絶対法則04で見た通り、ゴールまでの時間には、かぎりがあります。==勉強で一番高いのは、お金ではなく、時間です。==

### 「高いか、安いか」ではなく、「時間が短くなるか」で決めます

値段を見る前に、1つだけ、自分に聞きます。

　　==「これで、できるようになるまでの時間は、短くなる？」==

```
　　今の自分に合った解説の本　→　止まる時間が、減る
　　タイマー　→　時間を測れる（19番）。スマホを机に置かなくてすむ（32番）
　　志望校の過去問　→　やらなくていい所が、最初にわかる（17番）
　　書きやすいペンと、紙の束　→　白紙に書く回数が、増える（16番）
```

短くなるなら、それは、無駄づかいではありません。時間を買っています。逆も、あります。

```
　　まだ1冊目が終わっていないのに買う、2冊目の本（25番）
　　色のそろったペンと、きれいなノート
　　いつ、どう使うかを決めていない教材
```

時間が短くならないものは、どれだけ安くても、いりません。高いから効く、ということも、ありません。

### 買う前に、「いつ、どう使うか」を、1行で書きます

いい参考書を買うと、それだけで、少し、できるようになった気がします。絶対法則01で見た、「勉強した感じ」です。買ったものは、使った時にだけ、点になります。だから、買う前に、「いつ、どう使うか」を、1行で書きます。書けないものは、まだ、買わなくていいです。

### お金を出してもらう時は、3つを伝えます

中学生や高校生は、自分のお金で買うわけでは、ないと思います。出してくれるのは、家の人です。「参考書、買って」だけだと、家の人も、判断できません。3つを、伝えてください。3つ目は、さっき書いた1行です。

```
　　何を　「英語の文法の問題集。1,500円」
　　なぜ　「今の本は、解説を読んでも、わからない所が多い。これは、本屋で読めた」
　　いつまでに　「夏休みが終わるまでに、△と×だけを3周する」
```

絶対法則04の「戦略」を、人に説明しているだけです。ここまで言える人には、家の人も、出しやすくなります。

### お金をかけなくても、できることは、たくさんあります

お金をかけないと伸びない、という話では、ありません。学校の先生に質問する。図書館を使う。先輩に、使い終わった過去問をもらう。AIに、問題を作ってもらう（44番）。どれも、お金は、かかりません。この本に書いたやり方も、ほとんどは、紙とペンがあれば、できます。

==自分の時間を、安く見積もらないでください。==勉強で身についたものは、この先、ずっと使えます。参考書の数千円や、勉強に使った時間は、あとで、何倍にもなって返ってくる。僕は、そう思っています。

# 46　合格を、ゴールにする

## しないこと、すること

×　頭のいい人は「合格を、ゴールにする」をしない。
○　頭のいい人は「さっさと勝って、次の勝負へ。アップデートし続ける」をする。

## 本文

### 「受かったら、やりたいこと」を、3つ、言ってください

3秒で、どうぞ。

……

すぐに3つ出た人は、少ないと思います。

毎日、合格のために、やっています。でも、合格の「あと」は、まだ、何も決まっていません。

合格発表の日。自分の番号が、ありました。うれしくて、泣きました。1年間、このために、やってきました。

　　「やっと終わった。もう、勉強しなくていい」

参考書を、全部、しまいます。

4月。新しい学校が、始まります。授業は、前より難しくなっています。周りは、同じ試験を通ってきた人ばかりです。

ゴールだと思っていた場所は、次のスタートでした。

### 合格は、ゴールです。ただし、「その勝負の」ゴールです

絶対法則04で、受験のゴールは、合格最低点を上回ること、と書きました。ゴールから逆算して、やることを決める。それが、戦略でした。目の前の勝負には、はっきりしたゴールが要ります。ただ、1つだけ、足します。

　　==合格は、その勝負のゴールです。あなたの人生のゴールでは、ありません。==

高校受験の先には、高校があります。大学受験の先には、大学があります。資格試験も、検定も、同じです。受かったあとに、やりたいことがあるから、受けています。全部、通過点です。

あなたは、何のために、始めましたか。「受かったら、何をしたいか」を、1行で書いてください。そのために、次に学ぶことも、1つ書きます。

```
　　受かったら、何をしたい　「留学して、英語で友達を作る」
　　次に学ぶこと　　　　　　「英語で話すこと。受かった次の日から始める」
```

### 正解は、これからも、変わっていきます

今、覚えていることの中身は、いつか、古くなります。使う道具も、変わります。少し前まで、AIに質問しながら勉強する人は、ほとんどいませんでした。今は、当たり前です。何年かたてば、また、別のものが出てきます。よく知られた言葉があります。

　　「生き残るのは、一番強いものでも、一番賢いものでもない。変化に合わせて、変われるものだ」

一度勝った人が、ずっと勝ち続けるわけでは、ありません。変わり続けた人が、残ります。

### AIがある時代に、なぜ、勉強するのか

「AIが何でも答えてくれるなら、もう、勉強しなくていいんじゃないですか」。最近、よく聞かれます。逆だと、僕は思っています。

どれだけいい食材があっても、料理する人の腕がなければ、こげてしまいます。AIも、同じです。同じAIを使っても、何を聞くか。返ってきた答えが正しいかどうかを、見分けられるか。それを、どう使うか。==使う人の頭で、出てくるものが、まるで変わります。==

学び方を知っている人は、何が出てきても、また学べます。新しい道具が出たら、使い方を学ぶ。必要な知識が変わったら、それを学ぶ。

### この本で渡したのは、「学び方」です

この本に書いたのは、英単語の覚え方や、問題集の回し方だけでは、ありません。疑う。思い出す。負荷。戦略。分散。速度。第1章の6つは、受験が終わっても、使えます。高校や大学の勉強でも、資格の勉強でも、新しい道具の使い方を覚える時でも、同じです。

覚えた中身は、古くなります。でも、==学び方を知っていれば、何度でも、新しくできます。==

### さっさと勝って、次の勝負へ

だから、最後に、これを伝えます。

　　==さっさと勝って、勝ち続ける。==

目の前の勝負は、長引かせません。絶対法則06で書いた通り、さっさと失敗して、さっさと直して、最後に勝ち切ります。「はじめに」で書いた通り、やるからには、勝ちにいきます。そして、勝ったら、そこで止まりません。次の勝負を、自分で決めます。

```
　　×　合格がゴール　→　受かった日に、止まる
　　○　合格は通過点　→　受かった日に、次の勝負を決める
```

やり方も、新しくし続けます。月に1回、自分のやり方を、1つ、新しくしてください。この本では、それを、「アップデート」と呼んでいます。

合格は、最初の1勝です。ここから、勝ち続けてください。
