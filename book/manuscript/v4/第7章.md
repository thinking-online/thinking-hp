## 章の導入文

### この1か月で、勉強のことを、誰かに質問しましたか？

先生でも、友達でも、AIでも、かまいません。何回、ありましたか。

……

0回か、1回。そういう人も、多いと思います。

聞きたいことが、なかったからでは、ありません。「こんなことを聞いたら、恥ずかしい」「自分の力でやらないと、意味がない」。そう思って、1人で、抱えこんでいます。真面目な人ほど、そうです。

頭のいい人は、違います。==使えるものは、全部使います。==人にも聞きます。AIも使います。ただし、使い方を知っています。頭を使うところは、自分でやる。そうでないところは、人やAIの力を借りる。

最後の章は、6つです。人の力の借り方が2つ。AIの使い方が2つ。お金の使い方が1つ。そして最後に、この本で、一番伝えたいことを書きます。

# 41　全部、自分1人でやろうとする

## しないこと、すること

×　頭のいい人は「全部1人でやる」をしない。
○　頭のいい人は「途中で人に見せる」をする。

## 本文

### 録音した自分の声を、聞いたことがありますか？

……

「え、こんな声なの？」と、思いませんでしたか。

生まれてから毎日、聞いている声です。それでも、外から聞くと、自分が思っていた声とは、違います。

==自分のことは、自分では、見えません。==声でさえ、そうです。勉強のやり方や、答案の書き方は、もっと見えません。

### 「1人でやりきる」は、えらく見えます

人に頼らず、自分の力だけで、やりきる。真面目な人ほど、それを、えらいことだと思っています。「人に見せるのは、もう少し、できるようになってから」。そう考えて、1人で進めます。

例えば、英作文の練習です。問題を解いて、模範解答を見ます。自分の答えとは、違う文です。模範解答をノートに写して、次へ進みます。3か月で、50題、解きました。でも、自分の書いた文が、何点なのかは、今も、わかりません。同じ間違いを、50回、続けていたかもしれません。

「はじめに」の僕が、そうでした。1日13時間、1人でやって、全部、落ちました。やり方のズレは、人に言われるまで、見えませんでした。

### 自分のフォームは、自分では見えません

バスケのシュートを、ひじが開いたまま、1000本打つと、ひじが開いたフォームが、体に入ります。本人は、気づいていません。コーチが、横から見て、一言。「ひじ、開いてるよ」。3秒で、わかります。

プロの選手にも、コーチがいます。下手だからでは、ありません。自分では見えない所を、見てもらうためです。

勉強も、同じです。答えが違う、計算が合わない。こういう間違いは、自分で気づけます。でも、考え方のくせ、答案の書き方、勉強のやり方そのものは、1人で何時間やっても、見えません。==見えないものは、直せません。==

### 見せるのは、「できてから」ではなく、「途中」です

```
　　できてから見せる　→　ズレたまま、何十時間も進む。直す量が、増える
　　途中で見せる　　　→　ズレが小さいうちに、直せる
```

絶対法則06で書いた通り、早く間違えて、早く直す。人に見せるのも、同じです。

見せる相手は、先生や、その教科が得意な先輩です。見せるものを、1つ決めます。

```
　　答案　　記述、英作文、数学の途中の式
　　やり方　今使っている本と、1週間の進め方
　　計画　　ゴールと、やる3つ（絶対法則04）
```

聞き方も、1つ決めておきます。==「一番直したほうがいい所は、どこですか」。==「どうですか」と聞くと、「いいんじゃない」で終わります。「一番直す所」を聞くと、1つ、返ってきます。直すのは、その1つだけです。直したら、もう一度、同じ人に見せます。直ったかどうかも、自分では、見えないからです。

### 自分でやることと、見てもらうことを、分けます

「人に頼るのは、甘えだ」。そう思う人は、分けて考えてください。

```
　　自分でやること　　　考える。解く。思い出す。直す
　　人に見てもらうこと　どこがズレているかを、見つける
```

解くのを、人にやってもらったら、力は、つきません。でも、ズレを見つけてもらうのは、甘えでは、ありません。一番早く、伸びるやり方です。

## 頭のいい人と伸びない人の違い

伸びない人
1人でやり切る
見せるのは、できてから

頭のいい人
途中で見せる
一番直す所は、どこ？

## 今日からできる3STEP

STEP01　見せるものを、1つ決める
STEP02　「一番直す所は、どこですか」と聞く
STEP03　直したら、同じ人に、もう一度見せる
「できた」の基準：「一番直す所」を1つ聞いて、直して、もう一度見せたらOK！

## まとめ

自分のことは、自分では、見えない。
だから、全部を1人でやらない。途中で、人に見せる。
迷ったら、自分に聞きます。「これ、誰に見せた？」

# 42　「わかりません」とだけ、質問する

## しないこと、すること

×　頭のいい人は「丸投げで質問する」をしない。
○　頭のいい人は「3つそろえて質問する」をする。

## 本文

### 友達から、電話です。「道に迷った。どうすればいい？」

あなたは、最初に、何と聞きますか。

……

「今、どこにいるの？」「どこに行きたいの？」。そう聞くはずです。

今いる場所と、行きたい場所がわからないと、道は、教えようがありません。==質問も、同じです。==

### 「わかりません」だけの質問は、「道に迷った」と同じです

例えば、数学の問題が、解けません。先生に、質問しに行きます。「先生、この問題、わかりません」。

先生は、あなたが、どこまでわかっているのかを、知りません。だから、最初から、全部、説明します。10分かかりました。そのうち8分は、もう知っている話でした。知りたかった所は、最後の2分で、早口で終わりました。

先生の説明が、悪いのでは、ありません。「今、どこにいるか」を、伝えていないからです。

### 質問は、3つをそろえて、持っていきます

```
　　①ここまでは、わかります　今いる場所
　　②自分は、こう考えました　ここまで来た道
　　③ここを、教えてください　行きたい場所
```

①は、24番で引いた線です。「3行目までは、わかります」。これだけで、先生は、4行目から話せます。

②があるかないかで、質問は、大きく変わります。「4行目は、移項だと思ったのですが、数字が合いません」。考えを言うと、先生は、==あなたの考えの、どこがズレたかを、直せます。==41番で書いた、自分では見えない所です。考えを言わないと、正しいやり方を、もう一度聞くだけになります。

③は、答えではなく、知りたい所を、1つにします。

```
　　×　「この問題、わかりません」
　　○　「3行目までは、わかります。4行目は、移項だと思ったのですが、
　　　　数字が合いません。4行目で何をしているのか、教えてください」
```

### 聞く前に2回試して、聞いたあとに言い直します

聞く前に、2回だけ、自分で試します。試した分が、②になります。2回やって進まなければ、それ以上、1人で悩みません。21番で書いた通り、次に試すことがなくなったら、聞く時です。

聞いたあとは、自分の言葉で、言い直します。「つまり、ここで、両辺を3で割った、ということですか」。うなずいて終わると、わかった気になるだけです。言い直せたら、その日のうちに、何も見ずに、もう一度解きます。

### いい質問は、「わかっていない証拠」では、ありません

「こんなことを聞いたら、恥ずかしい」。そう思って、聞けない人が、多いです。でも、3つがそろった質問は、先生から見ると、よく考えている人の質問です。どこまでわかっているかを、言えるからです。

質問は、人の時間を借りることです。だから、3つをそろえて、短く聞きます。AIに聞く時も、同じ3つを入れます。（AIへの聞き方は、43番に書きます）

## 頭のいい人と伸びない人の違い

伸びない人
「全部わからない」
どこから聞けばいいの…

頭のいい人
「ここまでわかる」
この行で、止まりました

## 今日からできる3STEP

STEP01　「ここまでは、わかります」を言う
STEP02　自分の考えを、1行つける
STEP03　聞いたあと、自分の言葉で言い直す
「できた」の基準：3つをそろえた質問が、1回、できたらOK！

## まとめ

「わかりません」だけでは、相手は、最初から説明するしかない。
だから、丸投げで質問しない。わかる所、自分の考え、聞きたい所を、そろえる。
迷ったら、自分に聞きます。「この質問に、自分の考えは、入っている？」

# 43　AIに、答えを教えてもらう

## しないこと、すること

×　頭のいい人は「AIに答えを聞く」をしない。
○　頭のいい人は「AIにヒントをもらう」をする。

## 本文

### 車で、何十回も連れて行ってもらった場所。そこまでの道順を、言えますか？

最初の曲がり角から、言ってみてください。

……

言えない人が、ほとんどだと思います。何十回も、通っているのに、です。

覚える力がないから、では、ありません。運転している人は、ちゃんと言えます。「次は、どっちに曲がるか」を、毎回、自分で決めているからです。乗っているだけの人は、1回も、決めていません。

==任せたものは、頭に残りません。==便利なのは、悪いことでは、ありません。ただ、「自分の頭に残したいもの」まで任せると、残りません。

### 答えをもらうと、頭にかかる負荷が、ゼロになります

例えば、数学の宿題。3番の問題が、わかりません。写真を撮って、AIに聞きます。10秒で、答えと解説が返ってきました。ノートに写して、「なるほど。わかった」。宿題は、15分で終わりました。次の週の小テスト。同じ形の問題が出ました。手が、動きません。

絶対法則03を、思い出してください。力がつくのは、「うーん」と止まっている時間だけでした。AIに答えを聞くと、その時間が、丸ごとなくなります。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で、確かめています。AIに自由に質問できて、答えも聞けたグループは、練習問題の成績が、AIを使わなかったグループより、5割近く高くなりました。ところが、AIなしで受けたテストでは、2割近く、低くなりました。AIが、答えは言わずに、ヒントだけを出したグループは、下がりませんでした。

答えを聞いた生徒は、練習では、解けていました。でも、==解いていたのは、AIです。==生徒は、乗っていただけでした。

### 役割を、分けます

AIを使うと、頭が悪くなるのか。答えは、使い方しだいです。

```
　　自分の役割　考える。解く。思い出す
　　AIの役割　　ヒントを出す。穴を見つける
```

### 先に自分で考えて、答えではなく、ヒントをもらいます

わからない、と思った瞬間には、聞きません。21番の目安の時間だけ、自分で考えます。そして、聞く前に、==自分の考えを、1行書きます。==42番の、質問の②です。

聞く時は、最初に、「答えは言わないで」と入れます。カーナビを聞きながら、自分で運転する形です。

```
　　×　この問題の答えを教えて
　　○　答えは言わないで。最初の一歩だけ教えて
```

合わせると、AIに送る文は、こうなります。

```
　　「たぶん、相似を使う。でも、どの三角形かわからない。
　　　答えは言わないで。最初の一歩だけ教えて」
```

解けたら、次の日に、AIなしで、もう1回解きます。ヒントをもらって解いた問題は、まだ、1人では解いていません。

### 自分の考えの穴を、見つけてもらいます

41番で書いた通り、自分の考えの穴は、自分では見えません。AIには、ほめてもらうのではなく、突っこんでもらいます。

```
　　この英作文の、間違っている所を3つ指摘して。直した文は、まだ書かないで
　　この説明で、抜けていることは何？
```

ただ、AIも、間違えます。自信たっぷりに、間違ったことを言うことがあります。絶対法則01の「疑う」は、ここでも同じです。大事な所は、教科書か、解説で確かめてください。

もう、聞いちゃおう

AIはヒントだけ

STEP01　聞く前に、自分の考えを1行書く
STEP02　「答えは言わないで」と入れて、ヒントをもらう
STEP03　次の日に、AIなしで、もう1回解く

# 44　「AIに頼るのはズルだ」と、自力にこだわる

## しないこと、すること

×　頭のいい人は「AIはズルだと避ける」をしない。
○　頭のいい人は「AIを徹底的に使う」をする。

## 本文

### 洗濯機があるのに、毎日、服を手で洗っている人がいます。どう思いますか？

理由を聞くと、こう言います。「自分の手で洗わないと、きれいにならない気がして」。

……

「洗濯機を使って、空いた時間で、ほかのことをすればいいのに」。そう思ったはずです。

勉強でも、同じことが、起きています。

例えば、志望校の過去問が、5年分あります。どの単元がよく出るのかを、表にまとめたい。AIを使えば、すぐにできます。でも、「AIを使うのは、ズルな気がする」。自分で、大問ごとに書き出して、数えます。3日かかりました。問題は、まだ、1問も解いていません。

### 自分でやる所と、任せる所を、分けます

43番で、AIに答えを聞かない、と書きました。力がつく作業を、AIにやらせてしまうからです。では、力がつかない作業は、どうでしょうか。

```
　　力がつく　　　思い出す。解く。説明する。直す　　→　自分でやる
　　力がつかない　調べる。集める。数える。整理する　→　任せていい
```

3日かけて表を作っても、数学の力は、つきません。AIなら、数分です。==空いた3日で、問題を解く。==それが、頭のいい使い方です。全部を自分でやることが、えらいわけでは、ありません。

### 任せていい作業は、徹底的に、任せます

僕の塾生が、実際に任せている作業です。

```
　　覚えにくい英単語を、絵や場面にしてもらう（14番）
　　選択肢が、なぜ違うのかを、説明してもらう（18番）
　　英作文や記述を、添削してもらう（43番）
　　過去問を、分析してもらう
```

一番差がつくのは、過去問です。AIに過去問を見せて、こう頼みます。

```
　　「よく出る単元を、大問ごとに数えて」
　　「過去問に出てきた単語だけで、志望校だけの単語帳を作って」
　　「過去問と同じ形式、同じ難しさの問題を、新しく作って」
```

3つ目を、僕は、「未来問」と呼んでいます。過去に出た問題ではなく、==これから出そうな問題==です。過去問は、数に、かぎりがあります。未来問は、いくらでも作れます。作ってもらった問題は、その日のうちに、自分で解きます。作ってもらっただけでは、力は、つきません。

### 「AIを使うのは、ズルな気がします」

その気持ちは、まともです。ただ、任せるのは、力がつかない作業だけです。使い方を決めれば、AIは、いつでも横にいる家庭教師にもなります。

ハーバード大学の研究者たちの実験です。答えをすぐには言わず、ヒントを出しながら、1人ずつのペースに合わせるように作られたAIで学んだ学生は、普通の授業で学んだ学生より、==短い時間で、よく身についていました。==

### 道具は、変わります。変わらないものが、1つあります

AIは、どんどん進化します。ここに書いた使い方も、何年かたてば、古くなります。変わらないのは、==どこを任せて、どこを自分でやるかを、決める力==です。思い出す。負荷をかける。そこだけは、どんな道具が出てきても、自分でやってください。

守ることは、2つです。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。

# 45　勉強に使うものを、値段だけで決める

## しないこと、すること

×　頭のいい人は「値段だけで決める」をしない。
○　頭のいい人は「時間が縮むかで決める」をする。

## 本文

### あなたの1時間は、いくらですか？

……

考えたことがない人が、ほとんどだと思います。

高校生がアルバイトをすると、1時間で、だいたい1,000円くらいです。仮に、あなたの1時間も、1,000円だとします。この数字を、覚えておいてください。

### 節約したのは1,500円。使ったのは、30時間です

例えば、本屋で、参考書を選んでいます。1冊は、1,500円。解説が詳しくて、今の自分に合っています。もう1冊は、兄が使っていた古い本。家にあるので、0円です。ただ、解説が短くて、読んでも、よくわかりません。「お金がもったいない。家にあるほうで、いいや」。

古い本で始めると、解説がわからなくて、止まります。1日20分、止まったとします。3か月で、30時間です。1時間が1,000円なら、30,000円です。1,500円を節約して、30,000円分の時間を、使いました。

テストまでの日数は、誰にも、増やせません。==勉強で一番高いのは、お金ではなく、時間です。==

### 「高いか、安いか」ではなく、「時間が短くなるか」で決めます

値段を見る前に、1つだけ、自分に聞きます。==「これで、できるようになるまでの時間は、短くなる？」==

```
　　短くなる　今の自分に合った解説の本。志望校の過去問（17番）
　　　　　　　時間を測るタイマー（19番）
　　ならない　1冊目が終わっていないのに買う、2冊目の本（25番）
　　　　　　　色のそろったペン。使い道を決めていない教材
```

短くなるなら、それは、無駄づかいでは、ありません。時間を、買っています。短くならないものは、どれだけ安くても、いりません。高いから効く、ということも、ありません。

買う前に、「いつ、どう使うか」を、1行で書きます。いい参考書を買うと、それだけで、少し、できるようになった気がします。絶対法則01の、「勉強した感じ」です。買ったものは、使った時にだけ、点になります。

### 「せっかく買ったから」で、続けません

もう1つ、お金で、まちがえやすい所があります。合わないとわかった本を、「せっかく買ったから」と、最後まで続けることです。

払った1,500円は、続けても、やめても、戻ってきません。戻らないお金のために、これからの30時間まで、払う必要は、ありません。==見るのは、もう払ったお金ではなく、これから使う時間です。==

変えるかどうかは、25番の基準で決めます。10問のうち、ほとんど全部で手が止まるなら、今の自分には、重すぎます。変えます。2問から4問で止まるなら、合っています。続けます。

### お金を出してもらう時は、3つを伝えます

# 46　合格を、ゴールにする

## しないこと、すること

×　頭のいい人は「合格をゴールにする」をしない。
○　頭のいい人は「さっさと勝って次へ進む」をする。

## 本文

### 「受かったら、やりたいこと」を、3つ、言ってください

3秒で、どうぞ。

……

すぐに3つ出た人は、少ないと思います。毎日、合格のために、やっています。でも、合格の「あと」は、まだ、何も決まっていません。

例えば、合格発表の日。自分の番号が、ありました。「やっと終わった。もう、勉強しなくていい」。参考書を、全部、しまいます。4月。授業は、前より難しくなっています。ゴールだと思っていた場所は、次のスタートでした。

### 合格は、ゴールです。ただし、「その勝負の」ゴールです

絶対法則04で、受験のゴールは、合格最低点を上回ること、と書きました。目の前の勝負には、はっきりしたゴールが要ります。ただ、1つだけ、足します。

```
　　合格は、その勝負のゴールです。あなたの人生のゴールでは、ありません。
```

高校受験の先には、高校があります。大学受験の先には、大学があります。資格試験も、検定も、同じです。受かったあとに、やりたいことがあるから、受けています。全部、通過点です。

あなたは、何のために、始めましたか。「受かったら、何をしたいか」を、1行で書いてください。そのために、次に学ぶことも、1つ書きます。

```
　　受かったら、何をしたい　「留学して、英語で友達を作る」
　　次に学ぶこと　　　　　　「英語で話すこと。受かった次の日から始める」
```

### 正解は、これからも、変わっていきます

今、覚えていることの中身は、いつか、古くなります。使う道具も、変わります。少し前まで、AIに質問しながら勉強する人は、ほとんどいませんでした。何年かたてば、また、別のものが出てきます。よく知られた言葉があります。

```
　　生き残るのは、一番強いものでも、一番賢いものでもない。
　　変化に合わせて、変われるものだ。
```

一度勝った人が、ずっと勝ち続けるわけでは、ありません。変わり続けた人が、残ります。

「AIがあるなら、もう、勉強しなくていいのでは」。よく聞かれます。逆です。何を聞くか。答えが正しいかを、見分けられるか。==使う人の頭で、出てくるものが、まるで変わります。==

### この本で渡したのは、「学び方」です

この本に書いたのは、英単語の覚え方や、問題集の回し方だけでは、ありません。疑う。思い出す。負荷。戦略。分散。速度。第1章の6つは、受験が終わっても、使えます。覚えた中身は、古くなります。でも、==学び方を知っていれば、何度でも、新しくできます。==

### さっさと勝って、次の勝負へ

だから、最後に、これを伝えます。==さっさと勝って、勝ち続ける。==

目の前の勝負は、長引かせません。絶対法則06で書いた通り、さっさと失敗して、さっさと直して、最後に勝ち切ります。そして、勝ったら、そこで止まりません。次の勝負を、自分で決めます。

```
　　×　合格がゴール　→　受かった日に、止まる
　　○　合格は通過点　→　受かった日に、次の勝負を決める
```

やり方も、新しくし続けます。月に1回、自分のやり方を、1つ、新しくしてください。この本では、それを、「アップデート」と呼んでいます。

合格は、最初の1勝です。ここから、勝ち続けてください。
