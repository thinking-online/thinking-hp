# 付録　そのままパクる。5教科の勉強法（中学生版・高校生版　案・第1版　2026-11-17）

著者の依頼：Instagramで広まっている「5教科の勉強法」の形で、この本の内容をもとにした付録を、中学生版と高校生版で作る。

- 中身は、全部、この本の50個から取った（かっこの中の数字が、その項目の番号）。新しいやり方は、足していない
- 数字（単語は10個を30秒、1語5秒、数学は3分、30秒説明、白紙に3分など）は、本文と同じ
- 1教科が1ページに入る長さにした（×を1行、手順を4つか5つ、できた基準を1行）
- 題に「9割とれた」とは書いていない。書くなら、実際に9割を取った生徒の例が、本の中にいる（`docs/08` に書いた）

# 【中学生版】そのままパクる。5教科の勉強法

定期テストは、教科書と、学校のワークから出ます。だから、やることは決まっています。

この本の50個を、5教科に当てはめました。かっこの中の数字は、くわしく書いてある項目の番号です。

## 5教科とも、同じ流れでやります

```
　　授業の日　　その日やった所を、15分だけ、閉じて言う　　　　　　　　　　　（05・07）
　　2週間前　　 範囲を紙に書き出して、やる順に番号をつける　　　　　　　　　（04）
　　　　　　　　「前の日に3時間」を、「1時間を3日」に割る　　　　　　　　　 （05）
　　毎日　　　　ワークを解く。×に印。次の日は、印の問題だけ　　　　　　　　（06・16）
　　前の日　　　新しいものは開かない。印の問題だけ見て、いつもの時刻に寝る　（45・39）
　　当日　　　　最初の1分で全部めくって、解ける問題から解く　　　　　　　　 （47）
```

## 英語

×　単語を、10回ずつ書く。教科書の本文を、ノートに写す

```
　　1　単語は、10個を30秒見て、閉じて言う。出なかったものに印　　　　　　（12）
　　2　教科書の本文は、日本語を見て、英語で言う。言えなかった文に印　　　（02）
　　3　文法は、ワークを解いて、×の問題だけ、次の日にもう一度　　　　　　（16）
　　4　同じ所で2回止まったら、前の単元の基本問題を、3問解く　　　　　　 （24）
```

できた基準　教科書の本文を、日本語を見て、英語で言えたらOK！

## 数学

×　解説を読んで、「わかった」で次へ進む。解ける問題を、何回も解く

```
　　1　授業でやった例題を、その日のうちに、白紙から解く　　　　　　　　　（08）
　　2　ワークは、解いたら○△×。○はもうやらない。△と×だけ、次の日に　　（16・21）
　　3　手が止まったら、小声で実況する　　　　　　　　　　　　　　　　　　（22）
　　4　3分考えて、何をすればいいかわからなければ、答えを見て、閉じて解き直す（18）
　　5　ミスには、「符号ミス」のように名前をつける　　　　　　　　　　　　 （26）
```

できた基準　ワークの×だった問題を、何も見ずに解けたらOK！

## 国語

×　教科書の文章を、何度も読み返す。漢字を、じっと見て覚える

```
　　1　漢字は、10個書いたら、閉じて書く。書けなかったものに印　　　　　　（12・16）
　　2　教科書の文章は、ノートを閉じて、「結局、何の話？」を1行で言う　　 （15）
　　3　問題を解く時は、選ぶ前に、根拠になる文に線を引く　　　　　　　　　（19）
　　4　選ばなかった選択肢が、なぜ違うかを言う。問題文は、最後まで読む　　（19・20）
```

できた基準　「なぜ、その答えか」を、本文の言葉で言えたらOK！

## 理科

×　教科書に、線を引く。用語を、ノートにまとめる

```
　　1　新しい単元は、読む前に、ワークの問題を1問見て、3分考える　　　　　（11）
　　2　用語は、閉じて、声に出す。出なかったものに印　　　　　　　　　　　（12・16）
　　3　「なぜ、そうなるのか」を、キーワード3つで、30秒説明する　　　　　 （15）
　　4　計算の問題は、数学と同じ。白紙から解いて、×だけ、次の日に　　　　（08・16）
```

できた基準　実験の結果と、その理由を、何も見ずに30秒で説明できたらOK！

## 社会

×　ノートを、きれいにまとめ直す。教科書を、何度も読む

```
　　1　授業の最後の30秒で、「今日は結局、何の話？」を1行書く　　　　　　 （07）
　　2　用語は、答えを隠して言う。出なかったものに印　　　　　　　　　　　（12・16）
　　3　できごとは、「なぜ起きたか」「そのあとどうなったか」を、30秒で説明する（15）
　　4　テストの3日前に、教科書を閉じて、白紙に3分書く。抜けを、赤で足す　（13）
```

できた基準　赤で足した所を、次の日、何も見ずに言えたらOK！

# 【高校生版】そのままパクる。5教科の勉強法

高校の勉強は、量が多くて、全部はできません。だから、最初にやるのは、やらないことを決めることです。

この本の50個を、5教科に当てはめました。かっこの中の数字は、くわしく書いてある項目の番号です。

## 5教科とも、同じ流れでやります

```
　　最初の15分　過去問か、前回のテストを開いて、配点と分野を書き出す　　　　（34・04）
　　授業の日　　その日やった所を、15分だけ、閉じて言う　　　　　　　　　　　（05・07）
　　毎週　　　　先週できた時間を数えて、その8割で、次の週の計画を立てる　　 （30）
　　毎日　　　　解いて、×に印。次の日は、印の問題だけ　　　　　　　　　　　（06・16）
　　テストのあと　落とした問題を、原因ごとにまとめて、一番多い原因から直す　（25）
　　前の日　　　新しいものは開かない。印の問題だけ見て、いつもの時刻に寝る　（45・39）
　　当日　　　　最初の1分で全部めくって、解ける問題から解く　　　　　　　　 （47）
```

## 英語

×　単語帳を、1ページ目から眺める。長文を、解きっぱなしにする

```
　　1　単語は、10個ずつ。30秒見て、閉じて言う。5秒で出なければ、印をつけて次へ（12・18）
　　2　次の日は、印がついた単語だけをやる　　　　　　　　　　　　　　　　（16）
　　3　文法の問題は、選ばなかった選択肢が、なぜ違うかまで言う　　　　　　（19）
　　4　長文は、時間を測って解く。間違えた設問は、根拠になる文に線を引く　（21・19）
　　5　解いた長文は、次の日に、何も見ずに、「結局、何の話？」を1行で言う （15）
```

できた基準　間違えた設問の根拠を、本文の中で指させたらOK！

## 数学

×　解説を読んで、わかった気になる。同じ単元だけを、1日中やる

```
　　1　新しい単元は、基本の問題を5問だけ、まとめて解く。そのあとは、3種類を混ぜる（17）
　　2　3分考えて、何をすればいいかわからなければ、解答を見る　　　　　　 （18）
　　3　見たら閉じて、白紙から解き直す　　　　　　　　　　　　　　　　　　（18）
　　4　解けた問題も、時間を測って、○△×をつける。△は、もう一度　　　　　（21）
　　5　同じ所で2回止まったら、手前の基本問題に戻る　　　　　　　　　　　 （24）
```

できた基準　解答を見た問題を、次の日、何も見ずに、時間内に解けたらOK！

## 国語（現代文・古文・漢文）

×　文章を読んで、なんとなく選ぶ。古文単語を、眺めて覚える

```
　　1　選ぶ前に、根拠を一言、問題番号の横に書く　　　　　　　　　　　　　（19）
　　2　選ばなかった選択肢が、なぜ違うかを言う。言えなかった問題は、△　　（19）
　　3　設問は、最後の1文まで読んで、聞かれていることに線を引く　　　　　 （20）
　　4　古文単語と、漢文の句法は、英単語と同じやり方でやる　　　　　　　　（12・16）
```

できた基準　全部の選択肢について、合っている理由と、違う理由を言えたらOK！

## 理科

×　公式を、そのまま丸暗記する。教科書を、読み返す

```
　　1　新しい単元は、読む前に、問題を1問見て、3分考える　　　　　　　　　（11）
　　2　公式や用語は、「前に習った、どれと似ているか」を言ってから覚える　（14）
　　3　計算の問題は、数学と同じ。3分で解答を見て、閉じて、白紙から解き直す（18）
　　4　「なぜ、そうなるのか」を、キーワード3つで、30秒説明する　　　　　 （15）
```

できた基準　公式を、どの場面で使うかと一緒に、何も見ずに言えたらOK！

## 社会（歴史・地理・公民）

×　教科書に、線を引く。まとめノートを作る

```
　　1　用語は、答えを隠して言う。出なかったものに印。次の日は、印だけ　　（12・16）
　　2　新しい用語は、前に覚えたものと、つなげる。似ているものは、違いだけ覚える（14）
　　3　できごとは、「なぜ起きたか」「そのあとどうなったか」を、30秒で説明する（15）
　　4　1つの単元が終わったら、教科書を閉じて、白紙に3分書く。抜けを、赤で足す（13）
```

できた基準　赤で足した所を、次の日、何も見ずに言えたらOK！
