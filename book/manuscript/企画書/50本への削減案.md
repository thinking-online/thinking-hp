# 合計の調整

上の案だと暗記が7本になるので、全体は51本。

```
　8 + 4 + 3 + 5 + 7 + 6 + 6 + 5 + 4 + 3 ＝ 51本
```

ちょうど50にするなら、暗記からもう1本。候補は31（なぜそうなるのかを聞かずに覚える）。
ただしこれは「つなげる力」の数少ない項目なので、削ると力のバランスが崩れる。

51本のままでもいい。表紙の数字を「50」にするなら1本削る、
「51」でも構わないなら、このまま。

# 章が薄くなるところ

```
　計画　3本
　本番　3本
　モチベ　4本
　戦略　4本
```

3本の章は、章扉2ページ＋本文12ページで14ページ。章として薄い。

対処は2つ。

```
　A　そのまま。章の厚みはバラついていい
　B　計画を集中に寄せる（どちらも続ける力）、本番を終章のまま小さく持つ
```

Bにすると章が1つ減って9章になる。表紙と目次に影響するので、著者の判断。
