# S1　採点シート

1本につき2つの数字だけ。考え込まない。1本15秒。迷ったら低いほう。

```
　頻度　直近で見た生徒10人のうち、何人がこれをやっているか　　0〜10
　効き　やめたら、何点動くか　　　　　　　　　　　　　　　　 0 / 5 / 10
```

効きは、こちらの下書きが入っている。違うと思ったら直す。
頻度は空（_）にしてある。ここは朝倉さんにしか出せない数字。

書き方

```
　01　7　5　過程に、意味を持たせる
　　　↑  ↑
　　頻度 効き
```

外すと決めたら行頭に ×、足すなら末尾に ＋ の行を作る。
チャットで「01 7 5」と並べて送ってくれてもいい。こちらで入れる。

採点したら　`python3 scripts/s1.py`
