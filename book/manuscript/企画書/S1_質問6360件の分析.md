# 3　いちばん大きい発見

## ★1　「どこまでやったら次に行っていいか」が、本に1本もない

セクション3（勉強法全般・復習、101問）の中核がこれ。

```
　「チェックは何回復習したらつけるんですか」
　「完遂の基準って具体的にどんな感じですか」
　「一回全問正解できたからチェックをつけていいのか不安です」
　「テストの合格基準が90%なのはなぜですか。100%にしたいんですけど」
　「3回解いても9割取れなかった場合、86%でチェックをつけて進んでいいですか」
　「参考書って何周すればいいんですか。どこまでできたら次に行っていいのか」
　「ノーヒントで解ききれるようになれば良しとしてるんですが、この基準は甘いですか」
　「毎回きっちり覚えようとして前へ前へと進めません」
　「完璧主義が根付いていて、積分の単元ならその日は積分しかやれません」
```

中高生がいちばん困っているのは、やり方ではない。==終わりの基準==。

これは本の構造を変えるくらい大きい。
いまの本は「何をやるか」は書いてあるが、「どこで終わるか」が書いていない。

## ★2　生活・メンタルが173問で最大なのに、本は4本

内訳

```
　睡眠・起床　　　　　　 32問　　本　1本（44 睡眠を削って）
　スマホ・誘惑・環境　　 24問　　本　1本（41 スマホを机の上に）
　休憩・息抜き・遊び　　 18問　　本　1本（42 疲れてから休憩する）
　やる気・モチベ・自己管理 38問　　本　2本（08 45）
　不安・焦り・自信　　　 46問　　本　1本（48 他人と比べて落ち込む）
　親・学校との関係　　　 15問　　本　0本
```

==「不安・焦り・自信」が46問で、本はほぼゼロ。==
しかもこれは「勉強法」ではなく「勉強できない状態」の話。
類書がいちばん書いていないところで、質問がいちばん多い。

## ★3　睡眠の向きが、本と逆

本の44番は「睡眠を削って、勉強時間を増やす」。
でも実際の質問32問の大半はこれ。

```
　「7時間半寝てるのにアラームで起きられず二度寝してしまいます」
　「朝起きられなくて困ってます。24:30に寝ても8:30〜9:00に起きてしまい」
　「7時間寝たのに勉強中に睡魔が何回も来て、仮眠しても眠いです」
　「夜家に帰ってから勉強しようとすると毎回寝落ちしてしまいます」
　「仮眠を取ってもまだ眠くて、仮眠からも起きられません」
```

削る話ではなく、==起きられない・眠い==の話。項目を足す必要がある。

## ★4　学校との両立が67問なのに、本は1本

```
　授業・内職　　　　　　17問
　課題・宿題・小テスト　23問
　補習・講習　　　　　　12問
　部活・行事　　　　　　15問
```

中高生は1日の大半を学校で過ごす。そこに本が1本しかない。

```
　「学校課題は答えを写すだけで提出してます。この方針でいいですか」
　「受験で使わない教科の定期テスト対策は捨てていいんでしょうか。それは逃げですか」
　「小テストでペナルティを受けないために休み時間を全部使ってます」
　「学校の補習を受け続けるか辞めるか悩んでいます」
```

==「捨てていいのか」「逃げじゃないか」が共通の形。==
本の03「全部やろうとする」はこれに答えていない。

第4章 授業・学校　　　5本　　　10%　　　　 6本　★+1（学校との両立を足す）
第5章 暗記　　　　　　7本　　　12%　　　　 6本　−1

# 5　新しく立てる項目の候補（質問から直接起こしたもの）

```
【終わりの基準】
　・1周目から完璧にしようとして、前に進めない
　　　「毎回きっちり覚えようとして前へ前へと進めません」
　・100%できるまで、次に行かない
　　　「3回解いても9割取れなかった場合、進んでいいですか」
　・「できた」の基準を、自分で決めていない
　　　「何周すればいいんですか。どこまでできたら次に行っていいのか」

【学校との両立】
　・学校の課題を、全部同じ重さでやる
　　　「受験に使わない教科の定期テスト対策は捨てていいんですか。逃げですか」
　・小テストのために、休み時間を全部使う
　・補習・講習を、誘われるまま全部取る

【睡眠・起床】
　・寝る時間を決めずに、終わるまでやる
　　　「To doが終わるのが23〜24時で就寝が25時になります」
　・起きられないのを、意志の問題だと思う
　　　「アラームで起きられず二度寝。気持ちしかないですか」
　・眠くなってから、仮眠を取る

【不安・焦り】
　・不安なまま、手を動かさずに考え続ける
　　　「やり方が合ってるのかも不安。やってもやっても不安で」
　・できなかったことだけを数える
　　　「できなかったところばかり見て、できている所を認めていなかった」
　・人に言われた一言を、頭の中で再生し続ける
　　　「担任の言葉が脳内で再生され続けて焦りばかり募ります」

【時間の使い方】
　・計画を立てることに、時間を使う
　　　「計画を立てるのに2時間以上かかってしまいます」
　・1問に、時間をかけすぎる
　　　「1問のわからないところを3時間くらい考えてしまいます」
　・何をやるか迷うことに、時間を使う
　　　「何やるか迷って考えるのに今日だけで5時間使ってしまいました」

【模試・テスト】
　・模試を、受けるか受けないかで迷って時間を使う
　・模試の前に、範囲を全部やろうとする
　・模試が返ってきて、判定だけ見て終わる（既存11）
```

# 6　取り扱いに注意が必要なもの

質問の中に、希死念慮を含む深刻な相談が複数件ある（著者の注記）。

```
　・書籍の素材には一切しない
　・「頑張れない自分を責める」系の項目を書くときは、
　　　追い込む書き方をしない。本の方針（読者を責めない）がそのまま効く
　・巻末の「保護者の方へ」に、相談先を1行入れるかは要検討
```
