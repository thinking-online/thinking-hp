# 3　定義

この本には、定義が1つしかありません。

## 正式版

成績が伸びる人とは、必要な「できない」を、期限までに「できる」に変えた数が多い人。

## 短縮版（帯、各法則の結論、面談で繰り返す）

必要な「できない」を「できる」に変えた数が多い人。

## 第1章で定義する3つの言葉

　必要な　　試験に出ること。出ないできないは数えない
　できる　　本番で自力で出せること。読んでわかった、家で解けた、はできるではない
　数　　　　重い1つを変えて芋づるで変わった分も含む

## この定義を選んだ理由

- 一言で言い切れる
- 聞いた瞬間に、常識が1つひっくり返る（時間　→　数）
- 反証できる。10時間やって1つも変えていない人は、この定義では伸びない人
- 頑張っているのに伸びない読者が救われる。才能でも時間でもなく、数の問題になる
- 定義の言葉が、そのまま6つの力に分解される
- 45の見開き全部の判定基準になる。「この行動は、数を増やすか、減らすか」

## 主語について

主語は「勉強ができる人」ではなく「伸びる人」。
頭がいいは状態、伸びるは変化。変化は数えられます。

「やればやるだけ伸びる」は、「同じ時間で変えた数が多い」の言い換えです。

## 表紙と中身の対応（返品率対策）

　表紙「絶対にやらないこと」　　　→　45見開きの左ページ（伸びない人の答え）
　サブ「法則45」　　　　　　　　　→　45見開きの右ページと、まとめの一覧
　帯「数え方」　　　　　　　　　　→　序章の診断と、法則1
　帯裏「パクる」　　　　　　　　　→　法則の言い切りと、一覧ポスター
　帯裏「昨日、何個できるように？」→　はじめに、と序章

# 5　7つの型

## 型の作り方

伸びない人は、何も数えていないのではありません。
できるの数のかわりに、別の何かを数えています。

7つの型は全部「何を数えているか」で作っています。
あの子だけが、できるの数を数えている。あの子には型がありません。

7つとも、頑張っている人の型です。サボっている人は、カウンターを持っていません。

## 現在の型（名前は仮）

　1　机にいた時間を数えている　　　　「今日は6時間型」　　　　→　第1章
　2　やった冊数を数えている　　　　　「参考書ルート型」　　　　→　第2章
　3　止まった場所を突き止めていない　「全部わからない型」　　　→　第3章
　4　書いた回数を数えている　　　　　「10回書く型」　　　　　　→　第4章
　5　わかった回数を数えている　　　　「あーね型」　　　　　　　→　第5章
　6　付箋の枚数を数えている　　　　　「あとで付箋型」　　　　　→　第6章
　7　立て直した計画の数を数えている　「計画表に1時間型」　　　 →　第7章

そして、できるようになった数だけを数えている「あの子」。

## 名前の差し替えについて

構造は確定です。名前は仮です。

Instagramのストーリーズの質問箱で「勉強してるのに伸びない人がやりがちなこと」を集め、
場面ではなく「頭のなかで同じことが起きているか」で束ね直して、名前を差し替えます。
一番絵が浮かぶ行動から名前を取ります。

束が7つになるとは限らないので、7つに合わせにはいきません。
結果として6つや8つになった場合は、章構成ではなく型の数のほうを動かします。
（6つの力と章立ては、定義から出ているので動きません）

# 6　6つの力と、定義の対応

定義の言葉を1つずつ分解すると、6つ出てきます。
定義にない力はなく、定義の言葉で力になっていないものもありません。だから6つです。

| 定義の言葉 | 力 | 図の位置 | 頭のなかの先生の仕事 |
|---|---|---|---|
| 「必要な」を決める | 捨てる力 | 入口の漏斗 | 何を教えるか選ぶ |
| 「できない」の場所を見つける | 突き止める力 | 3つの箱を見渡す虫眼鏡 | 生徒のつまずきを突き止める |
| 「できる」に変える | つなげる力 | 知っている→わかっているの矢印 | 知っていることにつなげて教える |
| 「できる」を本番で出す | 取り出す力 | 解いてみるの判定 | テストで取り出させる |
| 変わらなかったとき | さかのぼる力 | ×から戻る3本の矢印 | つまずいた所までさかのぼる |
| 「期限までに」揃える | 回す力 | 今日→試験日の線 | 続けさせる |

順番は、勉強の時系列です。

## 6つに共通する性格

章扉の6問の答えは、全部、増やさない、教えない、渡さない、やらせない。
何かを足すのではなく、1つ変えるだけ。これが6つの力の共通の性格です。

## 頭のなかの先生（説明装置。定義ではありません）

伸びる人の頭のなかには先生がいる。伸びない人の頭のなかには生徒しかいない。
6つの力は、頭のなかの先生がやっている6つの仕事。

第1章で「なぜ数が多いのか」の答えとして使います。
定義には混ぜません。定義は測れるもの、比喩は腹落ち用です。

# 8　検討した切り口と、この案を推す理由

## 捨てた案

| 案 | 捨てた理由 |
|---|---|
| 成績が「伸びる人」と「伸びない人」の、勉強中の頭のなか | 対比型。既視感。あの子案に発展した |
| 勉強ができる人は、頭のなかで「この図」を回している | 図が表紙だと説明的で、学参の顔になる |
| 頑張っているのに伸びないのは、才能のせいじゃない | 自己啓発寄り。著者の知名度に依存する |
| 勉強は、根性じゃなく設計だ。 | ブランド直結だが、3秒で何の本かわからない。2冊目以降向き |
| 頭のいい「あの子」 | 頭がいい、は才能の言葉 |
| 学年1位の「あの子」 | 結果の言葉で、読者の痛みから遠い |
| 「勉強してないのに成績がいい」あの子 | 実際には勉強しているので、嘘になる |
| 「急に伸びた」あの子 | 希望は強いが、嫉妬の熱がない。帯裏に回した |
| 「こぞって捨てる勉強法」 | こぞって、は複数主語の言葉。あの子は1人 |
| 早慶合格・学年1位・偏差値70超えの肩書き行 | 早慶で大学受験の本に見える。帯裏と著者プロフィールへ |

## この案を推す理由

あの子も、読者も、勉強しています。
違うのは、やった分が伸びに変わるかどうかだけです。

「やればやるだけ伸びる」は、定義（同じ時間で変えた数が多い）の言い換えです。
だから、表紙の言葉と本文の骨格が、そのままつながっています。

そして、この表紙は読者を「勉強していない人」にも「才能がない人」にもしません。
やっているのに伸びない読者が、自分を責めずに手に取れる表紙になっています。

## 参考にした書籍と、借りたもの

- 『仕事ができる人の頭のなか』　一言の定義から力を分解する構造。観察由来として提示する見せ方
- 仕事ができる上司の「〇〇」の当たり前　章タイトルの統一フォーマット
- 『頭のいい人が話す前に考えていること』　二階建て構造。法則が全部逆説であること
- 残念なリーダー20の型　行動の描写＋「短い名前型」の命名形式。全部が善意の失敗であること
- 『上手に説明できる人とできない人の習慣』　二項対立の項目形式
- エレベーターの導入　問題　→　意外な答え　→　原理。答えは隣の層に置く
- 『小さなビジネスモデル100』　見開きの型（Q＋HINT／答え＋POINT）と、法則45の一覧
