　　　　　　　→　捨ててから、始める

　　　　　　　→　入れたら、すぐ出す
　　　　　　　「いま、閉じて出せる？」

つなげる力　　1個ずつ覚えると、1個も出てこない
　　　　　　　→　前にやったものに、くっつける
　　　　　　　「これ、前にどこで見た？」

出す力　　　　テストと違う練習は、練習じゃない
　　　　　　　→　テストと同じ形で、やる
　　　　　　　「それ、テストでもできる？」

なおす力　　　直すのは、問題じゃない。場所
　　　　　　　→　どこで止まったかを、探す
　　　　　　　「どこで、止まった？」

続ける力　　　やる気は、あてにならない
　　　　　　　→　やる気がなくても始まる形にする
　　　　　　　「次の1個目は？」

```

　　　　 「どれだけ面倒で時間のかかる勉強をするんだ」になる

対応1　番号をやめた。6つを並列に置く
対応2　序章で明記する　「6つ全部を毎回使うわけではありません。

```

# 3　序章の流れ

1問を解く3分を追いながら、6つが順に出てくる。

```
頭のいい人は、いきなり戦い始めません

　まず、やらないことを決めます　　　　　　　　　　　選ぶ力
　　　　「これ、出るの？」

　机に座る前に、1個目が決まっています　　　　　　　 続ける力
　　　　「次の1個目は？」

　解説を読んだら、すぐ閉じます　　　　　　　　　　　入れる力
　　　　「いま、閉じて出せる？」

　閉じる前に、前にやったものを探します　　　　　　　つなげる力
　　　　「これ、前にどこで見た？」

　○がついても、まだ信じません　　　　　　　　　　　出す力
　　　　「それ、テストでもできる？」

　出なかったとき、その問題に戻りません　　　　　　　なおす力
　　　　「どこで、止まった？」

ここまで、3分の話です。

6つ全部を、毎回使うわけではありません。
1問につき、だいたい2つです。
いまの3分で使ったのは、入れる力と出す力の2つでした。
```

序章の最後に、手持ちの一覧（並べの図）と「まず、この5つ」を置く。
