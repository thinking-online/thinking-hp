# 1　この本の設計

## 読者が持ち帰るもの

```
6つの武器と、6つの口ぐせ。
全部忘れても「いま、閉じて出せる？」が残れば、この本は成功。
```

## 層

```
10秒で　　　　1回、体験する　　　　　　　11個の数字
序章で　　　　6つの武器を受け取る　　　　1問の流れで紹介。3分の話
1週間で　　　 1回、勝つ　　　　　　　　　まず、この6つ
62の場面で　　武器の使い方を覚える　　　 引いて読む
巻末カードで　持ち帰る　　　　　　　　　 6行。筆箱に入る
```

## 6つの武器

```
選ぶ力　　　　全部やろうとすると、1つも終わらない
　　　　　　　→　捨ててから、始める
　　　　　　　「これ、出るの？」　　　　　　　　　　　11項目

入れる力　　　入れるだけでは、入らない
　　　　　　　→　入れたら、すぐ出す
　　　　　　　「いま、閉じて出せる？」　　　　　　　　8項目

つなげる力　　1個ずつ覚えると、1個も出てこない
　　　　　　　→　前にやったものに、くっつける
　　　　　　　「これ、前にどこで見た？」　　　　　　　5項目

出す力　　　　テストと違う練習は、練習じゃない
　　　　　　　→　テストと同じ形で、やる
　　　　　　　「それ、テストでもできる？」　　　　　 10項目

なおす力　　　直すのは、問題じゃない。場所
　　　　　　　→　どこで止まったかを、探す
　　　　　　　「どこで、止まった？」　　　　　　　　 10項目

続ける力　　　やる気は、あてにならない
　　　　　　　→　やる気がなくても始まる形にする
　　　　　　　「次の1個目は？」　　　　　　　　　　 18項目
```

迷ったら、入れる力と出す力。
この2つは同じ動作（閉じる）で、62のうち18がこれで片づく。

## 杉浦さんの指摘への対応

```
ご指摘　「①→⑥」を全部済ませてから次、と読まれると
　　　　 「どれだけ面倒で時間のかかる勉強をするんだ」になる

対応1　章を、力ではなく場面で切った
　　　 章名が「計画」「授業」「暗記」になるので、工程には見えない
　　　 目次から、順番にこなす気配が消える
対応2　番号をやめた。6つを並列に置く
対応3　序章で明記する　「6つ全部を毎回使うわけではありません。
　　　　　　　　　　　　 1問につき、だいたい2つです」
対応4　序章の最後に「ここまで、3分の話です」と書く
対応5　図を、矢印の鎖から、並べ（グリッド）に変える
```

# 3　序章の流れ

1問を解く3分を追いながら、6つが順に出てくる。

```
頭のいい人は、いきなり戦い始めません

　まず、やらないことを決めます　　　　　　　　　　　選ぶ力
　　　　「これ、出るの？」

　机に座る前に、1個目が決まっています　　　　　　　 続ける力
　　　　「次の1個目は？」

　解説を読んだら、すぐ閉じます　　　　　　　　　　　入れる力
　　　　「いま、閉じて出せる？」

　閉じる前に、前にやったものを探します　　　　　　　つなげる力
　　　　「これ、前にどこで見た？」

　○がついても、まだ信じません　　　　　　　　　　　出す力
　　　　「それ、テストでもできる？」

　出なかったとき、その問題に戻りません　　　　　　　なおす力
　　　　「どこで、止まった？」

ここまで、3分の話です。

6つ全部を、毎回使うわけではありません。
1問につき、だいたい2つです。
いまの3分で使ったのは、入れる力と出す力の2つでした。
```

序章の最後に、手持ちの一覧（並べの図）と「まず、この6つ」を置く。

```
　続ける力　　　「次の1個目は？」


　迷ったら、入れる力と出す力。
　この2つは同じ動作です。閉じること。
```

## まず、この6つ

# 7　力版からの差分

```
章の切り方　　　6つの力　→　8つの場面（計画・授業・暗記・演習・復習・集中・気持ち・本番）
6つの力　　　　 章名（6回）　→　各項目の右肩（62回）＋章扉＋巻末カード

新しく入れた　　12　授業を、聞く時間だと思っている
　　　　　　　　14　授業中、当てられないように下を向く
　　　　　　　　18　小テストを、点が出たら捨てる
　　　　　　　　21　英単語を、1語1訳で覚える

隣に吸収した　　旧18（語呂）　→　22 の中に1ページ
　　　　　　　　旧29（説明が下手）→　25 の中に1ページ
　　　　　　　　旧44（毎晩立て直す）→　10 の中に1ページ
　　　　　　　　旧49（休憩でスマホ）→　47 の中に1ページ

章の厚さ　　　　5本〜18本（2.6倍の差）　→　6本〜11本（1.8倍の差）
項目数　　　　　62　→　62（変わらず）
ページ　　　　　268　→　270
```

本文は、章と番号が変わるだけ。書いたものはほぼそのまま使える。
