# 決定

下書き工程（docs/36）で決めたことを、ここに1行ずつ書く。
`python3 scripts/step.py` がこのファイルを読む。
「＝」の右を埋めると、そのステップが通る。

---

## S2　テンプレ

```
テンプレ　＝　
基本の基本8本　＝　
```

テンプレは A／B／C のどれか（docs/35）。

```
　A　新テンプレを全面採用。1本300〜400字削る　　→　340〜350ページ
　B　固定見出しを「Q」と「まとめ」だけにする　　→　ページ増ほぼなし
　C　Qだけ採用。あとはいまの型のまま　　　　　　→　ページ増ゼロ
```

基本の基本8本 は「新テンプレを使わない」か「使う」。

## S4　固定見出しの文言

```
見出し1　＝　
見出し2　＝　
見出し3　＝　
見出し4　＝　
見出し5　＝　
```

試作で使ったのはこれ。変えたければ変える。

```
　見出し1　Q「…………」
　見出し2　頭のいい人が、絶対にやらないこと
　見出し3　なぜ、それだと伸びないのか
　見出し4　じゃあ、どうすればいいのか
　見出し5　まとめ
```
