# 1　表紙・帯・価格

## 表紙

```
　　　　やっているのに、伸びない。


　　　　　頭のいい人が勉強で、絶対にやらない62のこと


　　　　　　　　　　　　　　　　　　　　　　　朝倉 徹大
```

「やっているのに、伸びない」が読者定義そのもの。表紙にそれを置く。
保護者にとっては、自分の子を見ている文になる。

## 安全策（第2案）

```
　　　　やめるだけで、成績は上がる

　　　　　頭のいい人が勉強で、絶対にやらない62のこと
```

減らす約束は珍しいので目を引く。
ただ「やめる」側しか運ばず、6つの武器が表紙から落ちる。

どちらでも、62という数字は表紙に出す。

## 帯

```
　　1　4　9　1　6　2　5　3　6　4　9


　　　　　10秒で、覚えきれますか
```

書店で立っている人が、その場で負ける。
負けた人は、答えを探してめくる。
帯で体験が始まる勉強法本は、調べた範囲にはない。

## 帯の裏

```
　　2000人以上の中高生を指導してきました。

　　伸びなかった子に足りなかったのは、時間でも、才能でもありません。
　　「閉じる」という1つの動作でした。
```

## 価格

```
　　270ページ　四六判　2色刷り　→　1,700〜1,800円（学研の判断）
```

中高生の自腹上限は1,650円あたり。
この価格帯の買い手は、保護者か、本気で困っている生徒。
表紙を「やっているのに、伸びない。」にしているのは、そのため。

どう解釈するか（56「まだ、を足す」57「下がったのは、やり方。人じゃない」）も、
モチベ維持（52「始めたあとに、やる気が来る」）も、同じ武器の下に並べる。

## 水曜に何があったか（この本でいちばん大事な1ページ）

試合前の練習が長引いて帰宅9時半。何もできなかった。
それでも計画は崩れていない。理由が2つある。

```
1　水曜を、最初から空けてあった
　　崩れる日は週に1日来る。来るとわかっているものを、
　　来てから対応するのはおかしい。だから先に入れておく

2　水曜も、朝の単語20はやった
　　朝の20個は、やる気の話ではない。歯をみがく場所の隣に置いてある
　　やる気がない日に、やる気がなくても始まるものが1つあれば、
　　その日は「0の日」にならない
　　0の日が3日続くと、人は計画を捨てる。捨てさせないために朝の20個がある
```

## ブロックの3つのルール

```
1　1ブロックは30分までにする
2　量は、終わったかどうかが自分でわかる形で書く
　　「復習」ではなく「間違えた6問」
3　1日のブロックは、平日3つまで
　　4つ目から守れなくなる。守れない計画は、守れない自分を毎晩見せる
```

平日1日30分。朝の20個と合わせて週5時間半。
守れる5時間半は、守れない14時間より点になる。

# 14 杉浦さんへの出し方

場面版1本で送る。2案は送らない。

```
2案を並べて送ると　　「ご指摘にどう答えるか、決められませんでした」と読まれる
1案で送ると　　　　　「ご指摘を、構成で解決しました」と読まれる
```

添える文。

```
前回の企画書から、章の切り口を変えました。
ご指摘いただいた「①→⑥を順に通る工程に見える」問題を、
本文の弁解ではなく構成で消すためです。

章は、生徒が困っている場面で切りました（計画・授業・暗記・
演習・復習・集中・気持ち・本番）。6つの力は章名から降ろし、
62項目それぞれの右肩と、巻末カードに置きます。
章名で6回出るより、項目で62回出るほうが残ると判断しました。

序章では、読者に実際に1問解かせます。解説を読んで「わかった」
状態から本を閉じさせて、同じ問題をもう1回解かせる形です。
そこで使う武器は2つだけで、6つ全部は使いません。
「毎回6つ通す本ではない」ことを、言葉ではなく体験で示します。
```
