参考にした形

# 作りの決まり

## 項目の数

```
戦略編　　　　8本　　01〜08
計画編　　　　5本　　09〜13
インプット編　8本　　14〜21
暗記編　　　　5本　　22〜26
演習編　　　　7本　　27〜33
復習編　　　　8本　　34〜41
継続編　　　　4本　　42〜45
　　　　　　 45本
```

## 番号は、章をまたいで通す

章が変わっても、番号は切れない。
読者には45本の一本道に見える。探すときだけ、章で引ける。

## ×と○は、心の声で書く

本人が言いそうな言葉のまま書く。説明しない。

```
×　やっているときに、頭の中で言っていること
○　頭のいい人が、同じ場面で言っていること
```

×を読んだ瞬間に「それ、昨日言った」が来るかどうかで判定する。
来ないものは、書き直す。

## 項目のタイトルは、行動を書く

禁止形にしない。いま読者が実際にやっていることを、そのまま書く。

```
×　単語を10回書くのはやめよう
○　単語を、1語10回ずつ書いて覚える
```

## 章タイトルは、書名をくり返す

```
第5章　頭のいい人が、絶対にやらないこと　暗記編
```

目次の中で、書名が7回くり返される。
表紙の約束が、目次で7回回収される。

## 終章の役割

5教科の見せ方の問題は、ここで解く。
科目別を前のほうに独立させると、読者は自分の科目だけ読んで閉じる。
45を読んだあとの応用として後ろに置けば、45を飛ばす人が出ない。
