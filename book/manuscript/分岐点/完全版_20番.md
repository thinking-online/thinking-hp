# 型　9つの拍

各拍に役割がある。順番に意味がある。

```
1　場面　　　　　　　　読者が「これ自分だ」と気づく
　　　　　　　　　　　 失敗の瞬間で終わる。説明しない

2　あなたのせいではない 守りを下ろさせる
　　　　　　　　　　　 ここで責めると、以降が全部入らない

3　何が起きているか　　 「やった感じ」の正体を言う
　　　　　　　　　　　 ここまでが理解。まだ行動は変わらない

4　頭のなか　　　　　　 2つの頭を並べる。時間を入れる
　　　　　　　　　　　 ここで初めて、差が目に見える

5　分岐点　　　　　　　 1語。読者が持ち帰るのはこれだけ
　　　　　　　　　　　 4と6のあいだにしか置けない

6　やり方　　　　　　　 分岐点を実行する手順
　　　　　　　　　　　 解釈の余地を残さない。数字で書く

7　注意　　　　　　　　 やりすぎたときに起きること
　　　　　　　　　　　 これがないと、読者は極端に振れて失敗する

8　残るもの　　　　　　 1回やると何が溜まるか。時間で示す
　　　　　　　　　　　 続ける理由は、ここでしか渡せない

9　まとめ　　　　　　　 ×／○と武器の口ぐせ
```

なぜこの順番か。

```
1-3　読者を、守りから降ろして、理解まで連れていく
4-5　理解を、持ち帰れる1語に変える　　　　←　ここがこの本の価値
6-8　1語を、明日の手の動きに変える
```

3で終わると概念の本になる。6から始めると手順書になる。
4と5を挟むから、手順が再現できる。

# 20　単語を、1語10回ずつ書いて覚える

入れる力　　★厚く書く　4ページ

```
　　×「10回書けば、さすがに覚える」
　　○「見て、隠して、出す。これで1周」
```

---

## 1　場面

夜の9時。明日、英語の小テストがあります。範囲は50語。

ノートを開いて、1語ずつ書いていきます。

```
　　available　available　available　available　available……
```

1語10回。50語なので、500回。

途中で手が痛くなりました。右手の中指の、ペンが当たるところです。
それでも最後まで書きました。終わったのは10時半。1時間半かかりました。

やりきった、と思って寝ました。

翌日の小テスト。10問中、6問でした。

---

## 2　あなたのせいではありません

1時間半、手を動かし続けた。
これは、ほとんどの人ができないことです。

サボっていません。むしろ、やりすぎているくらいです。

だから、ここで言いたいのは「もっとやれ」ではありません。
その逆です。

問題は、努力の量ではなく、その1時間半のあいだ、
頭が何をしていたかです。

---

## 3　何が起きているか

10回書いているあいだ、目はどこを見ていますか。

単語帳です。

見ながら書くのは、写し取る作業です。
思い出す作業では、ありません。

もう1つあります。

書くという作業は、2回目から、手だけでできます。
3回目には、頭はもう別のことを考えています。明日の時間割とか、今日の部活とか。

```
　　1回目　　頭が参加している
　　2回目　　手が覚えはじめる
　　3回目以降　手だけが動いている
```

10回書いたうち、頭が参加しているのは、最初の1回だけです。
あとの9回は、手の運動です。

それでも「やった感じ」は10回ぶん残ります。
手が動いた。時間が経った。ページが埋まった。
この3つがそろうと、人は「覚えた」と判断します。

判断しただけで、確かめていません。

---

## 4　頭のなか

### 伸びない人

```
　　「available、利用できる」
　　「available、available、available……」（書いている）
　　「よし、10回書いた。次」
```

1語に40秒。

### 頭のいい人

```
　　「available、利用できる」
　　「じゃあ、隠す」
　　（手で訳を隠す）
　　「……利用できる」
　　「出た。でも、いま何秒かかった？　2秒だ」
　　「2秒かかったやつは、テストでは出ない」
　　「もう1回。……利用できる。今度は速い」
　　「次」
```

1語に15秒。

---

## 5　分岐点

違いは、1か所です。

出たか出なかったか、ではなく、何秒で出たかを見ている。

```
　　　　　　　何秒で出た？
```

出た、は合格ではありません。
0.5秒で出た、が合格です。

テストの日、1語に2秒かけていたら、長文は最後まで届きません。
制限時間は、思い出す時間を見てくれません。

「覚えた」の線を、出たかどうかから、何秒で出たかに引き直します。

---

## 6　やり方

10語を1セットにします。50語なら、5セット。

```
　1　10語を、上から3秒ずつ見る。　　　　　　　　　　30秒
　　　声に出さなくていい。意味を目で追うだけ

　2　訳を手で隠す。上から10語、順に出していく。　　 30秒
　　　出なかった語　→　その場で、語の横に点を1つ
　　　2秒かかった語 →　同じく、点を1つ
　　　0.5秒で出た語 →　何もしない

　3　点がついた語だけ、もう1周。　　　　　　　　　　20秒
　　　また点がつくものには、点が2つになる

　4　点が全部消えたら、次の10語へ
```

1セット、だいたい2分です。5セットで10分。

次の日、見るのは点が2つ以上ついた語だけです。
50語のうち、だいたい8語から12語になります。

その8語から12語に対してだけ、書いて覚えるをやってください。
書くのが無駄なのではありません。全部に書くのが無駄なのです。

---

## 7　注意

50語を1セットにしないでください。

50語を見てから隠すと、1語目を思い出すまでに1分以上あきます。
1分あくと、思い出す練習ではなく、忘れたものを覚え直す作業に戻ります。

10語が上限です。15語を超えたら、切ってください。

もう1つ。点がついた語を、その場で10回書かないでください。
その場で書くと、見ながら書く作業に戻ります。

点は、次の日のための印です。その日のうちには使いません。

---

## 8　残るもの

時間が変わります。

```
　　10回書く　　　　　1語90秒　×　50語　＝　75分
　　見て、隠して、出す 1語15秒　×　50語　＝　12分
```

同じ50語で、1時間以上あきます。

空いた1時間で、もう1教科できます。
あるいは、1時間早く寝られます。寝ると、覚えたものが残ります。

ただ、本当に残るのは時間ではありません。

「覚えた」の判定基準が、変わります。

```
　　前　　　書いた回数で判定していた
　　後　　　出た速さで判定するようになる
```

この基準は、単語以外にも移ります。

歴史の年号も、理科の用語も、数学の公式も、
全部「何秒で出るか」で測れるようになります。

1教科で身につけた判定基準が、5教科で効きます。

---

## 9　まとめ

10回書くのは、覚える作業ではありません。写す作業です。
覚えたかどうかは、隠してからしか分かりません。

```
　　×　10回書けば、さすがに覚える
　　○　見て、隠して、出す。これで1周
```

　　この場面を見つけた問い　　いま、閉じて出せる？

　　今日やること　　　　　　　今日の単語を10語だけ、3秒ずつ見て、
　　　　　　　　　　　　　　　隠して出す。2秒かかった語に、点を打つ。

入れる力　「いま、閉じて出せる？」

# この1本で使ったもの

```
数字　　　　500回　1時間半　10問中6問　40秒　15秒　3秒　2秒　0.5秒
　　　　　　10語　5セット　2分　10分　8〜12語　75分　12分

具体の語　　available　右手の中指　夜9時　10時半

やっていない　　専門用語を出す　　研究の名前を出す
　　　　　　　　「〜と言われています」で逃げる
```

数字が18個入っている。これが再現できるかどうかを決める。
「短い間隔で」ではなく「10語」。「速く出す」ではなく「0.5秒」。
