# 分岐点　試作5本

32番の形を、ほかの項目に移せるかの試作。
各項目の「頭のなか」の節に、そのまま入る想定。1本200〜300字。

形は3つ。
1　同じ場面で、2つの頭の中を並べる
2　時間を入れる
3　分岐点の1語を取り出す　←　読者が持ち帰るのはここだけ

---

# 37　「ここ、全部わからないです」と言う

なおす力　　×「どこがわからないかも、わからない」

## 頭のなか

### 伸びない人

```
　　「……」
　　「わかんない」
　　「先生、ここ、全部わからないです」
```

3秒です。

### 頭のいい人

```
　　「1行目。xを3でくくった。これはわかる」
　　「2行目。両辺に2をかけた。これもわかる」
　　「3行目。……『したがって』。なんで、ここで したがって になる？」
　　「2行目から3行目のあいだで、何かを使ってる。何だ」
　　「……因数分解の公式か。これ、覚えてないやつだ」
　　「わからないのは、この問題じゃない。公式のほうだ」
```

20秒です。

---

違いは、1か所です。

「わからない」と言う前に、上から指でなぞったかどうか。

そしてなぞるときに、頭のなかで言っている言葉がこれです。

```
　　　　　　　どこまで？
```

全部わからない、という状態は、存在しません。
1行目から読めていないことは、まずないからです。

必ず、読めた最後の行があります。
その次の1行が、あなたのわからないところです。

# 20　単語を、1語10回ずつ書いて覚える

入れる力　　×「10回書けば、さすがに覚える」

## 頭のなか

### 伸びない人

```
　　「available、利用できる」
　　「available、available、available……」（書いている）
　　「よし、10回書いた。次」
```

40秒です。

### 頭のいい人

```
　　「available、利用できる」
　　「じゃあ、隠す」
　　（手で訳を隠す）
　　「……利用できる」
　　「出た。でも、いま何秒かかった？　2秒だ」
　　「2秒かかったやつは、テストでは出ない」
　　「もう1回。……利用できる。今度は速い」
　　「次」
```

15秒です。

---

違いは、1か所です。

出たか出なかったか、ではなく、何秒で出たかを見ている。

```
　　　　　　　何秒で出た？
```

テストの日、1語に2秒かけていたら、長文は最後まで届きません。

出た、は合格ではありません。
0.5秒で出た、が合格です。

2秒かかった語に、印をつけてください。
10回書くのは、その語だけでいいです。

# 30　初めて見る問題を、ゼロから考え続ける

つなげる力　　×「自力で解くのが、本当の力」

## 頭のなか

### 伸びない人

```
　　「見たことない形だ」
　　「でも、考えればわかるはず」
　　「……」
　　「……」
　　「やばい、もう8分たってる」
```

8分です。そして、何も書けていません。

### 頭のいい人

```
　　「見たことない形だ」
　　「待て。本当に、全部が初めてか？」
　　「条件が3つある。1つ目……これは先週やった。2つ目も見た」
　　「3つ目だけが初めてだ」
　　「ということは、初めてなのは組み合わせだけ」
　　「じゃあ、どの問題に似てる？　先週のワークの、あの形か」
　　「あれは最初に図を描いた。じゃあ、図を描く」
```

40秒で、手が動き始めます。

---

違いは、1か所です。

「見たことない」で止まらずに、どこが初めてかを分けた。

```
　　　　　　　全部が初めて？　それとも、組み合わせだけ？
```

入試で、全部が初めての問題は出ません。
出たら、全員が解けないので、差がつかないからです。

必ず、どこかに見たことがあるものが混ざっています。
探すのは、答えではありません。見たことがある部分です。

# 52　やる気が出るのを待つ

続ける力　　×「気分が乗ったら、始めよう」

## 頭のなか

### 伸びない人

```
　　「やらなきゃ」
　　「でも今日、部活きつかったしな」
　　「ちょっとスマホ見てから始めよう」
　　「……9時半か。もう今日はいいや」
```

1時間半です。

### 頭のいい人

```
　　「やらなきゃ」
　　「でも今日、部活きつかったしな」
　　「……で、1個目は何だっけ」
　　（紙を見る）「単語20個」
　　「20個なら3分だ。3分ならできる」
　　（座る）
```

10秒です。

---

違いは、1か所です。

やる気があるかどうかを、一度も考えていない。

```
　　　　　　　で、1個目は？
```

頭のいい人も、疲れています。やりたくないのも同じです。
そこは変わりません。

変わるのは、次に何を考えるかです。

「やる気があるか」を考えると、答えはノーです。
ノーが出たら、始まりません。

「1個目は何か」を考えると、答えは紙に書いてあります。
答えが出るので、手が動きます。

自分に、答えの出ない質問をしないでください。

# 61　緊張したときに、落ち着こうとする

続ける力　　×「落ち着け、落ち着け」

## 頭のなか

### 伸びない人

```
　　「やばい、心臓すごい」
　　「落ち着け、落ち着け」
　　「……落ち着かない」
　　「落ち着かない自分、やばいな」
　　「まわり、みんな落ち着いて見える」
```

落ち着こうとするたびに、落ち着いていない自分が見つかります。

### 頭のいい人

```
　　「やばい、心臓すごい」
　　「……これ、部活の試合前と同じだ」
　　「あのとき、これが出てる日は調子よかった」
　　「体が、準備してるだけだ」
　　「よし、来てる」
```

---

違いは、1か所です。

心臓は、どちらも同じ速さです。
変えたのは、体ではありません。名前です。

```
　　　　　　　来てる
```

緊張と、やる気が出ているときの体は、同じ状態です。
心臓が速い。手が冷たい。息が浅い。

同じものに、片方は「やばい」と名前をつけ、
もう片方は「来てる」と名前をつけています。

名前を変えるのは、ごまかしではありません。
もともと、どちらの名前が正しいかは決まっていません。

# 5本やってみて

## 分岐点の1語

```
　37　どこまで？
　20　何秒で出た？
　30　全部が初めて？　それとも組み合わせだけ？
　52　で、1個目は？
　61　来てる
```

## 確認してほしいところ

```
20　「何秒で出た？」
　　出たかどうかではなく速さを見る、は本当に生徒にやらせていますか。
　　0.5秒と2秒の線引きは、僕が置いた仮の数字です。

30　「組み合わせだけが初めて」
　　実際に、初見問題で止まった生徒にこう聞いていますか。
　　別の聞き方をしているなら、そちらが正しいです。

61　「来てる」
　　部活の試合前とつなげました。
　　部活をやっていない子には効きません。別の入口が要るかもしれません。

37　「どこまで？」
　　これは実際に使っている言葉だと思っています。合っていますか。

52　「で、1個目は？」
　　続ける力の口ぐせそのままです。
```

## 気づいたこと

61番は、分岐点を探すときに「これ、前にどこで同じになった？」を使いました。
つなげる力の口ぐせです。

武器は、本番では混ざります。
終章で「6つが全部出てくる」と書いているのは、こういうことだと思います。
