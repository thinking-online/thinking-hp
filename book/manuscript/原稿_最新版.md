# 序章　頭のいい人が絶対にやらないこと

　　×「とりあえず、量！たくさんやるぞ！」
　　○「やってはいけないことを、避ける」

---

いまのあなたの勉強法、本当に結果が出る方法でしょうか？

本書では、頭のいい人がやってる勉強法を1つずつ見える化していきます。それだけではなくて、頭のいい人が絶対にやらないことも紹介していきます。

ただ、具体的な内容に入る前に、どうしてもわかっておいて欲しい大前提があります。ここを飛ばしたまま闇雲に努力をしたとしても、結果ははっきり言って出ません。

---

まず、1つ聞かせてください。

次の3つの中に、あなたがやってるものはありますか？

```
　　□　参考書や教科書を、何度も読み返す
　　□　覚える時に、教材に蛍光ペンなどで線を引く
　　□　学んだことを、ノートなどにまとめる
```

どうでしょうか。1つはやったことがあるって人が多いと思います。「毎日のようにやってる勉強です」っていう人もいると思います。

単刀直入にいいます。

　　この3つの勉強法、科学的には効果が低いとされています。

「いや、ほんまかいな。」「嘘つけ。みんなやってるわ。」

「先生にお勧めされた勉強法だよ。」「先輩もやっていたって言ってたよ。」

そんな声が聞こえてきますので、1つ1つご説明していきますね。

## 1つ目　何度も読み返す

「何度も教科書を読みなさい」

「繰り返し読まないからダメなんだ」

言われたことがある人、多いですよね。

実際、アメリカの名門大学の学生に聞いた調査では、84パーセントが試験対策に「読み返し」を挙げていました。半分以上が、いちばん大事な勉強法だと答えています。

世界でいちばんやられてる勉強法です。

### 読む回数を増やしても、途中から増えません

高校生と大学生155人に、同じ文章を何度も読ませて、そのあと穴埋め問題を解かせた実験があります。

```
　　1回読んだ人　よりも　2回読んだ人のほうが、点が高かった
　　2回読んだ人　と　　　4回読んだ人は、ほとんど変わらなかった
```

2回目までは、増えます。そこから先は、増えません。

4周した人と2周した人の点が同じってことは、後半の2周に使った時間は、まるごと消えてるってことです。

### しかも、その差は数日で消えます

コロラド大学の実験です。

大学生に同じ文章を読ませて、3つのグループに分けました。

```
　　1　1回だけ読む
　　2　2回続けて読む
　　3　1回読んで、1週間あけてから、もう1回読む
```

テストの時期も、読んだ直後と、2日後で分けました。

```
　　読んだ直後のテスト　　2が1位。3は1とほとんど変わらなかった
　　2日後のテスト　　　　3が1位。2は1と同じところまで落ちた
```

順位、ひっくり返ってますよね。

続けて2回読むのは、その日のうちは本当に効きます。効いた実感もあるし、直後の点も上がります。

でも、数日で消えます。

テストって、読んだ直後にはないですよね。

同じ回数読むなら、続けてじゃなくて、間隔をあける。それだけでも全然違います。

### なぜ、効いてる感じがするのか

ここが、いちばん大事なところです。

理由は、はっきりしています。

　　2回目は、すらすら読めるからです。

1回目より楽に、速く、引っかからずに読める。その感じを、人は「わかった」と受け取ります。

でも、すらすら読めるようになったのは、文章に慣れただけです。覚えたからじゃありません。

　　読めるようになっただけで、出せるようにはなっていない。

この取りちがえを、「流暢性の錯覚」と言います。

単語帳をぱらぱらめくって、見覚えのある単語が並んでるのを見て、なんとなく覚えた気になる。授業のノートを見返して、見覚えがあるから理解できてると思う。

全部これです。頭は、自分の覚え具合を、実際より高く見積もります。

---

読み返すこと自体が、悪いわけじゃありません。

　　読み返すだけで、終わるのが悪いんです。

## 2つ目　ノートにまとめる

これは、受験の王様として生徒を見てきた中で、やってるのに結果が出てない生徒を、本当にたくさん見てきました。

教科書や参考書の内容を、色ペンを使ってきれいにまとめる。時間はすごくかかるのに、結果が出ない。その代表がこれです。

理由は2つあります。

1つ目。要約って、そもそも難易度が高い作業なんです。

全体を把握して、何が幹で何が枝かを判断して、大事なところを短い言葉に組み直す。先生から「要約するといいぞ」と言われたこと、あると思います。でも、簡単な作業じゃありません。

2つ目。ほとんどの場合、ノートを作ること自体が目的になります。

きれいに書けた。全部埋まった。終わった。そこで満足して、閉じます。何時間かけても、プロが何年もかけて作った参考書のクオリティには届きません。

まとめて書くことで得られるものより、そこで失う時間のほうが、はるかに大きい。

## 3つ目　マーカーと下線

教科書に蛍光ペンで印をつける。これも、やったことありますよね。

結論から言います。覚えたいことを頭に入れるためには、使えません。

大事なところに印をつけると、安心しますよね。印をつけた時点で、脳が満足しちゃうんです。でも、やったのは仕分けだけです。中身は1つも入っていません。

歴史の教科書を使った実験があります。下線を引きながら読むグループと、引かずに読むグループで、1週間後にテストをしました。

書いてあることをそのまま聞く問題では、差がありませんでした。

ところが、書いてあることを組み合わせて答える問題では、下線を引いた人のほうが点が低くなりました。

線が引いてあるところだけに目が行って、文章全体のつながりが見えなくなってた、ということです。

英語の長文や現代文みたいに、文と文の関係を読む科目では、やらないほうがまし、ということになります。

ハイライトについては、ほかにも実験があります。自分でハイライトしながら読んだ人、引かずに読んだ人、他人が引いたものを読んだ人。1週間後のテストで、3つのグループに差はありませんでした。

## 3つとも、いちばん多くやられてる方法です

もう1つだけ、紹介させてください。

大学生200人以上に、普段どうやって勉強しているかを聞いて、実際の試験の点数と照らし合わせた調査があります。

いちばん多く使われていたのは、教科書を読み返す、ノートを読み返す、マーカーを引く。この3つでした。

そして、そのどれも、点数とほとんど関係がありませんでした。

点が高かったのは、自分で問題を解いて確認していた人たちです。

```
　　勉強時間の長さより、何をしていたかのほうが、点を説明していた
```

僕がこれまで2000人以上の中高生に同じことを聞いてきた結果も、まったく同じでした。

　　多くの人がやってるから、結果が出るとは限らない。

いちばん多くの人がやっていて、いちばん効かない。

自分の当たり前を、一度疑って欲しいんです。

## 「でも、先輩はそれで受かったって言ってました」

ここまで読んで、そう思った人もいると思います。

学校の先生。合格した部活の先輩。昔、受験をした親。みんな、自分のやり方で勝ってます。だから、そのやり方を教えてくれる。全部、善意です。

ただ、昔からこういう言葉があります。

　　勝ちに不思議の勝ちあり、負けに不思議の負けなし。

勝つときには、運やタイミングが混じることがある。だから、なぜ勝てたのか、本人にもわからないことがある。でも、負けるときには、必ず原因がある。たまたま負けた、ってことは起きないんです。

先輩が受かったのは、本当です。

でも、そのやり方で受かったのかどうかは、本人にもわかりません。その年の倍率。たまたま出た問題。もともと得意だった教科。全部、混ざってます。

確かなのは、こっちです。

　　やってはいけないことをやったら、誰がやっても結果は出ません。

倍率にも、環境にも、関係ありません。

だから本書は、誰か1人の勝ち方じゃなくて、全員に共通する「やってはいけないこと」から書いてあります。

### 幹の名前は「思い出して、出す」

　　思い出すこと。

これだけです。英語では、アクティブリコールと呼ばれています。本書では「思い出して、出す」と書きます。

巻頭で、11個の数字を覚えてもらいましたよね。

伏せたから、出せるかどうかがわかった。伏せなかったら、永遠に「たぶん覚えた」のままでした。

あれが、思い出すということです。

練習でやっていないことは、本番では起きません。

出なかったはずです。

10秒前に読んだばかりなのに、出てこない。難しい話でもなかったのに、出てこない。読むのと、出せるのは、別の作業だからです。

序章で決めたのは、選び方の基準でした。やりやすかったか、ではなく、出せたか。ここから先は、その「出す」の中身です。何を、どうやって出すのか。

## 読んでいるあいだ、頭は何もしていません

```

```

## 07　間違えた問題を、もう一度解く

　　○「どこで止まったかを、探す」

なおす力

前回のテストで間違えた問題を、1つ思い出してください。

どの教科の、どんな問題でしたか。

---

間違い直しは、やったはずです。赤ペンで、正しい答えを書いたはずです。それでも、1問も思い出せない。

## 直したのは、問題でした

間違い直しでやっているのは、だいたいこれです。

```
　　正しい答えを、写す
　　もう一度、同じ問題を解く
　　解説を、もう一度読む
```

3つとも、その問題を直しています。でも、次のテストに、その問題は出ません。似た問題が、形を変えて出ます。だから、問題を直しても、次に効きません。

## 直すべきなのは、止まった場所です

1つの問題を間違えるとき、全部が間違っているわけではありません。どこかの1行で、止まっています。

```
　　図　問題文を4行で描く

　　1行目　　読めた
　　2行目　　読めた
　　3行目　　ここで止まった　　←　これが原因（指を置く）
　　4行目　　以降、ついていけない
```

止まったのが3行目なら、直すのは3行目です。問題ではありません。そして3行目で止まる人は、別の問題の3行目でも止まります。だから、場所を直すと、1回で何問ぶんも直ります。

```
　　×がついたとき、伸びない人の頭のなか
```

```
　　② 下げていく。「ここまでは分かる」を確かめながら
　　③ 指が止まったところ。そこが、止まった場所です
　　④ その1行だけを、紙に書き写す
　　⑤ そこで初めて、解説を見る。その1行のところだけ
```

④で、問題全部を写さないのが大事です。1行だけ残すから、あとで見返せます。

止まった場所には、名前をつけます。書き写した1行に、1語だけ名前をつけます。

```
　　知らなかった　　言葉・公式・やり方を、そもそも持っていなかった
　　気づかなかった　持っていたのに、使うと分からなかった
```

```
　　知らなかった　　→　覚える
　　気づかなかった　→　覚えても直りません
　　　　　　　　　　　「このときは、これ」を1行で書く
```

ここを分けずに、全部を「覚える」で直そうとする人が、いちばん多いです。だから、同じミスが何回も出ます。


```
　　　　　答えを見たとき、知らない言葉はあったか
```

あった　→　知らなかった。なかった　→　気づかなかった。

これで、必ず分かれます。

```
　　　　　どこで、止まった？
```

```
　　数学からにするか、英語からにするか

```

```
　　○　教科書を1ページ読む
```

## 09　実力がついてから、過去問を開く

　　×「まだ早い。力がついてから使おう」
　　○「解かずに開いて、出るところだけ数える」

選ぶ力

高校3年生の6月。志望校の赤本を買いました。買った日にパラパラめくって、1問も解けませんでした。英語の長文は半分で時間が切れ、数学は大問1の途中で止まった。

本棚に立てました。

夏が終わって力がついてから、腕試しとして解こう。いまは、基礎の参考書を進めている最中です。この判断には、理由が3つあります。いまやっても解けないから、意味がない。過去問は数が限られているので、使い切りたくない。腕試しは、力がついてからのほうが正確に測れる。3つとも、まともです。どれも間違っていません。それでも、11月にこうなります。過去問を開いて、2日目の大問3を見て、気づきます。この学部に、この分野が一度も出ていない。夏の2ヶ月、そこをやっていました。

## 過去問を、問題集だと思っています

いま起きていることは、1つだけです。過去問を、問題集として扱っている。問題集は、解くための本です。だから「解けるようになってから使う」が正しい。本棚に立てた判断は、問題集に対しては完全に正しいのです。でも、過去問は問題集ではありません。

## 試験には、範囲があります

ここが、この章でいちばん大事なところです。試験には、出るものと出ないものがあります。どんな試験にもです。受験、定期テスト、資格の試験、全部そうです。出題する側は、無限に出せません。時間も配点も決まっているので、どこを出すかを決めてから作ります。つまり、試験が始まる前から、答えの半分は決まっています。どこが出るか、です。そして、その境界線が書いてある紙は、1種類しかありません。

過去問です。

過去問は、問題が載っている本ではありません。出るものと出ないものの境界線が、唯一書いてある紙です。これを見ないまま走るのは、範囲が決まっている試験を、範囲が決まっていない試験として受けることです。出ない分野を3ヶ月やっても、点は1点も増えません。努力が足りなかったという話ではありません。努力した場所が、採点されない場所だった、という話です。

## 頭のなか

### 赤本を買った日、伸びない人

「うわ、全然解けない」「まだ早かったな」「夏が終わってから、ちゃんと解こう」「もったいないから、きれいなまま取っておこう」

### 同じ日、頭のいい人

「うわ、全然解けない」「……まあ、そりゃそうか。6月だし」「でも、これ解きに来たんじゃない」「何が出るのか見に来たんだ」「大問いくつある？　4つか」「配点は……長文が30で、文法が20、語彙が20、英作文が30」「英作文、30点もあるのか。1回も書いたことないぞ」「あと、発音問題が1問もない。これ3年とも？」「……3年とも出てない。じゃあ発音帳、今年は閉じる」解いていません。1問もです。やったのは、数えることだけです。違いは1つ。過去問を、解く本だと思っているか、出る場所が書いてある紙だと思っているか。

## やり方

### 1　3つだけ、紙に書き出す

大問の数。それぞれの配点。出てくる分野の名前。これだけです。問題は読みません。英語なら、大問1が文法で20点、大問2が語彙で20点、のように書く。3年分やります。1年分では、たまたまが混ざります。

### 2　いま持っている参考書の目次を、横に並べる

書き出した紙と、参考書の目次を並べます。ここで、ずれが見えます。参考書には40単元あって、過去問に出ているのは22単元、ということが起きます。

### 3　一度も出ていない分野に、線を引く

3年分に一度も出ていないものに、線を引きます。それが、今日から手をつけないものです。40単元が22単元になります。同じ時間で、1単元にかけられる時間が倍になります。ここまで、15分です。高3の6月の15分で、夏の2ヶ月が変わります。

## 進めていて止まったときも、1ページ目には戻りません

やる場所を決めたあと、参考書を進めていると、必ず止まるページが出てきます。

78ページの応用問題。解説を読んでも、何を言っているのかわかりません。基礎が抜けているのかもしれない、と思います。途中で飛ばしたところもあった気がします。1ページ目に戻ります。1ページから30ページは、簡単です。スラスラ進みます。3日かかって、また78ページに戻ってきて、やっぱりわかりません。

戻るという判断は、正しいです。手前に原因があることは、よくあります。問題は、どこまで戻るかです。

戻る先の決め方は、1つだけです。

　　わかった最後の場所を探す。

78ページがわからないなら、77ページはわかりますか。わかるなら、原因は78ページの中にあります。77ページもわからないなら、70ページはどうですか。こうやって、わかるところが出てくるまで戻ります。たいていは、3ページから10ページ戻れば見つかります。1ページ目まで戻ることは、ほとんどありません。

ここでも、やっているのは同じことです。やらない場所に線を引いています。範囲のときは、出ないところに線を引きました。つまずいたときは、わかっているところに線を引きます。残ったところだけをやります。

## やりすぎないための注意

1年分だけで決めないでください。1年だけ出ていなかった分野を捨てると、翌年に出ます。3年分、できれば5年分見ます。同じ大学でも、学部で出題が変わります。同じ県でも、高校で変わります。自分が受けるところの過去問を見てください。捨てたのは「いまはやらない」であって「永久にやらない」ではありません。線を引いた紙は、取っておきます。余裕ができたら、そこから戻します。

## これをやると、何が残るか

自分が捨てた単元を、言えるようになります。「今日は何をやるか」を聞かれて答えられる人は、たくさんいます。「今年やらないと決めた単元」を言える人は、ほとんどいません。やることを答えられる人は、今日の予定を持っている人です。やらないことを答えられる人は、全体の設計を持っている人です。設計を持っている人は、10月に焦りません。やらなかったのは、やり忘れたのではなく、選んだからです。

## この場面のまとめ

過去問は、解く本ではなく、やらないことを決める本。試験には範囲がある。その境界線が書いてある紙は、過去問だけ。

　　この場面を見つけた問い　　これ、出るのか？

今日やること過去問を1年分開いて、大問の数と配点と分野だけを紙に書き出す。解かない。

## AIにやらせるなら

書き出した紙を、そのまま渡せます。「過去3年分の出題分野と配点を貼ります。毎年出ている分野と、一度も出ていない分野に分けてほしい」3年分を目で並べるのは手間です。分け方が出てきたら、自分の目で1回確かめてください。AIは見落としも作ります。

## 10　範囲の全部に、一度ずつ手をつける

　　×「とりあえず全部に触っておけば、安心」
　　○「3周できる量だけ選んで、1つずつ終わらせる」

選ぶ力　★厚く書く

定期テストの1週間前。範囲は、ワークの32ページから58ページまで。計画を立てました。1日4ページずつやれば、7日で終わる。きれいな計画です。実際、7日でやり切りました。全部のページに手がつきました。

テストの日。

半分くらいの問題で、見たことはあるけれど出てこない、という状態になります。

## 一度やった、はゼロと同じです

ここが、いちばん受け入れにくいところかもしれません。1回やった問題は、まだできるようになっていません。1回目に解いたとき、×だった問題があります。解説を読んで、なるほどと思った。そして次のページに進んだ。

その問題は、いまどうなっていますか。

できるようになったのではありません。解説を見て、納得しただけです。テストでは、解説がありません。27ページ分に一度ずつ手をつけた人の手元には、「見たことがある」が27ページ分あります。点になるのは、「できる」だけです。

## 全部に触るか、半分を終わらせるか

同じ7日間を、2人がこう使ったとします。

```
Aさん　27ページ全部を、1回ずつ
Bさん　14ページを、3回ずつ
```

Aさんは、27ページ全部が「見たことがある」で止まります。Bさんは、14ページが「できる」になります。残りの13ページは、白紙です。テストに出るのは、27ページ分です。Aさんのほうが広くカバーしているように見えます。でも、点が入るのはBさんです。見たことがある問題は、解けません。できる問題だけが、点になります。ただし、Bにも条件が1つあります。その14ページが、出る14ページであること。どれをやるかを先に決める。これが、この章の話です。

## 満点を取ろうとした人が、いちばん低い点になります

もう1つ、同じ形のまちがいがあります。全部できるようにしないと不安だから、満点を取るつもりで範囲をやる、というやり方です。

中学3年生の12月。志望校の前年の合格者平均は、5教科で380点でした。本人は、それを知りません。ワークを1問目から順にやって、できない問題が出てきたら、できるまでやります。全部できるようにしないと受からないと思っているからです。1月になって、理科と社会に手がついていないことに気づきます。数学の応用問題に、12月の3週間を使っていたからです。

その応用問題は、本番で1問出ました。配点は4点でした。手をつけなかった社会には、40点ぶんの出題がありました。

満点を目指すということは、全部の問題を同じ重さで扱う、ということです。4点の問題と40点の分野が、同じ重さになります。時間は有限なので、どこかで止まります。止まった時点で、手をつけていない場所が残ります。残った場所が40点だった、というだけの話です。

そして、合格点は、たいてい思っているより低いです。公立高校の入試で、合格者平均が6割台ということは、よくあります。大学入試でも、6割から7割で受かる学部はたくさんあります。6割でいいということは、4割は落としていい、ということです。

落としていい4割を決めてから始める人と、全部取るつもりで始める人では、1日の中身が変わります。

　　合格点　380
　　いまの点　320
　　差　　　　60

この60が、今日から埋めるものです。埋める先は、いちばん低い科目からです。80点の科目を90点にするより、40点の科目を60点にするほうが速いからです。「まだ足りない」は終わりません。「あと60点」は、終わります。

### 計画を立てるとき、伸びない人

### 同じとき、頭のいい人

「範囲は27ページ。1日4ページで、7日で1周」「……1周で終わるってことは、全部が1回ずつだ」「1回やった問題、テストで解けるか？」「解けないな。いつもそうだ」「じゃあ3周したい。27ページ3周は、無理」「何ページなら3周できる？　9ページか」「9ページを、どこにする？」「先生が2回言ったところと、ワークの星2つ。それで足りるか見てみよう」

## やり方

### 1　「何周できるか」から考える

ページ数から入らず、周回数から入ります。テストまでの日数と、1日に使える時間を出します。3周できるページ数を、逆算します。

### 2　やるページを選ぶ

選ぶ基準は、この順です。

```
1　先生が「出す」と言ったところ
2　ワークで印がついている重要問題
3　前回のテストで間違えたのと同じ形
```

### 3　選ばなかったページに、線を引く

線を引いたら、見ません。時間が余ったら戻ります。余らなければ、やりません。

## 選ぶときは、1ページ目を開きません

やるページを選ぶとき、人は無意識に、できるところから始めます。

ワークの1ページ目から始めるのは、自然な行動です。ワークはそういう作りになっています。でも、理由はもう1つあります。最初のほうは、解けるからです。解ける問題を解いているときは、気持ちがいい。○がつく。進んでいる感じがする。できない問題から始めると、×がつきます。手が止まります。進んでいる感じがしません。

テスト3日前に、1ページ目から2時間やって10ページまで来た人がいます。その10ページは、授業で2回やったところでした。解けなかったのは、13ページ以降の問題でした。

だから、選ぶときは、解きません。ページをめくって、問題を見るだけです。「これ、いま解ける?」を自分に聞いて、解けない問題に印をつけます。10分で終わります。

印がついたところから始めます。1ページ目は、最後でいいです。時間が余らなければ、開かなくてかまいません。

一度やった、は、できるではない。全部に触った人の手元に残るのは「見たことがある」だけ。

## 11　模試を、点数と判定だけ見て閉じる

　　×「E判定か。次こそがんばろう」
　　○「どの大問が落ちたか。それだけ見る」

選ぶ力

模試が返ってきた日。

封を開けます。いちばん上に、総合点と判定が書いてあります。

　　320点　　E判定

見た瞬間、気持ちが落ちます。ほかのページを見る気になりません。ファイルに入れて、机の横に積みます。次の模試まで、2ヶ月あります。その2ヶ月、この模試から得たものは、E判定という3文字だけです。

## 判定は、いちばん情報量が少ない数字です

模試の成績表には、何十個も数字が載っています。大問ごとの得点。設問ごとの正答率。分野別の到達度。同じ判定の人の平均との差。そのうち、いちばん情報量が少ないのが、判定です。判定は、全部の数字を1文字に潰したものです。潰したものからは、何も取り出せません。Eだとわかっても、明日やることが1つも決まりません。

## 見るべきは、たった2つです

模試の成績表で、見る価値があるのは2つだけです。

```
1　どの大問で落としたか
2　その大問は、本番でも出るか
```

これだけです。

1を見ると、自分の穴が大問の単位でわかります。2を見ると、その穴を埋める価値があるかがわかります。この2つで、明日やることが決まります。

## 頭のなか

### 成績表を開いた瞬間、伸びない人

「320点……」「E判定か」「まあ、まだ夏だし」「次こそがんばろう」（閉じる）

## やり方

### 1　総合点と判定のページは、閉じる

見なくていいとは言いません。見たあと、すぐ次のページに行きます。

### 2　大問別の得点表を開く

得点率が低い大問に、印をつけます。3つまでです。

### 3　その大問の正答率を見る

正答率が50パーセントを超えていて、自分が落としている問題。ここが最優先です。みんなが取れていて、自分が取れていない。いちばん差が開いているところです。

### 4　1行、書く

　　「確率の、場合の数の数え上げ」

できないノートに1行書きます。これで模試の処理は終わりです。所要時間は、15分です。

## これをやると、何が残るか

模試が、2ヶ月ぶんの指示書になります。判定だけ見た人の手元には、Eという文字しか残りません。2ヶ月後、また同じところで落とします。大問を見た人の手元には、3行残ります。2ヶ月、その3行を消しにいきます。

## この場面のまとめ

判定は、全部の数字を1文字に潰したもの。潰したものからは何も取り出せない。見るのは、どの大問で落としたかと、その正答率。

　　この場面を見つけた問い　　これ、出るのか？

今日やることいちばん最近の模試を出して、大問別の得点表を開く。得点率が低い大問を3つ書き出す。

## AIにやらせるなら

大問ごとの得点を打ち込んで、こう聞けます。「模試の大問別の得点です。配点も書きます。次の2ヶ月で、どこから埋めると総合点がいちばん上がりますか」出てきた順番を、自分の目で確かめてください。AIは、本番の出題傾向を知りません。そこは自分で足します。

## 12　毎日、全教科に少しずつ手をつける

　　×「どれも大事だから、平等にやろう」
　　○「新しく入れるときは、1つ終わらせてから次へ」

選ぶ力

高校1年生。苦手が5つあります。英文法の関係詞。数学の二次関数。化学のモル計算。古文の助動詞。世界史の中世。どれも放っておけないので、毎日少しずつやることにしました。1日2時間を、5つで割ります。1つにつき24分です。1ヶ月続けました。真面目にやりました。2ヶ月目に入っても、5つとも苦手なままです。

## 24分では、立ち上がりで終わります

やり始めてから、頭が動き出すまでに時間がかかります。前回どこまでやったかを思い出す。ノートを開く。前の問題を見返す。ここまでで5分から10分かかります。24分のうち、実際に進んでいるのは10分くらいです。そして明日、また同じ立ち上がりをやります。1ヶ月で、5つとも「立ち上がり」だけを30回やったことになります。

## 新しく入れるときは、まとめてやったほうが入ります

ここだけ、はっきり言います。これから新しく覚えるものは、1つずつ、まとめてやってください。混ぜないでください。二次関数を3日集中してやれば、終わります。終わったら、次に行けます。5つを少しずつやると、1ヶ月後も5つ残っています。1つずつやると、1ヶ月後に3つ終わっています。

同じ時間です。

（復習のときは、逆になります。混ぜたほうが残ります。43番で書きます）

## 頭のなか

### 計画を立てるとき、伸びない人

「苦手が5つある」「どれも落とせない」「毎日ちょっとずつやろう。1日24分ずつ」

### 同じとき、頭のいい人

## 13　まだいない自分を基準に、計画を立てる

　　○「先週やった時間を見てから、決める」

続ける力

日曜日の夜。中学3年生。

今週は、ほとんど勉強しませんでした。反省して、来週の計画を立てます。月曜　3時間火曜　3時間水曜　3時間木曜　3時間金曜　3時間土曜　6時間日曜　6時間週に27時間です。書き終わって、少しすっきりしました。月曜。部活から帰ったのが7時。ごはんを食べて、8時。机に座ったのが8時半で、11時に寝ました。2時間でした。火曜は1時間半。水曜は0でした。木曜の朝、計画表を見ます。全部ずれています。

月曜に3時間やる人を、基準にしています。その人は、まだ一度も出てきていません。先週も、その前の週も、実際にやったのは1日2時間でした。いない人の計画を、いる人が実行しようとしています。守れないのは、当たり前です。意志の問題ではありません。最初に書いた数字が、自分の数字ではなかった、というだけです。

## なぜ、いない自分で立ててしまうのか

日曜の夜だからです。

日曜の夜は、やる気があります。1週間を反省したあとなので、今週こそは、と思っています。そのとき頭に浮かぶのは、理想の自分です。3時間やれる自分。朝6時に起きる自分。その自分で計画を立てます。そして月曜の夜、実際に机に向かうのは、理想の自分ではありません。部活で疲れた、いつもの自分です。計画を立てる人と、実行する人が、別人になっています。

## 頭のなか

### 日曜の夜、伸びない人

「今週は全然できなかった」「来週はちゃんとやろう」「平日3時間、休日6時間。これならいける」（書く）「よし」

## やり方

### 1　先週、実際にやった時間を数える

記憶ではなく、記録で数えます。記録がない人は、ここから始めてください。スマホのメモに、終わった時間を1行書くだけでいいです。1週間ぶんたまったら、それが基準です。

### 2　その数字を、そのまま書く

良いか悪いかは判定しません。少なくても、それが事実です。事実からしか、計画は立ちません。

### 3　その8割で、来週を組む

13.5時間だったなら、11時間です。増やしません。増やすのは、この計画を2週続けて守れてからです。

## 崩れる日を、最初から1日入れておきます

計画が崩れたとき、人はこう考えます。

　　今週は、たまたま遠征が入った。

でも、先週も何かありました。来週も、たぶん何かあります。学校行事、部活、体調、家の用事、急な小テスト。1週間に1日くらいは、必ず何かが入ります。崩れることは、例外ではありません。毎週起きることです。毎週起きることを例外として扱っているから、毎週作り直すことになります。

作り直した30分で、問題は1問も解いていません。これを4回くり返すと、2時間が消えます。そして、計画を作り直すことのほうが習慣になります。

やることは1つです。1週間の計画を立てるとき、1日を空けておきます。何も入れません。予備日です。崩れなかった週は、その日で先に進めます。崩れた週は、その日で取り返します。木曜の朝にやるのは、水曜の分を予備日に移すだけです。矢印を1本引いて、30秒で終わります。紙は、1枚のままです。

曜日はどこでもいいですが、週の後半に置くほうが使いやすいです。前半で崩れることが多いので。長い計画ほど、余白を多めに取ります。1ヶ月なら、4週のうち1週を調整の週にします。

守れた1週間が残ります。

27時間の計画を立てて13時間やった人の1週間は、「14時間足りなかった週」として終わります。11時間の計画を立てて13時間やった人の1週間は、「2時間多くできた週」として終わります。やった時間は、同じ13時間です。残るものが、逆になっています。計画が続かない人は、根性がない人ではありません。毎週、減点をつけられ続けてきた人です。つけていたのは、その紙です。

今日やること今日、勉強が終わった時間を、スマホのメモに1行書く。7日ためたら、それが来週の基準になる。

## 何が起きているか

## 聞いていなかったわけでは、ありません

ここでよく言われるのが「集中して聞いていなかったからだ」です。でも、本当に聞いていたのです。先生が何の話をしていたかも言えます。ノートにも書いてあります。問題は、聞き方ではありません。聞くという行為そのものが、受け身だということです。

授業の50分で、あなたの頭が何回「出した」か、数えてみてください。当てられたのが1回だとしたら、1回です。あとの49分は、入れているだけです。家で単語を50分やるとき、あなたは何回も書いたり、思い出したりします。授業では、それを1回もやらずに50分が終わります。これが、授業を受けているのにテストで出てこない理由です。入れた量の問題ではなく、出した回数が0に近いという問題です。

## 先に、自分で答える

やることは1つだけです。

先生が問いを出す前に、自分で先に答えを作る。

```
　　先生「ここで大事なのは、なんでしたっけ」
　　　　　　　　↑　この「は」まで聞いた時点で、自分で答えを出す
```

先生の話し方には、くせがあります。「じゃあ」「つまり」「ここ大事」「なんでしたっけ」。この言葉が出たら、次に答えが来ます。来る前に、自分で言ってしまう。心の中で、1秒で。合っていたかどうかは、1秒後に先生が教えてくれます。これで、50分の授業が、50分のテストになります。

## 1コマに3回で、じゅうぶんです

全部の問いに先回りしようとすると、疲れて続きません。1コマに3回でいいです。3回やると、先生の言葉のくせがわかります。わかると、先回りが自動になります。

## 映像授業なら、止められます

同じことが、映像授業でも起きます。

1.5倍速。1コマ30分の授業が20分で終わります。今日は3コマ見ました。1時間で、90分ぶんの授業です。けっこう進んだと思って、寝ます。次の日、そのコマの確認テストで、半分しか取れません。

映像授業が悪いのではありません。わからないところを何回でも見られて、先生も選べます。問題は、その最大の利点を使っていないことです。映像授業にあって、教室の授業にないもの。それは、止められることです。

倍速にすると、入る速さは上がります。出す回数は、0のままです。

```
　　1倍速で30分　　出した回数　0
　　2倍速で15分　　出した回数　0
```

進んだ気がするのは、再生バーが右に動いたからです。再生バーは、あなたの頭の中を測っていません。

止める場所は、2種類だけです。

```
　1　先生が問題を出した直後
　　　「じゃあ、これ解いてみて」　→　止める。自分で解く

　2　先生が答えを言う直前
　　　「ここで使うのは……」　　　 →　止める。自分で言う
```

この2つだけで、1コマに5回くらい止まります。止まっているのは、1回10秒です。5回で50秒。20分で0回出すより、31分で5回出すほうが残ります。

倍速は、2周目からです。1周目は等速で、止めながら。2周目は倍速で、止めずに。先生が言う前に自分の頭が言っていたら、入っています。倍速の正しい使い道は、速く入れることではなく、速く確かめることです。

## これをやると、何が残るか

```
　　授業は、聞く時間ではない。
　　当てられ続ける時間にできる。
```

## この場面のまとめ

```
　　×　先生の話を、ちゃんと聞いておこう
　　○　次に何を聞かれるかを、先に考える
```

入れる力　「いま、閉じて出せる？」

## 18　板書を、全部そのまま写す

　　×「書いておけば、あとで見返せる」
　　○「写さない。その場で、1回わかる」

入れる力

数学の授業。先生が黒板に例題を書いて、解き始めます。ノートを開いて、写します。式を1行写す。顔を上げる。次の行を写す。顔を上げる。先生が何か説明していますが、手を動かしているので、半分しか聞こえません。45分、ずっと写していました。ノートは3ページ埋まりました。家に帰って、そのノートを開きます。式は全部そろっています。でも、なぜその式になったのかが、書いてありません。先生はそれを、口で言っていました。そのとき、手を動かしていました。

## 写している間、聞いていません

人は、書きながら聞くのが苦手です。写すという作業は、黒板を見て、形を覚えて、紙に再現する、という作業です。この間、頭は形の処理をしています。先生の言葉は、耳から入ってきますが、処理されません。そして、黒板に書いてあることと、先生が言っていることは、別です。黒板に書いてあるのは、結果です。先生が言っているのは、なぜそうなるか、です。写した人のノートには、結果だけが残ります。なぜそうなるかは、教室に置いてきています。

## 板書は、あとで手に入ります

ここが大事なところです。

黒板に書いてあることは、ほとんどの場合、教科書か問題集にも書いてあります。あとから手に入ります。先生がその場で言った言葉は、二度と手に入りません。手に入るもののために、手に入らないものを捨てています。

## 写さずに、何をするか

授業中にやることは、1つです。

　　わかったかどうかを、その場で判定する。

先生が説明しているあいだ、こう自分に聞きます。

　　「いま、これを自分で説明できるか」

できるなら、何も書きません。できないなら、1行だけ書きます。書くのは、式ではありません。

　　「3行目の変形、わからない」

これだけです。

## 頭のなか

### 授業中、伸びない人

（黒板を見る）「えーと、2x + 3y = 12 ……」（書く）「次、両辺を……」（書く）「あ、先生何か言った。まあ、あとで見ればいいか」

### 同じ授業中、頭のいい人

（黒板を見る。書かない）「2x + 3y = 12 を、yについて解く」「……両辺から2xを引いて、3で割る。これは自分でできる」「書かなくていい」（次の例題）「お、ここで場合分けが出てきた」「なんで場合分けが要るんだ？」（先生の説明を聞く）「……ああ、aが0のときに割れなくなるからか」「それ、黒板に書いてない。メモしよう」（1行だけ書く）「aで割る前に、a=0を確認」書いた量は、1行です。でも、その1行は教科書に書いていないことです。

## やり方

### 1　板書は、写さない

教科書に載っている例題なら、ページ番号だけメモします。

　　「教p.52 例3」

これで十分です。

### 2　先生が口で言ったことだけ、書く

黒板にないことを言った瞬間だけ、ペンを持ちます。「ここ、テストに出す」「この変形、みんな間違える」「ここでaが0の場合を忘れると、点が来ない」

こういう言葉です。

### 3　わからなかったところを、1行書く

授業の最後に、1行書きます。

　　「3行目の場合分けが、まだわからない」

これが、家でやることになります。

## 写したほうがいい場合

1つだけあります。

図です。

グラフ、実験装置、歴史の地図。こういうものは、見ただけでは頭に入りません。手で描くと入ります。図だけは、写してください。文字は写さなくていいです。

## 読むときも、同じことが起きています

授業を聞いているときだけではありません。教科書や問題文を読んだあとにも、同じ状態になります。

　　だいたいの意味はつかめた。

このとき、頭が何をしているかというと、知っている言葉を拾って、間をつないでいます。知らない言葉は、飛ばしています。飛ばした言葉が、たまたま飾りだったら、意味は取れます。飛ばした言葉が、文の骨だったら、まったく違う意味になります。そして、どちらだったかは、自分ではわかりません。飛ばしたことに、気づいていないからです。

　　アミラーゼという酵素はグルコースがつながってできたデンプンを分解するが、同じグルコースからできていても、形が違うセルロースは分解できない。

　　問　セルロースは（　　　）と形が違う。

答えは、デンプンです。グルコースと答える人が多いのですが、文には「同じグルコースからできていても、形が違う」と書いてあります。材料が同じで、形が違う。だから、形が違うのはデンプンとの間です。グルコースが2回出てきて、「形が違う」のすぐ近くにあるので、目が引っぱられます。生物の知識は要りません。文の形だけで解けます。

やることは1つです。読み終わったあと、知らない言葉が何個あったかを数えます。意味がはっきり言えないものは、全部「知らない」に入れます。「なんとなくわかる」も、知らないに入れてください。

3個以上あったら、意味で読むのをやめます。かわりに、知らない言葉を記号に置きかえます。

　　AはBがつながってできたCを分解するが、同じBからできていても、形が違うDは分解できない。

　　問　Dは（　　　）と形が違う。

これなら、Cだとわかります。何と何が比べられているか、どれが主語か。それだけを追います。

## これをやると、何が残るか

家に帰ったときの、やることが決まります。全部写した人のノートには、3ページの式が並んでいます。どこがわからなかったのかは、書いてありません。1行書いた人のノートには、3行あります。「3行目の場合分けがわからない」「a=0の確認」「教p.52」。家でやるのは、この3行です。10分で終わります。

## この場面のまとめ

板書は、あとで手に入る。先生が言った言葉は、二度と手に入らない。授業中にやるのは、わかったかどうかの判定。

　　この場面を見つけた問い　　いま、閉じて出せるか？

今日やること次の授業で、1つの例題だけ、写さずに聞く。聞き終わったあと、わからなかったことを1行書く。

## 19　予習を、ノートに写すだけで終える

　　×「予習はやった方がいいから、とりあえず写しておく」
　　○「知っていることを3つ書いてから、授業に出る」

つなげる力

理科の新しい単元が始まります。「電流」です。教科書の新しいページを開いて、1行目から読み始めます。知らない言葉が出てきます。抵抗、オーム、直列。30分読みました。終わったとき、何も残っていません。

## まっさらで聞くのは、礼儀正しい態度です

先入観を持たずに聞く。これは、ちゃんとした人の態度です。ただ、記憶の作りには合っていません。新しいことは、新しい場所には入りません。すでにある場所の、となりにしか入りません。まっさらで聞くというのは、となりに何も置かずに聞くということです。

## 知っていることが、引っかかりになります

電流の単元に入る前に、あなたはもう何かを知っています。

```
　　・コンセントに水をかけると危ない
　　・乾電池には向きがある
　　・豆電球を2個つなぐと、暗くなった（小学校でやった）
```

3つ書けました。これで、新しい言葉を引っかける場所が3か所できます。「直列」が出てきたとき、まっさらな人は言葉だけを覚えます。3つ書いた人は「豆電球が暗くなったやつか」とつながります。同じ30分で、残る量が変わります。

### 新しい単元、伸びない人

```
　　「とりあえず読もう」

　　「……抵抗って何だっけ」
```

### 同じとき、頭のいい人

```
　　「電流か。やったことない……いや、何か知ってるはずだ」

　　「コンセント。水で感電する」
　　「よし、3つ出た。これに引っかけていこう」
```

---

違いは、1か所です。

「やったことない」で止まらずに、知っていることを探した。

```
　　　　　　　本当に、何も知らない？
```

中学の単元で、本当にゼロから始まるものは、ほとんどありません。小学校か、生活の中か、別の教科で、必ず一度は触っています。

## 20　小テストを、点が出たら捨てる

　　×「10点満点の小テストなんて、意味がない」
　　○「小テストは、本番の予告。間違えたものだけ残す」

なおす力

毎週水曜日、英語の小テスト。単語10問。今日は7点でした。返ってきた紙を、カバンの底に入れます。

来週も、たぶん7点です。

## 10点に意味を感じないのは、普通です

成績に入らない小テストを本気で見る中学生は、あまりいません。点が低くても怒られないし、高くても何も起きない。ここで言いたいのは「小テストも大事にしよう」ではありません。小テストの点は、本当にどうでもいいです。どうでもよくないのは、間違えた3問のほうです。

## 小テストは、本番の予告です

小テストの範囲は、どこから出ていますか。

教科書の、今やっている単元です。定期テストの範囲も、同じところです。

```
　　小テストで落とした3問
　　　　　　↓
　　定期テストでも出る3問
```

先生は、わざわざ別の問題を作りません。小テストで出した語は、定期テストでもう一度出ます。つまり、小テストは「ここが出ます」という予告です。予告を見てから本番に行けるテストは、学校の中にしかありません。

## 残すのは、紙ではなく3問です

やることは、1分で終わります。

```
　1　返ってきたら、その場で間違えた語だけ見る
　2　1冊のノートの後ろから、1行ずつ書き写す
　3　テスト用紙は、捨てていい
```

書き写すのは、間違えたものだけです。合っていた7問は、二度と見なくていいです。1回の小テストで3問なら、1学期で12回。36語です。その36語が、あなただけの単語帳になります。市販の単語帳と違って、1語も無駄がありません。全部、自分が実際に落とした語だからです。

## 書き写すときに、やってはいけないこと

赤ペンで正解だけ書き写さないでください。

```
　　×　available　利用できる
　　○　available　利用できる　／　自分は「避けられる」と書いた
```

自分が何と書いたかを、横に残します。これを残しておくと、同じ間違いをしていることに気づきます。avoid と混ざっているなら、直すのは available ではなく、avoid と available を分けることです。

## これをやると、何が残るか

```
　　小テストは、点を取る場所ではない。
　　間違いを集める場所だ。
```

## この場面のまとめ

```
　　×　10点満点の小テストなんて、意味がない
　　○　小テストは、本番の予告。間違えたものだけ残す
```

なおす力　「どこで、止まった？」

## 23　教科書に線を引いて、まとめノートを作る

　　×「大事なところに印をつけておけば、あとで見返せる」
　　○「線を引く前に、閉じて言ってみる」

入れる力　★厚く書く

日曜日の午後。中学2年生。来週のテストに向けて、まとめノートを作っています。教科書を左に開いて、ノートを右に置きます。大事なところを、色分けしながら書き写していきます。3時間かかりました。8ページのノートができました。きれいです。

テストの日。

ノートに書いたはずのことが、出てきません。

## 書き写している間、頭は何もしていません

まとめノートを作っているとき、手は3時間動いています。だから、やった感覚が強く残ります。でも、そのあいだ頭が何をしていたかを考えてみてください。教科書の文字を見る。その文字を、ノートに移す。色を選ぶ。線を引く。全部、見ながらやる作業です。1回も、思い出していません。3時間、手は動きました。頭は、1回も「探す」をしていません。

## きれいなノートができたことが、いちばんの問題です

できあがったノートは、きれいです。きれいなノートを見ると、頭はこう判断します。

　　これだけやったんだから、入っているはずだ。

この判断が、確認を止めます。ノートができた時点で、満足してしまう。だから、そのノートを閉じて、中身を思い出してみる、をやりません。やった感じがいちばん強いのに、残っているものがいちばん少ない。これが、まとめノートです。

## まとめること自体が悪いのではありません

まとめるのは、頭の中を整理する作業です。整理すること自体は、意味があります。問題は、見ながらまとめていることです。同じ3時間を、こう変えます。

　　教科書を閉じてから、まとめる。

これだけで、まったく別の作業になります。閉じてまとめると、書けないところが出ます。書けなかったところが、あなたの「できない」です。そこだけ教科書を開いて、確かめて、書き足します。

## 頭のなか

### ノートを作っているとき、伸びない人

「ここ大事そうだな」「赤で書いておこう」「このへんも書いておくか」「よし、1ページ埋まった」

### 同じとき、頭のいい人

「まとめる前に、1回閉じよう」（教科書を閉じる）「この単元、何が書いてあった？」「光合成の式……二酸化炭素と水から、デンプンと酸素」「場所は、葉緑体」「あと何かあったな……条件？　光が要る」「……他に出てこない」（教科書を開く）「あ、呼吸との違いが書いてある。これ忘れてた」「ここだけ、書こう」書いたのは、1行です。でも、その1行は、自分が出せなかった1行です。

## やり方

### 1　教科書を閉じる

机の上から、どかしてください。

### 2　白紙に、思い出せることを書く

箇条書きでかまいません。字も汚くていいです。3分で書けるところまで書きます。

### 3　教科書を開いて、抜けているところを探す

書けなかったことが、3つか4つ出てきます。それだけを、赤で書き足します。できあがるノートは、きれいではありません。穴だらけで、赤が目立ちます。それでいいです。赤いところが、あなたの弱点です。

## 引いていい線と、引いてはいけない線

この先、この本には「線を引きます」と書いてある場面が5回出てきます。

```
　01　一度も出ていない分野に、線を引く
　03　選ばなかったページに、線を引く
　23　同じところに、線を引く
　28　聞かれていることに、線を引く
　29　設問に関係しそうな場所に、線を引く
```

序章で「線を引くのをやめてください」と書いたのに、おかしいと思うはずです。

違いは1つです。何のために引くか。

```
　×　大事そうだから、引く
　○　あとで自分が出すときの、手がかりになるから引く
```

上の5つは、全部、手がかりです。01と03は「ここはやらない」という目印です。あとで迷わないために引きます。23は、3つの共通点を1つにまとめるための目印。28と29は、何を探すかを決めるための目印です。どれも、引いたあとに自分が何かをするために引いています。「大事そうだから」引いた線は、引いたあとに何もしません。だから、残りません。引く前に、1回だけ聞いてください。

　　この線、あとで何に使う？

答えが出ないなら、引かないでください。

## これをやると、何が残るか

テスト前日に見るものが、赤いところだけになります。きれいな8ページのノートを持っている人は、前日に8ページ全部を見返します。そのうち7ページは、もともとできるところです。穴だらけのノートを持っている人は、赤いところだけ見ます。1ページ分もありません。同じ前日の30分で、埋まる穴の数が違います。

## この場面のまとめ

まとめるのが悪いのではない。見ながらまとめるのが悪い。閉じてからまとめると、書けなかったところが見つかる。

　　この場面を見つけた問い　　いま、閉じて出せるか？

今日やること今日習ったところを、教科書を閉じて、白紙に3分で書き出す。そのあと教科書を開いて、抜けていたものを赤で書き足す。

## 24　単語を、1語10回ずつ書いて覚える

出す力

英語の小テストが明日あります。範囲は30語。ノートを開いて、1語ずつ書いていきます。

　　available available available available ……

## 書いている間、単語帳を見ています

10回書くとき、ほとんどの人は単語帳を見ています。

見ながら書いているあいだ、頭は何をしているか。

## 回数ではなく、回数の中身です

10回書くのが悪いのではありません。1回目に見て書き、2回目から閉じて書くなら、10回でもかまいません。ただし、たいてい3回目で覚えるので、10回はいりません。悪いのは、10回とも見ながら書くことです。10回見ながら書くより、1回思い出して書くほうが、残ります。しかも、速いです。

## 頭のなか

### ノートに向かって、伸びない人

## やり方

### 1　10個だけ見る

30個を一気に見ないでください。10個ずつです。見る時間は30秒。覚えようとしなくていいです。眺めるだけ。

### 2　閉じて、10個書く

紙に書きます。英語と意味、両方です。出てこないものは、飛ばします。粘らないでください。10秒で次に行きます。

### 3　開いて、出なかったものだけ印をつける

## この場面のまとめ

## 25　英単語を、1語1訳で覚える

　　×「available は、利用できる。以上」
　　○「同じ形の仲間を、まとめて見る」

つなげる力

単語帳を開いています。

```
　　available　　利用できる
```

覚えました。次へ。

```
　　capable　　　能力がある
```

覚えました。次へ。

1日50語。3日で150語。1週間後、150語のうち40語しか出てきません。

## 1語1訳は、最初は正しいです

単語を覚えはじめたときに、意味を1つに絞るのは正しいです。最初から3つも4つも覚えようとすると、1つも残りません。問題は、1語1訳のまま、1,500語まで行こうとすることです。50語なら、1個ずつでいけます。1,500語を1個ずつは、いけません。

## 1個ずつ入れると、1個ずつしか出てきません

頭の中で、こうなっています。

```
　　available　　→　利用できる
　　capable　　　→　能力がある
　　reliable　　 →　信頼できる
```

3本の線が、別々に引かれています。1本切れたら、その1語は出てきません。同じ形に気づいた人の頭は、こうなっています。

```
　　　　　　　　　　　　　avail（役に立つ）
　　　　　　　　　　　　  cap（つかむ）　　　＋　-able「〜できる」
　　　　　　　　　　　　  rely（たよる）
```

3本が1か所でつながっています。1語思い出せたら、残り2語も一緒に出てきます。

## 新しい語を見たら、10秒だけ考えます

やることは1つです。

新しい語を見たとき、「この形、前にどこで見た？」と1回だけ聞く。

```
　　impossible　　→　im- は前にどこかで見た　→　incorrect、invisible
　　　　　　　　　　　im-／in- は「〜でない」

　　transport　　 →　trans- は前にどこかで見た　→　translate、transfer
　　　　　　　　　　　trans- は「移す」
```

思い出せなかったら、そこで終わりです。10秒まで。思い出せたら、2語か3語が一度に入ります。

## 語源を調べはじめると、沼です

ここで、語源辞典を買ってはいけません。ラテン語まで戻ると、楽しくはなりますが、テストには出ません。戻るのは、自分が前に見た単語までです。判断は簡単です。その説明に、自分がすでに知っている単語が出てこないなら、やめます。

## 似ているものは、違いだけ覚えます

くっつけるのは、英単語だけではありません。似ているものが2つ3つ並んだときも、同じです。

理科の、光合成と呼吸。光合成は、二酸化炭素と水から、デンプンと酸素を作る。呼吸は、酸素とデンプンから、二酸化炭素と水を作る。これを、それぞれ覚えました。テストで、こう出ます。

```
　　「次のうち、呼吸を表す式はどれか」
　　ア　二酸化炭素 + 水 → デンプン + 酸素
　　イ　デンプン + 酸素 → 二酸化炭素 + 水
```

迷います。どちらも見覚えがあります。これは、覚えていないのではありません。2つとも覚えているから、混ざっています。勉強量が多い人ほど、ここで落とします。

出てくる言葉は、4つとも同じです。違うのは、矢印の向きだけです。だから、覚えるのは1つです。

　　光合成は、作るほう。呼吸は、使うほう。

これだけで、式は作れます。作るほうならデンプンが右。使うほうならデンプンが左。

同じことが、あちこちで起きています。

```
　　動脈と静脈　　　　　　違うのは、向きだけ
　　需要と供給　　　　　　違うのは、どちら側か
　　不定詞の3用法　　　　 違うのは、文の中での働き
　　等差数列と等比数列　　違うのは、足すか掛けるか
　　蒸散と蒸発　　　　　　違うのは、生き物が関わるかどうか
```

やり方は3つです。似ていると感じたら、同じ紙に並べて書く。同じところに線を引いて消す。残った違いを、1つの短い言葉にする。長いと、それ自体が覚えられません。

## これをやると、何が残るか

```
　　単語は、1個ずつ覚えると、1個も出てこない。
　　前に覚えた語に、くっつける。
```

```
　　×　available は、利用できる。以上
　　○　同じ形の仲間を、まとめて見る
```

## 26　忘れてから、最初から覚え直す

　　×「もう全部忘れた。1からやり直しだ」
　　○「忘れる前に、間をあけてもう1回出す」

入れる力

高校1年生。夏休みに、英単語を500語やりました。8月の終わりには、ほとんど出せるようになっていました。9月は、学校が始まって忙しく、単語に手をつけませんでした。10月も、中間テストがあって、やりませんでした。11月、模試の前に単語帳を開きます。

ほとんど出てきません。

　「もう全部忘れた。1からやり直しだ」

また、1ページ目から始めます。

## 忘れるのは、ふつうのことです

まず、ここを押さえてください。覚えたことは、忘れます。これは、できない人だけに起きることではありません。全員に起きます。できる人が忘れないのではありません。できる人は、忘れる前に、1回出しているだけです。

## 忘れてからだと、ゼロからになります

覚えたことは、時間がたつと、だんだん出にくくなります。ある時点までは、ちょっと見れば思い出せます。その時点を過ぎると、見ても思い出せなくなります。忘れきってから開くと、1回目と同じ作業をすることになります。500語を、また最初からです。忘れかけているうちに開くと、全然違います。500語のうち、出てこないのは100語くらいです。その100語だけやればいいので、5分の1の時間で済みます。

## 間をあけるのが、ポイントです

ここが、少し意外なところです。毎日やればいいのではないか、と思うかもしれません。毎日だと、効率が落ちます。昨日やったことは、まだ忘れていないので、思い出す練習になりません。ちょうどいいのは、忘れかけたころです。1回目　　覚えた日2回目　　次の日3回目　　1週間後4回目　　1ヶ月後だんだん間を広げていきます。出しにくいタイミングで出すほうが、残ります。楽に出せるうちに出しても、あまり効きません。

## 頭のなか

### 11月、伸びない人

（単語帳を開く）「うわ、全然わからない」「夏にやったのに」「もう1回、最初からやるしかないな」

### 同じ11月、頭のいい人

「夏に500語やった。あれから2ヶ月半か」「全部は残ってないな。どれくらい残ってる?」（閉じて、50語分テストしてみる）「50個中、30個出た」「6割残ってるのか。思ったより残ってる」「出なかった20個に印をつけよう」「500語全部じゃなくて、この割合なら200語くらいか」「200語なら、3日で戻せる」1からやり直していません。残っているものを数えて、残っていないものだけを拾っています。

## やり方

### 1　覚えた日から、復習の日を3つ決める

覚えた日に、カレンダーに3つ印をつけます。

　　翌日　／　1週間後　／　1ヶ月後

この3回で、かなり残ります。

### 2　復習のときは、必ず閉じて出す

開いて眺めるのは、復習ではありません。閉じて、出せるかどうかを確かめます。出たものは終わり。出なかったものだけ、もう一度見ます。

### 3　出なかったものだけ、次の復習に持ち越す

回を追うごとに、量が減ります。1回目　500語2回目　180語3回目　60語4回目　20語4回目には、20語になっています。10分で終わります。

## もう忘れてしまった人へ

いま読んでいる人の中には、すでに忘れてしまった人もいると思います。その場合も、1からやり直さないでください。まず、どれくらい残っているかを数えます。50個だけテストして、何個出るかを見ます。6割出たなら、6割は残っています。残りの4割だけやれば、戻ります。全部忘れた、という感覚は、たいてい大げさです。

## これをやると、何が残るか

同じ量を、4分の1の時間で維持できます。忘れてから覚え直す人は、500語を3回やります。忘れる前に出す人は、500語を1回と、180語、60語、20語です。合計で、760語ぶんです。1500語ぶんやった人より、少ない。そして、残っている量は多いです。

## この場面のまとめ

忘れるのは全員に起きる。できる人は、忘れる前に1回出している。間をあけて、出しにくいときに出すほうが残る。

　　この場面を見つけた問い　　いま、閉じて出せるか？

今日やること今日覚えたものを、カレンダーに3つ印をつける。翌日、1週間後、1ヶ月後。その日に、閉じて出す。

## 27　「わかった」を、テストの日まで信じる

　　×「あそこは、もうできるから大丈夫」
　　○「できるかどうかは、出してから決める」

出す力

定期テストの2週間前。

計画を立てます。範囲の中で、どこをやるか決めます。「1章は大丈夫。2章も授業でわかった」「3章が苦手だから、3章をやろう」2週間、3章をやりました。3章は、できるようになりました。

テストの日。

3章の問題は解けました。1章と2章で、落としました。

## 「大丈夫」の根拠を、聞かれたら答えられますか

2週間前、「1章は大丈夫」と判断しました。

この判断の根拠は、何だったでしょうか。

授業でわかった。ワークも解いた。たしかに、そのときはできました。そのときは、3週間前です。3週間前にできたことが、いまもできるかどうかは、確かめていません。

## 「大丈夫」は、過去形です

ここが大事なところです。

「あそこは大丈夫」と言うとき、人は過去の記憶を見ています。

できたときの記憶です。

その記憶は本物ですが、情報としては古いです。3週間前の状態を、いまの状態だと思っています。そして、人は忘れます。3週間あれば、けっこう忘れます。

## 確かめるのに、3分しかかかりません

1章が大丈夫かどうかを確かめる方法は、1つです。1章から、問題を3問選んで、解いてみる。

3分です。

3問とも解けたら、本当に大丈夫です。計画から外していいです。1問でも落ちたら、大丈夫ではありません。3分で、2週間の使い道が決まります。

## よくわかった日の、その夜がいちばん危ない

これは、2週間前だけの話ではありません。授業を受けたその日の夜にも、同じことが起きます。

理科の授業で、天体をやりました。先生の説明がうまくて、地球が回っているから星が動いて見える、というところまで、はっきりわかりました。黒板の図も、意味がわかった状態で写せました。家に帰って、今日の分をどうするか考えます。今日はよくわかったので、ここはやらなくていい。わからなかった数学をやろう。

1ヶ月後のテスト。図を白紙に描け、という問題が出ます。手が止まります。

この子は、嘘をついていません。授業中、本当にわかっていました。先生の説明を聞いて、うなずけた。図の意味も取れた。これは、ちゃんと聞いていた人にしか起きません。

問題は、そのあとです。わかったことと、何も見ずに出せることが、別だということを知りません。授業中、目の前には黒板があります。先生の声があります。その状態で「わかる」というのは、与えられた情報を受け取って、つじつまが合った、ということです。テストの日、黒板はありません。先生の声もありません。白紙に、自分で出します。

だから、家に帰ったら、その日いちばんよくわかった単元を1つ選びます。よくわかったものを選ぶのが、ここのコツです。わからなかったものは、どうせやります。危ないのは、わかったと思っているところです。

教科書とノートを閉じて、白紙に図を描きます。3分です。描けなかったところが、1つか2つ出ます。その1つが、テストで落とすところでした。

## 捨てる判断が、速くなります

これは、捨てる力の話でもあります。「大丈夫」を確かめずに捨てると、捨てたところで落とします。確かめてから捨てると、安心して捨てられます。確かめた人は、3章に集中できます。1章のことを、1回も思い出さずに済みます。確かめていない人は、3章をやりながら、頭の隅で1章が気になっています。

## 頭のなか

### 計画を立てるとき、伸びない人

「範囲は1章から4章」「1章は大丈夫、2章も大丈夫」「3章が苦手だから、3章をやろう」

### 同じとき、頭のいい人

「1章は大丈夫……たぶん」「たぶん、ってなんだ。確かめよう」（1章から3問選んで解く）「1問目、できた。2問目、できた」「3問目……あれ、出てこない」「ここ、授業でわかったところだ。わかったのに、出てこない」「1章、大丈夫じゃなかったな」「じゃあ計画を変えよう。3章と、1章のこの単元」3分で、計画が変わりました。

## やり方

### 1　「大丈夫」と思っている単元を、全部書き出す

テスト範囲の中で、やらなくていいと思っているところです。だいたい、2つか3つあります。

### 2　それぞれから、3問ずつ選ぶ

選び方は、いちばん後ろのページの問題です。そこがいちばん難しいので、判定が正確になります。

### 3　解く。見ないで

答えも解説も見ません。制限時間は、1問1分です。

### 4　1問でも落ちたら、計画に戻す

3問とも解けたら、本当に捨てていいです。

## 頭の中で確かめると、あいまいなまま通過します

閉じて出すとき、頭の中でやらないでください。口を動かしてください。

歴史の、明治維新のところを覚えました。頭の中で流れを確認します。ペリーが来て、開国して、幕府が倒れて、明治政府ができた。言えました。覚えています。テストで、こう出ます。

　　「幕府が倒れた理由を、60字以内で説明せよ」

書けません。

頭の中で確認するとき、言葉は完全な形になっていません。「ペリーが来て」「……開国して」「……で、なんか不満が出て」「幕府が倒れた」。「なんか」の部分が、あいまいなまま通過しています。自分の頭の中なので、あいまいでも止まりません。

同じことを、口に出して言ってみてください。「ペリーが来て、開国して、えーと……」。ここで止まります。「なんか不満が出て」は、口に出せません。口に出すには、誰のどんな不満かを言わないといけないからです。

言葉にできないところが、覚えていないところです。「えーと」が出たら、そこです。「なんか」「あれ」が出たら、そこも同じです。止まったところだけ確認して、もう一度最初から言います。2回目で止まらなければ、終わりです。

聞く相手がいると、さらに効きます。相手がいると、省略できなくなります。自分に向かって言うときは「あれが、こうなって」で通ります。人に向かって言うときは、あれが何かを言わないと伝わりません。相手は、家の人でも、友達でも、ぬいぐるみでも、壁でもかまいません。誰かに向かって言う形になっていれば、効きます。

人に頼むときは、こう言ってください。

　　「わからなかったら、わからないって言って」

うなずくだけだと、効きません。わからないと言われたところが、説明できていないところです。聞く側は、その科目を知らないほうがいいです。知らない人に伝わる説明が、いちばん確かです。

## 相手がいるなら、教え合いではなく出し合いにします

テスト1週間前。友達3人で、図書館に集合しました。2時から4時まで、2時間。途中で英語の話をして、昨日のドラマの話をして、またワークに戻りました。楽しかったです。帰り道、今日何ができるようになったかを聞かれても、答えられません。

一緒にやるのは、正しいです。1人だとやらない人が、友達となら2時間やる。これは、立派な続ける力です。止めたいのは、一緒にやることではありません。一緒にいるだけで、出し合っていないことです。

教え合いが起きるとき、だいたいこうなります。

```
　　わかっている人　→　説明する　→　出している　→　伸びる
　　わからない人　　→　聞く　　　→　入れている　→　その場だけ
```

教え合いという言葉は、両方が得をしそうに見えますが、実際に出しているのは、説明した1人だけです。

やり方を1つ変えます。

```
　1　集まる前に、お互い5問つくってくる　　　　　　　家で10分
　　　範囲は同じでいい。答えも書いてくる
　2　集まったら、交換して解く　　　　　　　　　　　　　 10分
　3　答え合わせ。間違えたものだけ説明してもらう　　　　 10分

```

## 31　時間を測らずに解いて、解けたと数える

　　×「時間をかければ解けた。できる判定」
　　○「本番と同じ時間で、出せたか」

出す力

高校2年生。数学の問題集を進めています。1問目。10分かかりましたが、解けました。○。2問目。15分かかりました。解けました。○。3問目。20分かかりました。解けました。○。3問で45分です。全部○でした。できる、と判定します。

模試の日。

同じレベルの問題が、大問3つで、制限時間は60分でした。1問目に25分かかって、2問目の途中で終わりました。

## 時間を測らないと、できるの基準がずれます

20分かけて解けた問題は、できる問題でしょうか。

本番で、その問題に20分使えるなら、できる問題です。本番で使えるのが7分なら、できない問題です。同じ問題でも、持ち時間によって、できる・できないが変わります。時間を測らないと、この判定ができません。

## 本番の持ち時間を、知っていますか

ここで一度、計算してみてください。

　　試験時間　÷　問題数　＝　1問あたりの時間

数学で、60分で大問4つなら、1問15分です。英語で、80分で長文2つと文法30問なら、長文1つに25分です。この数字を知らずに練習している人が、かなりいます。知らないと、何分で解けばいいかがわかりません。わからないので、時間を測る意味もわかりません。

## 測ると、やることが変わります

時間を測ると、解き方が変わります。

15分と決めて解き始めると、途中で時計を見ます。7分たって、まだ方針が立っていなかったら、焦ります。焦ると、判断します。この問題は後回しにしよう、とか、別の方法を試そう、とか。

この判断が、本番で必要になるものです。測らずに解いている人は、この判断を1回も練習していません。

## 頭のなか

### 問題を解き終わったとき、伸びない人

「できた」「ちょっと時間かかったけど、まあ解けたし」「○にしとこう」

### 同じとき、頭のいい人

（タイマーを見る）「18分か」「本番の持ち時間は15分。オーバーしてる」「これは△だな」「どこで時間を使った?」「最初の方針を決めるのに、6分かかってる」「計算は速かった。方針が遅い」「方針が遅いってことは、型の候補が足りてないな」「この形の問題、あと3問やろう」○か×かではなく、○△×の3つで判定しています。

## やり方

### 1　本番の持ち時間を、計算する

志望校の過去問か、模試の問題を見て計算します。

　　試験時間　÷　大問の数

これを、紙に書いて、机に貼っておきます。

### 2　タイマーを置いて解く

スマホでもキッチンタイマーでもいいです。スマホを使うなら、機内モードにしてください。

### 3　○△×で判定する

```
○　時間内に解けた
△　解けたが、時間オーバー
×　解けなかった
```

△は、できるではありません。本番では、△は×になります。

### 4　△の原因を、1行書く

「方針を決めるのに6分かかった」「計算ミスで2回やり直した」原因で、次にやることが変わります。

## 全部測る必要はありません

毎回タイマーを置くのは、しんどいです。週に1回、まとめて測る日を作るのでもいいです。日曜に、大問4つを本番と同じ時間で解く。それだけでも違います。ふだんの練習は、時間を測らずにやってかまいません。ただし、そのときつけた○は、○ではなく「解き方はわかる」です。

## 34　「ここ、全部わからないです」と言う

## 頭のなか

### 試験が始まった瞬間、伸びない人

「よし、始まった」（大問1を見る）「計算か。これはいける」（解き始める）

### 同じ瞬間、頭のいい人

「まず、全部見る」（1分でめくる）「大問1、計算。5分」「大問2、関数。これもいける。10分」「大問3、証明。これは重い。後回し」「大問4、確率。公式覚えてる。8分」「大問5、資料。読むだけ。7分」「1、2、4、5で30分。残り19分を3に使う」（大問1から解き始める）1分使いました。その1分で、残り49分の使い方が決まりました。

## やり方

### 1　始まったら、1分で全部めくる

名前を書いたら、すぐやります。解きません。見るだけです。

### 2　大問の横に、記号を書く

A　知っていれば終わるB　考えないと解けない

2秒で書けます。

### 3　Aを全部終わらせてから、Bに入る

順番を無視します。大問1からでなくていいです。

### 4　Bに入るとき、残り時間を見る

残り時間を、Bの数で割ります。Bが2つで、残り20分なら、1つ10分です。10分たったら、途中でも次に行きます。そして、最後に戻ります。

## 後回しにしたほうも、白紙では出しません

Aを全部終わらせて、Bに入りました。残り時間で、Bが最後まで解けないことがあります。そのとき、白紙で出さないでください。

数学のテスト。大問4、証明問題です。読みます。難しそうです。最後まで解ける気がしません。飛ばしました。答案が返ってきます。大問4は0点です。配点は12点でした。隣の席の子は、同じ問題で5点取っていました。最後まで解けていません。途中までしか書いていません。それでも、5点入っていました。

記述問題には、部分点があります。答えが合っているかどうかだけで、点が決まるのではありません。証明問題なら、こうなっていることが多いです。

```
　　仮定を正しく書いた　　　　2点
　　使う定理を正しく選んだ　　3点
　　途中の式変形が正しい　　　4点
　　結論まで到達した　　　　　3点
```

最後まで行けなくても、前半の5点は取れます。

白紙に書き込める点数は、0点だけです。何も書かなければ、必ず0点です。1行書けば、0点ではなくなる可能性があります。そして、書ける1行は、たいてい誰にでもあります。

```
　1　問題文の条件を、式か記号にする
　2　図があれば、わかっていることを書き込む
　3　使えそうな定理や公式の名前を書く
```

この3つは、たいてい書けます。かける時間は、2分です。無理につなげようとしないでください。書けるところまで書いて、次に行きます。

解けない問題を全部白紙にすると、0点です。それぞれで3点から5点拾うと、合計で10点から15点になります。これは、新しいことを覚えなくても取れる点です。いま持っている知識のままで、書き方を変えるだけで取れます。

選択問題でも、同じです。マークシートなら、必ず塗ります。4択なら25パーセントで当たります。明らかに違う選択肢を1つ消せれば33パーセント、2つ消せれば50パーセントです。

## 気をつけること

マークシートの場合、順番を変えると、ずれる危険があります。解いた問題の番号を、必ず確認してください。飛ばした問題のマークを、空けておくのを忘れないでください。ここだけは、慎重にやります。

## これをやると、何が残るか

取りこぼしが、なくなります。順番に解いた人は、できる問題を時間切れで落とします。これは、いちばんもったいない落とし方です。先に見た人は、できる問題を全部取ってから、難しい問題に向かいます。同じ実力で、5点から10点変わります。

## この場面のまとめ

試験が始まったら、最初の1分で全部めくる。時間が読める問題を先に全部終わらせてから、読めない問題に残り時間を使う。
