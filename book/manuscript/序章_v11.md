いまのあなたの勉強法、本当に結果が出ますか。

ただ、その前に、どうしても分かっておいてほしいことがあります。

ここを飛ばして闇雲にやると、51個を読んでも結果が出ません。

まず、1つ聞かせてください。

次の3つの中に、あなたがやっているものはありますか。

```
　　□　参考書や教科書を、何度も読み返している
　　□　覚えるときに、教科書に蛍光ペンで線を引いている
　　□　学んだことを、ノートにまとめている
```

どうでしょうか。1つはやったことがある、という人が多いと思います。いまも続けている人も、たくさんいるはずです。

単刀直入に言います。

　　==この3つは、科学的には効果が低いとされています。==

1つずつ、見ていきます。

## 効果が低い勉強法　1　何度も読み返す

「何度も教科書を読みなさい」

「繰り返し読まないからダメなんだ」

言われたことがある人は、多いと思います。実際、アメリカの名門大学の学生に聞いた調査では、84パーセントが試験対策に「読み返し」を挙げていました。半分以上が、いちばん大事な勉強法だと答えています。

世界でいちばん多くやられている勉強法です。

### 読む回数を増やしても、途中から増えません

高校生と大学生155人に文章を何度も読ませて、そのあと穴埋め問題を解かせた実験があります。

```
　　1回読んだ人　よりも　2回読んだ人のほうが、点が高かった
　　2回読んだ人　と　　　4回読んだ人は、ほとんど変わらなかった
```

2回目までは、増えます。そこから先は、増えません。

4周した人と2周した人の点が同じなら、==後半の2周に使った時間は、まるごと消えています==。

### しかも、その差は数日で消えます

コロラド大学の実験です。

大学生に同じ文章を読ませて、3つのグループに分けました。

```
　　1　1回だけ読む
　　2　2回続けて読む
　　3　1回読んで、1週間あけてから、もう1回読む
```

テストの時期も、読んだ直後と、2日後で分けました。

```
　　読んだ直後のテスト　　2が1位。3は1とほとんど変わらなかった
　　2日後のテスト　　　　3が1位。2は1と同じところまで落ちた
```

順位が、ひっくり返っています。

続けて2回読むのは、その日のうちは本当に効きます。効いた実感もあるし、直後の点も上がります。

でも、数日で消えます。

テストは、読んだ直後にはありません。

同じ回数読むなら、続けてではなく、間隔をあける。それだけでも違います。

### なぜ、効いていると感じるのか

ここが、いちばん大事なところです。

理由は、はっきりしています。

　　2回目は、すらすら読めるからです。

1回目より楽に、速く、引っかからずに読めます。その感じを、人は「わかった」と受け取ります。

でも、すらすら読めるようになったのは、==文章に慣れたからです。覚えたからではありません==。

　　読めるようになっただけで、出せるようにはなっていません。

この取りちがえを、==「流暢性の錯覚」==と言います。

単語帳をぱらぱらめくって、見覚えのある単語が並んでいるのを見て、なんとなく覚えている気になる。授業のノートを見返して、見覚えがあるから、理解していると思う。

全部これです。頭は、自分の覚え具合を、実際より高く見積もります。

---

読み返すこと自体が、悪いのではありません。

　　==読み返すだけで、終わるのが悪いんです。==

## 効果が低い勉強法　2　ノートにまとめる

受験の王様として生徒を見てきた中で、この勉強法をやっていて結果が出ていない生徒を、本当にたくさん見てきました。

教科書や参考書の内容を、色ペンを使ってきれいにまとめる。時間はとてもかかるのに、結果が出ない。その代表がこれです。

理由は2つあります。

1つ目。要約は、そもそも難易度が高い作業です。

全体を把握して、何が幹で何が枝かを判断して、大事なところを短い言葉に組み直す。先生から「要約するといいぞ」と言われたことがあると思いますが、簡単な作業ではありません。

2つ目。ほとんどの場合、ノートを作ること自体が目的になります。

きれいに書けた。全部埋まった。終わった。そこで満足して、閉じます。何時間かけても、プロが何年もかけて作った参考書のクオリティには届きません。

まとめて書くことで得られるものより、==そこで失う時間のほうが、はるかに大きい==。

## 効果が低い勉強法　3　マーカーと下線

教科書に蛍光ペンで印をつける。これも、やったことがあると思います。

結論から言います。覚えたいことを頭に入れるためには、使えません。

大事なところに印をつけると、安心します。印をつけた時点で、脳が満足してしまいます。でも、やったのは仕分けだけです。中身は1つも入っていません。

歴史の教科書を使った実験があります。下線を引きながら読むグループと、引かずに読むグループで、1週間後にテストをしました。

書いてあることをそのまま聞く問題では、差がありませんでした。

ところが、書いてあることを組み合わせて答える問題では、==下線を引いた人のほうが点が低くなりました==。

線が引いてあるところだけに目が行って、文章全体のつながりが見えなくなっていた、ということです。

英語の長文や現代文のように、文と文の関係を読む科目では、やらないほうがましということになります。

ハイライトについては、ほかにも実験があります。自分でハイライトしながら読んだ人、引かずに読んだ人、他人が引いたものを読んだ人。1週間後のテストで、3つのグループに差はありませんでした。

## 3つとも、いちばん多くやられている方法です

もう1つだけ、紹介させてください。

大学生200人以上に、普段どうやって勉強しているかを聞いて、実際の試験の点数と照らし合わせた調査があります。

いちばん多く使われていたのは、教科書を読み返す、ノートを読み返す、マーカーを引く。この3つでした。

そして、そのどれも、点数とほとんど関係がありませんでした。

点が高かったのは、自分で問題を解いて確認していた人たちです。

```
　　勉強時間の長さより、何をしていたかのほうが、点を説明していた。
```

僕がこれまで2000人以上の中高生に同じことを聞いてきた結果も、まったく同じでした。

　　==多くの人がやっているから、結果が出るとは限らない。==

いちばん多くの人がやっていて、いちばん効かない。

自分の当たり前を、一度疑ってほしいんです。

## 「でも、先輩はそれで受かったって言ってました」

ここまで読んで、そう思った人もいると思います。

学校の先生。合格した部活の先輩。昔、受験をした親。みんな、自分のやり方で勝っています。だから、そのやり方を教えてくれます。全部、善意です。

ただ、昔からこういう言葉があります。

　　勝ちに不思議の勝ちあり、負けに不思議の負けなし。

勝つときには、運やタイミングが混じることがある。だから、なぜ勝てたのか、本人にも分からないことがある。でも、負けるときには、必ず原因がある。たまたま負けた、ということは起きない。

先輩が受かったのは、本当です。

でも、==そのやり方で受かったのかどうかは、本人にも分かりません==。その年の倍率。たまたま出た問題。もともと得意だった教科。全部、混ざっています。

確かなのは、こっちです。

　　==やってはいけないことをやったら、誰がやっても結果は出ません。==

倍率にも、環境にも、関係ありません。

だからこの本は、誰か1人の勝ち方ではなく、全員に共通する「やってはいけないこと」から書いてあります。

## このまま続けると、どうなるか

ここまでが、1つ目の話です。

効果がありそうに見えて、実は薄い勉強法がある。しかも、いちばん多くの人がやっている。

では、それを続けるとどうなるか。

　　時間だけが、消えます。

点は動きません。やった時間は返ってきません。

### 作業なのか、勉強なのか

ここで、言葉を1つ分けておきます。

```
　　作業　　終わらせることが目的。終われば、達成感がある
　　勉強　　できるようになることが目的。できなければ、意味がない
```

線を引く。まとめる。書き写す。どれも、必ず終わります。終わると、やった感じがします。

でも、終わったかどうかと、できるようになったかどうかは、別です。

5時間やってノートが10ページ進んだ、というのは、==作業が5時間ぶん終わった、ということです==。

やり方を知らないまま続けると、全部が作業になります。

学生生活は、そんなに長くありません。

## やることは、3つです

では、どうすればいいのか。

順番があります。

```
　　① 結果が出ない方法を、やめる
　　② 正しい方法を、知る
　　③ そのやり方を、徹底的にパクる
```

この順番です。逆から行くと、効きません。

---

バケツに、穴が空いているとします。水を入れても、下から漏れていきます。

あなたなら、どうしますか。

　　穴を、ふさぎますよね。

当たり前です。考えるまでもありません。

でも、勉強でこれをやっている人は、ほとんどいません。

点が出ないとき、ほとんどの人がやるのはこれです。もっと長い時間やる。もっと早起きする。もっと量を増やす。

全部、③です。いきなり③から入っています。

①が、穴をふさぐこと。②が、水の入れ方を覚えること。③が、そのうえでたくさん注ぐことです。

③の「徹底的に」は、量のことです。正しいやり方で、人より多くやる。ここは飛ばせません。

ただ、==①の前に③をやると、何時間やっても、たまりません==。

## ②　正しい方法は、1つしかありません

やめる話ばかりしてきました。

では、②です。何が正しいのか。

その前に、1つ見てください。結果を出している人を、何人も並べたときに見えてくるものです。

```
　　声に出して覚える人
　　白紙に書き出す人
　　人に説明する人
　　歩きながら、頭の中で言う人
```

やり方は、全員ばらばらです。

それなのに、==全員が、同じことをやっています==。

　　教材を閉じて、自分の中から出している。

最後の最後の枝葉は、違います。でも、幹は同じです。

　　==正しい勉強法のエッセンスは、やり方が違っても、必ず共通しています。==

僕は、誰か1人の勝ち方を書いているわけではありません。2000人以上を見てきて、全員に共通していたところだけを抜き出しました。

### 思い出すこと

幹の名前を書きます。

　　思い出すこと。

これだけです。英語では、アクティブリコールと呼ばれています。この本では「思い出して、出す」と書きます。

巻頭で、11個の数字を覚えてもらいました。

あのとき、あなたは何をしましたか。

本を伏せましたよね。

伏せたから、出せるかどうかが分かりました。伏せなかったら、永遠に「たぶん覚えた」のままでした。

あれが、思い出すということです。

### なぜ、それだけが効くのか

読んでいるとき、目は字を追っています。字は目から入ってくるので、わかった感じがします。

でも、そのあいだ、頭は何も探していません。

　　==探していないものは、あとで探せません。==

テストの日にやるのは、探すほうです。教科書は開けません。自分の中から、出すしかありません。

練習でやっていないことは、本番では起きません。

## ③　ただし、これが疲れます

正直に書きます。

　　==正しいやり方は、疲れます。==

教材を閉じて、「なんだっけ」と思い出す。理解したと思ったら、何も見ずに白紙で解いてみる。

どれも、頭を使わないとできません。やっている最中は、しんどいです。

それに比べて、線を引くのは楽です。読み返すのも楽です。まとめるのも、手は疲れますが、頭は楽です。

そして人は、楽なほうを選びます。

意志が弱いからではありません。人間だから、です。

### 楽で選んだものに、名前がつきます

ここが、この章でいちばん怖いところです。

楽だから、続いた。続いたから、残った。

そして残ったものを、人は何と呼ぶか。

　　「自分に合ったやり方」

これです。

だから、==「自分に合った勉強法」を探すのは、危険なんです==。探しているつもりで、楽なほうを選んでいるだけになります。しかも、選んだ本人には、そう見えません。

### 「やってみたんですけど、自分には合わなくて」

この言葉を、何百回も聞いてきました。

聞き返すと、だいたい、やっていません。3日でやめていたか、形だけ真似して中身をやっていなかったか、そのどちらかです。

合わなかったのではありません。==疲れたから、やめただけです==。

僕もそうでした。

高校3年のとき、毎日14時間やって、10校受けて10校落ちました。最低偏差値は42です。あのころのノートはきれいです。線が引いてあって、要点がまとまっていて、同じ単語が何十回も書いてあります。

全部、さっきの3つです。

自分に合っていました。やりやすくて、続けられて、終わったときに「やった」という感じがありました。

自己流です。いまから思えば、事故流でした。

量は、たぶん学年で一番やっていました。足りなかったのは、量ではありません。

---

念のため書いておくと、「自分に合った勉強法」は、かなり調べられています。そして、ほぼ全部、否定されています。

インディアナ大学で、学生400人以上にタイプ診断を受けてもらい、普段の勉強法と実際の成績を突き合わせた調査では、診断どおりに勉強していた少数の学生も、成績は変わりませんでした。タイプと成績のあいだにも、関係はありませんでした。

　　==好きかどうかと、身につくかどうかは、別です。==

だから、探すものを入れ替えてください。

```
　　×　自分に合った勉強法
　　○　点につながる、正しい勉強法
```

自分に合うかどうかは、あとで考えればいいです。先に、正しいかどうかです。

## この章のまとめ

```
　　① 結果が出ない方法を、やめる
　　② 正しい方法を、知る
　　③ そのやり方を、徹底的にパクる
```

これだけです。これさえできれば、結果は出ます。

## ここで本を閉じると、どうなるか

正直に書きます。

ここまで読んで、「思い出して、出す」が効くことは分かったと思います。

でも、明日の夜、机の前に座ったとき。やることは、まだ1つも決まっていません。

```
　　英単語は、どう思い出して、どう出すのか
　　数学の解き方は、どう出すのか
　　授業中は、何をすればいいのか
　　間違えた問題は、どう直すのか
　　計画が崩れた日は、どうするのか
```

ここが分からないまま始めると、たぶん3日でやめます。疲れるからです。

### 間違った姿勢は、1日では分かりません

姿勢の話をします。

背中を丸めて座っても、その日は何も起きません。痛くもありません。

でも、毎日続けると、体は少しずつ歪みます。

そして怖いのは、==歪んだ姿勢のほうが、楽になることです==。正しい姿勢に戻すと、逆にきつい。

勉強も、まったく同じです。

線を引いた1日は、何も起きません。でも3年続けると、それがあなたの「やり方」になります。あとから直そうとすると、きつくなります。

### 我慢した時間ごと、なくなります

もう1つ。こっちのほうが、大きいかもしれません。

遊びを我慢して、机に向かった時間。部活で疲れているのに、眠いのに、開いた教科書。

やり方が間違っていると、==その我慢ごと、なかったことになります==。

点が動かないからです。

やらなかった人と、同じ場所に立つことになります。

### あなたは、変わりたい人です

最後に、1つだけ。

勉強法の本を手に取る人は、そんなに多くありません。そして、ここまで読む人は、もっと少ない。

本気で変わりたいと思っていなければ、ここまで来ていません。

　　==だから、原理を知るだけで、終わらせたくないんです。==

## だから、51個あります

この本の51個は、全部こうなっています。

```
　　×　やってはいけないこと
　　○　かわりに、何をどうやるか
```

そして○のほうは、「思い出しましょう」では終わりません。

何を閉じて、何秒待って、どう出して、出てこなかったらどうするか。==手の動かし方まで書きます==。

そこまで書かないと、知っても動けないからです。

世の中の勉強法の本が、読んだときは納得できるのに、3か月後に点が変わっていない理由も、たぶんここです。
