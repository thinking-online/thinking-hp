# 序章　頭のいい人が持っている、6つの武器

さっき、数字で1回やりました。
今度は、勉強でやります。

鉛筆を持ってください。3分で終わります。

---

## 1問

次の日本語を、英語にしてください。
下の7つの語を、全部使います。

```
　　　彼は私に、その本を読むように言いました。


　　　( me ／ the ／ he ／ read ／ to ／ told ／ book )
```

30秒。

できましたか。
できた人は、横に○をつけてください。

では、答えを見ます。

```
　　　He told me to read the book.

　　　told me to 〜　で「私に〜するように言った」。
　　　tell のうしろは「だれに」「何を」の順。
　　　「〜するように」は、to のあとに動詞をそのまま置く。
```

読みましたか。
たぶん「なるほど」と思ったはずです。

ここが、勉強でいちばん危ないところです。

## もう1問。さっきと同じ問題

本を閉じてください。

閉じたまま、もう一度、同じ文を英語にしてください。
今度は、語のならびはありません。日本語だけです。

```
　　　彼は私に、その本を読むように言いました。
```

書けましたか。

1回目はできて、2回目で止まった人。
to が抜けた人。said を使った人。read を reading にした人。

その人が、この本の読者です。

1回目と2回目で、何が変わったか。

あなたの頭は、1分前と何も変わっていません。
変わったのは、選ぶ語が目の前にあるかないか。それだけです。

そして、テストは2回目のほうです。

テストの日、問題用紙の横に「 ( me ／ the ／ he ／ read ／ to ／ told ／ book ) 」
は置いてありません。

1回目を「できた」と数えて、次の問題に進む。

これが、頭のいい人が絶対にやらないことの、1つ目です。

## いま、2つのことが起きました

```
　　解説を読んで「なるほど」と思った

　　　　　　　　↓

　　閉じたら、出てこなかった
```

入れたつもりで、入っていなかった。
出したつもりで、出していなかった。

この2つに、名前をつけます。

```
　入れる力　　入れるだけでは、入らない
　　　　　　　→　入れたら、すぐ出す

　　　　　　　「いま、閉じて出せる？」


　出す力　　　テストと違う練習は、練習じゃない
　　　　　　　→　テストと同じ形で、やる

　　　　　　　「それ、テストでもできる？」
```

この2つが、この本でいちばん使う武器です。
62項目のうち18が、この2つで片づきます。

そして、この2つは、やることが同じです。

閉じること。

解説を閉じる。教科書を閉じる。ノートを閉じる。
閉じてから、出す。それだけです。

「わかった」は、閉じるまでは、ただの感想です。

## 残りの4つも、さっきの1問の中にいます

### 選ぶ力

テスト範囲が30ページあって、2週間しかない。
全部やろうとすると、1つも終わりません。

さっきの1問は、テストに出ます。
tell＋人＋to は、中2の範囲で必ず出ます。
だから、やる価値がありました。

```
　選ぶ力　　　全部やろうとすると、1つも終わらない
　　　　　　　→　捨ててから、始める

　　　　　　　「これ、出るの？」
```

### つなげる力

さっき told me to を覚えました。

次の授業で、ask me to が出てきます。
そのあと want me to も出てきます。

これを3つとも別のものとして覚えると、3つとも出てこなくなります。
同じ形だと気づいた人は、1つ覚えれば3つ出てきます。

```
　つなげる力　1個ずつ覚えると、1個も出てこない
　　　　　　　→　前にやったものに、くっつける

　　　　　　　「これ、前にどこで見た？」
```

### なおす力

2回目で、to が抜けた人。

直すのは、この文ではありません。
「to を落とす」というくせです。

この文だけ直すと、来週 ask me to でまた落とします。

```
　なおす力　　直すのは、問題じゃない。場所
　　　　　　　→　どこで止まったかを、探す

　　　　　　　「どこで、止まった？」
```

### 続ける力

ここまで、3分でした。

問題は、明日も3分やるかどうかです。
やる気があるかどうかではありません。
明日の朝、最初にやる1個が決まっているかどうかです。

```
　続ける力　　やる気は、あてにならない
　　　　　　　→　やる気がなくても始まる形にする

　　　　　　　「次の1個目は？」
```

## 手持ち、6本

```
　　　選ぶ力　　　　「これ、出るの？」

　　　入れる力　　　「いま、閉じて出せる？」

　　　つなげる力　　「これ、前にどこで見た？」

　　　出す力　　　　「それ、テストでもできる？」

　　　なおす力　　　「どこで、止まった？」

　　　続ける力　　　「次の1個目は？」
```

順番はありません。
1番から6番まで通す必要も、ありません。

さっきの1問で使ったのは、入れる力と出す力の2つだけです。
あとの4つは、出番が来たときに抜きます。

1問につき、だいたい2つ。それだけです。

迷ったら、入れる力と出す力。
つまり、閉じること。

## この本の読み方

最初から順に読まなくていいです。

第1章から第7章までの62項目は、辞書です。
困っている場面の章を開いて、その項目だけ読んでください。

```
　　計画どおりにいかない　　　　　　第1章
　　授業は受けているんですけど　　　第2章
　　覚えても、すぐ忘れる　　　　　　第3章
　　解説を読んでも、できない　　　　第4章
　　同じミスをくり返す　　　　　　　第5章
　　集中が続かない　　　　　　　　　第6章
　　モチベが出ない　　　　　　　　　第7章
　　本番で力が出ない　　　　　　　　終章
```

巻末に、悩み別の索引をつけました。
「覚えてもすぐ忘れる」なら、20番と24番と27番です。

62項目には、それぞれ右肩に武器の名前が書いてあります。
読み進めるうちに、同じ武器が何度も出てきます。
それは、同じ手が何度も効くという意味です。
