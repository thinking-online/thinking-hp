# 序章　頭のいい人が持っている、6つの武器

さっき、数字で1回やりました。
今度は、勉強でやります。

鉛筆を持ってください。3分で終わります。

---

## 1問

次の問題を解いてください。やり方も、下に書いてあります。

```
　　　1 から 100 までの数を、ぜんぶ足すと、いくつになりますか。


　　　やり方

　　　　　1 と 100 で　　101
　　　　　2 と　99 で　　101
　　　　　3 と　98 で　　101
　　　　　　　：
　　　　　組は、ぜんぶで 50 組

　　　　　101 × 50 ＝ 5050
```

読みましたか。

難しくなかったはずです。
足し算とかけ算しか使っていません。

たぶん「なるほど」と思ったはずです。

ここが、勉強でいちばん危ないところです。

---

## もう1問。数だけ、変えます

本を閉じてください。

閉じたまま、次の問題を解いてください。

```
　　　1 から 60 までの数を、ぜんぶ足すと、いくつになりますか。
```

30秒。

出ましたか。

1から順に、1、3、6、10……と足していった人。
101 を使ってしまった人。
50組のままにしてしまった人。
何をするんだったか、出てこなかった人。

その人が、この本の読者です。

（答えは 61 × 30 で 1830 です）

1問目と2問目で、何が変わったか。

あなたの頭は、1分前と何も変わっていません。
変わったのは、やり方が目の前にあるかないか。それだけです。

そして、テストは2問目のほうです。

テストの日、問題用紙の横に「やり方」は書いてありません。

1問目を「できた」と数えて、次の問題に進む。

これが、頭のいい人が絶対にやらないことの、1つ目です。

---

## いま、2つのことが起きました

```
　　解説を読んで「なるほど」と思った

　　　　　　　　↓

　　閉じたら、出てこなかった
```

入れたつもりで、入っていなかった。
出したつもりで、出していなかった。

この2つに、名前をつけます。

```
　入れる力　　入れるだけでは、入らない
　　　　　　　→　入れたら、すぐ出す

　　　　　　　「いま、閉じて出せる？」


　出す力　　　テストと違う練習は、練習じゃない
　　　　　　　→　テストと同じ形で、やる

　　　　　　　「それ、テストでもできる？」
```

この2つが、この本でいちばん使う武器です。
62項目のうち18が、この2つで片づきます。

そして、この2つは、やることが同じです。

閉じること。

解説を閉じる。教科書を閉じる。ノートを閉じる。
閉じてから、出す。それだけです。

「わかった」は、閉じるまでは、ただの感想です。

---

## 残りの4つも、さっきの1問の中にいます

### 選ぶ力

2問目を、1、2、3……と60回足した人がいます。

答えは合っています。でも、2分かかりました。
組にした人は、61×30 の1回で終わっています。

59回の足し算を捨てた人が、速い。

テスト範囲が30ページあって、2週間しかないときも、同じです。
全部やろうとすると、1つも終わりません。

```
　選ぶ力　　　全部やろうとすると、1つも終わらない
　　　　　　　→　捨ててから、始める

　　　　　　　「これ、出るの？」
```

### つなげる力

いま、1から100までと、1から60までをやりました。

次に、1から200までが来ます。
そのあと、2＋4＋6＋……＋100 が来ます。

これを3つとも別のものとして覚えると、3つとも出てきません。
同じ形だと気づいた人は、1つ覚えれば3つ出てきます。

```
　つなげる力　1個ずつ覚えると、1個も出てこない
　　　　　　　→　前にやったものに、くっつける

　　　　　　　「これ、前にどこで見た？」
```

### なおす力

2問目で、101 を使ってしまった人。

直すのは、この問題の答えではありません。
「組の相手は、いちばん後ろの数から取る」というところで止まっています。

ここを直さないと、1から200までで、また 101 を使います。

```
　なおす力　　直すのは、問題じゃない。場所
　　　　　　　→　どこで止まったかを、探す

　　　　　　　「どこで、止まった？」
```

### 続ける力

ここまで、3分でした。

問題は、明日も3分やるかどうかです。
やる気があるかどうかではありません。
明日の朝、最初にやる1個が決まっているかどうかです。

```
　続ける力　　やる気は、あてにならない
　　　　　　　→　やる気がなくても始まる形にする

　　　　　　　「次の1個目は？」
```

## 手持ち、6本

```
　　　選ぶ力　　　　「これ、出るの？」

　　　入れる力　　　「いま、閉じて出せる？」

　　　つなげる力　　「これ、前にどこで見た？」

　　　出す力　　　　「それ、テストでもできる？」

　　　なおす力　　　「どこで、止まった？」

　　　続ける力　　　「次の1個目は？」
```

順番はありません。
1番から6番まで通す必要も、ありません。

さっきの2問で使ったのは、入れる力と出す力の2つだけです。
あとの4つは、出番が来たときに抜きます。

1問につき、だいたい2つ。それだけです。

迷ったら、入れる力と出す力。
つまり、閉じること。

## 6つを持った1週間は、こう見えます

週6で部活。帰宅8時。定期テストまで2週間。中2。

```
　　　　朝 7:00　　　　　　　夜 20:30 から 30分

　月　　単語20　閉じて出す　　英語ワーク。配点の大きい2ページ
　火　　単語20　閉じて出す　　数学。間違えた6問を、原因で3つにまとめる
　水　　単語20　閉じて出す　　――
　木　　単語20　閉じて出す　　理科。1単元を、何も見ないで書き出す
　金　　単語20　閉じて出す　　社会。教科書を閉じて、流れを口で言う
　土　　――　　　　　　　　　9:00-11:00　ワーク2周目。×だけ
　日　　――　　　　　　　　　9:00-10:00　1週間の×を、原因で3つにまとめる
```

1日30分です。2時間ではありません。
週6で部活がある人に、2時間は書けません。

水曜が空いています。試合前で、何もできませんでした。

それでも、この計画は崩れていません。
崩れる日を、最初から1日入れてあるからです。

そして水曜も、朝の単語20だけはやりました。
朝の20個は、やる気の話ではありません。顔を洗うのと同じ場所に置いてあります。

この1週間の作り方は、第1章の09で全部書きます。

## この本の読み方

最初から順に読まなくていいです。

第1章から第7章までの62項目は、辞書です。
困っている場面の章を開いて、その項目だけ読んでください。

```
　　計画どおりにいかない　　　　　　第1章
　　授業は受けているんですけど　　　第2章
　　覚えても、すぐ忘れる　　　　　　第3章
　　解説を読んでも、できない　　　　第4章
　　同じミスをくり返す　　　　　　　第5章
　　集中が続かない　　　　　　　　　第6章
　　モチベが出ない　　　　　　　　　第7章
　　本番で力が出ない　　　　　　　　終章
```

巻末に、悩み別の索引をつけました。
「覚えてもすぐ忘れる」なら、20番と24番と27番です。

62項目には、それぞれ右肩に武器の名前が書いてあります。
読み進めるうちに、同じ武器が何度も出てきます。
それは、同じ手が何度も効くという意味です。
