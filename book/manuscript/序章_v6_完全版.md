# 序章　「自分に合った勉強法」を、探すのをやめる

いま、あなたがやっている勉強のやり方。

それ、誰から教わりましたか。

---

先生でしょうか。親でしょうか。塾でしょうか。
それとも、YouTubeでしょうか。

「誰からも教わっていない」という人が、いちばん多いと思います。

では、いつ決めましたか。

中1の最初。小学校のとき。
たぶん、そのあたりです。

つまりあなたは、12歳か13歳のころの自分が決めたやり方で、
いまも勉強していることになります。

---

もう1つ聞きます。

12歳のあなたは、何と何を比べて、それを選びましたか。

比べていませんよね。

比べようがなかったんです。1つしか知らなかったから。

## 人は、やったことのないものを選べません

当たり前の話に聞こえますが、ここが全部の入り口です。

食べたことのない料理を「好きな料理」に選ぶ人はいません。
やったことのない勉強法を「自分に合ったやり方」に選ぶ人も、いません。

だから、あなたの「自分に合ったやり方」は、選んだものではありません。

最初にやったものが、そのまま残っただけです。

---

試しに、聞きます。

次の4つのうち、やったことがあるものに、印をつけてください。

```
　　□　教科書の大事なところに、線を引く
　　□　わからないところを、何度も読み返す
　　□　ノートに、要点をまとめる
　　□　単語を、何回も書いて覚える
```

何個つきましたか。

3つか4つ、という人が多いはずです。

## 2000人が、全員同じでした

これはあなただけの話ではありません。

僕が見てきた2000人以上の中高生に、同じことを聞いてきました。
ほぼ全員が、この4つでした。

おかしいと思いませんか。

2000人がばらばらに「自分に合ったやり方」を探して、
全員が同じ4つにたどり着く。

探して選んだなら、ばらけるはずです。
ばらけないということは、誰も選んでいないということです。

## この4つは、まじめな人の行動です

先に言っておきます。

この4つをやっている人を、責めるつもりはありません。

サボっている人は、1つもやらないからです。

```
　　線を引くには、教科書を開かないといけない
　　読み返すには、1回目を読んでいないといけない
　　まとめるには、時間がかかる
　　何回も書くのは、手が疲れる
```

4つとも、やろうと思わないとできません。
あなたは、やろうと思った人です。

## でも、4つに共通していることが、もう1つあります

この4つをやっているあいだ、教科書かノートが、開いています。

```
　　線を引く　　　　→　教科書を見ながら
　　読み返す　　　　→　教科書を見ながら
　　まとめる　　　　→　教科書を見ながら
　　書いて覚える　　→　単語帳を見ながら
```

4つとも、見ながらやる作業です。

1回も、閉じていません。

---

ここで、巻頭の11個の数字を思い出してください。

あのとき、あなたは何をしましたか。

本を伏せましたよね。

伏せたから、出せるかどうかが分かりました。
伏せなかったら、永遠に「たぶん覚えた」のままでした。

## では、あなたはこの4つを、何で選んだのか

効果で選んだわけでは、ありません。
効果は、測っていないからです。

測ったことがあるのは、こっちです。

　　やりやすいかどうか。

---

線を引くのは、簡単です。
読み返すのは、知っているものを読むので、楽です。
まとめるのは、手が動いている実感があります。
書くのは、何も考えなくてもできます。

4つとも、やりやすい。
やりやすいから、続いた。続いたから、残った。

そして残ったものを、人は「自分に合ったやり方」と呼びます。

## やりやすいというのは、頭が楽をしているということです

ここが、いちばん大事なところです。

勉強は、頭に負荷がかかっているときにしか、残りません。

```
　　やりやすい　　→　頭が楽をしている　　→　残らない
　　やりにくい　　→　頭が働いている　　　→　残る
```

つまり、やりやすさで選び続けると、
残らないやり方だけが、手元に積み上がっていきます。

2000人全員が同じ4つだったのは、偶然ではありません。
全員が、同じ基準で選んだからです。

## 選ぶ基準を、1つだけ入れ替えてください

やめてほしいのは、4つの行動そのものではありません。

選び方です。

```
　　×　やりやすかったか
　　○　出せたか
```

これだけです。

今日の勉強の最後に、教科書を閉じて、今日やったことを3つ書いてみてください。
3つ書けたやり方は、合っています。
1つも書けなかったやり方は、どれだけやりやすくても、合っていません。

## ただし、探していいものもあります

「自分に合った勉強法を探すな」と言いました。
全部を探すな、という意味ではありません。

```
　　探していい　　　　どうやって、出すか
　　探してはいけない　出すかどうか
```

出し方は、人によって変わります。

声に出すのが合う人、書くのが合う人、
誰かに説明するのが合う人、歩きながらのほうが出る人。

そこは、自分で探してください。試す価値があります。

でも「出す」こと自体は、誰にとっても変わりません。
そこを探し始めると、永遠に始まりません。

## そして、探している間は、やらなくていいことになります

これが、いちばん怖いところです。

「自分に合ったやり方が分かってから、本気を出そう」
「まず、どの参考書が自分に合うか調べよう」

探しているあいだは、勉強していません。
それなのに、やっている感じがします。

探すのは、勉強の中でいちばん楽な作業だからです。

## 僕は、「自分に合ったやり方」を完璧に持っていました

高校3年のとき、僕のやり方は完成していました。

毎日、同じ時間に起きて、同じ順番で、同じやり方で進める。
崩れた日は、1日もありません。

自分に合っていたからです。
やりやすくて、続けられて、終わったときに「やった」という感じがありました。

結果は、最低偏差値42。10校受けて、10校落ちました。

合っていました。点が出なかっただけです。

---

あのころのノートを、いまでも持っています。

きれいです。線が引いてあって、要点がまとまっていて、
同じ単語が何十回も書いてあります。

全部、さっきの4つです。

14時間やった過程に、意味はありませんでした。10校落ちたからです。

だから僕は、過程に意味があるとは言いません。
ただ、努力が無駄だったという話でもありません。

量は、たぶん学年で一番やっていました。
足りなかったのは、量ではありません。

方向が違っただけです。

そして方向は、今日変えられます。

## この章のまとめ

```
　　やめるものは、4つです。

　　　線を引く　／　読み返す　／　まとめる　／　見ながら何回も書く

　　ただし、本当にやめてほしいのは、4つの行動ではありません。
　　やりやすさで選ぶ、という選び方のほうです。
```

---

ここから先は、頭のいい人が絶対にやらないことを、75個並べます。

最初の8個は、全部の土台になるものです。
残りの67個は、場面ごとの話です。

まず、土台から。
