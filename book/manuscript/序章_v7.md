# 00　「自分に合った勉強法」を、探す

　　×「自分に合ったやり方を、見つけたい」
　　○「やりやすさで選ぶのを、やめる」

---

いま、あなたがやっている勉強のやり方。

それ、どこで覚えましたか。

---

部活の先輩に聞いた。
塾で、そう言われた。
友達がやっていた。
誰に教わったわけでもなく、なんとなく始めて、そのまま続いている。

どれも、ありえます。
人によって、ちがうと思います。

では、もう1つ聞きます。

---

　　そのやり方が、点になっているかどうか。
　　これまでに1回でも、確かめたことがありますか。

---

ここは、ほぼ全員が同じ答えになります。

ない、です。

## 確かめる場面が、どこにもありませんでした

これは、あなたが悪いという話ではありません。

テストが返ってきます。点が書いてあります。

でも、そこに書いてあるのは、結果だけです。

　　どのやり方が効いて、どのやり方が効かなかったのか。

これは、どこにも書いてありません。
先生も、親も、教えてくれません。

点が下がったときに言われるのは、だいたい「もっとやれ」です。
やり方を見直せ、とは言われません。

だから、確かめないまま、今日まで来ました。

いまあなたがやっているのは、選んだやり方ではありません。

　　誰にも止められなかった、やり方です。

## 選んだつもりでも、選べていません

自分で選んだ、と思っている人もいると思います。

でも、人は、やったことのないものを選べません。
食べたことのない料理を「好きな料理」に選ぶ人は、いません。

試しに、聞きます。

次の4つのうち、やったことがあるものに、印をつけてください。

```
　　□　教科書の大事なところに、線を引く
　　□　わからないところを、何度も読み返す
　　□　ノートに、要点をまとめる
　　□　単語を、何回も書いて覚える
```

何個つきましたか。

3つか4つ、という人が多いはずです。

たぶん、あなたが知っている勉強のやり方は、これでほぼ全部です。
その中から選んだのなら、それは選んだのではありません。
これしか、なかったということです。

## 効果には、順番がついています

ここで、1つ先に言っておきます。

勉強のやり方は、何十種類もあります。
そのどれが効くのかは、調べられていて、効果の高い順に並べた一覧があります。

いちばん上のグループに入ったのは、2つだけでした。

```
　　思い出すこと
　　間隔をあけること
```

しかも、この2つはセットです。

　　間隔をあけて、思い出す。

これだけです。
これが、いまのところ分かっている、いちばん強いやり方です。

「思い出す」というのは、教科書を閉じて、自分の中から出すことです。
英語では、アクティブリコールと呼ばれています。

この本では、「閉じて、出す」と書きます。

---

では、さっきの4つを、同じ一覧の中で探してみます。

```
　　線を引く　　　　　　→　いちばん下のグループ
　　読み返す　　　　　　→　いちばん下のグループ
　　まとめる　　　　　　→　いちばん下のグループ
　　何回も書いて覚える　→　見ながらやるなら、いちばん下
```

いちばん上は、閉じて、出す。

あなたがチェックした3つは、いちばん下。

## なぜ、4つとも下なのか

もう一度、いちばん上を見ます。

　　間隔をあけて、思い出す。

さっきの4つに、これが入っているかどうかを見てください。

```
　　線を引く　　　　　　→　教科書を見ながら
　　読み返す　　　　　　→　教科書を見ながら
　　まとめる　　　　　　→　教科書を見ながら
　　何回も書いて覚える　→　単語帳を見ながら
```

4つとも、見ながらやっています。

思い出す場面が、1回もありません。

---

ここで、巻頭の11個の数字を思い出してください。

あのとき、あなたは何をしましたか。

本を伏せましたよね。

伏せたから、出せるかどうかが分かりました。
伏せなかったら、永遠に「たぶん覚えた」のままでした。

---

さっきの4つは、1回も伏せません。

だから、こう言えます。

　　効果が低いやり方を、やっているのではありません。
　　いちばん効くことを、1回もやっていないだけです。

## 2000人が、全員同じでした

これは、あなただけの話ではありません。

僕が見てきた2000人以上の中高生に、同じことを聞いてきました。

ほぼ全員が、この4つでした。

学校がちがっても、学年がちがっても、成績がちがっても、同じでした。

```
　　やっている人が、いちばん多い。
　　効果は、いちばん下。
```

2000人が、同じところで止まっている。

ここまで同じだと、もう個人の問題ではありません。
誰も確かめなかった、というだけです。

## この4つは、まじめな人の行動です

先に言っておきます。

この4つをやっている人を、責めるつもりはありません。

サボっている人は、1つもやらないからです。

```
　　線を引くには、教科書を開かないといけない
　　読み返すには、1回目を読んでいないといけない
　　まとめるには、時間がかかる
　　何回も書くのは、手が疲れる
```

4つとも、やろうと思わないとできません。
あなたは、やろうと思った人です。

## 「要領がいい」と言われる人は、何がちがうのか

クラスに、1人か2人います。

同じ授業を受けて、同じくらいしかやっていないのに、点が取れる人。
あの子はセンスがいい、要領がいい、と言われる人です。

何がちがうのか。

だいたい、2つのどちらかです。

```
　　1　たまたま、上のほうのやり方で始めた
　　2　誰かに教わって、それを続けている
```

1のほうが、多いです。

```
　　たまたま、問題集を閉じてから答え合わせをするくせがついた
　　たまたま、人に説明するのが好きだった
　　たまたま、前に習ったことと結びつける考え方をしていた
```

本人は、自分が何をしているのか分かっていません。

巻頭で、クラスで一番点を取る子に聞いてみてください、と書きました。
返ってくるのは「普通にやってるだけだよ」です。

あれは、ごまかしているのではありません。
本当に、分かっていないんです。

自分では、普通にやっているつもりだからです。

だから、センスに見えます。

でも、センスではありません。
やっていることが、たまたま上のほうだっただけです。

そして、やっていることなら、あとから真似できます。

## なぜ、誰も止めてくれなかったのか

昔から、こういう言葉があります。

　　勝ちに不思議の勝ちあり、負けに不思議の負けなし。

勝つときには、運やタイミングが混じることがある。
だから、なぜ勝てたのか、本人にも分からないことがある。

でも、負けるときには、必ず原因がある。
たまたま負けた、ということは起きない。

だったら、その原因を見つけて、次は同じことをしなければいい。

そういう意味です。

---

勉強も、同じです。

あなたのまわりには、勝った人がいます。

```
　　学校の先生
　　合格した部活の先輩
　　昔、受験をした親
```

みんな、自分のやり方で勝っています。
だから、そのやり方を教えてくれます。全部、善意です。

ただ、その人たちは、勝ったんです。

なぜ勝てたのかを、確かめたわけではありません。

### 勝った理由は、1つではありません

誰かが合格したとき、そこには色々なものが混ざっています。

```
　　その年の倍率
　　たまたま出た問題
　　家の環境
　　もともと得意だった教科
　　そして、やり方
```

どれが効いたのかは、本人にも分かりません。

それでも人は、自分が勝ったときのやり方を、全部正しかったと思います。
誰でもそうです。悪いことでもありません。

でも、効いていなかったものも混じったまま、次の人に渡ります。
渡された人がまた勝つと、同じまま、その次へ。

誰も確かめないまま、やり方だけが流れていきます。

### だから、まず「負けないこと」から始めます

勝ち方には、運が混じります。真似しても、同じにはなりません。

でも、負け方には、運が混じりません。

点が出ないやり方は、誰がやっても点が出ません。
倍率にも、環境にも、関係ありません。

```
　　勝ち方　　運が混じる　　　　本人にも分からない　　真似しにくい
　　負け方　　運が混じらない　　原因がはっきりする　　先に、消せる
```

だから、この本はやらないことで書いてあります。

正しいやり方を1個増やすより、
点にならないやり方を1個消すほうが、確実だからです。

## では、あなたはこの4つを、何で選んだのか

効果は、測れませんでした。
測れないものは、選ぶ基準になりません。

かわりに、全員が測れたものが、1つだけあります。

　　やりやすいかどうか。

---

線を引くのは、簡単です。
読み返すのは、知っているものを読むので、楽です。
まとめるのは、手が動いている実感があります。
書くのは、何も考えなくてもできます。

4つとも、やりやすい。
やりやすいから、続いた。続いたから、残った。

そして残ったものを、人は「自分に合ったやり方」と呼びます。

## やりやすいというのは、頭が楽をしているということです

勉強は、頭に負荷がかかっているときにしか、残りません。

```
　　やりやすい　　→　頭が楽をしている　　→　残らない
　　やりにくい　　→　頭が働いている　　　→　残る
```

ここに、この本でいちばん大事な分かれ目があります。

```
　　作業　　終わらせることが目的。終われば、達成感がある
　　勉強　　できるようになることが目的。できなければ、意味がない
```

線を引く。まとめる。書き写す。
どれも、必ず終わります。終わると、やった感じがします。

でも、終わったかどうかと、できるようになったかどうかは、別です。

5時間やってノートが10ページ進んだ、というのは、
作業が5時間ぶん終わった、ということです。

## 選ぶ基準を、1つだけ入れ替えてください

やめてほしいのは、4つの行動そのものではありません。

選び方です。

```
　　×　やりやすかったか
　　○　出せたか
```

これだけです。

今日の勉強の最後に、教科書を閉じて、今日やったことを3つ書いてみてください。

3つ書けたやり方は、勉強です。
1つも書けなかったやり方は、どれだけやりやすくても、作業です。

## 逃げ道が、2つあります

この基準を入れると、2つの言い訳が使えなくなります。
先に、両方ふさいでおきます。

### 1つ目　「自分に合ったやり方が分かってから、本気を出す」

探しているあいだは、勉強していません。
それなのに、やっている感じがします。

探すのは、勉強の中でいちばん楽な作業だからです。

参考書を比べる。やり方を調べる。計画を立て直す。
どれも1時間やれば、充実します。1問も解いていないのに。

### 2つ目　「それ、やってみたんですけど、自分には合わなくて」

この言葉を、何百回も聞いてきました。

聞き返すと、だいたい2つのどちらかです。

```
　　3日でやめていた
　　やりやすくなかった
```

3日は、合うか合わないかが分かる長さではありません。
そして、やりやすくないのは、当たり前です。

頭に負荷がかかるやり方は、やりにくいからです。
やりにくいから効くのに、やりにくいからやめてしまう。

合わなかったのではありません。
合わないと決める基準が、やりやすさだっただけです。

## では、何なら選んでいいのか

ここまで、選ぶな、探すな、と書いてきました。

選べるものも、ちゃんとあります。
場所がちがうだけです。

```
　　変えられない　　閉じて、出す
　　変えていい　　　どうやって、出すか
```

「閉じて、出す」のところは、誰がやっても同じです。
ここに、自分らしさはありません。

でも、出し方は、人によってぜんぜんちがいます。

```
　　声に出す
　　白紙に書く
　　誰かに説明する
　　歩きながら、頭の中で言ってみる
```

どれが続くかは、やってみないと分かりません。
ここは、試してください。試す価値があります。

やってはいけないのは、この2つを逆にすることです。

```
　　「閉じるのは、自分には合わない」　　　←　ここは、変えられません
　　「書くのが自分のやり方だから」　　　　←　ここは、変えていいです
```

ほとんどの人が、これを反対にやっています。

変えられないところを変えようとして、
変えていいところを、最初に決めつけている。

## 僕は、「自分に合ったやり方」を完璧に持っていました

高校3年のとき、僕のやり方は完成していました。

毎日、同じ時間に起きて、同じ順番で、同じやり方で進める。
崩れた日は、1日もありません。

自分に合っていたからです。
やりやすくて、続けられて、終わったときに「やった」という感じがありました。

結果は、最低偏差値42。10校受けて、10校落ちました。

合っていました。点が出なかっただけです。

---

あのころのノートを、いまでも持っています。

きれいです。線が引いてあって、要点がまとまっていて、
同じ単語が何十回も書いてあります。

全部、さっきの4つです。

毎日14時間、作業をしていました。

僕は、自己流でした。いまから思えば、事故流です。

---

量は、たぶん学年で一番やっていました。
足りなかったのは、量ではありません。

方向が違っただけです。

そして方向は、今日変えられます。

## 変えるには、順番があります

巻頭に、答えを出さずに置いた質問が1つあります。

　　では、どれを捨てますか？

1日に5つ覚えて、1つにつき1日後・1週間後・1か月後に復習する。
やってみると、1週間で1日20個になる。5教科なら、100個です。

全部はできません。どれかを捨てるしかない。
でも、どれを捨てるのかは、そこでは書きませんでした。

答えは、順番です。

```
　　① やってはいけないことを、まずやめる
　　② 結果を出している人の、やり方を知る
　　③ その正しいやり方で、量をやる
```

この順番です。逆から行くと、効きません。

点が出ないとき、ほとんどの人がやるのは、これです。

```
　　もっと長い時間やる
　　もっと早起きする
　　もっと量を増やす
```

全部、③です。いきなり③から入っています。

量は、要ります。③は飛ばせません。
ただ、①の前に③をやると、何時間やっても、たまりません。

高校3年の僕が、それでした。

そして、①をやると、100個は100個のままではなくなります。

```
　　①　やらなくていいものが消える　　→　時間が空く
　　②　残ったものの中身が変わる　　　→　同じ時間で、入る量が増える
　　③　空いた時間に、量を入れる
```

捨てるものは、自分で選ぶのではありません。
順番どおりにやると、勝手に決まります。

## 最後に、1つだけ

勉強が好きで好きでたまらない、という人は、多くないと思います。

僕も、好きではありませんでした。

それでも、あなたはこの本を開いています。
やらなきゃいけない、と思っているということです。

もう、頑張っているんです。

だから、その時間を作業で終わらせてほしくない。

同じ5時間なら、点になるほうの5時間にしてほしい。
それだけです。

```
　　ただし、本当にやめてほしいのは、4つの行動ではありません。
　　やりやすさで選ぶ、という選び方のほうです。

　　　×　やりやすかったか
　　　○　出せたか
```
