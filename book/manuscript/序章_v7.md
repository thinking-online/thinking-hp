# 00　「自分に合った勉強法」を、探す

　　×「自分に合ったやり方を、見つけたい」
　　○「やりやすさで選ぶのを、やめる」

---

いま、あなたがやっている勉強のやり方。

それ、誰から教わりましたか。

---

先生でしょうか。親でしょうか。塾でしょうか。
それとも、YouTubeでしょうか。

「誰からも教わっていない」という人が、いちばん多いと思います。

では、いつ決めましたか。

中1の最初。小学校のとき。
たぶん、そのあたりです。

つまりあなたは、12歳か13歳のころの自分が決めたやり方で、
いまも勉強していることになります。

---

もう1つ聞きます。

12歳のあなたは、何と何を比べて、それを選びましたか。

比べていませんよね。

比べようがなかったんです。1つしか知らなかったから。

## 人は、やったことのないものを選べません

当たり前の話に聞こえますが、ここが全部の入り口です。

食べたことのない料理を「好きな料理」に選ぶ人はいません。
やったことのない勉強法を「自分に合ったやり方」に選ぶ人も、いません。

だから、あなたの「自分に合ったやり方」は、選んだものではありません。

最初にやったものが、そのまま残っただけです。

---

試しに、聞きます。

次の4つのうち、やったことがあるものに、印をつけてください。

```
　　□　教科書の大事なところに、線を引く
　　□　わからないところを、何度も読み返す
　　□　ノートに、要点をまとめる
　　□　単語を、何回も書いて覚える
```

何個つきましたか。

3つか4つ、という人が多いはずです。

## 2000人が、全員同じでした

これはあなただけの話ではありません。

僕が見てきた2000人以上の中高生に、同じことを聞いてきました。
ほぼ全員が、この4つでした。

おかしいと思いませんか。

2000人がばらばらに「自分に合ったやり方」を探して、
全員が同じ4つにたどり着く。

探して選んだなら、ばらけるはずです。
ばらけないということは、誰も選んでいないということです。

---

もう1つ、言っておきます。

勉強のやり方には、効果を調べて順番をつけたものがあります。
その一覧を見ると、さっきの4つのうち3つが、いちばん下のグループに入っています。

```
　　やっている人が、いちばん多い。
　　効果は、いちばん低い。
```

なぜそうなるのかは、このあと書きます。

## この4つは、まじめな人の行動です

先に言っておきます。

この4つをやっている人を、責めるつもりはありません。

サボっている人は、1つもやらないからです。

```
　　線を引くには、教科書を開かないといけない
　　読み返すには、1回目を読んでいないといけない
　　まとめるには、時間がかかる
　　何回も書くのは、手が疲れる
```

4つとも、やろうと思わないとできません。
あなたは、やろうと思った人です。

## なぜ、誰も止めてくれなかったのか

昔から、こういう言葉があります。

　　勝ちに不思議の勝ちあり、負けに不思議の負けなし。

勝ったときは、なぜ勝てたのか、よく分からないことがある。
でも、負けたときには、必ず理由がある。そういう意味です。

勉強も、同じです。

あなたのまわりには、勝った人がいます。

```
　　学校の先生
　　合格した部活の先輩
　　昔、受験をした親
```

みんな、自分のやり方で勝っています。
だから、そのやり方を教えてくれます。全部、善意です。

ただ、ここに見えにくい問題が1つあります。

　　勝った人は、勝ち方のプロです。
　　でも、学び方のプロとは、限りません。

### 勝った理由は、1つではありません

誰かが合格したとき、そこには色々なものが混ざっています。

```
　　その年の倍率
　　たまたま出た問題
　　家の環境
　　もともと得意だった教科
　　そして、やり方
```

このうち、どれが効いたのかは、勝った本人にも分かりません。

人は、自分が勝ったときのやり方を、全部正しかったと思います。
これは誰でもそうです。悪いことでもありません。

でも、そのやり方の中には、効いていなかったものも混じっています。
混じったまま、次の人に渡されます。

渡された人がまた勝つと、同じまま、その次の人に渡ります。

こうして、誰も確かめないまま、やり方だけが流れていきます。

### だから、まず「負けないこと」から始めます

勝ち方は、人によって違います。運も混じります。

でも、負け方は違います。

点が出ないやり方は、誰がやっても点が出ません。
倍率にも、環境にも、関係ありません。

```
　　勝ち方　　人による　　　運が混じる　　　真似できないことがある
　　負け方　　全員同じ　　　確かめられる　　先に、消せる
```

だから、この本はやらないことで書いてあります。

正しいやり方を1個増やすより、
点にならないやり方を1個消すほうが、確実だからです。

## でも、4つに共通していることが、もう1つあります

さっきの4つに戻ります。

この4つをやっているあいだ、教科書かノートが、開いています。

```
　　線を引く　　　　→　教科書を見ながら
　　読み返す　　　　→　教科書を見ながら
　　まとめる　　　　→　教科書を見ながら
　　書いて覚える　　→　単語帳を見ながら
```

4つとも、見ながらやる作業です。

1回も、閉じていません。

---

ここで、巻頭の11個の数字を思い出してください。

あのとき、あなたは何をしましたか。

本を伏せましたよね。

伏せたから、出せるかどうかが分かりました。
伏せなかったら、永遠に「たぶん覚えた」のままでした。

## では、あなたはこの4つを、何で選んだのか

効果で選んだわけでは、ありません。
効果は、測っていないからです。

測ったことがあるのは、こっちです。

　　やりやすいかどうか。

---

線を引くのは、簡単です。
読み返すのは、知っているものを読むので、楽です。
まとめるのは、手が動いている実感があります。
書くのは、何も考えなくてもできます。

4つとも、やりやすい。
やりやすいから、続いた。続いたから、残った。

そして残ったものを、人は「自分に合ったやり方」と呼びます。

## やりやすいというのは、頭が楽をしているということです

勉強は、頭に負荷がかかっているときにしか、残りません。

```
　　やりやすい　　→　頭が楽をしている　　→　残らない
　　やりにくい　　→　頭が働いている　　　→　残る
```

2000人全員が同じ4つだったのは、偶然ではありません。
全員が、同じ基準で選んだからです。

## やりやすいものは、勉強ではなく、作業になります

ここで、言葉を1つ分けます。

```
　　作業　　終わらせることが目的。終われば、達成感がある
　　勉強　　できるようになることが目的。できなければ、意味がない
```

線を引く。まとめる。書き写す。

この3つには、共通点があります。
どれも、必ず終わります。

終わると、やった感じがします。
ノートが埋まって、ページが進んで、時間も使った。

でも、終わったかどうかと、できるようになったかどうかは、別です。

5時間やって、ノートが10ページ進んだ。
それは、作業が5時間ぶん終わった、ということです。

テストに出るのは、終わったかどうかではありません。

## 選ぶ基準を、1つだけ入れ替えてください

やめてほしいのは、4つの行動そのものではありません。

選び方です。

```
　　×　やりやすかったか
　　○　出せたか
```

これだけです。

今日の勉強の最後に、教科書を閉じて、今日やったことを3つ書いてみてください。

3つ書けたやり方は、勉強です。
1つも書けなかったやり方は、どれだけやりやすくても、作業です。

## 逃げ道が、2つあります

この基準を入れると、2つの言い訳が使えなくなります。
先に、両方ふさいでおきます。

### 1つ目　「自分に合ったやり方が分かってから、本気を出す」

探しているあいだは、勉強していません。
それなのに、やっている感じがします。

探すのは、勉強の中でいちばん楽な作業だからです。

参考書を比べる。やり方を調べる。計画を立て直す。
どれも1時間やれば、充実します。1問も解いていないのに。

### 2つ目　「それ、やってみたんですけど、自分には合わなくて」

この言葉を、何百回も聞いてきました。

聞き返すと、だいたい2つのどちらかです。

```
　　3日でやめていた
　　やりやすくなかった
```

3日は、合うか合わないかが分かる長さではありません。
そして、やりやすくないのは、当たり前です。

頭に負荷がかかるやり方は、やりにくいからです。
やりにくいから効くのに、やりにくいからやめてしまう。

合わなかったのではありません。
合わないと決める基準が、やりやすさだっただけです。

---

ただし、探していいものもあります。

```
　　探していい　　　　どうやって、出すか
　　探してはいけない　出すかどうか
```

出し方は、人によって変わります。

声に出すのが合う人、書くのが合う人、
誰かに説明するのが合う人、歩きながらのほうが出る人。

そこは、自分で探してください。試す価値があります。

でも「出す」こと自体は、誰にとっても変わりません。
そこを探し始めると、永遠に始まりません。

## 僕は、「自分に合ったやり方」を完璧に持っていました

高校3年のとき、僕のやり方は完成していました。

毎日、同じ時間に起きて、同じ順番で、同じやり方で進める。
崩れた日は、1日もありません。

自分に合っていたからです。
やりやすくて、続けられて、終わったときに「やった」という感じがありました。

結果は、最低偏差値42。10校受けて、10校落ちました。

合っていました。点が出なかっただけです。

---

あのころのノートを、いまでも持っています。

きれいです。線が引いてあって、要点がまとまっていて、
同じ単語が何十回も書いてあります。

全部、さっきの4つです。

毎日14時間、作業をしていました。

僕は、自己流でした。
誰にも教わらず、自分で決めて、自分のやり方を信じていました。

いまから思えば、事故流です。

---

だから僕は、過程に意味があるとは言いません。
14時間やった過程は、10校落ちたので、意味になりませんでした。

ただ、努力が無駄だったという話でもありません。

量は、たぶん学年で一番やっていました。
足りなかったのは、量ではありません。

方向が違っただけです。

そして方向は、今日変えられます。

## 変えるには、順番があります

巻頭に、答えを出さずに置いた質問が1つあります。

　　では、どれを捨てますか？

1日に5つ覚えて、1つにつき1日後・1週間後・1か月後に復習する。
やってみると、1週間で1日20個になる。5教科なら、100個です。

全部はできません。どれかを捨てるしかない。
でも、どれを捨てるのかは、そこでは書きませんでした。

答えは、順番です。

```
　　① やってはいけないことを、まずやめる
　　② 結果を出している人の、やり方を知る
　　③ その正しいやり方で、量をやる
```

この順番です。逆から行くと、効きません。

### 穴の空いたバケツ

バケツに、穴が空いているとします。
水を入れても、下から漏れていきます。

あなたなら、どうしますか。

　　穴を、ふさぎますよね。

当たり前です。

でも、勉強でこれをやっている人は、ほとんどいません。

点が出ないとき、ほとんどの人がやるのは、これです。

```
　　もっと長い時間やる
　　もっと早起きする
　　もっと量を増やす
```

全部、注ぐ量を増やす話です。
穴は、空いたままです。

注ぐ量を2倍にすると、漏れる量も2倍になります。

```
　　①　穴をふさぐ
　　②　水の入れ方を覚える
　　③　そのうえで、たくさん注ぐ
```

量は、要ります。③は飛ばせません。

ただ、①の前に③をやると、何時間やっても、たまりません。
高校3年の僕が、それでした。

そして、①をやると、100個は100個のままではなくなります。

```
　　①　やらなくていいものが消える　　→　時間が空く
　　②　残ったものの中身が変わる　　　→　同じ時間で、入る量が増える
　　③　空いた時間に、量を入れる
```

捨てるものは、自分で選ぶのではありません。
順番どおりにやると、勝手に決まります。

## 最後に、1つだけ

勉強が好きで好きでたまらない、という人は、多くないと思います。

僕も、好きではありませんでした。

それでも、あなたはこの本を開いています。
やらなきゃいけない、と思っているということです。

もう、頑張っているんです。

だから、その時間を作業で終わらせてほしくない。

同じ5時間なら、点になるほうの5時間にしてほしい。
それだけです。

```
　　ただし、本当にやめてほしいのは、4つの行動ではありません。
　　やりやすさで選ぶ、という選び方のほうです。

　　　×　やりやすかったか
　　　○　出せたか
```
