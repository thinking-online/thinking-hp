# はじめに　「お前の勉強法、ぜーんぶ、ズレとる。」

　　「お前の勉強法、ぜーんぶ、ズレとる。
　　　偏差値70を安定して超えていないなら、
　　　つべこべ言わず、俺の言うことを聞け。」

---

浪人が始まった日に、恩師に言われた言葉です。

言い返せませんでした。

僕はその数週間前、大学受験で地獄を見ていたからです。

勉強時間は、誰よりも長かった。それなのに、最低偏差値は42。受けた大学と学部、10個。全部、不合格。

そう、全落ちです。

---

いまでこそ「受験の王様」と名乗って、Instagramでは9万人以上、公式LINEでは4万人以上の人に見てもらっています（執筆時点）。英語講座もふくめて、これまで2000人以上の生徒を見てきました。

でも、スタートは、そこからいちばん遠い場所でした。

## 口だけ野郎の、ダサい男でした

高校には、サッカーを本気でやるために入りました。

部員は100人以上。本気で全国大会を目指していました。2年生のときから上級生の試合にスタメンで出させてもらって、3年生では副キャプテンと副部長。サッカーに、全部をかけていました。

（サッカーだけじゃありません。文化祭も体育祭も恋愛も、ぜーんぶ本気でやってました。その話は、コラムに書きます）

ただ、夢は破れました。全国大会への切符は、取れなかった。

サッカーという「威張れるもの」がなくなった僕には、何も残っていませんでした。

どうせ受験するなら、私立トップの早稲田か慶應っしょ。そう思って、志望校は早稲田にしていました。でも、口だけです。全然やらない。模試はずっとE判定。

```
　　「定期テストは、受験に関係ない」　　→　受験科目ですら、赤点ギリギリ
　　「私立の問題形式とは、違うから」　　→　模試の偏差値、40台
```

言い訳だけは達者。でも、行動はしない。

口だけ野郎の、ダサい男でした。

## 「努力の天才」と呼ばれて、全部落ちました

高校でいちばん尊敬していた友達が、あるとき言いました。

　　「結局、受験は覚悟の差だよな」

刺さりました。

　　努力していない自分が、いま、いちばんダサい。

そこから、覚悟を決めました。部活を正式に引退してからは、1日13時間以上。年末には「2日で30時間を超えないと年を越せません」という企画を、自分で勝手にやっていました。

勉強時間を記録するアプリで、友達と時間を見せ合っていたので、まわりからはこう言われていました。

　　「マジで、努力の天才だよな」
　　「がんばってるの見て、ほんと刺激もらうわ」

うれしかったです。自分でも、そう思っていました。

結果は、全落ちでした。

誰よりもやったのに、1つも受からなかった。

## 10か月で、全科目の偏差値が70を超えました

そこで言われたのが、最初の言葉です。

　　「お前の勉強法、ぜーんぶ、ズレとる」

量が足りなかったんじゃない。やり方が、全部ズレていた。

浪人の1年は、1からやり直しました。中学の英単語から、本当に基礎の基礎からです。しかも選択科目は、現役のときの日本史と数学から、世界史に変えました。ゼロからのスタートで、最初の模試は、もちろん40台です。

そして、ただ量をやるのをやめました。どう勉強するべきなのかを調べて、プロに徹底的にアドバイスをもらって、勉強法そのものを勉強しました。

（あなたは、何冊も読まなくて大丈夫です。この1冊に、全部入れました）

10か月後。

全科目で偏差値70を超えて、早稲田大学に合格しました。

## 「それは、もともと頭が良かったからですよね？」

これ、何百回も言われてきました。

まず、もともと頭が良かったら、10個も落ちません（笑）

口で言っても伝わらないな、と思いました。だったら、証明するしかない。

　　人は、誰だって、変われる。

この一言を証明するために、予備校のチューターから始めて、エリアのリーダーになり、大学1年のときに独立して、生徒を1人ずつ徹底的に見るようになりました。北海道から沖縄まで。ベトナムに住んでいる生徒も教えました。

その結果、起きたことです。

```
　　高校で不登校になり、通信制へ
　　　→　全統模試で全国1位。早稲田大学に現役合格

　　3日坊主で、勉強が大嫌いだった中学生
　　　→　毎日机に向かうようになって、学年トップ

　　高校を出て、工場で働いていた
　　　→　早稲田をふくめて、受けた法学部に全勝

　　現役で全落ち　　　　　　　　　→　早慶ダブル合格
　　偏差値50台、バイトをしながら　→　早慶全勝
```

サポートが終わったあとにもらう手書きのメッセージは、いまでは1000枚を超えました。

（本当に、みんなありがとう。自慢の生徒です）

## 受験の先まで効く、一生モノの武器です

話は、受験で終わりません。

「結果の出し方」を身につけた生徒たちは、大学に入ったあとも止まりませんでした。在学中に公認会計士試験に一発合格。英検1級。大学1年でIELTS7.0。宅建合格。学費免除の特待生。

勉強ができるようになる、というのは、学び方を知る、ということです。

学び方を知っていれば、この先、叶えたい目標が出てきたときに、叶える力があります。そして「自分で変えた」という経験は、早ければ早いほど、あとの人生に何倍にもなって効いてきます。

目の前の定期テストや模試のために、読んでください。

でも、手に入るのは、その先までずっと使える武器です。

## 伸びる子は、「やっていないこと」が同じでした

活動を始めてからずっと、1人ずつ、頭の中を開けてきました。

　　「いま、何を考えた？」
　　「そこで、なんで手が止まった？」
　　「それ、覚えたって、どうやって確かめた？」

そうしたら、伸びる子に、同じものが見つかったんです。

やっていることじゃ、ありませんでした。

　　やっていないこと、でした。

そして僕自身、誰よりも勉強ができなくて苦しんだ人間です。人より多く努力して、その努力を全部無駄にした経験があります。

だから、これだけは先に言わせてください。

　　努力に、酔ってはいけない。

If I play, I play to win.

やるからには、勝ちにいく。そして勝負に勝つためには、まず、負けないことです。

## バケツに、穴が空いています

バケツに、穴が空いているとします。水を入れても、下から漏れていきます。

あなたなら、どうしますか？

　　穴を、ふさぎますよね。

当たり前です。でも、勉強でこれをやってる人は、ほとんどいません。点が出ないとき、ほとんどの人は、もっと長くやる。もっと早く起きる。もっと量を増やす。

穴が空いたまま、水を増やしているんです。現役のときの僕が、まさにそれでした。

だから、順番があります。

```
　　① やってはいけないことを、避ける　　（穴をふさぐ）
　　② 正しいやり方を、知る　　　　　　　（水の入れ方を覚える）
　　③ そのやり方を、徹底的にパクる　　　（そのうえで、たくさん注ぐ）
```

この順番を守ってくれたら、受験は変わります。

いえ、人生も変わります。

## この本に書いてあること

頭のいい人が、何をやっているのか。そして、何を、絶対にやらないのか。その瞬間、頭の中で、何を考えているのか。

この本は、それを全部、見える形にしたものです。

```
　　第1章　　　　　頭のいい人の、絶対法則6
　　　　　　　　　　どの章よりも大事な大前提です。ここだけは、飛ばさないでください

　　第2章〜第8章　　場面ごとの、44個
　　　　　　　　　　授業、覚え方、解き方、計画、集中、本番、AI
```

50個、全部こうなっています。

```
　　×　頭のいい人が、絶対にやらないこと
　　○　かわりに、何をどうやるか
```

読んだら、そのままやってください。それだけで、いいです。
