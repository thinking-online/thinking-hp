第1章だけは、最初に読んでください。全部のもとになっている、6つの絶対法則です。

第2章から先の44個は、==順番に読まなくていいです。==いま困っていることから、開いてください。

## 巻頭で聞いたことの、答えの場所

巻頭で、「誰も教えてくれない」と書いたことがあります。答えは、ここにあります。

```
　「ちゃんと」の中身は、何なのか　　　　　　　　　　16　20　23
```

## 1つの項目は、こうなっています

50個とも、同じ順番で書いてあります。

```
　　×　頭のいい人が、絶対にやらないこと
　　○　かわりに、やっていること

　　場面　　　　　　よくある場面。たぶん、あなたにも覚えがあります
　　なぜ　　　　　　なぜ、それだと伸びないのか
　　頭のなか　　　　同じ場面で、伸びない人と、頭のいい人が考えていること
　　やり方　　　　　手順を3つ
　　今日やること　　今日、1つだけやること
```

読むだけで終わらせないでください。==各項目の最後にある「今日やること」を、1つだけやる。==それが、この本の使い方です。

50個を全部やろうとしなくていいです。全部やろうとすると、全部が途中で終わります。（理由は、04番に書きました）
