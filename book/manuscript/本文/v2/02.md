```
　　声に出して覚える人
　　白紙に書き出す人
　　人に説明する人
　　歩きながら、頭の中で言う人
```

やり方は、全員ばらばらですよね。

それなのに、==全員が、同じことをやっています==。

　　教材を閉じて、自分の中から出している。

最後の最後の枝葉は、違います。でも、幹は同じです。

僕は、誰か1人の勝ち方を書いてるわけじゃありません。2000人以上を見てきて、全員に共通していたところだけを抜き出しました。

## 幹の名前は「思い出して、出す」

　　思い出すこと。

これだけです。英語では、アクティブリコールと呼ばれています。本書では「思い出して、出す」と書きます。

巻頭で、11個の数字を覚えてもらいましたよね。あのとき、あなたは何をしましたか？

本を伏せましたよね。

伏せたから、出せるかどうかがわかった。伏せなかったら、永遠に「たぶん覚えた」のままでした。あれが、思い出すということです。

==覚える訓練ではなく、思い出す訓練をする。==これが、2つ目の絶対法則です。

## 今度は、文章でやります

ここまで、このページを読んできました。

本を閉じてください。

いま読んだページに書いてあったことを、3つ言ってください。

出なかったはずです。

10秒前に読んだばかりなのに、出てこない。難しい話でもなかったのに、出てこない。読むのと、出せるのは、別の作業だからです。

## 読んでいるあいだ、頭は何もしていません

読んでいるとき、目は字を追っています。字は目から入ってきます。入ってくるので、わかった感じがします。でも、そのあいだ、頭は何も探していません。探していないものは、あとで探せません。

```
　　図　本と、頭と、紙を横にならべる

　　上の矢印　本　→　頭　　「入れる」　太い矢印。目を開けていれば起きる
　　下の矢印　頭　→　紙　　「出す」　　細い矢印。自分で探さないと起きない
　　注　テストの日に使うのは、下の矢印だけ
```

テストの日にやるのは、下です。

## 「わかった」は、感想です

読んで「わかった」と思ったとき、あなたが確かめたのは1つだけです。

　　書いてあることが、理解できたかどうか。

確かめていないのは、こっちです。

　　本を閉じたときに、自分の中から出てくるかどうか。

この2つは、別です。そして、テストで聞かれるのは、2つ目だけです。

```
　　1ページ読み終わったとき、伸びない人の頭のなか
　　　「うん、わかった。次いこう」

　　同じとき、頭のいい人の頭のなか
　　　「いま、閉じて出せる？」
```

## 読んだ回数ではなく、出した回数で決まります

これは、調べられています。ワシントン大学の実験です。学生に同じ文章を学習させて、2つに分けました。

```
　　1　くり返して、4回読む
　　2　1回読んで、あとの3回は何も見ずに思い出して書く
```

学習した直後にテストすると、1のほうが点が高くなりました。読んだばかりなので、残っている感じもあります。ところが、1週間後にもう一度テストすると、順位がひっくり返ります。==2のほうが、大きく上でした。==使った時間は同じです。読んだ回数ではなく、出した回数で差がついています。

## やることは、1つだけ

入れたら、閉じる。閉じてから、出す。

手順は4つです。

```
　　① 閉じる
　　② 3秒、待つ
　　③ 声に出す
　　④ 出なかったら、開いて、その1か所だけ見る
```

①　赤シートではなく、手で隠すか、本を閉じます。赤シートは透けています。目が勝手に拾ってしまいます。②　すぐ出てこなくていいです。この3秒が、探している時間です。ここで点が決まります。1秒で諦めて開く人は、探していません。③　小さい声でいいです。頭の中で思い出すのは、なしです。頭の中だと、出たかどうかを自分でごまかせるからです。声は、出なければ止まります。だから、ごまかせません。④　全部を読み直しません。出なかった1か所だけ見ます。見たら、また閉じて、もう一度出します。どれくらいの間隔でやるのか。1ページごとです。長くても、見開き1つごと。章を1つ読み終わってからでは、もう遅いです。出す量が多すぎて、どこが出なかったのか分からなくなります。では、何を3つ出すのか。全部は出せません。出さなくていいです。

```
　　1　見出し
　　2　いちばん大事だと思った1文
　　3　自分が知らなかったこと
```

この3つで十分です。

## 「3つも出てきません」

1つでいいです。

0でなければ、探す作業は起きています。大事なのは個数ではなく、閉じたかどうかです。時間がかかる、と思うかもしれません。かかります。1ページあたり、20秒ほど増えます。でも、閉じずに10ページ読んだ時間は、全部0です。20秒を10ページぶん払って、3分。3分払って、10ページが残ります。

```
　　　　　いま、閉じて出せる？
```

この本で、いちばん多く出てくる問いです。迷ったときは、これだけ思い出してください。

## 解説を読んだあとも、同じです

問題集で間違えて、解説を読みます。

　　「なるほど、そういうことか」

納得して、次の問題に進みます。3日後、同じ問題が、また解けません。

理由は同じです。解説を読んだだけで、自分の中から1回も出していないからです。「なるほど」と思ったら、解説を閉じて、いま読んだ解き方を、何も見ずにもう一度書いてみてください。書けたら、入っています。書けなかったら、まだ読んだだけです。

## 練習でやっていないことは、本番では起きません

テストの日にやるのは、探すほうです。教科書は開けません。自分の中から、出すしかない。

だから、ふだんの勉強の中に、「何も見ずに出す」を入れます。読む時間を減らして、出す時間を増やす。==勉強の時間の半分以上を、閉じている時間にしてください。==

## この法則のまとめ

読んだ回数ではなく、思い出した回数で決まる。入れたら、閉じる。閉じてから、出す。

```
　　　　　いま、閉じて出せる？
```

この本で、いちばん多く出てくる問いです。迷ったときは、これだけ思い出してください。
