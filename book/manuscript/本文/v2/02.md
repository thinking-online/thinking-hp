01番は、やめる話でした。ここからは、何が正しいのか、です。

その前に、1つ見てください。結果を出してる人を、何人も並べたときに見えてくるものです。

```
　　声に出して覚える人
　　白紙に書き出す人
　　人に説明する人
　　歩きながら、頭の中で言う人
```

やり方は、全員ばらばらですよね。

それなのに、==全員が、同じことをやっています==。

　　教材を閉じて、自分の中から出している。

最後の最後の枝葉は、違います。でも、幹は同じです。

僕は、誰か1人の勝ち方を書いてるわけじゃありません。2000人以上を見てきて、全員に共通していたところだけを抜き出しました。

## 幹の名前は「思い出して、出す」

　　思い出すこと。

これだけです。英語では、アクティブリコールと呼ばれています。本書では「思い出して、出す」と書きます。

巻頭で、11個の数字を覚えてもらいましたよね。あのとき、あなたは何をしましたか？

本を伏せましたよね。

伏せたから、出せるかどうかがわかった。伏せなかったら、永遠に「たぶん覚えた」のままでした。あれが、思い出すということです。

==覚える訓練ではなく、思い出す訓練をする。==これが、2つ目の絶対法則です。

## 今度は、文章でやります

ここまで、このページを読んできました。

本を閉じてください。

いま読んだページに書いてあったことを、3つ言ってください。

出なかったはずです。

10秒前に読んだばかりなのに、出てこない。難しい話でもなかったのに、出てこない。読むのと、出すのは、別の作業だからです。

## 読んでいるあいだ、頭は何もしていません

読んでいるとき、目は字を追っています。字は目から入ってきます。入ってくるので、わかった感じがします。でも、そのあいだ、頭は何も探していません。一度も探したことがないものは、テストの日にも探し出せません。

```
　　図　本と、頭と、紙を横にならべる

　　上の矢印　本　→　頭　　「入れる」　太い矢印。目を開けていれば起きる
　　下の矢印　頭　→　紙　　「出す」　　細い矢印。自分で探さないと起きない
　　注　テストの日に使うのは、下の矢印だけ
```

テストの日にやるのは、下の矢印です。

## 「わかった」は、感想です

読んで「わかった」と思ったとき、あなたが確かめたのは1つだけです。

　　書いてあることが、理解できたかどうか。

確かめていないのは、こっちです。

　　本を閉じたときに、自分の中から出てくるかどうか。

この2つは、別です。そして、テストで聞かれるのは、2つ目だけです。

```
　　1ページ読み終わったとき、伸びない人の頭のなか
　　　「うん、わかった。次いこう」

　　同じとき、頭のいい人の頭のなか
　　　「いま、閉じて出せる？」
```

## 読んだ回数ではなく、出した回数で決まります

これは、調べられています。ワシントン大学の実験です。学生に同じ文章を学習させて、2つに分けました。

```
　　1　くり返して、4回読む
　　2　1回読んで、あとの3回は何も見ずに思い出して書く
```

学習した直後にテストすると、1のほうが点が高くなりました。読んだばかりなので、残っている感じもあります。ところが、1週間後にもう一度テストすると、順位がひっくり返ります。==2のほうが、大きく上でした。==使った時間は同じです。読んだ回数ではなく、出した回数で差がついています。

## 解説を読んだあとも、同じです

問題集で間違えて、解説を読みます。

　　「なるほど、そういうことか」

納得して、次の問題に進みます。3日後、同じ問題が、また解けません。

理由は同じです。解説を読んだだけで、自分の中から1回も出していないからです。「なるほど」と思ったら、解説を閉じて、いま読んだ解き方を、何も見ずにもう一度書いてみてください。書けたら、入っています。書けなかったら、まだ読んだだけです。

## 練習でやっていないことは、本番では起きません

テストの日にやるのは、探すほうです。教科書は開けません。自分の中から、出すしかない。

だから、ふだんの勉強の中に、「何も見ずに出す」を入れます。読む時間を減らして、出す時間を増やす。==勉強の時間の半分以上を、閉じている時間にしてください。==

## 頭のなか

### 1ページ読み終わったとき、伸びない人

「うん、わかった。次いこう」（10ページ読む。閉じたら、何も出てこない）

### 同じとき、頭のいい人

「わかった。……いや、いま読んだだけだ」「閉じて、出せる？」（閉じる）「見出しは、これ。大事なのは、これ。……3つ目が出ない」（その1か所だけ開く）「これか」（また閉じて、言う）

## やり方

### STEP 01　1ページ読んだら、本を閉じる

手で隠すか、閉じます。赤シートは透けるので、使いません。区切りは1ページ。長くても、見開き1つです。章を読み終わってからでは、出す量が多すぎます。

### STEP 02　3秒待って、書いてあったことを3つ、声に出す

見出し。いちばん大事だと思った1文。自分が知らなかったこと。この3つです。頭の中で言うのは、なしです。声は、出なければ止まるので、ごまかせません。

### STEP 03　出なかった1か所だけ開いて見て、また閉じて言う

全部は読み直しません。出なかったところだけ見て、閉じて、もう一度言います。次の日、同じページを開く前に、もう1回だけ言ってみます。

　　「できた」の基準　　本を閉じたまま、3つ言えた。次の日、開く前にも、同じ3つが言えた。

## 「3つも出てきません」

1つでいいです。

0でなければ、頭は探しています。大事なのは個数ではなく、閉じたかどうかです。時間がかかる、と思うかもしれません。かかります。1ページあたり、20秒ほど増えます。でも、閉じずに10ページ読んでも、あとには、ほとんど残りません。20秒を10ページぶんで、およそ3分。3分足すだけで、10ページが残ります。

## この法則のまとめ

読んだ回数ではなく、思い出した回数で決まる。入れたら、閉じる。閉じてから、出す。

```
　　　　　いま、閉じて出せる？
```

この本で、いちばん多く出てくる問いです。迷ったときは、これだけ思い出してください。

今日やること　教科書を1ページ読んだら、閉じて、書いてあったことを3つ声に出す。出なかった1か所だけ、開いて見る。
