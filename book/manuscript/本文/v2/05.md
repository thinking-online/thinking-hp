定期テストの2週間前。範囲表が配られました。

　　「よし、今日から本気を出す」

英単語は、前の日にまとめてやることにしました。前日の夜、3時間かけて、100個を一気に覚えます。

テストは、取れました。

1か月後の模試。同じ単語が出ました。

　　ほとんど、出てきません。

3時間かけたのに、です。

## 続けて2回より、あけて2回

これは、気合いの問題ではありません。調べられています。

コロラド大学の実験です。大学生に同じ文章を読ませて、3つのグループに分けました。

```
　　1　1回だけ読む
　　2　2回続けて読む
　　3　1回読んで、1週間あけてから、もう1回読む
```

テストの時期も、読んだ直後と、2日後で分けました。

```
　　読んだ直後のテスト　　2が1位。3は1とほとんど変わらなかった
　　2日後のテスト　　　　3が1位。2は1と同じところまで落ちた
```

順位、ひっくり返ってますよね。

2と3は、どちらも2回読んでいます。==使った時間は、同じです。==違うのは、続けたか、あけたか。それだけです。

## まとめてやると、効いた気がします

ここが、やっかいなところです。

続けて2回やるのは、その日のうちは本当に効きます。効いた実感もあるし、直後の点も上がります。前日に詰めこんで、テストが取れてしまう。だから、やめられません。

でも、数日で消えます。

入試は、覚えた次の日にはありません。3か月後、1年後、3年後です。前日に詰めこんだ単語は、そこまで持ちません。そして、また1から覚え直すことになります。

```
　　まとめてやる　→　その日は残る。数日で消える。また1からやる
　　分けてやる　　→　その日は残りにくい。でも、消えない
```

==まとめてやる人は、同じものを、何度も1から覚え直しています。==

## 同じ3時間を、3つに割ります

やることは、増やしません。割るだけです。

```
　　×　前日に　3時間　　　　　　　　　合計3時間
　　○　1時間を、3日に分ける　　　　　 合計3時間
```

2回目にやるとき、少し忘れています。忘れかけたものを、もう一度引っぱり出す。この「引っぱり出す」が、02番の「思い出す」です。

分けると、思い出す回数が自動で増えます。まとめると、1回も思い出さないまま終わります。==分散は、思い出す回数を増やすための仕組みです。==

## 範囲は、授業のその日に決まっています

「2週間前から本気を出す」が成り立たない理由が、もう1つあります。

範囲表に書いてあるのは、新しい情報ではありません。この1か月半、授業でやったところです。==範囲は、授業を受けたその日に、もう決まっていました。==

2週間前に始めると、1か月前に習ったことは、ほとんど消えています。テスト勉強のつもりで、最初から覚え直すことになります。

授業があった日に、15分だけ。その日やったところを、閉じて出しておく。これを続けた人にとって、2週間前は「2回目」か「3回目」です。まとめてやる人にとっては、「1回目」です。

## 1日の中でも、同じです

分けるのは、日にちだけではありません。

1つの教科を3時間ぶっ通しでやるより、区切って、あいだに別のものをはさんだほうが残ります。解く練習は種類を混ぜる（17番）。25分で区切る（37番）。短い時間でも毎日さわる（31番）。忘れる前に、もう1回出す（16番）。

この本の中で、形を変えて何度も出てきます。全部、この法則から出ています。

## 頭のなか

### 範囲表をもらった日、伸びない人

「2週間ある。まだ大丈夫」「英単語は前日にまとめてやればいい」（前日、3時間で100個。1か月後、0個）

### 同じとき、頭のいい人

「範囲、ここからここまでか。全部、授業でやったところだな」「授業の日に1回出してあるから、今日からは2回目」「英単語100個は、今日30分、3日後に20分、前日に10分」「合計1時間。前日に3時間やるより短い」

## やり方

### 1　授業があった日に、15分だけ出す

その日やったところを、教科書を閉じて言ってみます。全部でなくていいです。出なかったところに印をつけて終わりです。

### 2　テスト勉強の時間を、3日に割る

「前日に3時間」と書こうとしたら、「1時間を3日」に書き直します。時間は増やしません。

### 3　間隔は、だいたいでいい

何日あければいいか、正確に決めなくていいです。続けてやらない。それだけ守れば、ほとんどの効果は取れます。（くわしいやり方は、16番でやります）

## この法則のまとめ

同じ時間なら、続けてやるより、あけてやるほうが残る。まとめてやると、その日は効いた気がして、数日で消える。時間は増やさない。割るだけ。

今日やること　今日の授業でやったところを、寝る前に15分、閉じて出してみる。
