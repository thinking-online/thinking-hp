5時間目の社会。黒板を見ています。先生の話も、ちゃんと聞いています。ノートも取っています。寝ていません。スマホも見ていません。その日の夜、同じ範囲のワークを開きました。

1問目で止まりました。

## 聞いていなかったわけでは、ありません

ここでよく言われるのが「集中して聞いていなかったからだ」です。でも、本当に聞いていたのです。先生が何の話をしていたかも言えます。ノートにも書いてあります。問題は、聞き方ではありません。聞くという行為そのものが、受け身だということです。

## 音は入ります。出す練習には、なりません

授業の50分で、あなたの頭が何回「出した」か、数えてみてください。当てられたのが1回だとしたら、1回です。あとの49分は、入れているだけです。家で単語を50分やるとき、あなたは何回も書いたり、思い出したりします。授業では、それを1回もやらずに50分が終わります。これが、授業を受けているのにテストで出てこない理由です。入れた量の問題ではなく、出した回数が0に近いという問題です。

## 15分に1回、30秒だけ、思い出します

やることは、1つだけです。

授業を、時間で区切ります。区切りが来たら、30秒だけ、ここまでを思い出します。

```
　　始まって15分　　　30秒　　「ここまで、何の話だった？」
　　始まって30分　　　30秒　　「ここまで、何の話だった？」
　　終わった直後　　　30秒　　「今日は結局、何の話だった？」
```

黒板も、ノートも、見ません。授業中は声が出せないので、ノートのすみに、言葉を3つ書きます。書けば、出たかどうかを、ごまかせません。

これで、50分の授業の中に、「出す」が3回入ります。0回が、3回になります。

## 先生に合わせずに、時間で区切ります

先生が大事なことを言う前に、先回りして考える。そういうやり方もあります。ただ、先生によって、話し方はちがいます。教科によっても、ちがいます。

時間なら、==どの先生の、どの教科でも、同じようにできます。==

もう1つ、理由があります。50分のあいだ、同じ濃さで聞きつづけられる人は、いません。途中で、少しずつぼんやりしてきます。区切りごとに「出す」をはさむと、そこで頭が切りかわります。

## 途中に「出す」をはさむと、ぼんやりが減ります

ハーバード大学の実験です。

授業の映像を、4つに区切って見てもらいます。片方のグループには、区切りごとに、短いテストをはさみました。もう片方には、はさみませんでした。

はさんだグループは、==授業中にぼんやりしていた時間が減って、最後のテストの点も高くなりました。==ノートを取る量も、増えていました。

テストといっても、いま聞いたことを思い出すだけです。それを途中にはさむだけで、そのあとの聞き方まで変わります。

## 30秒で、いいんです

長くやる必要は、ありません。30秒で、言葉を3つ。それだけです。

出てこなかったら、「？」を1つ書いておきます。そこが、休み時間に確かめる場所です。

30秒のあいだ、先生の話を聞きのがすのでは、と心配になるかもしれません。先生が黒板に書いているあいだ、プリントを配っているあいだに、やってください。15分ちょうどでなくて、いいです。だいたい、で十分です。

慣れてきたら、先生が答えを言う前に、心の中で先に答えてみるのも、いい練習になります。

## 映像授業なら、止められます

同じことが、映像授業でも起きます。1.5倍速。1コマ30分の授業が20分で終わります。今日は3コマ見ました。1時間で、90分ぶんの授業です。けっこう進んだと思って、寝ます。次の日、そのコマの確認テストで、半分しか取れません。

映像授業が悪いのではありません。わからないところを何回でも見られて、先生も選べます。問題は、その最大の利点を使っていないことです。映像授業にあって、教室の授業にないもの。それは、止められることです。

倍速にすると、入る速さは上がります。出す回数は、0のままです。

```
　　1倍速で30分　　出した回数　0
　　2倍速で15分　　出した回数　0
```

進んだ気がするのは、再生バーが右に動いたからです。再生バーは、あなたの頭の中を測っていません。

止める場所を、決めておきます。

```
　　10分たったら　　　　　　　　　→　止める。ここまでを、声に出して言う
　　先生が問題を出した直後　　　　→　止める。自分で解く
```

映像なら、声が出せます。止まっているのは、1回30秒です。倍速は、2周目からです。1周目は等速で、止めながら。2周目は倍速で、止めずに。先生が言う前に自分の頭が言っていたら、入っています。==倍速の正しい使い道は、速く入れることではなく、速く確かめることです。==

## 頭のなか

### 授業中、伸びない人

「ちゃんと聞こう」（50分、聞く。ノートを取る）「今日も、ちゃんと受けた」（その日の夜、ワークを開く）「……あれ、何の話だっけ」

### 同じとき、頭のいい人

（時計を見る。15分たった）「ここまで、何の話だった？」（ノートのすみに書く）「鎌倉幕府。御恩と奉公。……3つ目が出ない」（「？」を書く）「あとで確かめよう」（30分。もう1回）（チャイム）「今日は結局、将軍と武士が、土地でつながった話」

## やり方

### STEP 01　授業の前に、ノートのすみに「15分　30分　終わり」と書く

1コマに3回だけ、思い出す。その印です。時計が見えにくい席なら、だいたいでいいです。

### STEP 02　その時間が来たら、30秒、黒板もノートも見ずに、ここまでの言葉を3つ書く

先生が黒板に書いているあいだに、やります。出てこなかったら、「？」を1つ書きます。書けたら、印を1つ消します。

### STEP 03　終わった直後の30秒で、「今日は結局、何の話だった？」を1行書く

黒板も、教科書も見ません。そのあと、「？」をつけたところを、休み時間に1か所だけ確かめます。

　　「できた」の基準　　1コマで3回、何も見ずに、言葉を3つずつ書けた。「？」のところは、その日のうちに確かめた。

## これをやると、何が残るか

```
　　授業は、聞く時間ではない。
　　15分ごとに、思い出す時間にできる。
```

家に帰ってから、ゼロから覚え直す必要がなくなります。授業の中で、もう3回出しているからです。05番の「1回目」が、授業の中で終わっています。

## この場面のまとめ

聞いているだけでは、出す回数が0のまま。時間で区切って、15分に1回、30秒だけ思い出す。先生にも教科にも、左右されない。
