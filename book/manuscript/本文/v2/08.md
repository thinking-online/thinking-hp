数学の授業。先生が黒板に例題を書いて、解き始めます。ノートを開いて、写します。式を1行写す。顔を上げる。次の行を写す。顔を上げる。先生が何か説明していますが、手を動かしているので、半分しか聞こえません。

45分、ずっと写していました。ノートは3ページ埋まりました。

家に帰って、そのノートを開きます。式は全部そろっています。でも、なぜその式になったのかが、書いてありません。先生はそれを、口で言っていました。そのとき、手を動かしていました。

## 写しているあいだ、先生の話は聞こえていません

人は、書きながら聞くのが苦手です。

写しているとき、頭の中で何が起きているかを、順番に書いてみます。

```
　　黒板を見る
　　　→　書いてある字を、少しのあいだ覚える
　　　→　ノートを見る
　　　→　覚えた字を、書く
```

これを、1行ごとにくり返しています。頭は、==字を覚えて、書きうつすことで、いっぱい==です。「なぜ、そうなるのか」を考える余裕は、残っていません。先生の声は耳に入っていますが、聞き流しています。

そして、黒板に書いてあることと、先生が言っていることは、別のものです。

```
　　黒板に書いてあること　　結果。式と、答え
　　先生が口で言うこと　　　理由。なぜ、そうするのか
```

写した人のノートには、結果だけが残ります。理由は、教室に置いてきています。

## 黒板は、あとで見られます。先生の説明は、その場かぎりです

ここが、大事なところです。

```
　　黒板に書いてあること　→　教科書や問題集にも、だいたい載っている。あとで、何回でも見られる
　　先生が口で言ったこと　→　その場で聞きのがしたら、もう聞けない
```

全部写している人は、==あとで見られるほうを一生けんめい写して、その場でしか聞けないほうを、聞きのがしています。==

逆にしたほうが、得です。

黒板を残しておきたいだけなら、写真という方法もあります。学校や先生がいいと言っているなら、授業の終わりに、黒板を1枚撮らせてもらう。写す45分が、1秒になります。撮っていいかどうかは、必ず先に、先生に聞いてください。

## 授業のゴールは、ノートではありません

授業のゴールを、決め直します。

　　==先生が解説した問題を、あとで、白紙から自分で解けること。==

ノートがきれいにできることでも、全部写し終わることでも、ありません。白紙から、自分で解けるかどうか。それだけです。

そう決めると、授業中にやることが変わります。写すより先に、まず、わかること。

## ただし、「わかった」だけで帰ると、家で困ります

聞いて、わかって、何も書かずに帰る。これも、うまくいきません。

家で机に向かったとき、何を復習すればいいのかが、わかりません。先生が何と言っていたかも、思い出せません。

だから、メモはします。ただし、書くのは、黒板の写しではありません。==あとで白紙から解くときに、自分を助けてくれるもの==だけです。2種類あります。

```
　　覚えておくこと　　　　　先生が口で言ったこと。教科書には書いていないこと
　　　　　　　　　　　　　　「aで割る前に、a=0を確かめる」「ここ、テストに出す」

　　思い出すときのヒント　　最初の一手。なぜ、そうするのか。自分が止まったところ
　　　　　　　　　　　　　　「まず、yについて解く」「3行目の変形で止まった」
```

1つの例題に、3行まで。これが、家で白紙から解くときの、手がかりになります。

## 頭のなか

### 授業中、伸びない人

（黒板を見る）「えーと、2x + 3y = 12 ……」（書く）「次、両辺を……」（書く）「あ、先生何か言った。まあ、あとでノートを見ればいいか」

### 同じ授業中、頭のいい人

（黒板を見る。書かない）「2x + 3y = 12 を、yについて解く」「……両辺から2xを引いて、3で割る。これは、自分でできる」「ヒントは『まず、yについて解く』だけでいい」（次の例題）「お、ここで場合分けが出てきた」「なんで、場合分けが要るんだ？」（先生の説明を聞く）「……ああ、aが0のときに、割れなくなるからか」「それ、黒板に書いてない。メモしよう」（1行だけ書く）「aで割る前に、a=0を確かめる」

書いた量は、2行です。でも、その2行があれば、家で白紙から解けます。

## やり方

（STEP）

## 写したほうがいい場合

1つだけあります。

図です。

グラフ、実験装置、歴史の地図。こういうものは、見ただけでは頭に入りません。手で描くと入ります。図だけは、写してください。

## これをやると、何が残るか

家に帰ったときの、やることが決まります。

全部写した人のノートには、3ページの式が並んでいます。どこがわからなかったのかは、書いてありません。ヒントだけ書いた人のノートには、5行あります。家でやるのは、ノートを閉じて、白紙から1問解くこと。10分で終わります。

そして、解けたかどうかで、今日の授業が入ったかどうかが、その日のうちにわかります。

## この場面のまとめ

黒板は、あとで見られる。先生の説明は、その場かぎり。授業のゴールは、白紙から自分で解けること。メモするのは、そのためのヒントだけ。

今日やること　次の授業で、例題を1つだけ、写さずに聞く。ヒントを3行書いて、その日のうちに、白紙から解いてみる。
