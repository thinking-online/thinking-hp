毎週水曜日、英語の小テスト。単語10問。今日は7点でした。返ってきた紙を、カバンの底に入れます。

来週も、たぶん7点です。

## 10点に意味を感じないのは、普通です

成績に入らない小テストを本気で見る中学生は、あまりいません。点が低くても怒られないし、高くても何も起きない。ここで言いたいのは「小テストも大事にしよう」ではありません。小テストの点は、本当にどうでもいいです。どうでもよくないのは、間違えた3問のほうです。

## 小テストは、本番の予告です

小テストの範囲は、どこから出ていますか。

教科書の、今やっている単元です。定期テストの範囲も、同じところです。

```
　　小テストで落とした3問
　　　　　　↓
　　定期テストでも出る3問
```

先生は、わざわざ別の問題を作りません。小テストで出した語は、定期テストでもう一度出ます。つまり、小テストは「ここが出ます」という予告です。予告を見てから本番に行けるテストは、学校の中にしかありません。

## 残すのは、紙ではなく3問です

やることは、1分で終わります。返ってきたその場で、間違えたものだけを、1冊のノートに書き写します。テスト用紙は、捨てていいです。

書き写すのは、間違えたものだけです。合っていた7問は、二度と見なくていいです。1回の小テストで3問なら、1学期で12回。36語です。その36語が、あなただけの単語帳になります。市販の単語帳と違って、1語も無駄がありません。全部、自分が実際に落とした語だからです。

## 書き写すときに、やってはいけないこと

赤ペンで正解だけ書き写さないでください。

```
　　×　available　利用できる
　　○　available　利用できる　／　自分は「避けられる」と書いた
```

自分が何と書いたかを、横に残します。これを残しておくと、同じ間違いをしていることに気づきます。avoid と混ざっているなら、直すのは available ではなく、avoid と available を分けることです。

## 模試も、同じです

小テストより大きいぶん、もっと捨てられやすいのが模試です。

　　「E判定か。次こそ、がんばろう」

点数と判定だけ見て、閉じる。これも、点が出たら捨てているのと同じです。判定は、見ても動かせません。動かせるのは、==どの大問で落としたか==のほうです。

見るのは1か所です。いちばん点を落とした大問を1つ選んで、そこから間違えた問題を3問だけ残す。小テストとやることは同じです。

## やり方

### STEP 01　返ってきたら、その場で、間違えたものだけを見る

30秒です。合っていたものは、二度と見なくていいです。

### STEP 02　1冊のノートの後ろから、間違えたものを1行ずつ書く

正解だけを書きません。==自分が何と書いたか==を、横に残します。「available　利用できる　／　自分は『避けられる』と書いた」。何と混ざっているかが、見えるようになります。模試なら、いちばん点を落とした大問から3問です。

### STEP 03　次の小テストの前の日に、そのノートを閉じて出す

出せたものには、線を引いて消します。出せなかったものだけが、残ります。それが、あなただけの単語帳です。

　　「できた」の基準　　前の小テストで間違えたものを、次の小テストの前の日に、何も見ずに出せた。

## これをやると、何が残るか

```
　　小テストは、点を取る場所ではない。
　　間違いを集める場所だ。
```

## この場面のまとめ

```
　　×　10点満点の小テストなんて、意味がない
　　○　小テストは、本番の予告。間違えたものだけ残す
```
