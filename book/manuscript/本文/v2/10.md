高校2年生の火曜日。

その日、学校から出てきたものを並べます。数学の課題プリント2枚。英語の小テスト（明日）。理科のレポート（金曜提出）。古典の予習（明日の授業で当たる）。放課後に、受験補習の案内が配られました。希望制です。全部やると、夜11時までかかります。自分でやろうと決めていた英語の長文は、1問も開けませんでした。次の日も、同じです。

## 量を足し算した人が、いません

当たり前のようで、見落とされているところです。数学の先生は、数学のことだけを考えて課題を出します。英語の先生も、理科の先生も同じです。それぞれが「これくらいなら妥当だ」と思う量を出しています。その5つを足した人は、==どこにもいません。==だから、全部を同じ本気でやろうとすると、時間が足りなくなります。最初から、1日に入りきらない量なのです。誰も悪くありません。足し算する人がいないだけです。足し算するのは、あなたです。

## 「捨てる」と「手を抜く」は、別です

ここを混ぜると、いちばん損をします。

```
　　捨てる　　やらないと決める。時間が丸ごと空く
　　手を抜く　やりながら、中身を薄くする。時間は減らない
```

手を抜くのが、いちばんもったいないやり方です。1時間かけて、何も身についていない。でも「やった」という記録は残るので、損をしていることに気づきません。たとえば、答えを写して出す課題です。写すのに1時間かかります。そのあいだ、頭は使っていません。==1時間使って、何も残っていません。==

## 3つに分けます

学校から出てくるものを、3つに分けます。

```
　1　出さないと困るもの　　提出物、赤点を避けるための最低限
　　　　　→　時間を決めて、いちばん短い方法で終わらせる

　2　点につながるもの　　　受験や、自分が伸ばすと決めた教科のもの
　　　　　→　自分の勉強として扱う。閉じて出すところまでやる

　3　どちらでもないもの
　　　　　→　受けない
```

大事なのは、1と2を混ぜないことです。1は「終わらせる作業」です。きれいにやる必要がありません。先に「30分」と時間を決めて、その中で終わらせます。時間をかけたまま中身だけ薄くする「手を抜く」とは、ここが違います。2は「できるようになる作業」です。終わらせても、できていなければ意味がありません。

## 受ける前に、1つだけ聞きます

3かどうかを見分ける質問が、1つあります。

　　これが終わったとき、何ができるようになっていますか。

補習でも、講習でも、追加の問題集でも同じです。答えが返ってこない、または返ってきた答えが自分に要らないものなら、3です。

```
　　「共通テストの形式に慣れる」　　　→　共テを使うなら2。使わないなら3
　　「苦手な人向けに基礎を復習する」　→　その単元が苦手なら2。違うなら3
　　「とりあえず受けておいたほうが」　→　3
```

先生に直接聞きにくければ、配られた案内の紙か、授業の予定表を見てください。たいてい書いてあります。書いていないものは、3の可能性が高いです。

## 中学生は、ここに1つ足します

高校受験で内申が使われるなら、分け方が少し変わります。

提出物、小テスト、授業中の発言、実技の教科。これが内申に入る学校では、それは「出さないと困るもの」ではありません。==入試の点、そのものです。== 2の箱に入れてください。

```
　　受ける前に聞くこと（中学生）
　　　　これは、内申に入りますか？
```

内申のつき方は、都道府県と学校でちがいます。だから、最初に確かめます。先生に聞いていいことです。「どれが成績に入りますか」と聞いた人は、やる気がない人ではありません。どこに力を入れるかを、決めようとしている人です。

入るとわかったものは、手を抜きません。入らないとわかったものは、いちばん短い方法で終わらせます。全部を同じ本気でやって、全部が中くらいになるのが、いちばん損です。

## 頭のなか

### 案内をもらったとき、伸びない人

「補習か」「みんな取るのかな」「取らないと不安だな」「とりあえず出しとくか」

### 同じとき、頭のいい人

「補習、週2回。1回90分。月に12時間か」「この12時間で、何ができるようになる?」（案内を見る）「『共通テスト対策演習』……自分は共テ使わないな」「じゃあ3だ。出さない」「空いた12時間で、英語の長文を24本やろう」受けるかどうかを決めたのではありません。==12時間の使い道を決めています。==

## やり方

### STEP 01　1週間ぶん、学校から出たものを全部、1行ずつ書き出す

月曜から金曜まで。たいてい、12個から18個あります。多さに驚くはずですが、それが事実です。

### STEP 02　1つ1分で、1・2・3の番号をつける

迷ったら、「終わったとき、何ができるようになっているか」を聞きます。中学生は、その前に「これは、内申に入りますか」を確かめます。入るものは、2です。

### STEP 03　2に、いちばん頭が回る時間を先に取る。1には、終わりの時刻を決める

2は、閉じて出すところまでやります。1は「30分で終わらせる」と上限を決めてから始めます。上限がないと、1がいちばん時間を使います。3は、受けません。

　　「できた」の基準　　1週間で、2に使った時間が、1に使った時間より長かった。

## 「それは逃げになりませんか」

いちばんよく聞かれます。

逃げかどうかは、捨てたかどうかでは決まりません。==空いた時間を何に使ったかで決まります。==

```
　　補習を断って、その12時間で寝た　　　　　　→　逃げ
　　補習を断って、その12時間で長文を24本　　　→　選択
```

同じ「断る」でも、別のことです。だから、3に番号をつけたときは、その時間に何を入れるかを同時に決めてください。決めないまま空けると、本当に逃げになります。

## これをやると、何が残るか

1日が、2時間長くなります。全部を同じ本気でやっている人は、1日の終わりに「学校のものは終わったけど、自分の勉強は0だった」という日を作ります。週に3日それがあると、週6時間が消えます。分けた人は、1を30分で終わらせて、残りを2に使います。かけた時間は同じです。その時間を、点につながるものに使ったかどうかが違います。

## この場面のまとめ

学校から出てくるものは、足し算されていない。足すのは自分。1（終わらせる）と2（できるようになる）を混ぜないこと。

今日やること　今週、学校から出てきたものを全部1行で書き出す。1・2・3の番号をつける。
