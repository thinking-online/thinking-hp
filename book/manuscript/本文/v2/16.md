高校1年生。夏休みに、英単語を500語やりました。8月の終わりには、ほとんど出せるようになっていました。9月は、学校が始まって忙しく、単語に手をつけませんでした。10月も、中間テストがあって、やりませんでした。11月、模試の前に単語帳を開きます。

ほとんど出てきません。

　「もう全部忘れた。1からやり直しだ」

また、1ページ目から始めます。

## 忘れるのは、ふつうのことです

まず、ここを押さえてください。覚えたことは、忘れます。これは、できない人だけに起きることではありません。全員に起きます。できる人が忘れないのではありません。できる人は、忘れる前に、1回出しているだけです。

## 忘れてからだと、ゼロからになります

覚えたことは、時間がたつと、だんだん出にくくなります。ある時点までは、ちょっと見れば思い出せます。その時点を過ぎると、見ても思い出せなくなります。忘れきってから開くと、1回目と同じ作業をすることになります。500語を、また最初からです。忘れかけているうちに開くと、全然違います。500語のうち、出てこないのは100語くらいです。その100語だけやればいいので、5分の1の時間で済みます。

## 間をあけるのが、ポイントです

ここが、少し意外なところです。毎日やればいいのではないか、と思うかもしれません。毎日やると、かけた時間のわりに残りません。昨日やったことは、まだ忘れていないので、思い出す練習にならないからです。ちょうどいいのは、忘れかけたころです。だんだん間を広げていきます。「あれ、何だっけ」と少し苦労して出したときのほうが、残ります。すぐ出せるうちに出しても、あまり残りません。

## あの右下がりのグラフの話をします

勉強法の本で、必ず見るグラフがあります。時間がたつほど下がっていく、忘れ方のグラフです。そして、その横に表が載っています。

```
　　1日後　／　3日後　／　7日後　／　14日後　／　1ヶ月後
```

この日に復習しなさい、と書いてあります。

先に言います。==この表のとおりにやるのは、無理です。==

## なぜ無理なのか、数えてみます

今日、新しく30個やったとします。この30個に、5回の復習日がつきます。明日も30個やります。この30個にも、5回つきます。

これを1ヶ月続けると、どうなるか。

```
　　ある1日にやる復習　　5つの別の日にやった、5つの範囲
　　　　　　　　　　　　　30 × 5 ＝ 150個
　　そこに新しい30個　　　合計180個
```

しかも、どれが何日目のぶんかを、1個ずつ覚えておく必要があります。

==これでは、勉強ではなく、予定表の管理になってしまいます。==

できなかったのは、根性が足りないからではありません。このやり方が、最初から、続けられない作りになっているのです。

## グラフのほうにも、言っておくことがあります

あのグラフは、100年以上前の実験から来ています。覚えてもらったのは、==意味のない3文字==でした。

　　ZOF　　QAX　　MUV

意味がなく、つながりもなく、知っているものと結びつかない。いちばん忘れやすいものを、わざと使っています。

学校の勉強は、逆です。意味があり、ほかのこととつながっていて、授業でも問題集でも何度も出てきます。==だから、あのグラフほど速くは忘れません。==

もう1つ。あの実験が測ったのは、「どれだけ覚えているか」ではありません。もう一度覚え直すのに、==どれだけ時間が短くて済むか==です。測ったものが違います。

そして、1日後・3日後・7日後という表は、あのグラフには書いてありません。あとから別につけられたものです。

## 間隔は、正確でなくていい

いちばん大事なことを言います。

間隔の研究でわかっているのは、==ちょうどいい間隔から少しずれても、残る量はほとんど変わらない==ということです。はっきり損をするのは、間隔が0のときだけです。つまり、覚えたその場で続けて5回やる、という形です。

```
　　×　正確な日に、やる　　　　→　予定を追いきれなくて、やらなくなる
　　○　だいたい空いていれば、いい　→　続く
```

正確にやろうとして続かない人より、雑に空けて続く人のほうが、残ります。

## 頭のなか

### 11月、伸びない人

（単語帳を開く）「うわ、全然わからない」「夏にやったのに」「もう1回、最初からやるしかないな」

### 同じ11月、頭のいい人

「夏に500語やった。あれから2ヶ月半か」「全部は残ってないな。どれくらい残ってる?」（閉じて、50語分テストしてみる）「50個中、30個出た」「6割残ってるのか。思ったより残ってる」「出なかった20個に印をつけよう」「500語全部じゃなくて、この割合なら200語くらいか」「200語なら、3日で戻せる」1からやり直していません。残っているものを数えて、残っていないものだけを拾っています。

## 日付のかわりに、印で回します

### 日付を決めるのは、1回だけ

翌日の1回。これだけです。カレンダーは要りません。==今日やったものを、明日やる。==それだけなので、管理するものがありません。

2回目から先は、日付を決めません。かわりに、次のことをします。

### 出なかったものに、印をつける

閉じて出します。出たものには、何もしません。出なかったものにだけ、印を1つつけます。

```
　　available　　　　　　（出た。何もしない）
　　consist　　　　　｜　（出なかった。印を1つ）
　　subsequent　　　｜｜　（2回続けて出なかった。印が2つ）
```

### 次の周は、印があるものだけ

2周目は、印がついているものだけをやります。3周目は、印が2つ以上のものだけ。

これで何が起きるか。

```
　　1回で入ったもの　　→　2周目から出てこない　→　勝手に、間が空く
　　8回かかるもの　　　→　毎周出てくる　　　　→　勝手に、間がつまる
```

==日にちを決めていないのに、ちょうどいい間が空きます。==しかも、単語1個ごとに、その単語に合った間になります。日付で決めるやり方には、これができません。

### やる量は、周ごとに減っていきます

```
　　1周目　500語　　60分
　　2周目　180語　　20分
　　3周目　 60語　　 7分
　　4周目　 20語　　 3分
```

出せた単語は、次の周には出てきません。だから、その単語との間は、自然に空いていきます。出せなかった単語だけが、すぐにもう一度出てきます。==日付を書かなくても、間は勝手に空きます。==

### 学校のスケジュールを、そのまま使う

もう1つ、作らなくていい理由があります。間隔は、学校がすでに組んでいます。

```
　　授業　→　小テスト　→　定期テスト　→　模試　→　入試
　　　　　　（数日後）　　（1〜2ヶ月後）　（数ヶ月後）
```

自分で作るどんな予定表より正確に並んでいて、しかも勝手にやってきます。
==自分で、もう1つ予定表を作る必要はありません。学校の予定を、まだ使っていないだけです。==
ここは、05番と09番に書きました。

## もう忘れてしまった人へ

いま読んでいる人の中には、すでに忘れてしまった人もいると思います。その場合も、1からやり直さないでください。まず、どれくらい残っているかを数えます。50個だけテストして、何個出るかを見ます。6割出たなら、6割は残っています。残りの4割だけやれば、戻ります。全部忘れた、という感覚は、たいてい大げさです。

## やり方

### STEP 01　覚えたものは、次の日に1回、閉じて出す

日付で決めるのは、この1回だけです。今日やったものを、明日やる。カレンダーは要りません。

### STEP 02　出なかったものにだけ、印を1つつける

出たものには、何もしません。2回続けて出なかったら、印は2つになります。

### STEP 03　次の周は、印があるものだけ。その次は、印が2つ以上のものだけをやる

回を追うごとに、量が減ります。量が減るので、次の周までの間が、勝手に空いていきます。日付は、書きません。

　　「できた」の基準　　印のついたものが、何も見ずに出せた。周を重ねても、印が増えなくなった。

## これをやると、何が残るか

同じ500語を、およそ半分の量で、覚えたままにできます。忘れてから覚え直す人は、500語を3回やります。忘れる前に出す人は、500語を1回と、180語、60語、20語です。合計で、760語ぶんです。1500語ぶんやった人より、少ない。そして、残っている量は多いです。

巻頭の「復習を、ちゃんとやってるだけ」の"ちゃんと"は、これです。全部をもう一度やるのではありません。出なかったものにだけ印をつけて、印があるものだけを、間をあけて、もう一度出す。

## この場面のまとめ

忘れるのは全員に起きる。できる人は、忘れる前に1回出している。日付で決めるやり方は、続かない。出なかったものに印をつけて、印があるものだけ次に回す。

今日やること　今日覚えたものを、明日もう一度、閉じて出す。出なかったものにだけ印をつける。次は、印があるものだけやる。
