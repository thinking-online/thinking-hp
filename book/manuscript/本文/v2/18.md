英単語のテスト形式で、復習しています。

　　available

意味が出てきません。

1秒で、ページをめくって答えを見ます。

　　「利用できる、か」

次の単語に行きます。

　　consist

出てきません。1秒でめくります。30語、こうやって流しました。5分で終わりました。速いです。次の日、同じ30語をやります。同じところで、同じように出てきません。

## すぐ見るのは、半分だけ正しいです

長く考え込むのは、時間の無駄です。これは、本当です。わからない単語を3分考えても、出てきません。知らないものは、考えても出ません。だから、すぐ見るという判断には、根拠があります。問題は、1秒だということです。

## 10秒が、分かれ目です

出てこないとき、頭の中では探しています。その単語を見たときの、ページの位置。隣に書いてあった単語。一緒に覚えた例文。似た形の別の単語。いろいろな方向から、取りに行っています。この「取りに行く」が、思い出す練習です。1秒でめくると、取りに行く前に終わります。練習になっていません。10秒やると、取りに行く動きが入ります。出てこなくても、入ります。出てこなかったあとに見た答えは、残りやすくなります。探して見つからなかった場所に、答えが置かれるからです。

## 粘ってはいけないのも、本当です

10秒を超えたら、見てください。30秒考えても、1分考えても、結果は同じです。知らないものは出てきません。そして、1問に1分かけると、30語で30分かかります。時間が足りなくなります。10秒です。ここは、数えてください。

## 2つの実験が、逆のことを言っているように見えます

ここは、言っていることが割れている場所です。聞いたことがあるかもしれないので、両方書きます。

ロンドンの大学の実験です。知らない言葉の意味を、覚えてもらいます。片方のグループには、最初から正解を見せます。もう片方には、まず当てずっぽうで答えさせます。知らない言葉なので、当然はずれます。はずしたあとで、正解を見せます。あとのテストで成績がよかったのは、==はずしたほうでした。==

オーストラリアの大学の実験は、逆のことを言っています。図形の問題を使いました。片方のグループには、解き方の見本を先に見せます。もう片方には、自力で解かせます。あとのテストで成績がよかったのは、==見本を先に見たほうでした。==

どちらも本当です。見ているものが、違います。

## 違いは、かけた時間です

はずしてから見た実験で、当てずっぽうに使った時間は、数秒です。
見本を先に見た実験で、自力で解こうとした時間は、数十分です。

```
　　数秒　考えてから見る　　→　残る
　　数十分　考えてから見る　→　残らない
```

つまり2つの実験は、どちらも==「長く粘るな」と言っています。==
片方が「でも0秒はもったいない」、もう片方が「30分はやりすぎ」と言っているだけです。

だから、10秒なのです。

## もう1つ、見落としやすい違いがあります

見本を先に見たほうが強かったのは、==その単元を初めてやる人==のときです。

同じ流れの研究で、続きがわかっています。ある程度できるようになった人では、逆になります。見本を見るより、自力で解いたほうが伸びます。見本が、じゃまになるからです。

だから、1周目と3周目で、やることが逆になります。

```
　　1周目　見たことのない型　→　先に解答を見て、閉じて再現する
　　3周目　知っている型　　　→　先に自力で解く。10分やる
```

同じ問題集を、同じ人が、逆のやり方で回します。
「答えは先に見るべきか」に、1つの答えがないのは、これが理由です。

## 2つの実験が、1つだけ同じことを言っています

はずしてから見る実験では、はずしたあとに==必ず正解を見せています。==
見本を先に見る実験では、見本のあとに==必ず自分で解かせています。==

```
　　争点は「見る前に、考えるかどうか」ではありません。
　　どちらも「見たあと、閉じて出したか」で差がついています。
```

考える時間を長くしても、残る量は増えません。
増えるのは、==見たあとに自分で出した回数==のほうです。

## 数学の問題だと、時間が変わります

単語は10秒ですが、数学の問題は違います。数学の場合は、こう判定します。方針が立たない　→　3分で見る方針は立つが、計算で詰まった　→　10分やる方針というのは、「何をすればいいか」です。何をすればいいかがわからないときは、考えても出ません。3分で見ます。何をすればいいかはわかっていて、計算の途中で詰まったときは、やればできます。ここは粘る価値があります。

## 3分のあいだに、やることがあります

数学で、方針が立たないときは3分と書きました。では、その3分で何をするか。ここが分かれ目です。高校1年生。見たことのない形の問題に出会いました。考えます。5分、何も浮かびません。10分、まだ浮かびません。30分たって、解けませんでした。その30分で、解いた問題は0問です。考えること自体は、大事です。すぐ答えを見る人より、考える人のほうが伸びます。問題は、考え方です。ゼロから考える、というのが、何をしているのか。まったく新しい方法を、自分で発明しようとしています。数学は、何百年もかけて作られてきた分野です。30分で新しい方法を発明できる可能性は、高くありません。そして、試験に出る問題は、全部どこかで見た形です。出す側は、習っていないことを出せません。だから、習った型の組み合わせになります。見たことがない、と感じる問題も、よく見ると、知っている型が2つ組み合わさっているだけです。だから、3分でやるのは、発明ではありません。

　　知っている型の、どれに似ているか。

探し方は3つです。形を見る。2乗がある、分数がある、円と直線が接している。この形を前にどこで見たかを探します。数字を見る。3、4、5が出てきたら直角三角形かもしれません。60度なら、正三角形か30-60-90かもしれません。聞かれ方を見る。「最大値を求めよ」ならやることは限られています。「〜であることを示せ」なら、証明の型があります。そのために、準備が1つ要ります。単元ごとに、「この形が出たら、この3つを試す」を紙に書いておきます。

```
　　2乗が出たら　　　平方完成／因数分解／置きかえ
　　分数式が出たら　　通分／部分分数分解
　　図形で角度なら　　平行線／円周角／外角
```

このリストがない人は、探しようがありません。だから、ゼロから考えるしかなくなります。リストがある人は、上から順に試します。考えるのではなく、手を動かして、違ったら次に行きます。解けた問題が増えるたびに、リストに1行足します。初見に強いというのは、発想力がある、という意味ではありません。当てる候補をたくさん持っている、という意味です。

## 頭のなか

### 同じとき、頭のいい人

「available ……」「出てこない。ちょっと待て」「どこで見た? 単語帳の右ページの上のほうだった気がする」「隣に avoid があった」「……ability と似てる。できる、って意味が入ってる?」「利用……できる?」（めくる）「利用できる。合ってた」10秒です。しかも、最後に自分で取りに行って、当たっています。これは、次に出てくる確率が、かなり上がっています。

## やり方

### STEP 01　解く前に、考える時間の上限を決める

```
　　単語や用語が出てこない　　　　　　　　10秒
　　数学で、方針が立たない　　　　　　　　 3分
　　方針は立ったが、計算で詰まった　　　　10分
```

わかるまで、ではありません。時間で決めます。

### STEP 02　上限が来るまでは、ぼんやり待たずに、取りに行く

単語なら、どこで見たか。隣に何があったか。似た言葉はないか。最初の1文字は何だったか。数学なら、知っている型のどれに似ているか。0秒で見るのは、もったいないです。出てこなくても、探したあとに見た答えは残ります。

### STEP 03　上限が来たら、見る。見たら閉じて、もう1回、自分で出す

粘りません。見ます。ただし、見て終わりにしません。閉じて、いま見た答えや解き方を、もう一度自分で出します。これで1周です。

　　「できた」の基準　　答えを見た問題を、その場で、閉じて自分で出せた。次の日にも、出せた。

## これをやると、何が残るか

同じ30分で、残る量が変わります。1秒でめくる人は、30語を5分で6周できます。でも、6周とも思い出していないので、次の日に出ません。10秒待つ人は、30語を15分で2周します。2周とも思い出しているので、次の日に出ます。周回数は3分の1です。残る量は、多いです。

## この場面のまとめ

すぐ見るのは半分正しい。長く粘るのは無駄。ただし1秒では、取りに行く前に終わっている。10秒だけ探す。

今日やること　今日、出てこなかったものが1つあったら、10秒数えてから答えを見る。見たあと、閉じてもう一度出す。
