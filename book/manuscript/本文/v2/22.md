数学の問題を解いています。手は止まっています。頭の中では考えています。3分たちました。まだ1行も書いていません。どこで止まったのかも、よくわかりません。

## 頭の中で考えるのは、ふつうのことです

声を出しながら勉強する人のほうが、少ないです。自習室では出せません。家でも、家族がいると出しにくい。ただ、頭の中だけで考えていると、自分がいま何を考えているのかが、自分でもはっきりしません。考えているのか、止まっているのか、わからない。3分たって気づく。これが、頭の中だけで追ったときに起きることです。

## 声に出すと、止まった場所がわかります

この本では、ここまで何度も、頭のいい人の頭のなかを見せてきました。

```
　　「なるほど。……いや待て。いま読んだだけだ」
　　「出た。でも、何秒かかった？」
　　「1行目はわかる。2行目もわかる。3行目で止まった」
```

あれを、自分でやります。

口に出すと、考えていることが、音になって自分の耳に入ります。耳に入ると、どこで止まったかがわかります。

## 頭のなか

### 止まったとき、伸びない人

```
　　（無言）
　　（3分）
　　「……わかんない」
```

### 同じとき、頭のいい人

```
　　「この問題は、三角形の面積を出す」
　　「底辺は……わかってる。6」
　　「高さは……書いてない」
　　「高さを出すには……あ、垂線を引くのか」
　　（手が動く）
```

20秒です。

---

違いは、1か所です。

考えていることを、自分の耳に入れた。

```
　　　　　　　いま、何をやってるか、言ってみて
```

口に出すと、「高さは書いてない」のところで、必ず引っかかります。頭の中だけだと、そこを素通りします。

## やり方

### STEP 01　手が止まったら、小声で実況する

「この問題は、何を出す問題か」から言います。20秒でいいです。声が出せない場所では、口だけ動かします。

### STEP 02　言えなくなったところで止まって、そこに印をつける

そこが、わからないところです。頭の中だけで追っていると、ここを通りすぎてしまいます。

### STEP 03　解き終わったら、最初から最後まで、止まらずに実況し直す

解説を読んで「なるほど」と思ったあとも、同じです。解説を閉じて、解き方を声で言います。最初は、自分の声が気持ち悪いです。3回目で慣れます。

　　「できた」の基準　　解き方を、最初から最後まで、何も見ずに、止まらずに声で言えた。

## 4つ以上出てきたら、手を動かします

声と同じで、もう1つ、頭の外に出すものがあります。

中学2年生。数学の文章題です。

　　「AさんはBさんより3歳年上で、CさんはAさんより5歳年下。3人の年齢の合計は46歳。Bさんは何歳か。」

頭の中で考えます。AがBより3つ上。CがAより5つ下。ということは、CはBより……えーと。もう一度、問題を読みます。ここまで来るのに、3回読み直しました。

人が頭の中で同時に持っておけるものの数には、限りがあります。3つくらいまでは、頭の中で動かせます。4つになると、1つ目を思い出している間に、3つ目が消えます。

この問題には、3人います。関係が2つあります。合計が1つ。6つです。頭の中では、動かせません。だから、読み直すことになります。読み直すたびに、前に考えたことが消えているからです。

```
　　A = B + 3
　　C = A - 5
　　A + B + C = 46
```

3行書くのに、20秒です。この3行を書いたら、もう迷うところはありません。あとは代入するだけです。書くのは、面倒です。ここはごまかしません。でも、頭の中でやろうとして3回読み直した時間と、3行書く20秒を比べてください。面倒なのは、最初の20秒だけです。

```
　1　文章題を読んだら、出てきたものを数える
　2　4つ以上なら、考える前に手を動かす
　　　書くかどうかで迷わない。数えて4つ以上なら、必ず書く
　3　書き方は何でもいい
　　　数学なら式か図。理科なら装置の絵。社会の年号なら横1本の線に点
```

計算が速い人を見て、頭の中で全部やっていると思うかもしれません。逆です。できる人ほど、早く書きます。頭の中は、考えるために空けておくものだと知っているからです。覚えておくために使うと、考える余地がなくなります。

## 残るもの

```
　　頭の中は、自分にも見えない。
　　口に出すと、自分で聞ける。
```
