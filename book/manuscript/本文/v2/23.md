参考書を1周しました。

2周目に入るべきか、次の参考書に行くべきか、分かりません。1周目で解けた問題もあります。でも、それが「いま解ける」かどうかは分かりません。解説を見ながら解いた問題もあります。それを○にしていいのかも分かりません。迷ったすえに、最初から全部やり直すことにしました。2周目が終わりました。また同じことを考えます。3周目に入りました。半年たって、その参考書の1章から3章だけが、やたら詳しくなっています。

## 基準がないと、終われません

これが、いちばん多い相談です。

```
　　「参考書って何周すればいいんですか」
　　「どこまでできたら次に行っていいのか教えてほしいです」
　　「一回全問正解できたから次に行っていいのか、不安です」
```

全部、同じことを聞いています。==終わっていいかどうかの条件を、誰も教えてくれない。==条件がないと、人は安全側に倒します。安全側というのは「もう1周する」です。もう1周して悪くなることはないからです。でも、もう1周したぶんの時間は、ほかのものに使えたはずの時間です。

## 「完璧になってから次」は、永久に来ません

よく聞く言い方があります。

　　完璧にしてから、次に行く。

これは、一見まともに聞こえます。でも、==完璧の定義がどこにもありません。==定義がないものには、到達したかどうかを判定できません。判定できないので、終われません。終われないので、進みません。「完璧主義だから進めない」のではありません。==基準がないから進めない==んです。性格の問題ではないので、直せます。

## 基準は、3つでできています

やることは1つです。参考書を開く前に、次に行く条件を1行で書きます。条件は、必ずこの3つでできています。

```
　　1　何を　　　　　　どの問題を
　　2　どんな条件で　　何も見ずに／時間内に
　　3　どれだけ　　　　何問中、何問
```

3つそろって、はじめて判定できます。

```
　　×　「この章を理解する」　　　　　　　判定できない
　　×　「ちゃんとできるようにする」　　　判定できない
　　○　「章末問題10問を、解説を見ずに、8問正解」　判定できる
```

1行です。参考書の表紙の裏に書いて、見える場所に置いておきます。

## なぜ8割なのか

10割にしないでください。理由が2つあります。1つ目。10問中10問を基準にすると、==たまたま落とした1問で止まります。== その1問のために、もう1周することになります。2つ目。残りの2割は、次の段階で拾えます。基本の参考書で取りこぼした2割は、その次の演習で何度も出てきます。そこで拾うほうが速いです。8割というのは、「完璧ではないが、次に行っても困らない」という線です。

## 段階で、基準が変わります

同じ8割ではありません。どの段階かで変わります。

```
　　初めて習う単元　　→　6割で次へ
　　　　　　　　　　　　　1周目は、どこが分からないかを探す周。
　　　　　　　　　　　　　分からない場所が分かれば、1周目の仕事は終わり

　　2周目　　　　　　→　8割で次へ
　　　　　　　　　　　　　ここで、できる状態を作る

　　試験前の最終確認　→　10割
　　　　　　　　　　　　　ただし、範囲を絞ったぶんだけ。
　　　　　　　　　　　　　全範囲で10割は、誰にもできない
```

1周目から8割を取ろうとするのが、いちばん時間がかかるやり方です。

「1周終わった」「最初に書いた条件、なんだっけ」（表紙の裏を見る）「『章末10問を見ずに8問』か」（章末10問を解く）「7問。1問足りない」「落としたのは……3章の、場合分けのところ」「この1問だけやる。全部やり直さない」（3章の場合分けだけ30分）「もう一度10問。9問。よし、次へ」1周のあと、やり直したのは1か所だけです。

## やり方

### STEP 01　本を開く前に、次へ進む条件を1行書いて、目に入る場所に置く

「章末問題10問を、解説を見ずに、8問正解したら次へ」。何を、どんな条件で、どれだけ。この3つを入れます。やりながら決めると、都合のいい基準になります。置く場所は、表紙の裏か、しおりです。

### STEP 02　条件を満たしたら、不安でも、次へ進む

ここが、いちばんむずかしいところです。8問取れても、不安は残ります。それでも進みます。不安で止まると、条件を作った意味がなくなります。

### STEP 03　満たさなかったら、落とした問題の原因だけ直して、もう一度測る

全部はやり直しません。落とした2問の原因だけです。24番のやり方で、原因を見つけてから戻ります。

　　「できた」の基準　　開く前に書いた1行のとおりに、進むか、戻るかを決めた。

## 条件を満たしたのに、次でつまずいたら

起きます。そのときは、条件が甘かったということです。そのまま戻らないでください。==条件を1段きつくして、次から使います。==

```
　　「8問正解」　→　「8問正解。かつ、各問で使った公式を言える」
```

戻るのではなく、基準を上げます。前に進みながら直ります。

## これをやると、何が残るか

参考書が、終わります。

基準がない人の参考書は、終わりません。1章から3章だけが詳しくなって、後半が白いまま次の年になります。基準がある人は、1冊が終わります。終わった1冊は、次の1冊の土台になります。==04番で書いたとおり、終わらせた1冊だけが点になります。==

巻頭の「基礎を、ちゃんと固めただけ」の"ちゃんと"も、中身はこれです。何を、どんな条件で、どれだけできたら「固まった」と言うのか。それを、始める前に決めてある。決めていないと、いつまでも固まった気がしないか、固まっていないのに先へ進むか、どちらかになります。

## この場面のまとめ

基準がないと、終われない。終われないから、安全側に倒して全部やり直す。基準は「何を・どんな条件で・どれだけ」の3つ。1周目は6割、2周目は8割。
