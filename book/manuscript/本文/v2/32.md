評判のいい参考書を、買いました。先輩が「これで受かった」と言っていた、分厚い1冊です。

開いてみると、むずかしい。1ページ進むのに、30分かかります。3週間たって、まだ20ページです。

　　「せっかく買ったし」
　　「ここまでやったし」
　　「最後までやり切らないと、意味がない」

4週目も、同じ1冊を開きます。

## つまらない映画を、最後まで見ますか

映画館に入りました。始まって30分で、つまらないとわかりました。

最後まで見ますか。

「チケット代がもったいないから」と、最後まで見る人が多いです。でも、考えてみてください。チケット代は、途中で出ても、最後まで見ても、戻ってきません。

```
　　最後まで見る　→　チケット代は戻らない。残りの1時間半も、失う
　　途中で出る　　→　チケット代は戻らない。残りの1時間半は、使える
```

もう払ったものは、どちらを選んでも同じです。ちがうのは、==これからの時間==だけです。

なのに人は、「ここまで払ったから」を理由に、これからの時間まで払ってしまいます。参考書も、同じです。使った3週間は、やめても続けても、戻りません。

## 見るのは、「これまで」ではなく「これから」です

聞く質問を、1つ変えます。

```
　　×　ここまで、どれだけやったか
　　○　いまから新しく選ぶとしても、これを選ぶか
```

答えが「選ばない」なら、続ける理由は、もう残っていません。

そして、もう1つ見るものがあります。==その時間で、ほかに何ができたか==です。合わない1冊に、あと30時間使う。その30時間で、合う1冊なら、何ページ進んだでしょうか。合わないものを続けるというのは、もっといいものに使えたはずの時間を、毎日失っているということです。

## 「やめる」と「逃げる」は、ちがいます

「一度決めたことは、最後までやりなさい」。そう言われて育った人は、やめることに罪悪感があります。

やり抜くのは、大事です。ただ、やり抜く価値があるのは、==方向が合っているとき==だけです。合っていない方向に、最後まで進むのは、やり抜くではありません。止まれなかった、だけです。

```
　　逃げる　　　　　しんどいから、やめる
　　方向を変える　　ここでは届かないとわかったから、変える
```

見分け方は、1つです。==やめたあとに、やることが決まっているかどうか。==次の1冊が決まっていて、そっちのほうが届くと言えるなら、それは逃げではありません。

## ただし、乗りかえ続けるのは、もっと損です

逆の失敗もあります。少しむずかしいとすぐ変える。3冊、5冊と手を出して、全部が途中。04番で見たとおり、途中の5冊は、0点です。

だから、変えるときの決まりを、先に作っておきます。

```
　　2週間は、やってみる
　　10問中、ほとんど全部で手が止まるなら、いまの自分には重すぎる　→　変える
　　10問中、2〜4問で止まるなら、合っている　→　しんどくても、続ける
```

03番の目安と同じです。しんどいから変える、ではありません。==重すぎて、何も残っていないから変える==んです。

## 参考書だけの話では、ありません

通っているのに、成績が変わらない塾。「ここまで目指してきたんだから」と、変えられない勉強の方針。

どれも、同じ形をしています。「これまで」を理由に、「これから」を払い続けている。

大きなことは、ひとりで決めなくていいです。家の人や、先生と話してください。ただ、話すときの質問は同じです。==いまから新しく選ぶとしても、これを選ぶか。==

## 頭のなか

### 合わない参考書の4週目、伸びない人

「せっかく買ったし」「先輩はこれで受かったって言ってたし」「ここでやめたら、3週間が無駄になる」（5週目も、1日1ページ）

### 同じとき、頭のいい人

「3週間で20ページ。10問中、9問で止まってる」「重すぎるな。いまの自分には、まだ早い」「いまから選ぶなら、これは選ばない」「1つ手前のレベルに変える。そっちを終わらせてから、戻ってくる」

## やり方

### 1　「いまから新しく選ぶとしても、これを選ぶか」と聞く

使ったお金と時間は、いったん横に置きます。今日がはじめての日だとして、選ぶかどうかです。

### 2　続ける場合と、変える場合を、紙に並べる

それぞれ、1か月後にどこまで進んでいるかを書きます。頭の中で比べると、「もったいない」が勝ちます。紙に書くと、数字で比べられます。

### 3　変えるなら、次の1冊を決めてから、やめる

先にやめません。次を決めて、それから変えます。そして、変えた1冊は、最後までやります。

## これをやると、何が残るか

合わないものに使っていた時間が、戻ってきます。そして、「せっかく」で決める癖がなくなります。この先、勉強以外のことを決めるときにも、同じ質問が使えます。

## この場面のまとめ

もう使ったものは、続けてもやめても戻らない。見るのは、これまでではなく、これから。変えるなら、次を決めてから。

今日やること　いま使っている教材を1つ選んで、「いまから新しく選ぶとしても、これを選ぶか」と聞いてみる。
