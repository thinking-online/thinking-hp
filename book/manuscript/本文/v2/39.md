## 覚えたものは、寝ているあいだに固まります

ここは、知っておいてください。昼に覚えたことは、その時点ではまだ不安定です。寝ているあいだに、頭の中で整理されて、固まります。寝ないと、この作業が起きません。つまり、夜中の2時間で覚えたことは、寝ていないので、固まらないまま朝を迎えます。2時間ぶん覚えたつもりで、ほとんど残っていません。単語を覚えたあと、そのまま寝たグループと、同じ時間ずっと起きていたグループを比べた実験があります。あとで思い出せた量は、==寝たグループのほうが多くなりました。==覚えてから寝るまでの時間が短いほど、残る量が多いことも分かっています。寝る直前にやった暗記が残りやすいのは、このためです。

## 寝不足は、思い出す力も下げます

もう1つあります。

寝不足のとき、頭の働きが落ちます。とくに落ちるのが、取り出す力です。覚えているはずのことが、出てこなくなります。テストでやるのは、取り出す作業です。いちばん落ちているところを、本番で使うことになります。

## 削った2時間と、落ちた分を比べます

計算してみます。

3日間で、6時間増やしました。仮に、6時間で30個覚えたとします。寝ていないので、そのうち残るのは、半分以下かもしれません。15個です。一方、寝不足で、取り出す力が1割落ちたとします。1年かけて覚えた1000個のうち、100個が出にくくなります。15個取って、100個を落としています。

## どうしても時間が足りないとき

足りないことは、あります。そのときは、削る順番があります。

```
1　まず、やることを減らす（捨てる）
2　次に、スマホの時間を削る
3　最後に、どうしてもなら、睡眠
```

睡眠は、いちばん最後です。そして、削るとしても、1時間までにしてください。2時間を超えると、はっきり落ちます。

## 前日だけは、絶対に削らない

テストの前日だけは、どんな状況でも削らないでください。前日の夜に覚えたことは、たいした量ではありません。前日の寝不足で落ちる分のほうが、はるかに大きいです。前日は、いつもより30分早く寝るくらいでちょうどいいです。

## 「受験生なら、1日○時間」は、気にしなくていいです

時間が足りないと感じたとき、まず睡眠を削る人が多いです。「受験生なら10時間はやらないと」という声も、聞こえてきます。

数え方を、変えてください。

24時間から、先に引くものがあります。睡眠の7時間。食事。お風呂と身じたく。学校。これは、動かせない時間です。==引いたあとに残ったものが、あなたの「使える時間」==です。

```
　　×　今日、何時間やったか
　　○　使える時間のうち、どれだけを勉強に使えたか
```

部活がある人と、ない人では、使える時間がちがいます。だから、「1日○時間」を人と比べても、意味がありません。比べるなら、自分の使える時間のうち、何割使えたか。削るのは、睡眠ではなく、使える時間の中の、何もしていない時間です。

## 昼に眠くなったら、15分だけ寝ます

夜はしっかり寝る。そのうえで、昼に眠くなったときは、がまんしないでください。眠いまま1時間座っているより、15分寝て、45分やるほうが進みます。

```
　　長さ　　15分から20分まで。30分をこえると、深く眠ってしまって、起きたあとに頭がぼんやりする

　　時間帯　午後3時まで。夕方に寝ると、夜に眠れなくなる
```

タイマーをかけて、寝ます。眠れなくても、目を閉じているだけでいいです。
