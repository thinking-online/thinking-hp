## 不安は、いま答えが出ない問いです

ここが、いちばん大事なところです。「このやり方で合ってるのか」という問いに、いま答えは出ません。やってみて、テストを受けて、点を見るまで出ないからです。出ないものを考え続けると、==考えるだけで終わります。==そして、考えているあいだは勉強している感じがします。真剣だからです。だから、止まっていることに気づけません。

```
　　答えが出る問い　　「この問題の答えは?」　　　→　解けば出る
　　答えが出ない問い　「このやり方は正しい?」　  →　やってみるまで出ない
```

下の問いを机の前でぐるぐる考えていると、時間だけが減ります。

## 不安が強い人ほど、まじめです

先に言っておきます。

サボっている人は、不安になりません。やり方が合っているか気になるのは、結果を出したいからです。そして、ここまで気にする人は、実際にちゃんとやっています。==不安は、手を抜いていない証拠です。== ただ、頭の中に置いたままなのが、よくないだけです。

## 「考えないようにしよう」は、効きません

46番でも書きます。白いクマのことを考えないでください、と言われると、白いクマのことを考えます。不安も同じで、考えないようにするほど、そのことを考え続けます。消そうとするのではなく、==置く場所を変えます。==頭の中から、紙の上へ。

## 紙に出して、10分だけ手を動かす

やることは、これだけです。

```
　1　紙を1枚出して、いま不安なことを全部書く　　　　5分
　　　きれいに書かない。文にならなくていい

　2　書いたら、その紙を裏返す
　　　見返さない。捨ててもいい

　3　タイマーを10分にして、いちばん軽いものを1つやる
　　　単語10個。計算3問。漢字10個

　4　10分たったら、もう一度その紙を見る
```

4が大事です。

10分前に書いた不安を見ると、==大きさが変わっています。== 気のせいではありません。理由があります。手を動かす前は、やることが「全部」残っています。10分やったあとは、「残り」になっています。10分ぶんだけ、減っています。そして、減ることがわかると、次の10分に入れます。

## 不安の種類で、やることが変わります

書き出した紙を見ると、3つに分かれます。

```
　1　やり方が合っているか不安
　　　　→　10分やって、閉じて出せたかを見る。出せたら合っている

　2　間に合うか不安
　　　　→　数字にする。あと何週間、1週間に何点

　3　落ちたらどうしようと不安
　　　　→　これは答えが出ない。書き出して、裏返す
```

1と2は、手を動かすと答えが出ます。3は、出ません。3を1や2と同じように考え続けるから、終わらなくなります。==3は、解決するものではなく、置いておくものです。==
