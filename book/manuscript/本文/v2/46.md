試験開始の15分前。席に座っています。参考書を開いていますが、頭に入ってきません。目は字を追っていますが、別のことを考えています。落ちたらどうしよう。あの単元、やってない。周りの人、みんなできそうに見える。考えないようにしよう、と思います。思ったとたん、もっと考えます。

## 考えないようにするのは、いちばん効きません

「考えないようにしよう」は、考えることと同じです。白いクマのことを考えないでください、と言われると、白いクマのことを考えます。不安も同じです。考えないようにするほど、そのことを考え続けます。

## 不安は、頭の作業場をふさぎます

試験中、頭の中には作業するための場所があります。計算を途中まで置いておいたり、問題文を覚えておいたりする場所です。その場所は、広くありません。不安が大きいとき、その場所の一部を不安が使っています。だから、ふだんできる計算でミスをします。能力が下がったのではなく、場所が狭くなっています。

## 10分前に、紙に出します

やることは、これだけです。

```
　　試験開始の10分前。
　　紙を1枚出して、いま不安に思っていることを、全部書く。
　　5分。きれいに書かなくていい。文にならなくていい。
```

```
　　・数学の図形、やってない
　　・時間が足りなくなりそう
　　・親に何て言おう
　　・前の席の人がペン回ししててうざい
```

書いたら、その紙は裏返します。見返さなくていいです。捨ててもいいです。書き出すと、頭の中にあったものが、紙の上に移ります。移った分だけ、作業場が空きます。

## これは、効果が確かめられています

シカゴ大学の実験です。試験の直前に10分だけ、いま不安に思っていることを紙に書き出してもらったグループと、関係のないことを書いたグループで、試験の点を比べました。==書き出したグループのほうが、点が高くなりました。==差がいちばん大きかったのは、ふだんから試験で不安が強くなる学生でした。不安が強い人ほど、効きます。

## 書くのは「対策」ではありません

ここで「じゃあ図形を10分でやろう」としないでください。10分で図形はできません。できないことを始めると、不安が増えます。書くのは、不安そのものです。解決策ではありません。

## 書いたあと、1つだけやることがあります

紙を裏返したら、最後に1つ書きます。

```
　　今日、確実に取れるのは、どこか
```

1つでいいです。「漢字の読み」でも「英語の並べかえ」でもいいです。試験が始まったら、まずそこから解きます。（解く順番は、47番でくわしく書きます）

## 心臓が速いのは、止めなくていいです

紙を裏返したあと、まだ心臓が速いことがあります。手が冷たくて、息が浅い。落ち着け、落ち着け、と心の中で言います。言うたびに、落ち着いていない自分に気づきます。余計に焦ります。落ち着こうとしても、すぐには落ち着けません。いまの体は、心拍数が上がっています。落ち着くというのは、心拍数を下げるということです。上がっているものを、1分で下げるのは無理があります。無理なことをやろうとして、できなくて、焦る。焦るので、もっと上がる。ここで知っておいてほしいことがあります。

```
　　緊張　　心臓が速い　手が冷たい　息が浅い　体が熱い
　　興奮　　心臓が速い　手が冷たい　息が浅い　体が熱い
```

体に起きていることは、同じです。違うのは、それを自分が何と呼んでいるかだけです。

```
　　「やばい、緊張してる」　　→　体は敵
　　「よし、来てる」　　　　　→　体は味方
```

だから、落ち着こうとするかわりに、こう言います。

```
　　これは興奮だ。
　　体が、本気を出す準備をしている。
```

声に出さなくていいです。心の中で3回。心拍数は下がりません。下げる必要がありません。心拍数が上がっているほうが、頭は速く回ります。変えるのは、体ではなく、呼び方です。1秒でできます。息が苦しいときだけ、もう1つあります。吐くほうを長くします。4秒で吸って、8秒で吐く。これを3回。心臓は、吸うときに速くなり、吐くときに遅くなります。だから、吐くほうを長くすると、全体がゆっくりになります。心臓が速いだけなら、そのままでいいです。言いかえは、会場に着く前から使えます。電車でそわそわする。手が冷たい。開始1分前。全部「来てる」です。1日に10回使うと、本番の1回で自然に出ます。

## 始める前の動作を、決めておきます

もう1つ、本番の前にできることがあります。

スポーツの選手が、試合の前に、毎回同じ動作をするのを見たことがあると思います。同じ順番で、同じことをする。あれは、おまじないではありません。==「いつもと同じだ」と、体に知らせている==んです。

試験でも、同じことができます。

```
　　席に着いたら、筆箱を右に置く
　　鉛筆を2本、消しゴムを1つ、並べる
　　息を、長く1回はく
　　「よし、来てる」と、心の中で言う
```

中身は、何でもいいです。大事なのは、ふだんの勉強を始めるときにも、同じ動作をしておくことです。毎日、同じ動作をしてから勉強を始める。本番の席で同じ動作をすると、体は、いつもの勉強と同じように動き始めます。

本番だけ特別なことをしようとすると、いつもとちがう、と体が気づきます。==本番を、いつもの続きにしておく==んです。

## やり方

### STEP 01　開始の10分前に、教材を閉じる

ここで閉じられるかどうかが、いちばん大事です。不安なときほど開いていたくなりますが、開いていると、知らないものが見つかります。

### STEP 02　紙に、いま思っていることを5分で書いて、裏返す。最後に1行、「今日、確実に取れるのはどこか」を書く

きれいに書きません。文にならなくていいです。最後の1行は、1つでいいです。試験が始まったら、まずそこから解きます。

### STEP 03　心臓が速いままなら、「よし、来てる」と心の中で3回言って、いつもの動作をする

落ち着こうとしません。体が、本気を出す準備をしています。筆箱を置く、息を1回長くはく。ふだんの勉強の前と、同じ動作をします。

　　「できた」の基準　　開始の合図の前に、教材が閉じてあって、最初に解く問題が決まっている。
