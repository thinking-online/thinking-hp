## 解く順番は、2つに分けます

問題は、2種類あります。

```
A　知っているかどうかで決まる問題　　知っていれば、すぐ終わる
B　考えないと解けない問題　　　　　　時間が読めない
```

Aから先に、全部片づけます。そのあとに、Bをやります。

理由は単純です。

Aは、時間が読めます。5分と見積もれば、5分で終わります。Bは、読めません。5分かもしれないし、20分かもしれません。読めるものを先に終わらせて、残り時間を全部Bに使う。これが、いちばん取りこぼしが少なくなります。

## 逆だと、こうなります

Bから始めると、Bに時間を吸われます。そして、確実に取れたAが、時間切れで落ちます。落としたのは、できない問題ではありません。できる問題です。

## 途中で、頭が真っ白になったら

解いている途中で、急に何も出てこなくなることがあります。さっきまで覚えていたはずの公式が、出てこない。問題文を読んでも、頭に入ってこない。

まず、知っておいてください。==覚えたものが、消えたわけではありません。==

46番で書いたとおり、不安が大きくなると、頭の作業場がふさがります。ふさがっているあいだ、取り出せないだけです。消えていないので、戻ってきます。

やることは、3つです。

```
　　① 鉛筆を置く。4秒で吸って、8秒ではく。これを3回　　　30秒
　　② その問題から離れて、Aの問題を1つ解く　　　　　　　 手が動くと、頭が戻ってくる
　　③ 真っ白になった問題には、最後に戻る
```

いちばんやってはいけないのは、その問題をにらみ続けることです。にらんでいるあいだ、不安はふくらみ続けます。==離れて、手が動く問題を1つ解く。==それで、戻ってくることが多いです。

30秒は、長く感じます。でも、真っ白のまま5分にらむより、30秒休んで、戻ってきた頭で解くほうが、点になります。

## 後回しにしたほうも、白紙では出しません

Aを全部終わらせて、Bに入りました。残り時間で、Bが最後まで解けないことがあります。そのとき、白紙で出さないでください。数学のテスト。大問4、証明問題です。読みます。難しそうです。最後まで解ける気がしません。飛ばしました。答案が返ってきます。大問4は0点です。配点は12点でした。隣の席の子は、同じ問題で5点取っていました。最後まで解けていません。途中までしか書いていません。それでも、5点入っていました。記述問題には、部分点があります。答えが合っているかどうかだけで、点が決まるのではありません。証明問題なら、こうなっていることが多いです。

```
　　仮定を正しく書いた　　　　2点
　　使う定理を正しく選んだ　　3点
　　途中の式変形が正しい　　　4点
　　結論まで到達した　　　　　3点
```

最後まで行けなくても、前半の5点は取れます。白紙に書き込める点数は、0点だけです。何も書かなければ、必ず0点です。1行書けば、0点ではなくなる可能性があります。そして、書ける1行は、たいてい誰にでもあります。

```
　1　問題文の条件を、式か記号にする
　2　図があれば、わかっていることを書き込む
　3　使えそうな定理や公式の名前を書く
```

この3つは、たいてい書けます。かける時間は、2分です。無理につなげようとしないでください。書けるところまで書いて、次に行きます。解けない問題を全部白紙にすると、0点です。それぞれで3点から5点拾うと、合計で10点から15点になります。これは、新しいことを覚えなくても取れる点です。いま持っている知識のままで、書き方を変えるだけで取れます。選択問題でも、同じです。マークシートなら、必ず塗ります。4択なら25パーセントで当たります。明らかに違う選択肢を1つ消せれば33パーセント、2つ消せれば50パーセントです。

## 気をつけること

マークシートの場合、順番を変えると、ずれる危険があります。解いた問題の番号を、必ず確認してください。飛ばした問題のマークを、空けておくのを忘れないでください。ここだけは、慎重にやります。

## これをやると、何が残るか

取りこぼしが、なくなります。順番に解いた人は、できる問題を時間切れで落とします。これは、いちばんもったいない落とし方です。先に見た人は、できる問題を全部取ってから、難しい問題に向かいます。同じ実力で、5点から10点変わります。
