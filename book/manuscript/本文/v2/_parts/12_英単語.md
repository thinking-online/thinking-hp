## 英単語なら、こうします

「単語は、どういう形で、何回くり返せばいいのか」。巻頭で出した質問に、ここで答えます。

いちばん多いやり方は、単語帳を見ながら、1語を10回ずつ書くことです。30語なら、手は300回動きます。でも、見ながら書いているあいだ、頭は1回も思い出していません。

同じ時間を、こう使います。

```
　　① 10個だけ、30秒見る　　　　　　　　覚えようとしなくていい。眺めるだけ
　　② 閉じて、10個を出す　　　　　　　　意味を声に出す。つづりが要る試験なら、書く
　　③ 出なかったものにだけ、印をつける　1語に10秒まで。出なければ、次へ
　　④ 次の10個へ。最後に、印のついたものだけ、もう一度
```

1セットで、2分ほどです。30語なら、3セットと、印のついたものをもう1回で、20分。見ながら10回書く1時間より短くて、落とす数が減ります。

何回くり返すかは、自分で決めなくていいです。==1回で出たものは、もうやらない。出なかったものだけが、もう1回になる。==回数は、単語ごとに、印が決めてくれます。次の日からの回し方は、16番に書きました。

書くかどうかは、試験で何を求められるかで決めます。

```
　　つづりを書かせる試験がある　→　書く。ただし、見て書くのは1回。あとは閉じて書く
　　意味が言えればいい　　　　　→　書かない。見て、閉じて、言う
　　漢字　　　　　　　　　　　　→　書く。手が形を覚える部分がある
```
