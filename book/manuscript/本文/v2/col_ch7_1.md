# コラム　無駄なプライドが、邪魔をしていた

現役のとき、僕には、変なプライドがありました。

中学の内容を、やり直したくない。こんな基礎を聞いたら、恥ずかしい。サッカー部の副キャプテンだった自分が、できないやつだと思われたくない。

だから、わからないところを飛ばして、むずかしい参考書を開いていました。形だけは、受験生らしく見えました。

浪人が決まって、中学の英単語からやり直したとき、最初は、くやしかったです。でも、そこからしか、積み上がりませんでした。

プライドには、2種類あります。

```
　　結果を出すことへのプライド　　　　持っていていい
　　途中の見え方へのプライド　　　　　捨てていい
```

かっこよく見える途中より、かっこわるくても、届く途中を選んでください。==結果が出れば、途中のかっこわるさは、全部、いい話になります。==
