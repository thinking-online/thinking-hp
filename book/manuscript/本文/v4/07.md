## 消しゴムは、なぜ、鉛筆の字を消せるのか。説明できますか？

筆箱の中に、入っています。小学生の頃から、毎日、使っています。

では、消しゴムでこすると、どうして、鉛筆の字が消えるのか。小学生に教えるつもりで、30秒、説明してみてください。

……

「えーと、こすると、取れて……」。そこで止まった人が、ほとんどだと思います。

知らなかったわけでは、ありません。何千回も使っているので、「知っている」つもりでした。説明しようとして初めて、言葉にならないことに気づきます。答えは、このあと、一緒に作ります。

勉強でも、同じことが起きています。授業で「わかった」と思ったのに、友達に「今日、何やったの？」と聞かれると、言葉になりません。

## 説明できないものは、まだ「知っている」だけです

頭のいい人は、「わかった」を3つに分けています。

```
　　知っている　　聞いたことがある。見れば思い出す
　　わかっている　何も見ずに、自分の言葉で説明できる
　　使える　　　　テストで、形を変えて出されても解ける
```

授業を聞いて「わかった」と思った時、ほとんどの場合は、1段目です。テストで点になるのは、3段目だけです。そして、2段目を通らずに、3段目には行けません。

　　==人に説明できない　＝　まだ、わかっていない==

## 「教えるつもり」で終わらせないために、型を埋めます

「人に説明するつもりで、勉強しなさい」。よく言われます。面白い実験があります。同じ文章を、2つのグループに読んでもらいます。片方には「あとでテストをします」、もう片方には「あとで、この内容を人に教えてもらいます」と伝えます。実際には、どちらも、誰にも教えません。結果は、==教えるつもりで読んだグループのほうが、よく覚えていました。==

ただ、多くの人は、「つもり」で終わります。つもり、と言われても、頭の中で、何をすればいいのかが、わからないからです。だから、この本では、型を使います。僕が、生徒に実際にやってもらっているやり方です。==「KW言語化勉強法」==と呼んでいます。KWは、キーワードのことです。

```
　　結局、【　　　　　　　　　　】の話。
　　キーワードは、【　　　】【　　　】【　　　】。
```

第2章の最初に、インプットは、その時、何を意識していたかで決まる、と書きました。==意識するのは、「この型を埋める」です。==そして、埋めた型を使って、説明します。

## 型を、入れる「前」に書きます

一番大事なのは、順番です。==この2行を、入れる「前」に、ノートのすみに書きます。==空いている枠があると、人の頭は、埋めたくなります。授業を聞いている間も、教科書を読んでいる間も、「結局、何の話だろう」「大事な言葉は、どれだろう」と、探しながら入れることになります。

最初の消しゴムで、やってみます。調べると、こう書いてあります。鉛筆の字は、黒い粉が、紙の表面にのっているだけです。こすると、その粉は、紙から、消しゴムのほうにくっつきます。粉をくっつけた消しゴムは、かすになって、はがれます。読みながら、型を埋めます。

```
　　結局、【紙にのった黒い粉を、消しゴムがくっつけて取る】話。
　　キーワードは、【紙にのった黒い粉】【消しゴムにくっつく】【かすになる】。
```

閉じて、3つの言葉を使って、30秒で説明します。「鉛筆の字は、黒い粉が、紙にのっているだけ。こすると、粉が、消しゴムにくっつく。その消しゴムが、かすになって、はがれる。だから、消える」。==さっきは止まった説明が、今は、言えます。==ボールペンの字が消えないのは、インクが、紙にしみこんで、粉のようには取れないからです。

教科でも、同じです。光合成なら、こうなります。

```
　　結局、【植物が、自分で養分を作る】話。
　　キーワードは、【光】【二酸化炭素と水】【デンプンと酸素】。
　　「光合成は、植物が光を使って、二酸化炭素と水から、
　　　デンプンなどの養分を作ること。その時、酸素が出る」
```

枠は、3つしかありません。大事なものと、細かいものを、分けるしかなくなります。これが、選ぶ力です。そして、3つの言葉を、自分でつなげて、1つの話に組み立て直します。これが、つなげる力です。==選んで、つなげる。==これが、「説明する」ということの中身です。

## 声に出します。相手がいなくても、できます

巻頭で出した質問に、ここで答えます。声に出すのか、心の中でいいのか。==声に出します。==心の中だと、止まったことを、自分でごまかせるからです。それに、声に出して読んだ言葉のほうが、黙って読んだ言葉より、よく覚えていた、という実験もあります。「プロダクション効果」と呼ばれています（14番で、くわしく書きます）。家のように、声を出せる場所で勉強できる時は、声に出すのが、一番いいです。

途中で止まったら、止まったところだけ開いて見て、閉じて、少し前から、もう一度言います。見開き2ページを、全部説明しようとしないでください。教科書の小見出し1つぶん。授業なら、黒板1枚ぶん。小さく区切って、1つずつ、型を埋めます。

相手は、ぬいぐるみでも、壁でも、スマホの録音でもいいです。AIに向かって説明するのも、いい方法です。型を埋めて、30秒の説明を書いたら、こう頼みます。

　　「光合成を、次のように理解しました。合っていますか。違っている所があれば、答えは言わずに、どの点を、何を意識して復習すればいいかだけ、教えてください」

答えをもらうのでは、ありません。自分の説明を、直してもらいます。（AIの使い方は、42番に書きます）

型を書いた紙は、捨てないでください。電車の中で、キーワードの3つだけを見て、30秒の説明をもう一度言えば、復習になります。出てこなかったら、そこが、まだわかっていない場所です。このあとの09番、10番、11番は、この型を、場面ごとに使う話です。
