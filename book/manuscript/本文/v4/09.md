## 「むかしむかし、あるところに、おじいさんと……」

続きを、頭の中で、言いましたね。

「おばあさんが、いました」。頼まれていないのに、最後まで言ったはずです。

途中で止まったものを、人の頭は、放っておけません。続きが、気になります。

「キリのいい所までやってから、休もう」と思うのも、同じ力です。途中で止めるのが、気持ち悪い。だから、あと3問、あと1ページ、と続けます。気づくと、1時間半、座りっぱなしです。その間、07番の「30秒で説明する」は、1回も、やっていません。

## 「あとでやろう」は、やらないまま、進みます

07番で、人に教えるつもりで入れて、30秒で説明する、と書きました。でも、いつ、説明するのか。授業中も、家で勉強している時も、そのタイミングは、誰も決めてくれません。「ちょうどいい所で」「ここまで進んだら」と思っていると、その時は、来ません。あとでやろう、と思ったまま、次へ進んでしまいます。

もう1つ、理由があります。人は、ずっと集中し続けることが、できません。座っているし、手も動いている。だから、やれていると思います。でも、同じ行を読み直す回数が、増えています。==集中は、切れてから休むのでは、遅いんです。==（集中の話は、第4章の集中編で、くわしく書きます）

```
　　×　キリのいい所まで進めて、あとで、まとめて思い出す
　　○　時間で区切って、そのたびに、思い出す
```

## 25分やって、1分で思い出して、5分離れます

区切りは、キリではなく、時間で決めます。僕が、生徒にやってもらっているのは、次の形です。==「25:1:5勉強法」==と呼んでいます。数学のワークなら、こうなります。

```
　　25分　　式を1行書いた所で、タイマーが鳴る。そこで止める
　　 1分　　閉じて言う。「結局、一次関数の話。傾き、切片、変化の割合」
　　 5分　　立って、水を飲む。戻ったら、式の続きから書く
```

大事なのは、まんなかの1分です。本を閉じて、「結局、今の25分は、何の話だった？」を、07番の型で言います。25分やって、そのまま休むと、入れただけで終わります。==1分で、思い出してから休む。==これを4回やれば、2時間で、4回、思い出しています。絶対法則02の「思い出す」が、区切るたびに、入ります。

授業の時は、タイマーが使えません。チャイムが鳴ったら、教科書をしまう前に、1分。これが、区切りです。

## タイマーが鳴ったら、キリが悪くても、止めます

タイマーが鳴った時、問題の途中だったら、どうするか。途中で、止めてください。最初の「むかしむかし」と同じで、人は、途中で止まったことが、気になります。心理学では、「ツァイガルニク効果」と呼ばれています。とくに、途中で止めた作業を、続けたくなることは、多くの実験で確かめられています。この力を、味方にします。

```
　　キリのいい所で止める　→　次は「新しい1問目」から。始めるのが、重い
　　キリの悪い所で止める　→　次は「さっきの続き」から。始めるのが、軽い
```

式を1行書いた所で、止める。英文を半分読んだ所で、止める。5分後、机に戻った時、やることは決まっています。続きを書くだけです。

## 休憩の5分は、何も入れません

休憩で、スマホを見ると、頭は休まりません。新しい文字と映像が、どんどん入ってくるからです。立つ。水を飲む。窓の外を見る。==何も入れない5分==にします。

25分は、目安です。大事なのは、25という数字ではありません。==切れる前に、時間で、自分から区切ること==です。
