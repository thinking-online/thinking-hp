　　「1ページ目から、丁寧に読んでいこう」

1ページ目、縄文時代。丁寧に読んで、ノートにまとめます。

1か月たちました。まだ、平安時代です。縄文時代は、もう、ほとんど忘れています。そして、この本が、全部でどんな話なのかは、まだ知りません。

## ジグソーパズルを、箱の絵を見ずに始めますか

1000ピースの、ジグソーパズルがあります。

箱の絵を見ずに、手に取った1ピース目から、順番にはめていく人は、いません。

まず、箱の絵を見ます。「空が上で、海が下。真ん中に、船」。全体がわかってから、ピースを見ます。すると、「この青は、空だな」「これは、船のはしだな」と、置く場所がわかります。

箱の絵を見ていないと、同じピースが、ただの青いかけらです。

勉強も、同じです。全体を知らないまま、1ページ目から読むと、==今読んでいる所が、全体のどこなのかが、わかりません。==どこが大事なのかも、わかりません。だから、全部が同じ大事さに見えて、全部を丁寧に読むことになります。

## 先に、5分で、最後までめくります

読む前に、5分だけ使います。

```
　　① 目次を見る　　　　　　　　　　　　章の題を、声に出して読む
　　② 最後まで、めくる　　　　　　　　　見出しと、太字と、図だけを見る
　　③ 閉じて、「何の本か」を3つで言う　「時代は、6つ。前半は貴族、後半は武士」
```

中身は、読みません。わからなくて、いいです。==見るのは、「何が、どの順番で並んでいるか」だけです。==

これが、箱の絵になります。

そのあとで、1ページ目から読みます。同じページでも、見え方が変わります。「これは、あとで出てくる武士の話の、準備だな」。ピースを置く場所が、わかるからです。

## 1周目は、薄く、最後まで行きます

読み始めてからも、同じ考え方を使います。

```
　　×　1章を完璧にしてから、2章へ　　　　　→　最後の章に着くのは、何か月もあと。そのころ、1章は忘れている
　　○　薄く、最後まで1周してから、2周目へ　→　全体を知った上で、細かい所を読める
```

絶対法則06で書いた通り、1回目から完璧にする必要は、ありません。絶対法則05で書いた通り、同じ所は、別の日に、もう一度やります。1周目は、「何が書いてあるか」を知るための周です。

1冊の本だけの話では、ありません。

```
　　歴史　　　　先に、マンガや年表で、流れを最後まで見ておく
　　数学　　　　章の最初に、例題の題だけを、全部見ておく
　　英語の長文　先に、設問を見ておく
```

全部、同じことをしています。先に、箱の絵を見ています。

## 「わからないまま進むのが、気持ち悪いです」

その気持ちは、まともです。

ただ、最初の章でわからなかったことが、あとの章を読んだら、わかる。そういうことは、よくあります。全体を知らないと、わからない所だったからです。

わからない所には、ふせんを貼って、先へ進んでください。2周目に、戻ってきます。その時には、いくつかは、もう、わかるようになっています。
