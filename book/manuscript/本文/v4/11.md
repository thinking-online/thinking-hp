## スワヒリ語を、3つ、覚えてください

```
　　ライオン　＝　シンバ
　　旅　　　　＝　サファリ
　　建てる　　＝　ジェンガ
```

……

もう、覚えましたよね。アフリカで話されている、スワヒリ語です。1回も習ったことがないのに、3つとも、10秒もかからなかったはずです。ライオン・キングのシンバ。サファリパーク。積み上げて遊ぶ、ジェンガ。どれも、もう知っているものに、つながったからです。では、あと2つ。

```
　　キリン　＝　トゥイガ
　　本　　　＝　キタブ
```

こちらは、明日には、たぶん、忘れています。同じスワヒリ語です。違いは、1つだけ。==もう知っているものに、つながったかどうか==です。

## 覚えられるかは、どれだけ深く考えたかでも、決まります

新しい言葉を、そのまま、何回もくり返す。心理学では、「維持リハーサル」と呼ばれます。もう知っていることとつなげて、意味を考える。こちらは、「精緻化リハーサル」です。名前はむずかしいですが、やることは、さっきの「シンバ」と同じです。長く残るのは、こちらです。

トロント大学の研究者たちの実験があります。単語を1つずつ見せて、単語ごとに、質問を変えます。「大文字で書いてある？」と、見た目を聞く。「この文に入る？」と、意味を聞く。あとでテストをすると、意味を考えた単語のほうが、ずっとよく覚えられていました。覚えようとしたかどうかより、==どれだけ深く考えたか==で、残る量が決まったんです。

教科書の言葉を、そのまま覚えようとするのは、「トゥイガ」を覚えるのと、同じです。

```
　　×　教科書の言葉を、そのまま、くり返して覚える
　　○　自分の知っていることに、つなげて、言い直す
```

## 「これって、つまりは？」で、知っていることに、つなげます

新しい言葉や説明が出てきたら、自分に聞きます。==「これって、つまりは？」==。そして、自分の知っているものや、好きなもので、言い直します。理科の教科書の1行で、やってみます。

　　ミトコンドリアは、酸素を使って、養分からエネルギーを取り出す。

「ミトコンドリアって、つまりは？」。燃料を燃やして、電気を作る場所。発電所に、似ています。「ミトコンドリアは、細胞の中の発電所。養分が、燃料」。自分の言葉になりました。

もう一歩、自分の好きなことに、つなげます。運動部なら、こうです。走りこみを続けると、スタミナがつきます。理由の1つは、筋肉の細胞の中で、ミトコンドリアが増えるからです。「走るたびに、足の中の発電所が、増えている」。教科書の1行が、自分の足の話になりました。もう、忘れません。

何につなげるか。3つあります。

```
　　身の回りのもの　　→　発電所、水道、学校、スマホ
　　前に習ったこと　　→　「あれと同じ」「あれの逆」
　　自分の好きなこと　→　部活、ゲーム、音楽
```

巻頭の11個の数字も、九九という「前に習ったこと」に、つなげただけでした。思いつかない時は、先生や友達、AIに、「〇〇でたとえると？」と聞いて、かまいません。聞いたたとえは、最後に、自分の言葉で言い直します。

たとえは、完璧でなくて、かまいません。「発電所とは、ここが違うな」と気づいたら、それは、理解が深くなった証拠です。

## 自分の言葉で説明できたら、「わかった」です

07番で、人に教えるつもりで入れて、30秒で説明する、と書きました。その時、教科書の言葉を、そのまま言えるだけでは、足りません。「つまり、どういうこと？」と聞かれて、止まるなら、まだ、写しただけです。

```
　　×　「酸素を使って、養分からエネルギーを取り出すところ」
　　○　「細胞の中の発電所。走りこむと増えるから、スタミナがつく」
```

×は、教科書の言葉です。○は、自分の言葉です。知っていることにつなげて、自分の言葉で、言い直せる。==そこまで持っていけるかどうかが、鍵です。==
