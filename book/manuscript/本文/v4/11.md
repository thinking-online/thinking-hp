## フランス語を、3つ、覚えてください

```
　　croissant（クロワッサン）　＝　三日月
　　chou（シュー）　　　　　　＝　キャベツ
　　encore（アンコール）　　　＝　もう一度
```

……

もう、覚えましたよね。フランス語を、1回も習ったことがないのに、3つとも、10秒もかからなかったはずです。三日月の形をしたパン、クロワッサン。キャベツみたいな形の、シュークリーム。ライブの最後の、「アンコール！」。どれも、もう知っているものに、つながったからです。では、あと2つ。

```
　　oiseau（オワゾー）　＝　鳥
　　livre（リーヴル）　　＝　本
```

こちらは、明日には、たぶん、忘れています。同じフランス語です。違いは、1つだけ。==もう知っているものに、つながったかどうか==です。

## 覚えられるかは、どれだけ深く考えたかでも、決まります

新しい言葉を、そのまま、何回もくり返す。心理学では、「維持リハーサル」と呼ばれます。もう知っていることとつなげて、意味を考える。こちらは、「精緻化リハーサル」です。名前はむずかしいですが、やることは、さっきの「クロワッサン」と同じです。長く残るのは、こちらです。

トロント大学の研究者たちの実験があります。単語を1つずつ見せて、単語ごとに、質問を変えます。「大文字で書いてある？」と、見た目を聞く。「この文に入る？」と、意味を聞く。あとでテストをすると、意味を考えた単語のほうが、ずっとよく覚えられていました。覚えようとしたかどうかより、==どれだけ深く考えたか==で、残る量が決まったんです。

教科書の言葉を、そのまま覚えようとするのは、「オワゾー」を覚えるのと、同じです。

```
　　×　教科書の言葉を、そのまま、くり返して覚える
　　○　自分の知っていることに、つなげて、言い直す
```

## 「これって、つまりは？」で、知っていることに、つなげます

新しい言葉が出てきたら、自分に聞きます。==「これって、つまりは？」==。そして、自分の知っているものや、好きなもので、言い直します。例えば、歴史で、「御恩と奉公」という言葉が出てきたとします。教科書には、こう書いてあります。

　　将軍は、御家人の領地を守り、手がらがあれば、新しい領地を与える（御恩）。御家人は、将軍のために戦う（奉公）。

そのまま、くり返しても、すぐ消えます。そこで、「御恩と奉公って、つまりは？」。

```
　　ゲームが好きなら　　→　「ゲームでいうと、クエストと報酬。戦えば、もらえる」
　　部活が好きなら　　　→　「部活でいうと、活躍とスタメン。働けば、出られる」
　　どちらでもないなら　→　「お手伝いと、お小遣い」
```

正解は、1つではありません。自分の頭の中にあるものに、つなげる。だから、残ります。しかも、つなげると、その先まで、わかります。

クエストをクリアしたのに、報酬が出なかったら、どうなるか。もう、その人のためには、戦いたくなくなります。鎌倉時代に、同じことが起きました。外国の軍が攻めてきた、元寇です。御家人は、命がけで戦って、追い返しました。でも、守っただけなので、新しい領地は、手に入りません。幕府は、十分な報酬を、出せませんでした。御家人の不満がたまり、幕府が弱っていく理由の1つになります。教科書の先のページが、もう、わかっています。

何につなげるか。3つあります。

```
　　自分の好きなこと　→　部活、ゲーム、音楽
　　身の回りのもの　　→　お小遣い、学校、スマホ
　　前に習ったこと　　→　「あれと同じ」「あれの逆」
```

巻頭の11個の数字も、九九という「前に習ったこと」に、つなげただけでした。思いつかない時は、先生や友達、AIに、「〇〇でいうと？」と聞いて、かまいません。聞いたたとえは、最後に、自分の言葉で言い直します。

## 自分の言葉で説明できたら、「わかった」です

07番で、人に教えるつもりで入れて、30秒で説明する、と書きました。その時、教科書の言葉を、そのまま言えるだけでは、足りません。「つまり、どういうこと？」と聞かれて、止まるなら、まだ、写しただけです。

```
　　×　「将軍が領地を与え、御家人が将軍のために戦う関係」
　　○　「ゲームでいう、クエストと報酬。報酬が出ないと、離れていく」
```

×は、教科書の言葉です。○は、自分の言葉です。知っていることにつなげて、自分の言葉で、言い直せる。==そこまで持っていけるかどうかが、鍵です。==
