英単語のテストが、来週あります。範囲は、100語です。

単語帳を開いて、1語目から始めます。

こんな時、あなたなら、どうしますか？

　　「この単語を、完璧に覚えてから、次の単語へ進もう」

1語目を、10回書きます。意味を、何度も言います。「よし、覚えた」。2語目へ進みます。

1時間たちました。進んだのは、20語です。

次の日。昨日の20語を、確かめてみます。半分も、出てきません。そして、残りの80語は、まだ1回も見ていません。

## 「完璧に覚えた」は、その時だけです

1語に3分かけて、「覚えた」と感じる。その感じは、うそではありません。その時は、本当に言えます。

ただ、絶対法則05で見た通り、まとめてやったものは、すぐあとには効きますが、長くは持ちません。1語に3分かけるのは、1語を、一夜漬けしているのと同じです。

```
　　1個ずつ、完璧に　→　1語に3分。1回だけ会う。100語に、5時間
　　薄く、何周も　　　→　1語に数秒。何回も会う。100語を1周、20分ほど
```

同じ5時間があれば、下のやり方なら、何周もできます。==1回を長くするより、会う回数を増やします。==

## 10個を30秒で見て、閉じて、出します

やり方は、こうです。

```
　　① 10個だけ、30秒見る　　　　　　　　覚えようとしなくていい。眺めるだけ
　　② 閉じて、10個を出す　　　　　　　　意味を声に出す。つづりが要る試験なら、書く
　　③ 出なかったものにだけ、印をつける　1語に5秒まで。出なければ、次へ
　　④ 次の10個へ
```

1セットで、2分ほどです。

「30秒眺めただけで、覚えられるわけがない」。そう思うはずです。その通りです。1周目は、ほとんど出てきません。それで、いいんです。

絶対法則02で見た通り、残るのは、見た時ではなく、思い出そうとした時です。出てこなくても、「えーと……」と探したあとに答えを見ると、ただ眺めた時より、残りやすくなります。

## 2周目からは、印があるものだけです

出なかったものには、印を1つつけました。

```
　　available　　　　　　（出た。何もしない）
　　consist　　　　　｜　（出なかった。印を1つ）
　　subsequent　　　｜｜　（2回続けて出なかった。印が2つ）
```

2周目は、印がついているものだけをやります。3周目は、印が2つ以上のものだけです。

```
　　1回で入ったもの　　→　2周目から出てこない
　　8回かかるもの　　　→　毎周出てくる
```

==何回やるかは、自分で決めなくていいです。印が、単語ごとに決めてくれます。==

やる量は、周ごとに減っていきます。例えば、こうなります。

```
　　1周目　100語　　20分
　　2周目　 40語　　 8分
　　3周目　 15語　　 3分
　　4周目　  5語　　 1分
```

「1個ずつ完璧に」の人は、1語目にも100語目にも、同じ時間をかけます。印で回す人は、==出てこない単語にだけ、時間を使います。==絶対法則03で見た通り、伸びるのは、「うーん」となる所だけです。

## 次の周は、別の日にやります

1周目のすぐあとに、印のあるものを、もう1周してもかまいません。ただ、それだけで終わらせません。

絶対法則05で決めた通り、同じものを、別の日に、もう一度やります。次の日に、印のあるものだけを、もう1周。テストの前の日は、印が2つ以上のものだけです。

## 書くか、書かないか

書くかどうかは、試験で何を求められるかで決めます。

```
　　つづりを書かせる試験がある　→　書く。ただし、見て書くのは1回。あとは閉じて書く
　　意味が言えればいい　　　　　→　書かない。見て、閉じて、言う
　　漢字　　　　　　　　　　　　→　書く。形は、手を動かしたほうが覚えやすい
```

英単語でなくても、同じです。古文単語、歴史の用語、化学式。どれも、薄く、何周もします。
