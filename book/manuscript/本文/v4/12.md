## 漢字の宿題で、「へん」だけ先に、書いたことはありませんか？

小学校の、漢字の宿題です。同じ字を、ノートに1行。3つ目あたりから、「にんべん」だけを、下まで先に書く。あとから、右側を、まとめて書く。やったことがある人、多いと思います。

サボりたかったわけでは、ありません。同じ字を何回も書くと、頭は、何も考えなくても、手が動くようになります。あの時、頭の中で、漢字を思い出しては、いませんでした。==すぐ上に書いた字を、写していただけ==です。

英単語を10回書く時も、同じことが起きています。1回目は、単語帳を見て、書きます。2回目からは、すぐ上の、自分の字を見て、書きます。10回書いて、思い出した回数は、0回です。

## 残るのは、書いた回数ではなく、思い出した回数です

「書かないと、覚えられない」。そう言う人は、多いです。書くと、ノートが、びっしり埋まります。手も、疲れます。「やった感じ」が、一番出るやり方です。10回書いた直後は、たしかに、言えます。でも、絶対法則01で見た通り、「やった感じ」と、「頭に残った」は、別のものです。

長く残るのは、何も見ずに、思い出そうとしたものです（絶対法則02）。そして、書くのは、時間がかかります。1語を10回書くと、1分ほどです。

```
　　10回書く　　　　　→　30分で、30語。思い出した回数は、0回
　　隠して、思い出す　→　30分で、100語。出ない語は、3回、思い出す
```

何回も書くことが、効く場合もあります。見たことのない形を、覚える時です。ただ、言葉を覚える時には、書いても、差が出なかった、という実験もあります。==時間は、書くことではなく、思い出すことに使います。==

## 10個を見て、隠して、言います

10個だけ、30秒、見ます。手か、赤シートで隠して、意味を言います。1語に、5秒まで。出なければ、答えを見て、印をつけて、次へ。10個で、2分ほどです。1周目は、ほとんど出てきません。それで、いいんです。「えーと……」と探してから答えを見ると、ただ見た時より、残ります。

```
　　available　　　　　　（出た。何もしない）
　　consist　　　　　｜　（出なかった。印を1つ）
　　subsequent　　　｜｜　（2回続けて出なかった。印が2つ）
```

2周目は、印があるものだけ。3周目は、印が2つ以上のものだけです。やる量は、周ごとに、減っていきます。

```
　　1周目　100語　　20分
　　2周目　 40語　　 8分
　　3周目　 15語　　 3分
```

書く人が、30語を書いている30分です。その間に、100語を見て、出ない単語を、3回、思い出しています。==出てこない単語にだけ、時間を使えます。==

## 思い出す回数は、1日に詰めこまず、別の日に分けます

1日で、10周するわけでは、ありません。絶対法則05で見た通り、同じ回数なら、間をあけたほうが、長く残ります。

```
　　×　今日、1語を、見ながら10回書く
　　○　今日3回、次の日に1回、テストの前の日に1回、隠して思い出す
```

今日、3周。次の日に、印があるものだけ、もう1周。テストの前の日は、印が2つ以上のものだけ。==思い出す回数を増やして、日を分ける。==覚えるためにやることは、この2つです。

## 書くのは、「隠してから」です

書くことを、全部やめるわけでは、ありません。

```
　　意味が言えればいい　→　書かない。隠して、言う
　　つづり、漢字　　　　→　書く。ただし、見ながら10回ではなく、隠して1回
```

隠して書けば、それは、「思い出す」になります。書けなかった所だけ、見て、もう一度、隠して書く。見ながら書くか、隠して書くか。同じ「書く」でも、頭の使い方は、まったく違います。
