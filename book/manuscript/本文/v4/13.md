　　abandon　捨てる

「アバンダン、捨てる。アバンダン、捨てる」。何度も、唱えます。

テストで、abandon が出ました。「見たことはある。なんだっけ」。文字は、覚えています。意味が、出てきません。

## 文字と文字を、くっつけているだけです

「abandon ＝ 捨てる」。これは、アルファベットの並びと、日本語の文字を、のりでくっつけている状態です。

どちらも、ただの文字です。頭の中に、何の絵も浮かんでいません。だから、はがれやすいんです。

試しに、やってみてください。

　　「りんご」

今、頭に浮かんだのは、「り・ん・ご」という3つの文字でしょうか。それとも、赤くて丸い、あの果物でしょうか。

……

ほとんどの人は、果物のほうが浮かんだはずです。==知っている言葉は、文字ではなく、絵や場面で入っています。==

覚えられない単語は、まだ、絵になっていない単語です。

## 絵か、場面を、1つ思い浮かべます

やることは、1つです。意味を読んだら、3秒だけ、絵か場面を思い浮かべます。

```
　　abandon　捨てる　→　雨の中、段ボールに入った子犬が、置いていかれる場面
　　borrow　借りる　→　友達に「消しゴム貸して」と言っている自分
　　huge　　巨大な　→　校舎より大きい、ゾウ
```

うまい絵でなくて、いいです。変な絵のほうが、残ります。自分が出てくる場面は、もっと残ります。

15番で書きますが、記憶は、ほかのものとつながっているほど、取り出しやすくなります。絵や場面は、その「つながる先」を、1つ増やしています。

## 絵にしにくい言葉は、使う場面にします

「捨てる」は、絵にできます。でも、「〜にもかかわらず」のような言葉は、絵になりません。

そういう時は、使う場面を、1つ決めます。

```
　　despite　〜にもかかわらず　　　→　「雨にもかかわらず、部活はあった」
　　あはれ　しみじみとした気持ち　→　夕焼けを見て、「あぁ……」となっている自分
　　墾田永年私財法　　　　　　　　→　「耕した土地は、ずっと自分のもの」と聞いて、喜んで耕す農民
```

英単語だけの話では、ありません。古文単語も、歴史の用語も、理科の言葉も、同じです。文字のままでは、入りにくい。絵か場面にすると、入ります。

どうしても思いつかない時は、AIに「この単語を、絵が浮かぶ場面にして」と頼んでいいです。（AIの使い方は、43番に書きます）

## 思い出す時も、絵から出します

12番のやり方で、閉じて出す時。日本語の文字を思い出そうとするのではなく、さっきの絵を思い出します。

　　abandon　→　（置いていかれる子犬）　→　捨てる

絵が出てくれば、意味は、あとからついてきます。
