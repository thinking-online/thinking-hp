数学の問題を、解いています。3分考えて、わかりませんでした。解説を、開きます。

1行ずつ、読んでいきます。「ああ、ここで、この公式を使うのか」。最後まで、読みました。

こんな時、あなたなら、どうしますか？

　　「なるほど、わかった。次」

赤ペンで、答えを写します。次の問題へ進みます。

1週間後。同じ問題が、小テストに出ました。

最初の1行が、書けません。「見たことはある。解説を読んで、わかったはずなのに」。

## 「わかる」と「できる」の間に、段差があります

解説を読んで「わかった」時、やっていたことは、何でしょうか。

人が解いた道を、後ろから、ついて歩いただけです。

```
　　わかる　　解説の1行1行に、「うん、そうなる」と言える
　　できる　　何も見ずに、最初の1行から、自分で書ける
```

道案内をしてもらって着いた場所に、次の日、1人で行けるとは、かぎりません。「次、どっちに曲がるか」を、自分で決めていないからです。

解説も、同じです。一番難しいのは、「最初に、何をするか」を、自分で決める所です。解説を読んでいる間、そこは、解説が決めてくれています。

テストで聞かれるのは、「できる」のほうだけです。

## 解説を閉じて、白紙に、最初から書きます

やることは、1つです。

==解説を読んだら、閉じます。白紙に、最初の1行から、自分で書きます。==

これを、「白紙再現」と呼びます。

```
　　① 解説を読む　　　　　　　　　わかるまで読んでいい
　　② 解説を閉じる　　　　　　　　答えも、途中の式も、見えないようにする
　　③ 白紙に、最初から書く　　　　止まったら、そこに印をつける
　　④ 止まった所だけ、解説を見る　見たら、また閉じて、最初からもう一度
```

絶対法則02の「思い出す」を、問題でやっているだけです。

やってみると、驚くと思います。「わかった」はずなのに、3行目で、手が止まります。==手が止まった所が、本当は、わかっていなかった所です。==解説を読んでいるだけでは、そこは、見つかりません。

## 写すのとは、違います

解説を見ながら、ノートに書き写す。これは、白紙再現では、ありません。

写している間、頭は、「次に何をするか」を、1回も決めていません。見て、書いているだけです。きれいな解答が、ノートに残ります。でも、頭には、残っていません。

見るのは、止まった時だけ。そして、見たら、もう一度、閉じます。

## 数学だけでは、ありません

```
　　数学・理科の計算　　解説を閉じて、最初の式から書く
　　英語の長文　　　　　和訳を閉じて、線を引いた文を、自分で訳す
　　社会・理科の説明　　教科書を閉じて、「なぜ、そうなったか」を、白紙に書く
　　授業　　　　　　　　その日のうちに、先生が解いた例題を、白紙から解く（07番）
```

全部の問題で、やる必要はありません。==解説を読んで、「わかった」と思った問題だけ==で、いいです。自分で解けた問題は、もう、できています。

## 別の日に、もう一度だけ

解説を閉じたすぐあとは、まだ、頭に解説が残っています。だから、書けて当然、という面もあります。

絶対法則05で決めた通り、同じ問題を、別の日に、もう一度、白紙から解きます。そこで書けたら、その問題は、「できる」になっています。
