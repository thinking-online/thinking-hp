## 病院で、「なんとなく、全体的に、調子が悪いんです」と言ったら？

お医者さんは、薬を出しません。まず、検査をします。熱を測る。のどを見る。血を調べる。数字と事実がそろって、初めて、治し方が決まります。

勉強の相談で、一番よく聞く言葉が、あります。「基礎が、できていないんです」。これは、「なんとなく、全体的に、調子が悪い」と、同じです。どの単元が、どのくらい、できていないのか。それがわからないと、何をやればいいかも、決まりません。

## 感覚の「できない」と、事実の「できない」は、別のものです

勉強ができる生徒は、あいまいに言いません。「確率は、今解いたら、正答率30％くらいです」。こう言います。数字で言えるのは、実際に、解いたからです。

```
　　×　「基礎が、できていないんです」
　　○　「確率は、今解くと、正答率30％です」
```

過去問でも、同じです。「今解いても、どうせ、できないじゃないですか」。そう言って、後回しにする人が、多いです。でも、感覚で「できない」と思っているのと、実際に解いて「できなかった」のは、まったく違います。同じ正答率30％でも、中身は、まったく違うことがあります。大問1と2が満点で、残りが0点の30％なのか。全部が、まんべんなく30％なのか。解いた人だけが、それを知っています。だから、次にやることが、決まります。

コーネル大学の研究者たちの実験では、テストの成績が低かった人ほど、自分の成績を、実際より高く見積もっていました。実力が足りていない時ほど、「自分は、できている」と思いやすい。「ダニング＝クルーガー効果」と呼ばれています。誰にでも、起きることです。自分の「できる」「できない」の感覚は、ずれます。==だから、まず、解きます。==

## 基礎の問題集を1冊、まず解いて、仕分けます

新しい単元や、科目の勉強を始める時。おすすめは、応用ではなく、基礎だけの問題集を1冊、一度、全部解くことです。考えこまずに、解けなければ、×をつけて、次へ進みます。これは、覚えるためではありません。==できるものと、できないものを、仕分ける作業==です。終わったら、単元ごとに、数字にします。

```
　　単元　　　　　解いた数　　○の数　　正答率
　　2次関数　　　　10問　　　　9問　　　90％　→　今は、やらない
　　図形と計量　　　10問　　　　6問　　　60％　→　×の4問だけ
　　確率　　　　　　10問　　　　3問　　　30％　→　ここから始める
```

僕の塾では、入ってきた生徒に、一番最初に、これをやってもらいます。何ができて、何ができないのかを、専用のシートで、見えるようにします。「基礎ができていない」が、「確率が30％」に変わった瞬間、やることは、決まります。

## 過去問も、最初に解きます。目的は、2つです

過去問を、力がついてからの、腕試しに取っておく人が、多いです。逆です。最初に、1年分、時間を測って、解きます。目的は、2つあります。

```
　　1　敵を知る　　　　どの分野が、どんな形で、どのくらいの量、出るのか
　　2　今の自分を知る　どこが、どれだけ、できていないのか。感覚ではなく、事実で
```

過去問を、秋まで開かなかった人が、11月に、気づくことがあります。「この学部には、この分野が、一度も出ていない」。夏の2か月を、そこに使っていました。敵を知らないまま進むと、こうなります。

点数は、気にしなくて、かまいません。0点でも、「何が出るか」と、「どこが0点か」は、手に入ります。定期テストなら、学校のワークと、去年の問題が、同じ役目をします。

## 「できない」を、早く知った人から、伸びます

×だらけの結果を見るのは、いやなものです。だから、多くの人が、「できない」を知るのを、先にのばします。でも、「できない」が、事実でわかった日から、やることが決まります。==その日が早いほど、成長は、速くなります。==多くの人が、ここに、気づいていません。
