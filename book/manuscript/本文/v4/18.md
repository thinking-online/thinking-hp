## りんごについて、正しいものを、1つ選んでください

```
　　ア　りんごの生産量が、日本で一番多いのは、長野県である
　　イ　りんごを切って置いておくと、切り口が、茶色くなる
　　ウ　りんごは、水に入れると、沈む
　　エ　青森県のりんごは、日本の生産量の、約1割である
```

……

答えは、イです。正解した人が、多いと思います。では、もう1問です。

　　アは、どこを直せば、正しくなりますか。

……

「長野県」を、「青森県」に直します。長野県は、2番目です。

1問目に正解した人でも、2問目で止まります。正しい選択肢だけを見て、○をつけたからです。外れの選択肢は、ただの外れでは、ありません。==次のテストで、形を変えて、聞かれるかもしれない所です。==

## その○は、当たったのか、わかっていたのか

問題は、ただ解けばいい、というものでは、ありません。○には、2種類あります。

```
　　根拠があって選んだ○　　次も、取れる
　　なんとなく選んだ○　　　次は、わからない
```

答え合わせの時、この2つは、同じ○に見えます。そして、なんとなくの○は、一番やっかいです。×なら、解説を読みます。○は、読みません。==わかっていないのに、一度も見直されないまま、本番まで行きます。==

## 選ぶ前に、根拠を一言、書きます

==選ぶ前に、根拠を1つ決めます。==「イだ。なぜなら、主語が複数だから」。問題番号の横に、一言で書いておきます。

コロンビア大学の研究者たちの実験では、自信を持って答えて、間違いだった時ほど、正しい答えを、強く覚えていました。「え、違うの？」という驚きが、記憶を強くするからです。根拠を書いておけば、合っていた時は、その根拠が使えるとわかります。間違っていた時は、驚くので、強く残ります。どちらに転んでも、残ります。

## 正解だけでなく、選ばなかった3つにも、根拠を取ります

正解の選択肢だけでなく、間違いの選択肢にも、「なぜ違うのか」の根拠を取る。==これを、「根拠取り」と呼びます。==最初のりんごの問題なら、こうなります。

```
　　選ぶ前の根拠　「切ったりんごが、茶色くなるのを、見たことがある」
　　ア　ちがう。一番は、青森県。長野県は、2番目
　　イ　合っている。切り口が、空気にふれて、色が変わる
　　ウ　ちがう……と思う。でも、理由が、言えない
　　エ　ちがう。約1割ではなく、約6割
```

根拠取りをすると、その問題だけでなく、次に、どう聞かれても、対応できるようになります。どんな聞かれ方をするのかを、問題を解きながら、学べるんです。4つとも言えたら、4問ぶんの勉強です。イを選んで○をつけて終わった人は、1問ぶん。しかも、当たっただけかもしれない1問ぶんです。

間違いの選択肢は、適当に作られていません。==多くの人が間違える考え方==を、わざと並べてあります。つまり、選ばなかった3つは、次に自分が引っかかる場所の一覧です。

## 言えなかった○は、△にします

さっきの見本では、ウの理由が言えませんでした。答えは合っていても、この問題は、○にしません。

```
　　○　選んだ理由も、他が違う理由も、言えた
　　△　合っていたけれど、理由が言えなかった
　　×　間違えた
```

△は、×と同じ扱いにします。次の日に、もう一度やる問題です。==なぜ合っていたかまで言えて、初めて○です。==

間違いの選択肢を、「正しい」と思った。正しい選択肢を、「違う」と思った。そういうミスは、落ちこむ所では、ありません。勘違いしていた所が、はっきり見つかった、ということです。==伸びしろが、一番大きいミスです。==

## 解説に、間違いの理由が書いていない時

問題集によっては、正解の説明しか載っていません。その時は、AIに聞いていいです。「自分は、こう考えて、ウを選んだ。どこで勘違いしている？」。答えではなく、自分の考えのどこが違うのかを聞くと、自分の課題が、はっきりします。（AIの使い方は、42番に書きます）

問題集を選ぶ時も、ここを見てください。間違いの選択肢について、1つずつ理由が書いてあるもの。それが、いい問題集です。
