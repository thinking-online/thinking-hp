## オーストラリアの首都は、どこですか？

5秒で、答えてください。

……

答えは、キャンベラです。

出てこなかった人に、聞きます。あと30分考えたら、出たと思いますか。

出ません。知らないものは、いくら考えても、出てこないからです。

首都なら、誰も、30分は粘りません。ところが、勉強では、粘ります。こんな経験は、ありませんか。数学の問題。最初の1行が、書けません。「答えを見たら、負けだ」。そう思って、問題文をにらみ続けます。30分たちました。ノートは、白いままです。

## 知らないものは、粘っても、出てきません

解けなかったのは、考える力が足りないからでは、ありません。使う解き方を、まだ、知らなかったからです。首都と、同じです。30分粘っても、出てきません。

粘っている間、同じ所を、ぐるぐる回っています。考えているつもりでも、進んでいません。==手が止まったままの時間は、考えている時間ではなく、悩んでいる時間です。==

では、すぐに見ればいいのか。それも、違います。0秒で見ると、頭を1回も使わないまま、終わります。「ああ、そうか」と思って、次の日には、忘れています。

## 2つの実験を合わせると、答えが出ます

ロンドンの大学の研究者たちの実験では、知らない言葉の意味を、まず自分で答えてみて、はずしてから正解を見たグループのほうが、最初から正解を見たグループより、あとのテストの成績がよくなりました。

オーストラリアの大学の研究者たちの実験では、図形の問題を、自力で解き続けたグループより、解き方の見本を先に見たグループのほうが、成績がよくなりました。

合わせると、こうなります。0秒で見るのは、もったいない。30分粘るのは、かけすぎ。==少しだけ自分で考えて、粘らずに、答えを見る。==それが、一番残ります。

## 基準は、1つです。「次に試すことが、まだあるか」

では、いつ見るのか。基準は、1つだけです。

```
　　次に試すことが、ある　→　続ける。手を動かす
　　次に試すことが、ない　→　答えを見る
```

図を、かいてみる。わかっている数字を、書き出してみる。前に解いた、似た問題のやり方を、あてはめてみる。試すことがある間は、前に進んでいます。粘る価値が、あります。

試すことが、なくなった。手が、止まった。問題文の同じ所を、また読んでいる。それが、見る合図です。そこから先は、何分かけても、変わりません。

## 時間は、目安として、先に決めておきます

手が止まっていることには、自分では、気づきにくいものです。だから、解く前に、目安の時間を、決めておきます。

```
　　単語や用語　　　　　　　　　→　5秒
　　数学で、最初の1行が書けない　→　3分
　　途中まで進んで、計算で詰まった→　10分
```

数字は、目安です。大事なのは、考え方です。==知らなければ出ないものは、短く。手を動かせば進むものは、長く。==単語は、知らなければ、出ません。だから、5秒です。計算は、やれば進みます。だから、長く取ります。自分に合う数字に、変えてかまいません。

## 答えを見たら、閉じて、もう1回解きます

答えを見るのは、負けでは、ありません。もったいないのは、見て、「なるほど」で終わることです。

2つの実験には、同じ所が、1つあります。はずしてから見る実験では、はずしたあとに、正解を見せています。見本を先に見る実験では、見本のあとに、自分で解かせています。残るのは、==見たあとに、自分で出した回数==のほうです。

```
　　単語　出てこない　→　答えを見る　→　隠して、もう1回言う
　　数学　手が止まった　→　解説を見る
　　　　　→　閉じて、最初の1行から、もう1回解く（16番）
```

見た問題を、その場で、何も見ずに、もう1回解けたら、OKです。

## 1周目は、先に解答を見ていいです

見本を先に見たほうがよかったのは、==その単元を初めてやる人==の時です。できるようになった人では、逆です。自力で解いたほうが、伸びます。だから、やることが変わります。

```
　　1周目　見たことのない問題　→　先に解答を見て、閉じて再現する
　　3周目　前にやった問題　　　→　先に自力で解く。試すことがある間は、粘る
```
