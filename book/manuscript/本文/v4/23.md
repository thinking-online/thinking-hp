## この1週間で、まちがえた問題は、どれでしたか？

学校のワークでも、問題集でも、小テストでも、かまいません。「何ページの、何番」で、3つ、答えてください。

……

答えられなかった人が、多いと思います。まちがえたことは覚えていても、どの問題だったかは、覚えていません。印がなければ、どれが解けなかったかは、わかりません。

わからないと、テストの前に、こうなります。「とりあえず、1番から、もう1周しよう」。1番。解けました。2番も、解けました。どちらも、1周目に、解けた問題です。

## 解ける問題を、もう一度解いても、点は増えません

1周目で、200問のうち、120問が解けたとします。2周目に、1番から全部解くと、その120問を、もう一度、解くことになります。==解く前から、解ける問題です。==

```
　　全部、もう1周　　　　200問。そのうち120問は、もう解ける
　　解けなかった所だけ　　 80問。全部が、点が増える問題
```

## ○△×を、問題番号の横に、記録します

記録は、3つの記号だけです。18番の根拠取りで決めた、○△×を、そのまま、問題番号の横に書きます。日付も、書いておきます。

```
　　12　　○ 6/3
　　13　　× 6/3　　△ 6/10
　　14　　△ 6/3　　○ 6/10
```

2周目は、△と×がついた問題だけを、解きます。○は、飛ばします。2周目で○になったら、3周目には、出てきません。周を重ねるたびに、やる量が、減っていきます。==残っている問題は、全部、自分がまだ解けない問題==です。問題集が、自分だけの弱点集に、変わっていきます。

## 「ここまでできたら、一回OK」を、先に決めます

記録していても、困ることがあります。「いつまで、この1冊を、回せばいいのか」。終わりが決まっていないと、不安で、いつまでも同じ本を回し続けるか、なんとなく、次の本に手を出すことになります。だから、始める前に、終わりの基準を、1行で決めます。

```
　　×　「この章を、ちゃんとできるようにする」　　　確かめられない
　　○　「章末問題10問を、何も見ずに、8問正解」　　確かめられる
```

10割には、しません。たまたま落とした1問のために、もう1周することに、なるからです。基準をこえたら、一回、OKにして、先へ進みます。

## 過去問とセットで、定点観測をします

もう1つ、大事なことがあります。問題集だけを、ずっと回していても、「今、どこまで、できるようになったのか」は、わかりません。だから、問題集と、過去問を、セットで使います。

問題集の区切りごとに、過去問を、1年分、解きます。17番と同じように、点と、単元ごとの正答率を、記録します。そして、前に解いた時の記録と、比べます。同じ物差しで、くり返し測る。これが、定点観測です。

「まだ、できていない気がする」。この感覚は、あてになりません。==どれだけ伸びて、どれだけ足りないのかを、事実で知る。==足りない所が見えたら、問題集の、その単元の△と×に、戻ります。1冊をやり込むことと、過去問で測ること。この2つを、行ったり来たりします。
