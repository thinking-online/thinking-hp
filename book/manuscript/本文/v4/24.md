## 筆箱が、ありません。最初に、何を考えますか？

……

「最後に使ったのは、どこだっけ」。こう考えたはずです。

```
　　1時間目　教室　　　あった
　　2時間目　理科室　　あった
　　――――――――――――――
　　3時間目　教室　　　ない
```

それなら、探す場所は、理科室と、帰りの廊下だけです。「あった」と「ない」の間に線を引くと、探す場所が、決まります。「全部わからない」と言って、学校じゅうを、1階から探す人は、いません。

ところが、勉強になると、こう言います。「この問題、全部わかりません」。

## 「全部わからない」は、禁止です

「この問題、わかりません」。「全部、わからないです」。この言い方を、今日から、禁止にしてください。「全部」と言った瞬間に、探す場所が、問題の全部になるからです。もう一度、最初から全部やるしか、なくなります。

でも、全部がわからない問題は、めったに、ありません。途中までは、わかっています。どこかの1か所で、止まっているだけです。

```
　　×　「この問題、全部わかりません」
　　○　「ここまでは、わかります。ここから、わかりません」
```

どこまで、わかっているのか。どこから、わからなくなるのか。==この2つに分けることが、分解です。==

## 「わかる」と「わからない」の間に、線を引きます

やることは、筆箱の時と、同じです。「どこまでは、あった？」を、「どこまでは、わかる？」に変えるだけです。解説を、上から、1行ずつ読みます。わかる行に、✓をつけます。✓がつかない最初の行。その上に、線を引きます。

```
　　1行目　✓
　　2行目　✓
　　3行目　✓
　　――――――――　ここに、線を引く
　　4行目　？　　ここから、わからない
　　5行目
```

線より上は、もう、わかっている所です。やり直さなくて、かまいません。==やるのは、線のすぐ下の、1行だけです。==「全部わからない問題」が、「4行目がわからない問題」に、変わります。質問する時も、調べる時も、その1行だけを、聞けばいいのです。

数学だけの話では、ありません。どの科目でも、線は引けます。

```
　　数学　式を立てる所までは、わかる　｜　その次の1行が、わからない
　　英語　単語の意味は、全部わかる　　｜　文の意味が、つながらない
　　国語　本文の内容は、わかる　　　　｜　答えの選び方が、わからない
```

1行目から✓がつかない時は、問題文に、線を引きます。「言葉の意味は、わかる」「何を聞かれているかは、わかる」「最初に何をすればいいかが、わからない」。線は、どこかに、引けます。

## 科目も、分解します

「数学が、苦手です」。これも、「全部わからない」と、同じ言い方です。数学の全部が、同じだけ苦手な人は、いません。単元ごと、大問ごとに、分けて見ます。

```
　　×　「数学が、苦手です」
　　○　「計算は9割。図形は3割。文章題は、式を立てる所で止まる」
```

模試の成績表には、大問ごと、分野ごとの点が、のっています。合計の点や、偏差値だけを見て、しまっていませんか。見るのは、そこでは、ありません。17番で作った、単元ごとの正答率の表も、同じ役目をします。

## みんな、ここを、見ようとしません

できなかった所を、細かく見るのは、いやな作業です。だから、多くの人が、サボります。点数だけを見て、「次は頑張ろう」で、終わりにします。

でも、ここを見ないと、戦略は、立てられません。何が、どのくらい、できていないのか。それがわかって、初めて、何から、どの順番でやるかが、決まります。==分解は、復習の中で、一番大事な作業です。==
