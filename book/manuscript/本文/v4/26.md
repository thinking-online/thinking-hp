日曜日の朝です。今日は、1日、空いています。

こんな時、あなたなら、どうしますか？

　　「今日は、3時間やろう」

机に向かいます。英語の教科書を開いて、読みます。ノートを、少し整理します。途中で、スマホを少し見ます。時計を見ると、3時間たっていました。

「よし、3時間やった」。満足して、終わります。

夜、聞かれます。「今日、何ができるようになった？」

……答えられません。

## 時間は、座っているだけで、過ぎます

「3時間やる」という計画は、3時間たてば、達成です。

その間に、何をしたかは、問われません。集中していても、ぼんやりしていても、3時間は、3時間です。

```
　　「3時間やる」　　　　　　　　　　座っていれば、終わる
　　「単語の51〜100を、閉じて言う」　言えるようになるまで、終わらない
```

絶対法則01で見た通り、「勉強した感じ」と、「点が上がる」は、別のものです。時間で立てた計画は、「勉強した感じ」のほうを、ゴールにしてしまいます。

テストは、何時間やったかを、聞いてきません。==聞かれるのは、何ができるか、だけです。==

## 「何を、どこまで」で決めます

計画は、時間ではなく、中身で書きます。

```
　　×　英語を1時間
　　○　英単語の51〜100を、閉じて、意味を言う

　　×　数学を2時間
　　○　問題集の△と×の12問を、解き直す

　　×　日本史を、がんばる
　　○　教科書の鎌倉時代を読んで、流れを、何も見ずに3つで言う
```

○のほうは、どれも、「終わったかどうか」が、自分でわかります。24番で決めた「終わりの条件」を、1日の大きさにしたものです。

こう決めると、変わることが、2つあります。

1つ目。早く終われば、早く休めます。「3時間」の計画では、速くやっても、得をしません。「ここまで」の計画では、==集中した分だけ、早く終わります。==

2つ目。終わらなかった時に、理由がわかります。「12問のうち、5問しかできなかった。1問に、思ったより時間がかかった」。次の計画を、直せます。

## 時間は、「どれだけ入るか」を見るために使います

時間を、見なくていいわけでは、ありません。

25番で、先週、実際にできた時間を見ました。それが、自分の入れ物の大きさです。

```
　　時間　　入れ物の大きさ。どれだけ入るかを、決める
　　中身　　その入れ物に、何を入れるか。計画に書くのは、こちら
```

例えば、入れ物が90分の日。「単語50個」と「数学12問」が、入るかどうか。入らないなら、中身を減らします。

入るかどうかがわからない時は、最初の1回だけ、測ってください。「数学1問に、8分かかった」。それがわかれば、次からは、入れ物に合った量を、決められます。

## 決める量は、少なめにします

最初は、「これなら、絶対終わる」と思う量にしてください。

多く書いて、終わらない日が続くと、計画を見るのが、嫌になります。少なく書いて、毎日終わるほうが、続きます。余ったら、次の日の分を、少しやれば、いいだけです。
