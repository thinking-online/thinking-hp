## 昨日、何時間、勉強しましたか？

……

では、もう1つ。昨日、新しくできるようになったことを、1つ、言ってください。

……

1つ目は、すぐ答えられたはずです。2つ目で、止まりませんでしたか。

時間は、数えています。できるようになったことは、数えていません。

こんな計画を、立てたことは、ありませんか。

```
　　「1日3時間、勉強する」
　　「19時から20時は、英語。20時から21時は、数学」
```

19時に、英語の教科書を開きます。読みます。ノートを、少し整理します。途中で、スマホを少し見ます。20時になりました。「よし、英語は終わり」。何ができるようになったかは、答えられません。

## 時間は、座っているだけで、過ぎます

「1時間やる」という計画は、1時間たてば、達成です。その間に、何をしたかは、問われません。集中していても、ぼんやりしていても、1時間は、1時間です。

でも、勉強の目的は、時間を達成することでは、ありません。点を上げることです。==「時間は、やった。でも、点は伸びていない」。==これでは、意味がありません。テストは、何時間やったかを、聞いてきません。聞かれるのは、何ができるか、だけです。

## 「ベストを尽くす」より、「ここまで」のほうが、人は動きます

1970年代に、アメリカの、木を切り出す現場で行われた、有名な実験があります。木を切るチームを、2つに分けました。片方には、「ベストを尽くしてください」とだけ伝えます。もう片方には、「ここまで切る」という、具体的な数字の目標を渡します。最初の週から、==目標を渡されたチームのほうが、多く切りました。==

もう1つ、あります。今度は、切った木を運ぶ、トラックの話です。場所は、アメリカのオクラホマ州。

トラックには、「ここまで積んでいい」という、重さの上限があります。運転手たちは、「ベストを尽くして積んでください」と言われていました。それでも、積んでいたのは、上限の約6割です。10本まで積めるトラックなら、6本ほどで走っていた、という計算です。

そこで、「ここまで積む」という、具体的で高い、数字の目標を渡しました。すると、積む量は、すぐに増えて、約9割になりました。10本積めるトラックで、6本だったものが、9本です。

「3時間やる」は、「3時間、ベストを尽くす」と同じです。どこまでやるかが、決まっていません。「ここまで」が決まると、人は、そこまでやります。

## 計画は、時間ではなく、ノルマで決めます

ノルマというのは、「今日は、ここまでやる」と決めた量のことです。計画を、時間ではなく、中身で書きます。

```
　　×　英語を1時間
　　○　英単語の51〜100を、隠して、意味を言えるようにする
　　×　数学を2時間
　　○　問題集の△と×の12問を、解き直す
　　×　19時から20時は、日本史
　　○　教科書の鎌倉時代を読んで、流れを、何も見ずに3つで言う
```

○のほうは、どれも、「やれたか、やれていないか」が、自分でわかります。23番で決めた「終わりの基準」を、1日の大きさにしたものです。

僕の塾でも、生徒の計画は、時間では決めません。1日ごとに、「何をやるか」を決めます。そして、見るのは、1つだけです。==ノルマを、やれたのか、やれていないのか。==

ノルマで決めると、いいことが、もう1つあります。早く終われば、早く休めます。「3時間」の計画では、速くやっても、得をしません。ノルマの計画では、集中した分だけ、早く終わります。

## 「絶対終わる」と思う量まで、減らします

時間を、見なくていいわけでは、ありません。時間は、ノルマが入るかどうかを見るために、使います。90分使える日に、「単語50個」と「数学12問」が、入るかどうか。26番の実績を見て、入らないなら、ノルマを減らします。

最初は、「これなら、絶対終わる」と思う量にしてください。多く書いて、終わらない日が続くと、計画を見るのが、嫌になります。少なく書いて、毎日終わるほうが、続きます。毎日終わるようになったら、少しずつ、増やします。実験で効いたのも、らくな目標ではなく、具体的で、少し高い目標でした。

## 終わったら線で消して、かかった時間を書きます

```
　　英単語の51〜100　　　→　線で消す。40分
　　問題集の△と×の12問　→　5問まで。1問に8分
```

終わらなかった時にも、理由がわかります。「1問に、8分かかった」。そうわかれば、次のノルマを、直せます。この記録が、26番の「実績」になります。
