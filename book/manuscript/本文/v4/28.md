## アプリやゲームの「連続記録」が切れた、次の日。開きましたか？

連続ログイン。連続日数。10日、20日と続いていたものが、1日忘れて、0に戻る。

その次の日、どうしましたか。

……

「もういいや」と、開かなくなった人が、多いと思います。

記録が切れた時に、やめたくなる。これは、誰にでも起きます。勉強でも、まったく同じことが起きます。

「今日から毎日、英語を2時間やる。1日も休まない」。そう決めて、3日続きました。4日目。部活の練習試合で、帰りが9時を過ぎました。疲れて、そのまま寝てしまいました。

5日目の朝。

　　「あーあ、途切れた。もういいや」

そこから、英語を開かなくなりました。

## 折れるのは、できなかった日ではありません。その次の日です

こうなる生徒を、何百人も見てきました。4日目にできなかったことは、たいした問題ではありません。次の日に戻れば、何も起きません。問題は、5日目です。「毎日やる」と決めた人にとって、1日の抜けは、==計画の全部が失敗したこと==に見えます。失敗したものを続ける理由がないので、やめます。

部活の試合。文化祭の準備。風邪。家の用事。いつも通りにいかない日は、必ず来ます。「毎日、同じだけやる」という計画は、こういう日が1日もないものとして、作られています。==この計画は、最初から崩れることが決まっています。==崩れたのは、あなたのせいではありません。

## 目標を、「最低」と「最高」の2つで書きます

決め方を、変えます。

```
　　×　毎日、2時間やる
　　○　最低1分。最高2時間。ゼロの日だけ、作らない
```

1つの数字ではなく、幅にします。ノートに、こう書きます。

```
　　英語　　最低：単語を1個、声に出す　　最高：2時間
```

調子がいい日は、2時間やります。部活で遅くなった日は、1分やります。単語を1個、声に出す。それで、その日は達成です。最低は、熱があってもできる量にします。寝る前に、1問だけ解いて、○をつけて寝る。それでいいんです。

## 1分で、何が変わるのか

1分では、力はつきません。それは、その通りです。1分で守っているのは、力ではありません。==「続いている」という事実==です。

0の日があると、次の日は「再開」になります。再開は、重いです。1でもやってあれば、次の日は「続き」です。続きは、軽いです。

## 0の日が出たら、次の日は、最低だけやります

やった時間を、カレンダーに書いていきます。1週間で、こうなります。

```
　　月　2時間　　火　10分　　水　1分（部活の試合）　　木　1時間
　　金　0（帰って、そのまま寝た）　　土　1分　　日　2時間
```

金曜日に、0が出ました。取り返そうとは、しません。次の日は、最低の1分だけやります。1分やってあれば、日曜日は、「続き」から始められます。

結果を出した生徒の記録を見ると、どの子も、でこぼこしています。3時間の日もあれば、10分の日もあります。共通しているのは、==0の日がほとんどない==ことだけです。目指すのは、1日も欠けない毎日ではありません。波があっても、続いている毎日です。
