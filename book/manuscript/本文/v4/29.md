## 昨日、スマホを見ていた時間は、何時間でしたか？

先に、予想を決めてください。決めたら、スマホの、使った時間の記録（スクリーンタイムなど）を、開いてみてください。

……

予想より、長かった人が、多いと思います。

「時間が足りない」と思った時、多くの人が最初に削るのは、寝る時間です。でも、削れる時間は、たいてい、別の所にあります。

テストの3日前。範囲が、まだ終わっていません。

　　「寝る時間を削ろう。終わるまで、寝られない」

いつもは12時に寝ますが、2時まで起きます。3日続けて、6時間増えました。

テストの日。問題を読んでも、頭に入ってきません。計算を、2回間違えました。覚えたはずのことが、出てきません。

## 覚えたものは、寝ている間に固まります

昼に覚えたことは、その時点では、まだ消えやすい状態です。寝ている間に、頭の中で整理されて、固まります。寝ないと、この作業が起きません。つまり、夜中の2時間で覚えたことは、寝ていないので、固まらないまま朝を迎えます。

単語を覚えたあと、そのまま寝たグループと、同じ時間ずっと起きていたグループを比べた実験があります。あとで思い出せた量は、==寝たグループのほうが多くなりました。==

寝不足の時は、思い出す力も落ちます。覚えているはずのことが、出てこなくなります。テストでやるのは、思い出すことです。一番落ちている力を、本番で使うことになります。

## 寝る時刻を、先に決めて、紙に書きます

「受験生なら10時間はやらないと」という声も、聞こえてきます。数え方を、変えてください。24時間から、先に引くものがあります。睡眠の7時間。食事。お風呂と身じたく。学校。これは、動かせない時間です。==引いたあとに残ったものが、あなたの「使える時間」==です。部活がある人なら、こうなります。

```
　　24時間
　　−　睡眠　　　　　　　　　　7時間（23時に寝て、6時に起きる）
　　−　学校と部活、行き帰り　　11時間
　　−　食事、お風呂、身じたく　2時間半
　　＝　使える時間　　　　　　　3時間半
```

だから、最初に決めるのは、勉強の時間ではなく、寝る時刻です。「23時に寝る」と、紙に書きます。

```
　　×　今日、何時間やったか
　　○　使える時間のうち、どれだけを勉強に使えたか
```

部活がある人と、ない人では、使える時間が違います。だから、「1日○時間」を人と比べても、意味がありません。

## 時間が足りない日は、睡眠ではなく、範囲を削ります

足りないことは、あります。その時は、削る順番があります。

```
　　1　まず、やることを減らす（捨てる）
　　2　次に、スマホの時間を削る
　　3　最後に、どうしてもなら、睡眠
```

睡眠は、一番最後です。そして、削るとしても、1時間までにしてください。2時間を超えると、頭の働きが、はっきり落ちます。

睡眠を削る前に、見つけておくものがあります。==何もしていない時間==です。1日だけ、記録してみてください。スマホをなんとなく見ていた時間。電車でぼーっとしていた時間。合計すると、たいてい1時間を超えます。

テストの前日だけは、どんな状況でも削らないでください。前日の夜に覚えたことは、たいした量ではありません。前日の寝不足で落ちる分のほうが、はるかに大きいです。前日は、いつもより30分早く寝るくらいでちょうどいいです。

## すきまの3分にやることを、1つ決めておきます

勉強というと、机に向かって、1時間は座るもの。そう思っている人が多いです。だから、短い時間は、「何もできない時間」になります。でも、絶対法則02を思い出してください。点になるのは、思い出した回数でした。==思い出すのに、机はいりません。==

```
　　電車を待つ3分　　単語を5個、目を閉じて言う
　　休み時間の2分　　さっきの授業を、「結局、何の話？」で言う
　　お風呂の5分　　　今日やった解き方を、頭から言ってみる
```

この中から、1つだけ、先に決めておきます。「電車を待つ時は、単語を5個」。1回は短くても、1日に5回あれば、5回思い出しています。

## 昼に眠くなったら、15分だけ寝ます

夜はしっかり寝る。そのうえで、昼に眠くなった時は、がまんしないでください。眠いまま1時間座っているより、15分寝て、45分やるほうが進みます。タイマーをかけて、机に伏せて寝ます。眠れなくても、目を閉じているだけでいいです。
