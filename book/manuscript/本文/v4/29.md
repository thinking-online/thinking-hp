## アプリやゲームの「連続記録」が切れた、次の日。開きましたか？

連続ログイン。連続日数。10日、20日と続いていたものが、1日忘れて、0に戻る。その次の日、どうしましたか。

……

「もういいや」と、開かなくなった人が、多いと思います。記録が切れた時に、やめたくなる。これは、誰にでも起きます。勉強でも、同じことが起きます。

例えば、「今日から毎日、英語を2時間やる。1日も休まない」と決めた人。3日、続きました。4日目。部活の練習試合で、帰りが9時を過ぎて、そのまま寝てしまいました。5日目の朝。「あーあ、途切れた。もういいや」。そこから、英語を開かなくなりました。

## 「どうにでもなれ効果」は、本当にあります

これには、名前がついています。「どうにでもなれ効果」です。面白い名前ですが、本当にあります。

ダイエットの研究で、見つかりました。ダイエット中の人に、先に、ミルクセーキを飲んでもらいます。そのあとで、アイスクリームを、好きなだけ食べてもらいます。すると、大きいミルクセーキを飲んだ人のほうが、小さいのを飲んだ人より、アイスクリームを、多く食べました。「今日は、もう、ダイエットは失敗だ。どうにでもなれ」。==1回くずれると、全部を投げ出してしまう==のです。

勉強でも、同じです。こうなる生徒を、何百人も見てきました。折れるのは、できなかった4日目では、ありません。その次の、5日目です。

## 目指すのは、完璧な継続ではなく、波のある継続です

「毎日2時間。1日も休まない」。これは、完璧な継続です。完璧な継続は、1日でも欠けたら、そこで「失敗」になります。でも、部活の試合。文化祭の準備。風邪。いつも通りにいかない日は、必ず来ます。==完璧な継続は、最初から、崩れることが決まっています。==崩れたのは、あなたのせいでは、ありません。

```
　　完璧な継続　　毎日、同じだけやる。1日欠けたら、失敗
　　波のある継続　多い日も、少ない日もある。0の日だけ、作らない
```

目指すのは、下です。2時間の日があっても、1分の日があっても、かまいません。守ることは、1つだけ。==0にしない==ことです。

## 「0にしない」ために、MinとMaxを決めます

決めることは、3行です。

```
　　ルール　0の日を、作らない
　　Min　　どんな日でも、これだけはやる　→　単語を1個、声に出す
　　Max　　調子がいい日は、ここまでやる　→　今日のノルマを、全部
```

Min（最低）は、0にしないための量です。だから、熱がある日でもできるくらい、小さくします。1分で終わる量です。Minを大きくすると、それができなかった日に、また「どうにでもなれ」が起きます。Max（最高）は、調子がいい日の上限です。

部活で遅くなった日は、Minだけやります。単語を1個、声に出す。それで、その日は、達成です。調子がいい日は、Maxまでやります。MinとMaxの間なら、どこで終わっても、かまいません。

1分では、力はつきません。それは、その通りです。1分で守っているのは、力では、ありません。==「続いている」という事実==です。0の日があると、次の日は「再開」になります。再開は、重いです。1でもやってあれば、次の日は「続き」です。続きは、軽いです。

## それでも0の日が出たら、次の日は、Minだけやります

0の日が出ても、取り返そうと、しません。次の日は、Minの1分だけ、やります。それで、波に戻れます。

```
　　月　2時間　　火　10分　　水　1分（部活の試合）　　木　1時間
　　金　0（帰って、そのまま寝た）　　土　1分　　日　2時間
```

結果を出した生徒の記録を見ると、どの子も、こういう形をしています。3時間の日もあれば、10分の日もあります。共通しているのは、==0の日が、ほとんどない==ことだけです。
