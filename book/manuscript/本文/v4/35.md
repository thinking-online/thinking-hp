## 「あれもやらなきゃ、これもやらなきゃ」。そう思っているうちに、1日が終わったことは、ありませんか？

……

あると思います。やる気は、ありました。机にも、向かいました。でも、数学を解いている途中で、「あ、英語の課題、明日までだ」。英語を開くと、「理科のレポートも、あった」。どれも、少しずつ手をつけて、どれも、終わっていません。

「やらなきゃ」は、別のことをやっている間も、消えていません。頭のどこかに、ずっと、残っています。いくつも抱えたままだと、目の前の1つに、力を回せません。

集中できないのは、意志が弱いからでは、ありません。==抱えたままの「やらなきゃ」が、多すぎるからです。==

## 「決めていないこと」は、頭を使い続けます

31番で見た通り、頭が一度に扱える量は、多くありません。

アメリカの大学の研究者たちの実験です。「まだ終わっていない用事」を抱えた人に、それとは関係のない文章を、読んでもらいました。読んでいる間も、用事のことが、何度も頭に浮かびました。別の課題の成績も、落ちました。

ところが、その用事を、「いつ、どうやるか」まで決めてもらうと、じゃまは、消えました。用事は、まだ、1つも終わっていません。==終わらせなくても、決めるだけで、頭から降りたのです。==

集中できる人は、用事が少ない人では、ありません。決めてある人です。

## 全部に全力は、最初から、入りきりません

では、全部を「やる」と決めれば、いいのでしょうか。それは、できません。

例えば、数学の先生が、「1時間くらいで終わる量」の課題を出します。英語の先生も、「1時間くらい」。理科の先生も、古典の先生も、「1時間くらい」。1つ1つは、無理のない量です。でも、4つ合わせると、4時間です。部活のあとの夜に、4時間は、入りません。

先生たちは、ほかの教科で何が出ているかを、知りません。==合わせて何時間になるかを、計算している人は、1人もいないのです。==誰も、悪くありません。計算できるのは、全部を受け取っている、あなただけです。

だから、全部に全力を出すのは、えらいことでは、ありません。入りきらないものを、全部抱えれば、どれも終わらず、頭の中に、ずっと残ります。==同じゴールに、より少ない力で届く。それが、正しいやり方です。==

## 選んで、全力を出します

やることは、1つです。==頭の中の「やらなきゃ」を、全部、「いつ、やる」か、「やらない」に、変えます。==

「やらなきゃ」を、紙に書き出します。そして、1つずつ、2つのことを確かめます。気持ちでは、決めません。見ればわかる事実で、決めます。

```
　質問1　点になる？　（入試の科目か、次のテストの範囲に、入っているか）
　質問2　期限がある？（出す日や、テストの日が、決まっているか）
```

答えは、4通りしか、ありません。

```
　①　点になる　・　期限がある　→　今日、全力
　②　点になる　・　期限がない　→　毎日の決まった時間に、全力
　③　ならない　・　期限がある　→　短く終わらせる
　④　ならない　・　期限がない　→　やらない
```

例えば、①は、明日の英語の小テスト。②は、入試に向けた、英語の長文。③は、入試で使わない教科のレポート。④は、希望する人だけの補習です。中学生で、内申が入試に使われる人は、提出物や小テストも、「点になる」に入ります。

気をつけるのは、②です。人は、期限があるものから、手をつけます。期限があるというだけで、得るものが小さいほうを選んでしまうことは、実験でも、確かめられています。何も決めないと、①と③だけで、1日が終わります。誰にも催促されない②は、いつまでも、後回しです。でも、==成績を一番動かすのは、②です。==

だから、先に、②の時間を取ります。一番進む時間帯に、置きます（33番）。③は、「木曜に、40分」のように、いつ、何分でやるかを決めて、その中で終わらせます。④は、やらない、と決めます。

書き終わった紙に、「やらなきゃ」は、もう、1つもありません。頭に残るのは、今やる1つです。

ブレない人は、性格が強いのでは、ありません。決めてあるから、ブレないのです。==やらないことを決めた人だけが、やると決めたことに、頭の全部を使えます。==
