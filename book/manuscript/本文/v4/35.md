## 虫めがねで、太陽の光を集めて、紙を焦がしたことは、ありますか？

小学校の理科で、やったと思います。

……

光を広げたままだと、紙は、少し温かくなるだけです。何分待っても、焦げません。ところが、1点に集めると、すぐに、煙が出ます。同じ太陽の、同じ光です。

==力も、同じです。広げると、何も起きません。集めた所でだけ、変化が起きます。==

こんな経験は、ありませんか。火曜日。学校から、これだけ出されました。

```
　　数学の課題プリント　2枚
　　英語の小テスト　　　明日
　　理科のレポート　　　金曜に提出
　　古典の予習　　　　　明日、当たる
```

「出された以上、全部ちゃんとやらないと」。全部を、同じ本気でやりました。終わったのは、夜の11時です。自分でやると決めていた英語の長文は、1問も、開けませんでした。次の日も、同じです。

## 全部に全力は、最初から、入りきりません

数学の先生は、数学のことだけを考えて、課題を出します。英語の先生も、理科の先生も、同じです。それぞれが、「これくらいなら」と思う量を出しています。でも、その全部を、==足し算した人は、どこにもいません。==

誰も、悪くありません。足し算する人が、いないだけです。足し算するのは、あなたです。

しかも、31番と33番で見た通り、頭が一度に扱える量も、深く集中できる時間も、限られています。全部に全力を配れば、どれも、薄くなります。

## 全力を出す所を、選びます

04番で、ゴールから、やらないことを決めました。同じことを、毎日、学校から出るものにも、やります。出されたものを書き出して、3つに分けます。

```
　1　出さないと困るもの　→　時間を決めて、短く終わらせる
　2　点につながるもの　　→　ここに、全力
　3　どちらでもないもの　→　やらない。受けない
```

さっきの火曜日なら、こうなります。英語と数学で受験する人の場合です。

```
　　数学の課題プリント　→　2　閉じて、もう一度解く所まで
　　英語の小テスト　　　→　2　小テストは、定期テストの予告
　　理科のレポート　　　→　1　木曜に、40分と決めて書く
　　古典の予習　　　　　→　1　当たる所だけ、15分
```

大事なのは、==1と2を、混ぜないこと==です。1は、「終わらせる作業」です。先に時間を決めて、その中で終わらせます。2は、「できるようになる作業」です。終わっても、できていなければ、意味がありません。2には、33番でつかんだ、一番進む時間を使います。

迷うものは、自分に聞きます。「これが終わった時、何ができるようになっている？」。答えが出ないものは、3です。

中学生で、内申が入試に使われる人は、提出物も、小テストも、実技の教科も、2です。入試の点、そのものだからです。何が内申に入るかは、先生に確かめてください。

## 「それは、手抜きや、逃げになりませんか」

なりません。手を抜くとは、時間をかけたまま、中身だけ薄くすることです。答えを写して出す課題が、そうです。1時間使って、何も残りません。1を短く終わらせるのは、その逆です。

逃げかどうかは、==空いた時間を、何に使ったか==で決まります。

```
　　空いた1時間で、動画を見た　　　　→　逃げ
　　空いた1時間で、長文を2本読んだ　→　選んだ
```

だから、1を短くしたら、空いた時間に入れる「2」を、同時に決めます。
