## 「できる」も「できない」も、そこで話が終わります

「ポジティブに考えよう」「自分を信じよう」。よく言われます。ニューヨーク大学の研究者たちが、長く続けている研究があります。うまくいく場面を、強く、明るく思い描いた人ほど、==そのあとの行動が減り、結果も出にくかった==というものです。

35番で書いたのと、同じことが起きています。「自分はできる」と言い聞かせると、気持ちが楽になります。その楽さで、少し満足します。だから、次の模試までに、やることが変わりません。

じゃあ、落ちこんだままでいいのか。それも、違います。面談で、一番よく聞く言葉は、「自分、数学できないんで」です。この言葉を言った瞬間に、話が終わります。できないのだから、やってもしょうがない。やらないので、できないままになる。「自分はできる」も、「自分はできない」も、同じです。==どちらも、そこで終わっている==んです。

## 1語だけ、足します

　　自分は、数学が、==まだ==できない。

この文は、終わっていません。「まだ」と言った瞬間に、じゃあ、いつできるのか、という続きが必要になります。==どう言うかで、次にどこを見るかが決まる==という話です。

「数学ができない」では、どこを見ればいいのか、わかりません。数学は、大きすぎます。「まだ」を足すと、言い直したくなります。全部ができないわけではないからです。計算はできる。基本問題も解ける。だから、「何が」まだなのかを、小さく言います。

```
　　自分は、数学ができない
　　→　自分は、数学が、まだできない
　　→　二次関数の最大値が、まだ出せない
　　→　今日、教科書の、最大値のページを開く
```

ここまで小さくなれば、今日やることが、1つに決まります。教科書のそのページを開けばいい。「まだ」を足すと、できないところが、小さくしぼられます。前向きになるからではなく、==正確になるから==です。

## つまずきを、「限界」と呼ぶか、「途中」と呼ぶか

難しい問題にぶつかった時、頭の中で起きることは、2通りあります。

```
　　「できない」　　　→　自分の力の、限界だと受け取る　→　やめる
　　「まだできない」　→　今、途中にいると受け取る　　　→　続ける
```

スタンフォード大学の研究者たちの研究では、力は伸ばせるものだと考えている生徒のほうが、難しい問題にぶつかった時に、やめずに続ける傾向がありました。

## 無理に、明るくならなくていいです

落ちこんで、いいです。うれしくないものを、うれしいふりをする必要はありません。やるのは、気持ちを変えることではなく、==事実を、そのまま、正確に言うこと==です。

　　「今、二次関数の場合分けが、まだできていない」

暗い言葉ではありません。明るい言葉でもありません。正しい言葉です。そして、正しい言葉からは、次にやることが出てきます。
