## 心の中で、3回、言ってみてください。「自分は、天才だ」

……

信じられましたか。

言いながら、どこかで、「いや、そんなわけないし」という声が、聞こえたと思います。自分が本当だと思っていない言葉は、何回言っても、信じられません。

例えば、数学の模試が、返ってきた時。また、40点です。落ち込みます。「大丈夫。自分はできる。次は、絶対いける」。気持ちは、少し、楽になりました。そして、次の模試。40点でした。

## 「できる」も「できない」も、そこで話が終わります

「ポジティブに考えよう」「自分を信じよう」。よく言われます。でも、「自分はできる」と言い聞かせても、やることは、何も変わっていません。変わったのは、気分だけです。だから、次の点も、変わりません。

では、落ち込んだままが、いいのか。それも、違います。相談で、一番よく聞く言葉は、「自分、数学できないんで」です。この言葉を言った瞬間に、話が終わります。できないのだから、やっても、しょうがない。やらないので、できないままになります。

「自分はできる」も、「自分はできない」も、同じです。==どちらも、言い切って、そこで終わっています。==

## 1語だけ、足します

```
　　自分は、数学が、まだ、できない。
```

この文は、終わっていません。「まだ」と言った瞬間に、「じゃあ、何が、まだなのか」という続きが、必要になります。「まだ」は、英語で、Not Yet。この本では、「Not Yet思考」と呼びます。

「数学ができない」では、どこを見ればいいのか、わかりません。数学は、大きすぎます。全部が、できないわけでは、ないはずです。計算は、できる。基本問題も、解ける。だから、「何が」まだなのかを、小さく言います。

```
　　自分は、数学ができない
　　→　自分は、数学が、まだできない
　　→　二次関数の最大値が、まだ出せない
　　→　今日、教科書の、最大値のページを開く
```

ここまで小さくなると、今日やることが、1つに決まります。「まだ」を足すと、動けるようになるのは、前向きになるからでは、ありません。==正確になるからです。==

## 「不合格」ではなく、「まだ」とつける高校があります

アメリカのシカゴに、単位を落とした生徒の成績を、「不合格」ではなく、「Not Yet（まだ）」とつける高校があります。スタンフォード大学の研究者が、講演で紹介した話です。「不合格」は、そこで終わりです。「まだ」は、途中です。

この研究者たちは、アメリカの高校1年生、約1万2000人で、実験もしています。「頭の力は、やり方しだいで、伸ばせる」という考え方を、1時間足らず、学んでもらいました。成績が下のほうだった生徒たちの成績が、上がりました。大きな差では、ありません。でも、1時間足らずで、です。

## 無理に、明るくならなくていいです

落ち込んで、いいです。うれしくないものを、うれしいふりをする必要は、ありません。Not Yet思考は、2つで、できています。「今は、できない」と、認めること。そして、「でも、できるようになる」と、考えること。できない自分を、ごまかしません。

```
　　今、二次関数の場合分けが、まだできていない。
```

暗い言葉では、ありません。明るい言葉でも、ありません。正しい言葉です。そして、==正しい言葉からは、次にやることが、出てきます。==
