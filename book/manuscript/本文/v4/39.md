信じられましたか。

言いながら、どこかで、「いや、そんなわけないし」という声が、聞こえたと思います。自分が本当だと思っていない言葉は、何回言っても、信じられません。

例えば、数学の模試が、返ってきた時。また、40点です。落ち込みます。「大丈夫。自分はできる。次は、絶対いける」。気持ちは、少し、楽になりました。そして、次の模試。40点でした。

## ただのポジティブも、ただのネガティブも、考えているようで、考えていません

「ポジティブに考えよう」「自分を信じよう」。よく言われます。でも、「次は、絶対いける」と言い聞かせた時、決まったことは、何でしょうか。何も、決まっていません。変わったのは、気分だけです。36番の、いい結果だけを思い描いたグループと、同じです。やることが同じなので、次の点も、同じです。

では、落ち込むほうが、ちゃんと考えているのか。それも、違います。相談で、一番よく聞く言葉は、「自分、数学できないんで」です。深く悩んでいるように、聞こえます。でも、この言葉を言った瞬間に、話は終わります。できないのだから、やっても、しょうがない。ここでも、何も、決まっていません。

```
　　ただのポジティブ　「次は、絶対いける」　→　次にやること：なし
　　ただのネガティブ　「自分は、できない」　→　次にやること：なし
```

向きは、逆です。でも、着地している場所は、同じです。==どちらも、気持ちに答えを出しただけで、「次、どうするか」が、ありません。==30分悩んで、頭を使った気はします。でも、やることは、1つも、決まっていません。考えているようで、考えていないのです。

前向きなのが、悪いのでは、ありません。そこで止まるのが、もったいないのです。

## 魔法の言葉「まだ」を1語だけ、足します

```
　　×　数学が、できない
　　○　数学が、まだ、できない
```

足したのは、1語だけです。でも、そのあとに続く言葉が、変わります。

「できない」のあとに続くのは、「だから、やっても、しょうがない」です。話は、そこで終わります。

「まだ、できない」のあとに続くのは、「じゃあ、この後、どうする？」です。「まだ」という言葉には、「いつかは、できるようになる」が、入っています。だから、その方法を、考えられます。

「まだ」は、英語で、Not Yet。この本では、この考え方を、「Not Yet思考」と呼びます。やることは、2つだけです。「できない」と思ったら、「まだ」を足す。そして、==「じゃあ、この後、どうする？」と、自分に聞く。==

```
　　数学が、まだ、できない
　　→　じゃあ、この後、どうする？
　　→　まず、二次関数の最大値から、やり直す
　　→　今日、教科書の、最大値のページを開く
```

ただのポジティブにも、ただのネガティブにも、なかった「次、どうするか」が、ここで、初めて、出てきました。

## 「不合格」ではなく、「まだ」とつける高校があります

アメリカのシカゴに、単位を落とした生徒の成績を、「不合格」ではなく、「Not Yet（まだ）」とつける高校があります。スタンフォード大学の研究者が、講演で紹介した話です。「不合格」は、そこで終わりです。「まだ」は、途中です。

この研究者たちは、アメリカの高校1年生、約1万2000人で、実験もしています。「頭の力は、やり方しだいで、伸ばせる」という考え方を、1時間足らず、学んでもらいました。成績が下のほうだった生徒たちの成績が、上がりました。大きな差では、ありません。でも、1時間足らずで、です。

## 無理に、明るくならなくていいです

落ち込んで、いいです。うれしくないものを、うれしいふりをする必要は、ありません。Not Yet思考は、2つで、できています。「今は、できない」と、認めること。そして、「でも、できるようになる」と、考えること。できない自分を、ごまかしません。

```
　　二次関数の最大値が、まだ出せない。
```

暗い言葉では、ありません。明るい言葉でも、ありません。本当のことを、そのまま言った言葉です。そして、==そのあとに、「じゃあ、この後、どうする？」が、続きます。==
