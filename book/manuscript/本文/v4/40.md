## 今から、白いクマのことを、絶対に、考えないでください

どうぞ。

……

考えましたね。

「考えるな」と言われると、頭は、「今、考えていないか」を、確かめ続けます。確かめるたびに、白いクマが、出てきます。

不安も、同じです。こんな経験は、ありませんか。夜の10時。参考書を開いています。目は、字を追っています。でも、頭は、別のことを考えています。「このままで、間に合うのかな」「落ちたら、どうしよう」。「考えるな。集中しろ」。そう言い聞かせて、1時間。進んだのは、3ページです。

## 不安は、消そうとするほど、大きくなります

不安になるのは、弱いからでは、ありません。サボっている人は、不安になりません。==不安は、本気でやっている人にしか、出てきません。==

真面目な人ほど、その不安を、気合いで消そうとします。でも、白いクマと同じです。消そうとするほど、考え続けます。

しかも、「このままで、間に合うのかな」は、今、いくら考えても、答えが出ません。答えが出ないことを考えている間も、勉強している気は、します。真剣だからです。だから、手が止まっていることに、気づけません。

消そうとするのを、やめます。==置く場所を、変えます。==頭の中から、紙の上へ。

## 紙に全部書いて、裏返して、10分だけ手を動かします

```
　　①紙を1枚出して、今、不安なことを、全部書く。5分（目安です）
　　②1つずつ、「今日の自分に、できることは、ある？」と聞く
　　　ある　→　今日やることを、横に1つ書く
　　　ない　→　何も書かない
　　③紙を裏返して、10分だけ、一番軽いものをやる
```

書くのは、35番で、頭の中の「やらなきゃ」を紙に出したのと、同じ理由です。紙に出したものは、頭の中で、持ち続けなくて、よくなります。

②で、不安は、2つに分かれます。

```
　　このやり方で、合ってるのかな　→　ある。10分やって、閉じて言えるか試す
　　このままで、間に合うのかな　　→　ある。残りの週と、1週間に上げる点を出す
　　落ちたら、どうしよう　　　　　→　ない。書いて、置いておく
```

「落ちたら、どうしよう」に、今日できることは、ありません。==解決するものではなく、置いておくものです。==これを、ほかの2つと同じように考え続けるから、終わらなくなります。

③は、単語10個でも、計算3問でも、かまいません。手を動かす前は、やることが、「全部」残っていました。10分やったあとは、「残り」になっています。減るとわかると、次の10分に、入れます。

涙が止まらない。眠れない日が、続く。何日も、机に向かえない。そういう時は、勉強のやり方の問題では、ありません。先に、人に言ってください。親でも、先生でも、誰でも、いいです。勉強の話は、そのあとで、間に合います。

## 本番の緊張は、「ワクワクしている」と言いかえます

試験の直前。心臓が、速くなります。「落ち着け、落ち着け」。言うたびに、落ち着いていない自分に気づいて、もっと、あせります。これも、白いクマです。

```
　　緊張している時　　　心臓が速い　手に汗をかく　そわそわする
　　ワクワクしている時　心臓が速い　手に汗をかく　そわそわする
```

体に起きていることは、同じです。違うのは、それを、何と呼ぶかだけです。だから、落ち着こうとするかわりに、心の中で、こう言います。

```
　　ワクワクしている。体が、本気を出す準備をしている。
```

ハーバード大学の研究者たちの実験です。大事な試験をひかえた学生の一部に、「緊張は、成績を下げるものではなく、助けるものだ」と伝えました。伝えられた学生たちは、練習の試験でも、そのあとの本番でも、数学の点が、高くなりました。

==変えるのは、体ではなく、呼び方です。==普段の小テストや模試で使っておくと、本番で、自然に出ます。試験の前に、不安が頭を回る時も、やることは同じです。紙に書いて、裏返します。
