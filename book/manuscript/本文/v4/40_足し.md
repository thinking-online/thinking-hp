## 本番の前も、同じです。10分前に、紙に出します

試験が始まる、15分前。席に座っています。参考書を開いていますが、頭に入ってきません。

　　落ちたらどうしよう。
　　あの単元、やってない。
　　周りの人、みんなできそうに見える。

「落ち着け。考えるな」。そう思ったとたん、もっと考えます。

やることは、普段と同じです。

```
　　試験開始の10分前。
　　紙を1枚出して、今、不安に思っていることを、全部書く。
　　5分。きれいに書かなくていい。文にならなくていい。
```

書いたら、その紙は裏返します。見返さなくていいです。捨ててもいいです。

シカゴ大学の研究者たちの実験です。試験の直前に10分だけ、今、不安に思っていることを紙に書き出してもらったグループと、関係のないことを書いたグループで、試験の点を比べました。==書き出したグループのほうが、点が高くなりました。==差が一番大きかったのは、普段から試験で不安が強くなる学生でした。

書くのは、不安そのものです。対策では、ありません。ここで「じゃあ図形を10分でやろう」としないでください。10分で図形はできません。できないことを始めると、不安が増えます。

## 緊張は、「ワクワクしている」と言いかえます

紙を裏返したあと、まだ心臓が速いことがあります。手が冷たくて、息が浅い。

落ち着け、落ち着け、と心の中で言います。言うたびに、落ち着いていない自分に気づきます。余計に焦ります。

落ち着こうとしても、すぐには落ち着けません。上がっている心拍数を、1分で下げるのは、無理があります。無理なことをやろうとして、できなくて、焦る。焦るので、もっと上がります。

ここで、知っておいてほしいことがあります。

```
　　緊張している時　　　　心臓が速い　手が冷たい　息が浅い　体が熱い
　　ワクワクしている時　　心臓が速い　手が冷たい　息が浅い　体が熱い
```

体に起きていることは、同じです。違うのは、それを自分が何と呼んでいるかだけです。

```
　　「やばい、緊張してる」　　　→　体は敵
　　「よし、ワクワクしてきた」　→　体は味方
```

だから、落ち着こうとするかわりに、こう言います。

```
　　ワクワクしている。
　　体が、本気を出す準備をしている。
```

声に出さなくていいです。心の中で3回。心拍数は、下がりません。下げる必要が、ありません。==変えるのは、体ではなく、呼び方です。==1秒でできます。

息が苦しい時だけ、もう1つあります。吐くほうを、長くします。4秒で吸って、8秒で吐く。これを3回。

言いかえは、会場に着く前から使えます。電車でそわそわする。手が冷たい。開始1分前。全部、「ワクワクしている」です。普段の小テストや模試で使っておくと、本番で、自然に出ます。
