## 洗濯機があるのに、毎日、服を手で洗っている人がいます。どう思いますか？

理由を聞くと、こう言います。「自分の手で洗わないと、きれいにならない気がして」。

……

「洗濯機を使って、空いた時間で、ほかのことをすればいいのに」。そう思ったはずです。

勉強でも、同じことが、起きています。

例えば、志望校の過去問が、5年分あります。どの単元がよく出るのかを、表にまとめたい。AIを使えば、すぐにできます。でも、「AIを使うのは、ズルな気がする」。自分で、大問ごとに書き出して、数えます。3日かかりました。問題は、まだ、1問も解いていません。

## 自分でやる所と、任せる所を、分けます

43番で、AIに答えを聞かない、と書きました。力がつく作業を、AIにやらせてしまうからです。では、力がつかない作業は、どうでしょうか。

```
　　力がつく　　　思い出す。解く。説明する。直す　　→　自分でやる
　　力がつかない　調べる。集める。数える。整理する　→　任せていい
```

3日かけて表を作っても、数学の力は、つきません。AIなら、数分です。==空いた3日で、問題を解く。==それが、頭のいい使い方です。全部を自分でやることが、えらいわけでは、ありません。

## AIに作ってもらうものは、3つあります

僕の塾生が、実際に、やり切っているものです。

```
　　①未来問　　　　　　過去問と同じ形式の、新しい問題
　　②大問別の対策問題　自分が落としている大問だけの問題
　　③苦手メモの問題　　間違えた所だけを集めた、自分専用の問題
```

①は、過去問を見せて、「同じ形式、同じ難しさの問題を、新しく作って」と頼みます。過去に出た問題ではなく、==これから出そうな問題==です。過去問は、数に、かぎりがあります。未来問は、いくらでも作れます。

②は、24番で分けた、大問ごとの正答率を使います。一番低い大問を、1つ選びます。「大問3と同じ形式の長文を、5題作って」。苦手な大問だけを、できるまで、やり切れます。

③は、間違えた問題と、覚えられない言葉だけを、メモにためておきます（23番）。そのメモをAIに渡して、こう頼みます。

```
　　「このメモから、5問、問題を出して。
　　　答えは、僕が答えたあとに、教えて」
```

毎日、同じメモを渡して、同じ頼み方をするだけです。何を思い出すかを、自分で選ばなくて、よくなります。絶対法則02の「思い出す」を、==気合いではなく、仕組みにするのです。==

どれも、作ってもらっただけでは、力は、つきません。その日のうちに、自分で解きます。AIが作った問題や答えにも、間違いは、あります。おかしいと思ったら、解説で確かめます。

ほかにも、任せていい作業は、あります。覚えにくい単語を、絵や場面にしてもらう（14番）。選択肢がなぜ違うのかを、説明してもらう（18番）。英作文を、添削してもらう（43番）。

## 「AIを使うのは、ズルな気がします」

その気持ちは、まともです。ただ、任せるのは、力がつかない作業だけです。使い方を決めれば、AIは、いつでも横にいる家庭教師にもなります。

ハーバード大学の研究者たちの実験です。答えをすぐには言わず、ヒントを出しながら、1人ずつのペースに合わせるように作られたAIで学んだ学生は、普通の授業で学んだ学生より、==短い時間で、よく身についていました。==

## 道具は、変わります。変わらないものが、1つあります

AIは、どんどん進化します。ここに書いた使い方も、何年かたてば、古くなります。変わらないのは、==どこを任せて、どこを自分でやるかを、決める力==です。思い出す。負荷をかける。そこだけは、どんな道具が出てきても、自分でやってください。

守ることは、2つです。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。
