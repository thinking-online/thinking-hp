## 1,000円払った映画が、つまらない。残りは、1時間半。最後まで、見ますか？

……

見る人が、多いと思います。理由は、「1,000円、払ったから」。

でも、その1,000円は、最後まで見ても、途中で出ても、戻ってきません。違うのは、これからの1時間半だけです。つまらない映画に、1,000円と、1時間半を使うか。1,000円だけで、すませるか。==「もったいない」で選んだほうが、多く、失っています。==

勉強でも、同じことが、起きています。

```
　　お金　　「せっかく買った参考書だから、最後までやる」
　　時間　　「ここまで15分考えたから、もう少し粘る」
　　やり方　「今まで、ずっと、書いて覚えてきたから」
```

## 「もったいない」が見ているのは、「これまで」です

ものを大事にする。途中で投げ出さない。真面目な人ほど、そうします。その姿勢は、まちがっていません。

ただ、さっきの3つが見ているのは、全部、「これまで」です。払ったお金。使った時間。どちらも、もう、戻ってきません。戻ってこないお金や時間のことを、「サンクコスト」と言います。「沈んで、もう取り出せない費用」という意味です。

人は、これに、引っぱられます。オハイオ大学の研究者たちの実験です。劇場の年間チケットを、定価で買った人と、割引で買った人がいました。シーズンの前半、多く通ったのは、定価で買った人でした。同じ劇場の、同じチケットです。違うのは、払った金額だけでした。

やめたら、払った分が、無駄になる気がします。でも、払った分は、もう、使い終わっています。==続けて失うのは、「これから」の時間です。==

## 決める時に見るのは、「これから」だけです

迷ったら、自分に、こう聞きます。

```
　　今日、ゼロから選ぶなら、これを選ぶ？
```

まだ、1円も払っていない。1分も使っていない。そう思って、選び直します。選ぶなら、続けます。選ばないなら、変えます。

例えば、2週間使った参考書。10問のうち、ほとんど全部で、手が止まります。今日、本屋で選び直すなら、この本は、選びません。だから、変えます（25番）。2週間は、無駄では、ありません。「今の自分には、重すぎる」と、わかりました。

逆も、あります。しんどいけれど、止まるのは、10問のうち、2問から4問。ゼロから選んでも、この本を選びます。だから、続けます。「飽きた」も、「せっかく」も、その場の気持ちです。==その場の気持ちでは、決めません。これからの時間が、短くなるほうを、選びます。==

やり方も、同じです。この本を読んで、「でも、今まで、こうやってきたし」と思った所が、あったかもしれません。それも、「これまで」です。今日、ゼロから選ぶなら、どちらのやり方を選ぶか。それだけで、決めます。==アップデートとは、「これから」で、選び直すことです。==

## お金を使う時も、「これから」で決めます

本屋で、迷っています。1,500円の、今の自分に合った参考書。家にある、兄のお古の本。こちらは、解説を読んでも、よくわかりません。「お金がもったいない。家にあるほうで、いいや」。

これも、その場の「もったいない」です。お古の本で、1日20分、止まったとします。3か月で、30時間です。1,500円を守って、30時間を、使いました。入試までの日数は、誰にも、増やせません。==勉強で一番高いのは、お金ではなく、時間です。==

だから、値段を見る前に、「これで、これからの時間は、短くなる？」と聞きます。短くなるなら、無駄づかいでは、ありません。時間を、買っています。短くならないものは、どれだけ安くても、いりません。

お金をかけないと伸びない、という話では、ありません。先生に質問する（42番）。図書館を使う。AIに問題を作ってもらう（44番）。どれも、お金は、かかりません。
