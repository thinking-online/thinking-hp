# 「しない／する」の言葉（案）

2026-11-20。著者の指示：「頭のいい人は『…』をしない。頭のいい人は『…』をする。」の『…』の中身を、名詞の形にもしながら、より短く、より自分ごとにできるように、一番いいものを考える。07〜45番の39個。こちらの案。決まっていない（著者が見る）。

まだ、台本や本の形には入れていない。今、項目の頭に出ているのは、題と、目次の○（`scripts/v4_data.py` の t と o）。この案を入れる時は、項目ごとに pair=("しない言葉", "する言葉") を足す。

## 作り方の決まり

1. 短く：どちらも10字以内を目安にする（長くても12字）
2. 自分ごと：読者が、自分の口ぐせや、いつもの行動だと気づく言葉にする。3つの型がある
   - 口ぐせの型：本人が言っている言葉を、そのまま使う（「次は気をつける」「今日は3時間やる」「全部わかりません」）
   - 行動に名前をつける型：名詞にする（「やる気待ち」「時間無制限」「全部自力」）
   - 1語だけ変える型：同じ言葉で、1語だけ入れかえる。対が、一目でわかる（「睡眠を削る／無駄を削る」「不安を消す／不安を書く」）
3. 「ん？」にならない：作った言葉、省きすぎた言葉にしない。中学1年生が、読んだ瞬間にわかる言葉だけ
4. 「する」は、今日できる行動にする（気持ちや心がけにしない）

## 迷った所と、別の案

- 08番「全体の下見」：受験会場の下見、と同じ言葉。別の案は「先に全体像」
- 11番：07番の「30秒説明」を、授業でやる項目なので、言葉をそろえた
- 13〜15番：3つとも「〜暗記」でそろえた（暗記編の中で、対が並ぶ）
- 17番：別の案は「過去問は最後／過去問は最初」（1語だけ変える型）
- 21番「3分で答えを見る」：単語は5秒、計算で詰まった時は10分、という決まりもある。全部に合う言い方なら「時間を決めて見る」
- 24番：別の案は「参考書の浮気」（受験生がよく使う言葉。中学生向けの本に合うかは、著者が決める）
- 30番：別の案は「ながら勉強」（音楽だけの話ではなくなる）
- 36番「親友に言うように」、32番「冴える時間にやる」：名詞にすると、わかりにくくなるので、そのままの言い方にした
- 38番：もとの「自分はできる／まだできない」は、「をしない／をする」に入れると、意味が取りにくい。行動の名前にした
- 45番：「をする」に入れるなら「合格をゴールにする／合格を通過点にする」

## 決まっていないこと

- 目次の題（今は長い文。例：「人に説明できないまま、次へ進む」）も、この短い言葉に変えるか。項目の頭だけに使うか
- 第1章（01〜06番）は、この形にしていない
