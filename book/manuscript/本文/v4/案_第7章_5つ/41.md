## 「1人で頑張る」は、えらく見えます

人に頼らず、自分の力だけで、やりきる。真面目な人ほど、それを、えらいことだと思っています。

「はじめに」の僕が、そうでした。1日13時間。1人で、誰よりも、やりました。そして、10個受けて、全部、落ちました。恩師に言われるまで、やり方のズレに、気づけませんでした。

「巨人の肩の上に立つ」という言葉があります。科学者のニュートンが、手紙に書いたことで、知られています。自分が遠くまで見えたのは、先人という巨人の肩に、乗ったからだ、という意味です。

==本当に結果を出す人ほど、自分でやろうとしません。==自分で探すだけが、えらいわけでは、ないのです。相談して、調べて、すぐ解決できるなら、それが、一番です。

## 頼り方は、2つです

友達の家の、Wi-Fiのパスワード。自分で当てますか。友達に、聞きますか。聞くはずです。3秒で、すみます。勉強にも、同じものが、あります。

```
　　知っていれば、すむこと　　→　すぐ聞く
　　　言葉の意味。公式。テストの範囲。おすすめの参考書
　　できるようになりたいこと　→　試してから、考え方を聞く
　　　問題の解き方。英作文の書き方
```

上は、Wi-Fiのパスワードと、同じです。知らないものは、いくら考えても、出てきません（21番）。すぐ、聞きます。調べても、かまいません。

下は、答えを聞いても、できるようには、なりません。聞くのは、考え方です。「どう考えて、そう決めたんですか」。==答えは、借りた武器です。その1問にしか、効きません。考え方は、自分の筋肉です。一度つけば、どの問題にも、使えます。==

## 配慮はしても、遠慮は、しません

「こんなことを聞いたら、迷惑かな」。そう思って、聞けない人が、多いです。

```
　　配慮はしても、遠慮はしない。
```

遠慮は、聞かないことです。配慮は、相手が答えやすいように、聞くことです。

```
　　①自分でやった所まで、言う　「3行目までは、わかります」
　　②聞くことを、1つにする　　「4行目だけ、教えてください」
　　③あとで、結果を伝える　　　「教わった通りにやったら、解けました」
```

教わったら、まず、その通りに、やってください。都合のいい所だけ使うと、うまくいかなかった時に、何が悪かったのか、わからなくなります。そして、③です。教えた人は、結果を聞くと、うれしくなります。また、教えたくなります。==頼るのがうまい人は、応援されるのが、うまい人です。==

頼る力は、受験が終わっても、ずっと使います。この先、何をやる時も、最後は、人と人だからです。自立とは、1人で全部できることでは、ありません。頼る力も、自立のうちです。
