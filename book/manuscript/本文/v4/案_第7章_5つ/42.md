## 洗濯機があるのに、毎日、服を手で洗っている人がいます。どう思いますか？

理由を聞くと、こう言います。「自分の手で洗わないと、ちゃんと洗った気が、しなくて」。

……

「洗濯機を使って、空いた時間で、ほかのことをすればいいのに」。そう思ったはずです。水道があるのに、毎日、川まで、水をくみに行く人。電気があるのに、ろうそくの明かりで、本を読む人。今は、いません。==同じ目的を果たせるなら、楽なほうが、いいに決まっています。==

ところが、勉強になると、手で洗う人が、たくさん、います。

## 「努力」は、いいことに見えます

例えば、きれいなノートです。教科書の内容を、色ペンで、3時間かけて、まとめ直しました。大変でした。「今日は、頑張った」と思います。でも、覚えたことは、ほとんど、増えていません。

==数えているのが、「できるようになったこと」ではなく、「大変だったこと」になっています。==これが、努力そのものを、美徳にしている状態です。「はじめに」で、書きました。努力に、酔ってはいけない。大変だったかどうかと、伸びたかどうかは、別のことです。

## 常識は、変わります

少し前まで、授業中に、画面を見ていたら、注意されました。今は、1人1台のタブレットで、授業を受けます。前の決まりが、まちがっていたのでは、ありません。道具が変わって、一番いいやり方が、変わったのです。

勉強も、同じです。「自分の手でやってこそ、力がつく」。その考えで固まっていると、新しい道具も、新しいやり方も、使えません。==ほめるのは、努力では、ありません。変わったこと。伸びたこと。結果を出したことです。==

```
　　楽できるものは、楽をする。空いた時間を、伸びることに使う。
```

## ただし、楽をしてはいけない所が、あります

全部を任せていい、という話では、ありません。線は、1本です。

```
　　それは、本番で、自分がやること？
```

```
　　いいえ　→　楽をする　　写す。まとめ直す。数える。探す。カードを作る
　　はい　　→　自分でやる　思い出す。解く。書く。直す
```

本番でやらない手間は、どんどん、楽をします。教科書に書きこめば、まとめ直さなくて、すみます。単語カードは、売っているものを使えば、作らなくて、すみます。

本番でやることは、楽をしません。そこを人や道具にやらせると、目の前の宿題は終わっても、自分は、伸びません。絶対法則03の通り、力がつくのは、頭が「うーん」と止まっている時間だけです。

楽をするのは、サボるためでは、ありません。==空いた時間を、「うーん」の時間に、回すためです。==
