## 習字の時間。お手本を見ないで、自分流で書いた人は、いますか？

……

いないと思います。まず、お手本を、そのまま、まねました。とめ、はね、はらい。自分流の字を書くのは、お手本通りに書けるようになった、あとです。

ところが、勉強のやり方になると、最初から、自己流でやる人が、多いです。

## 自己流は、「事故」流です

自己流には、2つあります。

```
　　①自分で考えたやり方で、やる　　　　まちがったやり方に、気づけない
　　②教わったやり方を、自分流に変える　大事な所から、なくなる
```

①は、「はじめに」の僕です。自分のやり方で、1日13時間やりました。やり方が、全部、ズレていました。量をやった分だけ、遠くまで、ズレました。

②は、例えば、こうです。成績のいい先輩に、英単語の覚え方を、聞きました。「1日100個を、見て、思い出す。それを、毎日くり返す」。「100個は、多いな。自分は、30個にして、1つずつ、丁寧に書いて覚えよう」。2週間後。覚えた単語は、あまり、増えていません。「あのやり方は、自分には、合わなかった」。

でも、やったのは、先輩のやり方では、ありません。==自分流に変えた、別のやり方です。==しかも、変えた所（数と、くり返し）が、そのやり方の、一番大事な所でした。どこが大事な所なのかは、できるようになる前の自分には、まだ、見えません。

## 上達には、順番があります。守る。破る。離れる

武道や茶道で、昔から言われてきた、上達の順番です。「守破離（しゅはり）」と言います。

```
　　守　教わった型を、そのまま、守る
　　破　型が身についてから、自分に合わせて、変える
　　離　自分の型を、作る
```

自己流でやる人は、「守」を飛ばして、「破」から始めています。型が身についていないので、何を破っているのかも、わかりません。

「はじめに」の恩師の言葉には、続きがありました。「偏差値70を安定して超えていないなら、つべこべ言わず、俺の言うことを聞け」。守破離で言えば、「まず、守れ」です。

## 2週間は、そのまま。変えるのは、数字を見てからです

```
　　①守るやり方を、1つ決める
　　②2週間、そのままやる。変えたくなったら、メモだけする
　　③2週間たったら、数字を見る。変えるのは、1つだけ
```

理科の実験と、同じです。条件を2つ変えると、どちらが効いたのか、わかりません。そのままやって、数字が上がれば、そのやり方は、合っています。上がらなければ、メモの中から、1つだけ、変えます。2週間は、目安です。

疑うな、という話では、ありません。絶対法則01の通り、やり方は、疑います。ただ、疑うのは、やってみて、数字を見てからです。==工夫は、禁止では、ありません。順番が、あとなだけです。==
