## 洗濯機があるのに、毎日、服を手で洗っている人がいます。どう思いますか？

理由を聞くと、こう言います。「自分の手で洗わないと、ちゃんと洗った気が、しなくて」。

……

「洗濯機を使って、空いた時間で、ほかのことをすればいいのに」。そう思ったはずです。水道があるのに、毎日、川まで、水をくみに行く人。電気があるのに、ろうそくの明かりで、本を読む人。今は、いません。==同じ目的を果たせるなら、楽なほうが、いいに決まっています。==

ところが、勉強になると、手で洗う人が、たくさん、います。

## 「頑張った感じ」を、求めていませんか

例えば、きれいなノートです。教科書の内容を、色ペンで、3時間かけて、まとめ直しました。大変でした。「今日は、頑張った」。気持ちが、いいです。でも、覚えたことは、ほとんど、増えていません。

ここで、自分に、聞いてみてください。

```
　　欲しいのは、「頑張った感じ」？　それとも、「できるようになること」？
```

大変なことをすると、「頑張った感じ」がします。その感じは、気持ちがいい。だから、知らないうちに、大変なほうを、選びます。手で写す。まとめ直す。長い時間、座る。

そして、何となく、こう思っています。「これだけ大変だったんだから、きっと、力になっている」。==でも、大変だったかどうかと、伸びたかどうかは、別のことです。==

「はじめに」の僕が、そうでした。1日13時間やって、まわりから、「努力の天才」と言われました。うれしかったです。頑張った感じは、たっぷり、ありました。結果は、全部、不合格です。努力に、酔っていました。

## 常識は、変わります

少し前まで、「勉強は、紙と鉛筆でやるもの」が、当たり前でした。今は、1人に1台のタブレットやパソコンで勉強するのが、当たり前になっている学校も、あります。前の考えが、まちがっていたのでは、ありません。道具が変わって、一番いいやり方が、変わったのです。

勉強も、同じです。「自分の手でやってこそ、力がつく」。その考えで固まっていると、新しい道具も、新しいやり方も、使えません。==自分をほめていいのは、どれだけ大変だったか、では、ありません。変わったこと。伸びたこと。結果を出したことです。==

```
　　楽できるものは、楽をする。空いた時間を、伸びることに使う。
```

## ただし、楽をしてはいけない所が、あります

全部を任せていい、という話では、ありません。線は、1本です。

```
　　それは、本番で、自分がやること？
```

```
　　いいえ　→　楽をする　　写す。まとめ直す。数える。探す。カードを作る
　　はい　　→　自分でやる　思い出す。解く。書く。直す
```

本番でやらない手間は、どんどん、楽をします。教科書に書きこめば、まとめ直さなくて、すみます。単語カードは、売っているものを使えば、作らなくて、すみます。

本番でやることは、楽をしません。そこを人や道具にやらせると、目の前の宿題は終わっても、自分は、伸びません。絶対法則03の通り、力がつくのは、頭が「うーん」と止まっている時間だけです。

楽をするのは、サボるためでは、ありません。==空いた時間を、「うーん」の時間に、回すためです。==
