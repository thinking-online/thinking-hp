## 漫画の主人公には、強い仲間がいます。では、最後の敵を倒すのは、誰ですか？

……

主人公です。仲間が、どれだけ強くても、最後の一撃を、仲間に任せる主人公は、ほとんど、いません。

勉強の主人公は、あなたです。そして、今は、AIという、とんでもなく強い仲間が、います。

```
　　主人公は、自分。AIは、最強の脇役。
```

## AIにやらせると、本番で、自分が、できません

例えば、数学の宿題。3番の問題が、わかりません。写真を撮って、AIに聞きます。10秒で、答えと解説が返ってきました。ノートに写して、宿題は終わり。次の週の小テスト。同じ形の問題で、手が、動きません。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で、確かめています。AIに答えも聞けたグループは、練習問題の成績が、AIを使わなかったグループより、5割近く高くなりました。ところが、AIなしで受けたテストでは、2割近く、低くなりました。練習で解いていたのは、AIだったからです。

同じ実験で、答えは言わずに、ヒントだけを出すAIを使ったグループは、点が、下がりませんでした。==AIを使うと頭が悪くなるのでは、ありません。使い方しだいです。==

## 線は、1本です。「それは、本番で、自分がやること？」

```
　　はい　　→　自分でやる　思い出す。解く。書く。直す
　　いいえ　→　AIに任せる　集める。数える。作る。整える
```

入試の会場に、AIは、持ちこめません。最後の敵と戦うのは、主人公です。だから、本番でやることは、ふだんから、自分でやります。

逆に、本番でやらない作業は、任せて、かまいません。41番の、「やらなくていい努力」です。

## そのまま打てる、頼み方です

```
　　問題を出してもらう
　　「答えは言わないで。この範囲から、5問出して。答え合わせは、あとで」
　　まちがいを、突いてもらう
　　「僕の答えの、まちがっている所を3つ指摘して。直した文は、まだ書かないで」
```

一番のおすすめは、「まちがいを、突いてもらう」です。「この答えで、合ってる？」と聞くと、「合っています」に近い答えが、返ってきやすいからです。==ほめてくれる仲間より、反対してくれる仲間のほうが、主人公を、強くします。==

```
　　詰まった時に、一歩だけもらう
　　「答えは言わないで。最初の一歩だけ教えて」
　　未来問を作ってもらう
　　「この過去問と、同じ形式、同じ難しさの問題を、新しく1題作って」
```

過去問と同じ形式で作ってもらう問題を、僕は、「未来問」と呼んでいます。過去問は、数に、かぎりがあります。未来問は、いくらでも作れます。

```
　　覚えやすくしてもらう
　　「この単語を、絵が浮かぶ場面にして」
　　作業を任せる
　　「過去問5年分の、単元ごとの出題回数を、表にして」
```

どれも、AIがやるのは、準備です。問題を作るのは、AI。解くのは、自分。絵を作るのは、AI。その絵で思い出すのは、自分です。

守ることは、3つです。AIも、まちがえます。大事な所は、教科書か、解説で確かめます。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。

AIは、これからも、どんどん強くなります。ここに書いた頼み方も、いつか、古くなります。変わらないのは、1つだけです。最後の敵を倒すのは、あなたです。
