## 地図アプリを見ながら行った場所。次は、アプリなしで、行けますか？

この前、初めて行った店や、試合の会場を、思い浮かべてください。

……

行けない人が、ほとんどだと思います。自分の足で、歩いたのに、です。

画面の青い点について行っただけで、「次は、どっちに曲がるか」を、1回も、自分で決めていないからです。==任せたものは、頭に残りません。==

## AIに質問すると、考えているのは、AIです

例えば、数学の宿題。3番の問題が、わかりません。写真を撮って、AIに聞きます。10秒で、答えと解説が返ってきました。ノートに写して、「なるほど。わかった」。次の週の小テスト。同じ形の問題が出ました。手が、動きません。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で、確かめています。AIに自由に質問できて、答えも聞けたグループは、練習問題の成績が、AIを使わなかったグループより、5割近く高くなりました。ところが、AIなしで受けたテストでは、2割近く、低くなりました。

練習では、解けていました。でも、解いていたのは、AIです。生徒は、ついて行っただけでした。

## 主人公は、自分です。考える座は、渡しません

AIは、これからも、どんどん賢くなります。それでも、入試の会場には、持ちこめません。力がつくのは、自分の頭が「うーん」と止まっている時間だけです（絶対法則03）。

だから、向きを、逆にします。

```
　　×　AIに、質問する　　「この問題の答えを教えて」　　考えるのは、AI
　　○　AIに、質問させる　「この範囲から、問題を出して」　考えるのは、自分
```

## AIに質問させる形は、3つあります

```
　　①問題を、出させる　　　覚えたか、解けるかを、試してもらう
　　②説明に、突っこませる　自分の考えの穴を、見つけてもらう
　　③一歩だけ、聞く　　　　詰まった時に、最初の一歩だけ、もらう
```

①は、間違えた問題と、覚えられない言葉を、メモにためておきます（23番）。そのメモを渡して、こう頼みます。

```
　　このメモから、5問、出して。答えは、僕が答えたあとに、教えて
```

過去問を見せて、「同じ形式、同じ難しさの問題を、新しく作って」と頼むことも、できます。これから出そうな問題なので、僕は、「未来問」と呼んでいます。落としている大問だけを、5題、作ってもらうことも、できます。

②は、ほめてもらうのではなく、突っこんでもらいます。「この説明で、抜けていることは、何？」「この英作文の、間違っている所を3つ指摘して。直した文は、まだ書かないで」。

③だけは、自分から聞きます。ただし、先に、自分の考えを1行書いて、「答えは言わないで。最初の一歩だけ教えて」と入れます。さっきの実験でも、ヒントだけを出すAIを使ったグループは、テストの点が、下がりませんでした。

ハーバード大学の研究者たちの実験も、あります。答えをすぐには言わず、ヒントを出しながら、1人ずつのペースに合わせるように作られたAIで学んだ学生は、普通の授業で学んだ学生より、短い時間で、よく身についていました。

## 力がつかない作業は、任せて、かまいません

例えば、過去問5年分の、どの単元がよく出るかを、表にする。自分で数えると、何日も、かかります。数学の力は、つきません。AIなら、数分です。空いた時間で、問題を解きます。==全部を自分の手でやることが、えらいわけでは、ありません。==

守ることは、3つです。AIも、まちがえます。大事な所は、教科書か、解説で確かめます。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。

ここに書いた使い方も、何年かたてば、古くなります。変わらないのは、1つだけです。==考えるのは、自分。==どんな道具が出てきても、そこだけは、渡さないでください。
