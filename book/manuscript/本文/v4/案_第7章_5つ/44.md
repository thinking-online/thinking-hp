## 150円のジュースは、迷わず買います。1,500円の参考書は、迷います。なぜでしょうか？

……

値段を、見ているからです。150円は、安い。1,500円は、高い。

でも、ジュースは、10分で、なくなります。参考書は、やり込めば、ずっと、自分の中に残ります。==消えるものには、すぐ払う。残るものには、迷う。==逆に、なっています。

```
　　値段を、見ない。返ってくるものを、見る。
```

## 払ったあとも、同じです。「買ったから」で、続けません

投資で考える人は、もう1つ、やることがあります。返ってこないとわかったら、すぐ、やめます。

例えば、2週間前に買った参考書。10問のうち、9問で、手が止まります。それでも、「せっかく買ったから」と、最後まで続ける。これも、払った金額を、見ています。

世界の36の研究グループが、6,000人以上に聞いて、確かめています。大事な試合の日。外は、こごえる寒さです。チケットを自分で買った人は、タダでもらった人より、「それでも行く」と、強く答えました。試合も、寒さも、同じです。違うのは、払ったかどうかだけです。

もう払って、戻ってこないお金のことを、「サンクコスト」と言います。人は、これに、引っぱられます。でも、払った1,500円は、続けても、やめても、戻りません。合わない本に使う1時間は、合う本で進めたはずの、1時間です。

## 迷ったら、「これで、何が返ってくる？」と聞きます

```
　　買う時　　「高いか、安いか」ではなく、「何が返ってくるか」
　　続ける時　「いくら払ったか」ではなく、「これから、何が返ってくるか」
```
