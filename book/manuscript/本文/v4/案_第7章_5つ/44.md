## 1,000円払った映画が、つまらない。残りは、1時間半。最後まで、見ますか？

……

見る人が、多いと思います。理由は、「せっかく、1,000円、払ったから」。

でも、その1,000円は、最後まで見ても、途中で出ても、戻ってきません。違うのは、これからの1時間半だけです。

```
　　もったいないのは、払ったお金じゃない。これからの時間だ。
```

## 買った参考書を、「買ったから」で、最後までやりません

勉強でも、同じことが、起きています。

例えば、2週間前に買った参考書。解説を読んでも、ほとんど、わかりません。10問のうち、9問で、手が止まります。それでも、「せっかく買ったから」と、最後まで続けます。途中でやめるのは、悪いことだと、思っているからです。真面目な人ほど、そうします。

払った1,500円は、続けても、やめても、戻ってきません。もう払って、戻ってこないもののことを、「サンクコスト」と言います。「沈んで、もう取り出せない費用」という意味です。

人は、これに、引っぱられます。オハイオ大学の研究者たちの実験では、劇場の年間チケットを、定価で買った人のほうが、割引で買った人より、シーズンの前半、多く通いました。違うのは、払った金額だけです。

## 数えるのは、これから失う時間です

時間は、1つしか、ありません。合わない参考書に使う1時間は、合う参考書で進めたはずの、1時間です。

==「せっかく」で続けている間、あなたは、もう1つの道を、毎日、捨てています。==払ったお金は、もう、数えなくて、かまいません。数えるのは、これからの時間です。

## 迷ったら、「今日、ゼロから選ぶなら？」と聞きます

```
　　今日、本屋で、ゼロから選ぶなら、これを買う？
```

まだ、1円も払っていない。1分も使っていない。そう思って、選び直します。見るのは、最後に勝つために、要るかどうかだけです。

```
　　買わない　→　変える。10問のうち、ほとんど全部で、手が止まる本
　　買う　　　→　やり込む。止まるのは、10問のうち、2問から4問の本
```

変えても、2週間は、無駄では、ありません。「今の自分には、重すぎる」と、わかりました。逆に、「飽きたから」は、変える理由に、なりません（25番）。「せっかく」も、「飽きた」も、その場の気持ちです。

参考書だけの話では、ありません。15分考えて進まない問題を、「ここまで考えたから」と粘る。効かないやり方を、「今まで、こうやってきたから」と続ける。全部、同じです。==アップデートとは、「これから」で、選び直し続けることです。==
