## 1,000円払った映画が、つまらない。残りは、1時間半。最後まで、見ますか？

……

見る人が、多いと思います。理由は、「せっかく、1,000円、払ったから」。

でも、その1,000円は、最後まで見ても、途中で出ても、戻ってきません。違うのは、これからの1時間半だけです。==「せっかく」で選んだほうが、多く、失っています。==

## 勉強では、「せっかく」の仲間が、3つ、出てきます

```
　　「せっかく、ここまでやったのに」　払ったお金と、使った時間
　　「前は、これで、できたから」　　　前の勝負の、勝ち方
　　「みんな、これを使っているから」　まわりの人
```

1つ目。合わないとわかった参考書を、「せっかく買ったから」と、最後まで続ける。戻ってこないお金や時間のことを、「サンクコスト」と言います。「沈んで、もう取り出せない費用」という意味です。オハイオ大学の研究者たちの実験では、劇場の年間チケットを、定価で買った人のほうが、割引で買った人より、シーズンの前半、多く通いました。違うのは、払った金額だけです。人は、払ったものに、引っぱられます。

2つ目。中学のテストは、前の日にまとめてやれば、点が取れました。高校でも、同じやり方を続けて、点が取れません。前の勝負で勝ったやり方が、次の勝負でも通じるとは、かぎりません。

3つ目。クラスのみんなが使っている単語帳。でも、みんなのゴールと、あなたのゴールは、違います（38番）。

==3つとも、見ているのは、「これまで」と「まわり」です。「これから」を、見ていません。==途中でやめるのは、悪いこと。真面目な人ほど、そう思っています。その姿勢は、まちがっていません。ただ、続ける理由が、この3つだけなら、それは、こだわりです。

## 決める時に見るのは、「これから」だけです

迷ったら、自分に、こう聞きます。

```
　　今日、ゼロから選ぶなら、これを選ぶ？
```

まだ、1円も払っていない。1分も使っていない。誰も使っていない。そう思って、選び直します。選ぶなら、続けます。選ばないなら、変えます。

例えば、2週間使った参考書。10問のうち、ほとんど全部で、手が止まります。今日、本屋で選び直すなら、この本は、選びません。だから、変えます（25番）。2週間は、無駄では、ありません。「今の自分には、重すぎる」と、わかりました。

逆も、あります。しんどいけれど、止まるのは、10問のうち、2問から4問。ゼロから選んでも、この本を選びます。だから、続けます。「飽きた」も、「せっかく」も、その場の気持ちです。==その場の気持ちでは、決めません。==

## 選び直す日を、先に、決めておきます

```
　　いつ　　　　テストが返ってきた日
　　いくつ　　　変えるのは、1つだけ
　　確かめ方　　2週間、数字で見る
```

テストが返ってきた日に、今のやり方を、3つ、紙に書きます。1つずつ、「今日、ゼロから選ぶなら？」と聞きます。変えるのは、1つだけです。2つ変えると、どちらが効いたのか、わかりません（42番）。2週間たったら、数字で確かめます。

お金を使う時も、同じです。「お金がもったいないから、家にある古い本でいいや」。これも、その場の「もったいない」です。その本で、毎日20分止まるなら、3か月で、30時間です。勉強で一番高いのは、お金ではなく、時間です。

この本に書いたやり方も、同じように、選び直してください。合わなくなったら、変えて、かまいません。==アップデートとは、「これから」で、選び直し続けることです。==
