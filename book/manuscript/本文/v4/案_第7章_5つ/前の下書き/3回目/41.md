## 友達の家の、Wi-Fiのパスワード。友達に聞きますか？　自分で当てますか？

……

聞くと思います。3秒で、つながります。1文字ずつ、全部の組み合わせを試す人は、いません。答えを知っている人が、目の前に、いるからです。

ところが、勉強になると、多くの人が、自分で、当てようとします。

## 「1人で頑張る」は、えらく見えます

人に頼らず、自分の力だけで、やりきる。真面目な人ほど、それを、えらいことだと思っています。

「はじめに」の僕が、そうでした。1日13時間。誰よりも、やりました。そして、10個受けて、全部、落ちました。努力が、足りなかったのでは、ありません。==やらなくていい努力を、山ほど、やっていました。==

今、悩んでいること。苦戦していること。そのほとんどは、もう、誰かが、解決しています。「愚者は経験に学び、賢者は歴史に学ぶ」という言葉があります。先人が、何年もかけて見つけた答えを、もう一度、自分で、何年もかけて見つける。それが、やらなくていい努力です。

## 結果を出す人ほど、自分でやろうとしません

本当に結果を出す人は、1人でやることに、こだわりません。考えているのは、「どうすれば、より早く、結果が出るか」だけです。

```
　　やらなくていい努力を、わざわざ、やらない。
```

自立とは、1人で全部できることでは、ありません。頼る力も、自立のうちです。

## 「知っていれば、すむこと」は、すぐ、聞きます

聞くものは、2つに、分かれます。

```
　　知っていれば、すむこと　　→　すぐ聞く
　　　言葉の意味。公式。テストの範囲。おすすめの参考書
　　できるようになりたいこと　→　自分で試してから、聞く
　　　問題の解き方。英作文の書き方。説明のしかた
```

Wi-Fiのパスワードは、上です。知らないものは、いくら考えても、出てきません（21番）。考えている時間が、やらなくていい努力です。3秒で、聞きます。調べても、かまいません。

下は、違います。答えを聞いても、自分でできるようには、なりません。だから、まず、自分で試します。詰まったら、聞きます。

## 聞くのは、答えではなく、考え方です

ただし、下を聞く時は、聞き方が、あります。

```
　　×　「この問題の答えは、何ですか」
　　○　「どう考えて、そう決めたんですか」
```

答えを聞くと、その1問は、解けます。でも、次の問題で、また、聞くことになります。考え方を聞くと、次の問題は、自分で解けます。

==答えは、借りた武器です。その1問にしか、効きません。考え方は、自分の筋肉です。一度つけば、どの問題にも、使えます。==筋肉は、人から、もらえません。でも、鍛え方は、聞けます。

聞くことは、3つです。最初に、どこを見たのか。何と何で、迷ったのか。なぜ、そっちに決めたのか。問題の解き方でも、参考書の選び方でも、同じです。

聞く相手は、できなかった所から、できるようになった人です。先生や、合格した先輩。その人は、あなたが今いる場所を、もう、通っています。
