## 漫画の主人公には、強い仲間がいます。では、最後の敵を倒すのは、誰ですか？

……

主人公です。仲間が、どれだけ強くても、最後の一撃を、仲間に任せる主人公は、ほとんど、いません。

勉強の主人公は、あなたです。そして、今は、AIという、とんでもなく強い仲間が、います。問題は、その仲間に、何をやってもらうかです。

## AIを使うと、頭が悪くなるのか。答えは、使い方しだいです

「AIを使うと、考えなくなる」。そう心配する人が、います。半分、当たっています。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で、確かめています。AIに自由に質問できて、答えも聞けたグループは、練習問題の成績が、AIを使わなかったグループより、5割近く高くなりました。ところが、AIなしで受けたテストでは、2割近く、低くなりました。練習で解いていたのは、AIだったからです。

でも、同じ実験で、答えは言わずに、ヒントだけを出すAIを使ったグループは、テストの点が、下がりませんでした。ハーバード大学の研究者たちの実験では、ヒントを出しながら、1人ずつのペースに合わせるように作られたAIで学んだ学生は、普通の授業で学んだ学生より、短い時間で、よく身についていました。

==AIにやらせると、力は落ちます。AIを脇役にすると、力は伸びます。==

## 線は、1本です。「それは、本番で、自分がやること？」

どこまでを、AIにやってもらって、いいのか。迷ったら、こう聞きます。

```
　　それは、本番で、自分がやること？
```

```
　　はい　→　自分でやる　　思い出す。解く。書く。直す
　　いいえ　→　任せていい　集める。数える。作る。整える
```

入試の会場に、AIは、持ちこめません。本番でやることを、ふだんからAIにやらせていたら、本番で、できません。逆に、本番でやらない作業を、自分の手でやる必要は、ありません。==全部を自分でやることが、えらいわけでは、ないのです。==

## 最強の脇役に、やってもらうこと

```
　　覚える　覚えにくい言葉を、絵や場面にしてもらう（14番）
　　　　　　知っていることに、たとえてもらう（11番）
　　解く　　過去問と同じ形式の、新しい問題を作ってもらう
　　　　　　落としている大問だけの問題を、作ってもらう
　　直す　　自分の説明の、抜けている所を、突いてもらう
　　調べる　過去問の、どの単元が何回出たかを、表にしてもらう
```

どれも、AIがやるのは、準備です。絵を作るのは、AI。その絵で思い出すのは、自分です。問題を作るのは、AI。解くのは、自分です。過去問と同じ形式で作ってもらう、これから出そうな問題を、僕は、「未来問」と呼んでいます。過去問は、数に、かぎりがあります。未来問は、いくらでも作れます。

## 一番いい使い方は、AIに、反対してもらうことです

人は、自分の考えに合う話ばかりを、集めるくせがあります（「確証バイアス」と言います）。AIに「この考えで、合ってる？」と聞くと、「合っています」に近い答えが、返ってきやすいです。それでは、自分のズレは、見つかりません。

だから、頼み方を、逆にします。

```
　　×　この答えで、合ってる？
　　○　この答えの、まちがっている所を、3つ、指摘して
　　○　答えは言わないで。質問だけして、僕に考えさせて
```

答えを教えずに、質問を重ねて、相手に考えさせる。古代ギリシャのソクラテスが使った、と言われる教え方です。41番で書いた「直してくれる人」の役を、AIにも、やってもらいます。

守ることは、3つです。AIも、まちがえます。大事な所は、教科書か、解説で確かめます。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。

ここに書いた使い方は、何年かたてば、古くなります。変わらないのは、1つだけです。==主人公は、自分。==どれだけ強い仲間がいても、最後の敵を倒すのは、あなたです。
