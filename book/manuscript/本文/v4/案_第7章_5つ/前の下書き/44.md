## 1,000円払った映画が、つまらない。残りは、1時間半。最後まで、見ますか？

……

見る人が、多いと思います。理由は、「せっかく、1,000円、払ったから」。

でも、その1,000円は、最後まで見ても、途中で出ても、戻ってきません。違うのは、これからの1時間半だけです。その1時間半があれば、別の、面白い映画が、1本、見られました。

## 買った参考書を、「買ったから」で、最後までやりません

勉強でも、同じことが、起きています。合わないとわかった参考書を、「せっかく買ったから」と、最後まで続ける。真面目な人ほど、そうします。途中でやめるのは、悪いことだと、思っているからです。

ここに、2つの考え方があります。

```
　　サンクコスト　もう払って、戻ってこないもの　→　数えない
　　機会費用　　　それをやる間に、できなくなること　→　数える
```

## もう払ったものは、数えません（サンクコスト）

払ったお金。使った時間。どちらも、続けても、やめても、戻ってきません。「サンクコスト」は、「沈んで、もう取り出せない費用」という意味です。

人は、これに、引っぱられます。オハイオ大学の研究者たちの実験です。劇場の年間チケットを、定価で買った人と、割引で買った人がいました。シーズンの前半、多く通ったのは、定価で買った人でした。違うのは、払った金額だけです。

## これから失うものを、数えます（機会費用）

時間は、1つしか、ありません。何かをやる、ということは、その時間にできた、ほかのことを、やらない、ということです。その「できたはずのこと」を、「機会費用」と言います。

合わない参考書に使う1時間は、合う参考書で進めたはずの、1時間です。==「せっかく」で続けている間、あなたは、もう1つの道を、毎日、捨てています。==

映画なら、1,000円は、数えません。数えるのは、これからの1時間半で、できることです。

## 物差しは、1つです。「最後に勝つために、どっちが要る？」

続けるか、やめるか。迷ったら、こう聞きます。

```
　　今日、ゼロから選ぶなら、勝つために、これを選ぶ？
```

まだ、1円も払っていない。1分も使っていない。そう思って、選び直します。見るのは、ゴールだけです（絶対法則04）。

例えば、2週間使った参考書。10問のうち、ほとんど全部で、手が止まります。今日、本屋で選び直すなら、この本は、選びません。だから、変えます。2週間は、無駄では、ありません。「今の自分には、重すぎる」と、わかりました。

逆も、あります。しんどいけれど、止まるのは、10問のうち、2問から4問。ゼロから選んでも、この本を選びます。だから、やり込みます（25番）。「飽きた」も、「せっかく」も、その場の気持ちです。==その場の気持ちでは、決めません。==

参考書だけの話では、ありません。15分考えて進まない問題を、「ここまで考えたから」と粘る（21番）。効かないやり方を、「今まで、こうやってきたから」と続ける。お金を、「もったいないから」と、合わない古い本で済ませる。全部、同じです。数えるものが、逆になっています。

テストが返ってきた日に、今のやり方を、3つ、書き出してください。1つずつ、ゼロから選び直します。==アップデートとは、「これから」で、選び直し続けることです。==
