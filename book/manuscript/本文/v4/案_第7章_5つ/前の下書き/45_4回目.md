## あなたは、なぜ、勉強を頑張っているのですか？

高校は、義務教育では、ありません。行かなくても、かまいません。受験も、資格の試験も、受けなくても、生きては、いけます。それでも、あなたは、今日、この本を開いています。なぜですか。

……

すぐに答えられた人は、少ないと思います。「みんなが、やっているから」「やらないと、怒られるから」。それも、正直な答えです。

ただ、理由がないまま走ると、こうなります。合格発表の日。自分の番号が、ありました。「やっと終わった。もう、勉強しなくていい」。参考書を、全部、しまいます。4月。授業は、前より難しくなっています。==ゴールだと思っていた場所は、次のスタートでした。==

## 合格は、目的では、ありません。手段です

```
　　目的　何のために、やるのか　「英語で、世界中の人と話したい」
　　手段　そのために、通る所　　合格。資格。検定
```

絶対法則04で、受験のゴールは、合格最低点を上回ること、と書きました。目の前の勝負には、はっきりしたゴールが要ります。ただ、それは、その勝負のゴールです。あなたの人生のゴールでは、ありません。全部、通過点です。

目的を見失うと、手段が、目的になります。受かることだけが目的になった人は、受かった日に、止まります。落ちた日に、全部が終わったと、思います。目的がある人は、どちらの日も、次の一歩を、決めています。

## はっきりした夢が、なくても、かまいません

「何のために、と言われても、まだ、わからない」。それで、大丈夫です。「選べるようにしておきたい」も、立派な目的です。勉強しておくと、やりたいことが見つかった時に、選べる道が、多くなります。

仮で、かまいません。「受かったら、何をしたいか」を、1行、書いてください。変わったら、書き直せば、いいだけです。

## さっさと勝って、勝ち続けろ

最後に、僕が、一番伝えたいことを書きます。

僕は、口だけの、ダサい男でした。模試は、ずっとE判定。クラスで最下位を取ったことも、あります。そのあと、誰よりも勉強して、10個受けて、全部、落ちました。そこから、やり方を1から変えて、10か月後に、早稲田に受かりました。才能があったからでは、ありません。変えたからです。

だから、言い切ります。

```
　　人は、誰だって、変われる。
```

今、E判定でも。今、クラスで一番下でも。大事なのは、今の点では、ありません。==今日、変えるか、変えないか。それだけです。==

変えた人は、受かったあとも、止まりません。僕の生徒たちの中には、大学に入ってから、会計士の試験に一発で受かった人も、英検1級を取った人も、います。受験で手に入れたのは、合格だけでは、なかったからです。結果の出し方を、手に入れていました。

だから、目の前の勝負は、長引かせないでください。さっさと失敗して、さっさと直して、さっさと勝つ。勝ったら、そこで止まらない。次の勝負を、自分で決める。そして、次の誰かに、やり方を、渡してください。今度は、あなたが、誰かの肩を貸す番です。

やるからには、勝ちにいく。合格は、あなたの、最初の1勝です。

```
　　さっさと勝って、勝ち続けろ。
```
