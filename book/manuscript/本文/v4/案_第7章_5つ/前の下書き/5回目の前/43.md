## いつ、何回聞いても、いやな顔をしない先生が、家にいます。答えだけ聞いて、終わりにしますか？

……

もったいない、と思ったはずです。わからない所を、わかるまで、聞ける。自分の説明を、聞いてもらえる。問題も、出してもらえる。使い方は、いくらでも、あります。

AIは、その先生です。ところが、多くの人が、答えだけ聞いて、終わりにしています。

## 答えだけ聞くと、宿題は終わっても、自分は伸びません

42番で、楽できる所は、楽をする、と書きました。では、AIに答えを聞くのは、どうでしょうか。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で、確かめています。AIに答えも聞けたグループは、練習問題の成績が、AIを使わなかったグループより、5割近く高くなりました。ところが、AIなしで受けたテストでは、2割近く、低くなりました。練習で解いていたのは、AIだったからです。

同じ実験で、答えは言わずに、ヒントだけを出すAIを使ったグループは、点が、下がりませんでした。==AIを使うと頭が悪くなるのでは、ありません。使い方しだいです。==

問題を解くのは、本番で、自分がやることです。42番の線で言えば、楽をしては、いけない所です。

```
　　主人公は、自分。AIは、最強の脇役。
```

## この本のやり方は、AIで、もっと強くなります

ここまでに書いたやり方を、AIに、手伝ってもらいます。

```
　　思い出す（絶対法則02）　今日の範囲から、問題を出してもらう
　　説明する（07番）　　　　説明を聞いてもらい、抜けを言ってもらう
　　声に出す（13番）　　　　声で質問して、声で答える
```

今のAIは、声で、話せます。打たなくても、先生に質問するのと同じように、聞けます。07番の「30秒説明」を、AIに向かって、声で、やってみてください。「今の説明で、抜けている所は？」と聞けば、その場で、返ってきます。

```
　　イメージにする（14番）　覚えにくい言葉を、場面にしてもらう
　　英作文を書く　　　　　　まちがっている所を、指摘してもらう
　　過去問を解く　　　　　　同じ形式の、新しい問題を、作ってもらう
```

過去問と同じ形式で作ってもらう問題を、僕は、「未来問」と呼んでいます。過去問は、数に、かぎりがあります。未来問は、いくらでも作れます。過去問の、どの単元が何回出たかを、表にしてもらうことも、できます。

## 一番伸びるのは、足りない所を、突いてもらうことです

古代ギリシャの哲学者、ソクラテスは、答えを、教えませんでした。質問を重ねて、相手に、自分の考えの足りない所を、気づかせました。

自分の考えの穴は、自分では、見えません。しかも、AIに「この答えで、合ってる？」と聞くと、「合っています」に近い答えが、返ってきやすいです。それでは、気持ちよくなるだけで、伸びません。

だから、頼み方を、逆にします。ほめてもらうのではなく、批判してもらいます。

```
　　×　「この答えで、合ってる？」
　　○　「この説明の、足りない所を、3つ、指摘して」
　　○　「答えは言わないで。質問だけして、僕に考えさせて」
```

==耳が痛いことを言ってくれる相手が、自分を、一番伸ばします。==「はじめに」の恩師が、そうでした。AIは、頼めば、何度でも、その役を、やってくれます。

## そのまま使える、頼み方です

```
　　「答えは言わないで。この範囲から、5問出して」
　　「答えは言わないで。最初の一歩だけ教えて」
　　「この過去問と、同じ形式の問題を、新しく1題作って」
　　「この単語を、絵が浮かぶ場面にして」
```

どれも、考えるのは、自分です。AIは、その手伝いです。

守ることは、3つです。AIも、まちがえます。大事な所は、教科書か、解説で確かめます。学校や先生が、「この課題では、AIを使わない」と決めている時は、使いません。名前や学校名など、自分や友達のことがわかる情報は、入れません。

AIは、これからも、どんどん強くなります。ここに書いた使い方も、いつか、古くなります。変わらないのは、1つだけです。==考えるのは、自分です。==
