# 38　「自分はできる」と、言い聞かせる

- 配分：問い7行／理由12行／やり方15行（31％。20行目から）／なぜ効くか7行／つまずく所7行
  - 理由は、「自分はできる」と「自分はできない」の2つを、1つの節にまとめた（どちらも、そこで終わっている）
  - 「つまずきを、『限界』と呼ぶか、『途中』と呼ぶか」は、×と○にあたる2行のブロックなので残した。やり方と合わせると22行（46％）。もとのやり方が短い項目なので、ふくらませていない
- 外したもの：
  - 「何も変えていないのに、もう大丈夫な気がしてしまう」
  - 「文として見てください。『自分は、数学ができない』は、そこで言い切って、終わっている文です。終わっている文には、続きがありません。続きがないので、次にやることも出てきません」
  - 「これは、前向きに考えよう、という話ではありません」（あとの「前向きになるからではなく、正確になるから」が同じことを言っている）
  - 「力そのものが違ったのではありません。つまずきの呼び方が、違っただけです」（研究から言いすぎないように）
  - 「40点は、うれしくありません」
  - 最後の段落「逆も、同じです。『英語はできる』も、言い切って終わっている文です。…『今のところ、出せている』と言えば、また確かめる気になります」（足しの話）
- 形を変えたもの：
  - 小見出し「前向きな言葉は、気持ちいいぶん、動けなくなります」と「逆に、『できない』で終わっても、次が出てきません」を、1つにした：「『できる』も『できない』も、そこで話が終わります」（まとめの一言から取った）
  - 「面談で、一番よく聞く言葉があります。『自分、数学できないんで』」を、1文にした
  - 「できないところが、自然に小さくしぼられます」→「小さくしぼられます」
- 足したもの（こちらで書いた見本。著者が確かめる）：
  - 「まだ」を足して、小さくして、ページを開くまでの見本（1〜3行目は、もとの文の言葉。4行目だけ、こちらで書いた）
    ```
    　　自分は、数学ができない
    　　→　自分は、数学が、まだできない
    　　→　二次関数の最大値が、まだ出せない
    　　→　今日、教科書の、最大値のページを開く
    ```
  - つなぎの文：「だから、『何が』まだなのかを、小さく言います。」「ここまで小さくなれば、今日やることが、1つに決まります。」（STEP02、STEP03に合わせた）
- 3STEP・まとめとの合い方：合っている。STEP03の「今日やることを1つ決めて」が本文になかったので、上の1文を足した。まとめの「（今の3つ）前向きにならなくていい。正確に言う」も、本文にある
