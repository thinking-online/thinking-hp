## ファスナーは、どうやって閉まるのか。説明できますか？

制服にも、カバンにも、筆箱にも、ついています。毎日、使っています。

では、あのつまみを上げると、どうして、左右の歯がかみ合うのか。小学生に教えるつもりで、30秒、説明してみてください。

……

「えーと、ギザギザが、こう……」。そこで止まった人が、ほとんどだと思います。

知らなかったわけでは、ありません。何百回も使っているので、「知っている」つもりでした。説明しようとして初めて、言葉にならないことに気づきます。

勉強でも、同じことが起きています。生物の授業で、光合成を習いました。先生の説明は、よくわかりました。帰り道、休んでいた友達に聞かれます。「今日の生物、何やったの？」

　　「えーと、光合成。なんか、葉っぱが、光で……。あとでノート見せるわ」

わかっていたはずなのに、言葉になりません。

## 説明できないものは、まだ「知っている」だけです

頭のいい人は、「わかった」を3つに分けています。

```
　　知っている　　聞いたことがある。見れば思い出す
　　わかっている　何も見ずに、自分の言葉で説明できる
　　使える　　　　テストで、形を変えて出されても解ける
```

授業を聞いて「わかった」と思った時、ほとんどの場合は、1段目です。知っている、の段階です。

テストで点になるのは、3段目だけです。そして、2段目を通らずに、3段目には行けません。

　　==人に説明できない　＝　まだ、わかっていない==

これを、基準にしてください。

ノーベル賞を取った物理学者のファインマンに、こんな話が残っています。同僚から、ある難しい理論を、大学1年生にもわかるように説明してほしい、と頼まれました。数日後、ファインマンは、こう言ったそうです。

　　「できなかった。1年生のレベルまで、下げられなかった。つまり、私たちは、まだ本当には、わかっていないんだ」

ノーベル賞を取った人でも、「説明できるかどうか」で、自分の理解を確かめていました。

## 教えるつもりで入れるだけで、変わります

面白い実験があります。

同じ文章を、2つのグループに読んでもらいます。片方には「あとでテストをします」と伝えます。もう片方には「あとで、この内容を人に教えてもらいます」と伝えます。

実際には、どちらのグループも、誰にも教えません。同じテストを受けるだけです。

結果は、==教えるつもりで読んだグループのほうが、よく覚えていました。==しかも、大事なところを、整理して覚えていました。

教えた、のではありません。教える「つもり」だっただけです。それだけで、入れ方が変わります。どこが大事か、どういう順番で話すかを、読みながら、勝手に考えるからです。

第2章の最初に、インプットは、その時、何を意識していたかで決まる、と書きました。==意識するのは、「あとで、人に教える」です。==

## 「教えるつもりで」と言われても、どうやるのか

ここまでは、聞いたことがある人もいると思います。「人に教えるつもりで、勉強しなさい」。

でも、つもり、と言われても、頭の中で、何をすればいいのか。勉強が苦手な人ほど、ここで止まります。

だから、型を使います。僕が、生徒に実際にやってもらっているやり方です。==「KW言語化勉強法」==と呼んでいます。KWは、キーワードのことです。

型は、2行です。

```
　　結局、【　　　　　　　　　　】の話。
　　キーワードは、【　　　】【　　　】【　　　】。
```

やることは、3つです。

```
　　① 入れる前に、型を書く　　　　ノートのすみに、上の2行を書いておく
　　② 入れながら、枠を埋める　　　「結局、何の話？」を探しながら、聞く。読む。大事な言葉を、3つ書く
　　③ 終わったら、30秒で説明する　閉じて、3つの言葉を使って、声に出す
```

一番大事なのは、①です。==型を、入れる「前」に書きます。==

空いている枠があると、人の頭は、埋めたくなります。授業を聞いている間も、教科書を読んでいる間も、「結局、何の話だろう」「大事な言葉は、どれだろう」と、探しながら入れることになります。何を意識して入れるかが、型で決まります。

光合成で、やってみます。

```
　　結局、【植物が、自分で養分を作る】話。
　　キーワードは、【光】【二酸化炭素と水】【デンプンと酸素】。

　　30秒の説明
　　「光合成は、植物が光を使って、二酸化炭素と水から、
　　　デンプンなどの養分を作ること。その時、酸素が出る」
```

この型を続けると、力が2つ、つきます。

```
　　選ぶ力　　　　枠は3つしかない。大事なものと、細かいものを、分けるしかなくなる
　　つなげる力　　3つの言葉を、自分でつなげて、1つの話に組み立て直す
```

==選んで、つなげる。==これが、「説明する」ということの中身です。

## 声に出します。止まったら、そこだけ見ます

巻頭で出した質問に、ここで答えておきます。

声に出すのか、心の中でいいのか。==声に出します。==心の中だと、止まったことを、自分でごまかせるからです。

説明の途中で止まったら、どうするのか。止まったところだけ開いて見て、閉じて、止まった少し前から、もう一度言います。

## いきなり全部は、やりません

見開き2ページを、全部説明しようとしないでください。大変すぎて、3日で続かなくなります。

教科書の小見出し1つぶん。授業なら、黒板1枚ぶん。小さいかたまりに区切って、1つずつ、型を埋めます。

## 聞いてくれる人がいなくても、できます

家でやるなら、相手は誰でもいいです。机の上のぬいぐるみでも、壁でもいい。スマホに録音して、自分で聞き直すのも効きます。

AIに向かって説明するのも、いい方法です。型を埋めて、30秒の説明を書いたら、こう頼みます。

　　「光合成を、次のように理解しました。合っていますか。違っている所があれば、答えは言わずに、どの点を、何を意識して復習すればいいかだけ、教えてください」

答えをもらうのでは、ありません。自分の説明を、直してもらいます。（AIの使い方は、42番に書きます）

## 書いた型は、そのまま復習の道具になります

型を書いた紙は、捨てないでください。

電車の中で、キーワードの3つだけを見ます。そして、頭の中で、30秒の説明をもう一度言います。教科書を開かなくても、復習ができます。3つの言葉から説明が出てこなかったら、そこが、まだわかっていない場所です。

このあとの09番（授業）、10番（文章を読む時）、11番（家で勉強する時）は、この型を、場面ごとに使う話です。
