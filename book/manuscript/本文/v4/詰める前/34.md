## 今、学校から出ている宿題と提出物を、全部、言えますか？

数えてみてください。

……

では、その中で、次のテストの点に、一番つながるものは、どれですか。3秒で、答えてください。

……

すぐに答えられなかった人が、多いと思います。全部を、同じ「やらなきゃいけないもの」として、並べているからです。

高校2年生の、火曜日。その日、学校から出たものを、並べてみます。

```
　　数学の課題プリント　2枚
　　英語の小テスト　　　明日
　　理科のレポート　　　金曜に提出
　　古典の予習　　　　　明日の授業で当たる
　　受験補習の案内　　　希望制
```

全部やると、夜の11時までかかります。

　　「出された以上、全部ちゃんとやらないと」

全部、やりました。自分でやろうと決めていた英語の長文は、1問も開けませんでした。次の日も、同じです。

## 量を足し算した人が、いません

当たり前のようで、見落とされているところです。数学の先生は、数学のことだけを考えて課題を出します。英語の先生も、理科の先生も同じです。それぞれが「これくらいなら妥当だ」と思う量を出しています。その5つを足した人は、==どこにもいません。==だから、全部を同じ本気でやろうとすると、時間が足りなくなります。最初から、1日に入りきらない量なのです。誰も悪くありません。足し算する人がいないだけです。足し算するのは、あなたです。

## 「捨てる」と「手を抜く」は、別です

ここを混ぜると、一番損をします。

```
　　捨てる　　やらないと決める。時間が丸ごと空く
　　手を抜く　やりながら、中身を薄くする。時間は減らない
```

手を抜くのが、一番もったいないやり方です。1時間かけて、何も身についていない。でも「やった」という記録は残るので、損をしていることに気づきません。例えば、答えを写して出す課題です。写すのに1時間かかります。その間、頭は使っていません。==1時間使って、何も残っていません。==

## 3つに分けます

学校から出てくるものを、3つに分けます。

```
　1　出さないと困るもの　　提出物、赤点を避けるための最低限
　　　　　→　時間を決めて、一番短い方法で終わらせる

　2　点につながるもの　　　受験や、自分が伸ばすと決めた教科のもの
　　　　　→　自分の勉強として扱う。閉じて出すところまでやる

　3　どちらでもないもの
　　　　　→　受けない
```

大事なのは、1と2を混ぜないことです。1は「終わらせる作業」です。きれいにやる必要がありません。先に「30分」と時間を決めて、その中で終わらせます。時間をかけたまま中身だけ薄くする「手を抜く」とは、ここが違います。2は「できるようになる作業」です。終わらせても、できていなければ意味がありません。

## 受ける前に、1つだけ聞きます

3かどうかを見分ける質問が、1つあります。

　　これが終わった時、何ができるようになっていますか。

補習でも、講習でも、追加の問題集でも同じです。答えが返ってこない、または返ってきた答えが自分に要らないものなら、3です。

```
　　「共通テストの形式に慣れる」　　　→　共テを使うなら2。使わないなら3
　　「苦手な人向けに基礎を復習する」　→　その単元が苦手なら2。違うなら3
　　「とりあえず受けておいたほうが」　→　3
```

先生に直接聞きにくければ、配られた案内の紙か、授業の予定表を見てください。たいてい書いてあります。書いていないものは、3の可能性が高いです。

## 中学生は、ここに1つ足します

高校受験で内申が使われるなら、分け方が少し変わります。

提出物、小テスト、授業中の発言、実技の教科。これが内申に入る学校では、それは「出さないと困るもの」ではありません。==入試の点、そのものです。== 2の箱に入れてください。

```
　　受ける前に聞くこと（中学生）
　　　　これは、内申に入りますか？
```

内申のつき方は、都道府県と学校で違います。だから、最初に確かめます。先生に聞いていいことです。「どれが成績に入りますか」と聞いた人は、やる気がない人ではありません。どこに力を入れるかを、決めようとしている人です。

入るとわかったものは、手を抜きません。入らないとわかったものは、一番短い方法で終わらせます。全部を同じ本気でやって、全部が中くらいになるのが、一番損です。

## 小テストは、「点につながるもの」に入れます

学校から出るものの中で、軽く見られやすいのが、小テストです。10点満点の、単語テスト。点だけ見て、捨てる人が多いです。

でも、小テストの範囲は、定期テストの範囲と、同じ所です。先生は、わざわざ別の問題を作りません。==小テストは、「ここが出ます」という予告です。==だから、2の箱に入れます。

やることは、1分で終わります。返ってきたら、間違えたものだけを、1冊のノートに書き写します。合っていた問題は、もう見なくていいです。

1回の小テストで3問なら、1学期で12回。36問です。それが、自分だけの問題集になります。全部、自分が実際に落とした問題だからです。次の小テストの前の日に、そのノートを閉じて、言えるかを確かめます。

## 「それは逃げになりませんか」

一番よく聞かれます。

逃げかどうかは、捨てたかどうかでは決まりません。==空いた時間を何に使ったかで決まります。==

```
　　補習を断って、その12時間で寝た　　　　　　→　逃げ
　　補習を断って、その12時間で長文を24本　　　→　選択
```

同じ「断る」でも、別のことです。だから、3に番号をつけた時は、その時間に何を入れるかを同時に決めてください。決めないまま空けると、本当に逃げになります。
