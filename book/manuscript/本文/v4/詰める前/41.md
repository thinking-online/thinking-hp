## 録音した自分の声を、聞いたことがありますか？

……

「え、こんな声なの？」と、思いませんでしたか。

生まれてから毎日、聞いている声です。それでも、外から聞くと、自分が思っていた声とは、違います。

==自分のことは、自分では、見えません。==声でさえ、そうです。勉強のやり方や、答案の書き方は、もっと見えません。

英作文の練習を、しています。問題を解いて、模範解答を見ます。自分の答えと、模範解答は、違う文です。

　　「人に見せるのは、もう少し書けるようになってから。今は、自分で直そう」

模範解答を、ノートに写します。「こう書けばいいのか」。次の問題へ進みます。

3か月たちました。50題、解きました。でも、自分の書いた文が、何点なのかは、今も、わかりません。同じ間違いを、50回、続けていたかもしれません。

## フォームも、自分では見えません

部活でも、同じです。

バスケのシュートを、1人で、1000本打つ。たくさん打てば、うまくなりそうです。でも、ひじが開いたまま1000本打つと、ひじが開いたフォームが、体に入ります。

本人は、ひじが開いていることに、気づいていません。自分のフォームは、自分では見えないからです。

コーチが、横から見て、一言。「ひじ、開いてるよ」。3秒で、わかります。

勉強も、同じです。

```
　　自分で気づける間違い　　　答えが違う。計算が合わない
　　自分では気づけない間違い　考え方のくせ。答案の書き方。時間の使い方。勉強のやり方そのもの
```

答えが1つに決まる問題は、自分で丸つけができます。でも、下のほうは、1人で何時間やっても、見えません。==見えないものは、直せません。==

## 1人でやるのが、えらいわけではありません

「人に頼るのは、甘えだ」。「自分の力でやらないと、力がつかない」。真面目な人ほど、そう思っています。

分けて考えます。

```
　　自分でやること　　　　考える。解く。思い出す。直す
　　人に見てもらうこと　　どこがズレているかを、見つける
```

解くのを、人にやってもらったら、力はつきません。でも、ズレを見つけてもらうのは、甘えでは、ありません。スポーツの選手に、コーチがいるのと、同じです。

## 見せるのは、「できてから」ではなく、「途中」です

多くの人は、「もう少しできるようになってから、見せよう」と思います。できていない所を、見られたくないからです。

でも、順番が逆です。

```
　　できてから見せる　→　ズレたまま、何十時間も進む。直す量が、増える
　　途中で見せる　　　→　ズレが小さいうちに、直せる
```

絶対法則06で書いた通り、早く間違えて、早く直す。人に見せるのも、同じです。==見せるのが早いほど、直すのが楽です。==

## 誰に、何を見せるか

見せる相手は、学校の先生、塾の先生、その教科が得意な先輩や友達。相手がいない時は、AIにも見せられます（42番と43番）。

見せるものは、3つです。

```
　　答案　　　記述、英作文、数学の途中の式。「どこで点を引かれますか」
　　やり方　　今使っている本と、1週間の進め方。「これで、足りますか」
　　計画　　　ゴールと、やる3つ（絶対法則04）。「順番は、これで合っていますか」
```

そして、聞き方を、1つ決めておきます。

　　==「一番直したほうがいい所は、どこですか」==

「どうですか」と聞くと、「いいんじゃない」で終わります。「一番直す所」を聞くと、1つ、返ってきます。直すのは、その1つだけで、いいです。全部を直そうとすると、続きません。

## 直したら、もう一度、同じ人に見せます

言われた所を直したら、もう一度、同じ人に見せます。

直ったかどうかも、自分では、見えないからです。「直りました」と言ってもらって、初めて、その1つが終わります。
