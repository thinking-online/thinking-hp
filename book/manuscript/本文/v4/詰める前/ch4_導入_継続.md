### この1か月で、当てはまるものは、いくつありますか？

```
　　◻︎　計画を立てたのに、3日で崩れた
　　◻︎　机に向かったのに、集中できずに終わった
　　◻︎　テストの結果を見て、落ちこんで、手につかなかった
```

……

1つでも当てはまった人に、聞きます。その時、自分に、何と言いましたか。

　　「自分は、意志が弱い」

そう思った人が、多いはずです。

違います。やる気も、集中力も、気持ちも、その日によって、変わります。変わるものに頼っているから、続かないだけです。意志が弱いからでは、ありません。

絶対法則06で、「意志では、変わりません。先に、仕組みを作ります」と書きました。この章は、その仕組みを、1つずつ作っていく章です。

頭のいい人は、やる気に頼っていません。==やる気がない日でも進む形を、先に作っています。==

上の3つは、そのまま、この章の3つの入口です。

```
　　計画が、崩れる　　　→　計画編（26〜30番）
　　集中が、続かない　　→　集中編（31〜35番）
　　気持ちが、落ちる　　→　モチベ編（36〜40番）
```

当てはまった所から、読んでください。
