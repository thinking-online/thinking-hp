# 08
## 次の文を、読んでください。何の話か、わかりますか？

```
　　まず、人数を数えます。
　　同じ量になるように、1つずつ、分けていきます。
　　最初に多く入れすぎると、最後に、足りなくなります。
　　全員に行きわたったら、残りを、ほしい人で分けます。
　　終わったら、決まった場所に、戻します。
```

……

何の話か、わからなかったと思います。知らない言葉は、1つもないのに、です。

題は、「給食当番」です。

もう一度、読んでみてください。同じ文が、今度は、すっと入ってきます。

==先に全体を知っていると、同じ文が、読めるようになります。==知らないまま読むと、1行1行は読めても、何の話なのかが、つかめません。

アメリカの、ニューヨーク州立大学の研究者たちが、同じ形の実験をしています。何の話かわかりにくい文章を、聞いてもらいます。先に、何の話かを知らされたグループは、内容がよくわかり、あとで、よく思い出せました。聞き終わってから知らされたグループは、どちらも、ずっと低いままでした。全体を知るのは、「あと」ではなく、「先」です。

## いきなり細かい所から入れると、全部が、同じ大事さに見えます

新しい参考書を買った時にも、同じことが起きています。日本史の、300ページある1冊。「1ページ目から、丁寧に読んでいこう」。1か月たちました。まだ、平安時代です。縄文時代は、もう、ほとんど忘れています。そして、この本が、全部でどんな話なのかは、まだ知りません。

全体を知らないまま読むと、==今読んでいる所が、全体のどこなのかが、わかりません。==どこが大事なのかも、わかりません。だから、全部が同じ大事さに見えて、細かい所まで、全部を丁寧に入れることになります。

```
　　×　1ページ目から、細かい所まで、丁寧に入れていく
　　○　先に、幹になる所をさっとつかんでから、細かい所に進む
```

## 先に、5分で、最後までめくります

読む前に、5分だけ使います。中身は、読みません。==見るのは、「何が、どの順番で並んでいるか」だけです。==さっきの日本史の1冊なら、こうなります。

```
　　目次を読む　　　　　「全部で6章。古い時代から、順番に並んでいる」
　　最後までめくる　　　「前半は、貴族の話。後半は、武士の話が多い」
　　閉じて、3つで言う　「時代は、6つ。前半は貴族、後半は武士」
```

これが、幹です。そのあとで、1ページ目から読みます。同じページでも、見え方が変わります。「これは、あとで出てくる武士の話の、準備だな」。今読んでいる所が、全体のどこなのかが、わかるからです。

## 1冊が無理なら、単元だけでも、先に全体像をつかみます

教科を丸ごと、一気につかめなくても、大丈夫です。これから習う単元だけでいいので、先に、全体像をつかみます。今は、そのための道具が、すぐ手に入ります。

```
　　教材なら　要点だけをまとめた、入門レベルのものを、さっとやる
　　動画なら　無料の解説動画を、さっと1本だけ見る
　　AIなら　　「この単元の要点だけ、教えて」と送ってから始める
```

例えば、江戸時代なら、「徳川が、約260年、治めた」「外国との付き合いを、しぼった」「黒船が来て、終わりへ向かった」。この3つを知ってから授業を受けると、細かい出来事が、「3つのうちの、どれの話か」と、置き場所つきで入ってきます。

1冊でも、単元でも、同じです。==いきなり細かい所からではなく、まず、幹をつかむ。==細かい所は、そのあとです。

読み始めてからも、同じです。1章を完璧にしてから2章へ、ではなく、薄く、最後まで進みます。絶対法則06で書いた通り、1回目から完璧にする必要は、ありません。わからないまま進むのは、気持ち悪いと思います。その気持ちは、まともです。ただ、最初の章でわからなかったことが、あとの章を読んだら、わかる。そういうことは、よくあります。わからない所には、ふせんを貼って、先へ進んでください。
