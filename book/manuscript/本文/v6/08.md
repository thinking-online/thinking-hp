# 08
## 次の文を、読んでください。何の話か、わかりますか？

```
　　まず、人数を数えます。
　　同じ量になるように、1つずつ、分けていきます。
　　最初に多く入れすぎると、最後に、足りなくなります。
　　全員に行きわたったら、残りを、ほしい人で分けます。
　　終わったら、決まった場所に、戻します。
```

……

何の話か、わからなかったと思います。知らない言葉は、1つもないのに、です。

題は、「給食当番」です。

もう一度、読んでみてください。同じ文が、今度は、すっと入ってきます。

==先に全体を知っていると、同じ文が、読めるようになります。==知らないまま読むと、1行1行は読めても、何の話なのかが、つかめません。

新しい参考書を買った時にも、同じことが起きています。日本史の、300ページある1冊。「1ページ目から、丁寧に読んでいこう」。1か月たちました。まだ、平安時代です。縄文時代は、もう、ほとんど忘れています。そして、この本が、全部でどんな話なのかは、まだ知りません。

## 「題」は、ジグソーパズルの、箱の絵です

1000ピースのジグソーパズルを、箱の絵を見ずに始める人は、いません。

まず、箱の絵を見ます。全体がわかってから、ピースを見ます。すると、「この青は、空だな」「これは、船のはしだな」と、置く場所がわかります。

さっきの「給食当番」という題が、箱の絵です。

全体を知らないまま、1ページ目から読むと、==今読んでいる所が、全体のどこなのかが、わかりません。==どこが大事なのかも、わかりません。だから、全部が同じ大事さに見えて、全部を丁寧に読むことになります。

## 先に、5分で、最後までめくります

読む前に、5分だけ使います。

```
　　①目次を見る　　　　　　　　　　　　章の題を、声に出して読む
　　②最後まで、めくる　　　　　　　　　見出しと、太字と、図だけを見る
　　③閉じて、「何の本か」を3つで言う　「時代は、6つ。前半は貴族、後半は武士」
```

中身は、読みません。わからなくて、いいです。==見るのは、「何が、どの順番で並んでいるか」だけです。==

これが、箱の絵になります。

そのあとで、1ページ目から読みます。同じページでも、見え方が変わります。「これは、あとで出てくる武士の話の、準備だな」。ピースを置く場所が、わかるからです。

## 1周目は、薄く、最後まで行きます

読み始めてからも、同じ考え方を使います。

```
　　×　1章を完璧にしてから、2章へ　　　　　→　最後の章に着くのは、何か月もあと。そのころ、1章は忘れている
　　○　薄く、最後まで1周してから、2周目へ　→　全体を知った上で、細かい所を読める
```

絶対法則06で書いた通り、1回目から完璧にする必要は、ありません。絶対法則05で書いた通り、同じ所は、別の日に、もう一度やります。1周目は、「何が書いてあるか」を知るための周です。

1冊の本だけの話では、ありません。

```
　　歴史　　　　先に、マンガや年表で、流れを最後まで見ておく
　　数学　　　　章の最初に、例題の題だけを、全部見ておく
　　英語の長文　先に、設問を見ておく
```

全部、同じことをしています。先に、箱の絵を見ています。

## 「わからないまま進むのが、気持ち悪いです」

その気持ちは、まともです。

ただ、最初の章でわからなかったことが、あとの章を読んだら、わかる。そういうことは、よくあります。全体を知らないと、わからない所だったからです。

わからない所には、ふせんを貼って、先へ進んでください。2周目に、戻ってきます。その時には、いくつかは、もう、わかるようになっています。
