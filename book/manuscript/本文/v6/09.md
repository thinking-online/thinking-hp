# 09
## 授業の最初に、先生がこう言ったら、聞き方は変わりますか？

　　「今日の授業の終わりに、1人、前に出てもらいます。今日の内容を、30秒で、みんなに説明してもらいます。誰に当てるかは、最後に決めます」

……

変わりますよね。

同じ先生の、同じ50分です。それでも、聞き方が、まるで変わります。大事な所を、探しながら聞きます。わからない所を、そのままにできません。ノートに書くことも、変わります。

先生の話は、1つも変わっていません。変わったのは、==「あとで、自分が説明する」と決まったこと==だけです。

ふだんの授業では、誰も、そう言ってくれません。だから、ちゃんと聞いているのに、その日の夜、同じ範囲のワークを開くと、1問目で手が止まります。「明日は、もっと集中して聞こう」。そう決めて、次の日も、同じことが起きます。

## 「ちゃんと聞く」だけでは、話が、通っていくだけです

授業中の頭の使い方は、3つに分けられます。

```
　　聞くだけ　　　先生の言葉が、耳を通っていく
　　写す　　　　　黒板の字を、ノートに運ぶ。手は動く。頭は、字を運んでいるだけ
　　自分で作る　　大事な所を選ぶ。自分の言葉にする。次を予想する
```

下に行くほど、頭に残ります。

「集中して聞く」は、どれだけ頑張っても、1つ目です。先生の説明は、わかりやすく作られています。だから、聞いている間は、すっと通ります。「わかった」と感じます。でも、絶対法則01で見た通り、「わかった感じ」と、頭に残ったことは、別です。

第2章の最初に書いた通り、インプットは、その時、頭が何に向いていたかで決まります。授業中に、頭を、3つ目に向ける。そのための一番かんたんな方法が、最初の質問です。

## 「終わったら、30秒で人に教える」と決めてから、聞きます

決まりは、1つです。

　　==授業が終わったら、30秒で、人に教える。そう決めてから、聞く。==

先生は、当ててくれません。だから、毎回、自分で自分に当てます。

教える相手は、今日休んだ友達でも、家の人でも、かまいません。いなければ、頭の中の相手で十分です。07番で書いた通り、教える「つもり」になるだけで、入り方が変わります。

そう決めて聞くと、頭が、勝手に、3つのことを始めます。

```
　　大事な所を、探す　　　　30秒で全部は話せない。「どれを話すか」を選びながら聞く
　　つながりを、聞く　　　　教えるには、「なぜ、そうなるか」が要る。理由を聞きのがさなくなる
　　わからない所に、気づく　わからない所は、教えられない。そのままにできなくなる
```

聞いている内容は、同じです。頭の向きが、変わります。

## 50分の中で、やることは3つです

「教えるつもり」を、授業の前、途中、あとに、1つずつ置きます。

```
　　始まる前　　　10秒　　ノートの上に、07番の型を書く
　　15分ごと　　　30秒　　ここまでを、何も見ずに、言葉3つで書く
　　終わった直後　30秒　　型を埋めて、今日の話を、30秒で教える
```

1つ目。ノートの一番上に、07番の型を書きます。「結局、【　】の話。キーワードは、【　】【　】【　】」。空いた枠があると、50分の間、それを埋めるものを、探しながら聞くことになります。

2つ目。50分の最後に、初めて思い出そうとすると、前半は、もう出てきません。だから、15分に1回、30秒だけ、ここまでを出します。授業中は声が出せないので、ノートのすみに、言葉を3つ書きます。黒板も、ノートも、見ません。出てこなかったら、「？」を1つ書いておきます。そこが、休み時間に確かめる所です。

「30秒の間に、先生の話を聞きのがしませんか」。先生が黒板に書いている間や、プリントを配っている間に、やってください。15分ちょうどでなくて、いいです。

3つ目。チャイムが鳴ったら、教科書をしまう前に、30秒。15分ごとに書いた言葉の中から、キーワードを3つ選んで、型を埋めます。その3つを使って、「今日は、結局、こういう話」を、頭の中の相手に教えます。型が埋まって、30秒で言えたら、今日の授業は、入っています。

## 途中に「出す」をはさむと、ぼんやりが減ります

ハーバード大学の研究者たちの実験です。

授業の映像を、4つに区切って見てもらいます。片方のグループには、区切りごとに、短いテストをはさみました。もう片方には、はさみませんでした。

はさんだグループは、==授業中にぼんやりしていた時間が減って、最後のテストの点も高くなりました。==ノートを取る量も、増えていました。

50分の間、同じ集中で聞き続けられる人は、いません。15分ごとの30秒は、頭を切りかえる合図にもなります。

## 先生が答えを言う前に、自分の予想を持ちます

慣れてきたら、もう1つ、足してください。

キリンの首の骨は、何個あると思いますか。予想してから、次の行を読んでください。

……

7個です。人間と、同じ数です。

「え？」と、なったはずです。予想してから聞いた答えは、ただ聞いた答えと、残り方が違います。そして、「え？」となったことは、人に話したくなります。

授業でも、同じことができます。先生が「なぜだと思う？」と聞いたら、当てられていなくても、心の中で、先に答えます。外れて、かまいません。外れた所には、ノートに「！」をつけます。

絶対法則03の「うーん」と、絶対法則06の「先にまちがえる」を、授業の中でやっています。

## ノートには、「教える時のヒント」だけを書きます

「あとで教える」と決めると、ノートも変わります。

黒板を、全部写す人が多いです。でも、写している間、頭は、字を運んでいるだけです。先生の話は、聞き流しています。

```
　　黒板に書いてあること　→　教科書や問題集にも、だいたい載っている。あとで、何回でも見られる
　　先生が口で言ったこと　→　その場で聞きのがしたら、もう聞けない
```

全部写している人は、==あとで見られるほうを一生けんめい写して、その場でしか聞けないほうを、聞きのがしています。==

説明の間は、ペンを置いて聞きます。書くのは、あとで教える時の、ヒントだけです。

```
　　先生が口で言ったこと　　　「aで割る前に、a=0を確かめる」「ここ、テストに出す」
　　最初の一手と、その理由　　「まず、yについて解く。文字を1つにするため」
　　「？」と「！」　　　　　　わからなかった所。予想が外れた所
```

1つの例題に、3行まで。図だけは、写してください。グラフや地図は、手で描いたほうが、頭に入ります。

数学や理科の例題は、30秒で教えるかわりに、その日のうちに、1問、白紙から解きます。解き方は、言葉で言うより、手で再現したほうが、確かめやすいからです。（15番に書きます）

## 映像授業は、止めて、教えます

映像授業でも、同じです。しかも、映像には、教室にないものが、1つあります。止められることです。

```
　　10分たったら　　　　　　→　止める。ここまでを、声に出して教える
　　先生が問題を出した直後　→　止める。答えを見る前に、自分で解く
```

倍速にすると、入る速さは上がります。でも、頭が自分で作った回数は、0のままです。進んだ気がするのは、再生バーが右に動いたからです。再生バーは、頭の中を測っていません。

1周目は、普通の速さで、止めながら。倍速は、2周目からです。==倍速の正しい使い道は、速く入れることではなく、速く確かめることです。==
