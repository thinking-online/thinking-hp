# 10
## 次の文を読んで、1問だけ、答えてください

　　アミラーゼという酵素はグルコースがつながってできたデンプンを分解するが、同じグルコースからできていても、形が違うセルロースは分解できない。

　　問　セルロースは（　　　）と形が違う。
　　①デンプン　②アミラーゼ　③グルコース　④酵素

……

答えは、①のデンプンです。③のグルコースを選んだ人は、いませんか。全国の中学生と高校生が受けた、読む力のテストの問題です。まちがえた人が多かった問題で、大人でも、グルコースを選ぶ人がいます。（新井紀子さんの本『AI vs. 教科書が読めない子どもたち』で、紹介されています）

知らない言葉は、ありました。でも、答えは、文の中に、全部、書いてあります。目も、最後の「。」まで、動きました。それでも、まちがえます。教科書や参考書を読んでいる時にも、同じことが、起きています。

## なんとなく読むと、1つ1つの理解が、甘くなります

多くの人は、教材を、なんとなく読んで、終わっています。目が最後の行まで行くと、「読めた」と感じるからです。でも、絶対法則01で見た通り、「やった感じ」と、「頭に残った」は、別のものです。

さっきの文で、グルコースを選んだ人も、文字は、全部、見ています。「グルコース」も、「形が違う」も、目に入っていました。入っていなかったのは、==言葉と言葉の、つながり==です。何が、何を、どうするのか。何と、何を、比べているのか。なんとなく読むと、近くにある言葉どうしを、頭の中で、くっつけてしまいます。

1文の理解が甘いまま、次の文に進む。次も、甘いまま進む。それが、1ページ、1章と、積み重なります。「読んだはずなのに、問題が解けない」は、ここから始まっています。

```
　　×　目で追って、読めたことにする
　　○　止まった文は、図にして、確かめる
```

## 止まった文は、丸と矢印で、図にします

読んでいて、「ん？」と止まった文。2回読んでも、入ってこない文。そこで、ペンを持ちます。==出てくるものを、丸で囲む。「何が、何を、どうする」を、矢印でつなぐ。残った説明を、横に書く。==この3つです。

さっきの文で、やってみます。出てくるものは、アミラーゼ、デンプン、セルロース、グルコースの4つ。「アミラーゼが、デンプンを、分解する」「セルロースは、分解できない」を、矢印にします。

```
　　アミラーゼ　→（分解できる）→　デンプン　　＝グルコースがつながったもの
　　アミラーゼ　→（分解できない）→　セルロース　＝同じグルコース。形が違う
```

図にすると、デンプンと、セルロースが、同じ位置に並びます。どちらも、同じグルコースからできている。でも、片方は分解できて、片方は分解できない。「形が違う」は、この2つを比べた言葉です。だから、答えはデンプン。==文のままだと迷った所が、図にすると、一目でわかります。==

アミラーゼが何なのか、知らなくても、この図は、かけます。図にするのは、言葉の意味ではなく、言葉と言葉の、つながりだからです。

図の形は、まず、3つで十分です。

```
　　誰が、何を、どうする　→　丸と、矢印
　　順番や、流れ　　　　　→　1列に並べて、矢印でつなぐ
　　AとBの違い　　　　　　→　2列の表
```

全部の文を、図にする必要は、ありません。止まった文だけで、十分です。きれいにかく必要も、ありません。ノートのすみに、30秒でかける図で、いいんです。

## 図にできない所が、まだ、わかっていない所です

図にしようとして、手が止まることがあります。矢印を、どこから、どこへ引くのか。丸は、いくつあるのか。==手が止まった所が、まだ、わかっていない所です。==読むだけでは気づけなかった所が、図にすると、見つかります。逆に、図にできたなら、その文は、わかっています。

中学生に、理科の文章を読んでもらった実験があります。図をかきながら読んだグループは、読むだけのグループより、内容のテストの点が高かった、という結果です。図を正確にかけた人ほど、点が高い傾向も、ありました。

## 自分で図にできない時は、AIに、手伝ってもらいます

どうしても、図にできない文も、あります。その時は、AIを使ってください。文をそのまま見せて、「この文を、丸と矢印の図にして」と頼みます。教科書や参考書に、同じ内容の図がのっていれば、それでも、かまいません。

ただし、図を見て、「なるほど」で、終わりにしません。見るだけより、自分でかいたほうが、頭に残ります。図を閉じて、自分の手で、もう一度かく。かけたら、わかった、です。（AIの使い方と、気をつける所は、34番に書きます）
