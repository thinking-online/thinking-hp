# 11
## 「むかしむかし、あるところに、おじいさんと……」

続きを、頭の中で、言いましたね。

「おばあさんが、いました」。頼まれていないのに、最後まで言ったはずです。

途中で止まったものを、人の頭は、放っておけません。終わらせたくて、気になり続けます。

「キリのいい所までやってから、休もう」と思うのも、同じ力です。途中で止めるのが、気持ち悪い。だから、あと3問、あと1ページ、と続けます。

気づくと、1時間半、座りっぱなしです。やっと休憩して、スマホを開きます。30分たちました。机に、戻れません。次に何をやるかも、決まっていません。

## 集中は、気づかないうちに落ちています

1時間半のうち、最後の30分。どれくらい、頭に入っていたでしょうか。

人は、自分が疲れているかどうかに、気づくのが苦手です。座っているし、手も動いている。だから、やれていると思います。でも、同じ問題を読み直す回数が増えています。計算の間違いが増えています。

==集中は、切れてから休むのでは、遅いんです。==切れる前に、区切ります。

## 区切りは、キリではなく、時間で決めます

「キリのいいところ」で区切ると、区切りは、どんどん後ろにズレます。だから、時間で決めます。よく知られているのは、25分やって、5分休むやり方です。タイマーが鳴ったら、止めます。

## 間に、1分を足します

僕が生徒にやってもらっているのは、ここに1分を足した形です。数学のワークなら、こうなります。

```
　　25分　　式を1行書いた所で、タイマーが鳴る。そこで止める
　　 1分　　閉じて言う。「結局、一次関数の話。傾き、切片、変化の割合」
　　 5分　　立って、水を飲む。戻ったら、式の続きから書く
```

25分が終わったら、本を閉じて、1分だけ。「結局、今の25分は、何の話だった？」。07番のキーワード3つを、ここで使います。

この1分が、絶対法則02の「思い出す」の1回になります。25分やって、そのまま休むと、入れただけで終わります。==1分で、出してから休む。==これを4回やれば、2時間で4回、思い出しています。

## キリの悪いところで、止めます

タイマーが鳴った時、問題の途中だったら、どうするか。途中で、止めてください。人は、終わったことより、途中で止まっていることのほうが、気になります。最初の「むかしむかし」と、同じです。

```
　　キリのいいところで止める　→　次は「新しい1問目」から。始めるのが、重い
　　キリの悪いところで止める　→　次は「さっきの続き」から。始めるのが、軽い
```

式を1行書いたところで、止める。英文を半分読んだところで、止める。5分後、机に戻った時、やることは決まっています。続きを書くだけです。

1日の最後だけは、別です。寝る前は、1問出して、○で終わります（24番に書きます）。==休憩の前は、途中で。1日の終わりは、○で。==

## 休憩で、スマホを見ません

スマホを見ると、頭は休まりません。新しい文字と映像が、どんどん入ってきます。立つ。水を飲む。窓の外を見る。少し歩く。==何も入れない5分==にします。

25分は、目安です。僕は、頭がよく回る午前中は、少し長めにしていました。疲れてくる夕方は、短めにしていました。大事なのは、25という数字ではありません。==切れる前に、自分で区切る==ことです。25分を3回か4回やったら、長めに休みます。
