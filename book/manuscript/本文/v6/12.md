# 12
## 好きな曲の歌詞を、ノートに書いて、覚えましたか？

好きな曲を、1つ、思い浮かべてください。サビを、頭の中で、歌えますか。

……

歌えたはずです。1曲まるごと歌える人も、いると思います。でも、その歌詞を、ノートに10回書いて覚えた人は、いないはずです。

やったことは、2つだけです。何回も、聴いた。そして、歌詞を見ずに、何回も、口ずさんだ。それも、1日でまとめてではなく、何日も、くり返しました。==1回も書いていないのに、覚えています。==

ところが、英単語になると、急に、ノートに10回、書き始めます。

## 残るのは、書いた回数ではなく、思い出した回数です

「書かないと、覚えられない」。そう言う人は、多いです。書くと、ノートが、びっしり埋まります。手も、疲れます。「やった感じ」が、一番出るやり方です。でも、「やった感じ」と、「頭に残った」は、別のものです。

10回書く時、1回目は、単語帳を見て、書きます。2回目からは、すぐ上の、自分の字を見て、書きます。答えは、ずっと目の前にあります。10回書いて、思い出した回数は、0回です。長く残るのは、何も見ずに、思い出そうとしたものでした（絶対法則02）。しかも、書くのは、時間がかかります。1語を10回書くと、1分ほどです。

```
　　10回書く　　　　　→　30分で、30語。思い出した回数は、0回
　　見て、思い出す　　→　30分で、100語。1語を、3回以上、思い出す
```

何回も書くことが、効く場合もあります。見たことのない形を、覚える時です。ただ、言葉を覚える時には、書いても、差が出なかった、という実験もあります。==時間は、書くことではなく、思い出すことに使います。==

## 見て、隠して、思い出す。これを、何周も回します

10個を、1セットにします。まず、単語と意味を、30秒、見ます。次に、意味を、赤シートか手で隠します。単語を見て、意味を思い出す。1語に、3秒。出なければ、すぐ答えを見て、次へ。止まりません。

最初は、ほとんど出てきません。それで、いいんです。==印も、まだ、つけません。==最初から印をつけると、全部が、印だらけになります。同じ10個を、続けて、3周。とにかく、何度も、回します。「えーと……」と探してから答えを見ると、ただ見た時より、残ります。回すたびに、出てくる単語が、増えていきます。

```
　　1〜3周目　　印は、つけない。出なくても、答えを見て、すぐ次へ
　　3周したら　　まだ出ない単語にだけ、印をつける
　　次の10個へ　同じように、3周、回す
```

10個で、2分ほど。100語でも、20分です。書く人が、30語を書いている30分で、100語を、3回ずつ、思い出せます。残った10分は、印がついた単語だけを、もう一度、回します。

## 思い出す回数は、1日に詰めこまず、別の日に分けます

歌詞も、1日で覚えたわけでは、ありませんでした。絶対法則05で見た通り、同じ回数なら、間をあけたほうが、長く残ります。

```
　　×　今日、1語を、見ながら10回書く
　　○　今日3回、次の日に1回、テストの前の日に1回、見て思い出す
```

今日、3周。次の日は、印がある単語から、もう一度、回します。出てきたら、印を消します。テストの前の日は、印が残っている単語だけ。==思い出す回数を増やして、日を分ける。==覚えるためにやることは、この2つです。

## 書くのは、「見ないで」です

書くことを、全部やめるわけでは、ありません。

```
　　意味が言えればいい　→　書かない。見て、隠して、思い出す
　　つづり、漢字　　　　→　書く。ただし、見ながら10回ではなく、見ないで1回
```

見ないで書けば、それは、「思い出す」になります。書けなかった所だけ、見て、もう一度、見ないで書く。見ながら書くか、見ないで書くか。同じ「書く」でも、頭の使い方は、まったく違います。
