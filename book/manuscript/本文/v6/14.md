## 攻略本を、全部覚えてから、ゲームを始めますか？

新しいゲームを、始める時。攻略本を、最初のページから最後まで覚えてから、スタートボタンを押す人は、いません。まず、始めます。敵に、やられます。「あ、ここは、こうするのか」。やられた所だけ調べて、もう一度、挑みます。そうやって、いつの間にか、全部、覚えています。

ところが、勉強では、逆をやります。「教科書を、ちゃんと覚えてから、問題集をやろう」。覚えきるまで、問題は、開きません。

```
　　×　教科書を、覚えきってから、問題を解く
　　○　ざっと読む　→　すぐ解く　→　×だった所だけ、教科書に戻る
```

## 問題は、ゴールに一番近く、いやでも思い出させてくれます

問題を解きながら覚えたほうがいい理由は、2つあります。

1つ目は、戦略です。最後に点になるのは、問題が解けるかどうかです。そして、問題は、「どこを、どんな形で聞かれるか」を、そのまま見せてくれます。教科書を読んでいるだけでは、どこが大事かは、わかりません。==ゴールに一番近い所から、始めます。==

2つ目は、思い出すことです。絶対法則02で見た通り、残るのは、思い出そうとしたものです。でも、自分で「思い出そう」と決めるのは、面倒です。問題を前にすると、いやでも、思い出そうとします。==問題は、「思い出す」を、半分、強制してくれる道具です。==問題を解くこと自体が、覚える方法になる。これを、「テスト効果」と呼びます。

「まだ覚えていないのに、解いても意味がない」。そう思うはずです。カリフォルニア大学アーバイン校の研究者たちの実験があります。文章を読む前に、先に問題を解いたグループは、ほとんど答えられませんでした。それでも、あとのテストでは、読む時間を長くもらったグループより、点が高い、という結果でした。

## 世界史を、ゼロから10か月で仕上げた時に、やったこと

僕は、浪人の時、選択科目を、世界史に変えました。ゼロからのスタートです。それでも、10か月後には、早稲田大学の入試でも、世界史で圧勝できるようになっていました。やったことは、「覚えてから解く」の、逆です。

```
　　1　その範囲を、ざっと読む（1回だけ。覚えようとしない）
　　2　すぐ、その範囲の問題を解く（解けなくていい）
　　3　答えと解説を見て、聞かれた所だけ、教科書に戻る
　　4　別の日に、まちがえた問題を、もう一度解く
```

例えば、こうなります。

```
　　問題　　「1789年に、フランスで起きたことは？」　→　出てこない
　　答え　　フランス革命　→　教科書の、その段落だけ読む
　　次の日　同じ問題　→　「フランス革命」
```

最初は、10問のうち、2問しか合いません。それで、いいんです。ゲームで、敵にやられるのと、同じです。「こう聞かれるのか」と知ってから読む教科書は、ただ読んだ時と、入り方が、まったく違います。

## 問題集は、力試しではなく、覚える道具です

「問題集は、覚えてから、力試しに使いたい」。そう思う人は、多いです。でも、初めて解いて○だった問題からは、何も増えません。×だった問題が、覚える所を、教えてくれます。問題集は、何周もするものです。1周目は、覚えるために使います。（過去問を先に解く話は、16番に書きます）
