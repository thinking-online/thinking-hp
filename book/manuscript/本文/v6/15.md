## 1から100までを、全部足すと、いくつですか？

解き方を、書きます。

```
　　1と100を足すと、101。2と99を足しても、101。
　　こういうペアが、50組できる。
　　だから、101×50＝5050。
```

「なるほど」と、思いましたね。

では、上の3行を手で隠して、解いてください。

　　1から40までを、全部足すと、いくつですか。

……

答えは、820です。（41×20）

「ペアは、何組だっけ」。そこで、手が止まりませんでしたか。

解き方を読んで、「なるほど」と思いました。それでも、数字が変わっただけで、止まります。

問題集の解説を読んだあとにも、同じことが起きています。「なるほど、わかった。次」。赤ペンで答えを写して、次の問題へ進みます。1週間後。同じ問題が、小テストに出ました。最初の1行が、書けません。

## 「わかる」と「できる」の間には、段差があります

解説を読んで「わかった」時、やっていたことは、何でしょうか。人が解いた道を、後ろから、ついて歩いただけです。

```
　　わかる　　解説の1行1行に、「うん、そうなる」と言える
　　できる　　何も見ずに、最初の1行から、自分で書ける
```

道案内をしてもらって着いた場所に、次の日、1人で行けるとは、かぎりません。「次、どっちに曲がるか」を、自分で決めていないからです。解説も、同じです。一番難しい、「最初に、何をするか」は、解説が決めてくれています。07番の、人に説明する時と同じです。見ながらできても、何も見ずに再現できなければ、まだ、自分のものでは、ありません。

## 本番で目の前にあるのは、問題文と、白紙だけです

模試でも、入試でも、目の前にあるのは、問題文と、白い解答用紙だけです。解説も、ノートも、ヒントも、ありません。だから、練習の最後は、本番と同じ状態で、確かめます。

==問題文だけを見て、白紙に、最初の1行から、最後まで再現する。==

これを、「白紙再現テスト」と呼びます。再現できないものは、点になりません。さっきの「1から40まで」なら、白紙は、こうなります。

```
　　1行目　1と40を足すと、41。2と39でも、41。
　　2行目　ペアは……（手が止まった。ここに印）
　　　→　止まった所だけ、解説を見る。「100までで、50組」
　　　→　閉じて、最初から、もう一度書く
　　1行目　1と40を足すと、41。2と39でも、41。
　　2行目　ペアは、40の半分で、20組。
　　3行目　41×20＝820。
```

やってみると、驚くと思います。「わかった」はずなのに、途中で、手が止まります。==手が止まった所が、本当は、わかっていなかった所です。==解説を読んでいるだけでは、そこは、見つかりません。

## 写すのとは、違います

解説を見ながら、ノートに書き写す。これは、白紙再現テストでは、ありません。写している間、頭は、「次に何をするか」を、1回も決めていません。見るのは、止まった時だけ。そして、見たら、もう一度、閉じて、最初から書きます。

## どの教科でも、最後は、白紙で確かめます

```
　　数学・理科の計算　解説を閉じて、最初の式から書く
　　英語の長文　　　　和訳を閉じて、線を引いた文を、自分で訳す
　　社会・理科の説明　教科書を閉じて、「なぜ、そうなったか」を書く
```

全部の問題で、やる必要はありません。==解説を読んで、「わかった」と思った問題だけ==で、いいです。そして、閉じたすぐあとは、まだ、頭に解説が残っています。別の日に、もう一度、白紙から解きます。そこで書けたら、「できる」になっています。（どこまでできたら○にするかは、17番に書きます）
