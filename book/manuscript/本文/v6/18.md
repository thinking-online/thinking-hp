# 18
## 10秒で、「さ」で始まる食べ物を、5つ言ってください

心の中で、10数える間です。どうぞ。

……

5つ、言えましたか。

時間がいくらでもあれば、全員、言えます。知らない言葉は、1つもありません。それでも、「10秒で」と言われたとたんに、3つで止まった人も、いると思います。

==知っていることと、時間内に出せることは、別の力です。==テストで測られるのは、あとのほうです。

数学の問題集を、進めています。

```
　　1問目　10分かかったけど、解けた
　　2問目　15分かかったけど、解けた
　　3問目　20分かかったけど、解けた
```

「時間はかかったけど、解けた。全部○」。そうつけました。

模試の日。同じレベルの問題が、大問3つで、制限時間は60分でした。1問目に25分かかって、2問目の途中で、終わりました。

## 時間を測らないと、「できる」が本番とズレます

20分かけて解けた問題は、できる問題でしょうか。

本番で、その問題に20分使えるなら、できる問題です。本番で使えるのが7分なら、できない問題です。同じ問題でも、持ち時間によって、できる・できないが変わります。時間を測らないと、どちらなのかがわかりません。

## 本番の1問あたりの時間を、紙に書いて、机に貼ります

ここで一度、計算してみてください。

　　試験時間　÷　問題数　＝　1問あたりの時間

数学で、60分で大問4つなら、1問15分です。英語で、80分で長文2つと文法30問なら、長文1つに25分です。この数字を知らずに練習している人が、かなりいます。知らないと、何分で解けばいいかがわかりません。計算したら、紙に書いて、机に貼ります。

## タイマーを置いて解いて、○△×をつけます

```
　　○　時間内に、解けた
　　△　解けたが、時間をこえた
　　×　解けなかった
```

本番が1問15分だとして、最初の数学の3問を、つけ直します。

```
　　1問目　10分　○
　　2問目　15分　○
　　3問目　20分　△　原因：最初の式を決めるまでに、8分かかった
```

「全部○」では、ありませんでした。△には、原因を1行書きます。そして、時間内で、もう一度解きます。時間内に解けたものだけが、○です。

時間を測ると、解き方も変わります。15分と決めて解き始めると、途中で時計を見ます。7分経って、まだ方針が立っていなかったら、焦ります。焦ると、決めます。この問題は後回しにしよう、とか、別の方法を試そう、とか。本番で必要になるのは、この「どうするかを、その場で決める」ことです。時間を測らずに解いている人は、これを1回も練習していません。

## 全部測る必要はありません

毎回タイマーを置くのは、しんどいです。週に1回、まとめて測る日を作るのでもいいです。日曜に、大問4つを本番と同じ時間で解く。それだけでも違います。普段の練習は、時間を測らずにやってかまいません。ただし、その時つけた○は、「本番で取れる」の○ではありません。「解き方はわかる」の印です。

## 時間だけでなく、やり方も本番にそろえます

テストの時のことを、思い出してください。何も見ない。順番はばらばら。時間は決まっている。==練習の最後の1回は、それと同じ条件でやります。==ノートを見ながら解いた問題は、ノートがないと解けません。最初は、見ながらでいいです。でも、見ながら解けたものを「できた」に数えないでください。

机の上の解答冊子も、同じです。問題集の横に、解答を開いて置いています。2問目、式を立てたところで、ちらっと見ます。同じ式です。安心して進みます。3問目、少し迷って、解答を見ます。ああ、そうか。その方針で解きます。20問、全部○でした。テストの日、同じ形の問題で、最初の式が立ちません。

解答が目に入る場所にあると、人は見ます。意志の問題ではありません。そして、数学の問題で、一番難しいのは計算ではありません。最初の1行です。何をすればいいかを決めるところ。解答を横に置いていると、この最初の1行を、気づかないうちに解答からもらっています。

```
　　1　解答冊子を、目に入らない場所に置く（引き出し、カバン、別の部屋）
　　2　5問か10問、まとめて解いてから、まとめて丸つけをする
　　3　×の時、自分がなぜその方針を選んだのかを、1行書く
```

閉じて解くと、○の数は減ります。20問中、12問になるかもしれません。でも、その12問は、本番でも取れます。（答えを、いつ見ればいいかは、20番に書きます）
