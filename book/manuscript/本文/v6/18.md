# 18
## 「時間が、足りなかった」。では、あと30分あったら、解けましたか？

テストや模試のあとに、よく聞く言葉です。「時間が、足りなかった」。「時間内に、解ききれませんでした」。

では、聞きます。あと30分あったら、残りの問題は、全部、解けましたか。

……

「解けた」と言える人は、時間が足りなかった人です。「たぶん、解けなかった」という人は、時間では、ありません。足りなかったのは、実力です。

## 解けなかった理由は、2つあります。やることが、まったく違います

```
　　実力が足りない　→　時間をかけても、解けない　→　解き方から、やり直す
　　時間が足りない　→　時間をかければ、解ける　　→　時間内に解く練習をする
```

「時間内に、解ききれないんです」と相談に来る生徒は、多いです。でも、話を聞くと、時間以前に、そもそも、解けていないことが、ほとんどです。==時間のせいにする前に、まず、実力です。==時間がかかってもいいから、自分の力で、最後まで解ける。先に作るのは、その状態です。

困るのは、時間を測らずに勉強していると、自分がどちらなのかが、わからないことです。だから、時間を測ります。それも、2つ、測ります。

## 「時間内」と「Max」の、2つを測ります

過去問や、模試の形の問題を解く時に、やります。まず、本番と同じ時間で、タイマーをかけて解きます。時間が来たら、解答用紙に、線を引きます。そのあとは、時間を気にせずに、解ける所まで、解きます。線より上が、「時間内」。全部合わせたものが、「Max」。丸つけをして、点を、2つ出します。

```
　　時間内40点・Max45点　→　時間をかけても、解けない。足りないのは、実力
　　時間内40点・Max75点　→　時間をかければ、解ける。足りないのは、速さ
```

時間内の点は、同じ40点です。でも、やることは、逆になります。上の人が、速く解く練習をしても、点は増えません。下の人が、解き方を最初から覚え直すのは、遠回りです。==2つを測って、初めて、次にやることが決まります。==

## 時間内にできて、完全クリアです

1問ずつの練習でも、同じ順番で、考えます。

```
　　×　時間をかけても、解けなかった　→　解き方から、やり直す
　　△　時間をかければ、解けた　　　　→　時間内で、もう一度
　　○　時間内に、解けた　　　　　　　→　完全クリア
```

15番の白紙再現テストも、最後は、時間内に再現できたら、完全クリアです。試しに、10秒で、「さ」で始まる食べ物を、5つ、言ってみてください。時間がいくらでもあれば、全員、言えます。それでも、10秒と言われると、止まります。==知っていることと、時間内に出せることは、別の力です。==テストで測られるのは、あとのほうです。

本番の、1問あたりの時間も、計算しておきます。試験時間を、問題の数で割るだけです。60分で大問4つなら、1問15分。この数字を知らないと、△なのか、○なのかが、決められません。

## 全部の問題で、測る必要はありません

毎回タイマーを置くのは、しんどいです。週に1回、まとめて測る日を作るだけでも、違います。

Maxで解いている時に、いくら考えても、わからない問題も、あると思います。その時、何分で答えを見るかは、20番に書きます。
