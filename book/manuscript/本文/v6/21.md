# 21
## 3秒で、答えてください

　　バットとボールは、合わせて110円。バットは、ボールより100円高い。ボールは、いくら？

……

10円、と答えた人が、多いと思います。答えは、5円です。（ボールが10円なら、バットは110円。合わせて、120円になってしまいます）

計算が、できなかったわけでは、ありません。「わかった」と思った瞬間に、確かめるのを、やめました。

テストでも、同じことが起きています。

数学のテストが、返ってきました。78点です。間違えた4問のうち、3問は、計算ミスでした。符号。写し間違い。最後の割り算。全部、わかっていた問題です。

　　「ケアレスミスだ。次は、気をつけよう」

答案をしまいます。次のテスト。また、計算ミスで、3問落とします。

## 「気をつける」は、行動ではありません

次は気をつける、と決めたとして、明日、何をしますか。

答えられないはずです。

気をつけるというのは、気持ちです。気持ちは、テスト中の40分、持ちません。特に、焦っている時には消えます。そして、計算ミスは、焦っている時に出ます。

## ケアレスミス、という名前が問題です

ケアレスミスという言葉は、便利です。それ以上、考えなくて済むからです。でも、この言葉は何も説明していません。実際には、ミスには種類があります。

符号を落とす。桁を間違える。写し間違える。単位を変え忘れる。問題文の条件を1つ見落とす。最後の1手を飛ばす。

どれも、原因が違います。対策も違います。全部を「ケアレスミス」と呼んでいるかぎり、1つも直りません。

## 名前をつけると、対策が出てきます

名前をつけた瞬間に、やることが決まります。

```
　　「符号を落とす」　　　→　負の数で割ったあと、符号だけ見る
　　「写し間違える」　　　→　問題文から式に写したら、1回だけ見比べる
　　「単位を変え忘れる」　→　答えを書く前に、単位に丸をつける
```

どれも、テスト中にできます。10秒で終わります。名前をつけると、「気をつけよう」という気持ちが、「これをやる」という手順に変わります。手順は、焦っていても実行できます。注意力が上がったわけではありません。==手順が1つ増えただけです。==

全部のミスに対策を作ると、手順が増えすぎます。同じ名前が3回出てきたものだけ、対策します。テストを3回分見れば、わかります。たいてい、2つか3つに集中しています。その2つか3つだけ、手順を足します。

## よくあるミス：「問題文を、最後まで読んでいない」

名前をつけていくと、よく出てくるものがあります。問題文の、読み落としです。

　　「兄が家を出発してから10分後に、弟が同じ道を自転車で追いかけた。兄の速さは分速80m、弟の速さは分速240mである。」

ここまで読んで、「はいはい、追いつく問題ね」と、式を立て始めます。計算して、15分。×でした。問題文の最後は、こうなっていました。

　　「弟が出発してから何分後に追いつくか。」

答えは、5分です。式も計算も、合っています。落としたのは、最後の1行を読まなかったからです。

頭は、「このパターンね」と思った瞬間、安心します。安心すると、残りの文を、丁寧に読まなくなります。よく勉強した人ほど、これが起きます。パターンを、たくさん知っているからです。

このミスの対策は、10秒でできます。==問題文の、次の3つに、線を引きます。==

```
　　1　聞かれていること（最後の1文）
　　2　単位（「何分後」「何cm」「小数第2位まで」）
　　3　条件（「ただし」「〜を除く」「整数とする」）
```

そして、答えを書く直前に、線を引いた所を、もう一度見ます。
