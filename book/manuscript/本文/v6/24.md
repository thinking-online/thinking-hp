# 24
## 今年のお正月に立てた目標を、言えますか？

……

思い出せなかった人。思い出せたけど、もうやっていない人。どちらかが、ほとんどだと思います。

では、もう1つ。昨日の夜、歯をみがきましたか。

こちらは、目標を立てていません。やる気も、要りません。それでも、毎日、続いています。

違いは、気合いでは、ありません。==「いつ、やるか」が、決まっているかどうか==です。

模試の結果が返ってきた夜。悔しくて、眠れません。動画で、逆転合格した先輩の話を見ました。やる気が、わいてきます。「よし、今日から毎日、英単語を100個やるぞ！」。ノートの表紙に、大きく書きました。3日後。ノートは、カバンの中に入ったままです。

## やる気が高い日の自分は、別人です

やる気が満タンの時、人は「できる」と思います。毎日100個。毎日3時間。朝5時起き。その目標を実行するのは、やる気が満タンの自分ではありません。==部活で疲れて帰ってきた、普通の日の自分==です。普通の日の自分には、重すぎます。だから、3日で止まります。

これは、意志が弱いからではありません。目標を立てた日の自分と、実行する日の自分が、別人のように違っていただけです。続く人ほど、自分の意志をあてにしていません。やる気があってもなくても、==勝手に始まる形==を、先に作っています。

## 「○○したら、△△する」の形にします

形は、1つだけです。

```
　　×　毎日、英単語をやる
　　○　歯をみがいたら、英単語を5個やる
```

「いつ、どこで、何をするか」まで決めておく。ニューヨーク大学の研究者たちの研究で、ここまで決めていた人たちは、決めていなかった人たちより、実際にやった割合がはっきり高くなりました。

理由は、迷う場面がなくなるからです。「毎日やる」だと、毎日「いつやろうかな」と考えることになります。考えるたびに、「あとでいいか」が入りこみます。「歯をみがいたら」と決めてあれば、考えません。歯ブラシを置いたら、始まります。

## 「前」ではなく、「後」につなげます

ここは、間違えやすいところです。

```
　　×　夕飯の前に、やる
　　○　夕飯の食器を下げたら、やる
```

「○○の前に」は、続きません。夕飯が始まるギリギリまで、いくらでも先のばしにできるからです。「○○の後に」は、ズレません。==もう毎日やっていることの、すぐ後ろ==につなげます。歯みがき、夕飯、お風呂、電車に乗る、家に着く。すでに習慣になっているものが、スイッチになります。

足すのは、1つだけにしてください。1つが、考えなくても始まるようになったら、次の1つを足します。3つ同時に足した人は、3つとも止まります。1つずつ足した人は、3ヶ月後に、3つ続いています。

## できない日のために、「最低」も決めておきます

部活の試合。文化祭の準備。風邪。いつも通りにいかない日は、必ず来ます。「毎日やる」と決めた人にとって、1日の抜けは、==計画の全部が失敗したこと==に見えます。「あーあ、途切れた。もういいや」。こうなる生徒を、何百人も見てきました。折れるのは、できなかった日ではありません。その次の日です。

だから、1つの数字ではなく、幅で決めます。

```
　　×　毎日、2時間やる
　　○　最低1分。最高2時間。ゼロの日だけ、作らない
```

調子がいい日は、2時間やります。部活で遅くなった日は、1分やります。単語を1個、声に出す。それで、その日は達成です。

1分で守っているのは、力ではありません。==「続いている」という事実==です。0の日があると、次の日は「再開」になります。再開は、重いです。1でもやってあれば、次の日は「続き」です。続きは、軽いです。

結果を出した生徒の記録を見ると、どの子も、でこぼこしています。3時間の日もあれば、10分の日もあります。共通しているのは、==0の日がほとんどない==ことだけです。

## やる気は、始めたあとに来ます

やる気が出たら始める、と考えている人が多いです。順番が逆です。==やる気は、始めたあとに出てきます。==5分やると、もう少しやろうか、という気になります。部屋の掃除を始めたら止まらなくなったこと、ありませんか。あれと同じです。

だから、最初の1つは、小さくていいんです。単語5個。1分で終わります。始まってしまえば、あとは続きます。
