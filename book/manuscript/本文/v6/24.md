# 24
## 今年のお正月に立てた目標を、言えますか？

……

思い出せなかった人。思い出せたけど、もうやっていない人。どちらかが、ほとんどだと思います。

では、もう1つ。昨日の夜、歯をみがきましたか。

こちらは、目標を立てていません。やる気も、要りません。それでも、毎日、続いています。違いは、気合いでは、ありません。==「いつ、やるか」が、決まっているかどうか==です。

こんな経験は、ありませんか。模試の結果が返ってきた夜。悔しくて、逆転合格した先輩の動画を見ました。やる気が、わいてきます。「よし、今日から毎日、英単語を100個やるぞ！」。ノートの表紙に、大きく書きました。3日後。ノートは、カバンの中に入ったままです。

## やる気が高い日の自分は、別人です

その目標を実行するのは、やる気が満タンの自分では、ありません。==部活で疲れて帰ってきた、普通の日の自分==です。やる気が高い時に立てた目標は、普通の日の自分には、重すぎます。だから、3日で止まります。意志が弱いからでは、ありません。

続いている人を見ると、「意志が強いんだな」と思いますよね。逆です。続く人ほど、自分の意志を、あてにしていません。やる気があってもなくても、==勝手に始まる形==を、先に作っています。

## 計画は、「if-thenプラン」で決めます

その形が、「if-thenプラン」です。英語の if は「もし」、then は「その時」。「もし○○したら、その時、△△する」。この形で、決めます。

```
　　×　毎日、英単語をやる
　　○　歯をみがいたら、英単語を5個やる
```

「○○」に入れるのは、もう毎日やっていることです。歯みがき、夕飯、お風呂。その中の1つに、つなげます。決めた1行は、紙に書いて、目に入る所に貼ります。

「いつ、どこで、何をするか」まで決めておく。ニューヨーク大学の研究者たちの研究で、ここまで決めていた人たちは、決めていなかった人たちより、実際にやった割合が、はっきり高くなりました。

理由は、迷う場面がなくなるからです。「毎日やる」だと、毎日、「いつやろうかな」と考えることになります。考えるたびに、「あとでいいか」が入りこみます。「歯をみがいたら」と決めてあれば、考えません。歯ブラシを置いたら、始まります。

## 「前」ではなく、「後」につなげます

```
　　×　夕飯の前に、やる
　　○　夕飯の食器を下げたら、やる
　　×　お風呂に入る前に、やる
　　○　お風呂から出て、髪をかわかしたら、やる
```

「○○の前に」は、続きません。夕飯が始まるギリギリまで、いくらでも、先のばしにできるからです。「○○の後に」は、ズレません。==もう毎日やっていることの、すぐ後ろ==に、つなげます。

## じゃまが入った時の分も、先に決めておきます

if-thenプランは、うまくいかない場面にも、使えます。じゃまが入りそうな場面を、先に思い浮かべて、その時にやることを、決めておきます。

```
　　眠くなったら　　　　　　　→　立って、単語を声に出す
　　部活で、帰りが遅くなったら　→　単語を1個だけ見て、寝る
```

決めていないと、その場で、「今日は、もういいか」になります。先に決めてあれば、迷いません。

## 足すのは、1つだけです

やる気が高い時は、3つも4つも、足したくなります。1つにしてください。最初の1つは、小さくていいんです。単語5個。1分で終わります。「やる気が出たら、始める」は、順番が逆です。==やる気は、始めたあとに、出てきます。==2週間続いたら、5個を10個に。考えなくても始まるようになったら、次の1つを、足します。

## できない日のために、「最低」も決めておきます

決めた通りにいかない日は、来ます。部活の試合。文化祭の準備。風邪。「毎日やる」と決めた人にとって、1日の抜けは、==計画の全部が失敗したこと==に見えます。折れるのは、できなかった日ではありません。その次の日です。だから、目標を、1つの数字ではなく、幅で書きます。

```
　　×　毎日、2時間やる
　　○　最低1分。最高2時間。ゼロの日だけ、作らない
```

調子がいい日は、2時間やります。部活で遅くなった日は、単語を1個、声に出す。それで、その日は達成です。最低は、熱があってもできる量にします。寝る前に、1問だけ解いて、○をつけて寝る。それでいいんです。1分で守っているのは、力ではありません。==「続いている」という事実==です。0の日があると、次の日は「再開」になります。再開は、重いです。1でもやってあれば、次の日は「続き」です。0の日が出たら、取り返そうとは、しません。次の日は、最低だけやります。
