# 25
## 昨日、スマホを見ていた時間は、何時間でしたか？

先に、予想を決めてください。決めたら、スマホの、使った時間の記録（スクリーンタイムなど）を、開いてみてください。

……

予想より、長かった人が、多いと思います。

「時間が足りない」と思った時、多くの人が最初に削るのは、寝る時間です。でも、削れる時間は、たいてい、別の所にあります。

テストの3日前。範囲が、まだ終わっていません。「寝る時間を削ろう。終わるまで、寝られない」。いつもは12時に寝ますが、2時まで起きます。3日続けて、6時間増えました。テストの日。問題を読んでも、頭に入ってきません。計算を、2回間違えました。覚えたはずのことが、出てきません。

## 覚えたものは、寝ている間に固まります

ここは、知っておいてください。昼に覚えたことは、その時点では、まだ消えやすい状態です。寝ている間に、頭の中で整理されて、固まります。寝ないと、この作業が起きません。つまり、夜中の2時間で覚えたことは、寝ていないので、固まらないまま朝を迎えます。2時間ぶん覚えたつもりで、ほとんど残っていません。単語を覚えたあと、そのまま寝たグループと、同じ時間ずっと起きていたグループを比べた実験があります。あとで思い出せた量は、==寝たグループのほうが多くなりました。==覚えてから寝るまでの時間が短いほど、残る量が多いこともわかっています。寝る直前にやった暗記が残りやすいのは、このためです。

## 寝不足は、思い出す力も下げます

もう1つあります。寝不足の時、頭の働きが落ちます。特に落ちるのが、思い出す力です。覚えているはずのことが、出てこなくなります。テストでやるのは、思い出すことです。一番落ちている力を、本番で使うことになります。

計算してみます。3日間で、6時間増やしました。仮に、6時間で30個覚えたとします。寝ていないので、そのうち残るのは、半分以下かもしれません。15個です。一方、寝不足で、思い出す力が1割落ちたとします。1年かけて覚えた1000個のうち、100個が出にくくなります。15個取って、100個を落としています。

## どうしても時間が足りない時

足りないことは、あります。その時は、削る順番があります。

```
1　まず、やることを減らす（捨てる）
2　次に、スマホの時間を削る
3　最後に、どうしてもなら、睡眠
```

睡眠は、一番最後です。そして、削るとしても、1時間までにしてください。2時間を超えると、頭の働きが、はっきり落ちます。

## 何もしていない時間は、思っているより、あります

睡眠を削る前に、見つけておくものがあります。==何もしていない時間==です。1日だけ、記録してみてください。スマホをなんとなく見ていた時間。電車でぼーっとしていた時間。合計すると、たいてい1時間を超えます。削るなら、睡眠より先に、こちらです。

## 3分あれば、1個出せます

勉強というと、机に向かって、1時間は座るもの。そう思っている人が多いです。だから、短い時間は、「何もできない時間」になります。

でも、絶対法則02を思い出してください。点になるのは、思い出した回数でした。==思い出すのに、机はいりません。==

```
　　電車を待つ3分　　　　　　単語を5個、目を閉じて言う
　　休み時間の2分　　　　　　さっきの授業を、「結局、何の話？」で言う
　　お風呂の5分　　　　　　　今日やった解き方を、頭から言ってみる
```

1回は短くても、1日に5回あれば、5回思い出しています。短い時間は、使えない時間ではありません。

## 前日だけは、絶対に削らない

テストの前日だけは、どんな状況でも削らないでください。前日の夜に覚えたことは、たいした量ではありません。前日の寝不足で落ちる分のほうが、はるかに大きいです。前日は、いつもより30分早く寝るくらいでちょうどいいです。

## 「受験生なら、1日○時間」は、気にしなくていいです

「受験生なら10時間はやらないと」という声も、聞こえてきます。数え方を、変えてください。24時間から、先に引くものがあります。睡眠の7時間。食事。お風呂と身じたく。学校。これは、動かせない時間です。==引いたあとに残ったものが、あなたの「使える時間」==です。

```
　　×　今日、何時間やったか
　　○　使える時間のうち、どれだけを勉強に使えたか
```

部活がある人と、ない人では、使える時間が違います。だから、「1日○時間」を人と比べても、意味がありません。削るのは、睡眠ではなく、使える時間の中の、何もしていない時間です。

## 昼に眠くなったら、15分だけ寝ます

夜はしっかり寝る。そのうえで、昼に眠くなった時は、がまんしないでください。眠いまま1時間座っているより、15分寝て、45分やるほうが進みます。長さは、15分から20分まで。30分をこえると、深く眠ってしまって、起きたあとに頭がぼんやりします。布団には入らず、机に伏せるか、いすに座ったまま寝ます。夕方に寝ると、夜に眠れなくなるので、午後3時までにします。眠れなくても、目を閉じているだけでいいです。

## 早起きも、無理にしなくていいです

「できる人は、朝5時に起きている」と聞くと、全員が、朝5時に起きようとします。僕も、やりました。浪人していた頃、「朝活だ」と言い出して、朝5時に起きるようにしたことがあります。朝一番にファストフードの店に入って、勉強を始める。朝マックです。3日は、続きました。でも、午前の授業の間、ずっと眠い。昼を過ぎると、何を読んでも頭に入らない。1週間で、やめました。あの時の僕は、勉強するために早く起きたはずなのに、いつのまにか、==早く起きることが目的==になっていました。

ドイツのミュンヘンの大学の研究者たちが、とても沢山の人の、寝る時間と起きる時間を調べた研究があります。結果は、朝型と夜型の2つには、分かれませんでした。==真ん中が一番多くて、極端な朝型も、極端な夜型も、少しずついる。==頭がよく回る時間帯は、人によって、少しずつ違います。

大事なのは、何時に起きたかではありません。==1日全部で、どれだけ進んだか==です。1週間、その日一番集中できた時間帯に、丸をつけてみてください。丸が多い時間帯に、数学の応用や英語の長文のような、一番頭を使うものを置きます。丸が少ない時間帯には、単語や漢字のような、繰り返すだけでいいものを置きます。

学校の日は、起きる時間を選べません。起きられない時、動かすのは、寝る時刻のほうです。==15分ずつ、早くします。==1週間かけて、15分。次の週に、もう15分。入試も、模試も、朝に始まります。夜に頭が回る人も、本番の2週間前からは、朝に1問だけ解く練習を入れてください。
