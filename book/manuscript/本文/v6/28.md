# 28
## 今、学校から出ている宿題と提出物を、全部、言えますか？

数えてみてください。

……

では、その中で、次のテストの点に、一番つながるものは、どれですか。3秒で、答えてください。

……

すぐに答えられなかった人が、多いと思います。全部を、同じ「やらなきゃいけないもの」として、並べているからです。

高校2年生の、火曜日。その日、学校から出たものを、並べてみます。

```
　　数学の課題プリント　2枚
　　英語の小テスト　　　明日
　　理科のレポート　　　金曜に提出
　　古典の予習　　　　　明日の授業で当たる
　　受験補習の案内　　　希望制
```

全部やると、夜の11時までかかります。「出された以上、全部ちゃんとやらないと」。全部、やりました。自分でやろうと決めていた英語の長文は、1問も開けませんでした。次の日も、同じです。

## 量を足し算した人が、いません

数学の先生は、数学のことだけを考えて課題を出します。英語の先生も、理科の先生も同じです。それぞれが「これくらいなら妥当だ」と思う量を出しています。その5つを足した人は、==どこにもいません。==最初から、1日に入りきらない量なのです。誰も悪くありません。足し算する人がいないだけです。足し算するのは、あなたです。

## 書き出して、3つに分けます

学校から出たものを、1週間ぶん、書き出します。1つ1分で、番号をつけます。

```
　1　出さないと困るもの　　提出物、赤点を避けるための最低限
　　　　　→　時間を決めて、一番短い方法で終わらせる
　2　点につながるもの　　　受験や、自分が伸ばすと決めた教科のもの
　　　　　→　自分の勉強として扱う。閉じて出すところまでやる
　3　どちらでもないもの
　　　　　→　受けない
```

さっきの火曜日なら、こうなります。英語と数学で受験する人の場合です。

```
　　数学の課題プリント　→　2　閉じて、もう一度解くところまで
　　英語の小テスト　　　→　2　間違えたものを、ノートに写す
　　理科のレポート　　　→　1　木曜に、40分と決めて書く
　　古典の予習　　　　　→　1　当たる所だけ、15分
　　受験補習の案内　　　→　3かどうかを、次の質問で確かめる
```

大事なのは、1と2を混ぜないことです。1は「終わらせる作業」です。きれいにやる必要がありません。先に「30分」と時間を決めて、その中で終わらせます。2は「できるようになる作業」です。終わらせても、できていなければ意味がありません。

番号をつけたら、2に、一番頭が回る時間を、先に取ります。帰ってすぐの1時間が一番頭が回るなら、そこに数学と英語を入れます。1は、そのあとです。

1を短く終わらせるのは、「手を抜く」のとは違います。手を抜くとは、時間をかけたまま、中身だけ薄くすることです。例えば、答えを写して出す課題です。写すのに1時間かかります。その間、頭は使っていません。==1時間使って、何も残っていません。==

## 受ける前に、1つだけ聞きます

3かどうかを見分ける質問が、1つあります。

　　これが終わった時、何ができるようになっていますか。

補習でも、講習でも、追加の問題集でも同じです。答えが返ってこない、または返ってきた答えが自分に要らないものなら、3です。

```
　　「共通テストの形式に慣れる」　　　→　共テを使うなら2。使わないなら3
　　「苦手な人向けに基礎を復習する」　→　その単元が苦手なら2。違うなら3
　　「とりあえず受けておいたほうが」　→　3
```

聞きにくければ、配られた案内の紙を見てください。たいてい書いてあります。

## 中学生は、内申に入るものを、2に入れます

高校受験で内申が使われるなら、分け方が少し変わります。提出物、小テスト、授業中の発言、実技の教科。これが内申に入る学校では、それは「出さないと困るもの」ではありません。==入試の点、そのものです。==2に入れてください。

内申のつき方は、都道府県と学校で違います。だから、最初に、先生に確かめます。「これは、内申に入りますか？」。そう聞いた人は、やる気がない人ではありません。どこに力を入れるかを、決めようとしている人です。全部を同じ本気でやって、全部が中くらいになるのが、一番損です。

## 小テストは、「点につながるもの」に入れます

点だけ見て、小テストを捨てる人が多いです。でも、小テストの範囲は、定期テストの範囲と、同じ所です。==小テストは、「ここが出ます」という予告です。==2に入れます。

返ってきたら、間違えたものだけを、1冊のノートに書き写します。1分で終わります。1回の小テストで3問なら、1学期で12回、36問です。それが、自分だけの問題集になります。次の小テストの前の日に、そのノートを閉じて、言えるかを確かめます。

## 「それは逃げになりませんか」

逃げかどうかは、受けなかったかどうかでは決まりません。==空いた時間を何に使ったかで決まります。==

```
　　補習を断って、その12時間で寝た　　　　　　→　逃げ
　　補習を断って、その12時間で長文を24本　　　→　選択
```

だから、3に番号をつけた時は、その時間に何を入れるかを同時に決めてください。決めないまま空けると、本当に逃げになります。
