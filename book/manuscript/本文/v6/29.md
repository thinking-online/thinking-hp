# 29
## 目を閉じて、10秒。合格発表で、自分の番号を見つけた瞬間を、思い浮かべてください

……

いい気分に、なりましたか。

では、聞きます。今、「よし、勉強しよう」と、体が動きましたか。それとも、少し、ほっとしましたか。

やる気が出ない日。「合格体験記を読んで、やる気を出そう」。E判定から逆転した先輩の話。読んでいると、胸が熱くなります。目を閉じて、想像します。自分の番号がある。家族が、よろこんでいる。いい気分で、その日は寝ました。次の日、机には向かいませんでした。

## 想像すると、少し、満足してしまいます

「成功した自分をイメージすれば、夢はかなう」。よく聞く話です。これを確かめた、カリフォルニア大学の研究者たちの実験があります。試験をひかえた学生を、3つに分けました。いい点を取った場面を、毎日イメージする人。勉強している場面を、毎日イメージする人。何もイメージしない人。

一番勉強時間がのびて、点も上がったのは、勉強している場面をイメージした人でした。いい点を取った場面をイメージした人は、==何もしなかった人より、勉強時間が短くなり、点も伸びませんでした。==

うまくいった場面を想像すると、気持ちがよくなります。その気持ちよさで、少し満足してしまうんです。まだ何もしていないのに、もう手に入れたような気分になる。だから、動かなくなります。

「大丈夫。自分はできる」と言い聞かせるのも、同じです。気持ちは、少し楽になります。その楽さで、少し満足します。何も変えていないのに、もう大丈夫な気がしてしまう。だから、次の模試までに、やることが変わりません。

## 読むのではなく、先に書きます

やることは、1つです。

　　==合格体験記を、先に、自分で書く。==

受かったあとの自分になったつもりで、書きます。ただし、書くのは「受かりました、うれしいです」ではありません。==何をやったか==です。

```
　　4月　　歯みがきのあとに単語を5個。これだけは毎日やった
　　6月　　模試でE判定。大問3が全滅だった。次の日から、長文を1日1題にした
　　夏休み　計画が3回崩れた。そのたびに、最低1分に戻した
　　11月　　過去問を開いた。時間が足りなかった。解く順番を変えた
```

結果ではなく、途中を書く。さっきの実験の、勉強している場面をイメージした人と、同じことをしています。書いてみると、わかることがあります。==書けないところが、まだ決まっていないところ==です。「夏休みに何をやったか」が書けないなら、夏休みの計画がないということです。

## 邪魔になるものを、先に書いておきます

もう1つ、書いてほしいものがあります。うまくいかなかった場面です。ニューヨーク大学の研究者たちの研究で、目標を思い描いたあとに、==「邪魔になりそうなもの」と「その時、どうするか」==まで考えた人のほうが、実際に動いたことがわかっています。

```
　　かなえたいこと　　　第一志望に受かる
　　邪魔になるもの　　　部活のあと、眠くてスマホを見てしまう
　　その時、どうする　家に着いたら、スマホを玄関に置く
```

## 「できない」と言いそうになったら、「まだ」を足します

書いている途中で、「自分、数学できないんで」と言いたくなる時があります。この言葉は、言い切って、終わっている文です。続きがないので、次にやることも出てきません。だから、1語だけ、足します。

　　自分は、数学が、==まだ==できない。

「まだ」と言った瞬間に、じゃあ、いつできるのか、という続きが必要になります。そして、言い直したくなります。全部ができないわけではないからです。「二次関数の最大値が、まだ出せない」。ここまで小さくなれば、教科書のそのページを開けばいい。前向きになるからではなく、==正確になるから==です。

スタンフォード大学の研究者たちの研究では、力は伸ばせるものだと考えている生徒のほうが、難しい問題にぶつかった時に、やめずに続ける傾向がありました。力そのものが違ったのではありません。==つまずきの呼び方==が、違っただけです。

## 迷ったら、受かった自分に聞きます

人は、未来の自分のことを、==他人のように感じる==ところがあります。「部活を引退したら、本気を出す」。たいへんなことを、未来の自分に、気楽に任せてしまえます。だから、さぼりそうになった時、こう聞きます。

　　受かったあとの自分なら、今の自分に、何と言うか。

未来の自分を、他人のままにしておかない。==こっちから、呼んでくる==んです。

先輩の体験記を、読むな、という話ではありません。読むなら、気持ちではなく、やったことを抜き出してください。「毎朝、前日の間違いを3問だけ解き直した」。こういう1行は、そのまま使えます。ただ、絶対法則01で書いた通り、先輩が受かった理由が、本当にそのやり方だったのかは、本人にもわかりません。抜き出したら、自分で試して、比べてください。
