# 29
## 目を閉じて、10秒。合格発表で、自分の番号を見つけた瞬間を、思い浮かべてください

……

いい気分に、なりましたか。

では、聞きます。今、「よし、勉強しよう」と、体が動きましたか。それとも、少し、ほっとしましたか。

こんな経験は、ありませんか。やる気が出ない日。「合格体験記を読んで、やる気を出そう」。E判定から逆転した先輩の話。読んでいると、胸が熱くなります。目を閉じて、想像します。自分の番号がある。家族が、よろこんでいる。

　　「よし、自分も頑張ろう」

いい気分で、その日は寝ました。次の日、机には向かいませんでした。

## 想像すると、少し、満足してしまいます

「成功した自分をイメージすれば、夢はかなう」。よく聞く話です。

これを確かめた、カリフォルニア大学の研究者たちの実験があります。試験をひかえた学生のうち、いい点を取った場面を毎日イメージしたグループは、==何もイメージしなかったグループより、勉強時間が短くなり、点も伸びませんでした。==勉強時間がのびて、点も上がったのは、勉強している場面を毎日イメージしたグループでした。

うまくいった場面を想像すると、気持ちがよくなります。その気持ちよさで、少し満足してしまうんです。まだ何もしていないのに、もう手に入れたような気分になる。だから、動かなくなります。

## 読むのではなく、先に書きます

やることは、1つです。

　　==合格体験記を、先に、自分で書く。==

受かったあとの自分になったつもりで、書きます。紙の一番上に、合格した日の日付を書きます。その下に書くのは、「受かりました、うれしいです」ではありません。==何をやったか==です。月ごとに、過去形で書きます。

```
　　3月10日　第一志望に、合格した
　　4月　　歯みがきのあとに単語を5個。これだけは毎日やった
　　6月　　模試でE判定。大問3が全滅だった。次の日から、長文を1日1題にした
　　夏休み　計画が3回崩れた。そのたびに、Minの1分に戻した
　　11月　　過去問を開いた。時間が足りなかった。解く順番を変えた
```

結果ではなく、途中を書く。さっきの実験の、勉強している場面をイメージしたグループと、同じことをしています。

書いてみると、わかることがあります。==書けないところが、まだ決まっていないところ==です。「夏休みに何をやったか」が書けないなら、夏休みの計画がないということです。書けなかった月には、やることを、1行だけ決めて、書きこみます。「夏休みは、毎朝、長文を1題」。

## 邪魔になるものを、先に書いておきます

もう1つ、書いてほしいものがあります。うまくいかなかった場面です。ニューヨーク大学の研究者たちの研究で、目標を思い描いたあとに、==「邪魔になりそうなもの」と「その時、どうするか」==まで考えた人のほうが、実際に動いたことがわかっています。

```
　　かなえたいこと　　　第一志望に受かる
　　邪魔になるもの　　　部活のあと、眠くてスマホを見てしまう
　　その時、どうする　家に着いたら、スマホを玄関に置く
```

## 迷ったら、受かった自分に聞きます

さぼりそうになった時。今日はもういいか、と思った時。自分に、こう聞きます。

　　受かったあとの自分なら、今の自分に、何と言うか。

人は、未来の自分のことを、==他人のように感じる==ところがあります。だから、「部活を引退したら、本気を出す」と、たいへんなことを、未来の自分に、気楽に任せてしまえます。未来の自分を、他人のままにしておかない。==こっちから、呼んでくる==んです。

## 先輩の体験記を読むなら

読むな、という話ではありません。読むなら、気持ちではなく、やったことを抜き出してください。「毎朝、前日の間違いを3問だけ解き直した」。こういう1行は、そのまま使えます。

ただ、絶対法則01で書いた通り、先輩が受かった理由が、本当にそのやり方だったのかは、本人にもわかりません。抜き出したら、自分で試して、比べてください。

## 「できない」には、「まだ」を足します

書いた通りに、いかない日もあります。数学の模試が、また40点でした。「大丈夫。自分はできる」と言い聞かせても、「自分、数学できないんで」と決めても、どちらも、そこで話が終わります。足すのは、1語です。

　　自分は、数学が、==まだ==できない。

「まだ」と言った瞬間に、じゃあ、いつできるのか、という続きが必要になります。「何が」まだなのかを、小さく言います。

```
　　自分は、数学ができない
　　→　自分は、数学が、まだできない
　　→　二次関数の最大値が、まだ出せない
　　→　今日、教科書の、最大値のページを開く
```

「まだ」を足すと、できないところが、小さくしぼられます。前向きになるからではなく、==正確になるから==です。落ちこんで、いいです。やるのは、気持ちを変えることではなく、事実を、そのまま、正確に言うことです。
