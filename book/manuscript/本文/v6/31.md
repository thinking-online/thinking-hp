# 31
## クラスで、自分より成績がいい人を、1人、思い浮かべてください

すぐに、顔が浮かんだと思います。その人の、前のテストの点も、だいたい言えるはずです。

では、半年前の、自分のテストの点を、1つ、言ってください。

……

出てこなかった人が、多いと思います。

人の点は、覚えています。自分の半年前の点は、覚えていません。

休み時間。前の席で、友達が話しています。

　　「模試どうだった？」「んー、まあまあ。8割くらい」

自分の結果は、カバンの中にあります。5割でした。判定は、Eでした。自分は、毎日やっています。あの子が遊んでいる時も、やっていました。それでも、3割違います。

　　「やっぱり、自分は向いてないのかもしれない」

その日は、家に帰ってから、何もできませんでした。

---

これを書いているのは、同じことを経験した人からの手紙を、何百通も読んできたからです。その中の1通に、こうありました。「自分は努力してるのになんでこんなに低いんだろうと悩んで、泣いたりしていました」まず言いたいのは、これです。

その感覚は、正しいです。

実際に差があるし、実際に悔しい。気にするな、というのは無理です。無理なことを言っても、意味がありません。

だから、別の話をします。

## 見えないものと、比べています

あの子の8割は、いつから積み上げた結果でしょうか。

今日できたことではありません。小学校から今日までの、積み上げの結果です。自分の5割も、同じです。今日までの積み上げです。つまり、比べているのは、お互いの「これまで全部」です。これまで全部は、今日どうにもなりません。どうにもならないものを比べているので、何回比べても同じ結論になります。そして、もっと大事なことがあります。あの子が、先月から何点上がったのかは、見えません。下がっているかもしれません。見えているのは、あの子の今の点だけ。どれだけ伸びたかは、見えません。見えないものと比べているから、何回比べても、答えが出ないのです。

## 比べること自体は、悪くありません

よく「人と比べるな」と言われます。無理です。教室に人がいるかぎり、比べます。比べないようにしよう、というのは、やり方ではありません。やるのは、比べる相手を変えることです。

　　先週の自分。

これなら、変化が見えます。しかも、自分で動かせます。

```
先週　52点
今週　58点
　　　6点、上がっている
```

あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきりわかります。

## 「でも、追いつかない」

ここで、こう思うはずです。

　　先週より6点上がっても、あの子には追いつかない。

その通りです。1週間では、追いつきません。ただ、計算してみてください。受験まで、あと何週間ありますか。仮に30週あるとします。

```
1週間に2点ずつ上げる
　30週で　60点
```

今3割の差があっても、届く可能性が出てきます。これは、気休めで言っているのではありません。見るものを変えると、計算できるようになる、という話です。「あの子との差」は、計算できません。「1週間に何点上げるか」は、計算できます。計算できるものだけが、今日やることに変わります。

## 落ち込んだ1時間は、0問です

ここは、少し冷たいことを言います。比べて落ち込んだ1時間に、1問も解いていません。これは、責めているのではありません。落ち込むな、とも言いません。落ち込みます。言いたいのは、落ち込む時間を短くしたほうが得だ、ということです。そして、短くする方法が1つあります。落ち込んだ時に、やることを決めておきます。

　　先週の自分の点を、見る。

これだけです。紙でも、スマホのメモでもいい。先週の自分が、どこにいたかを見ます。1分で終わります。そして、落ち込んでいる状態から、計算できる状態に戻ります。

## 物差しを、2本持ちます

結果を出す人は、自分を測る物差しを、2本持っています。そして、その2本を混ぜません。

```
　　1本目　ゴールまでの距離　　あと何点、足りないか
　　2本目　昨日からの伸び　　　前より、何ができるようになったか
```

1本目だけの人は、いつ測っても「足りない」になります。ゴールに着くまで、ずっと足りない。それが何ヶ月も続くと、折れます。

2本目だけの人は、「伸びてるから大丈夫」で止まります。伸びていても、間に合わなければ、届きません。

だから、2本とも使います。1本目で、まだ足りないことを冷静に見る。2本目で、1ミリでも進んだことを、ちゃんと見る。

結果が出るまでは、よろこばない。そういう人もいます。その厳しさは、強さです。でも、==進んだことに気づける==のも、同じくらい大事な力です。手ごたえがない日も、少しずつ、積み上がっています。それが見えている人が、最後まで続きます。

## 下がったのは、やり方です。人ではありません

比べる相手を変えても、先週の自分に負ける日があります。

模試が返ってきて、前回より20点下がっていました。この2ヶ月、前よりやったのに下がりました。やっぱり自分には向いてないのかもしれない。その日は、勉強できませんでした。

点が下がった時、考えられることは2つです。やり方が合っていなかったか、その回がたまたま難しかったか。==どちらも、やり方か、テストの問題の話です。あなたという人の話ではありません。== でも下がった瞬間に出てくる言葉は、たいてい、自分という人の話です。向いてない、頭が悪い、才能がない。これを言っても、次にやることが1つも決まりません。

一番の問題は、責めると成績表を見なくなることです。見るとつらいので、ファイルにしまって開かなくなる。どこで落としたかがわからないまま、次も同じところで落とします。==責めることが、直すのを止めています。==

だから、質問の形に変えます。「自分がダメだ」を「どこが下がった?」に。質問にすると、見るものが、「自分という人」から「点を落とした場所」に移ります。見るのは総合点ではなく大問ごとです。英語マイナス12、数学マイナス15、国語プラス7。言葉が「向いてない」から「長文が落ちた」に変わります。長文が落ちたなら、長文を見ればいい。「向いていない」には、やることがありません。

そして、国語は上がっています。20点下がったという見方をすると、この7点は見えません。上がったところには理由があって、その理由は他の科目にも使えます。

やり方が悪かったこともあります。その場合も、責める必要はありません。この本にある35のうち、1つを変えてみてください。==やり方は変えられます。人は、変えなくていいです。==
