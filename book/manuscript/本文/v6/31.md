# 31
## クラスで、自分より成績がいい人を、1人、思い浮かべてください

すぐに、顔が浮かんだと思います。その人の、前のテストの点も、だいたい言えるはずです。

では、半年前の、自分のテストの点を、1つ、言ってください。

……

出てこなかった人が、多いと思います。人の点は、覚えています。自分の半年前の点は、覚えていません。

こんな経験は、ありませんか。休み時間。前の席で、友達が話しています。

　　「模試どうだった？」「んー、まあまあ。8割くらい」

自分の結果は、カバンの中にあります。5割でした。判定は、Eでした。自分は、毎日やっています。あの子が遊んでいる時も、やっていました。それでも、3割違います。「やっぱり、自分は向いてないのかもしれない」。その日は、家に帰ってから、何もできませんでした。

---

これを書いているのは、同じことを経験した人からの手紙を、何百通も読んできたからです。その中の1通に、こうありました。「自分は努力してるのになんでこんなに低いんだろうと悩んで、泣いたりしていました」まず言いたいのは、これです。

その感覚は、正しいです。

実際に差があるし、実際に悔しい。気にするな、というのは無理です。だから、別の話をします。

## 見えないものと、比べています

あの子の8割は、今日できたことではありません。小学校から今日までの、積み上げの結果です。自分の5割も、同じです。つまり、比べているのは、お互いの「これまで全部」です。これまで全部は、今日どうにもなりません。

```
　　変えられないもの　他人と、これまで
　　変えられるもの　　自分と、これから
```

考えていいのは、下だけです。上は、何時間考えても、変わりません。

そして、あの子が、先月から何点上がったのかは、見えません。下がっているかもしれません。見えているのは、あの子の今の点だけです。見えないものと比べているから、何回比べても、答えが出ないのです。

## 比べる相手を、昨日までの自分に変えます

よく「人と比べるな」と言われます。無理です。教室に人がいるかぎり、比べます。やるのは、比べる相手を変えることです。

　　昨日までの自分。

これまでの自分の点を、3つ、見える所に書いておきます。

```
　　先月　47点
　　先週　52点
　　今週　58点　　先週から、6点、上がっている
```

これなら、変化が見えます。しかも、自分で動かせます。あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきりわかります。

## 落ち込んだら、その点を見て、上がった理由を書きます

比べて落ち込んだ1時間に、1問も解いていません。責めているのではありません。落ち込むな、とも言いません。落ち込みます。言いたいのは、落ち込む時間を短くしたほうが得だ、ということです。だから、落ち込んだ時に、やることを決めておきます。

　　書いておいた自分の点を、見る。上がった理由を、1行、書く。

「長文を、毎日1題やった」。1分で終わります。そして、落ち込んでいる状態から、計算できる状態に戻ります。

## 目標までの差を、残りの週の数で割ります

先週より6点上がっても、あの子には追いつかない。そう思うはずです。1週間では、追いつきません。でも、受験まで、30週あるとします。1週間に2点ずつ上げれば、30週で、60点です。逆に、目標までの差を、残りの週の数で割ると、1週間に上げる点が出ます。「あの子との差」は、計算できません。「1週間に何点上げるか」は、計算できます。==計算できるものだけが、今日やることに変わります。==

## 物差しを、2本持ちます

結果を出す人は、自分を測る物差しを、2本持っています。

```
　　1本目　ゴールまでの距離　　あと何点、足りないか
　　2本目　昨日からの伸び　　　前より、何ができるようになったか
```

1本目だけの人は、いつ測っても「足りない」になります。それが何ヶ月も続くと、折れます。2本目だけの人は、「伸びてるから大丈夫」で止まります。だから、2本とも使います。結果が出るまでは、よろこばない。その厳しさは、強さです。でも、==進んだことに気づける==のも、同じくらい大事な力です。

## 下がったのは、やり方です。人ではありません

比べる相手を変えても、昨日までの自分に負ける日があります。模試が返ってきて、前回より20点下がっていました。この2ヶ月、前よりやったのに下がりました。やっぱり自分には向いてないのかもしれない。

点が下がった時、考えられることは2つです。やり方が合っていなかったか、その回がたまたま難しかったか。==どちらも、やり方か、テストの問題の話です。あなたという人の話ではありません。==向いてない、頭が悪い、才能がない。これを言っても、次にやることが1つも決まりません。

だから、質問の形に変えます。「自分がダメだ」を「どこが下がった？」に。見るのは総合点ではなく、教科ごと、大問ごとです。英語マイナス12、数学マイナス15、国語プラス7。言葉が「向いてない」から「長文が落ちた」に変わります。長文が落ちたなら、長文を見ればいい。そして、国語は上がっています。上がったところには理由があって、その理由は他の科目にも使えます。

やり方が悪かったこともあります。その時は、この本にあるやり方のうち、1つを変えてみてください。==やり方は変えられます。人は、変えなくていいです。==
