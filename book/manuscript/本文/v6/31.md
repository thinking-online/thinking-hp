# 31
## クラスで、自分より成績がいい人を、1人、思い浮かべてください

すぐに、顔が浮かんだと思います。その人の、この前のテストの点も、だいたい言えるはずです。

では、もう1つ。半年前の、自分のテストの点を、1つ、言ってください。

……

出てこなかった人が、多いと思います。人の点は、覚えています。自分の半年前の点は、覚えていません。==いつも見ているのは、自分ではなく、人のほうです。==

## その悔しさは、まちがっていません

こんな経験は、ありませんか。休み時間。前の席で、友達が話しています。「模試、どうだった？」「んー、まあまあ。8割くらい」。自分の結果は、カバンの中です。5割でした。自分は、毎日やっています。あの子が遊んでいる時も、やっていました。「やっぱり、自分は、向いてないのかもしれない」。

僕の所に届いた感想に、こう書いた生徒がいました。「自分は努力してるのになんでこんなに低いんだろうと悩んで泣いたりしていました」。

悔しいのは、本気でやっているからです。「人と比べるな」と言われても、無理です。教室に人がいるかぎり、比べます。だから、比べるのをやめる話は、しません。==比べる相手を、変える話をします。==

## 友達と比べても、今日やることは、決まりません

友達と比べるのが、うまくいかない理由は、2つあります。

1つ目。変えられないものと、比べています。あの子の8割は、今日できたものでは、ありません。小学校から今日までの、積み上げの結果です。

```
　　変えられないもの　他人と、これまで
　　変えられるもの　　自分と、これから
```

考えていいのは、下だけです。上は、何時間考えても、変わりません。

2つ目。比べて出てきた「自分は、できない」が、当てになりません。41の国の、15歳の生徒を調べた研究があります。同じ学力でも、まわりにできる人が多い学校にいる生徒ほど、「自分は、勉強ができない」と感じていました。どの国でも、同じ向きでした。「できない」という感じは、自分の力ではなく、たまたま隣にいる人で、決まってしまうのです。

## 比べる相手を、2つに変えます

結果を出す人が見ているのは、友達の点では、ありません。次の2つです。

```
　　①昨日までの自分　　前より、何点、上がったか
　　②ゴールまでの距離　あと、何点、足りないか
```

①のために、これまでの自分の点を、3つ、見える所に書いておきます。

```
　　先月　47点
　　先週　52点
　　今週　58点　　先週から、6点、上がっている
```

あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきり、わかります。しかも、自分で動かせます。

②は、計算します。目標までの差を、残りの週の数で、割ります。あと60点で、残りが30週なら、1週間に2点です。「あの子との差」は、今日やることに、なりません。==「1週間に2点」は、今日やることに、なります。==

2つとも、使います。②だけだと、いつ測っても「足りない」になって、何か月かで、折れます。①だけだと、「伸びているから、大丈夫」で、止まります。

## 落ち込んだ時にやることを、先に決めておきます

それでも、比べて落ち込む日は、あります。落ち込むな、とは言いません。落ち込む時間を、短くします。書いておいた自分の点を見て、上がった理由を、1行、書きます。「長文を、毎日1題やった」。1分で、終わります。

前より下がった時は、「自分は、向いてない」ではなく、「どこが、下がった？」と聞きます。総合点ではなく、教科ごとに見ます。英語が、マイナス12点。国語は、プラス7点。「向いてない」が、「長文が落ちた」に変わります。==下がったのは、やり方です。あなたという人では、ありません。==
