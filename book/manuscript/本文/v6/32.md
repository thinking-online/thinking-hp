## 動物園のサルを、1匹、想像してください

バナナを食べている、サルです。

……

浮かんだと思います。では、今から、そのサルのことを、絶対に、考えないでください。

……

まだ、いますね。バナナも、食べています。

「サルを考えるな」と、自分に言うたびに、頭の中で、「サル」と言っています。だから、消えません。

不安も、同じです。こんな経験は、ありませんか。夜の10時。参考書を開いています。頭の中は、「このままで、間に合うのかな」「落ちたら、どうしよう」。「考えるな。集中しろ」。そう言い聞かせて、1時間。進んだのは、3ページです。

## 不安は、消さなくて、いいです

不安になるのは、弱いからでは、ありません。結果を出したいと、思っているからです。どうでもいいことには、不安になりません。

ハーバード大学の研究者たちの実験です。大事な試験をひかえた学生の一部に、「不安や緊張は、成績を下げるものではなく、助けるものだ」と伝えました。伝えられた学生たちは、練習の試験でも、そのあとの本番でも、数学の点が、高くなりました。

==不安そのものが、点を下げるとは、かぎりません。==頭を使ってしまうのは、不安を、消そうとする時です。

26番で、「あいうえお」と言いながら、●を数えた時、急に、難しくなりました。消そうとする時も、同じです。頭の中で、「考えるな、考えるな」と言いながら、問題を解いています。1時間で3ページだったのは、頭が、消すことに、使われていたからです。

だから、消そうとするのを、やめます。やることは、2つです。ふだんの不安は、紙に書く。本番の緊張は、呼び方を変える。

## ふだんの不安は、紙に書いて、「今日、できることは、ある？」と聞きます

```
　　①紙を1枚出して、今、不安なことを、全部書く。5分（目安です）
　　②1つずつ、「今日の自分に、できることは、ある？」と聞く
　　　ある　→　今日やることを、横に1つ書く
　　　ない　→　何も書かない
　　③紙を裏返して、10分だけ、一番軽いものをやる
```

①は、28番と同じです。紙に出せば、頭の中で、持ち続けなくて、すみます。

②が、一番大事な所です。不安は、2つに分かれます。

```
　　このやり方で、合ってるのかな　→　ある。10分やって、言えるか試す
　　このままで、間に合うのかな　　→　ある。1週間に上げる点を出す（31番）
　　落ちたら、どうしよう　　　　　→　ない
```

「ある」不安は、やることに変わります。==やることになった不安は、もう、不安では、ありません。予定です。==

「ない」不安は、いくら考えても、答えが出ません。紙に預けておくものです。また浮かんだら、消そうとしないで、こう言います。「それは、もう、紙に書いてある」。

③は、単語10個で、かまいません。「少しは、やった」と言えれば、十分です。

涙が止まらない。眠れない日が、続く。何日も、机に向かえない。そういう時は、勉強のやり方の問題では、ありません。先に、人に言ってください。親でも、先生でも、誰でも、いいです。勉強の話は、そのあとで、間に合います。

## 本番の緊張は、「ワクワクしている」と言いかえます

試験の直前。心臓が、速くなります。手に、汗をかきます。「落ち着け、落ち着け」。言うたびに、もっと、あせります。

「落ち着け」は、体への命令です。でも、心臓は、命令では、遅くなりません。「落ち着け」と言っているのに、体は、落ち着いていない。命令と、実際の体の間に、ギャップが生まれています。だから、言うたびに、あせります。

心臓が速いのは、体が、頭と筋肉に、酸素を送っているからです。本番に向けた、準備です。遠足の前の日にも、同じことが、起きていました。

```
　　緊張している時　　　心臓が速い　手に汗をかく　そわそわする
　　ワクワクしている時　心臓が速い　手に汗をかく　そわそわする
```

体に起きていることは、同じです。違うのは、それを、どう受け取るか。つまり、解釈だけです。だから、体を止めようとしないで、心の中で、こう言います。

```
　　ワクワクしている。体が、本気を出す準備をしている。
```

今度は、言葉と体の間に、ギャップが、ありません。最初の実験の学生たちが、やったことも、これです。緊張を、「助けるもの」と、解釈しました。

==起きていることは同じでも、どう解釈するかで、そのあとが、変わります。==不安や緊張の時だけでは、ありません。30番の失敗も、29番の「できない」も、そうでした。受験も、人生も、大事なのは、解釈力です。
