## 動物園のサルを、1匹、想像してください

バナナを食べている、サルです。

……

浮かんだと思います。では、今から、そのサルのことを、絶対に、考えないでください。

……

まだ、いますね。バナナも、食べています。

「サルのことを考えない」ためには、「サル」を、頭に置いておかないと、いけません。だから、消そうとするほど、サルは、そこにいます。

不安も、同じです。こんな経験は、ありませんか。夜の10時。参考書を開いています。でも、頭は、別のことを考えています。「このままで、間に合うのかな」「落ちたら、どうしよう」。「考えるな。集中しろ」。そう言い聞かせて、1時間。進んだのは、3ページです。

## 不安があると、「あいうえお」と言いながら解くのと、同じになります

不安になるのは、弱いからでは、ありません。結果を出したいと、思っているからです。どうでもいいことには、不安になりません。

真面目な人ほど、その不安を、気合いで消そうとします。でも、さっきのサルと同じです。消そうとするほど、そこにいます。

26番で、「あいうえお」と言い続けながら、●を数えたのを、思い出してください。数えるだけなのに、急に、難しくなりました。頭が一度に扱える量は、少ないからです。

不安がある時も、同じことが起きています。頭の中で、「落ちたら、どうしよう」と言い続けながら、問題を解いているのです。1時間で3ページだったのは、集中力がないからでは、ありません。==頭の一部が、不安のほうに、使われていたからです。==

だから、消そうとするのを、やめます。==置く場所を、変えます。==頭の中から、紙の上へ。

## 紙に全部書いて、「今日、できることは、ある？」と聞きます

```
　　①紙を1枚出して、今、不安なことを、全部書く。5分（目安です）
　　②1つずつ、「今日の自分に、できることは、ある？」と聞く
　　　ある　→　今日やることを、横に1つ書く
　　　ない　→　何も書かない
　　③紙を裏返して、10分だけ、一番軽いものをやる
```

①で、紙に出したものは、頭の中で、持ち続けなくて、よくなります。28番で、「やらなきゃ」を紙に出したのと、同じです。

②が、一番大事な所です。不安は、2つに分かれます。

```
　　このやり方で、合ってるのかな　→　ある。10分やって、言えるか試す
　　このままで、間に合うのかな　　→　ある。1週間に上げる点を出す（31番）
　　落ちたら、どうしよう　　　　　→　ない
```

「ある」不安は、やることに変わります。==やることになった不安は、もう、不安では、ありません。予定です。==

「ない」不安は、今、いくら考えても、答えが出ません。解決するものではなく、紙に預けておくものです。また浮かんできたら、消そうとしないで、こう言います。「それは、もう、紙に書いてある」。

③は、単語10個でも、計算3問でも、かまいません。10分やると、「何もやっていない」が、「少しは、やった」に変わります。

涙が止まらない。眠れない日が、続く。何日も、机に向かえない。そういう時は、勉強のやり方の問題では、ありません。先に、人に言ってください。親でも、先生でも、誰でも、いいです。勉強の話は、そのあとで、間に合います。

## 本番の緊張は、「ワクワクしている」と言いかえます

試験の直前。心臓が、速くなります。手に、汗をかきます。「落ち着け、落ち着け」。言うたびに、落ち着いていない自分に気づいて、もっと、あせります。これも、さっきのサルと同じです。

心臓が速くなるのは、体が、頭と筋肉に、酸素をたくさん送っているからです。本番に向けて、準備をしています。遠足の前の日や、試合の直前にも、同じことが、起きていたはずです。

```
　　緊張している時　　　心臓が速い　手に汗をかく　そわそわする
　　ワクワクしている時　心臓が速い　手に汗をかく　そわそわする
```

体に起きていることは、同じです。違うのは、それを、何と呼ぶかだけです。だから、落ち着こうとするかわりに、心の中で、こう言います。

```
　　ワクワクしている。体が、本気を出す準備をしている。
```

ハーバード大学の研究者たちの実験です。大事な試験をひかえた学生の一部に、「緊張は、成績を下げるものではなく、助けるものだ」と伝えました。伝えられた学生たちは、練習の試験でも、そのあとの本番でも、数学の点が、高くなりました。

==変えるのは、体ではなく、呼び方です。==普段の小テストで使っておくと、本番で、自然に出ます。
