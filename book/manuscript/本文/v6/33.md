## 友達から、電話です。「道に迷った。どうすればいい？」

あなたは、最初に、何と聞きますか。

……

「今、どこにいるの？」「どこに行きたいの？」。そう聞くはずです。

今いる場所と、行きたい場所がわからないと、道は、教えようがありません。==質問も、同じです。==

## 「わかりません」だけの質問は、「道に迷った」と同じです

例えば、数学の問題が、解けません。先生に、質問しに行きます。「先生、この問題、わかりません」。

先生は、あなたが、どこまでわかっているのかを、知りません。だから、最初から、全部、説明します。10分かかりました。そのうち8分は、もう知っている話でした。知りたかった所は、最後の2分で、早口で終わりました。

先生の説明が、悪いのでは、ありません。「今、どこにいるか」を、伝えていないからです。

## 質問は、3つをそろえて、持っていきます

```
　　①ここまでは、わかります　今いる場所
　　②自分は、こう考えました　ここまで来た道
　　③ここを、教えてください　行きたい場所
```

①は、わかる所と、わからない所の、境目です。「3行目までは、わかります」。これだけで、先生は、4行目から話せます。

②があるかないかで、質問は、大きく変わります。「4行目は、移項だと思ったのですが、数字が合いません」。考えを言うと、先生は、==あなたの考えの、どこがズレたかを、直せます。==自分では、見えない所です。考えを言わないと、正しいやり方を、もう一度聞くだけになります。

③は、答えではなく、知りたい所を、1つにします。

```
　　×　「この問題、わかりません」
　　○　「3行目までは、わかります。4行目は、移項だと思ったのですが、
　　　　数字が合いません。4行目で何をしているのか、教えてください」
```

## 聞く前に2回試して、聞いたあとに言い直します

聞く前に、2回だけ、自分で試します。試した分が、②になります。2回やって進まなければ、それ以上、1人で悩みません。20番で書いた通り、次に試すことがなくなったら、聞く時です。

聞いたあとは、自分の言葉で、言い直します。「つまり、ここで、両辺を3で割った、ということですか」。うなずいて終わると、わかった気になるだけです。言い直せたら、その日のうちに、何も見ずに、もう一度解きます。

## いい質問は、「わかっていない証拠」では、ありません

「こんなことを聞いたら、恥ずかしい」。そう思って、聞けない人が、多いです。でも、3つがそろった質問は、先生から見ると、よく考えている人の質問です。どこまでわかっているかを、言えるからです。

質問は、人の時間を借りることです。だから、3つをそろえて、短く聞きます。AIに聞く時も、同じ3つを入れます。（AIへの聞き方は、34番に書きます）

## わからない所がなくても、途中で見せます

質問は、わからない時だけのものでは、ありません。==自分のことは、自分では、見えません。==考え方のくせ、答案の書き方、勉強のやり方は、1人で何時間やっても、見えません。「もう少しできるようになってから、見せよう」と思いがちですが、順番が逆です。

```
　　できてから見せる　→　ズレたまま、何十時間も進む。直す量が、増える
　　途中で見せる　　　→　ズレが小さいうちに、直せる
```

見せるものを1つ決めて、こう聞きます。

　　==「一番直したほうがいい所は、どこですか」==

「どうですか」と聞くと、「いいんじゃない」で終わります。「一番直す所」を聞くと、1つ、返ってきます。英作文の答案を3題見せて、「時制。昨日の話なのに、現在形で書いている」と返ってきたら、3題とも、時制だけを書き直します。そして、もう一度、同じ人に見せます。直ったかどうかも、自分では、見えないからです。
