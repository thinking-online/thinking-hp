## 一番よく連絡する友達の、電話番号を、言えますか？

……

言えない人が、ほとんどだと思います。何百回も、連絡しているのに、です。覚える力がないから、では、ありません。スマホが覚えているので、自分の頭を、1回も使っていないからです。

==任せたものは、頭に残りません。==便利なのは、悪いことでは、ありません。ただ、「自分の頭に残したいもの」まで任せると、残りません。

数学の宿題。3番の問題が、わかりません。「写真を撮って、AIに聞こう。答えを教えてもらえば、早い」。10秒で、答えと解説が返ってきました。ノートに写します。「なるほど。わかった」。次の週の小テスト。同じ形の問題が、出ました。手が、動きません。

## 答えをもらうと、頭にかかる負荷が、ゼロになります

絶対法則03を思い出してください。力がつくのは、「うーん」と止まっている時間だけでした。AIに答えを聞くと、その時間が、丸ごとなくなります。止まる前に、答えが来ます。楽です。速いです。そして、何も残りません。

ペンシルベニア大学の研究者たちが、高校生の数学の授業で調べています。AIに自由に質問できて、答えも聞ける生徒。AIが、答えは言わずに、ヒントだけ出す生徒。AIを使わない生徒。練習問題の正答率は、答えも聞ける生徒が、一番高くなりました。

ところが、AIなしで受けたテストでは、==答えも聞けた生徒は、AIを使わなかった生徒よりも、点が低くなりました。==ヒントだけの生徒は、下がりませんでした。答えを聞いた生徒は、練習では解けていました。でも、解いていたのは、AIです。

## 答えではなく、ヒントをもらいます

聞き方を、変えます。

```
　　×　この問題の答えを教えて
　　○　答えは言わないで。最初の一歩だけ教えて
　　○　何がわかれば、この問題は解けますか
　　○　答えを教えずに、質問をしながら、僕を答えまで連れていって
```

最後の聞き方は、特に効きます。AIが「まず、求めたいものは何ですか？」と聞いてきます。答えると、次の質問が来ます。考えているのは、ずっと自分です。

順番も、大事です。わからない、と思った瞬間に聞かないでください。20番で書いた時間だけ、自分で考えます。単語なら5秒。数学で方針が立たないなら、3分。そして、聞く前に、==自分の考えを1行書きます。==「たぶん、相似を使う。でも、どの三角形かわからない」。ここまで書いてから、聞きます。

## 自分の考えに、反対してもらいます

人は、自分に都合のいい情報を集めます。自分の考えの穴は、自分では見えません。だから、==穴を探してもらいます。==

```
　　この英作文の、間違っているところを3つ指摘して。直した文は、まだ書かないで
　　僕のこの考えに、反対の立場から意見を言って
```

ほめてもらうために使うのではなく、突っこんでもらうために使います。07番でやった、30秒の説明を聞いてもらうのも、同じ使い方です。

## 力がつかない作業は、AIに任せます

「AIを使うのは、ズルな気がする」。そう思って、全部を自分でやる人もいます。でも、==「全部を」自分でやる必要は、ありません。==分けて考えます。

```
　　自分でやる　　思い出す。解く。説明する。間違いを直す
　　任せていい　　調べる。集める。数える。整理する。問題を作る
```

志望校の過去問を5年ぶん数えて、表にする。自分でやると、3日かけても、数学の力はつきません。AIなら、数分です。==空いた3日で、問題を解く。==

僕の塾生は、過去問と同じ形式、同じ難しさの問題を、AIに新しく作ってもらっています。過去に出た問題ではなく、==これから出そうな問題==です。分析はAIに任せて、生徒は、出てきた問題を解くことに時間を使っています。

## AIも、間違えます

AIの答えは、いつも正しいとはかぎりません。自信たっぷりに、間違ったことを言うことがあります。絶対法則01の「疑う」は、ここでも同じです。大事なところは、教科書か、解説で確かめてください。

学校や先生が、「この課題ではAIを使わない」と決めている時は、使いません。そして、名前や住所、学校名など、自分や友達のことがわかる情報は、入れません。
