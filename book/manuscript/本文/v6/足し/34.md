## 力がつかない作業は、AIに任せます

答えは、聞きません。力がつく作業を、AIにやらせてしまうからです。では、力がつかない作業は、どうでしょうか。思い出す。解く。説明する。間違いを直す。ここで、力がつきます。AIには、任せません。調べる。集める。数える。整理する。問題を作る。ここでは、力がつきません。時間だけ、かかります。任せていいのは、こちらです。志望校の過去問なら、こう分かれます。

```
　　5年ぶんを数えて、表にする　　→　任せていい
　　表を見て、よく出る単元を解く　→　自分でやる
```

AIに過去問を見せて、こう頼みます。

```
　　「よく出る単元を、大問ごとに数えて」
　　「過去問と同じ形式、同じ難しさの問題を、新しく作って」
```

作ってもらった問題は、その日のうちに、自分で解きます。作ってもらっただけでは、力はつきません。学校や先生が「この課題ではAIを使わない」と決めている時は、使いません。名前や住所、学校名など、自分や友達のことがわかる情報は、入れません。
