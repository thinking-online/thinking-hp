# 09　1日の計画を、to doリストで立てて終わる

```
　　×「今日やることは、この4つ」
　　○「10時までに単語30個。量と締切を、セットにする」
```

続ける力　　　　　　　　　　　　　　　　　　　　　　　★厚く書く　4ページ注　この項目の1週間の数字は仮。著者の実際の指導記録に差し替える。

---

## こんなとき

ノートの隅に、こう書いてある。

```
　　・英語ワーク
　　・数学 復習
　　・単語
　　・理科 プリント
```

これを書いた時点では、気分がいい。やることが見えて、整理された気がする。夜11時。4つのうち、1つ半しか終わっていない。

---

## あなたのせいではありません

このリストに、間違っているところは1つもありません。やるべきことは、たしかにその4つです。問題は、この4つのどれにも、終わりが書いていないことです。「英語ワーク」は、いつ終わるのか。1ページでも英語ワークです。20ページでも英語ワークです。終わりが書いていないものは、終わりません。いつまでも終わらないので、いつ次に進んでいいのかもわかりません。だから、1つ目に時間を使いすぎて、夜になります。

---

## 何が起きているか

to doリストは、やることの名前の一覧です。計画は、量と時間の約束です。名前の一覧を書いて、計画を立てた気になる。ここが、この項目の「やった気」です。

```
　　やることの名前　　→　書いた
　　どれだけやるか　　→　書いていない
　　いつまでにやるか　→　書いていない
```

3つのうち1つしか書いていないものを、計画と呼んでいる。

---

## やり方

名前のうしろに、量と締切をつける。それだけです。

```
　　×　英語ワーク

　　○　英語ワーク p42-45　　20:30-21:00
```

これで、3つそろいます。

この形を、ブロックと呼びます。1つのブロックに、1つの教材、量、始まりと終わりの時刻。ブロックには、3つのルールがあります。

```
　1　1ブロックは30分までにする
　2　量は、終わったかどうかが自分でわかる形で書く
　　　「復習」ではなく「間違えた6問」
　3　1日のブロックは、平日3つまで
```

3つまでにする理由は、4つ目から守れなくなるからです。守れない計画を立てると、守れない自分を毎晩見ることになります。

---

## 1週間を、実物で

週6で部活。帰宅8時。定期テストまで2週間。中2。

```
　　　　朝 7:00　　　　　　　　夜 20:30-21:00

　月　　単語20　閉じて出す　　　英語ワーク p42-45
　火　　単語20　閉じて出す　　　数学　間違えた6問を、原因で3つにまとめる
　水　　単語20　閉じて出す　　　――
　木　　単語20　閉じて出す　　　理科　光の単元を、何も見ないで書き出す
　金　　単語20　閉じて出す　　　社会　江戸の流れを、教科書を閉じて口で言う
　土　　――　　　　　　　　　　 9:00-9:30　　ワーク2周目　×だけ
　　　　　　　　　　　　　　　　 9:40-10:10　 英語　長文1本　時間を測る
　　　　　　　　　　　　　　　　 10:20-10:50　数学　土曜までの×を、もう1回
　日　　――　　　　　　　　　　 9:00-9:30　　1週間の×を、原因で3つにまとめる
```

平日は1日30分です。2時間ではありません。週6で部活がある人に2時間は書けません。書いたところで、守れないので、計画としての意味がありません。30分でも、朝の20個と合わせて週に5時間半。守れる5時間半は、守れない14時間より点になります。

---

## 水曜に、何があったか

水曜が空いています。

試合前の練習が長引いて、帰宅が9時半でした。夕食と風呂で10時半。何もできませんでした。それでも、この1週間の計画は崩れていません。

理由は2つあります。

1つ目。水曜を、最初から空けてありました。崩れる日が週に1日は来ます。来ると分かっているものを、来てから対応するのはおかしい。だから先に入れておきます。2つ目。水曜も、朝の単語20はやりました。朝の20個は、やる気の話ではありません。歯をみがく場所の隣に置いてあります。顔を洗って、座って、20個。やる気がない日に、やる気がなくても始まるものが1つあれば、その日は「0の日」になりません。0の日が3日続くと、人は計画を捨てます。捨てさせないために、朝の20個があります。

---

## 注意

量を細かく書きすぎると、書くのに時間がかかります。1日の計画を書くのにかかる時間は、2分までにしてください。2分を超えたら、計画が細かすぎます。それから、崩れた日に計画を作り直さないこと。作り直すのは、日曜の30分だけです。これは10番で書きます。

---

## 残るもの

```
　　やることの名前を書くのは、計画ではない。

　　量と、締切。この2つがついて、はじめて計画になる。

　　そして、崩れる日は最初から入れておく。
```
