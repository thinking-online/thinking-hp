# 19　新しい単元に入るとき、いきなり読み始める

×「知らないことを習うんだから、まっさらで聞く」○「知ってることを3つ書いてから、聞く」

---

理科の新しい単元が始まります。「電流」です。教科書の新しいページを開いて、1行目から読み始めます。知らない言葉が出てきます。抵抗、オーム、直列。30分読みました。終わったとき、何も残っていません。

## まっさらで聞くのは、礼儀正しい態度です

先入観を持たずに聞く。これは、ちゃんとした人の態度です。ただ、記憶の作りには合っていません。新しいことは、新しい場所には入りません。すでにある場所の、となりにしか入りません。まっさらで聞くというのは、となりに何も置かずに聞くということです。

## 知っていることが、引っかかりになります

電流の単元に入る前に、あなたはもう何かを知っています。

```
　　・コンセントに水をかけると危ない
　　・乾電池には向きがある
　　・豆電球を2個つなぐと、暗くなった（小学校でやった）
```

3つ書けました。これで、新しい言葉を引っかける場所が3か所できます。「直列」が出てきたとき、まっさらな人は言葉だけを覚えます。3つ書いた人は「豆電球が暗くなったやつか」とつながります。同じ30分で、残る量が変わります。

## 頭のなか

### 新しい単元、伸びない人

```
　　「電流か。やったことない」
　　「とりあえず読もう」
　　（読む）
　　「……抵抗って何だっけ」
```

### 同じとき、頭のいい人

```
　　「電流か。やったことない……いや、何か知ってるはずだ」
　　「乾電池。向きがある。逆にすると回らない」
　　「豆電球。2個つけたら暗くなった」
　　「コンセント。水で感電する」
　　「よし、3つ出た。これに引っかけていこう」
```

---

違いは、1か所です。

「やったことない」で止まらずに、知っていることを探した。

```
　　　　　　　本当に、何も知らない？
```

中学の単元で、本当にゼロから始まるものは、ほとんどありません。小学校か、生活の中か、別の教科で、必ず一度は触っています。

## やり方

```
　1　新しい単元に入る前に、紙の端に3つ書く　　　　　　　　1分
　　　正確でなくていい。間違っていてもいい
　　　「たぶんこうだと思う」でいい

　2　授業中、その3つのどれかに当たったら、丸をつける

　3　授業の終わりに、間違っていた1つを、線で消して書き直す
```

間違いを書いて、あとで消す。この消す作業がいちばん残ります。正しいことを最初から書いた人より、間違えて直した人のほうが、その単元を覚えています。

## 残るもの

```
　　新しいことは、新しい場所には入らない。
　　知っていることの、となりにしか入らない。
```

　　この場面を見つけた問い　　これ、前にどこで見た？

つなげる力　「これ、前にどこで見た？」

# 29　満点を取ったら、そこでやめる

×「10問中10問。もう覚えた。次へ進もう」○「満点が出てから、あと2周する」

---

単語の小テスト。10問中10問。満点です。もう覚えました。次の範囲へ進みます。2週間後の定期テスト。同じ10語のうち、4つが出てきません。

## 満点でやめるのは、効率がいいはずです

できるようになったものに時間を使わない。これは正しい判断に見えます。実際、ほとんどの参考書にもそう書いてあります。ただ、満点には2種類あります。

```
　　ぎりぎりの満点　　　思い出すのに2秒かかって、10問とも合った
　　余裕のある満点　　　0.5秒で出て、10問とも合った
```

テストの紙の上では、どちらも10点です。2週間後に残っているのは、下だけです。

## 満点のあとの2周が、固めます

できるようになった直後に、もう少し続ける。これで、記憶が固まって、ほかのものと混ざりにくくなります。やめた人の頭では、その10語はまだ、ぐらぐらしています。次の10語が入ってくると、押し出されます。「覚えたのに忘れた」の多くは、覚えきる手前でやめたものです。

## 頭のなか

### 満点が出たとき、伸びない人

```
　　「10問中10問。完璧」
　　「もうここはいいな。次いこう」
```

### 同じとき、頭のいい人

```
　　「10問中10問。……でも、3つは出るのが遅かった」
　　「遅かった3つは、まだぐらぐらしてる」
　　「全部もう1周。あと40秒」
　　「……今度は全部速い。もう1周」
　　「よし、これで固まった」
```

---

違いは、1か所です。

○の数ではなく、出てくるまでの速さを見ている。

```
　　　　　　　満点だったけど、全部 速かった？
```

## やり方

```
　1　満点が出た直後に、同じ10語をもう1周　　　　　　40秒
　　　2秒かかったものに、点を打つ

　2　点がついたものだけ、もう1周　　　　　　　　　　20秒

　3　全部が0.5秒で出たら、そこでやめる
```

満点のあとに足す時間は、1分です。1分足すか足さないかで、2週間後に残る数が変わります。

## やりすぎないために

3周を超えたら、やめてください。4周目から先は、ほとんど増えません。かわりに飽きます。飽きると、次の範囲を始めるのが重くなります。固めるのは1分まで。1分で足りないなら、その日は覚えきっていません。

## 残るもの

```
　　満点は、終わりの合図ではない。
　　固める作業の、始まりの合図。
```

　　この場面を見つけた問い　　それ、テストでもできる？

出す力　「それ、テストでもできる？」

# 39　解法を、頭の中だけで追う

×「声に出さなくても、頭で考えられる」○「やっていることを、小声で実況する」

---

数学の問題を解いています。手は止まっています。頭の中では考えています。3分たちました。まだ1行も書いていません。どこで止まったのかも、よくわかりません。

## 頭の中で考えるのは、ふつうのことです

声を出しながら勉強する人のほうが、少ないです。自習室では出せません。家でも、家族がいると出しにくい。ただ、頭の中だけで考えているとき、あなたは自分が何を考えているかを見ていません。考えているのか、止まっているのか、自分でもわからない。3分たって気づく。これが、頭の中だけで追ったときに起きることです。

## 声に出すと、止まった場所がわかります

この本では、ここまで何度も、頭のいい人の頭のなかを見せてきました。

```
　　「なるほど。……いや待て。いま読んだだけだ」
　　「出た。でも、何秒かかった？」
　　「1行目はわかる。2行目もわかる。3行目で止まった」
```

あれを、自分でやります。

口に出した瞬間、自分の思考が外に出ます。外に出たものは、自分で聞けます。聞けると、止まった場所がわかります。

## 頭のなか

### 止まったとき、伸びない人

```
　　（無言）
　　（3分）
　　「……わかんない」
```

### 同じとき、頭のいい人

```
　　「この問題は、三角形の面積を出す」
　　「底辺は……わかってる。6」
　　「高さは……書いてない」
　　「高さを出すには……あ、垂線を引くのか」
　　（手が動く）
```

20秒です。

---

違いは、1か所です。

考えていることを、自分の耳に入れた。

```
　　　　　　　いま、何をやってるか、言ってみて
```

口に出すと、「高さは書いてない」のところで、必ず引っかかります。頭の中だけだと、そこを素通りします。

## やり方

```
　1　止まったら、まず声に出す。小声でいい　　　　　　　20秒
　　　「この問題は、何を出す問題か」から言う

　2　言えないところで、止まる
　　　そこが、わからないところ

　3　家で、2回だけやってみる
　　　自習室ではやらない。恥ずかしいと続かない
```

最初は、自分の声が気持ち悪いです。3回目で慣れます。声が出せない場所では、口だけ動かしてください。声帯を使わなくても、口を動かすだけで効きます。

## 3つ以上出てきたら、手を動かします

声と同じで、もう1つ、頭の外に出すものがあります。

中学2年生。数学の文章題です。「AさんはBさんより3歳年上で、CさんはAさんより5歳年下。3人の年齢の合計は46歳。Bさんは何歳か。」頭の中で考えます。AがBより3つ上。CがAより5つ下。ということは、CはBより……えーと。もう一度、問題を読みます。ここまで来るのに、3回読み直しました。

人が同時に扱えるものの数には、限りがあります。3つくらいまでは、頭の中で動かせます。4つになると、1つ目を思い出している間に、3つ目が消えます。

この問題には、3人います。関係が2つあります。合計が1つ。6つです。頭の中では、動かせません。だから、読み直すことになります。読み直すたびに、前に考えたことが消えているからです。

```
　　A = B + 3
　　C = A - 5
　　A + B + C = 46
```

3行書くのに、20秒です。この3行を書いた瞬間、問題は終わっています。あとは代入するだけです。

書くのは、面倒です。ここはごまかしません。でも、頭の中でやろうとして3回読み直した時間と、3行書く20秒を比べてください。面倒なのは、最初の20秒だけです。

```
　1　文章題を読んだら、出てきたものを数える
　2　3つを超えたら、考える前に手を動かす
　　　考えてから決めるのではなく、数えたら自動で書く
　3　書き方は何でもいい
　　　数学なら式か図。理科なら装置の絵。社会の年号なら横1本の線に点
```

計算が速い人を見て、頭の中で全部やっていると思うかもしれません。逆です。できる人ほど、早く書きます。頭の中は、考えるために空けておくものだと知っているからです。覚えておくために使うと、考える余地がなくなります。

## 残るもの

```
　　頭の中は、自分にも見えない。
　　口に出すと、自分で聞ける。
```

　　この場面を見つけた問い　　どこで、止まった？

出す力　「それ、テストでもできる？」

# 56　誰のために受けるのかを、考えたことがない

×「とりあえず、行けるところに行く」○「受かったとき、誰に最初に言うかを決めておく」

---

「なんで受験するの」と聞かれて、答えられません。みんな受けるから。親が言うから。行かないと、あとで困るから。嘘ではありません。でも、これで夜11時に机に向かうのは、きついです。

## 目標がないのが悪い、という話ではありません

「夢を持て」と言われても、ない人のほうが多いです。中学生で将来やりたいことが決まっている人は、少数です。ここで言いたいのは、夢を持てではありません。自分のためだけの目標は、弱いということです。

## 自分のためだけだと、自分が許せば終わります

```
　　自分のため　　　　今日はもういいや　→　自分が許す　→　終わる
　　誰かのため　　　　今日はもういいや　→　許せない　　→　続く
```

これは根性の話ではなく、続く形かどうかの話です。自分との約束は、自分で破れます。誰かが関わっている約束は、破りにくい。

## 夢ではなく、顔を1つ決めます

将来の仕事を決める必要はありません。受かったとき、最初に言いたい相手を1人、決めるだけです。

```
　　・親
　　・いまの担任
　　・中学のとき、自分を馬鹿にした人
　　・下の兄弟
　　・自分を見てくれていた部活の先輩
```

誰でもいいです。見返したい相手でも、かまいません。その人の顔が浮かぶかどうかだけが条件です。

## 頭のなか

### 夜11時、伸びない人

```
　　「もう無理」
　　「なんでこんなことやってるんだろう」
　　「……まあ、明日やればいいか」
```

### 同じとき、頭のいい人

```
　　「もう無理」
　　「……でも、合格を言う相手は決まってる」
　　「あと1問だけやって寝る」
```

---

違いは、1か所です。

「なんでやってるんだろう」に、答えを持っていた。

```
　　　　　　　受かったら、最初に誰に言う？
```

## やり方

```
　1　紙に、1人の名前を書く　　　　　　　　　　　　　　1分

　2　その紙を、机の見えるところに貼らない
　　　貼ると、1週間で見えなくなる

　3　筆箱の中に入れる
　　　筆箱は、毎日開ける。1日1回は目に入る
```

言葉はいりません。名前だけでいいです。

## 残るもの

```
　　自分との約束は、自分で破れる。
　　誰かが入っている約束は、破りにくい。
```

　　この場面を見つけた問い　　次の1個目は？

続ける力　「次の1個目は？」
