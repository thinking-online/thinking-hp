# 19　新しい単元に入るとき、いきなり読み始める

　　×「知らないことを習うんだから、まっさらで聞く」
　　○「知ってることを3つ書いてから、聞く」

---

理科の新しい単元が始まります。「電流」です。

教科書の新しいページを開いて、1行目から読み始めます。
知らない言葉が出てきます。抵抗、オーム、直列。

30分読みました。終わったとき、何も残っていません。

## まっさらで聞くのは、礼儀正しい態度です

先入観を持たずに聞く。これは、ちゃんとした人の態度です。

ただ、記憶の作りには合っていません。

新しいことは、新しい場所には入りません。
すでにある場所の、となりにしか入りません。

まっさらで聞くというのは、となりに何も置かずに聞くということです。

## 知っていることが、引っかかりになります

電流の単元に入る前に、あなたはもう何かを知っています。

```
　　・コンセントに水をかけると危ない
　　・乾電池には向きがある
　　・豆電球を2個つなぐと、暗くなった（小学校でやった）
```

3つ書けました。これで、新しい言葉を引っかける場所が3か所できます。

「直列」が出てきたとき、まっさらな人は言葉だけを覚えます。
3つ書いた人は「豆電球が暗くなったやつか」とつながります。

同じ30分で、残る量が変わります。

## 頭のなか

### 新しい単元、伸びない人

```
　　「電流か。やったことない」
　　「とりあえず読もう」
　　（読む）
　　「……抵抗って何だっけ」
```

### 同じとき、頭のいい人

```
　　「電流か。やったことない……いや、何か知ってるはずだ」
　　「乾電池。向きがある。逆にすると回らない」
　　「豆電球。2個つけたら暗くなった」
　　「コンセント。水で感電する」
　　「よし、3つ出た。これに引っかけていこう」
```

---

違いは、1か所です。

「やったことない」で止まらずに、知っていることを探した。

```
　　　　　　　本当に、何も知らない？
```

中学の単元で、本当にゼロから始まるものは、ほとんどありません。
小学校か、生活の中か、別の教科で、必ず一度は触っています。

## やり方

```
　1　新しい単元に入る前に、紙の端に3つ書く　　　　　　　　1分
　　　正確でなくていい。間違っていてもいい
　　　「たぶんこうだと思う」でいい

　2　授業中、その3つのどれかに当たったら、丸をつける

　3　授業の終わりに、間違っていた1つを、線で消して書き直す
```

間違いを書いて、あとで消す。この消す作業がいちばん残ります。

正しいことを最初から書いた人より、
間違えて直した人のほうが、その単元を覚えています。

## 残るもの

```
　　新しいことは、新しい場所には入らない。
　　知っていることの、となりにしか入らない。
```

　　この場面を見つけた問い　　これ、前にどこで見た？

つなげる力　「これ、前にどこで見た？」

# 29　満点を取ったら、そこでやめる

　　×「10問中10問。もう覚えた。次へ進もう」
　　○「満点が出てから、あと2周する」

---

単語の小テスト。10問中10問。満点です。

もう覚えました。次の範囲へ進みます。

2週間後の定期テスト。同じ10語のうち、4つが出てきません。

## 満点でやめるのは、効率がいいはずです

できるようになったものに時間を使わない。これは正しい判断に見えます。
実際、ほとんどの参考書にもそう書いてあります。

ただ、満点には2種類あります。

```
　　ぎりぎりの満点　　　思い出すのに2秒かかって、10問とも合った
　　余裕のある満点　　　0.5秒で出て、10問とも合った
```

テストの紙の上では、どちらも10点です。
2週間後に残っているのは、下だけです。

## 満点のあとの2周が、固めます

できるようになった直後に、もう少し続ける。
これで、記憶が固まって、ほかのものと混ざりにくくなります。

やめた人の頭では、その10語はまだ、ぐらぐらしています。
次の10語が入ってくると、押し出されます。

「覚えたのに忘れた」の多くは、覚えきる手前でやめたものです。

## 頭のなか

### 満点が出たとき、伸びない人

```
　　「10問中10問。完璧」
　　「もうここはいいな。次いこう」
```

### 同じとき、頭のいい人

```
　　「10問中10問。……でも、3つは出るのが遅かった」
　　「遅かった3つは、まだぐらぐらしてる」
　　「全部もう1周。あと40秒」
　　「……今度は全部速い。もう1周」
　　「よし、これで固まった」
```

---

違いは、1か所です。

○の数ではなく、出てくるまでの速さを見ている。

```
　　　　　　　満点だったけど、全部 速かった？
```

## やり方

```
　1　満点が出た直後に、同じ10語をもう1周　　　　　　40秒
　　　2秒かかったものに、点を打つ

　2　点がついたものだけ、もう1周　　　　　　　　　　20秒

　3　全部が0.5秒で出たら、そこでやめる
```

満点のあとに足す時間は、1分です。

1分足すか足さないかで、2週間後に残る数が変わります。

## やりすぎないために

3周を超えたら、やめてください。

4周目から先は、ほとんど増えません。かわりに飽きます。
飽きると、次の範囲を始めるのが重くなります。

固めるのは1分まで。1分で足りないなら、その日は覚えきっていません。

## 残るもの

```
　　満点は、終わりの合図ではない。
　　固める作業の、始まりの合図。
```

　　この場面を見つけた問い　　それ、テストでもできる？

出す力　「それ、テストでもできる？」

# 39　解法を、頭の中だけで追う

　　×「声に出さなくても、頭で考えられる」
　　○「やっていることを、小声で実況する」

---

数学の問題を解いています。

手は止まっています。頭の中では考えています。
3分たちました。まだ1行も書いていません。

どこで止まったのかも、よくわかりません。

## 頭の中で考えるのは、ふつうのことです

声を出しながら勉強する人のほうが、少ないです。
自習室では出せません。家でも、家族がいると出しにくい。

ただ、頭の中だけで考えているとき、
あなたは自分が何を考えているかを見ていません。

考えているのか、止まっているのか、自分でもわからない。
3分たって気づく。これが、頭の中だけで追ったときに起きることです。

## 声に出すと、止まった場所がわかります

この本では、ここまで62回、頭のいい人の頭のなかを見せてきました。

```
　　「なるほど。……いや待て。いま読んだだけだ」
　　「出た。でも、何秒かかった？」
　　「1行目はわかる。2行目もわかる。3行目で止まった」
```

あれを、自分でやります。

口に出した瞬間、自分の思考が外に出ます。
外に出たものは、自分で聞けます。聞けると、止まった場所がわかります。

## 頭のなか

### 止まったとき、伸びない人

```
　　（無言）
　　（3分）
　　「……わかんない」
```

### 同じとき、頭のいい人

```
　　「この問題は、三角形の面積を出す」
　　「底辺は……わかってる。6」
　　「高さは……書いてない」
　　「高さを出すには……あ、垂線を引くのか」
　　（手が動く）
```

20秒です。

---

違いは、1か所です。

考えていることを、自分の耳に入れた。

```
　　　　　　　いま、何をやってるか、言ってみて
```

口に出すと、「高さは書いてない」のところで、必ず引っかかります。
頭の中だけだと、そこを素通りします。

## やり方

```
　1　止まったら、まず声に出す。小声でいい　　　　　　　20秒
　　　「この問題は、何を出す問題か」から言う

　2　言えないところで、止まる
　　　そこが、わからないところ

　3　家で、2回だけやってみる
　　　自習室ではやらない。恥ずかしいと続かない
```

最初は、自分の声が気持ち悪いです。3回目で慣れます。

声が出せない場所では、口だけ動かしてください。
声帯を使わなくても、口を動かすだけで効きます。

## 残るもの

```
　　頭の中は、自分にも見えない。
　　口に出すと、自分で聞ける。
```

　　この場面を見つけた問い　　どこで、止まった？

出す力　「それ、テストでもできる？」

# 55　朝型が正しい、と思っている

　　×「朝5時に起きて勉強するのが、いちばん効率がいい」
　　○「自分がいちばん頭が回る時間に、いちばん重いものを置く」

---

テスト2週間前。朝型に変えることにしました。

5時に起きます。1日目はできました。2日目も起きました。
3日目、起きられませんでした。

起きられなかった自分に、がっかりします。
そして、その日の夜も、集中できませんでした。

## 朝型がいい、は半分だけ本当です

朝に勉強すると集中できる人は、実際にいます。
そういう人は、もともと朝に頭が回る人です。

人には、頭が回る時間帯のくせがあります。
これは、気合いや習慣より、生まれ持ったものの影響が大きいとされています。

くせに逆らった時間に勉強すると、同じ1時間でも入る量が落ちます。

つまり、朝型の人が朝にやるのは正しい。
夜型の人が朝にやるのは、わざわざ悪い時間を選んでいることになります。

## 問題は、朝型を押してくるのが外からだということです

「早起きしなさい」は、親から来ます。学校からも来ます。
朝練もあります。

だから、夜型の子は「自分は怠けている」と思いがちです。
怠けていません。時間帯が合っていないだけです。

## 頭のなか

### 朝起きられなかった日、伸びない人

```
　　「また起きられなかった」
　　「意志が弱い」
　　「こんなんじゃ受からない」
　　（その日1日、引きずる）
```

### 同じとき、頭のいい人

```
　　「また起きられなかった」
　　「……3日連続だ。これはもう、合ってないってことだ」
　　「朝は、単語20個だけにする。頭を使わないやつ」
　　「数学は、夜9時に動かす。いちばん回る時間だ」
```

---

違いは、1か所です。

起きられない自分を直そうとせず、置く中身を変えた。

```
　　　　　　　いちばん頭が回るのは、何時？
```

## やり方

```
　1　1週間、記録する　　　　　　　　　　　　　　　　1日10秒
　　　その日いちばん集中できた時間帯に、丸をつけるだけ
　　　朝　昼　夕方　夜　深夜

　2　丸が多い時間帯に、いちばん重い教科を置く
　　　重い＝頭を使う。数学の応用、英語の長文、理科の計算

　3　丸が少ない時間帯には、軽いものを置く
　　　軽い＝手だけでできる。単語、漢字、丸つけ、記録
```

朝型に変えなくていいです。
朝に何を置くかを、変えてください。

## やりすぎないために

夜型だから夜中まで、にはしないでください。

睡眠を削ると、覚えたものが残りません。これは時間帯と別の話です。
起きる時間は変えなくていいので、寝る時間は守ってください。

それから、試験は朝に始まります。
本番の2週間前からは、朝に1問だけ解く練習を入れてください。
生活は変えなくていいです。1問だけです。

## 残るもの

```
　　直すのは、起きる時間ではない。
　　その時間に、何を置くか。
```

　　この場面を見つけた問い　　次の1個目は？

続ける力　「次の1個目は？」

# 56　誰のために受けるのかを、考えたことがない

　　×「とりあえず、行けるところに行く」
　　○「受かったとき、誰に最初に言うかを決めておく」

---

「なんで受験するの」と聞かれて、答えられません。

みんな受けるから。親が言うから。行かないと、あとで困るから。

嘘ではありません。でも、これで夜11時に机に向かうのは、きついです。

## 目標がないのが悪い、という話ではありません

「夢を持て」と言われても、ない人のほうが多いです。
中学生で将来やりたいことが決まっている人は、少数です。

ここで言いたいのは、夢を持てではありません。

自分のためだけの目標は、弱いということです。

## 自分のためだけだと、自分が許せば終わります

```
　　自分のため　　　　今日はもういいや　→　自分が許す　→　終わる
　　誰かのため　　　　今日はもういいや　→　許せない　　→　続く
```

これは根性の話ではなく、続く形かどうかの話です。

自分との約束は、自分で破れます。
誰かが関わっている約束は、破りにくい。

## 夢ではなく、顔を1つ決めます

将来の仕事を決める必要はありません。
受かったとき、最初に言いたい相手を1人、決めるだけです。

```
　　・親
　　・いまの担任
　　・中学のとき、自分を馬鹿にした人
　　・下の兄弟
　　・自分を見てくれていた部活の先輩
```

誰でもいいです。見返したい相手でも、かまいません。
その人の顔が浮かぶかどうかだけが条件です。

---

違いは、1か所です。
