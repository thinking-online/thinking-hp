# 01　過程に、意味を持たせる

　　×「がんばったことが大事。過程にも意味がある」
　　○「勝ってから、過程に意味が出る。先に1つ勝つ」

---

序章で、その時間を作業で終わらせてほしくない、と書きました。

では、何から変えるのか。

いちばん最初にやってほしいことは、1つです。

順番の①でも②でもありません。その前に、1回です。

## 努力そのものには、値段がつきません

その前に、1つだけ片づけておきます。

やり方を変えるというのは、これまでのやり方をやめるということです。
やめると、これまでやってきたことが無駄になる気がします。

ここを置いたままだと、何を読んでも手がつきません。

序章にも書きましたが、僕は1日14時間やって、10校落ちました。

あのとき、いろいろな人が声をかけてくれました。

　　「過程にも意味があるよ」
　　「頑張ったことは無駄にならないよ」

ありがたい言葉でした。でも、当時の自分には何も残りませんでした。

だからこの本では、努力そのものを褒めません。
頑張ったね、で終わらせません。

試験には、頑張った賞がありません。
点が足りたかどうかだけで決まります。

冷たく聞こえるかもしれません。
でも、この冷たさは、あなたの味方です。

点だけで決まるということは、
いまビリでも、点さえ取れば勝てるということだからです。

## 過程に意味が出るのは、勝ったあとです

おかしな言い方に聞こえるかもしれませんが、こうです。

受かったあとに振り返ると、あの1年には意味があったと思えます。
落ちたあとに振り返ると、意味は出てきません。

同じ1年なのに、です。

だから、過程に意味を持たせたいなら、勝つしかありません。
勝った人だけが、自分の過程を好きになれます。

これは、努力を否定する話ではありません。
逆です。

せっかくやるなら、点になる方向でやってほしい、という話です。

## 小さく、早く、勝ってください

ここからが、いちばん大事なところです。

勝つ、というのは、第一志望に受かることだけではありません。

```
　　小テストで満点を取る
　　前回より5点上げる
　　1冊の問題集を、最後まで終わらせる
　　1週間、決めた計画を守る
```

これも、勝ちです。

そして、この小さい勝ちを、早く1回やった人が、強くなります。

理由は、やり方を覚えるからではありません。
もっと単純です。

　　やれば変わる、という事実を、自分の体で1回知るからです。

これは、人から言われても手に入りません。
「やればできるよ」と100回言われても、変わりません。

自分で1回、変えたことがある人だけが持っています。

## やれば変わる、を知らない人は、折れます

逆から見ると、よくわかります。

一度も変えたことがない人が勉強を始めると、
最初の2週間が、ものすごくしんどいです。

やっても変わらないかもしれない、と思いながらやるからです。
その疑いが、ずっと消えません。

だから、少し結果が出ないと、やめてしまいます。

小さく勝ったことがある人は、ここで折れません。
前に1回変えたから、今回も変わると思えるからです。

同じしんどさでも、片方は耐えられて、片方は耐えられない。
差は、根性ではありません。過去に1回勝ったかどうかです。

## だから、いちばん小さいところから取ってください

いま、何も変えたことがないなら、
いちばん小さい勝ちから取りにいってください。

次の小テストでいいです。10問のやつでいいです。

範囲は10個です。

満点を取ったら、その日に1つ確かめてください。

　　やり方を変えたら、点が変わった。

これが手に入ると、ここから先の全部が変わります。

# 02　やり方だけを、直そうとする

　　×「勉強法の本を読んだ。これで変わるはず」

## 式はこれです

　　結果　＝　戦略　×　やり方　×　量

3つあります。

```
　　戦略　　どこをやるか
　　やり方　どうやるか
　　量　　　どれだけやるか
```

これで全部です。
勉強の悩みは、どんなものでも、この3つのどこかの話になります。

## 足し算ではなく、掛け算です

足し算なら、戦略が0点でも、やり方80点、量80点で、合計160点です。

でも、そうはなりません。掛け算だからです。

どれか1つが0だと、ほかが満点でも0になります。

0になる3つのパターンを見てください。

### 戦略が0のとき

出ないところを、完璧にしました。

やり方は正しかった。量もやった。
でも、試験に出ませんでした。

0点です。

### やり方が0のとき

出るところを選びました。たくさんやりました。

ただ、ずっと教科書を見ながらやっていました。
1回も、閉じて出していません。

試験では、教科書が見られません。

0点です。

### 量が0のとき

どこをやるかを決めました。正しいやり方も知りました。

それで、満足しました。

勉強のやり方の本を読んで、なるほどと思って、本を閉じた。
そこで終わりました。

0点です。

---

序章に書いた僕の話を、この式に入れると、こうなります。

量だけなら、満点でした。
でも掛け算なので、0が2つあれば0になります。

## 勉強法の本を読んでも、変わらなかった人へ

この本を手に取るまでに、勉強法の本を読んだことがある人もいると思います。
動画を見た人も、いるはずです。

読んだときは、なるほどと思った。
でも、3か月後、点は変わっていなかった。

書いてあったことが、嘘だったわけではありません。
理由は、別のところにあります。

世の中にある勉強法の本を、さっきの式に当てはめてみます。

ほとんどの本が、まん中の列だけを書いています。

どう覚えるか。どう解くか。どう復習するか。
全部、やり方の列です。

左の列、つまり何をやらないかを決める話は、ほとんど出てきません。
右の列、つまり量が必要だという話は、もっと出てきません。

量の話は、売り文句にならないからだと思います。
短い時間で結果が出ます、のほうが売れます。

ここで、何が起きるか。

```
　　やり方が0だった人　　→　読んで、伸びる
　　戦略が0だった人　　　→　何も変わらない
　　量が0だった人　　　　→　何も変わらない
```

本が悪かったのではありません。
読んだ本の列と、自分の0の列が、合っていなかっただけです。

だからこの本では、先に、自分のどの列が0かを決めてもらいます。
この項目の最後に、3つ質問します。

## 3つの列を、もう一段細かくします

### 戦略とは、やらないことを決めることです

やることを決める、ではありません。やらないことを決める、です。

試験には範囲があります。出るものと、出ないものがあります。
どんな試験にもあります。出す側は、無限には出せないからです。

つまり試験が始まる前から、答えの半分は決まっています。
どこが出るか、です。

それが書いてある紙を、ほとんどの人は見ません。
範囲表を1回見て、机に置いたままにします。
過去問を、実力がついてから開こうとして、本棚に立てます。

　　→　選ぶ力

### やり方とは、思い出すことです

序章で決めた基準が、そのままここに入ります。
やりやすかったか、ではなく、出せたか。

勉強のやり方は、世の中に何十種類もあります。
でも、点になるかどうかを決めているのは、1つだけです。

　　その勉強の中で、1回でも思い出したか。

思い出していれば、点になります。
思い出していなければ、何時間やっても点になりません。

ここだけ、4つに分かれます。
入れて、つなげて、出して、なおす。この順に動くからです。

　　→　入れる力　／　つなげる力　／　出す力　／　なおす力

### 量とは、埋めなければいけない差のことです

よく「量より質」と言われます。半分だけ本当です。

質は、1時間あたりに進む距離です。
量は、何時間歩いたかです。

　　進んだ距離　＝　速さ　×　時間

速さがどれだけ速くても、時間が0なら、1歩も進みません。

そして、もう1つあります。

いまの自分と、行きたいところのあいだには、差があります。
その差を埋めるのに必要な「できる」の数は、決まっています。

質を上げても、この数は減りません。減るのは、かかる時間だけです。

「量より質」と言う人は、たいてい、すでに量をやった人です。
量をやったうえで、質の話をしています。

質の話を先にして、量をやらなかった人が伸びたのを、僕は見たことがありません。

　　→　続ける力

## 6つあります

```
　　戦略　　→　選ぶ力

　　やり方　→　入れる力　つなげる力　出す力　なおす力

　　量　　　→　続ける力
```

この6つで、この本の75個が、全部できています。

```
　　選ぶ力　　　　これ、出るの？　　　　　　　11本
　　入れる力　　　いま、閉じて出せる？　　　　 8本

　　出す力　　　　それ、テストでもできる？　　12本
　　なおす力　　　どこで、止まった？　　　　　10本
　　続ける力　　　次の1個目は？　　　　　　　20本
```

まん中が、その力の合言葉です。
右の数字は、この本でその力が出てくる回数です。

全部足すと67。この章の8個を足して、75です。

やり方の列に4つあるのは、やり方がいちばん細かく分かれるからです。
勉強法の本が、やり方の話ばかりになる理由も、ここです。
書くことが、いちばん多いからです。

そして、続ける力の20本がいちばん多い。
正しいやり方を知っても、続かなければ0だからです。

この6つを、次の03から08で、1つずつ出します。

6つとも、10秒で確かめられます。
説明を読む前に、まず自分で1回やってみてください。

## なぜ、あの順番なのか

序章で、順番を出しました。

```
　　① やってはいけないことを、まずやめる
　　② 結果を出している人の、やり方を知る
　　③ その正しいやり方で、量をやる
```

なぜこの順番なのか。掛け算だからです。

掛け算では、いちばん小さい数を大きくするのが、いちばん効きます。

やり方が0.2の人が、量を2倍にしても、0.4です。
2倍になりましたが、かかった時間も2倍です。

同じ人が、やり方を0.2から1に変えると、1です。
5倍になって、かかった時間は増えていません。

これが、巻頭の11個の数字で起きたことです。

あのとき、覚えられる量が増えました。
声に出してもいないし、書いてもいない。努力の量は、むしろ減りました。

小さい数を、直したからです。

---

序章のバケツで言うと、こうなります。

```
　　穴をふさぐ　　→　いちばん小さい数を、0から1にする
　　量を増やす　　→　すでに大きい数を、2倍にする
```

どちらも、同じ努力です。
でも、効き方が5倍ちがいます。

そして、ここで終わる本が多いので、はっきり言っておきます。

穴をふさいだだけでは、バケツはいっぱいになりません。
ふさいだうえで、注ぎます。③は飛ばせません。

## 自分の0は、どれですか

3つ聞きます。

```
　　1　次のテストの範囲表を、いま出せますか。
　　　　出せない　→　戦略が0です。03番から読んでください。

　　2　今日やったことを、教科書を閉じて3つ言えますか。
　　　　言えない　→　やり方が0です。04番から読んでください。

　　3　先週、机に向かった日は何日ありましたか。
　　　　3日以下　→　量が0です。08番から読んでください。
```

3つとも引っかかった人も、いると思います。
そのときは、上から順にやってください。

掛け算なので、どこから直しても効きます。
でも、戦略がいちばん早く効きます。

やらないものが決まると、その日から時間が増えるからです。

## 入る量は、決まっています

1日に使える時間は決まっています。
中高生なら、学校と部活のあとに残るのは、2時間あるかないかです。

その2時間に、5冊を入れようとする。
1冊あたり24分です。24分では、どの1冊も前に進みません。

```
　　図　2時間の横棒を1本

　　上　　1本を5等分。どれも最後まで届いていない
　　下　　1本のまま。1冊が最後まで届いている
　　下に注　終わった＝点になる　／　途中＝0点
```

1冊に絞った人は、2時間をそこに入れます。
5倍の速さで終わります。終わった1冊は、点になります。

終わらなかった5冊は、0点です。
3冊目まで進んでいても、0点です。テストに出るのは、後半かもしれません。

## 捨てるのは、負けではありません

「捨てる」と聞くと、手を抜くように聞こえます。

逆です。

捨てないと、全部が中途半端になる。
中途半端は、0点です。だから、捨てたほうが点が取れます。

頭のいい人は、やる前に捨てています。
机に座ってから「何をやろう」と考えていません。
座る前に、やらないものが決まっています。

```
　　範囲表を見たとき、伸びない人の頭のなか
　　　「えっ、こんなにあるの。とりあえず最初から」

　　同じとき、頭のいい人の頭のなか
　　　「このうち、出ないのはどれだ」
```

## やることは、1つだけ

捨てる作業を、15分でやります。

テスト前でも、模試前でも、受験でも、やることは同じです。

```
　　① 範囲を、紙に全部書き出す
　　② 過去問か、前回のテストを、横に置く
　　③ 1行ずつ「これ、出るの？」と聞いて、出ないものに横線を引く
　　④ 残ったものに、やる順の番号をつける
```

①が大事です。
頭の中にあるうちは、捨てられません。

全部が同じ大きさに見えて、全部が不安だからです。
紙に出すと、はじめて差が見えます。

②は、過去問がなければ、前回のテストでいいです。
先生が同じなら、出し方はだいたい同じです。

③で迷ったら、聞くことは1つです。

```
　　　　　これ、出るの？
```

好き嫌いでも、得意不得意でもありません。
出るか、出ないか。それだけです。

15分です。
この15分が、何十時間かを決めます。

## 「捨てたところが出たら、どうするんですか」

出ます。たまに出ます。

でも、そこは5点です。

5点を捨てて、50点を取る。
それが、捨てるということです。

もう1つ、言っておきます。

捨てるというのは、今日やらない、ということです。
一生やらない、ではありません。

残ったものが先に終わって、時間が余ったら、戻ればいいです。
ただ、だいたいは戻る前に、テストの日が来ます。

それでいいんです。
点になるものから順に、終わっているからです。

# 04　入れるだけで、出さない

　　×「読んだ。わかった。次いこう」
　　○「入れたら、すぐ出す」

---

巻頭では、数字でやりました。

今度は、文章でやります。

ここまで、このページを読んできました。

本を閉じてください。

いま読んだページに書いてあったことを、3つ言ってください。

---

出なかったはずです。

10秒前に読んだばかりなのに、出てこない。
難しい話でもなかったのに、出てこない。

読むのと、出せるのは、別の作業だからです。

---

序章で決めたのは、選び方の基準でした。
やりやすかったか、ではなく、出せたか。

ここから先は、その「出す」の中身です。
何を、どうやって出すのか。

## 読んでいるあいだ、頭は何もしていません

読んでいるとき、目は字を追っています。
字は目から入ってきます。入ってくるので、わかった感じがします。

でも、そのあいだ、頭は何も探していません。
探していないものは、あとで探せません。

```
　　図　本と、頭と、紙を横にならべる

　　上の矢印　本　→　頭　　「入れる」　太い矢印。目を開けていれば起きる
　　下の矢印　頭　→　紙　　「出す」　　細い矢印。自分で探さないと起きない
　　注　テストの日に使うのは、下の矢印だけ
```

テストの日にやるのは、下です。

## 「わかった」は、感想です

読んで「わかった」と思ったとき、あなたが確かめたのは1つだけです。

　　書いてあることが、理解できたかどうか。

確かめていないのは、こっちです。

　　本を閉じたときに、自分の中から出てくるかどうか。

この2つは、別です。
そして、テストで聞かれるのは、2つ目だけです。

```
　　1ページ読み終わったとき、伸びない人の頭のなか
　　　「うん、わかった。次いこう」

　　同じとき、頭のいい人の頭のなか
　　　「いま、閉じて出せる？」
```

## やることは、1つだけ

入れたら、閉じる。閉じてから、出す。

手順は4つです。

```
　　① 閉じる
　　② 3秒、待つ
　　③ 声に出す
　　④ 出なかったら、開いて、その1か所だけ見る
```

①　赤シートではなく、手で隠すか、本を閉じます。
　　赤シートは透けています。目が勝手に拾ってしまいます。

②　すぐ出てこなくていいです。
　　この3秒が、探している時間です。ここで点が決まります。
　　1秒で諦めて開く人は、探していません。

③　小さい声でいいです。頭の中で思い出すのは、なしです。
　　頭の中だと、出たかどうかを自分でごまかせるからです。
　　声は、出なければ止まります。だから、ごまかせません。

④　全部を読み直しません。出なかった1か所だけ見ます。
　　見たら、また閉じて、もう一度出します。

# 06　本番と違う形で、練習する

　　×「解けた。できるようになった」
　　○「テストと同じ形で、やる」

九九の7の段を、逆から言ってください。

7×9、7×8、7×7……

---

止まりましたよね。

九九は、小学校で2000回以上やっています。
寝ていても出てくるはずです。それでも、逆からは出てこない。

量が足りないわけじゃありません。
7の段だけ練習が足りなかったわけでもありません。

上から言う練習しか、していないからです。

## 練習した形でしか、出てきません

人の頭は、練習したとおりの形でしか取り出せません。
形が1つちがうだけで、同じ内容でも出てこなくなります。

```
　　図　7の段を、1本の道として描く

　　上　　上から下への矢印だけが、太く通っている
　　下　　同じ道に、下から上への矢印はない（点線で、切れている）
```

九九を2000回やっても、逆から言う練習を0回やっていれば、逆からは0点です。

## テストの形を、思い出してください

テストの日、あなたはどんな形で出しますか。

```
　　1　解答は、横にない
　　2　時間は、決まっている
　　3　声は、出せない
　　4　誰にも、聞けない
```

では、ふだんの練習はどうですか。

解答を横に置いて、時間を測らず、わからなければすぐめくる。

形が、全部ちがいます。

違う形でどれだけ練習しても、本番では出ません。
九九と、同じです。

```
　　1問解き終わったとき、伸びない人の頭のなか
　　　「解けた。次いこう」

　　同じとき、頭のいい人の頭のなか
　　　「それ、テストでもできる？」
```

## 「できた」は、形とセットでしか意味がありません

解けた、は情報として足りません。

```
　　解答を見ながら解けた　　　　→　本番では出ない
　　時間をかけたら解けた　　　　→　本番では出ない
　　何も見ずに、5分で解けた　　 →　本番でも出る
```

同じ「解けた」でも、残っているものがちがいます。

## やることは、1つだけ

さっきの4つを、1つずつ本番に寄せます。

いちどに4つやると、1問も解けなくなって、やめます。
だから、順番があります。

```
　　1週目　解答を閉じる
　　2週目　時間を測る
　　3週目　手が止まっても、5分は自分で粘る
　　4週目　声を出さずにやる
```

1週目の「解答を閉じる」が、いちばん効きます。
これだけでも、やってください。

2週目は、1問何分かを先に決めて、タイマーを机に置きます。

3週目は、すぐ聞かない、すぐめくらないという練習です。
本番では、誰にも聞けません。粘る力も、練習しないと出ません。

4週目は、声に出して覚えた人のためのものです。
声を使って覚えたなら、1回は声なしで出してみてください。

4週間で、本番の形になります。

そのとおりです。だから、分けます。

```

```

いちばん多いのは、入れる段階をずっと続けてしまう人です。

ずっと解答を見ながらやって、テストの前日に、はじめて閉じる。
そこで出てこなくて、青くなります。

いつ切り替えるかを、先に決めてください。
日付で決めるのが、いちばん簡単です。

# 07　間違えた問題を、もう一度解く

前回のテストで間違えた問題を、1つ思い出してください。

どの教科の、どんな問題でしたか。

---

出てこないはずです。

間違い直しは、やったはずです。
赤ペンで、正しい答えを書いたはずです。

間違い直しでやっているのは、だいたいこれです。

```

　　もう一度、同じ問題を解く
　　解説を、もう一度読む
```

3つとも、その問題を直しています。

でも、次のテストに、その問題は出ません。
似た問題が、形を変えて出ます。

だから、問題を直しても、次に効きません。

## 直すべきなのは、止まった場所です

1つの問題を間違えるとき、全部が間違っているわけではありません。
どこかの1行で、止まっています。

```
　　図　問題文を4行で描く

　　1行目　　読めた
　　2行目　　読めた
　　3行目　　ここで止まった　　←　これが原因（指を置く）
　　4行目　　以降、ついていけない
```

止まったのが3行目なら、直すのは3行目です。
問題ではありません。

そして3行目で止まる人は、別の問題の3行目でも止まります。

だから、場所を直すと、1回で何問ぶんも直ります。

```
　　×がついたとき、伸びない人の頭のなか
　　　「うわ、間違えた。もう一回解こう」

　　同じとき、頭のいい人の頭のなか
　　　「どこで、止まった？」
```

```

　　② 下げていく。「ここまでは分かる」を確かめながら
　　③ 指が止まったところ。そこが、止まった場所です
　　④ その1行だけを、紙に書き写す
　　⑤ そこで初めて、解説を見る。その1行のところだけ
```

④で、問題全部を写さないのが大事です。
1行だけ残すから、あとで見返せます。

## 止まった場所に、名前をつけます

書き写した1行に、1語だけ名前をつけます。

```
　　知らなかった　　言葉・公式・やり方を、そもそも持っていなかった
　　気づかなかった　持っていたのに、使うと分からなかった
```

この2つしかありません。どちらかを選びます。

そして、やることが、まったくちがいます。

```
　　知らなかった　　→　覚える
　　気づかなかった　→　覚えても直りません
　　　　　　　　　　　「このときは、これ」を1行で書く
```

ここを分けずに、全部を「覚える」で直そうとする人が、いちばん多いです。
だから、同じミスが何回も出ます。

## 「全部わからない」は、存在しません

「ここ、全部わからないです」と言う人がいます。

1行目から読めていないことは、まずありません。

その次の1行が、あなたの止まった場所です。

くわしくは、48番に書きました。

10問間違えたとき、10個の原因があるわけではありません。
だいたい、2つか3つです。

```

　　公式を覚えていない　　3問
```

10問を順に直すと、10回かかります。
原因でまとめると、3回で終わります。

さっきの2択で聞いてください。
知らなかったか、気づかなかったか。

どちらか分からないときは、こう聞きます。

```
　　　　　答えを見たとき、知らない言葉はあったか
```

あった　→　知らなかった。
なかった　→　気づかなかった。

これで、必ず分かれます。

# 08　やる気に、頼る

　　×「やる気が出たら、始める」
　　○「やる気がなくても始まる形を、先に作る」

---

先週、「やろう」と思って、やらなかったこと。

1つ、思い当たりますか。

---

ありますよね。

そのとき、やる気はどうでしたか。

なかったわけじゃないはずです。
「やらなきゃ」とは、ちゃんと思っていました。

やる気はあったのに、やらなかった。

これが、やる気をあてにできない理由です。

## やる気は、始めたあとに来ます

順番が、逆になっています。

```
　　図　円を1つ描く

　　×　やる気　→　始める　　（やる気のところで止まっていて、円が回らない）
```

机に座って、1問目を解き始めてから、だんだん乗ってきた。

```
　　数学からにするか、英語からにするか
```

考えています。判断しています。

判断には、力が要ります。
疲れているときほど、その力が残っていません。

だから、座ったのに始められない。

やる気がないんじゃなくて、座ってから判断しているのが重いんです。

```
　　机に座った瞬間、伸びない人の頭のなか

　　　「次の1個目は？」（もう、決まっている）
```

```
　　④ 次の日、座ったら、紙を見て、考えずに始める
```

②が大事です。
2個目まで決めると、また判断になります。

1個目が始まれば、2個目は自然に流れます。

③で、カバンの中に入れないでください。

1個目を決める基準は、1つだけです。

```

```

考えるものは、1個目にしません。

1個目が、重すぎます。

もっと軽くします。

「単語10個」でも重いなら、「単語帳を開く」にします。

開くだけです。それでいいです。
開いたら、だいたい10個やります。

やらなかった日は、自分を責めないでください。
疑うのは、自分ではなく、1個目のサイズです。

