# 12　授業を、聞く時間だと思っている

×「先生の話を、ちゃんと聞いておこう」○「次に何を聞かれるかを、先に考える」

---

5時間目の社会。黒板を見ています。先生の話も、ちゃんと聞いています。ノートも取っています。寝ていません。スマホも見ていません。その日の夜、同じ範囲のワークを開きました。

1問目で止まりました。

## 聞いていなかったわけでは、ありません

ここでよく言われるのが「集中して聞いていなかったからだ」です。でも、本当に聞いていたのです。先生が何の話をしていたかも言えます。ノートにも書いてあります。問題は、聞き方ではありません。聞くという行為そのものが、受け身だということです。

## 音は入ります。出す練習には、なりません

授業の50分で、あなたの頭が何回「出した」か、数えてみてください。当てられたのが1回だとしたら、1回です。あとの49分は、入れているだけです。家で単語を50分やるとき、あなたは何回も書いたり、思い出したりします。授業では、それを1回もやらずに50分が終わります。これが、授業を受けているのにテストで出てこない理由です。入れた量の問題ではなく、出した回数が0に近いという問題です。

## 先に、自分で答える

やることは1つだけです。

先生が問いを出す前に、自分で先に答えを作る。

```
　　先生「ここで大事なのは、なんでしたっけ」
　　　　　　　　↑　この「は」まで聞いた時点で、自分で答えを出す
```

先生の話し方には、くせがあります。「じゃあ」「つまり」「ここ大事」「なんでしたっけ」。この言葉が出たら、次に答えが来ます。来る前に、自分で言ってしまう。心の中で、1秒で。合っていたかどうかは、1秒後に先生が教えてくれます。これで、50分の授業が、50分のテストになります。

## 1コマに3回で、じゅうぶんです

全部の問いに先回りしようとすると、疲れて続きません。1コマに3回でいいです。3回やると、先生の言葉のくせがわかります。わかると、先回りが自動になります。

## これをやると、何が残るか

```
　　授業は、聞く時間ではない。
　　当てられ続ける時間にできる。
```

## この場面のまとめ

```
　　×　先生の話を、ちゃんと聞いておこう
　　○　次に何を聞かれるかを、先に考える
```

入れる力　「いま、閉じて出せる？」

# 14　授業中、当てられないように下を向く

×「間違えたら、恥ずかしい」○「当てられる前に、心の中で答えを出す」

---

先生が、教室を見回しています。目が合わないように、ノートに視線を落とします。少しだけ、鉛筆を動かします。書いているふりです。「じゃあ、前から3番目の人」

ちがった。ほっとします。

## 恥ずかしいのは、当たり前です

間違えたくない気持ちを、なくす必要はありません。40人の前で間違えるのが平気な人のほうが、少ないです。ここで責めたいのは、その気持ちではありません。目を伏せた瞬間に、答えを作るのもやめてしまうことです。

## 当てられるのは、無料のテストです

当てられるというのは、こういう状態です。

```
　　問題が出る　→　時間制限がある　→　人が見ている　→　出さないといけない
```

これは、テストと同じ条件です。それが、1コマに何十回も、無料で来ます。家でこの条件を作るのは、かなり大変です。タイマーを置いて、誰かに見てもらって、声に出す。それを毎日やれる人は、ほとんどいません。授業では、それが勝手に起きています。下を向いた人は、それを1回ずつ捨てています。

## 手を挙げろ、とは言いません

やることは、もっと小さいです。誰が当てられても、自分も心の中で答えを出す。

```
　　先生「じゃあ、○○さん」
　　　　　　↑　ここで、自分も答えを作る。1秒でいい
　　○○さんが答える
　　　　　　↑　ここで、答え合わせが終わる
```

当たらなくていいのです。当たった人の答えが、あなたの丸つけになります。1コマで20回当てられたとしたら、あなたも20回テストを受けたことになります。声に出しているのは1人ですが、答えを作れるのは40人全員です。

## 出てこなかった回を、数えます

心の中で答えを作って、出てこなかった回。これが、あなたのその単元の穴です。ノートの端に、正の字を書いておきます。1コマで5回出てこなかったら、その日の夜は、その単元をやります。テスト前に探さなくても、穴の場所は授業中に全部わかります。

## これをやると、何が残るか

```
　　当てられるかどうかは、先生が決める。
　　答えを作るかどうかは、自分が決める。
```

## この場面のまとめ

```
　　×　間違えたら、恥ずかしい
　　○　当てられる前に、心の中で答えを出す
```

出す力　「それ、テストでもできる？」

# 15　映像授業を、流しながら見る

×「倍速で、どんどん進めよう」○「止めて、自分で言ってみてから再生する」

---

1.5倍速。1コマ30分の授業が20分で終わります。今日は3コマ見ました。1時間で、90分ぶんの授業です。「今日はけっこう進んだ」と思って、寝ます。次の日、そのコマの確認テストで、半分しか取れません。

## 映像授業が悪いのでは、ありません

映像授業は、紙の参考書よりできることが多いです。わからないところを何回でも見られます。先生を選べます。問題は、その最大の利点を、使っていないことです。映像授業にあって、教室の授業にないもの。それは、止められることです。

## 倍速は、入れる速さを上げるだけです

倍速にすると、入る速さは上がります。出す回数は、0のままです。

```
　　1倍速で30分　　出した回数　0
　　2倍速で15分　　出した回数　0
```

時間は半分になりました。身についた量も、半分の0です。進んだ気がするのは、再生バーが右に動いたからです。再生バーは、あなたの頭の中を測っていません。

## 止める場所は、決まっています

全部止めていたら、終わりません。止める場所は、2種類だけです。

```
　1　先生が問題を出した直後
　　　「じゃあ、これ解いてみて」　→　止める。自分で解く

　2　先生が答えを言う直前
　　　「ここで使うのは……」　　　 →　止める。自分で言う
```

この2つだけで、1コマに5回くらい止まります。5回止めるというのは、1コマで5回テストを受けるということです。止めているあいだの時間は、せいぜい1回10秒です。5回で50秒。1コマが30分50秒になります。20分で0回出すより、31分で5回出すほうが残ります。

## 倍速は、2周目から

1周目は等速で、止めながら。2周目は倍速で、止めずに。2周目の倍速は、思い出せているかの確認になります。先生が言う前に自分の頭が言っていたら、入っています。倍速の正しい使い道は、速く入れることではなく、速く確かめることです。

## これをやると、何が残るか

```
　　映像の価値は、速さではない。
　　止められることだ。
```

## この場面のまとめ

```
　　×　倍速で、どんどん進めよう
　　○　止めて、自分で言ってみてから再生する
```

入れる力　「いま、閉じて出せる？」

# 18　小テストを、点が出たら捨てる

×「10点満点の小テストなんて、意味がない」○「小テストは、本番の予告。間違えたものだけ残す」

---

毎週水曜日、英語の小テスト。単語10問。今日は7点でした。返ってきた紙を、カバンの底に入れます。

来週も、たぶん7点です。

## 10点に意味を感じないのは、普通です

成績に入らない小テストを本気で見る中学生は、あまりいません。点が低くても怒られないし、高くても何も起きない。ここで言いたいのは「小テストも大事にしよう」ではありません。小テストの点は、本当にどうでもいいです。どうでもよくないのは、間違えた3問のほうです。

## 小テストは、本番の予告です

小テストの範囲は、どこから出ていますか。

教科書の、今やっている単元です。定期テストの範囲も、同じところです。

```
　　小テストで落とした3問
　　　　　　↓
　　定期テストでも出る3問
```

先生は、わざわざ別の問題を作りません。小テストで出した語は、定期テストでもう一度出ます。つまり、小テストは「ここが出ます」という予告です。予告を見てから本番に行けるテストは、学校の中にしかありません。

## 残すのは、紙ではなく3問です

やることは、1分で終わります。

```
　1　返ってきたら、その場で間違えた語だけ見る
　2　1冊のノートの後ろから、1行ずつ書き写す
　3　テスト用紙は、捨てていい
```

書き写すのは、間違えたものだけです。合っていた7問は、二度と見なくていいです。1回の小テストで3問なら、1学期で12回。36語です。その36語が、あなただけの単語帳になります。市販の単語帳と違って、1語も無駄がありません。全部、自分が実際に落とした語だからです。

## 書き写すときに、やってはいけないこと

赤ペンで正解だけ書き写さないでください。

```
　　×　available　利用できる
　　○　available　利用できる　／　自分は「避けられる」と書いた
```

自分が何と書いたかを、横に残します。これを残しておくと、同じ間違いをしていることに気づきます。avoid と混ざっているなら、直すのは available ではなく、avoid と available を分けることです。

## これをやると、何が残るか

```
　　小テストは、点を取る場所ではない。
　　間違いを集める場所だ。
```

## この場面のまとめ

```
　　×　10点満点の小テストなんて、意味がない
　　○　小テストは、本番の予告。間違えたものだけ残す
```

なおす力　「どこで、止まった？」

# 21　英単語を、1語1訳で覚える

×「available は、利用できる。以上」○「同じ形の仲間を、まとめて見る」

---

単語帳を開いています。

```
　　available　　利用できる
```

覚えました。次へ。

```
　　capable　　　能力がある
```

覚えました。次へ。

1日50語。3日で150語。1週間後、150語のうち40語しか出てきません。

## 1語1訳は、最初は正しいです

単語を覚えはじめたときに、意味を1つに絞るのは正しいです。最初から3つも4つも覚えようとすると、1つも残りません。問題は、1語1訳のまま、1,500語まで行こうとすることです。50語なら、1個ずつでいけます。1,500語を1個ずつは、いけません。

## 1個ずつ入れると、1個ずつしか出てきません

頭の中で、こうなっています。

```
　　available　　→　利用できる
　　capable　　　→　能力がある
　　reliable　　 →　信頼できる
```

3本の線が、別々に引かれています。1本切れたら、その1語は出てきません。同じ形に気づいた人の頭は、こうなっています。

```
　　　　　　　　　　　　　avail（役に立つ）
　　　　　　　　　　　　  cap（つかむ）　　　＋　-able「〜できる」
　　　　　　　　　　　　  rely（たよる）
```

3本が1か所でつながっています。1語思い出せたら、残り2語も一緒に出てきます。

## 新しい語を見たら、10秒だけ考えます

やることは1つです。

新しい語を見たとき、「この形、前にどこで見た？」と1回だけ聞く。

```
　　impossible　　→　im- は前にどこかで見た　→　incorrect、invisible
　　　　　　　　　　　im-／in- は「〜でない」

　　transport　　 →　trans- は前にどこかで見た　→　translate、transfer
　　　　　　　　　　　trans- は「移す」
```

思い出せなかったら、そこで終わりです。10秒まで。思い出せたら、2語か3語が一度に入ります。

## 語源を調べはじめると、沼です

ここで、語源辞典を買ってはいけません。ラテン語まで戻ると、楽しくはなりますが、テストには出ません。戻るのは、自分が前に見た単語までです。判断は簡単です。その説明に、自分がすでに知っている単語が出てこないなら、やめます。

## これをやると、何が残るか

```
　　単語は、1個ずつ覚えると、1個も出てこない。
　　前に覚えた語に、くっつける。
```

## この場面のまとめ

```
　　×　available は、利用できる。以上
　　○　同じ形の仲間を、まとめて見る
```

つなげる力　「これ、前にどこで見た？」

# 26　友達と教え合うのを、おしゃべりで終える

×「一緒にやると、はかどる気がする」○「お互いに、問題を5問ずつ出し合う」

---

テスト1週間前。友達3人で、図書館に集合しました。2時から4時まで、2時間。途中で英語の話をして、昨日のドラマの話をして、またワークに戻りました。楽しかったです。帰り道、今日何ができるようになったかを聞かれても、答えられません。

## 一緒にやるのは、正しいです

1人だとやらない人が、友達となら2時間やる。これは、立派な続ける力です。この項目で止めたいのは、一緒にやることではありません。一緒にいるだけで、出し合っていないことです。

## 「教え合う」は、半分の人しか得をしません

教え合いが起きるとき、だいたいこうなります。

```
　　わかっている人　→　説明する　→　出している　→　伸びる
　　わからない人　　→　聞く　　　→　入れている　→　その場だけ
```

説明した側は、頭の中から引っぱり出しています。聞いた側は、わかった気になって終わります。教え合いという言葉は、両方が得をしそうに見えますが、実際に出しているのは、説明した1人だけです。

## 出し合いに、変えます

やり方を1つ変えるだけです。

```
　1　集まる前に、お互い5問つくってくる
　　　範囲は同じでいい。答えも書いてくる

　2　集まったら、交換して解く　　　　　　10分

　3　答え合わせ。間違えたものだけ説明してもらう　10分

　4　解散
```

合計30分です。2時間ではありません。5問つくるのに、家で10分かかります。問題をつくるときに、範囲をもう1回見ることになります。ここですでに1回、出しています。

## できなかった問題だけ、持って帰る

答え合わせのとき、できた問題の説明は聞かなくていいです。できなかった問題だけ、その場で説明してもらいます。そして、その場でもう1回、自分で解きます。説明を聞いて「わかった」で解散すると、家でまた出てきません。説明されたあと、閉じて、自分で1回解く。ここまでが1セットです。

## これをやると、何が残るか

```
　　並んで座るのは、勉強ではない。
　　出し合ってはじめて、勉強になる。
```

## この場面のまとめ

```
　　×　一緒にやると、はかどる気がする
　　○　お互いに、問題を5問ずつ出し合う
```

出す力　「それ、テストでもできる？」
