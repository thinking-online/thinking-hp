# 47　スマホを、机の上に置いたまま勉強する

　　×「触らなければ、大丈夫」
　　○「別の部屋に置く。一度切れると、戻るのに23分かかる」

---

机の右上に、スマホを置いています。画面は下向きです。

通知も切ってあります。触るつもりもありません。
万が一、親から連絡が来たときのために、置いてあるだけです。

7時から9時まで、2時間やりました。
でも、進んだのは、ワーク3ページです。

## 我慢が足りないのでは、ありません

「触らなければ大丈夫」と思っている人は、実際に触っていません。
2時間で3回くらいしか見ていないはずです。

意志が弱いという話ではありません。

問題は、触った回数ではなく、触ったあとに起きることです。

## 1回切れると、戻るのに23分かかります

集中が切れて、元の深さに戻るまでに、だいたい23分かかると言われています。

これを、2時間に当てはめてみます。

```
　　19:00　　開始
　　19:25　　1回見る（20秒）　→　ここから23分かけて戻る
　　19:48　　やっと元の深さ
　　19:55　　もう1回見る（15秒）　→　また23分
　　20:18　　やっと元の深さ
　　20:40　　もう1回（10秒）　→　また23分
　　21:00　　終了
```

スマホを触っていた時間は、合計45秒です。
深く集中できていた時間は、2時間のうち、30分ほどです。

45秒で、1時間半が削れます。

## 画面を下向きにしても、効きません

机の上にあるだけで、頭の一部がそこを見張っています。
「来ていないか」を確認し続けている状態です。

だから、置き方を工夫しても意味がありません。
距離を変えるしかありません。

```
　　×　机の上に、画面を下にして置く
　　×　引き出しに入れる
　　○　別の部屋に置く
　　○　家族に預ける
```

立ち上がらないと取りに行けない場所。これが基準です。

## 親からの連絡は、先に片づけます

「連絡が来るかもしれないから」は、だいたい本当です。

なので、勉強を始める前に、こう言っておきます。

「9時まで別の部屋に置くから、用があるときは部屋に来て」

これで、スマホを手元に置く理由が、1つもなくなります。

## どうしても手元に置きたい日は

テスト前日など、どうしても連絡を待つ日があります。

その日は、机の上ではなく、自分の背中側に置きます。
振り返らないと見えない位置です。

視界に入らないだけで、見張りの仕事はかなり減ります。

## これをやると、何が残るか

```

　　そのあとの1時間半だ。
```

# 48　集中できないのを、自分のせいにする

　　×「自分は、集中力がないから」
　　○「切れた場所を、1つずつ潰す」

---

今日も、1時間座って、30分しか進みませんでした。

「自分は集中力がないんだ」と思います。
前からそうでした。たぶん、これからもそうです。

そう思ったあと、何をすればいいかは、わかりません。

## 集中力という言葉には、直し方がありません

「集中力がない」は、便利な言葉です。
全部それで説明がつきます。

でも、この言葉を使った瞬間に、やることがなくなります。

```
　　ワークが終わらない　　→　集中力がないから　　→　やることなし
　　単語が覚えられない　　→　集中力がないから　　→　やることなし
```

能力の名前をつけると、話が終わります。
終わるので、来週も同じことが起きます。

## 集中は、切れた場所を見るしかありません

集中が切れるとき、必ず何かが起きています。
何も起きずに切れることは、ありません。

1週間だけ、こうしてみてください。

```
　　机の端に、紙を1枚置く。
　　集中が切れたと思ったとき、そのとき何があったかだけ、1行書く。
```

書くのは原因ではなく、事実だけです。

```
　　19:20　LINEの通知音
　　19:45　英語の長文が読めなくて、いやになった
　　20:10　のどがかわいた
　　20:30　弟がドアを開けた
　　20:50　眠い
```

1週間続けると、20行くらいたまります。

## たまった行は、3種類にしか分かれません

```
　1　外から来たもの　　　通知、音、人、のどのかわき
　2　中で起きたもの　　　わからない、眠い、飽きた
　3　決まっていないもの　次に何をやるか考えていた
```

1は、物を動かせば消えます。
スマホを別の部屋に。水を机に置く。ドアに紙を貼る。

2は、やり方の問題です。
「わからなくていやになった」なら、その単元のレベルが合っていません。
「眠い」なら、51番です。

3は、座る前の問題です。46番で消えます。

## 20行のうち、同じ原因が半分を占めます

実際に書いてみると、だいたい2つか3つの原因が、半分以上を占めます。

集中力がないのではありません。
同じ場所で、毎回切れているだけです。

そして、同じ場所なら、潰せます。

## これをやると、何が残るか

```
　　集中力という力は、直せない。
　　切れた場所は、直せる。
```

## この場面のまとめ

```
　　×　自分は、集中力がないから
　　○　切れた場所を、1つずつ潰す
```

続ける力　「次の1個目は？」

# 49　疲れてから、休憩する

　　×「きりのいいところまで、やろう」
　　○「25分やって、1分で思い出して、5分休む」

---

7時に始めました。

1時間くらいで、少し疲れてきました。
でも、この大問が終わっていません。きりが悪いです。

もう20分がんばりました。

8時20分。やっと区切りがつきました。
休憩します。そのまま、戻れませんでした。

## 最後まで終わらせたいのは、正しい気持ちです

途中でやめるのは気持ち悪い。これは、ちゃんとやる人の感覚です。

ただ、「きりのいいところ」を基準にすると、
休憩の時刻が、毎日ばらばらになります。

ばらばらだと、自分がいつ休むかを、自分で予想できません。
予想できないと、「あと少し」が止まらなくなります。

## 疲れてから休むと、休憩が長くなります

これは、順番の問題です。

```
　　疲れる　→　休む　→　回復に時間がかかる　→　戻れない
　　疲れる前に休む　→　すぐ戻れる
```

疲れきってから座ると、ソファから立てません。
疲れる手前で止めると、5分で戻れます。

休憩は、回復のためではなく、疲れないためにとります。

## 25分やって、1分出して、5分休みます

```
　　25分　　やる
　　 1分　　閉じて、いまやったことを思い出す
　　 5分　　休む
```

真ん中の1分が、この項目の本体です。

25分やったあと、ノートを閉じて、1分だけ思い出します。
紙に書いても、頭の中だけでもいいです。

```
　　いま、何をやったか
　　いちばん大事だったのは、どこか
　　出てこなかったのは、どこか
```

この1分があると、25分が記憶に残ります。
ないと、25分は流れていきます。

休憩の直前は、記憶に残りやすい時間です。
そこに「出す」を置きます。

## 休憩の5分で、やってはいけないこと

```
　　×　スマホを開く
　　×　横になる
　　×　別の教科のことを考える
　　○　立つ。水を飲む。窓の外を見る。歩く
```

スマホを開くと、5分は5分で終わりません。47番の23分が来ます。

## タイマーが鳴ったら、途中でも止めます

大問の途中でも、止めます。

途中で止めると、気持ち悪いです。
その気持ち悪さが、次の25分を始めやすくします。

区切りのいいところで終わると、次に始めるのが重くなります。
途中で終わると、続きからなので軽いです。

## これをやると、何が残るか

```
　　休憩は、疲れたから取るのではない。
　　疲れないために、先に取る。
```

## この場面のまとめ

```
　　×　きりのいいところまで、やろう
　　○　25分やって、1分で思い出して、5分休む
```

続ける力　「次の1個目は？」

# 50　覚えるときも、音楽をかけたままにする

　　×「音楽があったほうが、集中できる」
　　○「言葉を入れるときだけ、音を消す」

---

イヤホンをして、机に向かいます。

音楽があったほうが、はかどります。
静かすぎると、かえって落ち着きません。

今日は英単語を50個やりました。
次の日のテストで、20個しか出てきませんでした。

## 音楽があったほうがはかどるのは、本当です

これは気のせいではありません。

音楽があると、机に向かうまでが軽くなります。
作業のあいだ、飽きにくくなります。
周りの生活音も消えます。

全部、本当の効果です。
だから「音楽をやめなさい」とは言いません。

## 効くものと、効かないものが分かれます

分かれ目は1つです。

いま入れようとしているものが、言葉かどうかです。

```
　　言葉を入れる　　単語、用語、英文、年号、古文　　→　歌詞とぶつかる
　　言葉を使わない　計算、図形、グラフ、丸つけ　　　→　ぶつからない
```

言葉を覚えるときに使っている場所と、
歌詞を聞くときに使っている場所が、同じです。

同じ場所を2つで使うので、どちらも半分になります。

計算や丸つけは、別の場所を使います。だから、ぶつかりません。

## 教科ではなく、作業で分けます

数学なら音楽あり、英語なら音楽なし、ではありません。

数学でも、公式を覚えるときは言葉です。
英語でも、問題を解き直すときは計算に近い作業です。

```
　　音を消す　　　　覚えるとき　読むとき　思い出すとき
　　かけてもいい　　解き直すとき　丸つけ　書き写し　整理
```

## 消せない日は、歌詞のないものに

どうしても無音がつらい日があります。

そのときは、歌詞のない音にします。
日本語でも英語でも、言葉が入っているとぶつかります。

```
　　×　J-POP　洋楽　歌ってみた
　　△　歌詞のないピアノ　環境音　雨の音
　　○　無音
```

無音が落ち着かないのは、慣れの問題です。
1週間、覚える時間だけ無音にすると、慣れます。

そして、テスト会場は無音です。
覚えたときと出すときの音が同じほうが、出てきやすいです。

## これをやると、何が残るか

```
　　音楽をやめる必要はない。
　　言葉を入れる25分だけ、消せばいい。
```

## この場面のまとめ

```
　　×　音楽があったほうが、集中できる
　　○　言葉を入れるときだけ、音を消す
```

# 60　不安なまま、席に座っている

　　×「不安だけど、考えないようにしよう」
　　○「始まる10分前に、不安を紙に書き出す」

---

試験開始の15分前。席に座っています。

参考書を開いていますが、頭に入ってきません。
目は字を追っていますが、別のことを考えています。

落ちたらどうしよう。
あの単元、やってない。
周りの人、みんなできそうに見える。

考えないようにしよう、と思います。
思ったとたん、もっと考えます。

## 考えないようにするのは、いちばん効きません

「考えないようにしよう」は、考えることと同じです。

白いクマのことを考えないでください、と言われると、
白いクマのことを考えます。

不安も同じです。
ふたをしようとすると、ふたのことを考え続けます。

## 不安は、頭の作業場を占領します

試験中、頭の中には作業するための場所があります。
計算を途中まで置いておいたり、問題文を覚えておいたりする場所です。

その場所は、広くありません。

不安が大きいとき、その場所の一部を不安が使っています。
だから、ふだんできる計算でミスをします。

能力が下がったのではなく、場所が狭くなっています。

## 10分前に、紙に出します

やることは、これだけです。

```
　　試験開始の10分前。
　　紙を1枚出して、いま不安に思っていることを、全部書く。
　　5分。きれいに書かなくていい。文にならなくていい。
```

```
　　・数学の図形、やってない
　　・時間が足りなくなりそう
　　・親に何て言おう
　　・前の席の人がペン回ししててうざい
```

書いたら、その紙は閉じてしまいます。
見返さなくていいです。捨ててもいいです。

書き出すと、頭の中にあったものが、紙の上に移ります。
移った分だけ、作業場が空きます。

## 書くのは「対策」ではありません

ここで「じゃあ図形を10分でやろう」としないでください。

10分で図形はできません。
できないことを始めると、不安が増えます。

書くのは、不安そのものです。解決策ではありません。

## 書いたあと、1つだけやることがあります

紙を閉じたら、最後に1つ書きます。

```
　　今日、確実に取れるのは、どこか
```

1つでいいです。「漢字の読み」でも「英語の並べかえ」でもいいです。

試験が始まったら、まずそこから解きます。
62番と同じことです。

## これをやると、何が残るか

```
　　不安は、消さなくていい。
　　頭から紙に、移せばいい。
```

## この場面のまとめ

```

　　○　始まる10分前に、不安を紙に書き出す
```

# 61　緊張したときに、落ち着こうとする

　　×「落ち着け、落ち着け」
　　○「これは興奮だ、と言いかえる」

---

試験開始の1分前。

心臓が速くなっています。手が少し冷たいです。
息が浅くなっているのが、自分でわかります。

落ち着け、落ち着け、と心の中で言います。

言うたびに、落ち着いていない自分に気づきます。
余計に焦ります。

## 落ち着こうとするのは、遠いところを目指しています

いまのあなたの体は、心拍数が上がっています。

落ち着くというのは、心拍数を下げるということです。
上がっているものを、1分で下げるのは、無理があります。

無理なことをやろうとして、できなくて、焦る。
焦るので、もっと上がる。

## 緊張と、やる気は、体の上では同じです

ここが、この項目のいちばん大事なところです。

```
　　緊張　　心臓が速い　手が冷たい　息が浅い　体が熱い
　　興奮　　心臓が速い　手が冷たい　息が浅い　体が熱い
```

体に起きていることは、同じです。

違うのは、それを自分が何と呼んでいるかだけです。

```
　　「やばい、緊張してる」　　→　体は敵
　　「よし、来てる」　　　　　→　体は味方
```

## 言いかえます

落ち着こうとするかわりに、こう言います。

```
　　これは興奮だ。
　　体が、本気を出す準備をしている。
```

声に出さなくていいです。心の中で3回。

心拍数は下がりません。下げる必要がありません。
心拍数が上がっているほうが、頭は速く回ります。

変えるのは、体ではなく、呼び方です。

## 体を落ち着ける方法も、1つだけ持っておきます

呼び方を変えても、息が苦しいときがあります。

そのときは、吐くほうを長くします。

```
　　4秒で吸って、8秒で吐く。
　　これを3回。
```

吸うときは速くなり、吐くときは遅くなります。
だから、吐くほうを長くすると、全体が落ち着きます。

ただし、これは苦しいときだけです。
心臓が速いだけなら、そのままでいいです。

## 当日の朝から、使えます

言いかえは、会場に着く前から使えます。

```
　　電車の中で、そわそわする　→　「来てる」
　　会場で、手が冷たい　　　　→　「来てる」
　　開始1分前　　　　　　　　 →　「来てる」
```

1日に10回使うと、本番の1回で自然に出ます。

## これをやると、何が残るか

```
　　緊張は、止めなくていい。
　　名前を変えれば、味方になる。
```

## この場面のまとめ

```
　　×　落ち着け、落ち着け
　　○　これは興奮だ、と言いかえる
```

続ける力　「次の1個目は？」
