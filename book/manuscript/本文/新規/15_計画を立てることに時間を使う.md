# 15　計画を立てることに、時間を使う

×「ちゃんと計画を立ててから、始めたい」○「計画は10分。超えたら、立てるのをやめて始める」

---

日曜の夜8時。来週の計画を立てはじめました。ノートを開いて、曜日を書きます。教科を並べます。englishは何ページまで、数学は何問。書いているうちに、量が多すぎることに気づきます。消します。並べ直します。火曜は部活の試合があるかもしれない。土曜は模試かもしれない。どっちに転んでもいいように、2パターン作ります。

気づくと、10時でした。

2時間です。その2時間で、問題は1問も解いていません。

## 計画は、終わらない作業です

問題を解く作業には、終わりがあります。20問やれば終わりです。計画には、終わりがありません。==正解がないからです。==もっといい配分があるかもしれない。この順番でいいのか。来週の予定が変わったらどうするか。考えはじめると、いくらでも考えられます。そして、考えているあいだは、気持ちがいいです。前に進んでいる感じがします。手も疲れません。頭も、問題を解くほどは疲れません。

```
　　計画を立てる　　終わりがない。疲れない。進んだ感じがする
　　問題を解く　　　終わりがある。疲れる。進んだかどうかは、出してみないと分からない
```

人は、上を選びます。

## 10分で切ります

やることは1つです。

　　タイマーを10分にして、鳴ったら書けたところで始める。

1週間の計画が10分。1日の計画は2分です。10分で足りないのは、決めなくていいことまで決めようとしているからです。

```
　　いま決めること　　　　　明日の1つ目と、今週やらないもの
　　いま決めなくていいこと　木曜の3時間目に何をやるか
　　　　　　　　　　　　　　予定が変わったときのBプラン
```

木曜のことは、水曜の夜に決めれば間に合います。

## やり方

### 1　タイマーを10分にしてから、ノートを開く

開いてから測りはじめると、もう5分たっています。先に押します。

### 2　書くのは、3つだけ

```
　　今週、やらないもの
　　今週、終わらせるもの　1つ
　　明日の1つ目
```

それ以外は書きません。木曜の3時間目に何をやるかは、水曜の夜に決めれば間に合います。

### 3　鳴ったら、書けたところで始める

途中でもやめます。足りないところは、やりながら埋まります。

## 計画は、机の上では完成しません

ここが大事なところです。

立てた計画は、どうせ1日目で崩れます。13番で書いたとおり、崩れることは例外ではなく、毎週起きることです。==机の上で完璧にしても、崩れ方は変わりません。== 変わるのは、計画に使った時間だけです。計画は、実行しながら直すものです。2時間かけて完璧なものを作るより、10分で7割のものを作って、1週間使いながら直すほうが、結果として正確になります。

## これをやると、何が残るか

```
　　2時間かけた計画も、10分で立てた計画も、1日目で崩れる。
　　違うのは、残り1時間50分を何に使ったかだけ。
```
