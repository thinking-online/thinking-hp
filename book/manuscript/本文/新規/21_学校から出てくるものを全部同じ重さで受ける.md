# 21　学校から出てくるものを、全部同じ重さで受ける

×「出された以上、全部ちゃんとやらないと」○「受ける前に、終わったとき何ができているかを聞く」

---

高校2年生の火曜日。

その日、学校から出てきたものを並べます。数学の課題プリント2枚。英語の小テスト（明日）。理科のレポート（金曜提出）。古典の予習（明日の授業で当たる）。放課後に、受験補習の案内が配られました。希望制です。

全部やると、夜11時までかかります。

自分でやろうと決めていた英語の長文は、1問も開けませんでした。次の日も、同じです。

## 量を足し算した人が、いません

当たり前のようで、見落とされているところです。

数学の先生は、数学のことだけを考えて課題を出します。英語の先生も、理科の先生も同じです。それぞれが「これくらいなら妥当だ」と思う量を出しています。

その5つを足した人は、==どこにもいません。==

だから、全部を同じ重さで受けると、必ずあふれます。あふれるように設計されています。誰も悪くありません。足し算する人がいないだけです。

足し算するのは、あなたです。

## 「捨てる」と「手を抜く」は、別です

ここを混ぜると、いちばん損をします。

```
　　捨てる　　やらないと決める。時間が丸ごと空く
　　手を抜く　やりながら、中身を薄くする。時間は減らない
```

手を抜くのが、いちばんもったいないやり方です。1時間かけて、何も身についていない。でも「やった」という記録は残るので、捨てた罪悪感もありません。

答えを写して提出する課題は、写す時間はかかっています。頭は使っていません。==いちばん高い買い物です。==

## 3つに分けます

学校から出てくるものを、3つに分けます。

```
　1　出さないと困るもの　　提出物、赤点を避けるための最低限
　　　　　→　いちばん短い方法で終わらせる。中身は求めない

　2　点につながるもの　　　受験や、自分が伸ばすと決めた教科のもの
　　　　　→　自分の勉強として扱う。閉じて出すところまでやる

　3　どちらでもないもの
　　　　　→　受けない
```

1と2を混ぜないことが、全部です。

1は「終わらせる作業」です。きれいにやる必要がありません。2は「できるようになる作業」です。終わらせても、できていなければ意味がありません。

## 受ける前に、1つだけ聞きます

3かどうかを見分ける質問が、1つあります。

　　これが終わったとき、何ができるようになっていますか。

補習でも、講習でも、追加の問題集でも同じです。

答えが返ってこない、または返ってきた答えが自分に要らないものなら、3です。

```
　　「共通テストの形式に慣れる」　　　→　共テを使うなら2。使わないなら3
　　「苦手な人向けに基礎を復習する」　→　その単元が苦手なら2。違うなら3
　　「とりあえず受けておいたほうが」　→　3
```

先生に直接聞きにくければ、シラバスか案内の紙を見てください。たいてい書いてあります。書いていないものは、3の可能性が高いです。

## 頭のなか

### 案内をもらったとき、伸びない人

「補習か」「みんな取るのかな」「取らないと不安だな」「とりあえず出しとくか」

### 同じとき、頭のいい人

「補習、週2回。1回90分。月に12時間か」「この12時間で、何ができるようになる?」（案内を見る）「『共通テスト対策演習』……自分は共テ使わないな」「じゃあ3だ。出さない」「空いた12時間で、英語の長文を24本やろう」受けるかどうかを決めたのではありません。==12時間の使い道を決めています。==

## やり方

### 1　1週間ぶん、全部書き出す

月曜から金曜まで、学校から出てきたものを全部1行で書きます。たいてい、12個から18個あります。多さに驚くはずですが、それが事実です。

### 2　1・2・3の番号をつける

迷ったら、さっきの質問をします。1分で決めます。

### 3　3には、手をつけない

断る必要がないものは、ただ受け取って置いておきます。断る必要があるもの（補習の申し込みなど）だけ、出さない。

### 4　1は、最短で終わらせる方法を決めておく

答えを写すかどうかは、あなたと学校の関係で決まります。ここでは決められません。ただ、==1に時間をかけるのがいちばん損だ==ということだけは、決まっています。

## 「それは逃げになりませんか」

いちばんよく聞かれます。

逃げかどうかは、捨てたかどうかでは決まりません。==空いた時間を何に使ったかで決まります。==

```
　　補習を断って、その12時間で寝た　　　　　　→　逃げ
　　補習を断って、その12時間で長文を24本　　　→　選択
```

同じ「断る」でも、別のことです。

だから、3に番号をつけたときは、その時間に何を入れるかを同時に決めてください。決めないまま空けると、本当に逃げになります。

## これをやると、何が残るか

1日が、2時間長くなります。

全部を同じ重さで受けている人は、1日の終わりに「学校のものは終わったけど、自分の勉強は0だった」という日を作ります。週に3日それがあると、週6時間が消えます。

分けた人は、1を30分で終わらせて、残りを2に使います。やった量は同じです。どこに当たったかが違います。

## この場面のまとめ

学校から出てくるものは、足し算されていない。足すのは自分。
1（終わらせる）と2（できるようになる）を混ぜないこと。

　　この場面を見つけた問い　　これ、出るのか？

今日やること今週、学校から出てきたものを全部1行で書き出す。1・2・3の番号をつける。
