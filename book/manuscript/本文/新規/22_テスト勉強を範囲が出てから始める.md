# 22　テスト勉強を、範囲が出てから始める

×「2週間前から本気を出せば、間に合う」○「範囲は、授業のその日にもう決まっている」

---

定期テストの2週間前。範囲表が配られました。数学はワークの32ページから58ページ。英語は教科書の Lesson 5 と 6。理科は化学反応式の単元。計画を立てます。1日4ページずつやれば、7日で1周できる。そのあと2周目。きれいな計画です。でも、授業は止まりません。範囲表が出たあとも、新しい単元が進みます。部活もあります。課題も出ます。結局、最後の3日で詰めることになります。3日で27ページをやると、どうなるか。1問も止まれません。止まらずにやるということは、==見ながらやるということです。==

## 範囲表は、新しい情報ではありません

ここに気づくと、話が変わります。

範囲表に書いてあるのは何でしょうか。

　　授業でやったところ。

それだけです。3週間前に習ったところから、先週習ったところまで。あなたは全部、その場にいました。つまり、==範囲は2週間前に決まったのではなく、授業のその日に決まっています。== 範囲表は、それを紙にしただけです。

待つ理由が、ありません。

## 2週間前に始めると、覚え直しになります

もう1つ、大きい問題があります。2週間前に初めてワークを開くと、そこに書いてあるのは「3週間前に習ったこと」です。26番で書いたとおり、覚えたことは時間がたつと出にくくなります。ある時点を過ぎると、見ても思い出せなくなります。3週間は、その時点を過ぎています。

```
　　2週間前に初めて開く　　→　もう一度、覚え直す
　　授業の日に15分やる　　 →　まだ残っているうちに、確認する
```

同じ範囲です。かかる時間が、3倍から5倍ちがいます。

## 授業の日に、15分

やることは1つです。

　　その日の授業でやったところを、閉じて、白紙に出す。

教科書とノートを閉じます。白紙に、今日やったことを書きます。図でも、式でも、用語でも、何でもいいです。

3分です。

出てこなかったところだけ、教科書を開いて確認します。これで10分から15分。1日に授業が5つあっても、全部はやりません。==その日いちばん重い教科を1つだけ==です。1日15分、1週間で75分。

## 2週間前には、何をやるのか

ここで、やることが変わります。毎日15分やってきた人は、2週間前の時点で「出なかったところ」のリストを持っています。範囲全体ではありません。たいてい、全体の2割くらいです。

```
　　毎日やっていない人　　2週間で　27ページを覚え直す
　　毎日やっている人　　　2週間で　5ページぶんの穴を埋める
```

2週間前からやるのは、勉強ではありません。==確認です。==そして、確認なので、2週間かかりません。だから、残りの時間を自分の勉強に使えます。

## 頭のなか

### 範囲表をもらった日、伸びない人

「2週間前か」「まだ余裕あるな」「来週から本気出すか」（カバンにしまう）

### 同じ日、頭のいい人

「範囲、32から58ページ」「……これ、9月に習ったところからだ」「9月のぶん、いま出せるか?」（閉じて、1ページぶん書いてみる）「……半分も出ない」「じゃあ今日から、授業の日に15分やろう」「今日の授業は化学だったな。化学反応式、閉じて書いてみる」範囲表を見て、過去を確認しています。未来の計画を立てていません。

## やり方

### 1　今日の授業から、1つ選ぶ

いちばん重い教科を1つ。全部やると続きません。

### 2　閉じて、白紙に出す。3分

きれいに書かなくていいです。思い出せたものを、思い出せた順に書きます。

### 3　出なかったところだけ、開いて確認する

全部読み直さないでください。出なかったところだけです。

### 4　出なかったものを、1行メモする

　　「化学反応式の係数合わせ、出なかった」

これが、2週間前に見るリストになります。

## 範囲表が出てからでも、間に合わせたい日のために

今回のテストが、もう10日後だという人もいると思います。その場合は、過去には戻れません。やることは1つです。

```
　　範囲を全部やろうとしない。
　　10番のやり方で、3周できる量だけ選ぶ。
```

そして、次のテストから、授業の日の15分を始めてください。1回の定期テストぶん先行すると、それ以降がずっと楽になります。

## これをやると、何が残るか

テスト前の2週間が、空きます。毎日15分やった人は、2週間前に「穴が5ページぶん」という状態で立っています。埋めるのに3日です。残りの11日は、受験勉強でも、苦手教科でも、好きに使えます。やった総量は、たぶん同じです。==いつやったかが違うだけです。==

## この場面のまとめ

範囲表は新しい情報ではない。範囲は授業のその日に決まっている。2週間前に始めると覚え直しになる。授業の日に15分なら、確認で済む。

　　この場面を見つけた問い　　今日、何個増えた？

今日やること今日の授業でいちばん重かった教科を1つ選ぶ。閉じて、白紙に3分出す。
