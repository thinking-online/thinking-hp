# 41　場所を変えずに、同じ机で粘る

×「家で集中できないのは、自分の問題」○「切れたら、場所を1つ変える」

---

家の机。7時に座りました。8時の時点で、進んだのは30分ぶんです。スマホは別の部屋に置きました。音楽も消しました。それでも、気づくと止まっています。

「家だと集中できない」

そう思いながら、同じ机に座り続けています。移動するのが面倒だからです。

## 場所にも、くせがつきます

同じ場所で同じことをくり返すと、その場所とその状態が結びつきます。ベッドの上で30分だらだらした日が続くと、ベッドに座っただけで頭がゆるみます。逆に、図書館の同じ席でいつも集中できていた人は、その席に座るだけで入れます。家の机が「集中が切れる場所」になっているなら、==そこで粘っても、切れ方は変わりません。==これは、意志の問題ではありません。場所の問題です。

## 違う場所で覚えると、残る量も変わります

ついでに、もう1つ。

同じ単語リストを、2つの違う部屋で1回ずつ覚えたグループと、同じ部屋で2回覚えたグループを比べた実験があります。あとで思い出せた量は、==2つの部屋で覚えたグループのほうが多くなりました。==覚えたものは、場所ごと記憶されます。1つの場所でしか覚えていないと、その場所の手がかりがないと出てきません。試験会場は、あなたの机ではありません。

## 3分で行ける場所を、2つ持つ

やり方は3つです。

### 1　移動先を、先に2つ決めておく

切れてから探すと、探すだけで15分かかります。先に決めます。3分以内で行ける場所がいいです。

```
　　家の中　　リビングのテーブル、台所、階段
　　家の外　　図書館、コンビニのイートイン、学校の空き教室
```

家の中でも効きます。部屋を変えるだけで違います。

### 2　切れたら、移動する。粘らない

切れたと気づいたら、そこで動きます。「あと10分やってから」は、その10分が丸ごと消えます。

### 3　移動するときは、1つだけ持つ

全部持っていかないでください。持てるぶんだけにすると、やることが勝手に絞られます。

```
　　×　カバンごと移動して、何をやるか迷う
　　○　単語帳1冊だけ持って出る
```

## 移動しないほうがいい場合

1つだけあります。

==わからなくて止まっているとき==です。これは場所の問題ではありません。レベルが合っていないか、手前が抜けています。35番の話です。眠い、飽きた、気が散る。これは場所で動きます。わからない。これは動きません。

## これをやると、何が残るか

```
　　集中できる場所がないのではない。
　　切れた場所に、座り続けているだけ。
```

```

　　○　切れたら、場所を1つ変える
```
