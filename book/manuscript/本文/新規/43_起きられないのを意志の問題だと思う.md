# 43　起きられないのを、意志の問題だと思う

×「気合いが足りないから、起きられない」○「起きる工夫ではなく、寝る時刻を1つ変える」

---

6時にアラームをかけました。鳴りました。止めました。次のアラームが6時10分に鳴ります。止めました。6時20分。止めました。気づいたら、7時半でした。寝たのは11時半です。7時間半、寝ています。足りていないわけではありません。それでも起きられません。「意志が弱いんだ」と思います。冷たいシャワーを試しました。アラームを部屋の反対側に置きました。3日は続きました。4日目から、歩いて止めて、また寝るようになりました。

## 起きるのは、いちばん意志が弱い瞬間です

ここを押さえてください。

起きる工夫は、全部「起きる瞬間に、意志でなんとかする」設計です。でも、起きる瞬間のあなたは、1日のうちでいちばん判断力が落ちています。寝起きの頭は、数十分かけて立ち上がります。その状態の自分に、重い判断をさせています。==いちばん弱いタイミングに、全部を賭けている。== だから続きません。

## 動かすのは、寝る側です

起きる時刻は、起きる瞬間には決められません。でも、==寝る時刻は、まだ起きている自分が決められます。==そして、眠りの深さは、寝入った時刻でだいたい決まります。遅く寝た日は、同じ7時間半でも浅くなります。浅い眠りから起きるのは、きついです。

```
　　×　起きる時刻を、起きる瞬間の自分に守らせる
　　○　寝る時刻を、起きている自分が決める
```

## 15分ずつ、動かします

いきなり1時間早くしないでください。寝られません。

### 1　いま何時に寝ているかを、3日記録する

「11時半に寝ている」と思っていても、実際は12時20分ということがよくあります。ベッドに入った時刻ではなく、スマホを置いた時刻を書きます。

### 2　15分だけ、早くする

1週間、同じ時刻で寝ます。慣れたら、また15分。1ヶ月で1時間動きます。

### 3　アラームを1個に減らす

5個かけている人は、==1個目で起きない前提で脳が動いています。== 1個にすると、そこで起きるしかなくなります。ベッドから3歩の場所に置いてください。遠すぎると、歩いて止めて戻るという儀式になります。

### 4　起きたら、カーテンを開ける

これだけは、起きた瞬間にやります。1秒です。光が入ると、頭が立ち上がる速さが変わります。

## どっちの問題かを、先に分ける

判断は1つです。

```
　　7時間以上寝ていて起きられない　→　寝る時刻の問題。15分ずつ動かす
　　6時間以下しか寝ていない　　　　→　量の問題。42番を先に読む
```

量が足りていない人が寝る時刻をいじっても、何も変わりません。

## これをやると、何が残るか

```
　　起きる意志は、鍛えられない。
　　寝る時刻は、今日から動かせる。
```
