# 47　不安なまま、手を動かさずに考え続ける

×「このやり方で合ってるのか、不安で手がつかない」○「不安は紙に出して、10分だけ手を動かす」

---

夜の10時。参考書を開いています。

目は字を追っています。でも、頭は別のことを考えています。

　　このやり方で、合ってるのかな。
　　もっといい方法があるんじゃないか。
　　これ、点につながってるのかな。時間かけてるだけじゃないのか。
　　このままで、間に合うのかな。

1時間たちました。3ページ進んでいます。

勉強していなかったわけではありません。机にいました。参考書も開いていました。それでも、頭は1時間ずっと、答えの出ない問いを回していました。

## 不安は、答えが出ない形をしています

ここが、いちばん大事なところです。

「このやり方で合ってるのか」という問いに、いま答えは出ません。

やってみて、テストを受けて、点を見るまで出ないからです。出ないものを考え続けると、==考えるだけで終わります。==

そして、考えているあいだは勉強している感じがします。真剣だからです。だから、止まっていることに気づけません。

```
　　答えが出る問い　　「この問題の答えは?」　　　→　解けば出る
　　答えが出ない問い　「このやり方は正しい?」　  →　やってみるまで出ない
```

下の問いを机の前で回すと、時間だけが減ります。

## 不安が強い人ほど、まじめです

先に言っておきます。

サボっている人は、不安になりません。やり方が合っているか気になるのは、結果を出したいからです。そして、ここまで気にする人は、実際にちゃんとやっています。

==不安は、手を抜いていない証拠です。== ただ、置き場所が悪いだけです。

## 「考えないようにしよう」は、効きません

49番でも書きますが、ここでも同じです。

白いクマのことを考えないでください、と言われると、白いクマのことを考えます。不安も同じで、ふたをしようとすると、ふたのことを考え続けます。

消そうとするのではなく、==場所を変えます。==

## 紙に出して、10分だけ手を動かす

やることは、これだけです。

```
　1　紙を1枚出して、いま不安なことを全部書く　　　　5分
　　　きれいに書かない。文にならなくていい

　2　書いたら、その紙を裏返す
　　　見返さない。捨ててもいい

　3　タイマーを10分にして、いちばん軽いものを1つやる
　　　単語10個。計算3問。漢字10個

　4　10分たったら、もう一度その紙を見る
```

4が大事です。

10分前に書いた不安を見ると、==大きさが変わっています。== 気のせいではありません。理由があります。

　　手を動かす前の不安は「全部」が対象です。
　　手を動かしたあとの不安は「残り」が対象になります。

10分ぶんだけ、対象が減っています。そして、減ることが分かると、次の10分に入れます。

## 不安の種類で、やることが変わります

書き出した紙を見ると、3つに分かれます。

```
　1　やり方が合っているか不安
　　　　→　10分やって、閉じて出せたかを見る。出せたら合っている

　2　間に合うか不安
　　　　→　数字にする。あと何週間、1週間に何点

　3　落ちたらどうしようと不安
　　　　→　これは答えが出ない。書き出して、裏返す
```

1と2は、手を動かすと答えが出ます。3は、出ません。

3を1や2と同じように考え続けるから、終わらなくなります。==3は、解決するものではなく、置いておくものです。==

## 頭のなか

### 夜10時、伸びない人

「このやり方で合ってるのかな」「もっといい方法あるんじゃ」「調べてみるか」（スマホで勉強法を検索する）「……いろいろ書いてあるな」「どれが正しいんだ」（1時間経過）

### 同じ夜10時、頭のいい人

「また不安が来たな」「……これ、考えても答え出ないやつだ」（紙を出す）「間に合うか不安、やり方が不安、落ちたら怖い」（3つ書いて、裏返す）「10分だけやる。単語30個」（タイマー）（10分後）「30個のうち、22個出た」「……合ってるかどうかは、出せたかで分かるのか」「じゃあ合ってる。続けよう」不安は消えていません。でも、10分ぶん進んでいます。

## やり方

### 1　止まっていることに、気づく

同じページを2回読んでいたら、それが合図です。目が字を追っていて、中身が入っていない状態です。

### 2　そこで閉じて、紙を出す

勉強を中断することになりますが、もう中断しています。認めるだけです。

### 3　5分で書いて、裏返す

対策は書きません。不安そのものを書きます。

### 4　10分、いちばん軽いものをやる

重いものを選ばないでください。不安なときに重いものを開くと、また止まります。

## それでも動けない日のために

正直に書きます。

ここまでのやり方は、「不安だけど、やろうとは思える」状態のためのものです。

涙が出て止まらない。眠れない日が続く。何日も机に向かえない。そういう日があるなら、それは勉強のやり方の問題ではありません。==先に、人に言ってください。==

親でも、学校の先生でも、塾の人でも、誰でもいいです。言いにくければ、紙に書いて渡すだけでもいいです。

僕も、浪人の年に動けなくなった時期がありました。あのとき動けるようになったのは、やり方を変えたからではありません。1人、笑わずに聞いてくれる人がいたからです。

勉強の話は、そのあとで間に合います。

## これをやると、何が残るか

1日が、1時間長くなります。

不安なまま机にいた1時間は、勉強時間として記録されます。でも、進んでいません。週に5回あれば、5時間が消えます。

紙に出した人は、5分使って、残りの55分を手に使います。==不安は消えていません。場所が机の上から紙の上に移っただけです。==

それで、じゅうぶんです。

消そうとせず、紙に出して裏返す。10分だけ手を動かすと、対象が「全部」から「残り」に変わる。
