# 60　他人と比べて、落ち込む

×「あの子はもう8割。自分は何をやってるんだろう」○「比べる相手は、先週の自分」

---

休み時間。前の席で、友達が話しています。「模試どうだった？」「んー、まあまあ。8割くらい」まあまあ、と言っています。自分の結果は、鞄の中にあります。5割でした。判定はEでした。その日は、家に帰ってから何もできませんでした。自分は、毎日やっています。あの子が遊んでいるときも、やっていました。

それでも、3割違います。

　　やっぱり、向いてないのかもしれない。

そう思いました。

---

これを書いているのは、同じことを経験した人からの手紙を、何百通も読んできたからです。その中の1通に、こうありました。「自分は努力してるのになんでこんなに低いんだろうと悩んで、泣いたりしていました」まず言いたいのは、これです。

その感覚は、正しいです。

実際に差があるし、実際に悔しい。気にするな、というのは無理です。無理なことを言っても、意味がありません。

だから、別の話をします。

## 見えないものと、比べています

あの子の8割は、いつからの結果ですか。

今日できたことではありません。小学校から今日までの、積み上げの結果です。自分の5割も、同じです。今日までの積み上げです。つまり、比べているのは、お互いの「これまで全部」です。これまで全部は、今日どうにもなりません。どうにもならないものを比べているので、何回比べても同じ結論になります。そして、もっと大事なことがあります。あの子が、先月から何点上がったのかは、見えません。下がっているかもしれません。見えているのは、あの子の点だけ。変化は、見えません。見えないものと比べているから、終わらないのです。

## 比べること自体は、悪くありません

よく「人と比べるな」と言われます。無理です。教室に人がいるかぎり、比べます。比べないようにしよう、というのは、やり方ではありません。やるのは、比べる相手を変えることです。

　　先週の自分。

これなら、変化が見えます。しかも、自分で動かせます。

```
先週　52点
今週　58点
　　　6点、上がっている
```

あの子の6点前がどこだったかは、わかりません。でも、自分の6点前は、はっきりわかります。

## 「でも、追いつかない」

ここで、こう思うはずです。

　　先週より6点上がっても、あの子には追いつかない。

その通りです。1週間では、追いつきません。ただ、計算してみてください。受験まで、あと何週間ありますか。仮に30週あるとします。

```
1週間に2点ずつ上げる
　30週で　60点
```

いま3割の差があっても、届く可能性が出てきます。これは、気休めで言っているのではありません。見るものを変えると、計算できるようになる、という話です。「あの子との差」は、計算できません。「1週間に何点上げるか」は、計算できます。計算できるものだけが、行動に変わります。

## 落ち込んだ時間は、0点です

ここは、少し冷たいことを言います。比べて落ち込んだ1時間に、1問も解いていません。これは、責めているのではありません。落ち込むな、とも言いません。落ち込みます。言いたいのは、落ち込む時間を短くしたほうが得だ、ということです。そして、短くする方法が1つあります。落ち込んだときに、やることを決めておきます。

　　先週の自分の点を、見る。

これだけです。紙でも、スマホのメモでもいい。先週の自分が、どこにいたかを見ます。1分で終わります。そして、落ち込んでいる状態から、計算できる状態に戻ります。

## 頭のなか

### 友達の会話を聞いたあと、伸びない人

「8割か……」「自分は5割」「毎日やってるのに」「やっぱり才能なのかな」（鞄にしまう。家で何もしない）

### 同じとき、頭のいい人

「8割か。すごいな」「……で、自分は先週から何点上がった？」（前回の成績表を出す）「前回52、今回58。6点か」「上がってる」「あの子、先月から何点上がったんだろう」「……わかんないな。見えない」「見えないものと比べても、どうしようもないか」「6点上がった理由は？　英語の長文で、設問を先に読むようにした」「じゃあ次は、数学でも同じことをやろう」8割の子のことは、途中で考えるのをやめています。考えても、何も出てこないからです。

## やり方

### 1　前回の自分の点を、すぐ出せるところに置く

成績表をファイルの奥にしまわないでください。スマホのメモに、点数だけ書いておくのでもいいです。

```
6月　48
9月　52
11月　58
```

3行あれば十分です。

### 2　落ち込んだら、それを見る

落ち込まないようにする、ではありません。落ち込んだあとの手順を、決めておきます。

### 3　上がった理由を、1つ書く

6点上がったなら、何か変えたはずです。それを1行書きます。書けなかったら、たまたま上がっただけかもしれません。それもわかったほうがいいです。

### 4　残りの週数で、割る

```
目標まで　あと60点
残り　　　30週
1週間で　2点
```

この数字を出すと、見るものが「あの子」から「2点」に変わります。

## 下がったのは、やり方です。人ではありません

比べる相手を変えても、先週の自分に負ける日があります。

模試が返ってきて、前回より20点下がっていました。この2ヶ月、前よりやったのに下がりました。やっぱり自分には向いてないのかもしれない。その日は、勉強できませんでした。

点が下がったとき、考えられることは2つです。やり方が合っていなかったか、その回がたまたま難しかったか。==どちらも、やり方か問題の話です。人の話ではありません。== でも下がった瞬間に出てくる言葉は、たいてい人の話です。向いてない、頭が悪い、才能がない。これを言っても、次にやることが1つも決まりません。

いちばんの問題は、責めると成績表を見なくなることです。見るとつらいので、ファイルにしまって開かなくなる。どこで落としたかが分からないまま、次も同じところで落とします。==責めることが、直すのを止めています。==

だから、質問の形に変えます。「自分がダメだ」を「どこが下がった?」に。質問にすると、人から場所に移ります。見るのは総合点ではなく大問ごとです。英語マイナス12、数学マイナス15、国語プラス7。言葉が「向いてない」から「長文が落ちた」に変わります。長文が落ちたなら、長文を見ればいい。向いていない、にはやることがありません。

そして、国語は上がっています。20点下がったという見方をすると、この7点は見えません。上がったところには理由があって、その理由はほかの科目にも使えます。

やり方が悪かったこともあります。その場合も、責める必要はありません。この本にある50のうち、1つを変えてみてください。==やり方は変えられます。人は、変えなくていいです。==

## 「できない」で終わると、次が出てきません

落ち込んだあと、口から出る言葉が決まっています。面談でいちばんよく聞く言葉です。

　　「自分、数学できないんで」

この言葉を言った瞬間に、話が終わります。できないのだから、やってもしょうがない。やらないので、できないままになる。言葉のとおりになります。

日本語として見てください。「自分は、数学ができない」は、完結した文です。終わった文には続きがありません。続きがないので、次にやることも出てきません。

1語足します。

　　自分は、数学が、まだできない。

この文は終わっていません。「まだ」と言った瞬間に、いつできるのか、という続きが必要になります。

これはポジティブに考えようという話ではなく、==言葉が、探す範囲を決めている==という話です。「数学ができない」で、何を探しますか。探すものがありません。数学は大きすぎます。「二次関数の最大値が、まだ出せない」なら、教科書のそのページを開けばいい。

実際に言ってみると、違和感が出ます。全部できないわけではないからです。計算はできる。基本問題も解ける。だから言い直したくなります。==「まだ」を足すと、自動的に範囲が狭くなります。== ポジティブになるからではなく、正確になるからです。

逆も気をつけてください。「英語はできる」も終わりの形です。終わっているので確認しません。30番の話です。「いまのところ出せている」なら、確認する余地が残ります。

人に聞くときにも効きます。「数学、全然できないんですけど」では相手も答えられません。「二次関数の場合分けが、まだ出せないんですけど」なら、3分で答えが返ってきます。35番と同じで、聞き方で返ってくるものが変わります。

## これをやると、何が残るか

落ち込んでいる時間が、短くなります。完全になくなることは、ありません。教室で8割の声を聞いたら、やっぱりきついです。でも、1日止まっていたのが、1時間になります。その差が、1年で大きくなります。そして、もう1つあります。比べる相手を変えると、勝てるようになります。あの子には、1年かけても勝てないかもしれません。でも、先週の自分には、今週勝てます。勝った回数が増えると、人は続けられます。第1章で書いた、小さく勝つ、というのはこれのことです。

## この場面のまとめ

比べているのは、お互いの「これまで全部」。今日どうにもならないもの。相手の変化は見えない。見えないものと比べるから、終わらない。比べるのをやめるのではなく、相手を先週の自分に変える。

　　この場面を見つけた問い　　今日、何個増えた？

今日やることこれまでの模試かテストの点を、3つだけスマホのメモに書く。落ち込んだときに、それを見る。
