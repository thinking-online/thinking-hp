# 40　ケアレスミス、次は気をつける、で終える

気をつけるというのは、気持ちです。気持ちは、テスト中の40分、持ちません。とくに、焦っているときには消えます。そして、計算ミスは、焦っているときに出ます。

```

写し間違える

```

どれも、原因が違います。対策も違います。全部を「ケアレスミス」と呼んでいるかぎり、1つも直りません。

「気をつける」が効かないのは、それが気持ちだからです。気持ちは、テスト中の40分、持ちません。とくに焦っているときには消えます。そして計算ミスは、焦っているときに出ます。名前をつけると、気持ちが手順に変わります。

```
　　「符号を落とす」　→　負の数で割ったあと、符号だけもう一度見る
```

手順は、焦っていても実行できます。10秒で終わるからです。直っているのは、注意力ではありません。==手順が1つ増えただけです。==

## 3回出たものだけ、対策する

全部のミスに対策を作ると、手順が増えすぎます。同じ名前が3回出てきたものだけ、対策します。テストを3回分見れば、わかります。たいてい、2つか3つに集中しています。その2つか3つだけ、手順を足します。

# 41　10個の間違いを、10問とも順に直す

×「全部つぶさないと、不安」○「同じ原因のものを、1つにまとめる」

---

模試が返ってきました。数学で、10問落としています。1問目から、直していきます。1問目。解説を読んで、解き直す。20分。2問目。同じく20分。3問目。20分。10問で、200分です。3時間半かかります。途中で、集中が切れます。7問目あたりから、解説を読むだけになります。そして、次の模試でも、同じくらい落とします。

## 10個の間違いに、原因は10個ありません

落とした10問を並べてみると、原因は3つか4つに集まっています。符号のミス　　　　　　3問因数分解ができない　　3問問題文の読み違い　　　2問時間切れ　　　　　　　2問

4つです。

10問を順に直すと、符号のミスを3回直すことになります。同じことを、3回やっています。4つにまとめると、4回で済みます。

## 原因でまとめると、別のものが見えます

もっと大事なことがあります。1問ずつ直していると、気づかないことがあります。因数分解で3問落としている、という事実です。1問ずつ見ると、それぞれ別の問題に見えます。大問2と大問4と大問6。単元も違います。でも、止まっている場所は同じです。因数分解です。これは、1問ずつ直しているかぎり、見えません。並べて、原因を書き出したときに、はじめて見えます。

## 因数分解を直すと、3問が同時に消えます

原因でまとめると、直す対象が変わります。1問ずつ直す人は、大問2の解き方を覚えます。原因でまとめる人は、因数分解を直します。因数分解を直すと、3問が同時にできるようになります。しかも、次の模試に出る、まだ見たことのない因数分解の問題にも効きます。1個直して、3個以上が消えます。

## 頭のなか

### 模試を直すとき、伸びない人

「10問落ちてる」「1問目から直そう」（解説を読む。解き直す）「次、2問目」

### 同じとき、頭のいい人

「10問落ちてる。まず、原因を書き出そう」（10問ぶん、1行ずつ書く）「大問1(2)　符号」「大問2(1)　因数分解できず」「大問2(3)　因数分解できず」「大問3(1)　問題文の読み違い」「……」（書き終わる）「因数分解が3つ。符号が3つ。読み違いが2つ。時間切れが2つ」「因数分解からやろう。3問ぶんだ」「因数分解の基本問題、20問やる」10問を直すのではなく、4つの原因を直しています。

## やり方

### 1　落とした問題を、全部1行で書き出す

問題番号と、止まった原因。それだけです。

　　「大問2(1)　因数分解でつまった」

10問なら、10行です。5分で書けます。

### 2　同じ原因のものを、くくる

線で囲むか、同じ印をつけます。たいてい、3つか4つのグループになります。

### 3　いちばん数が多いグループから、直す

直すのは、その問題ではありません。原因のほうです。因数分解が3問なら、因数分解の基本問題をやります。模試の問題は、最後に解き直して確認するだけです。

### 4　1グループ終わったら、該当する問題を解き直す

因数分解を直したあと、大問2と4と6を解き直します。たいてい、解けます。

## なぜ、原因でまとめると速くなるのか

10問を1問ずつ直すと、同じ説明を3回聞くことになります。符号のミスが3問あれば、「符号に気をつけよう」と3回思います。思っただけです。手順は、1つも増えていません。原因でまとめると、3問が1つの対策になります。対策は手順なので、テスト中にも実行できます。

```
　　×　気をつけようと、3回思う
　　○　手順を1つ足して、3問が同時に消える
```

そして、その手順は次の模試にも効きます。1問ずつ直した人は、その10問だけができるようになります。

## 1問しかないグループは、後回し

1問しか落ちていない原因は、優先度が低いです。たまたまかもしれません。時間が余ったら、やります。

## 1問ずつ直すと、なぜ次に効かないのか

1問ずつ直すと、直っているのは==その1問だけ==です。大問2の(1)を解き直して、解けるようになりました。でも、次の模試に大問2の(1)は出ません。出るのは、同じ因数分解を使う別の問題です。原因でまとめた人は、因数分解そのものを直しています。だから、==まだ見たことのない問題にも効きます。==

```
　　1問ずつ　　10問直して、10問できるようになる
　　原因ごと　　4つ直して、その4つを使う全部の問題ができるようになる
```

テストの日。

問題が、順番に並んでいません。1次方程式の次に、いきなり図形が出ます。

## 順番にやると、考えなくて済みます

1章を順に解いているとき、頭は何をしているか。

1番が1次方程式でした。だから、2番も1次方程式だろうと思っています。

実際、そうです。

つまり、2番を見たとき、「これは何の問題か」を考えていません。もう、わかっているからです。テストでは、ここを考えないといけません。

これを決めるのが、いちばん難しいところです。順番に解いている人は、ここを1回も練習していません。

## 混ぜたほうが、残ります

混ぜると、解くのがしんどくなります。正答率も下がります。やっていて、気持ちよくありません。でも、あとまで残るのは、混ぜたほうです。これは、調べられていることです。同じ種類の問題を続けて解くより、混ぜて解くほうが、あとのテストの点が高くなります。気持ちよくないほうが残る、というのは、この本でずっと出てきている話と同じです。

## 新しく覚えるときは、混ぜません
