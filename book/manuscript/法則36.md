# 法則36　さかのぼる力

## 右ページ

さかのぼる力　36
場面タグ　模試の直しを始める前

### Q

間違いが10個。数える？分ける？

### 状況文

高校2年生。模試が返ってきた。英語で10問間違えていた。
10問を、1問目から順番に解き直そうとしている。
全部やると、3時間かかりそう。
今日は日曜で、時間はある。

### HINT

10個の間違いに、10種類の原因がありますか。

## 左ページ

### 分かれ道

| | 伸びない人 | 伸びる人 |
|---|---|---|
| すること | 10問を順番に直す | 10問を3種類に分ける |
| 数えているもの | 直した問題の数 | 原因の種類の数 |
| 図の上では | 10本の×から10本戻る | 3つの箱に3本戻る |
| 試験の日に | また同じ10問分を落とす | 3種類ごと消えている |

### 伸びない人の答え

10問を順番に直す。
全部間違えたのだから全部直す、というのは正しい判断です。
3時間かけて10問直したが、同じ種類のものを何度も直していた。次の模試でも、同じ10問分を落とす。

### 伸びる人の答え

直す前に、10問を原因の種類で分ける。
知らなかったもの、3問。わかっていたのに出せなかったもの、5問。読み違えたもの、2問。
種類ごとに、手当てが違います。
知らないものは覚える。出せないものは白紙で解き直す。読み違いは、読む手順を決める。
3つ直せば、10問が動く。

### 法則36

間違いは数えず、種類で分ける

### 他の場面で

定期テスト。教科ごとではなく、原因の種類ごとに並べ直す。
英語。間違いを、単語・文法・読み方の3つに分けてから手をつける。

### 結論

同じ3時間で、伸びない人は10問を直し、伸びる人は10問の元になった3つを直す。

### 隅の図

完全版を小さく置く。伸びない人の道は灰色で、10本の×から10本戻る。伸びる人の道は赤で、3つの箱に3本戻る。
