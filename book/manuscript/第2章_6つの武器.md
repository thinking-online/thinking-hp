# 第2章　頭のいい人が持っている、6つの武器

前の章で、3つの問いを渡しました。

```
　　始める前　　　　これ、出るのか？

　　やっている間　　いま、閉じて出せるか？

　　終わったあと　　今日、何個増えた？
```

この章でやるのは、まん中を4つに割ることだけです。
新しく覚えるものは、1つもありません。

---

## なぜ、まん中を割るのか

「閉じて、出す」は正しいです。
序章で書いたとおり、いちばん効果が高いやり方です。

ただ、机の前に座っているとき、これだけでは手が動きません。

```
　　英単語をやっている　　　→　何を閉じる？　　単語帳
　　解説を読んでいる　　　　→　何を閉じる？　　解説
　　前にやった問題と似てる　→　何を閉じる？　　……？
　　同じミスをくり返す　　　→　何を閉じる？　　……？
```

下の2つには、閉じるものがありません。
でも、どちらも「出す」が必要な場面です。

だから、まん中を4つに割ります。
割ると、どの場面でも、やることが1つに決まります。

---

## 6つの武器

```
　　　　　　結果　＝　戦略　×　やり方　×　量
　　　　　　　　　　　 │　　　 │　　　　│
　　　　　　　　　　選ぶ力　　入れる力　続ける力
　　　　　　　　　　　　　　 つなげる力
　　　　　　　　　　　　　　 出す力
　　　　　　　　　　　　　　 なおす力
```

1つずつ見ます。
どれも、2行です。やらないことと、やること。

---

## 選ぶ力

```
　　全部やろうとすると、1つも終わらない
　　　　　　　　→　捨ててから、始める

　　　　　　　「これ、出るの？」
```

前の章の1つ目の問いが、そのまま武器になります。

テスト範囲が30ページあって、2週間しかない。
全部に手をつけた人は、全部が中途半端で終わります。
7ページに絞った人は、7ページが点になります。

戦略というのは、やることを決めることではありません。
やらないことを決めることです。

この本では11個の場面で出てきます。

---

## 入れる力

```
　　入れるだけでは、入らない
　　　　　　　　→　入れたら、すぐ出す

　　　　　　　「いま、閉じて出せる？」
```

前の章の2つ目の問いが、そのまま武器になります。

教科書を見ながらノートを作る。
解説を読んで納得する。
映像授業を倍速で見る。

どれも、入れています。出していません。

入れたものが残っているかどうかは、閉じるまでわかりません。
閉じてはじめて、入っていたかどうかが決まります。

この本では8個の場面で出てきます。

---

## つなげる力

```
　　1個ずつ覚えると、1個も出てこない
　　　　　　　　→　前にやったものに、くっつける

　　　　　　　「これ、前にどこで見た？」
```

ここから先の4つは、前の章には出てきませんでした。

単語を1語1訳で覚える。
似ている3つを、3つとも丸ごと覚える。
初めて見る問題を、ゼロから考える。

全部、頭のなかに線を1本ずつ引いています。
1本ずつだと、1本切れたらそこは出てきません。

前にやったものにくっつけると、1本思い出せば、まわりも一緒に出てきます。

この本では5個の場面で出てきます。

---

## 出す力

```
　　テストと違う練習は、練習じゃない
　　　　　　　　→　テストと同じ形で、やる

　　　　　　　「それ、テストでもできる？」
```

解答を横に置いたまま解く。
時間を測らずに解く。
頭のなかで言えたから、覚えたことにする。

どれも、テストと形が違います。

テストの日、横に解答はありません。時間は決まっています。
声に出して確かめることもできません。

練習とテストの形が違うと、練習でできたことが、テストで出ません。

この本では10個の場面で出てきます。

---

## なおす力

```
　　直すのは、問題じゃない。場所
　　　　　　　　→　どこで止まったかを、探す

　　　　　　　「どこで、止まった？」
```

間違えた問題に、赤で正解を写す。
解けなかった問題を、もう一度そのまま解く。
ケアレスミス、次は気をつける、で終える。

全部、その問題を直しています。
直すべきなのは、その問題ではありません。

同じ場所で止まる人は、別の問題でも同じ場所で止まります。
問題を100問直しても、場所を直さないかぎり、101問目でまた止まります。

この本では10個の場面で出てきます。

---

## 続ける力

```
　　やる気は、あてにならない
　　　　　　　　→　やる気がなくても始まる形にする

　　　　　　　「次の1個目は？」
```

前の章の3つ目の問いが、形を変えたものです。

「今日、何個増えた？」を毎日聞くには、毎日やっている必要があります。
だから、毎日やる形をつくるのが、この武器の仕事です。

やる気が出るのを待つ。
机に座ってから、何をやるか決める。
計画が崩れてから、作り直す。

全部、始めるときに判断をしています。
判断をするから、重くなります。

判断を、前の日に済ませておく。
座ったら、考えずに1個目を始める。

この本では18個の場面で出てきます。
6つのなかで、いちばん多いです。
やり方を知っても、続かなければ0だからです。

---

## 手持ち、6本

```
　　　選ぶ力　　　　「これ、出るの？」　　　　　　　11

　　　入れる力　　　「いま、閉じて出せる？」　　　　 8

　　　つなげる力　　「これ、前にどこで見た？」　　　 5

　　　出す力　　　　「それ、テストでもできる？」　　10

　　　なおす力　　　「どこで、止まった？」　　　　　10

　　　続ける力　　　「次の1個目は？」　　　　　　　 18
```

右の数字は、この本でその武器を使う場面の数です。合計62。

順番はありません。1番から6番まで通すものでもありません。

6つ全部を、毎回使うわけでもありません。
1つの場面で使うのは、だいたい2つです。

迷ったときは、入れる力と出す力。
この2つは、やることが同じです。閉じること。

---

## 類書が埋めているのは、まん中だけです

前の章で、勉強法の本を読んでも変わらなかった人の話を書きました。
理由は、この図で言えます。

```
　　　　　　　戦略　　　　やり方　　　　　量

　　類書　　　　　　　　　●●●●
　　この本　　　●　　　　●●●●　　　　●
```

世の中の勉強法の本は、まん中の列に集中しています。
覚え方、解き方、ノートの取り方。

この本は、62のうち29、つまり半分近くが、
まん中ではなく、左と右の列の話です。

やり方だけ直しても伸びなかったのは、
やり方が間違っていたからではありません。
かけ算の、別の列が0だったからです。

---

## まず、この6つ

62全部を、いますぐやる必要はありません。

1つの武器から1つずつ、今日からできて、1週間で結果が出るものを選びました。

```
　選ぶ力　　　　29　設問を先に見る

　入れる力　　　20　見て、隠して、出す

　つなげる力　　22　なぜ？　を1回だけ、自分に聞く

　出す力　　　　32　解説を閉じて、白紙に解き直す

　なおす力　　　42　どの作業で落としたか、名前をつける

　続ける力　　　46　座る前に、1つ目だけ決めておく
```

この6つで1週間やってから、残りを読んでください。

---

## ここから先の読み方

ここから先は、7つの章と終章に分かれています。
章は、あなたが困っている場面で分けてあります。

```
　　第3章　計画編　　　「計画どおりに、いきません」
　　第4章　授業編　　　「授業は、受けているんですけど」
　　第5章　暗記編　　　「覚えても、すぐ忘れます」
　　第6章　演習編　　　「解説を読んでも、できません」
　　第7章　復習編　　　「同じミスを、くり返します」
　　第8章　集中編　　　「集中が、続きません」
　　第9章　気持ち編　　「モチベが、出ません」
　　終章　　本番編　　　「本番で、力が出ません」
```

最初から順に読まなくていいです。
いま困っている章を開いて、その項目だけ読んでください。

巻末に、悩み別の索引をつけました。
「覚えてもすぐ忘れる」なら、20番と24番と27番です。

62の項目には、それぞれ右肩に武器の名前が書いてあります。
読み進めるうちに、同じ武器が何度も出てきます。

それは、同じ手が何度も効くという意味です。

62個のやり方を覚える本ではありません。
6本の武器を、62回使ってみる本です。
