絶対法則02　思い出す
覚える訓練ではなく、思い出す訓練をする

## 導入文

01番で、こう書きました。

「3回目を読む時間があるなら、その時間で、もっと点につながることができます」

その「もっと点につながること」が、2つ目の絶対法則です。

結果を出している人を何人も並べると、やり方は、ばらばらに見えます。

```
　　声に出して覚える人
　　白紙に書き出す人
　　人に説明する人
　　歩きながら、頭の中で言う人
```

でも、全員が、同じことをやっています。

　　==教材を閉じて、何も見ずに、思い出している。==

これは、誰か1人の勝ち方ではありません。僕が2000人以上の生徒を見てきて、結果を出した人に共通していたことです。

頭のいい人の絶対法則、2つ目。「思い出す」を、具体的に見ていきましょう。

## 質問ページ

今読んだページを閉じて、書いてあったことを、3つ言えますか？

## 本文

本を、閉じてみてください。

今読んだページに書いてあったことを、3つ、言ってみてください。

……

出てこなかったはずです。

10秒前に読んだばかりなのに、出てこない。難しい話でもなかったのに、出てこない。

安心してください。それが普通です。==読むのと、思い出すのは、別の作業==だからです。

## 読んでいる間、頭は何も探していません

読んでいる時、目は字を追っています。字が入ってくるので、わかった感じがします。

でも、その間、頭は何も探していません。一度も探したことがないものは、テストの日にも、探し出せません。

```
　　図　本と、頭と、紙を横に並べる

　　本　→　頭　　「入れる」　　　目を開けていれば、起きる
　　頭　→　紙　　「思い出す」　　自分で探さないと、起きない
```

テストの日に使うのは、下の「思い出す」だけです。教科書は、開けません。

巻頭で、11個の数字を覚えてもらいましたよね。あの時、最後に何をしましたか。

本を伏せましたよね。

伏せたから、言えるかどうかがわかりました。伏せなかったら、ずっと「たぶん覚えた」のままでした。

　　==覚える訓練ではなく、思い出す訓練をする。==

これが、2つ目の絶対法則です。（英語では「アクティブリコール」と呼ばれています。覚えなくてOKです）

## 「わかった」は、感想です

読んで「わかった」と思った時、あなたが確かめたのは、1つだけです。

　　書いてあることが、理解できたかどうか。

確かめていないのは、こっちです。

　　本を閉じた時に、何も見ずに言えるかどうか。

この2つは、別です。そして、テストで聞かれるのは、2つ目だけです。

## 【朗報】同じ時間でも、1週間後に残る量が変わります

これは、実験で確かめられています。

ワシントン大学の実験です。学生に同じ文章を勉強してもらって、2つのグループに分けました。

```
　　1　4回、繰り返して読む
　　2　1回読んで、あとの3回は、何も見ずに思い出して書く
```

勉強した直後のテストでは、1のグループのほうが、点が高くなりました。

ところが、1週間後にもう一度テストをすると、逆になります。==2のグループのほうが、大きく上でした。==

使った時間は、同じです。差がついたのは、読んだ回数ではなく、思い出した回数です。

01番で、「3回目と4回目に使った時間は、丸ごと消えている」と書きました。その時間を、思い出すことに使えばいいんです。

## 問題集の解説を読んだあとも、同じです

間違えた問題の、解説を読みます。

　　「なるほど、そういうことか」

納得して、次の問題に進みます。3日後、同じ問題が、また解けません。

理由は同じです。解説を読んだだけで、何も見ずに解くことを、1回もやっていないからです。

「なるほど」と思ったら、解説を閉じて、今読んだ解き方を、何も見ずにもう一度書いてみてください。書けたら、覚えています。書けなかったら、まだ読んだだけです。

## 練習でやっていないことは、本番ではできません

テストの日にやるのは、思い出すことです。

だから、普段の勉強の中に、「何も見ずに思い出す」時間を入れます。読む時間を減らして、思い出す時間を増やす。

==勉強の時間の半分以上を、本を閉じている時間にしてください。==

## 「3つも出てきません」という人へ

1つでいいです。

0でなければ、頭は探しています。大事なのは、言えた数ではなく、閉じたかどうかです。

時間がかかる、と思うかもしれません。かかります。1ページあたり、20秒ほど増えます。10ページで、およそ3分です。でも、閉じずに10ページ読んでも、あとには、ほとんど残りません。

## 頭のいい人と伸びない人の違い

伸びない人

読んだ。わかった。次！

頭のいい人

## 今日からできる3STEP

STEP01
1ページ読んだら、本を閉じる
「読み返したい。でも、閉じる」

STEP02
3秒待って、書いてあったことを3つ、声に出す
「1つ目は……えーと」
※3つ＝見出し／一番大事だと思った1文／自分が知らなかったこと。頭の中で言うのは、なしです。声は、出なければ止まるので、ごまかせません

STEP03
出なかった1か所だけ見て、また閉じて言う
「ここか。もう1回、見ないで」

できた基準
次の日、開く前に、同じ3つが言えたらOK！

## まとめ

読んだ回数ではなく、思い出した回数で決まる。

```
　　1　読むのと、思い出すのは、別の作業
　　2　「わかった」は、理解できただけ。言えるかどうかは、まだ確かめていない
　　3　4回読むより、1回読んで3回思い出すほうが、1週間後に残る
```

だから、読んだら、閉じる。
迷ったら、自分に聞きます。「今、何も見ずに言える？」
