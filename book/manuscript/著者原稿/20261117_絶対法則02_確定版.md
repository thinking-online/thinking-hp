絶対法則02　思い出す
覚える訓練ではなく、思い出す訓練をする

## 導入文

5時間、勉強した日の夜。ふと、思います。

「今日って、何を勉強したっけ」

……出てこない。

テストの日も、同じです。沢山やったはずなのに、解けない。

勉強時間は、足りています。ちゃんと、追い込めています。でも、==頭に、残っていない==んです。

では、結果を出している人は、何が違うのか。

```
　　声に出して覚える人
　　白紙に書き出す人
　　人に説明する人
　　歩きながら、頭の中で言う人
```

先生や、合格した先輩に聞くと、やり方は、ばらばらに見えます。でも、全員が、同じことをやっています。

　　==何も見ずに、思い出す。==

僕が2000人以上の生徒を見てきて、結果を出した人に共通していたことです。そして、科学的にも、効果が高いと確かめられている方法です。「アクティブリコール」と呼ばれています。（名前は、覚えなくてOKです）

頭のいい人の絶対法則、2つ目。「思い出す」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「何度も読む」
じゃあ、何をするの？

## 本文

## 「きれい」を、漢字で書けますか？

紙とペンを、用意してください。

　　きれい

これを、漢字で書いてみてください。

……

書けましたか。

答えは、「綺麗」です。

毎日のように、スマホで打っている言葉です。「きれい」と打てば、候補に「綺麗」が出てきます。見れば、すぐにわかる。迷わず選べる。

それなのに、何も見ずに書こうとすると、手が止まります。

　　==見ればわかる。でも、何も見ずには、書けない。==

覚えていないわけでは、ありません。頭の中には、入っています。足りないのは、思い出す練習です。

そして、テストの日、教科書は開けません。自分の頭から、思い出すしかありません。

## どっちが、勉強していると思いますか？

同じ参考書を使っている、2人がいます。

```
　　A　1週間で、100ページ進んだ
　　B　1週間で、300ページ進んだ
```

ほとんどの人が、Bと答えます。同じ1週間で、3倍進んでいるからです。

意地悪な答えですが、僕の答えは「これだけでは、わからない」です。

勉強には、2つあります。

```
　　入れる　　　　　　　　読む、聞く、覚える
　　思い出して取り出す　　何も見ずに、言う、書く、解く
```

点になるのは、2つ目ができるようになった分だけです。

300ページ読んでも、本を閉じたら何も言えないなら、点にはなりません。100ページでも、閉じて言えるなら、それは点になります。

```
　　どれだけ読んだか、ではない。
　　どれだけ思い出せるようになったか。
```

「勉強した」の意味を、今日から、こっちに変えてください。

## 【研究結果】同じ時間の勉強でも、1週間後に残る量が変わる

繰り返し読むのと、何も見ずに思い出すのと。どちらが、あとまで残るのか。

それを確かめた、ワシントン大学の実験があります。学生に同じ文章を勉強してもらって、2つのグループに分けました。

```
　　1　4回、繰り返して読む
　　2　1回読んで、あとの3回は、何も見ずに思い出して書く
```

勉強した直後のテストでは、1のグループのほうが、点が高くなりました。

ところが、1週間後にもう一度テストをすると、逆になります。==2のグループのほうが、大きく上でした。==

使った時間は、同じです。差がついたのは、読んだ回数ではなく、思い出した回数です。

01番で、「3回目と4回目に使った時間は、丸ごと消えている」と書きました。その時間を、思い出すことに使えばいいんです。

## なぜ、みんな「読む」ほうを選ぶのか

何度も読む。ノートにまとめる。やっている時は、気持ちがいいんです。スラスラ進むし、ページも進みます。

思い出すほうは、逆です。

　　「え、全然覚えてないやん」

できていない自分を、毎回、見ることになります。頭も、すごく使います。きついです。

だから、ほとんどの人が、読むほうを選びます。

でも、最後の試験で勝つのは、きついほうを毎日やってきた人です。

なぜ、きついほうが効くのか。次の絶対法則03で、説明します。

## 机に座っている時だけが、勉強ではありません

思い出すのに、教科書もノートも要りません。

```
　　歯をみがきながら、30秒。さっきやったことを、思い出す
　　授業が終わったら、休み時間に入る前に、1分。今日の話を、何も見ずに思い出す
　　問題集の解説を読んだら、閉じて、今読んだ解き方を、もう一度書く
```

どれも、立派な勉強です。

目安は、==勉強の時間の半分以上を、本を閉じている時間にする==ことです。

## 1分前に読んだこと、思い出せますか？

では、今、やってみてください。

本を、閉じます。指をはさんで、閉じるだけでいいです。

この項目で、ここまでに読んできたことを、さっと思い出してください。いくつ、言えますか。

もう1つ。1つ前の絶対法則01「疑う」には、何が書いてありましたか。

……

どうでしたか。

1分前まで読んでいた内容です。難しい話でもありません。それでも、いざ思い出そうとすると、出てこない。01番は、もっと出てこなかったかもしれません。

5時間勉強した日の夜と、同じことが、今、起きました。==「読んだ」と「思い出せる」は、別のこと==なんです。

答え合わせです。

```
　　絶対法則01　疑う
　　　1　読み返す、まとめる、線を引く。みんながやっている3つは、効果が低い
　　　2　先輩が受かった理由は、本人にもわからない
　　　3　やってはいけないことをやると、誰がやっても結果は出ない

　　絶対法則02　思い出す（ここまで）
　　　1　「きれい」を、漢字で書けない
　　　2　100ページ進んだ人と、300ページ進んだ人
　　　3　4回読む人と、1回読んで3回思い出す人
　　　4　読むのは気持ちいい。思い出すのは、きつい
　　　5　歯みがきの30秒。授業のあとの1分
```

出てこなかったものだけ、そのページに戻って、見てください。全部は、読み直しません。

今やったことが、そのまま、このあとの3STEPです。

## 頭のいい人は、「思い出す」回数を、とにかく増やしています

ここまでが、2つ目の絶対法則です。そして、6つの中でも、中心にある法則です。

この先、頭のいい人のやり方を、場面ごとに見ていきます。授業の受け方。ノートの取り方。単語の覚え方。間違えた問題の直し方。

やっていることは、ばらばらに見えます。でも、よく見ると、ほとんどが同じことをしています。

　　==どうやって、「思い出す」回数を増やすか。==

```
　　授業中に、思い出す　　　　　　　　　　　　07番
　　ノートを閉じて、思い出す　　　　　　　　　08番　13番
　　間をあけて、もう一度思い出す　　　　　　　05番　16番
　　答えを見たあとに、閉じて、思い出す　　　　18番
```

頭のいい人は、特別な方法を、50個も知っているわけではありません。「思い出す」を、あらゆる場面でやっているだけです。

だから、50個を全部は覚えられなくても、「思い出す」だけは、持っていってください。

## 頭のいい人と伸びない人の違い

伸びない人

読んだ。わかった。次！

頭のいい人

## 今日からできる3STEP

STEP01
1ページ読んだら、本を閉じる
「読み返したい。でも、閉じる」

STEP02
3秒待って、書いてあったことを3つ、声に出す
「1つ目は……えーと」
※3つ＝見出し／一番大事だと思った1文／自分が知らなかったこと。3つ出なくても、1つでいいです。頭の中で言うのは、なしです

STEP03
出なかった1か所だけ見て、また閉じて言う
「ここか。もう1回、見ないで」

できた基準
次の日、開く前に、同じ3つが言えたらOK！

## まとめ

「どれだけ読んだか」ではなく、「どれだけ思い出せるか」で決まる。

```
　　1　見ればわかる、と、何も見ずに書ける、は別の力
　　2　4回読むより、1回読んで3回思い出すほうが、1週間後に残る
　　3　この本のやり方のほとんどは、「思い出す」回数を増やすためのもの
```

だから、読んだら、閉じる。
迷ったら、自分に聞きます。「今、何も見ずに言える？」
