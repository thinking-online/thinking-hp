## 導入文

数学の問題集を、開きます。

1問目、解けました。2問目も、解けました。3問目も、スラスラ解けました。30分で10問、全部○です。

　　「調子いい。このやり方、自分に合ってる」

気持ちよく、ノートを閉じます。

さて、この30分で、新しくできるようになったことは、いくつあるでしょうか。

　　==0個です。==

10問とも、始める前から解けた問題だったからです。

02番の最後で、「なぜ、きついほうが効くのか」と書きました。その答えが、3つ目の絶対法則です。

頭のいい人の絶対法則、3つ目。「負荷」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「自分に合った勉強法」
じゃあ、何をするの？

## 本文

## 「1＋1」と「17×23」。頭を使ったのは、どっちですか？

次の2つを、暗算でやってみてください。

```
　　1＋1
　　17×23
```

……

1つ目は、考える前に、答えが出たはずです。

2つ目は、「うーん」と、止まったはずです。答えが出なくても、大丈夫です。（答えは、391です）

2つ目をやっている時、頭が動いている感じが、しませんでしたか。

その感じが、「負荷」です。

1＋1を1万回やっても、連立方程式は、解けるようになりません。頭が強くなるのは、止まっている時だけです。

## 1キロのダンベルを100回上げても、筋肉はつきません

筋トレで、考えてみてください。

1キロのダンベルを、100回上げます。楽です。汗もかきません。そして、筋肉はつきません。筋肉がつくのは、「重い」と感じる重さを、上げた時だけです。

頭も、同じです。

```
　　スラスラ解ける　　→　もう、できること。何回やっても、増えない
　　うーん、と止まる　→　まだ、できないこと。ここだけが、増える
```

　　==「うーん」と止まっている時間だけが、勉強です。==

02番の実験を、思い出してください。繰り返し読むグループは、楽だったはずです。何も見ずに思い出すグループは、きつかったはずです。1週間後に勝ったのは、きついほうでした。

## 正直に書きます。正しいやり方は、疲れます

本を閉じて、「なんだっけ」と思い出す。わかったと思ったら、何も見ずに、白紙で解いてみる。どれも、頭を使わないとできません。やっている最中は、しんどいです。

それに比べて、線を引くのは、楽ですよね。読み返すのも、楽。まとめるのも、手は疲れますが、頭は楽です。

そして人は、楽なほうを選びます。意志が弱いからでは、ありません。人間だからです。

## 楽だから続いたやり方を、人は「自分に合っている」と呼びます

ここが、この法則で、一番怖いところです。

楽だから、続いた。続いたから、残った。そして、残ったやり方を、人はこう呼びます。

　　「自分に合ったやり方」

だから、==「自分に合った勉強法」を探すのは、危険==なんです。探しているつもりで、楽なほうを選んでいるだけになります。しかも、本人には、そう見えません。

僕も、そうでした。

高校3年の時、誰よりも長く勉強して、10個受けて、全部落ちました。あの頃のノートは、きれいですよ。線が引いてあって、要点がまとまっていて、同じ単語が何十回も書いてあります。全部、01番で見た「効果が低い」やり方です。

自分には、合っていました。やりやすくて、続けられて、終わった時に「やった」という感じがありました。

足りなかったのは、量ではありません。負荷でした。

「やってみたけど、自分には合わなかった」

そう言う人も、沢山います。でも、多くの場合、合わなかったのでは、ありません。疲れただけです。そして、==疲れるのは、効いている合図==です。

## 【研究結果】「自分のタイプ」に合わせて勉強しても、成績は変わらなかった

「目で見て覚えるタイプ」「耳で聞いて覚えるタイプ」。こういうタイプ診断を、見たことがあると思います。

タイプに合わせて勉強すると、成績は上がるのか。それを調べた、インディアナ大学の調査があります。学生400人以上にタイプ診断を受けてもらって、普段の勉強法と、実際の成績を比べました。

```
　　診断の通りに勉強していた学生も、成績は変わらなかった
　　タイプと成績の間にも、関係はなかった
```

　　==好きかどうかと、身につくかどうかは、別です。==

だから、探すものを、入れかえてください。

```
　　×　自分に合った勉強法
　　○　点につながる、正しい勉強法
```

合うかどうかで選ぶなら、今の自分ではなく、なりたい自分に合うかどうかで、選んでください。

## じゃあ、どのくらい「きつい」のがいいのか

きつければきついほどいい、というわけでは、ありません。重すぎるダンベルは、1回も上がりません。

目安は、==10問のうち、2問から4問で、手が止まる==ことです。僕が2000人以上の生徒を見てきた中での、目安です。

```
　　0問か1問しか止まらない　→　やさしすぎる。1つ上のレベルへ
　　2問から4問で止まる　　　→　ちょうどいい
　　8問以上で止まる　　　　　→　重すぎる。1つ下のレベルへ
```

## AIに答えを聞くと、負荷は0になります

わからない問題をAIに入れて、答えを写す。楽です。速いです。そして、頭には、少しも負荷がかかっていません。

AIが悪いのでは、ありません。自分の頭にかかるはずだった負荷を、全部AIに渡してしまう使い方が、まずいんです。（負荷を残したまま使うやり方は、48番と49番に書きました）

## 今、3つの法則を、思い出せますか？

本を閉じて、ここまでの3つの絶対法則を、思い出してください。

……

「うーん」と、止まりましたか。

止まったなら、それでいいんです。その「うーん」が、負荷です。今、頭が使われています。

答え合わせです。

```
　　01　疑う　　　　みんながやっているから正しい、とは限らない
　　02　思い出す　　読んだ回数ではなく、思い出した回数で決まる
　　03　負荷　　　　「うーん」と止まっている時間だけが、勉強
```

きついことを、全部やる必要は、ありません。どこに負荷をかけるのか。それを決めるのが、次の絶対法則04です。

## 頭のいい人と伸びない人の違い

伸びない人
自分に合う勉強
スラスラ進む。調子いい

頭のいい人
少しキツい勉強
手が止まる。これでいい

## 今日からできる3STEP

STEP01
30分やったら、手が止まった問題を数える
「うーん、となったのは、3問」
※「うーん」と10秒以上止まった問題に、印をつけます。0個なら、その30分で、新しくできるようになったことは、ありません

STEP02
10問のうち、2問から4問で手が止まる教材を選ぶ
「全部○は、やさしすぎる」

STEP03
スラスラ解けた問題は線で消して、止まった問題だけを、次の日にもう一度やる
「昨日止まった3問から、始めよう」

できた基準
2問から4問で手が止まる教材で、30分やれたらOK！

## まとめ

「うーん」と止まっている時間だけが、勉強。

```
　　1　スラスラ進む時、頭は使われていない
　　2　「自分に合ったやり方」は、たいてい「楽なやり方」
　　3　目安は、10問のうち、2問から4問で手が止まること
```

だから、合うかどうかではなく、手が止まるかどうかで、選ぶ。
迷ったら、自分に聞きます。「止まる問題は、どれ？」
