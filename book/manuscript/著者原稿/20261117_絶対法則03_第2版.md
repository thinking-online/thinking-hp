## 導入文

「自分に合った勉強法が、見つからなくて……」

「どうやったら、自分に合った勉強法って、見つかりますか」

これまで、沢山の生徒から、聞かれてきました。

ただ、この「自分に合った勉強法」というものは、とても危険です。

今の自分に合った勉強を、どれだけ続けても、脳力（頭の力のことです）は、鍛えられないからです。

実は、調査でも、結果が出ています。自分のタイプに合った方法で勉強しても、成績は変わりませんでした。（あとで、紹介します）

大事なのは、自分に合うかどうかでは、ありません。

脳力を鍛えるために、絶対に必要なものが、1つあります。

　　==「負荷」です。==

少しきついことを、やる。そういう意味です。

頭のいい人の絶対法則、3つ目。「負荷」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「自分に合った勉強法」
じゃあ、何をするの？

## 本文

## 自分の名前を、逆から言えますか？

まず、自分の名前を、声に出して言ってみてください。

一瞬で、言えたはずです。

次に、同じ名前を、フルネームで、逆から言ってみてください。

……

「やまだ たろう」なら、「うろた だまや」です。

「うーん」と、止まりませんでしたか。途中でわからなくなって、最初からやり直した人も、いると思います。

スラスラ言えた人は、昔、遊びで練習したことがある人です。その場合は、仲のいい友達の名前で、やってみてください。

よく知っている名前です。知らない文字は、1つもありません。それでも、逆から言おうとした時だけ、頭を使いました。

　　==「うーん」と止まって、頭を使っている。この状態が、「負荷」です。==

1回目は、負荷が0でした。2回目は、負荷がかかりました。同じ名前でも、やり方を変えただけで、負荷は変わります。

勉強でも、同じことが起きます。

```
　　教科書を読む　　　→　スラスラ進む。負荷は、ほぼ0
　　閉じて、思い出す　→　「うーん」と止まる。負荷がかかる
```

絶対法則02で、「なぜ、きついほうが効くのか。次の絶対法則03で、説明します」と書きました。

答えは、1つです。==脳力が鍛えられるのは、負荷がかかっている時だけ==だからです。

## スラスラ解けた30分。新しくできるようになったことは、0個です

数学の問題集を、30分やったとします。10問、全部○でした。

　　「調子いい。このやり方、自分に合ってる」

気持ちいいですよね。

でも、この30分で、新しくできるようになったことは、0個です。10問とも、始める前から解けた問題だったからです。

筋トレで、考えてみてください。

1キロのダンベルを100回上げても、筋肉はつきません。筋肉がつくのは、「重い」と感じる重さを、上げた時だけです。

頭も、同じです。

```
　　スラスラ解ける　　→　もう、できること。何回やっても、できることは増えない
　　うーん、と止まる　→　まだ、できないこと。できることが増えるのは、こっちだけ
```

　　==「うーん」と止まっている時間だけが、勉強です。==

## 「自分に合う」とは、「今の自分が、楽にできる」という意味です

「自分に合う勉強法」と言う時、合わせている相手は、今の自分です。

今の自分が、スラスラできる。疲れない。続けやすい。

==「自分に合う」とは、「今の自分が、楽にできる」という意味==なんです。

慣れていて、不安がなくて、楽にできる。今の自分にとって、そういう範囲のことを、「コンフォートゾーン」と呼びます。居心地のいい場所、という意味です。（名前は、覚えなくてOKです）

成長とは、この範囲が、広がることです。

範囲の外に、少しだけ、はみ出す。「うーん」と止まる。止まった問題が、解けるようになる。すると、その問題は、楽にできる範囲の中に入ります。

この流れを繰り返すと、範囲は、どんどん広がっていきます。先週は手が止まった問題が、今週は、スラスラ解ける。できることが増えるというのは、こういうことです。

自分の名前を、逆からスラスラ言えた人も、同じです。最初は止まったものが、何度かやるうちに、楽にできる範囲に入りました。

逆に、今の自分に合った勉強だけを続けていると、範囲の外に、はみ出すことがありません。だから、範囲は、広がりません。

「自分に合った勉強法」が危険なのは、このためです。

## 「変わりたい」のに、変われない。意志が弱いからでは、ありません

「変わりたいです」

「今度こそ、本気でやります」

相談に来る生徒は、みんな、そう言ってくれます。その気持ちは、本物です。

それでも、新しいやり方を始めて3日たつと、元のやり方に戻っている。そういうことが、本当によく起きます。

意志が弱いからでは、ありません。

人間には、「変わりたい」という気持ちとは別に、==「今のままでいたい」という反応が、もともと備わっている==からです。

身近な所で、確かめてみてください。

```
　　席が自由な時も、いつも同じあたりに座る
　　アプリの見た目が変わると、「前のほうがよかった」と思う
　　髪型を変えるつもりで切りに行ったのに、「いつもと同じで」と言ってしまう
```

当てはまるものが、あったと思います。

誰かに決められたわけでは、ありません。考える前に、「いつもと同じ」を選んでいます。

理由は、2つあります。

1つ目。いつもと同じことは、安全だとわかっています。昨日もやって、何も困らなかったからです。いつもと違うことは、安全かどうか、まだわかりません。

2つ目。いつもと同じことは、考えなくても、できます。いつもと違うことは、1つ1つ、考えないとできません。考えるのは、疲れます。

だから人間は、考える前に、「いつもと同じ」のほうを選びます。意志とは関係のない、本能のようなものです。

```
　　「変わりたい」　　　　→　頭で考えて、出てくる気持ち
　　「今のままでいたい」　→　考える前に、出てくる反応
```

2つとも、本物です。ただ、先に出てくるのは、「今のままでいたい」のほうです。だから、何も決めずにいると、人は、元のやり方に戻ります。

勉強でも、同じことが起きます。

正直に書きます。==正しいやり方は、疲れます。==

本を閉じて、「なんだっけ」と思い出す。わかったと思ったら、何も見ずに、白紙で解いてみる。どれも、やっている最中は、しんどいです。

線を引くのは、楽です。読み返すのも、楽です。しかも、昨日までやってきた、いつものやり方です。

だから、何も考えずに選ぶと、いつもの、楽なやり方のほうが、残ります。そして、残ったやり方を、人はこう呼びます。

　　「自分に合ったやり方」

探しているつもりで、いつもの、楽なほうを選んでいる。しかも、本人には、そう見えません。

僕も、そうでした。

高校3年の時、誰よりも長く勉強して、10個受けて、全部落ちました。あの頃のノートは、きれいですよ。線が引いてあって、要点がまとまっていて、同じ単語が何十回も書いてあります。全部、絶対法則01で見た「効果が低い」やり方です。

自分には、合っていました。やりやすくて、続けられて、終わった時に「やった」という感じがありました。

足りなかったのは、量ではありません。負荷でした。

「やってみたけど、自分には合わなかった」

そう言う人も、沢山います。でも、多くの場合、合わなかったのでは、ありません。疲れただけです。そして、==疲れるのは、効いている合図==です。

## 【研究結果】「自分のタイプ」に合わせて勉強しても、成績は変わらなかった

「目で見て覚えるタイプ」「耳で聞いて覚えるタイプ」。こういうタイプ診断を、見たことがあると思います。

タイプに合わせて勉強すると、成績は上がるのか。それを調べた、インディアナ大学の調査があります。学生400人以上にタイプ診断を受けてもらって、普段の勉強法と、実際の成績を比べました。

```
　　診断の通りに勉強していた学生も、成績は変わらなかった
　　タイプと成績の間にも、関係はなかった
```

　　==好きかどうかと、身につくかどうかは、別です。==

だから、選ぶ基準を、入れかえてください。

```
　　×　自分に合うかどうかで、選ぶ
　　○　手が止まるかどうかで、選ぶ
```

## 負荷は、大きいほどいい、というわけではありません

ここで、1つ注意です。

きつければきついほどいい、というわけでは、ありません。

10問やって、10問とも、手も足も出ない。解説を読んでも、わからない。これでは、何時間やっても、できることは増えません。焦るだけで、続きません。

伸びるのは、コンフォートゾーンから、「少しだけ」はみ出した所です。遠くまではみ出すと、伸びません。

```
　　楽にできる　　10問のうち、0〜1問で手が止まる　→　伸びない。1つ上のレベルへ
　　少しきつい　　10問のうち、2〜4問で手が止まる　→　ここで、伸びる
　　きつすぎる　　10問のうち、8問以上で手が止まる　→　伸びないし、続かない。1つ下のレベルへ
```

目安は、==10問のうち、2問から4問で、手が止まる==ことです。僕が2000人以上の生徒を見てきた中での、目安です。

5問から7問で止まるなら、少し重めです。解説を読んでわかるなら、そのまま続けます。読んでもわからないなら、1つ下のレベルにします。

そして、きついことを、全部やる必要は、ありません。どこに負荷をかけるのか。それを決めるのが、次の絶対法則04です。

## AIに答えを聞くと、負荷は0になります

わからない問題をAIに入れて、答えを写す。楽です。速いです。そして、頭には、少しも負荷がかかっていません。

AIが悪いのでは、ありません。自分の頭にかかるはずだった負荷を、全部AIに渡してしまう使い方が、まずいんです。（負荷を残したまま使うやり方は、48番と49番に書きました）

## 頭のいい人と伸びない人の違い

伸びない人
自分に合う勉強
スラスラ進む。調子いい

頭のいい人
少しきつい勉強
手が止まる。これでいい

## 今日からできる3STEP

STEP01
30分やったら、手が止まった問題を数える
「うーん、となったのは、3問」
※「うーん」と10秒以上止まった問題に、印をつけます。0個なら、その30分で、新しくできるようになったことは、ありません

STEP02
10問のうち、2問から4問で手が止まる教材を選ぶ
「全部○は、やさしすぎる」

STEP03
スラスラ解けた問題は線で消して、止まった問題だけを、次の日にもう一度やる
「昨日止まった3問から、始めよう」

できた基準
2問から4問で手が止まる教材で、30分やれたらOK！

## まとめ

「うーん」と止まっている時間だけが、勉強。

```
　　1　「自分に合う」とは、「今の自分が、楽にできる」という意味
　　2　できることが増えるのは、楽にできる範囲から、少しはみ出した時だけ
　　3　目安は、10問のうち、2問から4問で手が止まること
```

だから、合うかどうかではなく、手が止まるかどうかで、選ぶ。
迷ったら、自分に聞きます。「止まる問題は、どれ？」
