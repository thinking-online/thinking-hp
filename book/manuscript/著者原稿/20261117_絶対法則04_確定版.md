絶対法則04　戦略
やみくもにやらない。やらないことを先に決める

## 導入文

「毎日5時間やってるのに、成績が上がらないんです」

「もっと、勉強時間を増やしたほうがいいですか」

相談で、一番多い質問の1つです。

そのたびに、僕は聞き返します。

「その5時間で、何をやったの？」

「ワークを、最初のページから全部です」

「単語帳を、1番から順番にやってます」

ほとんどの人が、「全部」と答えます。

頑張っているんです。時間も、足りています。

足りないのは、==「どこをやるか」を、先に決めること==です。これを、「戦略」と呼びます。

頭のいい人の絶対法則、4つ目。「戦略」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「やみくもに全部頑張る」
じゃあ、何をするの？

## 本文

## テストまで、あと3日。あなたなら、どうしますか？

次の場面で、考えてみてください。

```
　　テストまで、あと3日
　　範囲は、ワーク60ページ
　　1日にできるのは、10ページ
```

あなたなら、どちらを選びますか。

```
　　A　1ページ目から、順番にやる
　　B　先に、出そうな30ページを選んでから、やる
```

……

多くの人が、Aを選びます。「全部大事だから」「選んでいる時間が、もったいないから」。

でも、計算してみてください。1日10ページで、3日。できるのは、30ページです。

Aの人は、30ページ目で、テストの日が来ます。後ろの30ページは、1問もやっていません。

ここが、大事な所です。

Aの人も、30ページを捨てています。==捨てる場所を、自分で選んでいないだけ==です。時間が足りなくなった所が、そのまま、捨てた所になりました。

　　==「全部やる」は、最初から選べません。選べるのは、「自分で選んで捨てる」か、「時間切れで捨てる」か。この2つだけです。==

## 結果 ＝ 戦略 × やり方 × 量

勉強の結果は、3つの掛け算で決まります。

```
　　戦略　　どこをやるか
　　やり方　どうやるか
　　量　　　どれだけやるか
```

足し算では、ありません。掛け算です。だから、どれか1つが0だと、ほかが満点でも、結果は0になります。

```
　　戦略が0　　出ない所を、完璧にした
　　やり方が0　出る所を、教科書を見ながらやった。一度も、閉じて思い出していない
　　量が0　　　やり方の本を読んで、「なるほど」と思って、終わった
```

どれも、点になりません。

「はじめに」で書いた、現役の時の僕を、この式に入れてみます。

```
　　戦略　　「全部やる」
　　やり方　読み返す、まとめる、線を引く（絶対法則01で見た、効果が低いやり方）
　　量　　　1日13時間
```

　　==戦略0 × やり方0 × 13時間 ＝ 全落ち==

量だけなら、誰にも負けていませんでした。でも、掛け算なので、0が2つあれば、0です。

## 見ていたのは、点ではなく、「頑張っている自分」でした

現役の時、僕は、勉強時間をアプリに記録して、友達と見せ合っていました。数字は、毎日増えていきます。「マジで、努力の天才だよな」と言われて、嬉しかったです。

あの時、僕が見ていたのは、点ではありません。==頑張っている自分==でした。

```
　　×　今日は、13時間やった
　　○　今日は、何ができるようになった
```

試験に、「頑張った賞」は、ありません。

「はじめに」で、「努力に、酔ってはいけない」と書きました。努力を否定したいのでは、ありません。逆です。せっかくやるなら、点になる所に、使ってほしいんです。

## 戦略とは、「やらないこと」を決めることです

やることを決める、では、ありません。やらないことを決める、です。

テストには、範囲があります。出る所と、出ない所があります。出す側は、全部は出せないからです。

そして、どこが出るかは、テストの前から、わかります。範囲表と、前回のテストに、書いてあるからです。入試なら、過去問です。

でも、ほとんどの人は、見ません。範囲表は、1回見て、机に置いたまま。過去問は、「力がついてから」と言って、本棚に立てたままです。

「捨てる」と聞くと、手を抜くように聞こえます。逆です。

今、手元にある参考書とワークを、数えてみてください。5冊あるとします。学校と部活のあとに残る時間が、2時間。5冊に分けると、1冊あたり24分です。24分では、どの1冊も、終わりません。

1冊に絞った人は、5倍の速さで終わります。終わった1冊は、点になります。途中で止まった5冊は、点になりません。

　　==捨てないと、全部が、途中で終わります。==

## 「捨てた所が出たら、どうするんですか？」

出ます。たまに、出ます。

でも、そこは5点です。全部に手をつけて、全部が途中で終わった人は、50点を落とします。5点を捨てて、50点を取りにいく。それが、戦略です。

それに、捨てるというのは、「今は、やらない」という意味です。「一生やらない」では、ありません。残した所が先に終わって、時間が余ったら、戻ればいいんです。

## 【研究結果】始める前に「何を、どう使うか」を決めた学生は、成績が高かった

始める前に決めるだけで、本当に成績は変わるのか。それを確かめた、スタンフォード大学の研究チームの実験があります。

大学の統計の授業で、テストの1週間ほど前に、学生を2つのグループに分けました。

```
　　①　いつも通り、テストのお知らせだけを受け取る
　　②　お知らせと一緒に、「どんな問題が出そうか」「そのために、どの教材を、どう使うか」を、書き出す
```

結果です。②のグループは、①のグループより、授業の成績が高くなりました。100点満点で、平均3点から5点の差です。

②のグループがやったのは、始める前に、書き出して決めることだけです。

## それでも、量は、飛ばせません

「じゃあ、戦略さえあれば、量はいらないんですね」

違います。掛け算です。量が0なら、戦略が満点でも、0です。

戦略は、量を減らすためのものでは、ありません。同じ量を、点になる所に集めるためのものです。

## 【チェック】あなたの0は、どれですか？

3つ、聞きます。

```
　　□　次のテストの範囲表を、今、出せない　　　　　→　戦略が0。34番へ
　　□　今日やったことを、何も見ずに、3つ言えない　→　やり方が0。絶対法則02へ
　　□　先週、机に向かった日が、3日以下　　　　　　→　量が0。28番へ
```

3つとも印がついた人は、上から順にやってください。一番早く効くのは、戦略です。やらないことが決まると、その日から、使える時間が増えるからです。

どこをやるかが、決まりました。次は、いつやるか、です。次の絶対法則05で、説明します。

## 今日からできる3STEP

題：頭のいい人の『戦略の立て方』3STEP

STEP01
次のテストの範囲を、紙に全部書き出す
「まず、全部並べてみよう」

STEP02
前回のテストを横に置いて、出ない所に線を引く
「これ、出る？出ない。消す」

STEP03
残った所に、やる順の番号をつける
「配点が大きい所が、1番」

できた基準
15分で、線と番号が入った紙が1枚できたらOK！

## まとめ

結果 ＝ 戦略 × やり方 × 量。1つでも0なら、0。

```
　　1　「全部やる」は、選べない。「選んで捨てる」か、「時間切れで捨てる」か
　　2　戦略とは、やらないことを決めること
　　3　出る所は、範囲表と、前回のテストに書いてある
```

だから、始める前に、やらないことを決める。
迷ったら、自分に聞きます。「これ、テストに出る？」
