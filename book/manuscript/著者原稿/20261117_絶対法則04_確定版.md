## 本文

## 修学旅行の自由行動。3時間で、京都を全部回りますか？

修学旅行の、班別の自由行動を、思い浮かべてください。場所は、京都。時間は、3時間です。

あなたの班は、どうしますか。

……

ほとんどの班が、同じことをします。

```
　　1　行きたい所を、出し合う
　　2　3時間では全部回れないので、行かない所を決める
　　3　回る順番と、1か所に使う時間を決める
```

「駅に近いお寺から順に、全部回ろう」と言う班は、ありません。全部は回れないと、わかっているからです。

行き先を決める。行かない所を決める。順番を決める。

　　==この3つが、「戦略」です。==

旅行なら、誰でも、当たり前にやっています。

ところが、勉強になると、ほとんどの人が、やりません。

　　「テスト範囲、最初のページから、全部やろう」

行き先も、行かない所も決めずに、駅に近い順に、全部回ろうとしています。

## 受験は、ゴールが決まっている勝負です

修学旅行には、行き先がありました。勉強にも、行き先があります。

次の定期テスト。模試。高校入試。大学入試。

いつ、何が、どんな形で出るのか。何点取れば、勝ちなのか。==ゴールは、最初から決まっています。==

この本では、そのゴールのことを、「敵」と呼びます。倒す相手、という意味です。

ゴールが決まっている勝負では、ゴールに一番早く着ける道が、正しい道です。努力は、多ければ多いほどいい、というわけでは、ありません。

敵を知らないまま努力すると、こうなります。

　　どんな大会に出るのかを知らないまま、毎日、腕立て伏せを100回やる。
　　大会の日。会場に行ってみたら、将棋の大会でした。

努力は、本物です。筋肉も、つきました。でも、勝てません。

もう1つ、あります。

　　気になる人が、できました。
　　「モテる人は、いい香りがする」と聞いて、香水を買って、毎日つけました。
　　その人は、香水のにおいが、苦手でした。

頑張ったぶんだけ、遠ざかっています。

笑い話に聞こえます。でも、勉強では、同じことが、本当によく起きています。

出ない所を、完璧にする。配点が小さい所に、一番時間を使う。志望校の入試にない科目を、毎日やる。

　　==努力の量より先に、努力の向きです。==

## 戦略は、受験だけの武器ではありません

部活の試合。ゲーム。好きな人に、振り向いてもらうこと。この先、あなたが本気でかなえたくなる目標。

どれにも、「何をしたら勝ちなのか」があります。それを先に知って、そこから逆算する人が、勝ちます。やみくもに頑張るだけでは、勝てません。

受験は、その練習に、ちょうどいい場所です。ゴールが、はっきり決まっているからです。

## 結果 ＝ 戦略 × やり方 × 量

勉強の結果は、3つの掛け算で決まります。

```
　　戦略　　どこをやるか
　　やり方　どうやるか
　　量　　　どれだけやるか
```

足し算では、ありません。掛け算です。だから、どれか1つが0だと、ほかが満点でも、結果は0になります。

```
　　戦略が0　　出ない所を、完璧にした
　　やり方が0　出る所を、教科書を見ながらやった。一度も、閉じて思い出していない
　　量が0　　　やり方の本を読んで、「なるほど」と思って、終わった
```

「はじめに」で書いた、現役の時の僕を、この式に入れてみます。

　　==戦略0 × やり方0 × 1日13時間 ＝ 全落ち==

量だけなら、誰にも負けていませんでした。あの頃の僕が見ていたのは、点ではなく、頑張っている自分でした。

逆も、同じです。戦略が満点でも、量が0なら、0です。戦略は、量を減らすためのものでは、ありません。同じ量を、点になる所に集めるためのものです。

## ゴールを早く知って、ゴールに必要なもので練習する

絶対法則01で、「みんながやっているから正しい、とは限らない」と書きました。

教材も、同じです。みんなが使っている問題集だから、自分にも必要、とは限りません。必要かどうかは、敵で決まります。

そして、敵は、人によって違います。

```
　　大学入試　　大学と学部によって、科目ごとの配点も、問題の形も違う
　　　　　　　　国公立は、科目が多い。ただ、1科目ごとの重みは、大学と学部で大きく違う
　　　　　　　　私立は、同じ大学でも、学部が違うだけで、問題の形が変わることがある
　　高校入試　　目指す高校が変わると、出る問題も変わることがある
　　定期テスト　範囲表と、問題を作る先生で決まる
```

英語が200点、国語が100点の学部なら、英語は、国語の2倍の重みです。同じ1点でも、敵によって、重みが違います。

だから、敵を知るのは、早いほどいいんです。知るのが遅れたぶんだけ、いらない練習に、時間を使うことになります。

僕たちの塾では、最初に、敵を徹底的に調べます。過去問を開いて、配点と、問題の形を見る。そこから逆算して、やることと、やらないことを決める。練習を始めるのは、そのあとです。

## 少なく、でも、良く

敵がわかったら、次にやることは、1つです。

　　==やらないことを、決める。==

「全部やる」は、選べません。数字で、確かめてみます。

```
　　テストまで、あと3日
　　範囲は、ワーク60ページ
　　1日にできるのは、10ページ
```

できるのは、30ページです。1ページ目から順にやった人は、後ろの30ページを、1問もやらないまま、テストの日が来ます。

この人も、30ページを捨てています。捨てる場所を、自分で選んでいないだけです。

　　==選べるのは、「自分で選んで捨てる」か、「時間切れで捨てる」か。この2つだけです。==

「より少なく、しかし、より良く」という言葉があります。大事でないものを捨てて、本当に大事な少しに、力を集める。そのために要るのは、2つです。

```
　　見極める　　本当に大事なものだけを、選ぶ
　　捨てる　　　大事でないものを、勇気を出して、やめる
```

捨てるのは、こわいです。友達が使っている問題集。SNSで話題の参考書。見るたびに、「自分もやらなきゃ」と思います。

でも、手を出すたびに、本当に大事なものに使う時間が、減っていきます。「自分は、やらない」と言えることも、力です。

「捨てた所が出たら、どうするんですか？」

出ます。たまに、出ます。でも、そこは5点です。全部に手をつけて、全部が途中で終わった人は、50点を落とします。

## 場面ごとの戦略は、このあと出てきます

```
　　学校の宿題と提出物を、どう分けるか　　10
　　計画を、どう立てるか　　　　　　　　　30
　　参考書を、続けるか、やめるか　　　　　32
　　過去問を、いつ開くか　　　　　　　　　34
　　本番で、どの問題から解くか　　　　　　47
```

形は違いますが、もとは、この絶対法則04です。

どこをやるかが、決まりました。次は、いつやるか、です。次の絶対法則05で、説明します。

## 頭のいい人と伸びない人の違い

伸びない人

## 今日からできる3STEP

題：頭のいい人の『戦略の立て方』3STEP

STEP01
今の勉強のゴールを、紙に1行で書く
「次の期末で、数学80点」

STEP02
範囲表か過去問を開いて、出る所と配点を書く
「何が出る？配点は？」

STEP03
出ない所に線を引いて、やる順に番号をつける
「これは出ない。消す」

できた基準
ゴールと、やらないことが、1枚の紙に書けたらOK！

## まとめ

結果 ＝ 戦略 × やり方 × 量。戦略が0なら、どれだけ頑張っても、0。

```
　　1　戦略とは、ゴールから逆算して、やることと、やらないことを決めること
　　2　ゴールが変われば、必要な練習も変わる。だから、ゴールを早く知る
　　3　「全部やる」は、選べない。「選んで捨てる」か、「時間切れで捨てる」か
```

だから、始める前に、ゴールを見る。
迷ったら、自分に聞きます。「これ、ゴールに必要？」
