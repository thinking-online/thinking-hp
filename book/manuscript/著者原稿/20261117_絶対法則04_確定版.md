やみくもにやらない。やらないことを先に決める

## 導入文

「努力は、裏切らない」

そう言われて、育ってきたと思います。

僕も、信じていました。高校3年の時、1日13時間以上、勉強しました。周りからは、「努力の天才」と呼ばれていました。

結果は、全落ちです。受けた10個、全部、落ちました。

だから、はっきり言います。

　　==努力は、裏切ります。==

正しく言い直すと、こうです。向きがずれた努力は、どれだけ積んでも、裏切ります。

「毎日5時間やってるのに、成績が上がらないんです」

相談で、一番多い言葉です。聞くたびに、昔の自分を見ている気持ちになります。

成績が上がらない理由は、1つでは、ありません。時間が足りない人もいます。頑張りが足りない人もいます。

ただ、時間も、頑張りも足りているのに、上がらない人がいます。その人に足りないのは、==頑張る前に、「どこに向かって頑張るか」を決めること==です。これを、「戦略」と呼びます。

戦略がないまま頑張ると、頑張った時間が、点につながりません。せっかくの努力が、無駄になってしまいます。

頭のいい人の絶対法則、4つ目。「戦略」を、具体的に見ていきましょう。

## 本文

## 修学旅行の自由行動。3時間で、京都を全部回りますか？

修学旅行の、班別の自由行動を、思い浮かべてください。場所は、京都。時間は、3時間です。

あなたの班は、どうしますか。

……

「駅に近いお寺から順に、全部1つずつ回ろうよ！」とでも言ったら、班長に引っ叩かれます（笑）。全部は回れないと、わかっているからです。

どの班も、この手順で考えるはずです。

```
　　1　行きたい所を出し合って、絶対に外せない所を決める
　　2　3時間では全部回れないので、行かない所を決める
　　3　回る順番と、1か所に使う時間を決める
```

メインの清水寺は、必ず押さえたいところです。

広隆寺、というお寺もあります。聞いたことがない人も、多いかもしれません。でも、京都で一番古いと言われるお寺で、国宝の仏像もあります。

そりゃ、行けるなら、行ったほうがいいです。でも、全部は行けません。だから、今回は、あきらめます。

外せない所を決める。行かない所を決める。順番を決める。

　　==この3つが、「戦略」です。==

旅行なら、誰でも、当たり前にやっています。

ところが、勉強になると、ほとんどの人が、やりません。

　　「範囲、広っ。とりあえず、ワークの1ページ目からやるか」
　　「どこが出るかわかんないし、全部やっとこ」

外せない所も、行かない所も決めずに、駅に近い順に、全部回ろうとしています。

## 受験は、ゴールが決まっている勝負です

修学旅行には、行き先がありました。では、勉強の行き先は、どこでしょうか。

次の定期テスト。模試。高校入試。大学入試。

いつ、何が、どんな形で出るのか。何点取れば、勝ちなのか。==勉強のゴールは、最初から決まっています。==

この本では、そのゴールのことを、「敵」と呼びます。倒す相手、という意味です。

ゴールが決まっている勝負では、ゴールに一番早く着ける道が、正しい道です。努力は、多ければ多いほどいい、というわけでは、ありません。

ゴールにまっすぐ向かっていない努力は、ただの寄り道です。最速で結果を出す、という点では、無駄な努力になります。

その寄り道が、最初に書いた、「裏切る努力」です。

たとえば、こういうことです。

　　サッカーの試合で、勝ちたい。
　　だから毎日、リフティングを練習して、1000回できるようになりました。
　　試合では、1点も取れませんでした。

努力は、本物です。リフティングも、うまくなりました。でも、試合で点を取るのに必要だったのは、シュートの練習でした。

もう1つ、あります。

　　好きな人が、できました。
　　「マメに連絡する人が、モテる」と聞いて、毎日、朝と夜にLINEを送りました。
　　1週間後。既読が、つかなくなりました。

その人は、LINEが苦手でした。頑張ったぶんだけ、遠ざかっています。

どちらも、相手を知らないまま、頑張っています。

そして勉強でも、同じことが、本当によく起きています。出ない所を、完璧にする。配点が小さい所に、一番時間を使う。志望校の入試にない科目を、毎日やる。

　　==努力の量より先に、努力の向きです。==

## 結果 ＝ 戦略 × やり方 × 量

勉強の結果は、この3つで決まります。

```
　　戦略　　どこをやるか
　　やり方　どうやるか
　　量　　　どれだけやるか
```

足し算では、ありません。掛け算です。だから、どれか1つが0だと、ほかが満点でも、結果は0になります。

最初に書いた、現役の時の僕を、この式に入れてみます。

　　==戦略0 × やり方0 × 量100（1日13時間）＝ 全落ち==

量だけなら、誰にも負けていませんでした。あの頃の僕が見ていたのは、点ではなく、頑張っている自分でした。「裏切る努力」を、1日13時間、積んでいたんです。

逆も、同じです。戦略が満点でも、量が0なら、0です。戦略は、量を減らすためのものでは、ありません。同じ量を、点になる所に集めるためのものです。

では、戦略は、何から始めればいいのか。ゴールを、正しく知ることから、です。

## 受験のゴールは、満点ではありません

受験のゴールを、正確に言うと、こうなります。

　　==合格最低点を、0.001点でも上回る。==

合格最低点とは、合格した人の中で、一番低かった点です。大学入試では、小数点の差で、合格と不合格が分かれることもあります。

満点で受かった人も、合格最低点ぎりぎりで受かった人も、同じ合格です。4月には、同じ入学式に並んでいます。

つまり、合格最低点が、100点のうち65点なら、35点は、落としていいんです。

定期テストも、同じです。「次は80点」と決めたなら、80点を超えれば、クリアです。

全部できるようになる必要は、ありません。必要な点を、確実に取る。それが、ゴールです。

## ゴールを早く知って、ゴールに必要なもので練習する

では、必要な点は、何点なのか。どこで、取ればいいのか。答えは、敵によって違います。

```
　　大学入試　　同じ大学でも、学部が違うだけで、配点も、問題の形も変わることがある
　　高校入試　　目指す高校が変わると、出る問題も変わることがある
　　定期テスト　範囲表と、問題を作る先生で決まる
```

英語が200点、国語が100点の学部なら、英語は、国語の2倍の重みです。同じ1点でも、敵によって、重みが違います。

教材も、同じです。みんなが使っている問題集だから、自分にも必要、とは限りません。必要かどうかは、敵で決まります。

だから、敵を知るのは、早いほどいいんです。知るのが遅れたぶんだけ、寄り道が増えます。

僕たちの塾では、最初に、敵を徹底的に調べます。過去問を開いて、合格最低点と、配点と、問題の形を見る。そして、ゴールから後ろ向きに考えて、今やることを決めます。これを、「逆算」と言います。

逆算は、ふだん、誰でもやっています。

```
　　10時に、駅で待ち合わせ
　　電車で20分。駅まで歩いて10分。準備に30分
　　だから、9時に起きる
```

勉強も、同じです。

```
　　去年の合格最低点は、65%。だから、英語は70%を取る
　　そのために、長文で落とせるのは、2問まで
　　そのために、今月は、長文を毎日1つ読む
```

ゴールから決めるので、やることが、はっきりします。そして、もう1つ、はっきりするものがあります。やらなくていいことです。

## 「やったほうがいいこと」は、無限にあります

単語帳を、もう1冊。ノートを、きれいにまとめ直す。友達が使っている問題集。SNSで話題の参考書。

どれも、やれるものなら、やったほうがいいです。時間が、無限にあるなら。

でも、時間は、限られています。

たとえば、テストまで、あと3日。範囲は、ワーク60ページ。1日にできるのは、10ページだとします。

3日で、30ページ。どう頑張っても、半分しか終わりません。

ここで、2人に分かれます。

```
　　Aさん　「全部やろう」と、1ページ目から順に進める
　　　　　　→　30ページ目で、テストの日。後ろの30ページは、1問もやっていない

　　Bさん　最初に、点になる30ページを選ぶ。残りは、やらないと決める
　　　　　　→　選んだ30ページをやり切って、テストの日
```

2人とも、やったのは、30ページです。やらなかったのも、30ページです。

違うのは、1つだけ。==やらない30ページを、自分で選んだかどうか==です。Aさんは、選びませんでした。だから、後ろの半分が、まるごと残りました。

全部やるのは、あきらめてください。

あきらめる、と聞くと、負けたように感じるかもしれません。違います。

全部は、できません。そして、全部は、要りません。ゴールは、満点ではないからです。

あきらめるのは、本当に大事なものに、時間を使うためです。

## 先に、「やらないといけないこと」。「やったほうがいいこと」は、そのあと

修学旅行を、思い出してください。先に決めたのは、絶対に外せない清水寺でした。行けるなら行きたい広隆寺のことを考えたのは、そのあとです。

勉強も、同じ順番にします。

```
　　先に　　　「やらないと、ゴールに届かないこと」
　　そのあと　時間が余ったら、「やったほうがいいこと」
```

やったほうがいいことを、やるな、という話では、ありません。順番の話です。

大事なのは、こういう考え方です。

　　==あれもこれも、少しずつ、ではなく、大事なことを、最後まで。==

10個に手をつけて、10個とも途中で終わる。それより、3個を選んで、3個とも最後までやり切る。点になるのは、3個をやり切ったほうです。

そのために要るのは、2つです。

```
　　見極める　　本当に大事なものを、選ぶ
　　捨てる　　　それ以外は、勇気を出して、今はやらない
```

## 「捨てた所が出たら、どうするんですか？」

出ます。たまに、出ます。

でも、それでいいんです。合格最低点を、0.001点でも上回れば、合格です。捨てた所で数点落としても、やると決めた所を取り切っていれば、ゴールには届きます。

それに、この質問をしてくれる生徒に、「やると決めた所は、もう全部できる？」と聞き返すと、たいてい、「まだです」と返ってきます。

順番は、さっきと同じです。まず、やると決めた所を、確実に取る。捨てた所を取りに行くのは、そのあとです。

## 戦略は、受験だけの武器ではありません

ここまで、受験の話をしてきました。でも、戦略が要るのは、受験だけでは、ありません。

部活の試合。ゲーム。好きな人に、振り向いてもらうこと。この先、あなたが本気でかなえたくなる目標。どれにも、「何をしたら勝ちなのか」があります。それを先に知って、そこから、やることを決める人が、勝ちます。

受験は、ゴールがはっきり決まっているので、戦略の練習には、ちょうどいいんです。受験で身につけておくと、この先、ずっと使えます。

この本の中でも、場面ごとの戦略が、このあと出てきます。

```
　　学校の宿題と提出物を、どう分けるか　　10
　　計画を、どう立てるか　　　　　　　　　30
　　参考書を、続けるか、やめるか　　　　　32
　　過去問を、いつ開くか　　　　　　　　　34
　　本番で、どの問題から解くか　　　　　　47
```

形は違いますが、もとは、この絶対法則04です。

どこをやるかが、決まりました。次は、いつやるか、です。次の絶対法則05で、説明します。

組む時の注意（本文には入れない）

- 修学旅行の問いのあと（「駅に近いお寺から順に」より先）は、問いと同じ見開きに置かない
- 広隆寺：京都で一番古い寺と紹介されることが多い（603年の創建と伝わる）ので、「一番古いと言われる」と書いた。弥勒菩薩半跏思惟像は国宝。「国宝第1号」は、同じ日に指定されたものがほかにも多いので、書かない
- 実在のお寺を「聞いたことがない人も、多いかもしれません」「今回は、あきらめます」と書いている。編集部に確認する（かえるなら、大報恩寺＝千本釈迦堂。本堂は国宝で、京都の街なかで一番古い木造の建物とされる）
- 研究は、入れていない
- 「合格最低点を、0.001点でも上回れば、合格」は、著者の言葉。東京大学は、合格者の最低点を小数第4位まで出している（河合塾、旺文社の入試結果のページで確かめた）ので、「小数点の差で、合格と不合格が分かれることもあります」と書いた。合格最低点は、年によって変わる。公表していない学校もある。本文の65%、70%、80点は、たとえの数字
- 「より少なく、しかし、より良く」の言葉は、使っていない（著者の指示。考え方として書いた）。書名（エッセンシャル思考）も出していない
- 大学入試と高校入試の説明は、「ことがある」と書いて、言い切っていない（大学や都道府県で違うため）
- 「LINE」は、商品の名前。本にそのまま書けるかは、編集部に確認する（書けない時は「メッセージ」にする）
