絶対法則05　分散
まとめてやらない。分けて、繰り返す

## 導入文

「一夜漬けは、やめなさい」

何度も、言われてきたと思います。

でも、やめられませんよね。理由は、はっきりしています。

　　==一夜漬けは、効くからです。==

テストの前の日に、3時間かけて、英単語を100個、一気に覚える。次の日のテストは、そこそこ取れます。だから、次のテストでも、同じことをします。

問題は、そのあとです。

「定期テストは、取れるんです。でも、模試になると、全然取れなくて」

本当によく聞く相談です。1ヶ月後の模試に、同じ単語が出ます。……出てこない。あんなに、やったのに。

サボったわけでは、ありません。3時間、ちゃんとやっています。

変えるのは、時間の長さでは、ありません。==同じ3時間を、1日にまとめるか、何日かに分けるか==です。それだけで、1ヶ月後に残る量が、変わります。

分けて、間をあけて、繰り返す。これを、「分散」と呼びます。

絶対法則04で、「どこをやるか」を決めました。次は、「いつやるか」です。

頭のいい人の絶対法則、5つ目。「分散」を、具体的に見ていきましょう。

## 質問ページ

## 本文

## 7×8は、いくつですか？

……

56ですね。一瞬で、出たはずです。

では、もう1つ。

前回の定期テストの前の日に、必死で覚えたこと。今、3つ、言えますか。

……

出てこなかった人が、多いと思います。

おかしいと、思いませんか。

九九を覚えたのは、小学2年生です。何年も前です。定期テストは、ついこの前です。それなのに、古いほうが残っていて、新しいほうが消えています。

違うのは、覚え方です。

```
　　九九　　　　　　　　何日も、何週間も、間をあけて、何度も思い出した
　　テスト前の日の暗記　1日に、まとめて、一気にやった。そのあとは、やっていない
```

九九を、1日で覚えた人は、いません。昨日やって、今日もやって、来週もやって、次の学年でも使いました。

　　==間をあけて、何度も思い出したものは、長く残ります。==

## 【研究結果】続けて2回より、間をあけて2回

まとめるか、分けるかで、残る量は、どのくらい変わるのか。アメリカの大学の研究者たちが、実験で確かめています。

大学生に同じ文章を読んでもらって、3つのグループに分けました。

```
　　①　1回だけ読む
　　②　2回、続けて読む
　　③　1回読んで、1週間あけてから、もう1回読む
```

テストは、読んだ直後と、2日後の、2通りでやりました。

```
　　直後のテスト　　②が1位。③は、①とほとんど変わらなかった
　　2日後のテスト　③が1位。②は、①とほとんど変わらなくなった
```

順位が、ひっくり返っています。

②と③は、どちらも2回読んでいます。使った時間は、同じです。違うのは、続けたか、あけたか。それだけです。

## まとめてやると、「効いた気」がします

実験でも、直後のテストは、続けて読んだ②が1位でした。まとめてやると、その日のうちは、本当に効きます。一夜漬けが、やめられない理由です。

でも、数日で消えます。

入試は、覚えた次の日には、ありません。3ヶ月後、1年後、3年後です。前の日に詰めこんだ単語は、そこまで持ちません。そして、また1から、覚え直すことになります。

```
　　まとめてやる　→　その日は残る。数日で消える。また1から覚え直す
　　分けてやる　　→　1回ごとの手ごたえは小さい。でも、消えにくい
```

==まとめてやる人は、同じものを、何度も1から覚え直しています。==

## 同じ3時間を、3日に分けるだけです

やることは、増やしません。分けるだけです。

```
　　×　前の日に、3時間　　　　　合計3時間
　　○　1時間を、3日に分ける　　合計3時間
```

部活の練習と、同じです。試合の前の日だけ、12時間練習する部は、ありません。毎日、少しずつ、やっています。

分けると、2回目にやる時は、少し忘れています。忘れかけたものを、「うーん」と思い出すことになります。

気づきましたか。絶対法則02の「思い出す」と、絶対法則03の「負荷」が、両方入っています。

まとめてやると、まだ覚えているうちに次をやるので、スラスラ進みます。負荷が、かかりません。分けてやると、毎回、少し忘れた所から始まるので、「うーん」となります。

　　==分けるだけで、「思い出す」と「負荷」が、勝手に入ります。==

## テストの範囲は、授業を受けた日に、もう決まっています

「2週間前から、本気を出す」。そう決めている人も、多いと思います。

でも、範囲表に書いてあるのは、新しい情報では、ありません。この1ヶ月か2ヶ月、授業でやった所です。範囲は、授業を受けたその日に、もう決まっていました。

2週間前に始めると、1ヶ月前に習ったことは、ほとんど消えています。テスト勉強のつもりで、最初から覚え直すことになります。

授業があった日の夜に、15分だけ。その日やった所を、閉じて、思い出しておく。

これを続けた人にとって、テストの2週間前は、「2回目」か「3回目」です。まとめてやる人にとっては、「1回目」です。

## 「何日、あければいいですか？」

よく聞かれます。答えは、「だいたいで、いい」です。

「1日後、1週間後、1ヶ月後に復習する」。そういう表を、見たことがあると思います。巻頭ページで計算した通り、あの表の通りにやると、1日にやる量が、どんどん増えていきます。続きません。

守るのは、1つだけです。

　　==2回目は、別の日にやる。==

少なくとも1日あける。それで、十分です。（無理なく続けられるやり方は、16番に書きました）

## 「分ける」は、この本で、何度も出てきます

```
　　忘れる前に、もう一度思い出す　　　16
　　解く練習は、種類を混ぜる　　　　　17
　　短い時間でも、毎日やる　　　　　　31
　　25分で、区切る　　　　　　　　　　37
```

形は違いますが、もとは、この絶対法則05です。

分けて、何度もやる。だから、1回目を完璧にする必要は、ありません。次の絶対法則06で、説明します。

## 頭のいい人と伸びない人の違い

前日にやれば、間に合う

頭のいい人

## 今日からできる3STEP

題：頭のいい人の『分け方』3STEP

STEP01
今日の授業を、夜15分、閉じて言う
「今日が、1回目」

STEP02
まとめてやる予定を、3日に分ける
「1時間ずつ、3日でやろう」

STEP03
2回目は、思い出せなかった所だけ
「印の所だけ、もう1回」

できた基準
同じ内容を、日をあけて3回、閉じて言えたらOK！

## まとめ

同じ時間でも、まとめるか、分けるかで、残る量が変わる。

```
　　1　まとめてやると、その日は効く。でも、数日で消える
　　2　続けて2回より、間をあけて2回。使う時間は、同じ
　　3　テストの範囲は、授業の日に決まっている。その日が、1回目
```

だから、時間は増やさない。分ける。
