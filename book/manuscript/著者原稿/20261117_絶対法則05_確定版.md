まとめてやらない。分けて、繰り返す

## 導入文

「一夜漬けは、やめなさい」

何度も、言われてきたと思います。

でも、やめられませんよね。

やりたくて、やっているわけでは、ありません。部活がある。提出物がある。ほかの教科の小テストもある。気づいたら、テストは明日です。もう、一気に詰めこむしか、ありません。

しかも、やっかいなことに、==一夜漬けは、効きます。==

前の日に3時間、必死に詰めこむ。次の日のテストは、そこそこ取れます。「なんとかなった」。だから、次のテストの前の日も、同じことが起きます。

　　追い込まれる　→　一夜漬け　→　なんとかなる　→　また、追い込まれる

問題は、そのあとです。

「定期テストは、取れるんです。でも、模試になると、全然取れなくて」

本当によく聞く相談です。1ヶ月後の模試に、同じ単語が出ます。……出てこない。あんなに、やったのに。

サボったわけでは、ありません。3時間、ちゃんとやっています。

時間は、増やしません。変えるのは、==同じ3時間を、1日にまとめるか、何日かに分けるか==です。それだけで、1ヶ月後に残る量が、変わります。

分けて、間をあけて、繰り返す。これを、「分散」と呼びます。

絶対法則04で、「どこをやるか」を決めました。次は、「いつやるか」です。

頭のいい人の絶対法則、5つ目。「分散」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「まとめて一気にやる」
じゃあ、何をするの？

## 本文

## 腹筋300回。1日でやりますか。30日に分けますか

1つ、聞かせてください。

```
　　A　今日1日で、腹筋を300回やる
　　B　1日10回を、30日続ける
```

1ヶ月後、腹筋がついているのは、どっちでしょうか。

……

Bですよね。迷わなかったと思います。Aは、次の日、筋肉痛で動けなくなるだけです（笑）

合計は、どちらも300回です。違うのは、まとめたか、分けたか。それだけです。

体のことなら、誰でも、分けたほうがいいと知っています。

ところが、勉強になると、ほとんどの人が、Aをやります。テストの前の日に、3時間。英単語を100個、一気に。

自分の頭で、確かめてみてください。

前回の定期テストの前の日に、必死で覚えたこと。今、3つ、言えますか。

定期テストがない人は、次のどれかでも、いいです。

```
　　模試や検定の前の日に、詰めこんだこと。3つ、言えますか
　　1日でまとめて見た、授業の動画。中身を、3つ、言えますか
　　一気に見たドラマの、3話目。何が起きたか、言えますか
```

……

出てこなかった人が、多いと思います。

では、7×8は。

……

56です。一瞬で、出たはずです。

九九を覚えたのは、小学2年生。何年も前です。それなのに、ついこの前、一気に入れたものが消えて、九九は残っています。

「あれだけやったんだから、当たり前でしょ」。そう思った人。九九の覚え方を、思い出してください。

九九を、一晩で覚えた人は、いません。2の段から始めて、毎日、少しずつ。学校で言って、家でも言って、何週間もかけました。

もし九九を、テストの前の晩に一気に詰めこんでいたら、今、7×8は、出てこなかったはずです。

　　==間をあけて、何度も思い出したものは、長く残ります。==

## 【研究結果】続けて2回より、間をあけて2回

腹筋は、体の話でした。頭でも、同じことが起きるのか。アメリカの大学の研究者たちが、実験で確かめています。

大学生に同じ文章を読んでもらって、3つのグループに分けました。

```
　　①　1回だけ読む
　　②　2回、続けて読む
　　③　1回読んで、1週間あけてから、もう1回読む
```

テストは、読んだ直後と、2日後の、2通りでやりました。

```
　　直後のテスト　　②が1位。③は、①とほとんど変わらなかった
　　2日後のテスト　③が1位。②は、①とほとんど変わらなくなった
```

順位が、ひっくり返っています。

②と③は、どちらも2回読んでいます。使った時間は、同じです。違うのは、続けたか、あけたか。それだけです。

同じ時間でも、まとめるより、間をあけたほうが、長く残る。専門用語で、「分散効果」と言います。（名前は、覚えなくてOKです）

この実験だけの話では、ありません。記憶の研究では、100年以上前から、何度も確かめられてきたことです。

## まとめてやると、「効いた気」がします

さっきの実験でも、直後のテストは、続けて読んだ②が1位でした。まとめてやると、その日のうちは、本当に効きます。「なんとかなった」は、気のせいでは、ありません。

でも、長くは、持ちません。

入試は、覚えた次の日には、ありません。3ヶ月後、1年後、3年後です。前の日に詰めこんだ単語は、そこまで持ちません。そして、また1から、覚え直すことになります。

```
　　まとめてやる　→　その日は残る。でも、長くは持たない。また1から覚え直す
　　分けてやる　　→　1回ごとの手ごたえは小さい。でも、消えにくい
```

==まとめてやる人は、同じものを、何度も1から覚え直しています。==

## 同じ3時間を、3日に分けるだけです

やることは、増やしません。分けるだけです。腹筋の300回を、30日に分けたのと、同じです。

```
　　×　前の日に、3時間　　　　　合計3時間
　　○　1時間を、3日に分ける　　合計3時間
```

分けると、2回目にやる時は、少し忘れています。忘れかけたものを、「うーん」と思い出すことになります。

気づきましたか。絶対法則02の「思い出す」と、絶対法則03の「負荷」が、両方入っています。

まとめてやると、まだ覚えているうちに次をやるので、スラスラ進みます。負荷が、かかりません。分けてやると、毎回、少し忘れた所から始まるので、「うーん」となります。

　　==分けるだけで、「思い出す」と「負荷」が、勝手に入ります。==

## テストの範囲は、授業を受けた日に、もう決まっています

「2週間前から、本気を出す」。そう決めている人も、多いと思います。

でも、範囲表に書いてあるのは、新しい情報では、ありません。この1ヶ月か2ヶ月、授業でやった所です。範囲は、授業を受けたその日に、もう決まっていました。

2週間前に始めると、1ヶ月前に習ったことは、かなり忘れています。テスト勉強のつもりで、最初から覚え直すことになります。

授業があった日の夜に、15分だけ。その日やった所を、閉じて、思い出しておく。これが、「1回目」です。

学校の授業でなくても、同じです。動画の授業でも、自分で進めた参考書でも、新しくやった日の夜が、「1回目」です。

そのあとは、たとえば、こうなります。

```
　　授業の日の夜　　　1回目　　15分、閉じて言う
　　その週の週末　　　2回目　　言えなかった所だけ
　　テストの1週間前　 3回目　　言えなかった所だけ
　　テストの前の日　　4回目　　確認するだけ
```

テストの前の日には、同じ所を、もう3回やっています。だから、前の日は、確認するだけで終わります。

まとめてやる人は、同じ所を、前の日に初めてやります。前の日が、「1回目」です。

　　==前の日に追い込まれるのは、前の日が、「1回目」になっているからです。==

## 「何日、あければいいですか？」

よく聞かれます。答えは、「1日以上あけば、あとは、だいたいで、いい」です。

さっきの表には、「その週の週末」「テストの1週間前」と書きました。ぴったり守らなくて、大丈夫です。3日後になっても、5日後になっても、分けた効果は、あります。

「1日後、1週間後、1ヶ月後に復習する」。そういう表を、見たことがあると思います。巻頭ページで計算した通り、あの表を、覚えたもの全部で守ろうとすると、1日にやる量が、どんどん増えていきます。ほとんどの人は、続きません。完璧な表を守ろうとして、3日でやめてしまったら、もったいないです。

絶対法則04を、思い出してください。先に、「やらないといけないこと」。「やったほうがいいこと」は、そのあと、でした。

分散も、同じです。

```
　　やらないといけないこと　　2回目は、別の日にやる
　　やったほうがいいこと　　　3回目、4回目と、間をあけて重ねる
```

　　==まず、「2回目は、別の日にやる」。これだけは、守ってください。==

それができたら、3回目、4回目を足します。いつやるか迷ったら、「週末」と「テストの前」に置けば、十分です。（無理なく続けられるやり方は、16番に書きました）

## 「分ける」は、この本で、何度も出てきます

```
　　忘れる前に、もう一度思い出す　　　16
　　解く練習は、種類を混ぜる　　　　　17
　　短い時間でも、毎日やる　　　　　　31
　　25分で、区切る　　　　　　　　　　37
```

形は違いますが、もとは、この絶対法則05です。

分けて、何度もやる。だから、1回目を完璧にする必要は、ありません。次の絶対法則06で、説明します。

## 頭のいい人と伸びない人の違い

伸びない人
まとめて一気に
前の日に、なんとかする

頭のいい人
分けて繰り返す
今日はここまで。また明日

## 今日からできる3STEP

題：頭のいい人の『分け方』3STEP

STEP01
今日やった所を、夜15分、閉じて言う
「今日が、1回目」

STEP02
まとめてやる予定を、3日に分ける
「1時間ずつ、3日でやろう」

STEP03
2回目は、言えなかった所だけやる
「2回目は、すぐ終わるな」

できた基準
同じ内容を、日をあけて3回、閉じて言えたらOK！

## まとめ

同じ時間でも、まとめるか、分けるかで、残る量が変わる。

```
　　1　まとめてやると、その日は効く。でも、長くは持たない
　　2　続けて2回より、間をあけて2回。使う時間は、同じ
　　3　テストの範囲は、授業の日に決まっている。その日が、1回目
```

だから、時間は増やさない。分ける。2回目は、別の日にやる。
迷ったら、自分に聞きます。「これ、次は、いつやる？」

組む時の注意（本文には入れない）

- 腹筋の問いのあと（「Bですよね」より先）と、「今、3つ、言えますか」のあと（「出てこなかった人が」より先）は、問いと同じ見開きに置かない
- 「7×8は」のあと（「56です」より先）も、同じ
- 九九は、小学2年生で、何週間もかけて習う（学校によって長さは違うので、本文は「何週間も」と書いた）
- 腹筋のたとえは、03番のダンベル（重さ＝負荷）の続き。05番は、回数の分け方
- 【研究結果】の中身（1回／続けて2回／1週間あけて2回。直後と2日後のテスト。結果の向き）は、この実験を引用しているほかの論文の説明で確かめた。大学名（コロラド大学）は、まだ確かめられていないので、本文は「アメリカの大学の研究者たち」にしてある。要旨で確かめられたら、「コロラド大学の研究者たちの実験」に直せる
- 「分散効果」（spacing effect。間隔効果とも言う）は、1885年のエビングハウスの本から研究が続いている。本文は「100年以上前から、何度も確かめられてきた」と書いた。巻末の参考文献では、「10の学習法の有効性を比較した報告」（分散学習が高評価）に、05番の番号を足す
- この実験は、大学生が「読み返す」時の比べ方。中学生の教室で同じことをやって、差が出なかった、という別の報告もある。だから本文は「大学生に」と書いて、「誰でも必ず」とは書いていない。この本ですすめているのは、読み返しではなく、間をあけて「思い出す」こと
- 「次の日のテストは、そこそこ取れます」は、言い切らない書き方にした（一夜漬けで取れない人もいるため）
