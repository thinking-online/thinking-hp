まとめてやらない。分けて、繰り返す

## 導入文

「一夜漬けは、やめなさい」

何度も、言われてきたと思います。

でも、やめられませんよね。

やりたくて、やっているわけでは、ありません。部活がある。提出物がある。ほかの教科の小テストもある。気づいたら、テストは明日です。もう、一気に詰めこむしか、ありません。

しかも、やっかいなことに、==一夜漬けは、効きます。==

前の日に3時間、必死に詰めこむ。次の日のテストは、そこそこ取れます。「なんとかなった」。だから、次のテストの前の日も、同じことが起きます。

　　追い込まれる　→　一夜漬け　→　なんとかなる　→　また、追い込まれる

問題は、そのあとです。

「定期テストは、取れるんです。でも、模試になると、全然取れなくて」

本当によく聞く相談です。1ヶ月後の模試に、同じ単語が出ます。……出てこない。あんなに、やったのに。

サボったわけでは、ありません。3時間、ちゃんとやっています。

時間は、増やしません。変えるのは、==同じ3時間を、1日にまとめるか、何日かに分けるか==です。それだけで、1ヶ月後に残る量が、変わります。

分けて、間をあけて、繰り返す。これを、「分散」と呼びます。

絶対法則04で、「どこをやるか」を決めました。次は、「いつやるか」です。

頭のいい人の絶対法則、5つ目。「分散」を、具体的に見ていきましょう。

## 質問ページ

頭のいい人が絶対やらないこと
「まとめて一気にやる」
じゃあ、何をするの？

## 本文

## 腹筋300回。1日でやりますか。30日に分けますか

1つ、聞かせてください。

```
　　A　今日1日で、腹筋を300回やる
　　B　1日10回を、30日続ける
```

1ヶ月後、腹筋がついているのは、どっちでしょうか。

……

Bですよね。迷わなかったと思います。Aは、次の日、筋肉痛で動けなくなるだけです（笑）

合計は、どちらも300回です。違うのは、まとめたか、分けたか。それだけです。

体のことなら、誰でも、分けたほうがいいと知っています。

ところが、勉強になると、ほとんどの人が、Aをやります。テストの前の日に、3時間。英単語を100個、一気に。

自分の頭で、確かめてみてください。

前回の定期テストの前の日に、必死で覚えたこと。今、3つ、言えますか。

定期テストがない人は、次のどれかでも、いいです。

```
　　模試や検定の前の日に、詰めこんだこと。3つ、言えますか
　　1日でまとめて見た、授業の動画。中身を、3つ、言えますか
　　一気に見たドラマの、3話目。何が起きたか、言えますか
```

……

出てこなかった人が、多いと思います。

では、7×8は。

……

56です。一瞬で、出たはずです。

九九を覚えたのは、小学2年生。何年も前です。それなのに、ついこの前、一気に入れたものが消えて、九九は残っています。

「あれだけやったんだから、当たり前でしょ」。そう思った人。その通りです。たくさん、言いました。

ただ、まとめては、言っていません。2の段から始めて、毎日、少しずつ。学校で言って、家でも言って、何週間もかけました。同じ回数を、一晩でやった人は、いません。

もし、同じ回数を、一晩でまとめてやっていたら、どうだったでしょうか。腹筋のAと、同じです。

　　==間をあけて、何度も思い出したものは、長く残ります。==

## 【研究結果】同じ2回でも、間をあけると、結果が変わった

腹筋も、九九も、たまたまでは、ありません。アメリカの大学の研究者たちが、実験で確かめています。

大学生に文章を読んでもらって、3つのグループに分けました。実験は2つで、参加したのは、合わせて400人以上です。

```
　　①　1回だけ読む
　　②　2回、続けて読む
　　③　1回読んで、1週間あけてから、もう1回読む
```

テストは、読んだ直後と、2日後の、2通りでやりました。

```
　　直後のテスト　　①より点が高かったのは、②だけ。③は、①とほとんど変わらなかった
　　2日後のテスト　①より点が高かったのは、③だけ。②は、①とほとんど変わらなくなった
```

結果が、ひっくり返っています。

②と③は、どちらも2回読んでいます。読んだ回数は、同じです。違うのは、続けたか、あけたか。それだけです。

同じ量の勉強でも、まとめるより、間をあけたほうが、長く残る。専門用語で、「分散効果」と言います。（名前は、覚えなくてOKです）

この実験だけの話では、ありません。記憶の研究では、100年以上前から、何度も確かめられてきたことです。

## まとめてやると、すぐあとのテストには、効きます

さっきの実験でも、直後のテストで点が上がったのは、続けて読んだ②だけでした。まとめてやると、すぐあとのテストには、本当に効きます。「なんとかなった」は、気のせいでは、ありません。

でも、長くは、持ちません。

入試は、覚えた次の日には、ありません。3ヶ月後、1年後、3年後です。前の日に詰めこんだ単語は、そこまで持ちません。

```
　　まとめてやる　→　すぐあとは残る。でも、長くは持たない。また1から覚え直す
　　分けてやる　　→　1回ごとの手ごたえは小さい。でも、消えにくい
```

==まとめてやる人は、同じものを、何度も1から覚え直しています。==

## 同じ3時間を、3日に分けるだけです

やることは、増やしません。分けるだけです。腹筋の300回を、30日に分けたのと、同じです。

```
　　×　前の日に、3時間　　　　　合計3時間
　　○　1時間を、3日に分ける　　合計3時間
```

範囲を3つに切って、1日ずつやる、という意味では、ありません。同じ所を、3日に分けて、3回やります。

分けると、2回目にやる時は、少し忘れています。閉じて思い出そうとすると、「うーん」となります。

気づきましたか。絶対法則02の「思い出す」に、絶対法則03の「負荷」が、かかっています。

まとめてやると、まだ覚えているうちに次をやるので、スラスラ出てきます。負荷が、かかりません。分けてやると、毎回、少し忘れた所から始まるので、「うーん」となります。

　　==分けると、「思い出す」に、ちょうどいい負荷がかかります。==

## テストの範囲は、授業を受けた日に、もう決まっています

3時間を、3日に分ける。それだけでも、変わります。もう1つ、できることがあります。最初にやる日を、もっと前に持ってくることです。

「2週間前から、本気を出す」。そう決めている人も、多いと思います。

でも、範囲表に書いてあるのは、新しい情報では、ありません。この1ヶ月か2ヶ月、授業でやった所です。範囲は、授業を受けたその日に、もう決まっていました。

2週間前に始めると、1ヶ月前に習ったことは、かなり忘れています。テスト勉強のつもりで、最初から覚え直すことになります。前の日に始める人は、授業で聞いたきりのことを、前の日に、初めて自分で思い出すことになります。

　　==前の日に追い込まれるのは、前の日が、「1回目」になっているからです。==

だから、「1回目」を、前に持ってきます。

授業があった日の夜に、15分だけ。その日やった所を、閉じて、思い出しておく。これが、「1回目」です。

時間を足すのが目的では、ありません。テストの前にやるはずだった分を、先に、少しずつやっておくだけです。そのぶん、テストの前は、軽くなります。

学校の授業でなくても、同じです。動画の授業でも、自分で進めた参考書でも、新しくやった日の夜が、「1回目」です。

## 「2回目は、何日あければいいですか？」

よく聞かれます。答えは、「1日以上あけば、あとは、だいたいで、いい」です。次の日でも、3日後でも、週末でも、分けた効果は、あります。

損をするのは、同じ日に続けてやる時です。あけるのが、少し長すぎるくらいなら、損は、ほとんどありません。

「1日後、1週間後、1ヶ月後に復習する」。そういう表を、見たことがあると思います。巻頭ページで計算した通り、あの表を、覚えたもの全部で守ろうとすると、1日にやる量が、どんどん増えていきます。ほとんどの人は、続きません。完璧な表を守ろうとして、3日でやめてしまったら、もったいないです。

絶対法則04を、思い出してください。先に、「やらないといけないこと」。「やったほうがいいこと」は、そのあと、でした。

分散も、同じです。

```
　　やらないといけないこと　　2回目は、別の日にやる
　　やったほうがいいこと　　　3回目、4回目と、間をあけて重ねる
```

　　==まず、「2回目は、別の日にやる」。これだけは、守ってください。==

同じ日のうちに、何度言い直しても、数え方は「1回目」のままです。言い直すのは、いいことです。ただ、「2回目」は、日が変わってから、です。

1回目から4回目までを並べると、こうなります。迷ったら、この通りに置いてください。

```
　　習った日の夜　　　1回目　　15分、閉じて言う
　　次の日か、週末　　2回目　　言えなかった所だけ
　　テストの1週間前　 3回目　　言えなかった所だけ
　　テストの前の日　　4回目　　確認するだけ
```

日にちは、ぴったりでなくて、大丈夫です。

こうしておくと、テストの前の日には、同じ所を、もう3回やっています。前の日は、確認するだけで終わります。もう、追い込まれません。

## 「1日の中では、どうすればいいですか？」

ここまでは、日をまたぐ話でした。

1日の中にも、まとめてやらないための、やり方があります。くわしくは、このあとの項目に書きました。

```
　　25分で、区切る　　　　　　　37
　　すきまの3分を使う　　　　　31
　　同じ種類を続けず、混ぜる　　17
```

ただ、1日の中でどれだけうまくやっても、その日だけで終わりにしたら、長くは残りません。

だから、絶対法則05で決めることは、1つだけです。

　　==同じものを、別の日に、もう一度やる。==

別の日にやる時のやり方は、16番に書きました。

何度もやるので、1回目を完璧にする必要は、ありません。次の絶対法則06で、説明します。

## 頭のいい人と伸びない人の違い

伸びない人
まとめて一気に
前の日に、なんとかする

頭のいい人
分けて繰り返す
今日はここまで。また明日

## 今日からできる3STEP

題：頭のいい人の『分け方』3STEP

STEP01
今日やった所を、夜15分、閉じて言う
「今日が、1回目」

STEP02
2回目をやる日を、決めて書く
「次は、土曜にやろう」

STEP03
決めた日に、言えなかった所だけやる
「2回目は、すぐ終わるな」

できた基準
同じ内容を、別の日にもう一度、閉じて言えたらOK！

## まとめ

同じ時間でも、まとめるか、分けるかで、残る量が変わる。

```
　　1　まとめてやると、すぐあとには効く。でも、長くは持たない
　　2　同じ2回でも、間をあけたほうが、あとまで残る
　　3　追い込まれるのは、前の日が「1回目」だから。習った日を、1回目にする
```

だから、時間は増やさない。分ける。2回目は、別の日にやる。
迷ったら、自分に聞きます。「これ、次は、いつやる？」

組む時の注意（本文には入れない）

- 腹筋の問いのあと（「Bですよね」より先）と、「今、3つ、言えますか」のあと（「出てこなかった人が」より先）は、問いと同じ見開きに置かない
- 「7×8は」のあと（「56です」より先）も、同じ
- 九九は、小学2年生で、何週間もかけて習う（学校によって長さは違うので、本文は「何週間も」と書いた）
- 腹筋のたとえは、03番のダンベル（重さ＝負荷）の続き。05番は、回数の分け方
- 【研究結果】のもと：Rawson, K. A., & Kintsch, W. (2005). Rereading effects depend on time of test. Journal of Educational Psychology, 97(1), 70–80. https://doi.org/10.1037/0022-0663.97.1.70（著者の別の作業で確かめた。出典台帳 081d7ee）
- 実験の中身：大学生に、二酸化炭素を地中にためる技術の説明文（約1,700語）を読んでもらった。実験は2つで、合わせて約420人（本文は「400人以上」）。3つのグループ（1回／続けて2回／1週間あけて2回）。テストは、直後と2日後
- 読んだ回数は同じだが、読むのにかかった時間が同じかどうかは、確かめていない。本文は「読んだ回数は、同じです」と書いた
- 01番の実験（1回より2回読んだほうが点が高い）と、05番の2日後の結果（続けて2回は、1回とほとんど変わらない）は、テストをした時が違うと思われる。01番の実験のテストがいつだったかは、まだ確かめていない
- 結果の書き方：論文は、②と③を、それぞれ①と比べている。②と③を直接比べて順位を決めてはいないようなので、「1位」「順位」とは書かず、「①より点が高かったのは、②だけ／③だけ」「結果が、ひっくり返っています」にした
- 大学名（コロラド大学）は、確かめられていない。本文は「アメリカの大学の研究者たち」のまま
- 「分散効果」（spacing effect。間隔効果とも言う）。「100年以上前から、何度も確かめられてきた」のもと：エビングハウス（1885年）と、300件以上の実験をまとめた分析（Cepeda ほか、2006年、Psychological Bulletin）。巻末の参考文献に足した
- 「1日以上あけば、あとは、だいたいで、いい」：「同じ日に続けてやるより、1日でもあけたほうがいい」「長めにずれても損は小さい」までは、研究と合う。1年先まで残したいなら、数週間あけたほうが残るので、「1日あければ十分」とは書かない。「損をするのは、同じ日に続けてやる時です。あけるのが、少し長すぎるくらいなら、損は、ほとんどありません」を足した
- この実験を学校の授業でやり直した研究（Greving & Richter, 2018）では、2日後に「あけて2回」が有利になる結果は出なかった。聞かれたら、「この実験1本ではなく、300件以上の実験をまとめた分析が根拠」と答える。本文の「この実験だけの話では、ありません」が、その守り。この本ですすめているのは、読み返しではなく、間をあけて「思い出す」こと
- 「次の日のテストは、そこそこ取れます」は、言い切らない書き方にした（一夜漬けで取れない人もいるため）
