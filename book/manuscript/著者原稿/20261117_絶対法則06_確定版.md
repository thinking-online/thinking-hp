絶対法則06　速度
完璧を待たない。解いて、直す

## 導入文

「基礎が、大事」

「ちゃんと理解してから、次に進みなさい」

何度も、言われてきたと思います。どちらも、正しいです。

だから、真面目な人ほど、こうなります。

「まだ基礎が完璧じゃないので、問題集は、来月からにします」

「過去問は、もう少し力がついてから、開きます」

英語の文法書を、第1章から、丁寧に読む。わからない所は、戻って読み直す。ノートにも、まとめる。完璧に理解してから、問題集に進むつもりです。

3週間たちました。まだ、第2章です。問題は、1問も解いていません。

サボっているわけでは、ありません。毎日、ちゃんと机に向かっています。

ただ、==完璧を待っている間、点は、1点も動いていません。==

結果を出す人は、逆のことをします。完璧になる前に解いて、間違えて、直します。

この「解く → 間違える → 直す」を、どれだけ早く始めて、何回やるか。それを、「速度」と呼びます。問題を速く解く、という意味では、ありません。

頭のいい人の絶対法則、6つ目。「速度」を、具体的に見ていきましょう。

## 本文

## 新しいゲームを始める時、説明を、全部読みますか？

新しいゲームを始める時のことを、思い出してください。

説明を、最初から最後まで全部読んで、完璧に理解してから、始めますか。

……

ほとんどの人が、読みません。まず、やってみます。

やってみる。負ける。「あ、こうすればいいのか」と、やり方を変える。また、やる。

この繰り返しで、気づいたら、うまくなっています。

ゲームなら、誰でも、こうやっています。ところが、勉強になると、急に変わります。

　　「ちゃんと理解してから、問題を解こう」
　　「基礎を固めてから、過去問を開こう」

うまくなる順番は、ゲームも、勉強も、同じです。

　　==やってみる　→　間違える　→　直す==

うまくなるのは、「直す」の所です。そして、やってみないと、直す所が見つかりません。

## 「完璧にしてから」の日は、来ません

読んでいるだけでは、自分がどこをわかっていないのかが、わかりません。わからないので、全部を、もう1回読みます。それでも不安なので、もう1回読みます。

絶対法則01で見た通り、3回目からは、読んでも、点はほとんど増えません。

わかっていない所は、解いて、×がついた時に、初めて見つかります。

　　==わかってから、解く。ではなく、解いてから、わかる。==

## 6割わかったら、もう解きます

だから、決まりは、1つです。

　　==6割わかったら、もう解く。==

6割は、だいたいの目安です。「半分よりは、わかった」と思ったら、読むのをやめて、解いてください。

絶対法則05で書いた通り、同じ所は、このあと何度もやります。1回目から完璧にする必要は、ありません。

解くと、×がつきます。×がついた所が、わかっていなかった所です。そこだけ戻って、読み直します。

```
　　完璧にしてから解く　→　全部を何回も読む。どこが弱いかは、最後までわからない
　　6割で解いて、直す　 →　×がついた所だけを読み直す。弱い所から、埋まる
```

ほとんど解けなかった時は、読む所に戻れば、いいだけです。それも、解いたから、わかったことです。

Done is better than perfect.

完璧を目指すより、まず終わらせろ。終わらせてから、直せばいいんです。

## 早くするのは、「始める」だけです

雑にやれ、という話では、ありません。

```
　　早くすること　　　解き始めるのを、早くする
　　早くしないこと　　×は、○になるまで、ちゃんと直す
```

6割で解き始めて、×を放っておいたら、6割のままです。解き始めるのは、早く。直すのは、最後まで。この2つで、1セットです。

伸びる速さは、読んだ時間より、直した回数で変わります。

## ×は、失敗ではありません。次にやる所の、目印です

×がつくのが、こわい。その気持ちは、わかります。

でも、×が1つもつかない勉強は、もうできることを、確認しているだけです。絶対法則03で見た通り、それでは、できることは増えません。

×がついた所が、「うーん」となる所です。伸びるのは、そこです。

できていないこと自体は、何も悪くありません。悪いのは、できないままで、いることです。

「こんなことを聞いたら、恥ずかしい」。そう思って、聞けないまま進んでしまう人も、います。昔の僕も、そうでした。今は、AIがあります。中学の内容でも、同じことを何回聞いても、笑われません。（聞き方は、48番に書きました）

## 小さく、早く、1回、勝ってください

早く解いたほうがいい理由が、もう1つあります。

勝つ、というのは、第一志望に受かることだけでは、ありません。

```
　　小テストで、満点を取る
　　前回より、5点上げる
　　1冊の問題集を、最後まで終わらせる
```

どれも、勝ちです。そして、小さい勝ちを、早く1回やった人が、強くなります。「やれば変わる」ということを、自分で1回、確かめるからです。

人から「やればできるよ」と100回言われるより、自分で1回、変えた経験のほうが、ずっと効きます。

今の小テストで0点を取っても、人生は、何も変わりません。だから、今が、一番試せます。

## 6つの絶対法則が、そろいました

「早く始める」は、このあとの項目にも出てきます。

```
　　読む前に、問題を1問だけ見ておく　11
　　考える時間を、先に決める　　　18
　　過去問は、最初に開く　　　　　34
　　片づける前に、1問解く　　　　40
```

形は違いますが、もとは、この絶対法則06です。

これで、6つの絶対法則が、全部そろいました。迷った時は、この6つを、自分に聞いてください。

```
　　01　疑う　　　　これで、点は上がる？
　　02　思い出す　　今、何も見ずに言える？
　　03　負荷　　　　今、うーんってなってる？
　　04　戦略　　　　これ、ゴールに必要？
　　05　分散　　　　これ、次は、いつやる？
　　06　速度　　　　もう、解いてみた？
```

第2章からは、この6つを、場面ごとに使っていきます。

## 頭のいい人と伸びない人の違い

## 今日からできる3STEP

題：頭のいい人の『進み方』3STEP

STEP01
読むのをやめるページに、ふせんを貼る
「ここまで読んだら、解く」

STEP02
ふせんまで読んだら、5問解く
「6割わかった。もう解こう」

STEP03
×の所だけ読んで、もう一度解く
「ここだけ読んで、もう1回」

できた基準
×だった問題を、何も見ずに、○にできたらOK！

## まとめ

完璧を待っている間、点は動かない。伸びるのは、解いて、直した時。

```
　　1　「完璧にしてから」の日は、来ない。わかっていない所は、解いて初めて見つかる
　　2　6割わかったら、解く。×がついた所だけ、読み直す
　　3　早くするのは、始めるだけ。×は、○になるまで直す
```

だから、完璧主義ではなく、改善主義。
迷ったら、自分に聞きます。「もう、解いてみた？」

組む時の注意（本文には入れない）

- 「新しいゲーム」の問いのあと（「ほとんどの人が、読みません」より先）は、問いと同じ見開きに置かない

- 最後の「6つを、自分に聞いてください」の表は、01〜06番のまとめの問いを並べたもの（01番は、2コマの言葉から取った）。新しい中身は足していない。著者に確認する
