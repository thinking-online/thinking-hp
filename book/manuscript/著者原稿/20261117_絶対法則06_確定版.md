## 導入文

「まだ基礎が完璧じゃないので、問題集は、来月からにします」

「過去問は、もう少し力がついてから、開きます」

真面目な生徒ほど、こう言います。

英語の文法書を、第1章から、丁寧に読む。わからない所は、戻って読み直す。ノートにも、まとめる。完璧に理解してから、問題集に進むつもりです。

3週間たちました。まだ、第2章です。問題は、1問も解いていません。

サボっているわけでは、ありません。毎日、ちゃんと机に向かっています。

ただ、==完璧を待っている間、点は、1点も動いていません。==

結果を出す人は、逆のことをします。早く解いて、早く間違えて、早く直します。

やってみる。間違える。直す。この1回を、どれだけ早く、何回やるか。それを、「速度」と呼びます。問題を速く解く、という意味では、ありません。

頭のいい人の絶対法則、6つ目。「速度」を、具体的に見ていきましょう。

## 本文

## 新しいゲームを始める時、説明を、全部読みますか？

新しいゲームを始める時のことを、思い出してください。

説明を、最初から最後まで全部読んで、完璧に理解してから、始めますか。

……

ほとんどの人が、読みません。まず、やってみます。

やってみる。負ける。「あ、こうすればいいのか」と、やり方を変える。また、やる。

この繰り返しで、気づいたら、うまくなっています。

ゲームなら、誰でも、こうやっています。「完璧に理解してから、始めます」と言う人は、いません。

ところが、勉強になると、急に変わります。

　　「ちゃんと理解してから、問題を解こう」
　　「基礎を固めてから、過去問を開こう」

うまくなる順番は、ゲームも、勉強も、同じです。

　　==やってみる　→　間違える　→　直す==

うまくなるのは、「直す」の所です。そして、やってみないと、直す所が見つかりません。

## 「完璧にしてから」の日は、来ません

ちゃんと理解してから、解く。基礎を固めてから、過去問。きれいなノートができてから、覚える。

どれも、真面目な人ほど、やります。そして、どれも、同じ所で止まります。

完璧になる日が、来ないからです。

読んでいるだけでは、自分がどこをわかっていないのかが、わかりません。わからないので、全部を、もう1回読みます。それでも不安なので、もう1回読みます。

絶対法則01で見た通り、3回目からは、読んでも点は増えません。

## 6割わかったら、もう解きます

やることは、逆です。

　　==6割わかったら、もう解いてしまう。==

6割は、だいたいの目安です。「半分よりは、わかった」と思ったら、解いてください。

解くと、×がつきます。×がついた所が、わかっていなかった所です。そこだけ戻って、読み直します。

```
　　完璧にしてから解く　→　全部を3回読む。どこが弱いかは、最後までわからない
　　6割で解いて、直す　 →　×がついた所だけを読み直す。弱い所から、埋まる
```

同じ1ヶ月でも、差がつきます。

完璧にしてから解く人は、1ヶ月たっても、「やってみる → 間違える → 直す」が、まだ0回です。6割で解く人は、同じ1ヶ月で、何回もやっています。

伸びる速さを決めているのは、読んだ時間では、ありません。==直した回数==です。

Done is better than perfect.

完璧を目指すより、まず終わらせろ。終わらせてから、直せばいいんです。

## ×は、失敗ではありません。次にやる所の、目印です

×がつくのが、こわい。その気持ちは、わかります。

でも、×が1つもつかない勉強は、もうできることを、確認しているだけです。絶対法則03で見た通り、それでは、できることは増えません。

×がついた所が、「うーん」となる所です。伸びるのは、そこです。

できていないこと自体は、何も悪くありません。

悪いのは、できないままで、いること。それだけです。

## 「こんな基礎も、わかっていないのか」

この学年で、こんなことを聞いたら、恥ずかしい。そう思って、聞けないまま進んでしまう人がいます。昔の僕も、そうでした。

今は、AIがあります。中学の内容でも、同じことを何回聞いても、笑われません。「恥ずかしくて聞けない」は、もう、止まる理由になりません。（聞き方は、48番に書きました）

## 小さく、早く、1回、勝ってください

早く解いたほうがいい理由が、もう1つあります。

勝つ、というのは、第一志望に受かることだけでは、ありません。

```
　　小テストで、満点を取る
　　前回より、5点上げる
　　1冊の問題集を、最後まで終わらせる
```

どれも、勝ちです。そして、小さい勝ちを、早く1回やった人が、強くなります。

「やれば変わる」ということを、自分で1回、確かめるからです。

人から「やればできるよ」と100回言われても、変わりません。自分で1回、変えたことがある人だけが、次も動けます。

今の小テストで0点を取っても、人生は、何も変わりません。だから、今が、一番試せます。

6つの絶対法則が、全部そろいました。

疑う。思い出す。負荷。戦略。分散。速度。

第2章からは、この6つを、場面ごとに使っていきます。

## 今日からできる3STEP

題：頭のいい人の『進み方』3STEP

STEP01
読むのをやめるページに、ふせんを貼る
「完璧は待たない。ここまで」

STEP02
ふせんまで読んだら、5問解く
「6割わかった。もう解こう」

STEP03
×の所だけ読んで、もう一度解く
「ここだけ読んで、もう1回」

できた基準
×だった問題を、何も見ずに、○にできたらOK！

## まとめ

伸びる速さは、どれだけ読んだかではなく、何回直したかで決まる。

```
　　1　「完璧にしてから」の日は、来ない。待っている間、点は動かない
　　2　6割わかったら、解く。×がついた所だけ、直す
　　3　×は、失敗ではなく、次にやる所の目印
```

だから、完璧主義ではなく、改善主義。
迷ったら、自分に聞きます。「もう、解いてみた？」
