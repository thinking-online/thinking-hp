# 新テンプレ試作　3本

著者案の流れで組み直したもの。採用前の見本。

```
　Q　生徒が実際に言う言葉で投げかける
　↓
　頭のいい人が絶対にやらないことを、まず明示する
　↓
　具体的な説明・解説・図
　↓
　じゃあどうすればいいのか（頭のいい人の思考プロセス＋手順）
　↓
　まとめ
```

章もタイプも散らして3本選んだ。
30は★厚く書く（演習）、25は標準（暗記）、40は行動系（集中）。
文体は序章v12にそろえてある。

# 30　解説を読んで納得したら、次の問題へ進む

出す力　★厚く書く

## Q「解説を読んだら分かるんです。でも、自分で解くとできません」

これ、面談でいちばん多く聞く言葉かもしれません。

サボってる子からは、出てこない言葉です。解説をちゃんと読んでる子しか言いません。つまり、この質問をしてる時点で、あなたはやってます。

じゃあ、なんで出ないのか。

## 頭のいい人が、絶対にやらないこと

　　==解説を読んで「なるほど」と思ったら、そのまま次の問題へ進む。==

これだけは、やりません。

```
　　×　なるほど、わかった。次いこう
　　○　わかった。……いや待て、いま読んだだけだ
```

## なぜ、それだと出ないのか

夜の9時。中学3年生。数学のワークの12問目、文章題で止まりました。5分考えて、出てこない。解説を開きます。3行目で「あ」と声が出ました。ここで両辺に2をかければ、きれいな形になる。そういうことか。最後まで読んで、納得しました。チェックをつけて、13問目へ。

2週間後のテスト。同じ形の問題が出ます。手が、止まります。

この子、解説を飛ばしてないんです。最後まで読んでます。5分考えてから開いてます。やることは全部やってる。それでも出ませんでした。

理由は、1つです。

解説を読んでるあいだ、頭がやってるのは「受け取る」作業だからです。

〔図30　受け取ると、取り出す〕
　左に「解説を読む＝受け取る」、右に「テスト＝取り出す」。
　矢印の向きが逆であることを、一目で見せる。

テストのとき、手元には問題用紙しかありません。解説はない。自分の頭の中から、取り出すしかない。受け取る練習を30回しても、取り出せるようにはならないんです。

能力の話じゃありません。練習してないことができない、っていうだけの話です。

そして、やっかいなのが、読んでるあいだの感覚です。

解説って、読みやすく書いてありますよね。だから、スラスラ読める。つまずかない。スラスラ読めると、頭はこう判断します。

　　わかった。

その判断が、まちがってます。==スラスラ読めたのは、書いてあったからです。==

## じゃあ、どうすればいいのか

### 頭のいい人の、頭のなか

同じ瞬間、2人の頭のなかで何が鳴ってるか、のぞいてみます。

伸びない人

```
　　「あー、なるほどね」
　　「ここで両辺に2をかけるのか」
　　「わかったわかった。次いこう」
```

3秒です。ここで終わります。

頭のいい人

```
　　「なるほど。……いや待て。いま、なるほどって言っただけだ」
　　「閉じたら、出るか？」
　　「2行目までは出る。3行目の、両辺に2をかけるところ。
　　　あれは自分で思いつくか？」
　　「たぶん、出ない」
　　「じゃあ、閉じる」
　　（解説を閉じて、白紙に書き始める）
　　「……やっぱり3行目で止まった」
　　「出なかったのは、3行目だけ。それ以外は出た」
```

40秒です。

違い、1か所しかありません。

　　「……いや待て」

ここだけです。なるほど、と思った瞬間に、もう1人が割り込んでくる。「それ、本当に出るのか？」と聞いてくる。この声を、頭のなかに置いてください。置ければ、あとは自動です。

### 手順

1　「なるほど」と言った瞬間に、手を止める

最後まで読み切る前でもいいです。なるほど、が合図です。そこで自分に聞きます。いま、閉じて出せるか？

2　閉じる

本当に閉じます。指で押さえたままにしない。裏返してもいい。白紙を出して、頭から書きます。

3　止まった場所に、印をつける

書けなくなったところで止まります。そこが、出せなかった場所です。解説をもう一度開いて、==その1行だけ==読みます。最初から読み直さないこと。出なかったのは、その1行だけです。

1問につき、1分です。

### やりすぎないように

全部の問題でやらなくていいです。○がついた問題は、そのままで大丈夫。やるのは、×だった問題と、たまたま合った問題だけ。

白紙にきれいに書く必要もありません。字は汚くていいです。清書を始めると、これも「見ながらやる作業」に戻ります。

## まとめ

　　==解説を読むのは、受け取る作業。テストは、取り出す作業。==

受け取る練習を何回しても、取り出せるようにはなりません。

残るのは、1問につき1行です。

　　この問題で、出なかったのは3行目

これが、テスト前日に効きます。ワークを全部やり直す人は、50問やり直します。この1行を持ってる人は、12行見るだけで済みます。

```
　　この場面を見つけた問い　　いま、閉じて出せるか？

　　今日やること　今日×だった問題を1問。解説を読んで「なるほど」と
　　　　　　　　　思ったら、閉じて白紙に書く。止まった場所を1行メモ
```

# 25　忘れてから、最初から覚え直す

入れる力

## Q「覚えても、次の日には忘れてるんですけど」

これも、めちゃくちゃ多いです。

先に結論を言っておきますね。

　　忘れるのは、あなただけじゃありません。

全員に起きます。頭のいい人も、同じように忘れます。違うのは、忘れたあとに何をするかです。

## 頭のいい人が、絶対にやらないこと

　　==忘れきってから、1ページ目に戻る。==

これを、やりません。

```
　　×　もう全部忘れた。1からやり直しだ
　　○　忘れる前に、間をあけてもう1回出す
```

## なぜ、それだと終わらないのか

高校1年生。夏休みに、英単語を500語やりました。8月の終わりには、ほとんど出せるようになってました。

9月は、学校が始まって忙しくて、単語に手をつけませんでした。10月も、中間テストがあってやりませんでした。11月、模試の前に単語帳を開きます。

ほとんど出てきません。

　　「もう全部忘れた。1からやり直しだ」

また、1ページ目から始めます。

覚えたことって、時間がたつとだんだん出にくくなりますよね。ある時点までは、ちょっと見れば思い出せる。その時点を過ぎると、見ても思い出せなくなる。

〔図25　忘れかけたところで、1回出す〕
　横軸に時間、縦軸に「出せる度合い」。
　下がりきってから開く線と、下がりかけで1回ずつ持ち上げる線を重ねる。

忘れきってから開くと、1回目と同じ作業をやることになります。500語を、また最初からです。

忘れかけてるうちに開くと、全然違います。500語のうち、出てこないのは100語くらい。その100語だけやればいいので、==5分の1の時間で済みます==。

ここで、「じゃあ毎日やればいいのか」と思うかもしれません。

毎日だと、効率が落ちます。昨日やったことは、まだ忘れてないので、思い出す練習になりません。

　　==ちょうどいいのは、忘れかけたころです。==

出しにくいタイミングで出すほうが、残ります。楽に出せるうちに出しても、あまり効きません。

## じゃあ、どうすればいいのか

### 頭のいい人の、頭のなか

11月、同じ単語帳を開いた瞬間です。

伸びない人

```
　　（単語帳を開く）「うわ、全然わからない」
　　「夏にやったのに」
　　「もう1回、最初からやるしかないな」
```

頭のいい人

```
　　「夏に500語やった。あれから2ヶ月半か」
　　「全部は残ってないな。どれくらい残ってる？」
　　（閉じて、50語ぶんテストしてみる）
　　「50個中、30個出た」
　　「6割残ってるのか。思ったより残ってる」
　　「出なかった20個に印をつけよう」
　　「500語全部じゃなくて、この割合なら200語くらいか」
　　「200語なら、3日で戻せる」
```

1からやり直してません。==残ってるものを数えて、残ってないものだけを拾ってます。==

### 手順

1　覚えた日に、復習の日を3つ決める

覚えた日に、カレンダーへ3つ印をつけます。

```
　　翌日　／　1週間後　／　1ヶ月後
```

この3回で、かなり残ります。

2　復習のときは、必ず閉じて出す

開いて眺めるのは、復習じゃありません。閉じて、出せるかどうかを確かめます。出たものは終わり。出なかったものだけ、もう一度見ます。

3　出なかったものだけ、次に持ち越す

回を追うごとに、量が減っていきます。

```
　　1回目　500語
　　2回目　180語
　　3回目　 60語
　　4回目　 20語
```

4回目には、20語です。10分で終わります。

### もう忘れちゃった人へ

いま読んでる人の中に、すでに忘れてしまった人もいると思います。

その場合も、1からやり直さないでください。まず、どれくらい残ってるかを数えます。50個だけテストして、何個出るかを見る。6割出たなら、6割は残ってます。残りの4割だけやれば、戻ります。

　　==「全部忘れた」っていう感覚は、たいてい大げさです。==

## まとめ

忘れるのは、全員に起きます。できる人が忘れないんじゃなくて、==できる人は、忘れる前に1回出してるだけです==。

同じ量を、4分の1の時間で維持できます。

```
　　忘れてから覚え直す人　　500語 × 3回　＝　1,500語ぶん
　　忘れる前に出す人　　　　500 + 180 + 60 + 20　＝　760語ぶん
```

半分の手間で、残ってる量は多いほうです。

```
　　この場面を見つけた問い　　いま、閉じて出せるか？

　　今日やること　今日覚えたものに、カレンダーで3つ印をつける。
　　　　　　　　　翌日、1週間後、1ヶ月後。その日に、閉じて出す
```

# 40　机に座ってから、何をやるか決める

続ける力

## Q「やる気はあるんです。でも、座ってから1時間たってます」

やる気がない、って言われがちなやつです。

でも、これ、やる気の問題じゃありません。入口の問題です。

## 頭のいい人が、絶対にやらないこと

　　==机に座ってから、今日やることを考える。==

座る前に、もう決まってます。

```
　　×　とりあえず座れば、やる気が出る
　　○　座る前に、1つ目だけ決まっている
```

## なぜ、それだと始まらないのか

夜の8時。中学2年生が、机に座りました。

さて、何をやろう。

今日の宿題は、数学のプリント。でも明日は提出じゃない。英語の小テストが明後日ある。単語かな。いや、そういえば理科のワークが溜まってた。教科書を出します。数学。やっぱり英語。筆箱を開けます。シャープペンの芯がない。替えます。

気づくと、8時25分です。まだ1問も解いてません。

机に座った瞬間、頭は休んでます。そこから「何をやるか」を考えるのは、頭を使う作業です。しかも、選択肢が5つも6つもある。どれも「やったほうがいい」ものです。

選べません。

選べないとき、人は何をするか。筆箱を整理します。机を片づけます。芯を替えます。

　　==選ばなくていい作業に、逃げるんです。==

だらしないからじゃありません。選ぶのが大変だから、選ばなくていいことをやってるだけです。

〔図40　入口でつまずいている〕
　「座る → 選ぶ（重い） → やる」と「選ぶ（前日） → 座る → やる」を上下に並べる。
　重い箱が、座る前にどいていることを見せる。

## じゃあ、どうすればいいのか

### 頭のいい人の、頭のなか

同じ夜8時です。

伸びない人

```
　　「よし、やるか」（座る）
　　「何からやろう」
　　「数学は……明日じゃないな」
　　「英語かな。いや、理科が溜まってる」
　　「とりあえず机を片づけるか」
```

頭のいい人

```
　　（座る前に、机の上の紙を見る）
　　「英単語、1番から30番」
　　（座って、単語帳を開く）
```

5秒です。

違いは、==昨日の夜にその紙を書いたかどうか==、だけです。

### 手順

1　今日の勉強が終わったら、紙に1行書く

その日の最後に書きます。頭が、今日やったことをいちばん覚えてるタイミングだからです。

```
　　明日の1つ目　　数学ワーク　41ページ
```

2　その紙を、机の真ん中に置く

引き出しにしまわないでください。座った瞬間に目に入る場所に、置いたままにします。

3　座ったら、それをやる

何も考えません。書いてあることをやります。==やる気があるかどうかは、聞かない。==聞いたら、ないって答えが返ってきますから。

### 1つ目は、2分で終わるものに

もう1つ、コツがあります。紙に書く1つ目を、いちばん軽いものにしてください。

```
　　英語なら　単語を10個見る
　　数学なら　計算問題を3問
　　国語なら　漢字を10個
```

重いものを置くと、座れません。重いものは、乗ってから持ちます。2分やると、乗ってきます。乗ってきたら、本題に入ります。

## まとめ

　　==座ってから決めると、決めることに時間を使います。==

決めるのは、座る前。全部じゃなくて、1つ目だけ。

座ってから決める人は、毎日20分から30分を、決めることに使ってます。1週間で3時間。1ヶ月で12時間です。

そして、もう1つ。始められなかった日が減ります。始められなかった日の理由って、たいてい「何をやるか決まらなかった」なんです。やる気がなかったんじゃありません。==入口が、ふさがってただけです。==

```
　　この場面を見つけた問い　　今日、何個増えた？

　　今日やること　今日の勉強が終わったら、紙に1行だけ書いて、
　　　　　　　　　机の真ん中に置く。明日の1つ目。それだけ
```
