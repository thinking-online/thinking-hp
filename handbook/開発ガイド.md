## 書体

| 用途 | 書体 |
|------|------|
| 見出し（和文） | Zen Old Mincho |
| 本文（和文） | Zen Kaku Gothic New |
| 欧文・数字・英文 | Lora |

日本語は**1文字ずつ空けない**（「本 資 料 に つ い て」のような組版はしない）。
`letter-spacing` は和文で最大 .04em 程度まで。字間を空けるほど「機械が組んだ」印象になる。

## 設計方針

**1つのHTMLが、3つの見え方をする。**

| 環境 | 見え方 |
|------|--------|
| スマホ（〜879px） | 1カラムのスクロール読み物。文字サイズ15px |
| PC（880px〜） | A4（210×297mm）の冊子。ページが積み重なって見える |
| 印刷 / PDF保存 | A4縦・28ページぴったり（`@page size: A4 portrait`） |

- ページ内の要素は基本 `em` 指定。ページの `font-size` を変えるだけで全体が縮む。
- A4に収まらないページには `class="page tight"`（さらに詰めるなら `tight tighter`）を付ける。
- 画面右上の「この冊子を印刷 / PDF保存」ボタン → ブラウザの印刷ダイアログ。

## 次回（第3回）の作り方

```bash
cp -r handbook/jitsuryoku-02 handbook/jitsuryoku-03
```

1. `index.html` の表紙・見出し・出題レベル・基準表を差し替える
2. **ページ番号（`XX / 28`）とフッターのPART名を、増減に合わせて必ず更新する**
3. パス（`/handbook/jitsuryoku-03/styles.css`）を書き換える
4. `netlify.toml` にリダイレクトを追加

```toml
[[redirects]]
  from = "/jitsuryoku-03"
  to = "/handbook/jitsuryoku-03/index.html"
  status = 200
[[redirects]]
  from = "/jitsuryoku-03/*"
  to = "/handbook/jitsuryoku-03/:splat"
  status = 200
```

## A4に収まっているかの確認

ローカルで静的サーバを立てて、各ページの `scrollHeight` が A4（1123px @96dpi）を超えていないかを見る。
超えているページに `tight` を足して調整する。

```bash
python3 -m http.server 8899     # リポジトリ直下で
# → http://localhost:8899/handbook/jitsuryoku-02/index.html
```

## 配布用PDF

`index.html` をブラウザで開き、印刷 → PDF保存（余白なし・背景グラフィックON）。
生成したPDFは同じフォルダに `THINKING-jitsuryoku-0X.pdf` として置く。
**HTMLを更新したらPDFも作り直すこと**（内容がずれる）。
