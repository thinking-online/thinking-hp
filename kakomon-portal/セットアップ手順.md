# 過去問ポータル セットアップ手順（最初の1回だけ）

所要時間：30〜40分。上から順番にやれば終わります。
**手順1〜6はてったさんの作業**、手順7以降はこちら（Claude）で引き取ります。

使うもの：塾用のGoogleアカウント（個人アカウントは不可。全教材がこのアカウントのドライブに入ります）、LINE Developers のログイン

---

## 手順1　スプレッドシートを作る

1. 塾用のGoogleアカウントで Googleスプレッドシートを新規作成
2. 名前を **【過去問ポータル】DB** にする

## 手順2　コードを貼る

1. スプレッドシートのメニュー **拡張機能 → Apps Script** を開く
2. 左上のプロジェクト名を **過去問ポータル** に変える
3. `コード.gs` の中身を全部消して、リポジトリの `kakomon-portal/gas/Code.gs` を丸ごと貼る
4. 左の「ファイル」の **＋ → HTML** で、名前を **Upload** にして作成 → 中身を全部消して `kakomon-portal/gas/Upload.html` を丸ごと貼る
5. 左の歯車（**プロジェクトの設定**）→「**appsscript.json マニフェスト ファイルをエディタで表示する**」に☑
6. エディタに戻り `appsscript.json` を開いて、中身を全部消して `kakomon-portal/gas/appsscript.json` を丸ごと貼る
7. 上の💾（保存）を押す

## 手順3　初期セットアップを実行する

1. スプレッドシートのタブに戻って、ページを再読み込み
2. 上のメニューに **過去問ポータル** が出るので → **初期セットアップ（最初の1回だけ）**
3. 「承認が必要です」→ 続行 → 塾用アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら **詳細 → 過去問ポータル（安全ではないページ）に移動** → 許可
   （自分で作ったスクリプトなので問題ありません）
4. 「セットアップが完了しました」と出たらOK。タブが「問題集・教材・利用者・設定」になっています
5. ドライブに **過去問ポータル（教材PDF）** というフォルダができています（ここに全PDFが入ります）

## 手順4　問題集の一覧（64冊）を取り込む

1. 「問題集」タブを開く
2. **ファイル → インポート → アップロード** で `kakomon-portal/seed/問題集.csv` を選ぶ
3. 「インポート場所」は **現在のシートに追加する** → データをインポート
4. メニュー **過去問ポータル → 今すぐ全員に反映**（IDが自動で入ります）

※ この時点ではすべて「公開」が外れています。教材を入れた問題集から☑していきます。

## 手順5　LIFFアプリを作る（LINE Developers）

塾生判定を THINKING CAMPUS と共通にするため、**CAMPUS と同じチャネル**に作ります。

1. https://developers.line.biz/console/ にログイン
2. THINKING CAMPUS の LIFF（ID が `2010454771-` で始まるもの）が入っている **LINEログインチャネル** を開く
3. **LIFF** タブ → **追加**
   - LIFFアプリ名：過去問ポータル
   - サイズ：Full
   - エンドポイントURL：`https://thinking-online.com/kakomon-portal/`
   - Scope：**openid** と **profile** に☑
   - 友だち追加オプション：Off
4. 作成後に表示される **LIFF ID**（`20…-…` の形）を控える
5. 同じチャネルの **チャネル基本設定** タブにある **チャネルID**（数字）を控える
6. スプレッドシートの「設定」タブ → 「LINEチャネルID」の値の欄に、そのチャネルIDを貼る

## 手順6　Webアプリとして公開する

1. Apps Script の画面右上 **デプロイ → 新しいデプロイ**
2. 種類の選択（歯車）→ **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. デプロイ → 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を控える

**ここまで終わったら、次の2つを Claude に送ってください。**
- LIFF ID
- ウェブアプリのURL

## 手順8　（一緒に）動作確認

1. てったさんのLINEで LIFF URL（`https://liff.line.me/<LIFF ID>`）を開く
2. 初回は「ゲスト」で開き、「利用者」タブに自分の行が自動で追加される
3. その行の **スタッフ** に☑ → ポータルを開き直すと、非公開も含めて全部見える
4. 教材を1つ追加して表示・印刷を確認

## 手順9　（一緒に）既存9大学分の移行

`kakomon/` にあるPDFを、パソコン版Googleドライブ経由で「過去問ポータル（教材PDF）/大学/問題集名/」に入れ、**フォルダから取り込み** で一括登録します。

## 手順10　公開

- リッチメニュー（または THINKING CAMPUS）に LIFF URL を置く
- サンプルにする問題集の「サンプル」に☑

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「通信できませんでした」 | 設定タブの LINEチャネルID が正しいか / デプロイが「全員」になっているか |
| 新しい教材が出てこない | 教材と問題集の両方に「公開」☑があるか → メニュー「今すぐ全員に反映」 |
| PDFが開けない | メニュー「点検」で赤くなった行を確認 |
| GASのコードを更新したとき | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ**（URLは変わらない） |
