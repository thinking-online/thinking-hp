# kakomon/ — 大学別問題集（PDFは置かない）

**教材のPDFはこのリポジトリに置かない。** リポジトリは公開されているため、ここに置くと誰でもダウンロードできてしまう。
生徒への配布は **過去問ポータル**（`kakomon-portal/`、LINEログインの会員限定）に一本化している。

- 教材の作り方・渡し方：`kakomon-portal/教材の納品ルール.md`
- 登録のしかた：PDF一式と `links.txt` を Googleドライブ「過去問ポータル（教材PDF）/<大学名>/<問題集名>/」に入れ、スプレッドシートの「フォルダから取り込み」
- 旧URL `https://thinking-online.com/kakomon/…` は、過去問ポータル（LINE）へ自動で案内される（netlify.toml）

## links.txt（過去問ポータルの目次）

ポータルに出るタイトル・区分・並び順は、問題集ごとの `links.txt` から決まる。問題集を作ったら必ず一緒に作る。

- 「--- 見出し ---」の行で区切る（「--- URLのみ ---」以降は読まない）
- **タイトルの行 → 次の行にURL** の順で書く。タイトルはPDFの表紙と同じ名前（例：`Vol3 大問III 誤り指摘`）
- URLの最後のファイル名（例：`q3-error.pdf`）で、同じフォルダのPDFと対応づける
- 書いた順番がポータルでの並び順になる
- 区分はタイトルの語で自動判定：「模試」→模試、「単語・熟語帳」→単語帳、「Vol0・戦略・分析」→戦略編、「解説」→解説、それ以外→大問別
