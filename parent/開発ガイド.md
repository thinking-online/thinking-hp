# THINKING保護者通信 — 開発・運用ガイド

保護者向け月刊通信サイトの追加・更新手順です。王様通信（`lp/king-letter-*`）とは別に、リポジトリ直下の `parent/` で管理します。

## 公開URL

| ページ | URL |
|--------|-----|
| アーカイブ（バックナンバー一覧） | `https://thinking-online.com/parent` |
| 各号 | `https://thinking-online.com/parent/YYYYMM-NN` |
| 例：8月号 | `https://thinking-online.com/parent/202508-01` |

旧URL `/parent-202506-01` は `/parent/202506-01` へ自動リダイレクトされます。

## 基本方針（7月号以降）

**各号の LP ページ自体が保護者通信です。** PDF へ飛ばさず、すべての本文・画像・説明は `index.html` 上に載せます。

| 種類 | 扱い |
|------|------|
| 保護者通信の本文 | LP 内に直接記載（`#letter` など） |
| 写真・シートのスクショ | `assets/` に配置して LP 内に表示 |
| 英語読解特訓の解説 | **外部リンクのみ**（`link-chip` → 英語精読解説ページ） |
| ページ内ナビ | `#letter` などのアンカー |
| アーカイブ | `/parent`（サイト内） |
| 保護者チャット | LINE（フッター・お問い合わせのみ） |

**外部リンクにしてよいもの：** 英語読解特訓の解説ページ（`thinking-llcarc.github.io/english-lesson/...` または `thinking-online.com/reading-lesson/...`）のみ。

## 公開・非公開の切り替え

**準備ができた号だけ**公開します。未公開の号はフォルダに置いておいても、次の2点をしない限りユーザーからは見えません。

1. `netlify.toml` にリダイレクトを追加しない（任意・推奨）
2. `parent/index.html` のアーカイブにカードを載せない

### 新しい号を公開するとき

1. 号の中身（`index.html`・画像）を仕上げる
2. （任意）`netlify.toml` にリダイレクトを追加
3. `parent/index.html` の `issue-list` **一番上**にカードを追加
4. push → デプロイ

```toml
# THINKING保護者通信 8月号 — /parent/202508-01 で公開
[[redirects]]
  from = "/parent/202508-01"
  to = "/parent/202508-01/index.html"
  status = 200
[[redirects]]
  from = "/parent/202508-01/*"
  to = "/parent/202508-01/:splat"
  status = 200
```

## 毎月の追加手順

### 1. 新しい号フォルダを作る

**直近の完成号（例：8月号）をコピー**してリネームします。

```bash
cp -r parent/202508-01 parent/202509-01
```

命名規則：`YYYYMM-NN`（例：`202509-01`）

### 2. カバー・本文画像を配置する

```bash
cp ~/Desktop/parent-202509-cover.png parent/202509-01/assets/img_cover.png
# 本文用スクショも assets/ に追加
```

### 3. 号の中身を更新する

`parent/202509-01/index.html` を開き、月・セクション・本文・画像を更新します。

| 箇所 | 変更内容 |
|------|----------|
| `<title>` / OGタグ | 月・概要文 |
| パス | `/parent/202509-01/...` |
| `#contents` | 目次（今月のセクション一覧） |
| 各 `#section` | 本文・画像・ハイライト |
| `#reading` | 英語読解特訓 — **解説のみ外部リンク** |

### 4. styles.css

前号からコピーした `styles.css` に、7月号以降の拡張スタイル（`link-chip`・`feature-hero`・`steps-grid` など）が含まれていることを確認。不足していれば `202507-01/styles.css` の末尾ブロックを追記。

### 5. アーカイブにカードを追加

`parent/index.html` の `issue-list` 内、**一番上**に `issue-card` を追加します。

### 6. デプロイ

```bash
git add parent/202509-01 parent/index.html
git commit -m "publish parent letter 202509"
git push
```

## 各号のコンテンツ構成（7月号以降の例）

号ごとにセクションは増減してよい。目次 `#contents` と quicknav を合わせて更新する。

| セクション例 | ID | 内容 |
|-------------|-----|------|
| その月の保護者通信 | `#letter` | ハイライト・塾からのメッセージ |
| 夏期特訓・単元演習 など | `#units` `#summer` など | 取り組み説明＋シート画像 |
| 英文解釈 | `#english-interp` | 説明＋演習イメージ |
| 実力テスト | `#mock` | 日程・位置づけ |
| 英語読解特訓 | `#reading` | 応用/基礎クラス — **解説ページへの link-chip のみ外部** |
| 受験本番へ | `#exam-season` | 過去問・進路 |

## 英語読解特訓のリンク形式

**PDF は使わない。** 各カードの大学名と一致する解説ページへ `link-chip` でリンクする。

```html
<a class="link-chip" href="https://thinking-llcarc.github.io/english-lesson/tokyo-university-of-science-2023-english-q1.html"
   target="_blank" rel="noopener noreferrer">東京理科大学 解説</a>
```

- ラベルは **「○○大学 解説」**（複数大学の日は chip を分ける）
- 中央大学法学部などサイト内解説は `/reading-lesson/chuo-law-2023` も可
- 存在しない `/pdfs/parent-*-reading-*.pdf` へのリンクは **作らない**

PDF ボタン（`btn btn-sage` → `/pdfs/...`）は **使わない**（6月号の保護者通信PDFなど旧形式を除く）。

## 画像について

- カバー：`parent/YYYYMM-01/assets/img_cover.png`（1024×1024 推奨）
- 本文用：`assets/img_*.png` — LP 内に `<figure class="feature-hero">` または `img-pair` で表示
- アーカイブ上部：`parent/assets/img_archive_hero.png`（全号共通）
- スマホで見切れないよう `width: 100%`・`max-width: 100%` を維持（7月号 styles 参照）

## トラブルシューティング

- **ページが 404** → `netlify.toml` のリダイレクト、または `index.html` の存在を確認
- **画像が表示されない** → パスが `/parent/YYYYMM-01/assets/...` 形式か確認
- **レイアウトが崩れる** → 前号の `styles.css` をコピーしたか、`feature-hero` 等の拡張 CSS があるか確認
