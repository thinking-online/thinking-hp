# 英語設計診断（/shindan/eigo/）

学年別・全14問の英語力診断。診断結果をコピーしてLINEに送ってもらい、
そのリストをもとに個別面談 → 英語講座へつなげるための入口ページ。

- 公開URL: `https://<サイトドメイン>/shindan/eigo/`（フォルダ直下の index.html がそのまま配信される）
- 依存なし・単一HTMLファイル。ビルド不要。

## 導線設計（全体フロー）

1. スタート → STEP1 学年（中1〜高3・既卒の7分岐）→ STEP2 志望校（自由入力）→ STEP3 英語偏差値（帯選択）
2. 学年に応じた14問のテスト（中1〜高3で6セット。既卒は高3セット）
3. 結果シート表示（スコア／タイプ／4分野グラフ／弱点単元／夏の処方箋）
4. 「結果をコピーする」→「LINEを開いて送る」→ トークに貼り付けて送信
5. 送られてきたテキストには **学年・志望校・偏差値・タイプ・弱点単元・1問ごとの正誤（○×14個）・診断コード** が
   全部入っているので、そのまま面談準備の資料になる

## 運用前の差し替えポイント（index.html 冒頭の ★マーク）

| 変数 | 内容 |
|---|---|
| `LINE_URL` | 公式LINEのURL（現在は shindan/min と同じLIFFリンクを設定済み） |
| `GIFT_TEXT` | 送信特典の文言 |
| `QUIZZES` | 問題データ（下記ポリシーに従って編集） |
| `TYPES` | タイプ名・説明文・「夏の処方箋」3ステップ |

## 問題設計ポリシー（ここが命）

各学年14問 ＝ **語彙4／文法4／構造3／読解3**。

1. **語彙は「意味当て」禁止**。必ず文脈の中の空所補充にする（丸暗記の想起だけでは解けず、
   使える語彙かどうかを測る）。誤答の選択肢は同品詞・同レベル帯から選ぶ。
2. **文法は誤答1つ1つに「典型的なつまずき」を対応させる**。
   例: `My sister ( ) fifteen years old next month.` の誤答 `will` は
   「will の後ろに be が必要なことを理解していない」生徒を検出する。
3. **構造は暗記では解けない問題にする**。SVOC判別・節の働き・省略・挿入など、
   文の構造が見えているかだけを問う。
4. **読解は必ず短いパッセージ＋根拠のある設問**。指示語（it / one / This）、
   論理マーカー（However / For example / In other words）、内容一致のいずれか。
5. **正解は必ず1つに定まること**。「口語ならアリ」「文法的には成立する」選択肢は置かない。
   （例: 平叙文＋?の疑問文は口語で成立してしまうので誤答に使わない）
6. **出題範囲は「その学年の8月時点で既習」の内容に限定**。
   - 中1: be動詞・一般動詞・疑問文/否定文・can まで（三単現・過去形は出さない）
   - 中2: 過去形・未来・不定詞・接続詞まで（比較・受動態は出さない）
   - 中3: 現在完了・受動態・不定詞応用まで（分詞・関係代名詞は出さない）
   - 高1: 5文型・時制・助動詞・受動態まで（関係詞・仮定法は出さない）
   - 高2: 関係詞・比較・動名詞/不定詞・仮定法過去まで（分詞構文は出さない）
   - 高3・既卒: 全範囲
7. データ上は `a:0`（先頭が正解）で統一し、表示時にシャッフルする。

## 問題QCチェックリスト（追加・変更したら必ず全項目）

- [ ] 正解が1つに定まるか（誤答が文法的にも意味的にも成立しないか、ネイティブ視点でも確認)
- [ ] その学年の8月時点で既習範囲か（教科書進度と照合）
- [ ] 丸暗記の想起だけで解けない形になっているか
- [ ] 英文が自然か（冠詞・コロケーション・タイポ）
- [ ] 和訳・選択肢の日本語が英文と正確に対応しているか
- [ ] 誤答がそれぞれ「特定のつまずき」を検出する設計になっているか
- [ ] 単元名 `u` が結果画面・LINEテキストに出て意味が通るか（「分野：単元名」形式）

運用フロー: **問題作成担当が作る → 別の担当（またはAIに敵対的レビューを依頼）がチェック → 修正して反映**。
作成者自身のチェックだけで公開しない。

## 判定ロジック

- スコア = 正答数/14 を100点換算。Lv5:90〜 / Lv4:75〜 / Lv3:58〜 / Lv2:40〜 / Lv1:〜39
- タイプ判定: 4分野すべて75%以上 → 実戦設計型／2分野以上が50%未満 → 基礎再設計型／
  それ以外 → 最も正答率の低い分野のタイプ（単語迷子型・文法穴あき型・構造ブラックボックス型・読解失速型）
- 弱点単元 = 誤答した問題の単元名（最大4つ）

## 面談側の読み方（送られてきたテキスト）

- 「正誤：○×…」は出題順と対応（Q1〜Q4語彙 / Q5〜Q8文法 / Q9〜Q11構造 / Q12〜Q14読解）。
  ×の位置と `QUIZZES` を突き合わせれば、どの単元で落としたかが1人ずつ特定できる。
- 診断コードは「TH-月日-ランダム4文字」。同一人物の再受験はコードで区別。
