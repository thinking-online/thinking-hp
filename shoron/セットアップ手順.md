# 小論文ポータル セットアップ手順（最初の1回だけ）

所要時間：30〜40分。**手順1〜6はてったさんの作業**、手順7以降は Claude が引き取ります。
先に画面だけ見たいときは、設定なしで `https://thinking-online.com/shoron/?preview=1` が開けます。

使うもの：塾用のGoogleアカウント、LINE Developers のログイン、Anthropic の API キー（AI の下書きを使うとき）

## 手順1　スプレッドシートを作る

塾用のGoogleアカウントで新規作成し、名前を **【小論文ポータル】DB** にする。

## 手順2　コードを貼る

1. **拡張機能 → Apps Script** を開き、プロジェクト名を **小論文ポータル** にする
2. `コード.gs` の中身を全部消して、`shoron/gas/Code.gs` を丸ごと貼る
3. 歯車（プロジェクトの設定）→「appsscript.json マニフェスト ファイルをエディタで表示する」に☑ → `appsscript.json` を `shoron/gas/appsscript.json` の中身に置きかえる
4. 保存

## 手順3　初期セットアップ

1. スプレッドシートを再読み込み → メニュー **小論文ポータル → 初期セットアップ（最初の1回だけ）**
2. 承認を求められたら塾用アカウントで許可（「確認されていません」は 詳細 → 移動）
3. タブが「課題・提出・利用者・観点・設定」になり、練習課題が4つ入っていればOK

## 手順4　AI のキーを入れる

1. https://platform.claude.com で API キーを作る
2. Apps Script の歯車（プロジェクトの設定）→ **スクリプト プロパティ** → プロパティを追加
   - プロパティ `ANTHROPIC_API_KEY`、値にキー
3. キーは**ここ以外（シート・チャット・ファイル）に貼らない**

AI を使わずに講師だけで添削するなら、この手順は飛ばして「設定」シートの「AI下書き」を `オフ` にする。

## 手順5　LIFFアプリを作る

THINKING CAMPUS・過去問ポータルと**同じ LINEログインチャネル**に作ります。

1. https://developers.line.biz/console/ → そのチャネル → **LIFF → 追加**
   - 名前：小論文ラボ ／ サイズ：Full ／ エンドポイントURL：`https://thinking-online.com/shoron/` ／ Scope：openid・profile
2. **LIFF ID** を控える
3. 同じチャネルの **チャネルID**（数字）を「設定」シートの「LINEチャネルID」に入れる

## 手順6　Webアプリとして公開

Apps Script の **デプロイ → 新しいデプロイ → ウェブアプリ**（実行：自分 ／ アクセス：全員）→ 表示された URL（…/exec）を控える。

**LIFF ID と ウェブアプリのURL を Claude に送ってください。**

## 手順7　（Claude）画面に設定を入れて公開

`shoron/index.html` の `LIFF_ID` と `GAS_URL` に入れて push。

## 手順8　（一緒に）動作確認

1. LINE で `https://liff.line.me/<LIFF ID>` を開く →「利用者」シートに自分の行が入る
2. その行の **講師** に☑ → 開き直すと添削の画面になる
3. もう1台（または別の人）で生徒として1本提出 → 1〜2分で「提出」シートの状態が「AI下書き済」になる → 講師の画面で直して返却

## 運用で触るところ

| やりたいこと | 場所 |
|---|---|
| 課題を足す | 「課題」シートに1行。「出題のねらい」を必ず書く（AI の添削の質が変わる）。公開☑ |
| 過去問を課題にする | 課題文は貼らず「課題文PDF」にドライブのリンク |
| 塾生以外に受講させる | 「利用者」シートのその人の「受講」☑ |
| 講師を足す | 「利用者」シートの「講師」☑ |
| 配点・レベルの文を直す | 「観点」シート（キーの列は変えない） |
| AI を止める／手動にする | 「設定」シートの「AI下書き」 |
| 講師の確認なしで返す | 「設定」シートの「返却のしかた」を `AIの下書きをすぐ返却`（おすすめしません） |
| 返却を LINE で知らせる | スクリプト プロパティ `LINE_CHANNEL_ACCESS_TOKEN` に公式LINE（Messaging API）のチャネルアクセストークン |

## 生徒・保護者への説明について

答案は添削の下書きを作るために AI（Anthropic の Claude API）に送られます。氏名と LINE ID は送りません。受講の案内にこの点を書いておいてください。

## 自動デプロイ（任意）

過去問ポータルと同じ仕組みです。GitHub の Variables に `SHORON_SCRIPT_ID`（スクリプトID）と `SHORON_DEPLOYMENT_ID`（デプロイID）を足すと、main に入った時点で GAS が自動で更新されます（`CLASPRC_JSON` は過去問ポータルのものを共用）。
