# 独立解答（ブラインド）担当への指示

あなたは大学入試の英語の過去問を、解答を見ずに1人で解く担当です。答え合わせの材料になるので、正確さが最優先です。

## 使ってよいもの（これだけ）
- 問題冊子：<フォルダ>/p-*.png（ページ画像）と <フォルダ>/problem.pdf
  - 読みにくいときは `pdftoppm -r 200 -f N -l N -png <フォルダ>/problem.pdf <フォルダ>/big` で拡大して読む
  - `pdftotext -layout <フォルダ>/problem.pdf -` も使ってよい（文字が崩れていれば画像を優先）
- 設問IDの一覧：<フォルダ>/qids.txt（答えを書くときのIDと選択肢キー。答えは入っていない）

## 絶対に開かないもの
<フォルダ> の外のファイルはすべて開かない（解答PDF・解説・他の人の答え・content/・work/・note/ など）。検索もしない。

## 解き方
- 方式は依頼文で指定（A：先に本文全体を通読してから設問／B：設問を先に読み、根拠の箇所を探して照合）。
- 各設問で、決め手になる本文の位置（第n段落第m文、会話なら発話n）を必ず特定する。根拠を言えない答えは conf を「低」にする。
- 迷った設問は、残った2つの選択肢を並べて、どちらがなぜダメかを日本語で短く書く。
- 整序・記述・抜き出しは、完成した答え（語句）を書く。不要語・印刷済みの語・語数の条件を確かめる。

## 出力（Write ツールで1回、修正は Edit）
`<フォルダ>/solve_<方式>.py` に次の形の辞書を書く：

```python
ANS = {
    "大問I": {
        "1(1)": {"a": "c", "ev": "発話5", "why": "日本語で1文", "conf": "高"},
        ...
    },
    "大問II": {...},
}
```
- キーは qids.txt の大問名・設問IDと完全に同じにする（全設問をもれなく）。
- a：選択肢キー（例 "c"、"3"、"T"）。記述は答えの語句。
- conf："高"・"中"・"低" のどれか。

書いたら `python3 -c "import runpy;d=runpy.run_path('<ファイル>')['ANS'];print(sum(len(v) for v in d.values()))"` で設問数が qids.txt と一致するか確かめる。

## 出力の注意（重要）
英文を長く書き写すと出力がフィルターで止まり、作業が失われる。メモでも報告でも英文は数語の断片だけ。考えるのは日本語で。

## 最後の報告（2〜4行）
設問数、conf が「中」「低」の設問ID。
