# 明治大学 法学部 用の追加指示（WRITER_BRIEF.md に加えて守る）

- 大学・学部：明治大学 法学部（学部別入試）。大問は年度によって2つ（I・II）。1つの大問の本文が長い（700〜1,500語）。
- 見本：スキーマと品質の基準は早稲田の見本（wsc25/content/parts/part*.py）と同じ。選択肢は数字（"1"〜"4"）なので、choices の key は "1"〜"4"、answer も数字の文字列にする。
- 設問の id は冊子の表記どおり（例："1-(ア)"、"2-(A)"、"3-(B)"、"4"）。問の番号と枝番を必ず両方入れる。冊子に無い枝番（例：(キ)が無い）は作らない。
- 日本語の記述（○字以内）：answer_display に解答例（字数を数えて明記）、examples に解答例と要点（採点で見られるポイントを2〜4つ）、ng に減点例（要点の欠け・字数オーバー・主語や因果の取り違え）。build.py の chars（マス目）を使う場合は見本 wsc25/content/parts/part5.py や 2026年度の part の書き方に合わせ、字数制限と一致させる。公式の解答例があるときはそれを「大学の解答例」として示し、THINKING の別の言い方も添えてよい。市販の解答の文章は写さない。
- 英語1語や語句を書く記述（空所に1語など）：answer/examples/ng で、別解として成り立つ語・成り立たない語を明示する。
- 1つの大問の英語の量の制限（body_words の約3割以内、1引用は原則1文）は同じ。本文が長いので根拠の英文は短い断片にする。
- checked：公式解答がある年は「公式解答と一致」、それ以外は「市販の解答・THINKINGの解答と一致」（確定解答のメモに従う）。
- 出典（source）は冊子の表記どおりに日本語で：例「The Guardian 掲載の記事（Coco Khan, 2023）に基づく（大学の冊子の表記 “…” による）」、書籍は「書籍『…』（著者, 年）に基づく」。
